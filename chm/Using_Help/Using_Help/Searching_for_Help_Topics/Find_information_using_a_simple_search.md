# Find information using a simple search

*Using Help › Search for Information*

1.  Click the **Search** tab.

2.  Type the [words or phrases](Search_for_words_or_phrases.md) you want to find in the **Type in the word(s) to search for** list.

3.  Decide if you want to:

    - <a href="Find_words_similar_to_your_search_term.md" class="hcp1">Find words similar to your search term</a>.

    - <a href="Search_only_the_last_group_of_topics.md" class="hcp1">Search only the last group of topics</a>.

    - <a href="Search_topic_titles_only.md" class="hcp1">Search topic titles only</a>.

4.  Click **List Topics**.

5.  Click the topic you want, and then click **Display**.

> [!NOTE]
>
> - The search terms will be *highlighted* in each topic when it is displayed. To clear this highlighting, click the **Refresh** button on the [Help toolbar](../Help_Window/Help_window_screen_shot.md).
