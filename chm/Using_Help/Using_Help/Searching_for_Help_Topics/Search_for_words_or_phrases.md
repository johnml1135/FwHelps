# Search for words and phrases

*Using Help › Search for Information*

You can search for words alone, or you can search for combinations of words (phrases). You can also use *wildcard expressions* with both these searches. *Wildcard* expressions allow you to search for one or more characters using a *question mark* (?) or *asterisk* (\*). The table below describes the results of these different kinds of searches.
