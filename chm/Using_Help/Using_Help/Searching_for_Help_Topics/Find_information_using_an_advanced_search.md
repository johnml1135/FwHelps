# Find information using an advanced search

*Using Help › Search for Information*

1.  Click the **Search** tab.

2.  Type the [words or phrases](Search_for_words_or_phrases.md) you want to find in the **Type in the word(s) to search for** list.

3.  Use any [nested expressions](Search_using_nested_expressions.md) for complex searches.

4.  Click ![](Black_arrow_right.gif) to add [boolean operators](Search_using_boolean_operators.md) to your search terms.

5.  Click **List Topics**.

6.  To sort the topic list, click the **Title**, **Location**, or **Rank** column heading.

7.  Select the topic you want, and then click **Display**.
