# Using Help overview

*Using Help*

With Using Help, you will be able to:

- Use the [Help Window](Help_Window/Help_Window_overview.md) to find, resize, reformat, copy, and print Help topics.

- [Search for Information](Searching_for_Help_Topics/Search_for_Information_overview.md) using basic and advanced techniques.

- Learn [Shortcuts](Shortcuts/Shortcuts_overview.md) to manage the Help tabs and the Help window.

> [!NOTE]
>
> - If you are new to using Help, we suggest you *first* start learning about Help Windows.
