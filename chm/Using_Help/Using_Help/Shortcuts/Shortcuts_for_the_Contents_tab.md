# Shortcuts for the Contents tab

*Using Help › Shortcuts*

| To                            | Press                       |
|-------------------------------|-----------------------------|
| Open a book.                  | `Left Arrow`                |
| Close a book.                 | `Right Arrow`               |
| Select a topic.               | `Down Arrow` and `Up Arrow` |
| Display the selected topic.   | `Enter`                     |
| Display the **Contents** tab. | **Alt+C**                   |

| To | Command |
|----|----|
| Expand all books in the table of contents. | Right-click in the **Contents** tab, and then click **Open All**. |
| Collapse all books in the table of contents. | Right-click in the **Contents** tab, and then click **Close All.** |
