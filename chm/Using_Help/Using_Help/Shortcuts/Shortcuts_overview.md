# Shortcuts overview

*Using Help › Shortcuts*

Shortcut keys are individual keys and key combinations you can use to speed up your work.

The following keyboard shortcuts can be used for navigation in the Help window:

[Shortcuts for the Help window](Shortcuts_for_the_Help_window.md).

<a href="Shortcuts_for_the_Options_menu.md" style="x-condition: HTML_only;">Shortcuts for the Options toolbar</a>.

[Shortcuts for the Contents tab](Shortcuts_for_the_Contents_tab.md).

[Shortcuts for the Index tab](Shortcuts_for_the_Index_tab.md).

[Shortcuts for the Search tab](Shortcuts_for_the_Search_tab.md).

[Shortcuts for the Favorites tab](Shortcuts_for_the_Favorites_tab.md).

> [!NOTE]
>
> - Shortcuts also work in secondary and pop-up windows.
>
> - When you use a shortcut in the [Navigation pane](../Help_Window/Help_window_screen_shot.md), you may lose focus in the Topic pane. To return to the [Topic pane](../Help_Window/Help_window_screen_shot.md), press `F6`.
