# Understanding Help window panes

*Using Help › Help Window*

The [Help window](Help_window_screen_shot.md) contains a toolbar and two panes.

- The *Help toolbar* is below the Using Help window title bar.

- The *Navigation pane is o*n the left of the window. It contains four tabs: the **Contents** tab, the **Index** tab, the **Search** tab, and the <a href="Create_a_list_of_favorite_Help_topics.md" style="x-condition: HTML_only;">Favorites</a> tab.

- The *Topic pane* (also known as the *Content pane*) is on the right of the window. It displays the selected Help topic.

> [!NOTE]
>
> - Understanding these panes will help you [find a help topic](Find_a_Help_topic.md).
