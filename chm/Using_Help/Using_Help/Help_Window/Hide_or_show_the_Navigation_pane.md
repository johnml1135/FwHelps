# Hide or show the Navigation pane

*Using Help › Help Window*

- On the toolbar, click **Hide** or **Show** to close or display the Help Navigation pane, which contains the **Contents**, **Index**, **Search**, and **Favorites** tabs.

> [!NOTE]
>
> - If you close the Help window with the Help [Navigation pane](Help_window_screen_shot.md) hidden, it *may* appear that way when you open the Help window again.
