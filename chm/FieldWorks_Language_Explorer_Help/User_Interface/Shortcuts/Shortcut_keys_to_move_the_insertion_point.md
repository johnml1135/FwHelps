# Shortcut keys to move the insertion point

*User Interface › Shortcuts*

This table is for use with fields in panes, such as the **Entry** pane in **Lexicon Edit**. For dialog boxes, see [Shortcut keys for use with dialog boxes](shortcut_keys_for_use_with_dialog_boxes.md).

<table width="100%">
<tbody>
<tr>

<th style="width: 46%"><p>Press</p></th>
</tr>
&#10;<tr>
<td style="width: 54%"><p>To move the insertion point <em>by code point</em> (split the insertion point around and between diacritics) instead of <em>by base character and its diacritic(s)</em></p></td>
<td style="width: 46%"><p><strong>F7</strong> or <strong>F8</strong><a href="../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/about_font_features.md"><br />
About Font Features</a> has more information.</p></td>
</tr>
<tr>
<td style="width: 54%"><p>To move the insertion point over a base character and its diacritics with one press of a key</p></td>
<td style="width: 46%"><p><strong>Left Arrow</strong> or <strong>Right Arrow</strong> key</p></td>
</tr>
<tr>
<td style="width: 54%"><p>Move focus vertically down to the next field, button, or list down arrow</p></td>
<td style="width: 46%"><p><code>Tab</code></p></td>
</tr>
<tr>
<td style="width: 54%"><p>Move focus vertically up to next field, button, or list down arrow</p></td>
<td style="width: 46%"><p><code>Shift+Tab</code></p></td>
</tr>
<tr>
<td style="width: 54%"><p>In a <a href="../Field_Descriptions/Field_Types/Single_line_text_field_example_graphic.md">single-line text field</a> with multiple lines displayed (with different writing systems), to move to an adjacent line in the same field</p></td>
<td style="width: 46%"><p><code>Ctrl+Down Arrow</code> or <code>Ctrl+Up Arrow</code></p></td>
</tr>
<tr>
<td style="width: 54%"><p>To move focus into a list and then select an item in a list (for fields with a down arrow, such as the <a href="../Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Grammatical_Info_field.md">Grammatical Info</a> in <strong>Sense 1</strong>, <strong>Sense 2</strong>, and so on in a lexical entry).</p></td>
<td style="width: 46%"><p><code>Tab</code> or <code>Shift+Tab</code> to move the focus into the field, and then type the first letter of the desired list item to select it. Use <code>Tab</code> or <code>Shift+Tab</code> to leave the field.</p></td>
</tr>

<td style="width: 46%"><p><em>Or</em></p></td>
</tr>
<tr>
<td style="width: 54%"></td>
<td style="width: 46%"><p><code>Tab</code> or <code>Shift+Tab</code> to move the focus into the field, and then press the <code>Spacebar</code> (or <code>Alt+Down Arrow</code>) to open the list.</p>
<p>Then, use the <code>Up/Down Arrow</code> keys to move focus to an adjacent list item, and then press <code>Enter</code> to select the list item and close the list.</p></td>
</tr>
<tr>
<td style="width: 54%"><p>To select or clear a check box in a lexical entry (such as in the <a href="../Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Allomorph_Status_field.md">Is Abstract Form</a> field)</p></td>
<td style="width: 46%"><p><code>Tab</code> or <code>Shift+Tab</code> to move the focus into the check box, the press the <code>Spacebar</code> to select or clear the check box.</p>
<p>(There may or may <em>not</em> be a visual indication that the check box is selected. However, notice the menu button to the left of the label.)</p></td>
