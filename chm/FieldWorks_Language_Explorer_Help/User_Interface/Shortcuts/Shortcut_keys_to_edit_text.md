# Shortcut keys to edit text

*User Interface › Shortcuts*

|  |  |
|----|----|
| To | Press |
| [Cut](../Menus/Edit/Cut_copy_and_paste.md) the selected text to the Clipboard | `Ctrl+X` |
| [Copy](../Menus/Edit/Cut_copy_and_paste.md) the selected text to the Clipboard | `Ctrl+C` |
| [Paste](../Menus/Edit/Cut_copy_and_paste.md) the text in the Clipboard at the insertion point | `Ctrl+V` |
| [Undo](../Menus/Edit/Undo_and_Redo.md) (reverse the effect of the most recent change). | `Ctrl+Z` |
| [Redo](../Menus/Edit/Undo_and_Redo.md) (reverse the effect of the most recent **Undo**). | `Ctrl+Y` |
