# Shortcut keys: Notebook tools

*User Interface › Shortcuts*

|  |  |
|----|----|
| To | Press |
| **Find** a fieldnote record | `Ctrl+F` |
| **Find** a string of characters (a character, morpheme, word, and so on) | `Ctrl+Shift+F` |
| **Replace** a string of characters (a character, morpheme, word, and so on) | `Ctrl+H` |
| **Insert** a fieldnote record | `Ctrl+I` |
| **Move** to the *previous* record | `Alt+P` |
| **Move** to the *next* record | `Alt+N` |
| **Refresh** the window | `F5` |
| **Select All** | `Ctrl+A` |
| **Use** an ellipsis button **![](../../assets/images/Ellipsis_button.PNG)** open a [dialog box](shortcut_keys_for_use_with_dialog_boxes.md) | `Tab` onto the desired ellipsis button, and then press `Enter.` |
