# Shortcut keys overview

*User Interface › Shortcuts*

Shortcut keys are individual keys and key combinations that you can use to speed up your work. Most shortcut keys invoke commands that are also available on menus and toolbars.

### Key combination notation

- Press `Ctrl+C` means press and hold `Ctrl`, and then press `C`.

- Press `Shift+Left Arrow` means press and hold `Shift`, and then press `Left Arrow`.

- Press `Ctrl+Shift+S` means press and hold `Ctrl` and `Shift`, and then press `S`.

- Other *Microsoft-common* shortcut methods are available throughout FieldWorks Language Explorer, but are not fully described in these `User Helps`.

- [About Font Features](../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/about_font_features.md) describes moving the insertion point through characters and diacritics by code point.

- [Insert a NBSP](../Menus/Insert/Insert_a_NBSP.md) describes how to insert a non-breaking space.
