# Show a hidden toolbar or menu bar

*User Interface › Changing toolbars and menus*

**Not currently implemented**

1.  In any window, point to the unused area to the right of the [toolbars](../Toolbars/Toolbars_overview.md), and then right-click.

    A menu with a list of toolbars appears.

2.  In the menu, do one of the following:

    - Click the toolbar to add the check mark.

      The toolbar is added to the window.

    - Click **Customize** to open the **Customize** dialog box. Add a check mark to the check box for each toolbar you want to show, or to the **Menu Bar**, and then click **Close**.

      Each bar with a check mark appears in the window.
