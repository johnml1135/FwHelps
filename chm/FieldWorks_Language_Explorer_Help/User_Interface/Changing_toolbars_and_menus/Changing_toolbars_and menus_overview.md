# Changing toolbars and menus overview

*User Interface › Changing toolbars and menus*

## Definitions:

- The *menu bar* is the horizontal bar *below* the Title bar that contains the names of menus.

- A *menu* is a list of commands that appears when you click a menu name on a menu bar or other toolbar. A menu command can include a [shortcut key](../Shortcuts/shortcut_keys_overview.md) or an associated toolbar icon (button), or both.

- A *toolbar* is a row of buttons, boxes, and lists that you use to carry out commands.
