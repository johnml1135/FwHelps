# Hide a toolbar or the menu bar

*User Interface › Changing toolbars and menus*

**Not currently implemented**

1.  In any window, point to the unused area to the right of the [toolbars](../Toolbars/Toolbars_overview.md), and then right-click.

    A menu with a list of toolbars appears.

2.  In the menu, do one of the following:

    - Click the toolbar to remove the check mark.

      The toolbar removed from the window.

    - Click **Customize** to open the **Customize** dialog box. Remove the check mark from the check box for each toolbar you want to hide, or from the **Menu Bar**, and then click **Close**.

      Each toolbar without a check mark is removed from the window.

> [!NOTE]
>
> - The **Menu Bar** command is re-selected automatically so you cannot hide the menu bar.
