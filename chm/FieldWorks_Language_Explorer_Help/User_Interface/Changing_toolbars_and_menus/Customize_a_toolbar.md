# Customize a toolbar

*User Interface › Changing toolbars and menus*

**Not currently implemented**

1.  In any window, point to the unused area to the right of the [toolbars](../Toolbars/Toolbars_overview.md), and then right-click.

2.  Click **Customize**.

    The **Customize** dialog box appears.

3.  In the dialog box, do one or more of the following:

    - [Hide a toolbar](Hide_a_toolbar_or_menu_bar.md).

    - [Show a hidden toolbar](Show_a_hidden_toolbar_or_menu_bar.md).

    - Click the **Options** tab. Under the **Other** label, select or clear the check boxes as desired to show/hide tool tips (screen tips) or [shortcut keys](../Shortcuts/shortcut_keys_overview.md) in them, and then click **Close**.
