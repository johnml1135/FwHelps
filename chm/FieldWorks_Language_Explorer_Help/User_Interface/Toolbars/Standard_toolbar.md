# Standard toolbar

*User Interface › Toolbars*

|  |  |  |
|----|----|----|
| To | Click | Press |
| Move *back* to the previous view | ![](../../assets/images/User_Interface/Toolbars/GreenBackArrow.GIF) | `Alt+Left` |
| Move *forward* to the previous view | ![](../../assets/images/User_Interface/Toolbars/GreenForwardArrow.GIF) | `Alt+Right` |
| *Delete* the current record | ![](../../assets/images/User_Interface/Toolbars/RedDeleteRecordX.GIF) | `Ctrl+Delete` |
| [Undo](../Menus/Edit/Undo_and_Redo.md) the effect of the most recent change. | ![](../../assets/images/User_Interface/Toolbars/Undo.gif) | `Ctrl+Z` |
| [Redo](../Menus/Edit/Undo_and_Redo.md) the effect of the most recent undo. | ![](../../assets/images/User_Interface/Toolbars/Redo.gif) | `Ctrl+Y` |
| *Refresh* the screen | ![](../../assets/images/User_Interface/Toolbars/RefreshButton.GIF) | `F5` |
| Display the *first* record | ![](../../assets/images/User_Interface/Toolbars/BlueFirstRecordArrow.GIF) |  |
| Display the *previous* record | ![](../../assets/images/User_Interface/Toolbars/BluePreviousRecordArrow.GIF) | `Alt+P` |
| Display the *next* record | ![](../../assets/images/User_Interface/Toolbars/BlueNextRecordArrow.GIF) | `Alt+N` |
| Display the *last* record | ![](../../assets/images/User_Interface/Toolbars/BlueLastRecordArrow.GIF) |  |
| Use [Send/Receive](../../Basic_Tasks/Collaborating_with_Others/Send_Receive_overview.md) (**Project** *or* **Lexicon**, whichever you used *last*) | ![](../../assets/images/User_Interface/Toolbars/Send_Receive_Icon.png) | `Ctrl+R` |

> [!NOTE]
>
> - "Record" refers to a lexical entry in **Dictionary**, a reversal entry in **Reversal Indexes**, and so on.
>
> - In [Grammar Sketch](../../Using_Tools/Grammar_tools/Grammar_Sketch/Using_a_Grammar_Sketch.md), the ![](../../assets/images/User_Interface/Toolbars/left_and_right_arrows.png) buttons appear below the toolbars, near the **Generate** button. These allow you to move backwards or forward to previously visited locations *in the sketch*.
