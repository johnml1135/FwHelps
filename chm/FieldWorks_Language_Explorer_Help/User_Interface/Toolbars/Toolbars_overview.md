# Toolbars overview

*User Interface › Toolbars*

These toolbars provide fast access to commands:

[Standard toolbar](Standard_toolbar.md)

[Format toolbar](Format_toolbar.md)

[Insert toolbar](Insert_toolbar.md)

[View toolbar](View_toolbar.md)

[Information bar](information_bar_overview.md)

> [!TIP]
>
> - To see a Tool Tip, rest the mouse pointer on a toolbar button.
>
> - A toolbar button that appears dimmed is unavailable for any of the following reasons: the position of the insertion point, the selection, or the active view.
>
> - Most toolbar buttons correspond to frequently used commands on the [menus](../Menus/Menus_overview.md).
