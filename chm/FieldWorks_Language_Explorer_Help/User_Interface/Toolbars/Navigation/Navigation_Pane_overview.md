# Navigation Pane overview

*User Interface › Toolbars › Navigation*

The **Navigation Pane** [(example)](Navigation_Pane_graphic.md) is located along the left edge of the FieldWorks Language Explorer window. It contains area buttons (buttons) that open the available *areas*. When you click a button, the *tools or views* that are available in that area appear above the buttons. Click a tool or view to display it in the window.

To customize the way the **Navigation Pane** appears, you can do any of the following:

[Add or Remove, Show More or Show Fewer Navigation Pane buttons](add_or_remove_navigation_pane_buttons.md).

Use the [Navigation Pane Options](Navigation_Pane_Options_dialog_box.md) **dialog box to work with buttons, such as change their order.**

> [!NOTE]
>
> - The controls for these buttons are interrelated. So if you change the order of buttons, the results are different depending on if you have hidden or removed some of the buttons.
