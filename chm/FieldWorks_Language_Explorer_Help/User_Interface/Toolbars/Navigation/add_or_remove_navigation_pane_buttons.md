# Add, Remove, Show More or Show Fewer Navigation Pane buttons

*User Interface › Toolbars › Navigation*

In the **Navigation Pane** [(example)](Navigation_Pane_graphic.md), the area buttons (buttons) are named **Lexicon**, **Texts & Words**, **Grammar**, and so on. Each button has a unique icon.

Below these area buttons is an space with a double-right arrow ![](../../../assets/images/User_Interface/Toolbars/Navigation/double_rightarrow.PNG) which you can click to open a menu.

- Click ![](../../../assets/images/User_Interface/Toolbars/Navigation/double_rightarrow.PNG), and do one of the following:

  - Click **Show More Buttons**.

    The *most recently-hidden* area button is shown again.

  - Click **Show Fewer Buttons**.

    The *lowest* area button is hidden, and a functional icon is added.

  - Click **Navigation Pane Options** to use the [Navigation Pane Options](Navigation_Pane_Options_dialog_box.md) dialog box.

  - Point to **Add or Remove Buttons**, and then click an area in the submenu. Result:

    Those *with* a highlighted icon (selected) are shown either as buttons *or* as icons next to the double-right arrow (as vertical space below the [blue bar](Navigation_Pane_graphic.md) permits).

    Those *without* a highlighted icon (cleared) are hidden (*not* shown as buttons *or* as icons).
