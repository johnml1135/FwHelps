# Navigation Pane Options dialog box

*User Interface › Toolbars › Navigation*

You can use the **Navigation Pane Options** dialog box to *change the order* of the area buttons (buttons), or to *add or remove* them.

1.  In the **Navigation Pane** [(example)](Navigation_Pane_graphic.md), click the double-right arrow ![](../../../assets/images/User_Interface/Toolbars/Navigation/double_rightarrow.PNG), and then click **Navigation Pane Options**.

    The **Navigation Pane Options** dialog box appears.

2.  In the **Display buttons in this order** area, do one or more of the following:

    - Click the button label that you want to move, and then click **Move Up** or **Move Down** until that button is in the desired position. Repeat this for each button until the desired order is shown in the dialog box.

    - Clear a check box to *hide* that button from the **Navigation Pane**, or select a check box show that button.

3.  Click **OK**.
