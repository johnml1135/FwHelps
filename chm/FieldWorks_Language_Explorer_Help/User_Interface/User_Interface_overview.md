# User Interface overview

*User Interface*

This `Help` book contains the following `Help` sub books:

- [Changing toolbars and menus](Changing_toolbars_and_menus/Changing_toolbars_and%20menus_overview.md) contains steps to hide/show or customize the toolbars or menu bar.

- [Field Descriptions](Field_Descriptions/field_descriptions_overview.md) and associated topics list and describe all of the fields by *name* and list some appropriate task topics.

  - [Field Types](Field_Descriptions/Field_Types/field_types_overview.md) describes the different *types* of fields.

  - You can [change the width](Field_Descriptions/Field_Types/change_the_width_of_the_field_label_area.md) of the field label area.

  - [Text Chart tab columns and rows](../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Text_Chart_tab/Text_Chart_tab_columns_and_rows.md) describes the **Text Chart** tab.

- [Menus](Menus/Menus_overview.md) are arranged to match the menu bar and the menu commands. Each `has one or more` topics.

- [Shortcut keys](Shortcuts/shortcut_keys_overview.md) contain lists of *shortcut key*s (also known as *keyboard shortcuts*)

- [Toolbars](Toolbars/Toolbars_overview.md) show toolbar graphic `Helps`.

  - [Navigation pane](Toolbars/Navigation/Navigation_Pane_overview.md) shows features of the **Navigation Pane**.

  - [Status bar](Toolbars/status_bar.md) shows the areas on the status bar with an explanation of the information found in each area.

  - [Information bar](Toolbars/information_bar_overview.md) shows the content of the pane and may include buttons like a toolbar.
