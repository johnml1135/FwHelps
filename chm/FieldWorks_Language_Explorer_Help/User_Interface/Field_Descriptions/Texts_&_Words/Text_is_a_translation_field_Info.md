# Text is a translation (Info)

*User Interface › Field Descriptions › Texts & Words*

**Full name:** **Text is a translation**

**Location:** **Info** tab ([Interlinear Texts](../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/texts_edit_overview.md), [Concordance](../../../Using_Tools/Texts_&_Words_tools/Concordance/Concordance_overview.md) and [Word List Concordance](../../../Using_Tools/Texts_&_Words_tools/Word_List_Concordance/Word_List_Concordance_overview.md) tools)

**Description:**

Cleared (![](../../../assets/images/UncheckedBox.PNG)) means that the current text is an original text, and has *not* been translated.

Selected (![](../../../assets/images/CheckedBox.PNG)) means that the current text is *not* an original text, but that it has been translated.

**Tasks:**

- [Enter text metadata](../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Enter_text_metadata.md)

- You can [configure columns](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) in the tools listed above to display this field, such as in the **Texts**, **Concordance Results** and upper-right panes, respectively. You can then [sort](../../../Basic_Tasks/Sorting_data/Sorting_data_overview.md) and [filter](../../../Basic_Tasks/Filtering_data/filter_data.md) to display texts based on whether or not they are a translation.

- **See also:** [Texts & Words overview](../../../Using_Tools/Texts_%26_Words_tools/Texts_and_Words_overview.md)

**Field type:** Check box (*not* available for you to change if the text was [included](../../../Basic_Tasks/Filtering_data/Choose_Texts.md) from another FieldWorks program)

**Writing systems:** Not applicable.
