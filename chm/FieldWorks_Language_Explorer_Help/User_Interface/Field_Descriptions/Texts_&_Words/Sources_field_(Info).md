# Sources field (Info)

*User Interface › Field Descriptions › Texts & Words*

**Full name:** **Sources**

**Abbreviation:** none

**Location:** **Info** tab ([Interlinear Texts](../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/texts_edit_overview.md), [Concordance](../../../Using_Tools/Texts_&_Words_tools/Concordance/Concordance_overview.md) and [Word List Concordance](../../../Using_Tools/Texts_&_Words_tools/Word_List_Concordance/Word_List_Concordance_overview.md) tools), below the **Notebook Record** field.

**Description:**

For texts that were entered in the [Text](../Notebook/Text_field_(Notebook).md) field in **Notebook**, this field is another instance of the [Sources](../Notebook/Sources_field_Ntbk.md) field in that **Notebook** record. It displays the same content, and you can [choose sources](../../../Using_Tools/Notebook_tools/Record_Edit_overview/Choose_sources.md) in either field.

- If the current text was *not* entered in the **Text** field (**Notebook**), but you choose a source in this field, then a new fieldnote record is added to **Notebook**, and the current text appears in the **Text** field.
