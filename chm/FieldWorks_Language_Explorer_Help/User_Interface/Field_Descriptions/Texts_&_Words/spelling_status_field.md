# Spelling Status field

*User Interface › Field Descriptions › Texts & Words*

**Full name:** **Spelling Status**

**Location:** Near the top of the **Wordform Analyses** pane ([Word Analyses](../../../Using_Tools/Texts_&_Words_tools/Word_Analyses/Word_Analyses_overview.md))

**Description:**

The selection you make in this field determines whether the word in the [Wordform field](wordform_field.md) is included or excluded from the [vernacular spelling dictionary](../../../Basic_Tasks/Spell_Checking/vernacular_spell_checking.md):

- **Correct** *includes* it in the [selected](../../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Writing_System_Properties_General_tab.md) \<name\>.dic file as a *correct* spelling.

- **Incorrect** and **Undecided** *exclude* it from the \<name\>.dic file and *include* it in the \<name\>.exc file.

To learn more about these files, see [About spelling dictionary files](../../../Basic_Tasks/Spell_Checking/dictionary_files.md).

**Tasks:**

- Right-click or use the menu button ![](../../../assets/images/Menu_Button_pic.GIF), and then click **Change Spelling** to [open](../../../Using_Tools/Texts_%26_Words_tools/Word_Analyses/Change_Spelling/Open_Change_Spelling_dialog_box.md) the **Change Spelling** dialog box.

- [Specify spelling status](../../../Using_Tools/Texts_&_Words_tools/Word_Analyses/Specify_spelling_status.md)

- **See also:** [Texts & Words overview](../../../Using_Tools/Texts_%26_Words_tools/Texts_and_Words_overview.md)

**Field type:** [List reference field](../Field_Types/List_reference_field.md) with a down arrow ![](../../../assets/images/down_arrow_pic.png) (The list is not user-editable.)

**Writing systems:** Not Applicable

**Note:**

- **Correct** is specified when you click **Add to Spelling Dictionary** while [spell checking](../../../Basic_Tasks/Spell_Checking/vernacular_spell_checking.md). **Undecided** is the default selection for new words.

- This field does *not* change when you change the **User Opinion** of any analyses.
