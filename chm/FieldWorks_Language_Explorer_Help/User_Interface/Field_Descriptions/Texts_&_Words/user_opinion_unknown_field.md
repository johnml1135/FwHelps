# User Opinion Unknown field

*User Interface › Field Descriptions › Texts & Words*

**Full name:** **User Opinion Unknown (Analysis Candidates)**

**Description:**

This field acts as a heading under which all analyses that have a **User Opinion** set to **Unknown** are stored.

If the user opinion is not known and the parser cannot produce analyses under this heading, then such analyses are deleted the next time the words are parsed.

**Tasks:**

- **See:** [Specify the status of an analysis](../../../Using_Tools/Texts_%26_Words_tools/Word_Analyses/Specify_status_of_analysis.md) (**User Opinion**)

- **See also:** [Texts & Words overview](../../../Using_Tools/Texts_%26_Words_tools/Texts_and_Words_overview.md)

**Field type:** Not Editable

**Writing systems:** Not Applicable
