# Comment field (Info)

*User Interface › Field Descriptions › Texts & Words*

**Full name:** **Comment**

**Abbreviation:** **cm**

**Location:** **Info** tab ([Interlinear Texts](../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/texts_edit_overview.md), [Concordance](../../../Using_Tools/Texts_&_Words_tools/Concordance/Concordance_overview.md) and [Word List Concordance](../../../Using_Tools/Texts_&_Words_tools/Word_List_Concordance/Word_List_Concordance_overview.md) tools)

**Description:** What you enter in this field, using the default analysis writing system, appears as a *subheading* below the text title in the [Print View](../../../Using_Tools/Texts_%26_Words_tools/Interlinear_Texts/Print_View_Tab_overview.md) tab. Correspondingly, if you print or export the text, then the source information appears on the printed page or in the export file. **See Also:** [Source field](Source_field_info.md).

**Tasks:**

- [Enter text metadata](../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Enter_text_metadata.md)

- [Export](../../Menus/File/Export/Export_Interlinear.md) a text

- [Print](../../Menus/File/Print.md) a text

- You can [configure columns](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) in the tools listed above to display comments, such as in the **Texts**, **Concordance Results** and upper-right panes, respectively. You can then [sort](../../../Basic_Tasks/Sorting_data/Sorting_data_overview.md) and [filter](../../../Basic_Tasks/Filtering_data/filter_data.md) to display texts by comment.

- **See also:** [Texts & Words overview](../../../Using_Tools/Texts_%26_Words_tools/Texts_and_Words_overview.md)

**Field type:** Editable [single-line text](../Field_Types/Single_line_text_field.md) — allows embedded [writing systems](../../Menus/Format/select_a_writing_system.md) and [styles](../../Menus/Format/apply_a_style_to_text.md)

**Writing Systems:** All [vernacular and analysis](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
