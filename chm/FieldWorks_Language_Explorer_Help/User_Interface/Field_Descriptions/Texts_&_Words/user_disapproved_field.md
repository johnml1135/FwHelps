# User Disapproved field

*User Interface › Field Descriptions › Texts & Words*

**Full name:** **User Disapproved (Test Case Analyses)**

**Description:** This field acts as a heading under which all analyses that have a **User Opinion** set to **Disapprove** are stored. Analyses that are user disapproved but continue to show **Successful** in the [Parse result](Parse_result_field.md) field indicate that your grammar or constraints (environments, rules, and so on) permit an invalid [parse](../../Menus/Parser/Parsing_words_overview.md) and consequently need additional work.

**Tasks:**

- **See:** [Specify the status of an analysis](../../../Using_Tools/Texts_%26_Words_tools/Word_Analyses/Specify_status_of_analysis.md) (**User Opinion**)

- **See also:** [Texts & Words overview](../../../Using_Tools/Texts_%26_Words_tools/Texts_and_Words_overview.md)

**Field type:** Not Editable

**Writing systems:** Not Applicable
