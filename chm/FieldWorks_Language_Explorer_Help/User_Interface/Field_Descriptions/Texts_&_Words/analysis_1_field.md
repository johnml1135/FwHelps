# Analysis 1 field

*User Interface › Field Descriptions › Texts & Words*

**Full name:**

- For **User Approved (Analyses)**:

  **Analysis 1**, **Analysis 2**, and so on.

- For **User Opinion Unknown (Analyses Candidates)**:

  **Analysis Candidate 1**, **Analysis Candidate 2**, and so on.

- For **User Disapproved (Test Case Analyses)**:

  **Test Case 1**, **Test Case 2**, and so on.

**Location:** **Wordform Analysis** pane of **Word Analyses** ([Texts & Words](../../../Using_Tools/Texts_%26_Words_tools/Texts_and_Words_overview.md))

**Description:**

Each of these fields acts as a header field for one set of fields: an [Analysis field](Analysis_field.md) and its associated fields ([Parse result](Parse_result_field.md), [Word Category](word_category_field.md) and [Word Gloss](Word_Gloss_field.md)).

The **User Opinion** (**Approve**, **Unknown** or **Disapprove**) determines where the set of fields appears in the pane, and correspondingly, which full name is applied to this field.

**Tasks:**

Click or right-click near the field label to display a menu button ![](../../../assets/images/User_Interface/Menus/Tools/Menu_Button_pic.GIF) and the [Assign Analysis](../../../Using_Tools/Texts_&_Words_tools/Word_Analyses/Assign_analysis_usage.md) link. Then you can do any of the following:

- [Assign Analysis](../../../Using_Tools/Texts_&_Words_tools/Word_Analyses/Assign_analysis_usage.md)

- [Show Word Gloss in Concordance](../../../Basic_Tasks/Show_data/Show_Concordance_of_from_Interlinear_view.md)

- [Add a word gloss](../../../Using_Tools/Texts_&_Words_tools/Word_Analyses/Add_Word_Gloss.md)

- [Delete an analysis](../../../Using_Tools/Texts_&_Words_tools/Word_Analyses/Delete_an_analysis.md) (**Delete Candidate** or **Delete Disapproved Analysis**)

- [Specify the status of an analysis](../../../Using_Tools/Texts_&_Words_tools/Word_Analyses/Specify_status_of_analysis.md) (**User Opinion**)

- **See also:** [Texts & Words overview](../../../Using_Tools/Texts_%26_Words_tools/Texts_and_Words_overview.md) and [Show in from Word Analyses](../../../Basic_Tasks/Show_data/Show_in_from_Word_Analyses.md)

**Field type:** Not Editable

**Writing systems:** Not Applicable
