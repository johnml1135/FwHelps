# Media field (Info)

*User Interface › Field Descriptions › Texts & Words*

**Full name:** **Media**

**Location:**

**Info** tab ([Interlinear Texts](../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/texts_edit_overview.md), [Concordance](../../../Using_Tools/Texts_&_Words_tools/Concordance/Concordance_overview.md) and [Word List Concordance](../../../Using_Tools/Texts_&_Words_tools/Word_List_Concordance/Word_List_Concordance_overview.md) tools)

- In the **Analyze** tab, the **Media** *line* can display a play button (![](../../../assets/images/User_Interface/Menus/Tools/PlayMedialineInterlinear.png)), with the start and stop times and speaker name.

**Description:** This field displays the url (path) to the media content that appears in the **Media** line in the **Analyze** [tab](../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/About_Gloss_Analyze_tabs.md). These files can appear if you [imported a FLExText file](../../../Beginning_Tasks/Importing_Data/Import_interlinear_data.md) that had an audio recording. These files could be from ELAN or SayMore.

**Tasks:**

None

**Field type:** text, which you cannot edit.

**Writing systems:** One or more writing system. These would have been selected in the **Configure Interlinear** [dialog box](../../Menus/Tools/Configure_interlinear_lines_dialog_box.md) for the **Media** line that appears in the **Analyze** tab.
