# Word Category field

*User Interface › Field Descriptions › Texts & Words*

**Full name:** **Word Category**

**Location:** **Word Category** fields appear in the **Wordform Analyses** pane ([Word Analyses](../../../Using_Tools/Texts_%26_Words_tools/Word_Analyses/Word_Analyses_overview.md)) for analyses that are under **User Approved (Analyses)**. (This field is hidden for analyses under **User Opinion Unknown** or **User Disapproved**.)

**Description:**

Each **Word Category** field references and displays the grammatical category of the current wordform.

You typically select categories when you [gloss](../../../Using_Tools/Texts_%26_Words_tools/Interlinear_Texts/specify_the_word_gloss.md) or [analyze](../../../Using_Tools/Texts_%26_Words_tools/Interlinear_Texts/Analyze_Text_overview.md) interlinear texts. You can *also* select them in this field. The selection appears in each occurrence of the wordform that has the current analysis in the interlinear texts.
