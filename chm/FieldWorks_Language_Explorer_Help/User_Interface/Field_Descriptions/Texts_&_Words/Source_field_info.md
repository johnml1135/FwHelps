# Source field (Info)

*User Interface › Field Descriptions › Texts & Words*

**Full name:** **Source**

**Abbreviation:** **so**

**Location:** **Info** tab ([Interlinear Texts](../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/texts_edit_overview.md), [Concordance](../../../Using_Tools/Texts_&_Words_tools/Concordance/Concordance_overview.md) and [Word List Concordance](../../../Using_Tools/Texts_&_Words_tools/Word_List_Concordance/Word_List_Concordance_overview.md) tools)

**Description:**

What you enter in this field, using in the writing system that matches the writing system of the **Baseline** tab, appears as a *subheading* below the text title in the [Print View](../../../Using_Tools/Texts_%26_Words_tools/Interlinear_Texts/Print_View_Tab_overview.md) tab.

Correspondingly, if you print or export the text, then that source information appears on the printed page or in the export file.

Intellectual Property (Copyright) permissions, source attributions, licenses, and other permissions metadata should be entered here.

**See Also:** [Comment field](Comment_field_info.md).

**Tasks:**

- [Configure columns](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) in the views listed above to display the information in this field.

- [Enter text metadata](../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Enter_text_metadata.md).

- [Export](../../Menus/File/Export/Export_Interlinear.md) a text.

- [Print](../../Menus/File/Print.md) a text.

- [Sort](../../../Basic_Tasks/Sorting_data/Sort_Texts_Words.md) and [filter texts and words](../../../Basic_Tasks/Filtering_data/filter_Texts_Words.md) to display texts by content in this field.

- **See also:** [Texts & Words overview](../../../Using_Tools/Texts_%26_Words_tools/Texts_and_Words_overview.md)

**Field type:** Editable [single-line text](../Field_Types/Single_line_text_field.md) — allows embedded [writing systems](../../Menus/Format/select_a_writing_system.md) and [styles](../../Menus/Format/apply_a_style_to_text.md)
