# Analysis field

*User Interface › Field Descriptions › Texts & Words*

**Full name:** **Analysis**

**Location:** **Word Analyses** (**Texts & Words**), **Wordform Analyses** pane, below an [Analysis 1](analysis_1_field.md) (**2**, **3**, and so on) field

**Description:** Each analysis is displayed in a field labeled **Analysis**, regardless if its **User Opinion** is set to **Approve**, **Unknown** or **Disapprove**. The field contains the same morphological content as the [word focus box](../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Word_Focus_Box_examples.md) for the current analysis of the current wordform.

**Tasks:**

- Right-click content in any of the rows in the analysis (**Morphemes**, **Lex Entries**, and so on) to see right-click menus with various [Show in](../../../Basic_Tasks/Show_data/Show_data_overview.md) commands.

- Some rows (such as **Lex Entries**) in the analysis may have a down arrow ![](../../../assets/images/User_Interface/Field_Descriptions/Texts_&_Words/down_arrow_pic.png). In these cases, you can select available commands to [change the analysis](../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Analyze_Text_overview.md).

- **See also:** [Texts & Words overview](../../../Using_Tools/Texts_%26_Words_tools/Texts_and_Words_overview.md) and [Show in from Word Analyses](../../../Basic_Tasks/Show_data/Show_in_from_Word_Analyses.md)

**Field type:** Not Editable

**Writing systems:** Not Applicable
