# Subcategories field (Reversal Index Categories)

*User Interface › Field Descriptions › Lists › Reversal Index Categories fields*

**Full name:** **Subcategories**

**Location:** These **Subcategories** fields appear in the **Category (or Part of Speech)** pane in **Reversal Index Categories** ([Lists](../../../../Using_Tools/Lists_tools/Lists_overview.md)).

**Description:**

Each **Subcategories** field acts as a header below which any number of **Subcategories** field sets ([Name](Name_field_Reversal_Index_Categories.md), [Abbreviation](Abbreviation_field_Reversal_Index_Categories.md) and [Description](Description_field_Reversal_Index_Categories.md) fields) may appear in a hierarchical structure. The subcategory names are used in the [Category field](../../Lexicon/Reversal_Indexes_fields/category_field.md) in **Reversal Indexes** ([Lexicon](../../../../Using_Tools/Lexicon_tools/Lexicon_overview.md)).

Each reversal index has a *separate* **Categories (or Parts of Speech)** list, which you select with the menu button ![](../../../../assets/images/Information_bar_Menu_button.PNG) on the [Information bar](../../../Toolbars/information_bar_overview.md).

**Tasks:**

- Click or right-click a **Subcategories** field, and then use the menu button ![](../../../../assets/images/Menu_Button_pic.GIF) or the [Insert Subcategory](../../../../Using_Tools/Lists_tools/Insert_a_list_subitem.md) link to insert a subcategory.

<!-- -->

  - [Use the Add from Catalog dialog box](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Using_Add_from_Catalog_dialog_box.md)

- **See also:** [About Reversal Index Categories](../../../../Using_Tools/Lists_tools/about_reversal_index_categories.md) and [Reversal Indexes overview](../../../../Using_Tools/Lexicon_tools/Reversal_Indexes/reversal_indexes_overview.md)

**Field type:** Not Editable

**Writing systems:** Not Applicable

> [!IMPORTANT]
>
> - In the current version of Language Explorer, you *cannot* see any subcategories in the **Categories (or Parts of Speech)** pane (center pane) for the **Reversal Index Categories** list. Instead, you see them below this heading field.
>
> <!-- -->
>
> - When you choose or [change the category of a reversal entry](../../../../Using_Tools/Lexicon_tools/Reversal_Indexes/change_the_category_of_a_reversal_entry.md), you can insert new categories or subcategories from the **Category** field in **Reversal Indexes** (**Lexicon**).
