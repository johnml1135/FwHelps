# Abbreviation field (Reversal Index Categories)

*User Interface › Field Descriptions › Lists › Reversal Index Categories fields*

**Full name:** **Abbreviation**

**Location:** In the **Lists** area, an **Abbreviation** field appears in the **Category (or Part of Speech)** pane in **Reversal Index Categories**. One or more **Abbreviation** fields may *also* appear under [Subcategories](Subcategories_field_Reversal_Index_Categories.md) fields.

**Description:**

**Abbreviation** fields store the abbreviation of the [name](Name_field_Reversal_Index_Categories.md) of the current grammatical *category* such as `Adp` for `Adposition`, or *subcategory* such as `Post` for `Postposition`.

These abbreviations do *not* appear in the **Grammar Sketch**.

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:**

One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

The writing systems match the reversal indexes you have [inserted](../../../../Using_Tools/Lexicon_tools/Reversal_Indexes/Insert_a_reversal_index.md).
