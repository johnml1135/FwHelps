# Reversal Index Categories fields overview

*User Interface › Field Descriptions › Lists › Reversal Index Categories fields*

The categories stored in this list are used in **Reversal Indexes** ([Lexicon](../../../../Using_Tools/Lexicon_tools/Lexicon_overview.md)).

*Each* reversal index has a *separate* **Categories (or Parts of Speech)** list. In **Reversal Index Categories**, the [Information bar](../../../Toolbars/information_bar_overview.md) has a menu button ![](../../../../assets/images/Information_bar_Menu_button.PNG). You use it to choose the writing system that matches the writing system of the reversal index.

Here are the fields in the **Reversal Index Categories** [list](../../../../Using_Tools/Lists_tools/List_item_usage_table.md):

- [Name](Name_field_Reversal_Index_Categories.md)

- [Abbreviation](Abbreviation_field_Reversal_Index_Categories.md)

- [Description](Description_field_Reversal_Index_Categories.md)

- [Subcategories](Subcategories_field_Reversal_Index_Categories.md)
