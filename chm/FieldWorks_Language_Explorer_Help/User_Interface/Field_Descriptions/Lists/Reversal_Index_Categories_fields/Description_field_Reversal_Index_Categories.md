# Description field (Reversal Index Categories)

*User Interface › Field Descriptions › Lists › Reversal Index Categories fields*

**Full name:** **Description**

**Location:** In **Lists**, a **Description** field appears in the **Category (or Part of Speech)** pane in **Reversal Index Categories**. One or more **Description** fields may *also* appear under [Subcategories](Subcategories_field_Reversal_Index_Categories.md) fields.

**Description:**

**Description** fields store the description of the current [named](Name_field_Reversal_Index_Categories.md) grammatical *category* or *subcategory*.

These descriptions do *not* appear in the **Grammar Sketch**.
