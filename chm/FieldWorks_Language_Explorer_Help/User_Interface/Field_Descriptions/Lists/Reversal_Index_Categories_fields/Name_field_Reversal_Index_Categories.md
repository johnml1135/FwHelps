# Name field (Reversal Index Categories)

*User Interface › Field Descriptions › Lists › Reversal Index Categories fields*

**Full name:** **Name**

**Location:** In the **Lists** area, a **Name** field appears at the top of the **Category (or Part of Speech)** pane in **Reversal Index Categories**. One or more **Name** fields may *also* appear below a [Subcategories](Subcategories_field_Reversal_Index_Categories.md) field.

**Description:**

**Name** fields store the name of the current grammatical *category*, such as `Adposition`, or *subcategory* such as **Postposition**.

These names are used in [Category](../../Lexicon/Reversal_Indexes_fields/category_field.md) fields in **Reversal Indexes**. Each reversal index has a *separate* **Categories (or Parts of Speech)** list, which you select with the menu button ![](../../../../assets/images/Information_bar_Menu_button.PNG) on the [Information bar](../../../Toolbars/information_bar_overview.md).

These names do *not* appear in the **Grammar Sketch**.

**Tasks:**

- Click the appropriate **Name** field and use the menu button ![](../../../../assets/images/Menu_Button_pic.GIF) to do any of the following:

  - [Delete a category](../../../../Using_Tools/Lists_tools/Delete_a_list_item.md) or [subcategory](../../../../Using_Tools/Lists_tools/Delete_a_list_subitem.md)

  - [Merge categories](../../../../Using_Tools/Lists_tools/Merge_categories.md)

  - [Move a category or subcategory](../../../../Using_Tools/Lists_tools/Move_a_category.md) (also *demotes* them)

  - [Promote a subcategory](../../../../Using_Tools/Lists_tools/Promote_or_Demote_a_list_item.md)

- [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- Use the **Subcategories** fields menu button ![](../../../../assets/images/Menu_Button_pic.GIF) or the [Insert Subcategory](../../../../Using_Tools/Lists_tools/Insert_a_list_subitem.md) link to insert a subcategory.

  - [Use the Add from Catalog dialog box](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Using_Add_from_Catalog_dialog_box.md)

- **See also:** [About Reversal Index Categories](../../../../Using_Tools/Lists_tools/about_reversal_index_categories.md) and [Reversal Indexes overview](../../../../Using_Tools/Lexicon_tools/Reversal_Indexes/reversal_indexes_overview.md)

**Field type:** [Single-line text](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles.

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md). Reversal indexes are automatically added when you add an analysis writing system.

> [!IMPORTANT]
>
> - In the current version of Language Explorer, you *cannot* see any subcategories in the **Categories (or Parts of Speech)** pane (center pane) for the **Reversal Index Categories** list. Instead, you see them below the **Subcategories** fields.

> [!TIP]
>
> - While you choose or [change the category](../../../../Using_Tools/Lexicon_tools/Reversal_Indexes/change_the_category_of_a_reversal_entry.md) of a reversal entry, you can insert new categories or subcategories from the **Category** field in **Reversal Indexes** (**Lexicon**).
