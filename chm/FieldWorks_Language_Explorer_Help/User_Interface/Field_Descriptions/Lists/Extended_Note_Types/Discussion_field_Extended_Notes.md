# Discussion field (Extended Note Types)

*User Interface › Field Descriptions › Lists › Extended Note Types*

**Full name:** **Discussion**

**Location:** **Extended Note Type** pane of the **Extended Note Types** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores an optional discussion about the current [named](Name_field_Extended_Notes.md) extended note type.

**Tasks:**

- [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** [Multi-paragraph text field](../../Field_Types/Multiparagraph_text_field.md) — allows embedded [writing systems](../../../Menus/Format/select_a_writing_system.md) and [styles](../../../Menus/Format/apply_a_style_to_text.md)

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) or vernacular
