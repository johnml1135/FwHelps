# Confidence field (Extended Note Types)

*User Interface › Field Descriptions › Lists › Extended Note Types*

**Full name:** **Confidence**

**Location:** **Extended Note Type** pane of the **Extended Note Types** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field references and displays the [name](../Confidence_Levels_fields/Name_field_Confidence_Levels.md) of an item from the **Confidence Levels** list. This indicates your confidence in the current [named](Name_field_Extended_Notes.md) extended note type.

**Tasks:**

- [Choose](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) an item for a list reference field

- [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** [List reference](../../Field_Types/List_reference_field.md) (permits type-ahead)

**Writing systems:** Best [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
