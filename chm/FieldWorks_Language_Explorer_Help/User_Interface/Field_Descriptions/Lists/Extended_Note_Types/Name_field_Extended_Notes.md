# Name field (Extended Note Types)

*User Interface › Field Descriptions › Lists › Extended Note Types*

**Full name:** **Name**

**Location:** **Extended Note Type** pane of the **Extended Note Types** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores the name of the current extended note type.

Names, such as *Collocation*, *Cultural*, *Grammar* and so on, are displayed and referenced in the [Type](../../Lexicon/Lexicon_Edit_fields/Sense_level_fields/Extended_Note/Type_field_(Extended_Note).md) field in senses and subsenses (**Lexicon**).

**Tasks:**

- [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) to include the [abbreviation](Abbreviation_field_Extended_Notes.md), name or both when you configure [Extended Notes](../../../Menus/Tools/Configure_Dictionary/Extended_Note.md).

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
