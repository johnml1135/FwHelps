# Status field (Complex Form Types)

*User Interface › Field Descriptions › Lists › Complex Form Types*

**Full name:** **Status**

**Abbreviation:** **st**

**Location:** **Complex Form Type** pane of the **Complex Form Types** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field references and displays the [name](../Status_fields/Name_field_Status.md) of an item from the **Status** list. This indicates the status of the current [named](name_fld_(complex_fm_types).md) complex form type.

**Tasks:**

- [Choose](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) an item for a list reference field

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- [Insert a list item](../../../../Using_Tools/Lists_tools/Insert_a_list_item.md)
