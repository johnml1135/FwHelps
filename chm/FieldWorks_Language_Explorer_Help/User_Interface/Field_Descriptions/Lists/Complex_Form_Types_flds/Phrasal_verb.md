# Phrasal Verb

*User Interface › Field Descriptions › Lists › Complex Form Types*

Phrasal verbs are usually [complex forms](../../../../Using_Tools/Lists_tools/About_complex_forms.md) with [components](../../Lexicon/Lexicon_Edit_fields/Entry_level_fields/Components_field.md).

- A *Phrasal Verb* is a combination of a lexical verb and a verbal particle that forms a single semantic and syntactic unit.

  - Example (English)

    The item *give up* is a phrasal verb, as in the following:

    He gave up smoking.

    He gave smoking up.

  - Example (Akan)

    The item gyee ... so 'answered' is a phrasal verb, as in the following:

    Kofi gyee Kwame so

    Kofi received Kwame on

    'Kofi answered Kwame.'

> [!TIP]
>
> - *How you analyze phrases like these usually must be discussed with a consultant.*
