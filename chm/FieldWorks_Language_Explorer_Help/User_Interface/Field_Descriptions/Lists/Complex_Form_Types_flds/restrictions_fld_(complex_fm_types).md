# Restrictions field (Complex Form Types)

*User Interface › Field Descriptions › Lists › Complex Form Types*

**Full name:** **Restrictions**

**Abbreviation:** **ox**

**Location:** **Complex Form Type** pane of the **Complex Form Types** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field references and displays the [names](../Restrictions_fields/name_field_restrictions.md) of one or more items from the **Restrictions** list. These indicate any restrictions for publishing the current [named](name_fld_(complex_fm_types).md) complex form type.

This field does *not* control any process or print features.

- [Choose](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) an item for a list reference field
