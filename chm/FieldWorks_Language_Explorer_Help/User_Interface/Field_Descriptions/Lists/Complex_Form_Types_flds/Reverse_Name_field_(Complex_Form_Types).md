# Reverse Name field (Complex Form Types)

*User Interface › Field Descriptions › Lists › Complex Form Types*

**Full name:** **Reverse Name**

**Location:** **Complex Form Type** pane of the **Complex Form Types** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

For the current type, this field stores the *reverse* name, such as **Compound of.** or **Derivative of.**

**See Also:** [Name](name_fld_(complex_fm_types).md) field.

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to display this reverse name when you configure [Component References](../../../Menus/Tools/Configure_Dictionary/Component_References.md), [Referenced Complex Forms](../../../Menus/Tools/Configure_Dictionary/Referenced_Complex_Forms.md), and so on.

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing system:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Note:** **See Also:** [Reverse Abbr](reverse_abbr_fld_(complex_fm_types).md) and [Abbreviation](reverse_abbr_fld_(complex_fm_types).md) fields.
