# Reverse Abbr field (Complex Form Types)

*User Interface › Field Descriptions › Lists › Complex Form Types*

**Full name:** **Reverse Abbr.**

**Location:** **Complex Form Type** pane of the **Complex Form Types** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

For the current type, this field stores the *reverse* abbreviation, such as **comp. of.** or **der. of.**

**See Also:** [Abbreviation](abbr_fld_(complex_fm_types).md) field.

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to display this reverse abbreviation when you configure [Referenced Complex Forms](../../../Menus/Tools/Configure_Dictionary/Referenced_Complex_Forms.md).

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md)

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Note:** **See Also:** [Reverse Name](Reverse_Name_field_(Complex_Form_Types).md) and [Name](name_fld_(complex_fm_types).md) fields.
