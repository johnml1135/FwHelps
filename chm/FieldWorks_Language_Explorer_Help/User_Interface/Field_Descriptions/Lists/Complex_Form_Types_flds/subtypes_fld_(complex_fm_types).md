# Subtypes fld (Complex Form Types)

*User Interface › Field Descriptions › Lists › Complex Form Types*

**Full name:** **Subtypes**

**Location:** **Complex Form Type** pane of the **Complex Form Types** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** Each **Subtypes** field acts as a header below which one or more **Complex Form Type** fields may appear for the current [named](name_fld_(complex_fm_types).md) complex form type. The **Complex Form Type** fields below this header are subtypes.

**Tasks:**

- Click a subitem in the center pane to display it in the right pane for [editing](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md).

- The menu button ![](../../../../assets/images/Menu_Button_pic.GIF) for a **Subtypes** field allows you to [insert a subitem](../../../../Using_Tools/Lists_tools/Insert_a_list_subitem.md) to the *current* selection.

- The menu button ![](../../../../assets/images/Menu_Button_pic.GIF) for a **Complex Form Type** field (that you see below the **Subtypes** field) allows you to [delete that subtype](../../../../Using_Tools/Lists_tools/Delete_a_list_subitem.md) and its subtypes from the *current* selection.

**Field type:** Not Editable

**Writing systems:** Not Applicable
