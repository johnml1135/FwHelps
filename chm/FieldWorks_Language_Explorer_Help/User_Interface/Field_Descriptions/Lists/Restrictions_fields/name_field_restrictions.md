# Name field (Restrictions)

*User Interface › Field Descriptions › Lists › Restrictions fields*

**Full name:** **Name**

**Location:** **Restriction** pane of the **Restrictions** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores the name of the current restriction.

Many lists have a **Restrictions** field that displays and references this name.

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Note:** There is a [Restrictions field](../../Lexicon/Lexicon_Edit_fields/Sense_level_fields/restrictions_field.md) in **Lexicon Edit**. However, it is a [text field](../../Field_Types/Single_line_text_field.md) which does not display or reference any list items.
