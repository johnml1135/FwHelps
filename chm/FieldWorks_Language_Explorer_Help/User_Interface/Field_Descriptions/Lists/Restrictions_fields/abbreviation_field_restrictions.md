# Abbreviation field (Restrictions)

*User Interface › Field Descriptions › Lists › Restrictions fields*

**Full name:** **Abbreviation**

**Location:** **Restriction** pane of the **Restrictions** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores the abbreviation of the [name](name_field_restrictions.md) of the current restriction.

**Tasks:** [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
