# Researchers field (Anthropology Categories)

*User Interface › Field Descriptions › Lists › Anthropology Categories fields*

**Full name:** **Researchers**

**Abbreviation:** **Anthropology Category** pane of the **Anthropology Categories** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field references and displays the [names](../People_fields/full_name_field_people.md) of one or more people from the **People** list. This records who researched the current [named](Name_field_Anthropology_Categories.md) category. This would be useful for custom anthropology categories.
