# Subcategory field (Anthropology Categories)

*User Interface › Field Descriptions › Lists › Anthropology Categories fields*

**Full name:** **Subcategory**

**Location:** **Anthropology Category** pane of the **Anthropology Categories** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

Each [Subcategories](Subcategories_field_Anthropology_Categories.md) field acts as a header below which one or more **Subcategory** fields may appear.

Each **Subcategory** field corresponds to one subcategory of the category or subcategory currently selected in the center pane.

**Tasks:**

- Click a subcategory in the center pane to display it in the right pane for [editing](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md).

- The menu button ![](../../../../assets/images/Menu_Button_pic.GIF) for a [Subcategories](Subcategories_field_Anthropology_Categories.md) field allows you to [insert a subcategory](../../../../Using_Tools/Lists_tools/Insert_a_list_subitem.md) into the current [named](Name_field_Anthropology_Categories.md) category.

- The menu button ![](../../../../assets/images/Menu_Button_pic.GIF) for a **Subcategory** field allows you to [delete that subcategory](../../../../Using_Tools/Lists_tools/Delete_a_list_subitem.md) and its subcategories from the current [named](Name_field_Anthropology_Categories.md) category.

**Field type:** Not Editable

**Writing systems:** Not Applicable
