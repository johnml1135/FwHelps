# Abbreviation field (Anthropology Categories)

*User Interface › Field Descriptions › Lists › Anthropology Categories fields*

**Full name:** **Abbreviation**

**Location:** **Anthropology Category** pane of the **Anthropology Categories** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores the abbreviation of the [name](Name_field_Anthropology_Categories.md) of the current category. Abbreviations appear in dialog boxes, such as when you [choose anthropology categories](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/choose_anthropology_categories.md).

**Tasks:**

- [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) to include the abbreviation, name or both when you configure **Anthropology Categories**.

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
