# Name field (Anthropology Categories)

*User Interface › Field Descriptions › Lists › Anthropology Categories fields*

**Full name:** **Name**

**Abbreviation:** **Anthropology Category** pane of the **Anthropology Categories** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores the name of the current list item.

Anthropology category names are displayed and referenced in the [Anthropology Categories](../../Lexicon/Lexicon_Edit_fields/Sense_level_fields/anthropology_categories_field.md) field in each sense and subsense (**Lexicon**) and in the [Anthropology Categories](../Semantic_Domains_fields/Anthropology_Categories_field_Sem_Dom.md) field in each **Semantic Domains** list item.

**Tasks:**

- [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) to include the [abbreviation](abbreviation_field_anthropology_categories.md), name or both when you configure **Anthropology Categories**.

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
