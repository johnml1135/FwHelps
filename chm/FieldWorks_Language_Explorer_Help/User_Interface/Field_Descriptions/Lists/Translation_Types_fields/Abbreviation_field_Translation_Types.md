# Abbreviation field (Translation Types)

*User Interface › Field Descriptions › Lists › Translation Types fields*

**Full name:** **Abbreviation**

**Location:** **Translation Type** pane of the **Translations Types** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores the abbreviation of the [name](Name_field_Translation_Types.md) of the current list item, such as `BT`, `FT` or `LT`*.*

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- [Insert a list item](../../../../Using_Tools/Lists_tools/Insert_a_list_item.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) to include the abbreviation, name or both when you configure [Examples](../../../Menus/Tools/Configure_Dictionary/Examples.md).

**Field type:** [Single-line text](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
