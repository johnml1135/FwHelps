# Subitems field (Translation Types)

*User Interface › Field Descriptions › Lists › Translation Types fields*

In the current version, you are allowed to add list subitems to the **Translation Types** list. However the [Type](../../Lexicon/Lexicon_Edit_fields/Sense_level_fields/Type_field.md) field used with example sentences *cannot* use subitems.

**Full name:** **Subitems** or **Subitem**

**Location:**

**Translation Type** pane of the **Translations Types** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md)).

![](../../../../assets/images/Important_Icon.gif) These fields only appear if you [configure](../../../Menus/Tools/Configure_List.md) this list to support hierarchy.

**Description:**

Each **Subitems** field acts as a header below which one or more **Subitem** fields may appear for the current [named](../Time_of_Day_fields/Name_field_(Time_of_Day).md) **Time of Day** list item.

Each **Subitem** field corresponds to one subitem of the item or subitem currently selected in the center pane. The [name](../Time_of_Day_fields/Name_field_(Time_of_Day).md) of the subitem appears in these fields.

**Tasks:**

- Click a subitem in the center pane to display it in the right pane for [editing](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md).

- The **Subitems** field menu button ![](../../../../assets/images/Menu_Button_pic.GIF) allows you to [insert a list subitem](../../../../Using_Tools/Lists_tools/Insert_a_list_subitem.md) to the *current* selection.

- The **Subitem** field menu button ![](../../../../assets/images/Menu_Button_pic.GIF) allows you to [delete that list subitem](../../../../Using_Tools/Lists_tools/Delete_a_list_subitem.md) and its subitems from the *current* selection.

**Field type:** Not Editable

**Writing systems:** Not Applicable
