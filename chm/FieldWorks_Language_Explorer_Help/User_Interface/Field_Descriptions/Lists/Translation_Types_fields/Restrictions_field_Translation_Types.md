# Restrictions field (Translation Types)

*User Interface › Field Descriptions › Lists › Translation Types fields*

**Full name:** **Restrictions**

**Abbreviation:** **ox**

**Location:** **Translation Type** pane of the **Translations Types** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field references and displays the [names](../Restrictions_fields/name_field_restrictions.md) of one or more items from the **Restrictions** list. These indicate any restrictions for publishing the current [named](Name_field_Translation_Types.md) translation type.

This field does *not* control any process or print features.

- [Choose](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) an item for a list reference field
