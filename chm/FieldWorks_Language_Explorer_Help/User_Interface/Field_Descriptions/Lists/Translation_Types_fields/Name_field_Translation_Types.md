# Name field (Translation Types)

*User Interface › Field Descriptions › Lists › Translation Types fields*

**Full name:** **Name**

**Location:** **Translation Type** pane of the **Translations Types** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores the name of the current translation type, such as *Back translation, Free translation* or *Literal translation*.

Translation type names are displayed and referenced in the [Type](../../Lexicon/Lexicon_Edit_fields/Sense_level_fields/Type_field.md) field that appears with the [Example](../../Lexicon/Lexicon_Edit_fields/Sense_level_fields/example_field.md) field (**Lexicon Edit**).

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- [Insert a list item](../../../../Using_Tools/Lists_tools/Insert_a_list_item.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) to include the [abbreviation](Abbreviation_field_Translation_Types.md), name or both when you configure [Examples](../../../Menus/Tools/Configure_Dictionary/Examples.md).

**Field type:** [Single-line text](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
