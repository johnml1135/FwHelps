# Discussion field (Translation Types)

*User Interface › Field Descriptions › Lists › Translation Types fields*

**Full name:** **Discussion**

**Location:** **Translation Type** pane of the **Translations Types** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores an optional discussion about the current [named](Name_field_Translation_Types.md) translation type.

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- [Insert a list item](../../../../Using_Tools/Lists_tools/Insert_a_list_item.md)

**Field type:** [Multi-paragraph text](../../Field_Types/Multiparagraph_text_field.md) — allows embedded [writing systems](../../../Menus/Format/select_a_writing_system.md) and [styles](../../../Menus/Format/apply_a_style_to_text.md)
