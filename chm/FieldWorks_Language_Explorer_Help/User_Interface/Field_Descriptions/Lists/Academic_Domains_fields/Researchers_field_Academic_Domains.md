# Researchers field (Academic Domains)

*User Interface › Field Descriptions › Lists › Academic Domains fields*

**Full name:** **Researchers**

**Location:** **Academic Domain** pane of the **Academic Domains** lists ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field references and displays the [names](../People_fields/full_name_field_people.md) of one or more people from the **People** list. This records who researched the current [named](Name_field_Academic_Domains.md) academic domain. This would be useful for custom academic domains.

**Tasks:**

- [Choose](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) an item for a list reference field

- [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** [List reference field](../../Field_Types/List_reference_field.md)
