# Abbreviation field (Academic Domains)

*User Interface › Field Descriptions › Lists › Academic Domains fields*

**Full name:** **Abbreviation**

**Location:** **Academic Domain** pane of the **Academic Domains** lists ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores the abbreviation of the current academic domain [name](Name_field_Academic_Domains.md), such as *Anat*, *Anthro*, *Artintel* and so on.

**Tasks:**

- [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) to include the abbreviation, name or both when you configure **Academic Domains**.

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
