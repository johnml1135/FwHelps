# Name field (Genres)

*User Interface › Field Descriptions › Lists › Genres*

**Full name:** **Name**

**Location:** **Genre** pane of the **Genres** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores the name of the current genre, such as *Dialogue, Metrical Category,* *Monologue* and so on.

Genre names are displayed and referenced in the [Genres](../../Texts_&_Words/Genres_field_Info.md) field in each **Info** tab (for [text metadata](../../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Enter_text_metadata.md)).

**Tasks:**

- [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
