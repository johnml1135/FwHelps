# Restrictions field (Genres)

*User Interface › Field Descriptions › Lists › Genres*

**Full name:** **Restrictions**

**Abbreviation:** **ox**

**Location:** **Genre** pane of **Genres** list ([Lists](../../../../Using_Tools/Lists_tools/Lists_overview.md))

**Description:**

This field references and displays the [names](../Restrictions_fields/name_field_restrictions.md) of one or more items from the **Restrictions** list. These indicate any restrictions for publishing the current [named](Name_field_Genres.md) genre.

This field does *not* control any process or print features.

**Tasks:**

- [Choose](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) an item for a list reference field

- [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** [List reference](../../Field_Types/List_reference_field.md) (permits type-ahead)
