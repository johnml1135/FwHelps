# Status field (Genres)

*User Interface › Field Descriptions › Lists › Genres*

**Full name:** **Status**

**Abbreviation:** **st**

**Location:** **Genre** pane of the **Genres** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field references and displays the [name](../Status_fields/Name_field_Status.md) of an item from the **Status** list. This indicates the status of the current [named](Name_field_Genres.md) genre.

**Tasks:**

- [Choose](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) an item for a list reference field

- [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** [List reference](../../Field_Types/List_reference_field.md) (permits type-ahead)
