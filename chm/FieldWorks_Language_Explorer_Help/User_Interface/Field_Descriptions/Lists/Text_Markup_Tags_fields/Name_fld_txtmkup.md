# Name field (TxtMkUp)

*User Interface › Field Descriptions › Lists › Text Markup Tags fields*

**Full name:** **Name**

**Location:** **Text Markup Tag** pane of the **Text Markup Tags** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores the name of the current list item. **See Also:** [Abbreviation](Abbreviation_fld_txtmkup.md).

**Tasks:** [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
