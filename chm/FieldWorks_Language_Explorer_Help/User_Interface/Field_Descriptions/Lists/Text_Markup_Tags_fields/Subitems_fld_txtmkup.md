# Subitems field (TxtMkUp)

*User Interface › Field Descriptions › Lists › Text Markup Tags fields*

**Full name:** **Subitems** or **Subitem**

**Location:** **Text Markup Tag** pane of the **Text Markup Tags** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

Each **Subitems** field acts as a header below which one or more **Subitem** fields may appear for the current [named](Name_fld_txtmkup.md) list item.

Each **Subitem** field corresponds to one subitem of the item or subitem currently selected in the center pane.

**Tasks:**

- Click a subitem in the center pane to display it in the right pane for [editing](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md).

- The menu button ![](../../../../assets/images/Menu_Button_pic.GIF) for a **Subitems** field allows you to [insert a list subitem](../../../../Using_Tools/Lists_tools/Insert_a_list_subitem.md) in the current list item.

- The menu button ![](../../../../assets/images/Menu_Button_pic.GIF) for a **Subitem** field allows you to [delete a list subitem](../../../../Using_Tools/Lists_tools/Delete_a_list_subitem.md) and its subitems from the current list item.

**Field type:** Not Editable

**Writing systems:** Not Applicable
