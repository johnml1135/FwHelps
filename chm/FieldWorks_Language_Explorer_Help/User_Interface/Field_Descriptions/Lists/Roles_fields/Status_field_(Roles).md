# Status field (Roles)

*User Interface › Field Descriptions › Lists › Roles fields*

**Full name:** **Status**

**Abbreviation:** **st**

**Location:** **Role** pane of the **Roles** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field references and displays the [name](../Status_fields/Name_field_Status.md) of an item from the **Status** list, such as *Confirmed*, *Disproved*, and so on. This indicates the status of the current [named](Name_field_(Roles).md) role.
