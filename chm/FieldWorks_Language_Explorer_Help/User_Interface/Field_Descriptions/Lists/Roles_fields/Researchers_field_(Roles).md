# Researchers field (Roles)

*User Interface › Field Descriptions › Lists › Roles fields*

**Full name:** **Researchers**

**Location:** **Role** pane of the **Roles** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field references and displays the [names](../People_fields/full_name_field_people.md) of one or more people from the **People** list. This records who researched the current [named](Name_field_(Roles).md) role. This would be useful for custom roles.

**Tasks:**

- [Choose](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) an item for a list reference field

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- [Insert a list item](../../../../Using_Tools/Lists_tools/Insert_a_list_item.md)

**Field type:** [List reference](../../Field_Types/List_reference_field.md) (permits type-ahead)
