# Description field (Roles)

*User Interface › Field Descriptions › Lists › Roles fields*

**Full name:** **Description**

**Location:** **Role** pane of the **Roles** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores the description of the current [named](../Status_fields/Name_field_Status.md) role.
