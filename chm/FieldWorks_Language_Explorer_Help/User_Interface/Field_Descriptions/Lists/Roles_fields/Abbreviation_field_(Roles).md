# Abbreviation field (Roles)

*User Interface › Field Descriptions › Lists › Roles fields*

**Full name:** **Abbreviation**

**Location:** **Role** pane of the **Roles** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores the abbreviation of the current [named](Name_field_(Roles).md) **Roles** list item, such as *Accsd, Accsr* or *Arbit*, and so on.

You can choose to display the role abbreviations when you [configure the Document Layout](../../../Menus/Tools/Configure_Document/Configure_Document_View_dialog_box.md).

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- [Insert a list item](../../../../Using_Tools/Lists_tools/Insert_a_list_item.md)

**Field type:** [Single-line text](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
