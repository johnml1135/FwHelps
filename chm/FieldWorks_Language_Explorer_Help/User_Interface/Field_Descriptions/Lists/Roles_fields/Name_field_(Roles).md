# Name field (Roles)

*User Interface › Field Descriptions › Lists › Roles fields*

**Full name:** **Name**

**Location:** **Role** pane of the **Roles** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores the name of the current role, such as *Accused, Accuser,* *Arbitrator*, and so on.

The names of the **Roles** list items appear in [Notebook](../../../../Using_Tools/Notebook_tools/Record_Edit_overview/Record_Edit_overview.md) when you [choose participants and roles](../../../../Using_Tools/Notebook_tools/Record_Edit_overview/Choose_participants_roles.md). You can choose to display the role names or [abbreviations](Abbreviation_field_(Roles).md) when you [configure the Document layout](../../../Menus/Tools/Configure_Document/Configure_Document_View_dialog_box.md).

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- [Insert a list item](../../../../Using_Tools/Lists_tools/Insert_a_list_item.md)

**Field type:** [Single-line text](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
