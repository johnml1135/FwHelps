# Discussion field (Roles)

*User Interface › Field Descriptions › Lists › Roles fields*

**Full name:** **Discussion**

**Location:** **Role** pane of the **Roles** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores an optional discussion about the current [named](Name_field_(Roles).md) role.
