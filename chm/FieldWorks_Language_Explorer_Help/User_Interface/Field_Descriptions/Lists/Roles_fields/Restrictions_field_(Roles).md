# Restrictions field (Roles)

*User Interface › Field Descriptions › Lists › Roles fields*

**Full name:** **Restrictions**

**Abbreviation:** **ox**

**Location:** **Role** pane of the **Roles** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field references and displays the [names](../Restrictions_fields/name_field_restrictions.md) of one or more items from the **Restrictions** list, such as *No restrictions*, *Do not publish*, and so on. These indicate any restrictions for publishing the current [named](Name_field_(Roles).md) role.

This field its contents are metadata only, and do *not* control any process or print features.
