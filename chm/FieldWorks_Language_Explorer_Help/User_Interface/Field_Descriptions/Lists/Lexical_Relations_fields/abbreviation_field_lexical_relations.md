# Abbreviation field (Lexical Relations)

*User Interface › Field Descriptions › Lists › Lexical Relations fields*

**Full name:** **Abbreviation**

**Location:** **Lexical Relation** pane of the **Lexical Relations** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

For the current lexical relation, this field stores the abbreviation of the [name](name_field_lexical_relations.md), such as `ant` or `cf`.

**See Also:** [Name](name_field_lexical_relations.md) field.

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- In the **Configure Dictionary** dialog box, see [Cross References](../../../Menus/Tools/Configure_Dictionary/Cross_References.md) and [Lexical Relations](../../../Menus/Tools/Configure_Dictionary/Lexical_Relations.md).

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md)– you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Note:** If the current lexical relation uses a [reference set type](../../../../Using_Tools/Lists_tools/About_reference_set_types.md) for *two names*, see [Reverse Name](reverse_name_field_lexical_relations.md) and [Reverse Abbreviation](reverse_abbreviation_field_lexical_relations.md).
