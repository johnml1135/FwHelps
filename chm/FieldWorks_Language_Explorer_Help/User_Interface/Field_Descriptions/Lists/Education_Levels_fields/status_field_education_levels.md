# Status field (Education Levels)

*User Interface › Field Descriptions › Lists › Education Levels fields*

**Full name:** **Status**

**Abbreviation:** **st**

**Location:** **Education Level** pane of the **Education Levels** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field references and displays the [name](../Status_fields/Name_field_Status.md) of an item from the **Status** list. This indicates the status of the current [named](Name_field_Education_Levels.md) education level.

**Tasks:**

- [Choose](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) an item for a list reference field

- [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** [List reference](../../Field_Types/List_reference_field.md) (permits type-ahead)
