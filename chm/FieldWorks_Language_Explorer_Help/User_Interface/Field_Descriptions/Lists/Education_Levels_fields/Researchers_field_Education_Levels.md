# Researchers field (Education Levels)

*User Interface › Field Descriptions › Lists › Education Levels fields*

**Full name:** **Researchers**

**Location:** **Education Level** pane of the **Education Levels** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field references and displays the [names](../People_fields/full_name_field_people.md) of one or more people from the **People** list. This records who researched the current [named](Name_field_Education_Levels.md) education level. This would be useful for custom education levels.
