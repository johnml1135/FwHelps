# Researchers field (Text Chart Markers)

*User Interface › Field Descriptions › Lists › Text Chart Markers fields*

**Full name:** **Researchers**

**Location:** **Text Chart Marker** pane of the **Text Chart Markers** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field references and displays the [names](../People_fields/full_name_field_people.md) of one or more people from the **People** list. This records who researched the current [named](Name_fld_tcmrkers.md) marker.

**Tasks:**

- [Choose](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) an item for a list reference field

- [Text Chart Markers](../../../../Using_Tools/Lists_tools/Text_Chart/Text_Chart_Markers.md)

**Field type:** [List reference](../../Field_Types/List_reference_field.md) (permits type-ahead)

**Writing systems:** Best [vernacular](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) or [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
