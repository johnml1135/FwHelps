# Subitems field (Text Chart Markers)

*User Interface › Field Descriptions › Lists › Text Chart Markers fields*

**Full name:** **Subitems** or **Subitem**

**Location:** **Text Chart Marker** pane of the **Text Chart Markers** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

Each **Subitems** field acts as a header below which one or more **Subitem** fields may appear for the current [named](Name_fld_tcmrkers.md) marker.

Each **Subitem** field corresponds to one subitem of the item or subitem currently selected in the center pane.

**Tasks:**

- Click a subitem in the center pane to display it in the right pane for editing.

  - **See** **also****:** [Text Chart Markers](../../../../Using_Tools/Lists_tools/Text_Chart/Text_Chart_Markers.md).

- The menu button ![](../../../../assets/images/Menu_Button_pic.GIF) for a **Subitems** field allows you to [insert a subitem](../../../../Using_Tools/Lists_tools/Insert_a_list_subitem.md) to the *current* selection.

- The menu button ![](../../../../assets/images/Menu_Button_pic.GIF) for a **Subitem** field allows you to [delete that subitem](../../../../Using_Tools/Lists_tools/Delete_a_list_subitem.md) and its subitems from the *current* selection.

**Field type:** Not Editable

**Writing systems:** Not Applicable
