# Name field (Text Chart Markers)

*User Interface › Field Descriptions › Lists › Text Chart Markers fields*

**Full name:** **Name**

**Location:** **Text Chart Marker** pane of the **Text Chart Markers** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores the name of the current marker.

The names of the markers appear in the submenus that appear when you [mark grammatical information](../../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Text_Chart_tab/mark_grammatical_information.md) in the chart.

**Tasks:** [Text Chart Markers](../../../../Using_Tools/Lists_tools/Text_Chart/Text_Chart_Markers.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
