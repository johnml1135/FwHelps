# Positions fields overview

*User Interface › Field Descriptions › Lists › Positions fields*

Here are the fields in the **Positions** [list](../../../../Using_Tools/Lists_tools/List_item_usage_table.md):

|                                                 |
|-------------------------------------------------|
| **Field Label**                                 |
| [Name](name_field_positions.md)                 |
| [Abbreviation](abbreviation_field_positions.md) |
| [Description](description_field_positions.md)   |
| [Status](status_field_positions.md)             |
| [Discussion](discussion_field_positions.md)     |
| [Confidence](confidence_field_positions.md)     |
| [Researchers](Researchers_field_Positions.md)   |
| [Restrictions](Restrictions_field_Position.md)  |
| [Subitems](Subitems_field_(Positions).md)       |

> [!NOTE]
>
> - Positions are used to attribute roles (chief, policeman, doctor, and so on) to the persons in the [Positions field](../People_fields/People_fields_overview.md), which is in the **People** list. Only list item you [insert](../../../../Using_Tools/Lists_tools/Insert_a_list_item.md) appear in this list.
>
> - The [People list](../People_fields/People_fields_overview.md) fields allow you to be very specific and thorough as you describe the individuals in your list. This may be particularly important to document individuals listed in your [fieldnote records](../../../../Using_Tools/Notebook_tools/Notebook_overview.md). Positions is just one of the fields.
