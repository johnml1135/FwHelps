# Restrictions field (Status)

*User Interface › Field Descriptions › Lists › Status fields*

**Full name:** **Restrictions**

**Abbreviation:** **ox**

**Location:** **Status** pane of the **Status** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field references and displays the [names](../Restrictions_fields/name_field_restrictions.md) of one or more items from the **Restrictions** list. These indicate any restrictions for publishing the current [named](Name_field_Status.md) status.

This field does *not* control any process or print features.
