# Name field (Status)

*User Interface › Field Descriptions › Lists › Status fields*

**Full name:** **Name**

**Location:** **Status** pane of the **Status** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores the name of the current status, such as *Confirmed, Disproved,* *Pending*, or *Tentative*.

Many lists have a **Status** field that displays and references this status name.

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- [Insert a list item](../../../../Using_Tools/Lists_tools/Insert_a_list_item.md)

**Field type:** [Single-line text](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
