# Status field (Status)

*User Interface › Field Descriptions › Lists › Status fields*

**Full name:** **Status**

**Abbreviation:** **st**

**Location:** **Status** pane of the **Status** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field references and displays the [name](Name_field_Status.md) of an item from the **Status** list. This indicates the status of the current [named](Name_field_Status.md) status.

**Tasks:**

- [Choose](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) an item for a list reference field

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- [Insert a list item](../../../../Using_Tools/Lists_tools/Insert_a_list_item.md)
