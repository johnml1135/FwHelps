# What is a publication

*Using Tools › Lexicon tools › Lexicon Edit*

In FieldWorks, **Dictionary**, **Classified Dictionary** and **Reversal Indexes** display data (entries or senses, pictures, pronunciations, examples and so on).

Publications are part of the way you can control which data are *available.*

"Availability" can happen on *two* levels.

1.  [Named](Name_field_(Publications).md) publications are stored in **Lists**. You can have any number of them.\
    For example, **Main Dictionary** could include the most data, **Pocket Dictionary** could exclude archaic data, and another publication could exclude offensive data.

    - You can [choose](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_Publish_In_publications.md) to

      - *remove* a publication from a **Publish** \<item\> **In** field to make that data *unavailable* for display in that publication.

      - *add* the publication to the field to make the data *available* for display again.

      <!-- -->

      - You can [configure](../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) the dictionary, [configure](../../../Menus/Tools/Configure_Classified_Dictionary/Configure_Classified_Dictionary_View_dlgbox.md) the classified dictionary or [configure](../../../Menus/Tools/Configure_Reversal_Index/Configure_Reversal_Index_dialog_box.md) the reversal indexes to display or exclude *available* data.

<!-- -->

2.  You use the [Manage Dictionary layouts](../../../Menus/Tools/Configure_Dictionary/Manage_Dictionary_Views.md) or [Manage Reversal Index layouts](../../../Menus/Tools/Configure_Reversal_Index/Manage_Views_Reversal_Index.md) to specify which layouts you want to be *available* to each publication.

    - You see the effect when you use the menu buttons (![](../../../../assets/images/Using_Tools/Lists_tools/Information_bar_Menu_button.PNG)) on the [Information bar](../../../Toolbars/information_bar_overview.md).

After you [select a publication](../../../../Using_Tools/Lexicon_tools/Dictionary/Select_a_publication.md), you can only [select a dictionary layout](../../../../Using_Tools/Lexicon_tools/Dictionary/Select_a_dictionary_view.md) or [select a reversal index layout](../../../../Using_Tools/Lexicon_tools/Reversal_Indexes/Select_a_Reversal_index_view.md) that you specified should be *available* for that publication.

If you select a publication for which no layout is *available*, you see this notice instead of data: **No layouts match the current publication**.

> [!NOTE]
>
> - [Specify publishable lexical data](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Specify_publishable_lexical_data.md) has links to **Publish** \<item\> **In** fields and some other fields association with them.
