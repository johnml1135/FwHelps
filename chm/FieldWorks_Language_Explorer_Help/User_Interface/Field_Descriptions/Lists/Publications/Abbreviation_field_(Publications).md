# Abbreviation field (Publications)

*User Interface › Field Descriptions › Lists › Publications fields*

**Full name:** **Abbreviation**

**Location:** **Publication** pane of the **Publications** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores the abbreviation of the [name](Name_field_(Publications).md) of the current **Publications** list item. Currently, this abbreviation is not used elsewhere in Language Explorer.

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
