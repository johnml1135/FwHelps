# Name field (Publications)

*User Interface › Field Descriptions › Lists › Publications fields*

**Full name:** **Name**

**Abbreviation:** **Publication** pane of the **Publications** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores the name of the current publication.

The name of a publication can appear in these fields:

- [Publish Entry In](../../Lexicon/Lexicon_Edit_fields/Publication_Settings_flds/Publish_In_(Publication_Settings).md) for the entire *entry*

- [Publish Pronunciation In](../../Lexicon/Lexicon_Edit_fields/Entry_level_fields/Publish_In_(Pronunciations).md) for each *pronunciation*

- [Publish Sense In](../../Lexicon/Lexicon_Edit_fields/Sense_level_fields/Publish_In_(Sense).md) for each *sense*

- [Publish Picture In](../../Lexicon/Lexicon_Edit_fields/Sense_level_fields/Publish_In_(Pictures).md) for each *picture*

- [Publish Example In](../../Lexicon/Lexicon_Edit_fields/Sense_level_fields/Publish_In_(Example).md) for each *example.*

- You [select a publication](../../../../Using_Tools/Lexicon_tools/Dictionary/Select_a_publication.md) by name in [Dictionary](../../../../Using_Tools/Lexicon_tools/Dictionary/Dictionary_overview.md).

**See:** [What is a publication?](What_is_a_Publication.md).
