# Discussion field (Publications)

*User Interface › Field Descriptions › Lists › Publications fields*

**Full name:** **Discussion**

**Location:** **Publication** pane of the **Publications** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores an optional discussion about the current [named](Name_field_(Publications).md) **Publications** list item.

If there are [restrictions](Restrictions_field_(Publications).md) regarding the use of this publication, you may want to clarify the restriction here, or in the [Description](Description_field_(Publications).md) field.

**Tasks:** [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** [Multi-paragraph text field](../../Field_Types/Multiparagraph_text_field.md) — allows embedded [writing systems](../../../Menus/Format/select_a_writing_system.md) and [styles](../../../Menus/Format/apply_a_style_to_text.md)

**Writing systems:** One or more [analysis or vernacular](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
