# Status field (Publications)

*User Interface › Field Descriptions › Lists › Publications fields*

**Full name:** **Status**

**Abbreviation:** **st**

**Location:** **Publication** pane of the **Publications** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field references and displays the [name](../Status_fields/Name_field_Status.md) of an item from the **Status** list. This indicates the status of the current [named](../Time_of_Day_fields/Name_field_(Time_of_Day).md) **Publications** list item.
