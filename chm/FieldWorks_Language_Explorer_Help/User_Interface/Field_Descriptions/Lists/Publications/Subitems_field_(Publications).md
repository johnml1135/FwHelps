# Subitems field (Publications)

*User Interface › Field Descriptions › Lists › Publications fields*

**Full name:** **Subitems** or **Subitem**

**Location:**

**Publication** pane of the **Publications** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md)).

![](../../../../assets/images/Important_Icon.gif) This field only appears if you [configure](../../../Menus/Tools/Configure_List.md) this list to support hierarchy.

**Description:**

Each **Subitems** field acts as a header below which one or more **Subitem** fields may appear for the current [named](../Languages/name_field_Languages.md) location.

Each **Subitem** field corresponds to one subitem of the item or subitem currently selected in the center pane.

**Tasks:**

- Click a subitem in the center pane to display it in the right pane for [editing](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md).

- The menu button ![](../../../../assets/images/Menu_Button_pic.GIF) for a **Subitems** field allows you to [insert a list subitem](../../../../Using_Tools/Lists_tools/Insert_a_list_subitem.md) in the *current* selection.

- The menu button ![](../../../../assets/images/Menu_Button_pic.GIF) for a **Subitem** field allows you to [delete a list subitem](../../../../Using_Tools/Lists_tools/Delete_a_list_subitem.md) and its subitems from the *current* selection.

**Writing systems:** The **Subitem** name field contains the name of the subitem (in the **Name** field). Accordingly, it uses the same writing system as that subitem's name.
