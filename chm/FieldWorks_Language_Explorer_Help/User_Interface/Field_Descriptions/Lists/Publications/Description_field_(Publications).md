# Description field (Publications)

*User Interface › Field Descriptions › Lists › Publications fields*

**Full name:** **Description**

**Location:** **Publication** pane of the **Publications** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores a description of the current **Publications** list item.

[What is a publication?](What_is_a_Publication.md) mentions that you can [create](../../../../Using_Tools/Lists_tools/Create_new_publication.md) any number of publications. Use this field to describe the publication to distinguish it from other publications.

If there are [restrictions](Restrictions_field_(Publications).md) regarding the use of this publication, you may want to clarify the restriction here, or in the [Discussion](Discussion_field_(Publications).md) field.

**Tasks:** [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) — allows embedded [writing systems](../../../Menus/Format/select_a_writing_system.md) and [styles](../../../Menus/Format/apply_a_style_to_text.md)

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
