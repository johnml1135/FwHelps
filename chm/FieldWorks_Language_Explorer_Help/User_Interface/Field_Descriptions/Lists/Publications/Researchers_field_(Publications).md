# Researchers field (Publications)

*User Interface › Field Descriptions › Lists › Publications fields*

**Full name:** **Researchers**

**Abbreviation:** **Publication** pane of the **Publications** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field references and displays the name of one or more people from the **People** list. This documents the person or people who researched the current **Publications** list item. This probably should minimally record who [created the publication](../../../../Using_Tools/Lists_tools/Create_new_publication.md) and entered the [description](Description_field_(Publications).md).

**Tasks:**

- [Choose](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) an item for a list reference field

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** [List reference](../../Field_Types/List_reference_field.md) (permits type-ahead)

**Writing systems:** Best [vernacular](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) or [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
