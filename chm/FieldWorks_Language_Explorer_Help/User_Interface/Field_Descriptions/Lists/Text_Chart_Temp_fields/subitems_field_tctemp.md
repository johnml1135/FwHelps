# Subitems field (Text Constituents Chart Templates)

*User Interface › Field Descriptions › Lists › Text Constituent Chart Templates fields*

**Full name:** **Subitems** or **Subitem**

**Locations:** **Text Constituent Chart Template** pane of the **Text Constituent Chart Markers** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

Each **Subitems** field acts as a header below which one or more **Subitem** fields *may* appear for the current [named](name_field_tctemp.md) template list item.

(See the topic [Default Text Chart columns](../../../../Using_Tools/Lists_tools/Text_Chart/default_chart_columns.md) for information about the structure of the template and table.)

Each **Subitem** field corresponds to one subitem of the item or subitem currently selected in the center pane.

**Tasks:**

- Click a subitem in the center pane to display it in the right pane for editing.

  - [Specify columns for Text Chart tab](../../../../Using_Tools/Lists_tools/Text_Chart/specify_columns_for_chart.md)

- The menu button ![](../../../../assets/images/Menu_Button_pic.GIF) for a **Subitems** field allows you to [insert a subitem](../../../../Using_Tools/Lists_tools/Insert_a_list_subitem.md) to the *current* selection.

- The menu button ![](../../../../assets/images/Menu_Button_pic.GIF) for a **Subitem** field allows you to [delete that subitem](../../../../Using_Tools/Lists_tools/Delete_a_list_subitem.md) and its subitems from the *current* selection.

**Field type:** Not Editable

**Writing systems:** Not Applicable
