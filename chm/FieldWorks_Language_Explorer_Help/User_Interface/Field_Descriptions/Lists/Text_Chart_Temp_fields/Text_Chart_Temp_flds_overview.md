# Text Constituents Chart Templates fields overview

*User Interface › Field Descriptions › Lists › Text Constituent Chart Templates fields*

Here are the fields in the **Text Constituent Chart** **Templates** [list](../../../../Using_Tools/Lists_tools/List_item_usage_table.md):

|                                              |
|----------------------------------------------|
| **Field Label**                              |
| [Name](name_field_tctemp.md)                 |
| [Abbreviation](abbreviation_field_tctemp.md) |
| [Description](description_field_tctemp.md)   |
| [Status](status_field_tctemp.md)             |
| [Discussion](discussion_field_tctemp.md)     |
| [Confidence](confidence_field_tctemp.md)     |
| [Researchers](researchers_field_tctemp.md)   |
| [Restrictions](restrictions_field_tctemp.md) |
| [Subitems](subitems_field_tctemp.md)         |

> [!TIP]
>
> - Templates define the [hierarchical structure](../../../../Using_Tools/Lists_tools/Text_Chart/default_chart_columns.md) of the [Text Chart tab](../../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Text_Chart_tab/Text_chart_overview.md). **Name** fields at the *lowest* hierarchical level store the [column](../../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Text_Chart_tab/Text_Chart_tab_columns_and_rows.md) labels. Otherwise, metadata about the template is typically stored in these fields (currently not displayed in or used by other Language Explorer features).
>
> - You can [change](../../../../Using_Tools/Lists_tools/Text_Chart/specify_columns_for_chart.md) the default template, or [add](../../../../Using_Tools/Lists_tools/Text_Chart/Add_a_new_Text_Constituent_Chart_Template.md) a new template or [copy](../../../../Using_Tools/Lists_tools/Text_Chart/Copy_Text_Constituent_Chart_Template.md) one.
