# Name field (Text Constituents Chart Templates)

*User Interface › Field Descriptions › Lists › Text Constituent Chart Templates fields*

**Full name:** **Name**

**Location:** **Text Constituent Chart Template** pane of the **Text Constituent Chart Markers** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

In this list, **Name** fields store different content at each hierarchical level:

- Template names, such as **Default**.

  - Column group names, such as **Nucleus**.

    - [Column](../../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Text_Chart_tab/Text_Chart_tab_columns_and_rows.md) header labels, such as **Subject**, **Verb** and **O/C**.

[Default Text Chart columns](../../../../Using_Tools/Lists_tools/Text_Chart/default_chart_columns.md) describes the hierarchical levels. When this list is selected, the center pane displays them.

**Tasks:** [Specify columns for Text Chart tab](../../../../Using_Tools/Lists_tools/Text_Chart/specify_columns_for_chart.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [vernacular](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) and [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
