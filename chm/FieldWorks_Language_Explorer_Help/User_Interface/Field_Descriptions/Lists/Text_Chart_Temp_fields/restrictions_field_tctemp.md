# Restrictions field (Text Constituents Chart Templates)

*User Interface › Field Descriptions › Lists › Text Constituent Chart Templates fields*

**Full name:** **Restrictions**

**Abbreviation:** **ox**

**Location:** **Text Constituent Chart Template** pane of the **Text Constituent Chart Markers** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field references and displays the [names](../Restrictions_fields/name_field_restrictions.md) of one or more items from the **Restrictions** list. These indicate restrictions for publishing the current [named](name_field_tctemp.md) list item.

This field does *not* control any process or print features.

**Tasks:**

- [Choose](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) an item for a list reference field

- [Specify columns for Text Chart tab](../../../../Using_Tools/Lists_tools/Text_Chart/specify_columns_for_chart.md)

**Field type:** [List reference](../../Field_Types/List_reference_field.md) (permits type-ahead)
