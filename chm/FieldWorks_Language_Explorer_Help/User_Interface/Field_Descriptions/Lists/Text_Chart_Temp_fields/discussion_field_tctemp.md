# Discussion field (Text Constituents Chart Templates)

*User Interface › Field Descriptions › Lists › Text Constituent Chart Templates fields*

**Full name:** **Discussion**

**Location:** **Text Constituent Chart Template** pane of the **Text Constituent Chart Markers** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores an optional discussion about the current [named](name_field_tctemp.md) list item.

- [Specify columns for Text Chart tab](../../../../Using_Tools/Lists_tools/Text_Chart/specify_columns_for_chart.md)
