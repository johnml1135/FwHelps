# Trailing Token field (Morpheme Types)

*User Interface › Field Descriptions › Lists › Morpheme Types fields*

**Full name:** **Trailing Token**

**Location:** **Morpheme Type** pane of the **Morpheme Types** ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores the token (character, symbol) that comes *after* the current [named](Name_field_Morpheme_Types.md) morpheme type such as a hyphen for a **prefix-** or **-infix-**, or an equal sign for a **proclitic=**.

This token may be used or appear in numerous places, such as in the [New Entry](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Create_a_lexical_entry.md) dialog box (**Lexeme Form** field and **Morpheme Type** box), the [Morph Type](../../Lexicon/Lexicon_Edit_fields/Entry_level_fields/Morph_Type_Field.md) field, and in the dictionary entry.

**Tasks:**

- [Change tokens](../../../../Using_Tools/Lists_tools/Change_the_tokens_for_morpheme_types.md)

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- **See also:** [Lists overview](../../../../Using_Tools/Lists_tools/Lists_overview.md) and [About morpheme types](../../../../Using_Tools/Lists_tools/About_Morpheme_Types.md)

**Field type:** [Single-line text](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles, nor can you choose the writing system to use in this field.

**Writing systems:** English

**Notes:** The position of this token comes *after* the letters in right-to-left writing systems as well, such as **–prefix**.
