# Name field (Morpheme Types)

*User Interface › Field Descriptions › Lists › Morpheme Types fields*

**Full name:** **Name**

**Location:** **Morpheme Type** pane of the **Morpheme Types** ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores the name of the current morpheme type.

You choose morpheme type names in the [New Entry](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Create_a_lexical_entry.md) dialog box. You use the **Choose Morpheme Type** dialog box to [change the morpheme type](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/change_the_morph_type.md) in [Morph Type](../../Lexicon/Lexicon_Edit_fields/Entry_level_fields/Morph_Type_Field.md) fields. Various [columns](../../../../Basic_Tasks/Configure_Columns/Configure_Columns_overview.md) display the names.

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) to display [abbreviations](abbreviation_field_morpheme_types.md), names or both when you configure [Allomorphs](../../../Menus/Tools/Configure_Dictionary/alternate_forms.md).

- **See also:** [Lists overview](../../../../Using_Tools/Lists_tools/Lists_overview.md) and [About morpheme types](../../../../Using_Tools/Lists_tools/About_Morpheme_Types.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

> [!NOTE]
>
> - You *cannot* insert new morpheme types in the **Morpheme Types** list.
