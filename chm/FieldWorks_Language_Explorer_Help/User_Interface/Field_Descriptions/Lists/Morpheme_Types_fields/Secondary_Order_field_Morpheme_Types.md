# Secondary Order field (Morpheme Types)

*User Interface › Field Descriptions › Lists › Morpheme Types fields*

**Full name:** **Secondary Order**

**Location:** **Morpheme Type** pane of the **Morpheme Types** ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores the numerical values that set the dictionary order of similar entries, such as `in`, `in-`, `-in`, `in=`, `=in`, `and –in-`.

For example, if a `3` is entered for **prefix-** and a `5` is entered for **-infix-**, then `in-` would appear before `-in-` in the dictionary.

- [Change the secondary sort order](../../../../Using_Tools/Lists_tools/Change_the_secondary_sort_order.md)

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- **See also:** [Lists overview](../../../../Using_Tools/Lists_tools/Lists_overview.md) and [About morpheme types](../../../../Using_Tools/Lists_tools/About_Morpheme_Types.md)

**Field type:** [Single-line text](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles, nor can you choose the writing system to use in this field.

**Writing systems:** English
