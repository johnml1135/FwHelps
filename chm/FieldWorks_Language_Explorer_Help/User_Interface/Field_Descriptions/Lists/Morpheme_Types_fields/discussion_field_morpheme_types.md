# Discussion field (Morpheme Types)

*User Interface › Field Descriptions › Lists › Morpheme Types fields*

**Full name:** **Discussion**

**Location:** **Morpheme Type** pane of the **Morpheme Types** ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores an optional discussion about the current [named](Name_field_Morpheme_Types.md) morpheme type.

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- **See also:** [Lists overview](../../../../Using_Tools/Lists_tools/Lists_overview.md) and [About morpheme types](../../../../Using_Tools/Lists_tools/About_Morpheme_Types.md)

**Field type:** [Multi-paragraph text field](../../Field_Types/Multiparagraph_text_field.md) — allows embedded [writing systems](../../../Menus/Format/select_a_writing_system.md) and [styles](../../../Menus/Format/apply_a_style_to_text.md)

**Writing systems:** One or more [analysis or vernacular](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
