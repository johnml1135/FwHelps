# Discussion field (Locations)

*User Interface › Field Descriptions › Lists › Locations fields*

**Full name:** **Discussion**

**Location:** **Location** pane of the **Locations** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores an optional discussion about the current [named](location_name_field_locations.md) location.
