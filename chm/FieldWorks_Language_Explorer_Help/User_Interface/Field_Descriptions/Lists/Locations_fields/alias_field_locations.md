# Alias field (Locations)

*User Interface › Field Descriptions › Lists › Locations fields*

**Full name:** **Alias**

**Location:** **Location** pane of the **Locations** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores an alias (other or false) name of the current [named](location_name_field_locations.md) location.

You can display an alias name when you configure the location used with [pronunciations](../../../Menus/Tools/Configure_Dictionary/Pronunciations.md).

**Tasks:**

- [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
