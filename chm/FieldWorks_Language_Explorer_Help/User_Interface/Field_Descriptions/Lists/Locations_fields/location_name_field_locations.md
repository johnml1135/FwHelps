# Location Name field (Locations)

*User Interface › Field Descriptions › Lists › Locations fields*

**Full name:** **Location Name**

**Location:** **Location** pane of the **Locations** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores the name of the current location. It could be a country, city, town, area, region and so on, or other locations depending on your needs.

Location names are displayed and referenced in the [Location](../../Lexicon/Lexicon_Edit_fields/Entry_level_fields/Location_field.md) field in **Lexicon Edit**. Also, the [Place of Residence](../People_fields/Place_of_Residence_field_People.md) field and [Place of Birth](../People_fields/Place_of_Birth_field_People.md) field in the **People** list display and reference this name.

If the location has a nickname or alias, you can enter it in the [Alias](alias_field_locations.md) field.

**Tasks:**

- [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to include the [abbreviation](abbreviation_field_locations.md), name or both when you configure [Variant Forms](../../../Menus/Tools/Configure_Dictionary/Variant_Forms.md) and [Pronunciations](../../../Menus/Tools/Configure_Dictionary/Pronunciations.md).

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [vernacular](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) and [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
