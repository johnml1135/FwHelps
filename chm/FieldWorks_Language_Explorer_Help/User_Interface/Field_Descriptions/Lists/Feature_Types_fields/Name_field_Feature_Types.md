# Name field (Feature Types)

*User Interface › Field Descriptions › Lists › Feature Types fields*

**Full name:** **Name**

**Location:** **Feature Type** pane in the **Feature Types** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md)).

**Description:**

This field stores the name of the current feature type.

Feature type names are referenced and displayed in the [Type](../../Grammar/Inflection_Features_fields/Type_field_Features.md) field for complex features ([Inflection Features](../../Grammar/Inflection_Features_fields/Features_fields_overview.md) in **Grammar**).

It appears in the [Grammar Sketch](../../../../Using_Tools/Grammar_tools/Grammar_Sketch/Grammar_Sketch_overview.md) under **Feature System**.

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- **See also:** [About Features and Feature Types](../../../../Using_Tools/Grammar_tools/Inflection_Features/About_Infl_Features_and_Types.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
