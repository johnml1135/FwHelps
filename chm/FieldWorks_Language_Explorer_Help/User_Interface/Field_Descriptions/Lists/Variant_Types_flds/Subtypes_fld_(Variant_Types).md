# Subtypes fld (Variant Types)

*User Interface › Field Descriptions › Lists › Variant Types fields*

**Full name:** **Subtypes**

**Location:** **Variant Type** pane of the **Variant Types** ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

Each **Subtypes** field acts as a header below which one or more fields may appear.

For the current type, you see the type again in an abbreviated field label below this header field. Then, in that field you see the name of a subtype.

Example: For **Irregularly Inflected Form**, below **Subtypes** you see the **Irr. Inflected Form** field. The field contains the subtype named **Plural**.

**Tasks:**

- Click a subtype in the *center* pane to display it in the *right* pane for [editing](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md).

- On the menu button ![](../../../../assets/images/Menu_Button_pic.GIF) for this **Subtypes** field, you can click the **Insert Subtype** command to [insert a subtype](../../../../Using_Tools/Lists_tools/Insert_a_list_subitem.md).

- The menu button ![](../../../../assets/images/Menu_Button_pic.GIF) for any fields below the **Subtypes** field has the **Delete subitem and its subitems** command. You can use it to [delete that subtype](../../../../Using_Tools/Lists_tools/Delete_a_list_subitem.md) and its subtypes from the *current* selection.

**Field type:** Not Editable

**Writing systems:** Not Applicable
