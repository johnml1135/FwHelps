# Confidence field (Variant Types)

*User Interface › Field Descriptions › Lists › Variant Types fields*

**Full name:** **Confidence**

**Location:** **Variant Type** pane of the **Variant Types** ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field references and displays the [name](../Confidence_Levels_fields/Name_field_Confidence_Levels.md) of an item from the **Confidence Levels** [list](../../../../Using_Tools/Lists_tools/List_item_usage_table.md). This indicates your confidence in the current [named](name_fid_variant_types.md) variant type.

**Tasks:**

- [Choose](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) an item for a list reference field

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- [Insert a list item](../../../../Using_Tools/Lists_tools/Insert_a_list_item.md)
