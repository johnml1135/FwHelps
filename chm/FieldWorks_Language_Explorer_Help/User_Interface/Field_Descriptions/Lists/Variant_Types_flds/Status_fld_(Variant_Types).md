# Status field (Variant Types)

*User Interface › Field Descriptions › Lists › Variant Types fields*

**Full name:** **Status**

**Abbreviation:** **st**

**Location:** **Variant Type** pane of the **Variant Types** ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field references and displays the [name](../Status_fields/Name_field_Status.md) of an item from the **Status** [list](../../../../Using_Tools/Lists_tools/List_item_usage_table.md). This indicates the status of the current [named](name_fid_variant_types.md) variant type.
