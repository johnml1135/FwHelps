# Reverse Abbr field (Variant Types)

*User Interface › Field Descriptions › Lists › Variant Types fields*

**Full name:** **Reverse Abbr.**

**Location:** **Variant Type** pane of the **Variant Types** ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

For the current type, this field stores the abbreviations of the [reverse name](Reverse_Name_field_(Variant_Types).md), such as `dial. var. of` or **sp. var. of**.

**See Also:** [Abbreviation](abbreviation_fld_variant_types.md) field.

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- In the **Configure Dictionary** dialog box, see [Variant Forms](../../../Menus/Tools/Configure_Dictionary/Variant_Forms.md) and [Variant of Sense](../../../Menus/Tools/Configure_Dictionary/Variants_of_Sense.md) and so on.

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md)

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Note:** **See Also:** [Name](name_fid_variant_types.md) field.
