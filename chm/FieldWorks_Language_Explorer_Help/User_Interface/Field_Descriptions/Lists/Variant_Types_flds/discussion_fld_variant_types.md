# Discussion field (Variant Types)

*User Interface › Field Descriptions › Lists › Variant Types fields*

**Full name:** **Discussion**

**Location:** **Variant Type** pane of the **Variant Types** ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores an optional discussion about the current [named](name_fid_variant_types.md) variant type.

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)
