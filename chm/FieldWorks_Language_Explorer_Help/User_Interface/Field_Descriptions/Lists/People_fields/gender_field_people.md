# Gender field (People)

*User Interface › Field Descriptions › Lists › People fields*

**Full name:** **Gender**

**Location:** **Person** pane of the **People** ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field displays **Male**, **Female** or **Unknown** from a list that you cannot edit. It indicates the gender of the current [named](full_name_field_people.md) person.

**Tasks:**

- Click the down arrow ![](../../../../assets/images/down_arrow_pic.png), and then select one of the following: **Unknown**, **Male** or **Female**.

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** [List reference field](../../Field_Types/List_reference_field.md) (that you cannot edit)

**Writing systems:** User interface language
