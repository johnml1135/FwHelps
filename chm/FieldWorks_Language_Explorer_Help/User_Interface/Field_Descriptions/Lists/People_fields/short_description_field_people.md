# Short Description field (People)

*User Interface › Field Descriptions › Lists › People fields*

**Full name:** **Short Description**

**Location:** **Person** pane of the **People** ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores a description of the current [named](full_name_field_people.md) person. This field does not allow multiple paragraphs, so you should keep the description brief.

(**Tip:** The [Biographical Information field](biographical_information_field_people.md) permits multiple paragraphs.)

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) — allows embedding styles and writing systems

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
