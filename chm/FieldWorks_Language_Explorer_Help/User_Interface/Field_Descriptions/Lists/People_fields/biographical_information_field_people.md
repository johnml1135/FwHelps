# Biographical Information field (People)

*User Interface › Field Descriptions › Lists › People fields*

**Full name:** **Biographical Information**

**Location:** **Person** pane of the **People** ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores biographical information about the current [named](full_name_field_people.md) person.
