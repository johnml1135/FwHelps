# Alias field (People)

*User Interface › Field Descriptions › Lists › People fields*

**Full name:** **Alias**

**Location:** **Person** pane of the **People** ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores the alias name of the current [named](full_name_field_people.md) person. An alias name could be an *assumed name*, or it could be a name to conceal one's true identity.

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
