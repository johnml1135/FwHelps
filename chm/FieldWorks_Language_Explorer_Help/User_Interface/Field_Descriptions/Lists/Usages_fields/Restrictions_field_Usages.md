# Restrictions field (Usages)

*User Interface › Field Descriptions › Lists › Usages fields*

**Full name:** **Restrictions**

**Abbreviation:** **ox**

**Location:** **Usage** pane of the **Usages** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field references and displays the [names](../Restrictions_fields/name_field_restrictions.md) of one or more items from the **Restrictions** [list](../../../../Using_Tools/Lists_tools/List_item_usage_table.md). These indicate any restrictions for publishing the current [named](Name_field_Usages.md) usage.

This field does *not* control any process or print features.

**Tasks:**

- [Choose](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) an item for a list reference field

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- [Insert a list item](../../../../Using_Tools/Lists_tools/Insert_a_list_item.md)

**Field type:** [List reference](../../Field_Types/List_reference_field.md) (permits type-ahead)
