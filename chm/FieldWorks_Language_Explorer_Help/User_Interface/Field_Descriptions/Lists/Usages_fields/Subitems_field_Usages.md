# Subitems field (Usages)

*User Interface › Field Descriptions › Lists › Usages fields*

**Full name:** **Subitems** or **Subitem**

**Location:** **Usage** pane of the **Usages** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

Each **Subitems** field acts as a header below which one or more **Subitem** fields may appear for the current [named](Name_field_Usages.md) usage.

Each **Subitem** field corresponds to one subitem of the item or subitem currently selected in the center pane. The [name](Name_field_Usages.md) of the subitem appears in these fields.

**Tasks:**

- Click a subitem in the center pane to display it in the right pane for [editing](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md).

- The **Subitems** field menu button ![](../../../../assets/images/Menu_Button_pic.GIF) allows you to [insert a list subitem](../../../../Using_Tools/Lists_tools/Insert_a_list_subitem.md) to the *current* selection.

- The **Subitem** field menu button ![](../../../../assets/images/Menu_Button_pic.GIF) allows you to [delete that list subitem](../../../../Using_Tools/Lists_tools/Delete_a_list_subitem.md) and its subitems from the *current* selection.

**Writing systems:** The **Subitem** name field contains the name of the subitem (in the **Name** field). Accordingly, it uses the same writing system as that subitem's name.
