# Name field (Usages)

*User Interface › Field Descriptions › Lists › Usages fields*

**Full name:** **Name**

**Abbreviation:** **Usage** pane of the **Usages** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores the name of the current usage, such as *archaic, colloquial,* *formal* and so on.

Usages names are displayed and referenced in the [Usages](../../Lexicon/Lexicon_Edit_fields/Sense_level_fields/Usages_field.md) field in each sense (**Lexicon**).

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- [Insert a list item](../../../../Using_Tools/Lists_tools/Insert_a_list_item.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) to include the [abbreviation](Abbreviation_field_Usages.md), name or both when you configure **Usages**.

**Field type:** [Single-line text](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

> [!TIP]
>
> - For a more complete discussion about usages, such as when to use archaic or obsolete, on the **Help** menu point to **Resources** and then click **Introduction to Lexicography**.
