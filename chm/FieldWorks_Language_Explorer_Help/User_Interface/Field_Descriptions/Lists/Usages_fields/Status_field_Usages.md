# Status field (Usages)

*User Interface › Field Descriptions › Lists › Usages fields*

**Full name:** **Status**

**Abbreviation:** **st**

**Location:** **Usage** pane of the **Usages** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field references and displays the [name](../Status_fields/Name_field_Status.md) of an item from the **Status** [list](../../../../Using_Tools/Lists_tools/List_item_usage_table.md). This indicates the status of the current [named](Name_field_Usages.md) usage.

- [Choose](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) an item for a list reference field
