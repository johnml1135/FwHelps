# Researchers field (Usages)

*User Interface › Field Descriptions › Lists › Usages fields*

**Full name:** **Researchers**

**Location:** **Usage** pane of the **Usages** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field references and displays the [names](../People_fields/full_name_field_people.md) of one or more people from the **People** [list](../../../../Using_Tools/Lists_tools/List_item_usage_table.md). This records who researched the current [named](Name_field_Usages.md) usage. This would be useful for custom usages.
