# Short Description field (Dialect Labels)

*User Interface › Field Descriptions › Lists › Dialect Labels*

**Full name:** **Short Description**

**Location:** In the right pane of the **Dialect Labels** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores the description of the current [named](Full_Name_field_(Dialect_Labels).md) dialect label.

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) — allows embedded [writing systems](../../../Menus/Format/select_a_writing_system.md) and [styles](../../../Menus/Format/apply_a_style_to_text.md)

**Writing systems:** One or more [vernacular](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) and [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
