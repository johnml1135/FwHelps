# Full Name field (Dialect Labels)

*User Interface › Field Descriptions › Lists › Dialect Labels*

**Full name:** **Full Name**

**Location:** In the right pane of the **Dialect Labels** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores the full name of the current dialect label.

In **Lexicon Edit**, the various **Dialect Labels** fields display the [abbreviation](Abbreviation_field_(Dialect_Labels).md), not this name.

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) to include the abbreviation or this name when you configure a [Dialect Labels](../../../Menus/Tools/Configure_Dictionary/Dialect_Labels.md) node.

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [vernacular](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) and [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
