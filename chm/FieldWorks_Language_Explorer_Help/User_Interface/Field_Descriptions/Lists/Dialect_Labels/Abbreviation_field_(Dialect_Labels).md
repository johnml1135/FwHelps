# Abbreviation field (Dialect Labels)

*User Interface › Field Descriptions › Lists › Dialect Labels*

**Full name:** **Abbreviation**

**Location:** In the right pane of the **Dialect Labels** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores the abbreviation of the [full name](Full_Name_field_(Dialect_Labels).md) of the current dialect label.

This abbreviation, *not* the full name, is displayed in the [Dialect Labels (Entry)](../../Lexicon/Lexicon_Edit_fields/Entry_level_fields/Dialect_Labels_Entry.md) and [Dialect Labels (Sense)](../../Lexicon/Lexicon_Edit_fields/Sense_level_fields/Dialect_Labels_(Sense).md) fields (**Lexicon Edit**).

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) to include this abbreviation or the full name when you configure a [Dialect Labels](../../../Menus/Tools/Configure_Dictionary/Dialect_Labels.md) node.

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [vernacular](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) and [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
