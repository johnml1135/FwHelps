# Researchers field (Confidence Levels)

*User Interface › Field Descriptions › Lists › Confidence Levels fields*

**Full name:** **Researchers**

**Abbreviation:** **Confidence Level** pane of the **Confidence Levels** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field references and displays the [names](../People_fields/full_name_field_people.md) of one or more people from the **People** list. This records who researched the current [named](Name_field_Confidence_Levels.md) confidence level. This would be useful for custom confidence levels.

- [Choose](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) an item for a list reference field
