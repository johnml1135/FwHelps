# Custom Lists fields overview

*User Interface › Field Descriptions › Lists*

Here is an overview of fields that are typical in a [custom list](../../../Using_Tools/Lists_tools/Insert_a_custom_list.md). They may also be in a list that is stored in the *Lists* area, but which is used by related program, but *not* FieldWorks Language Explorer. For all other lists, each field has a Help topic that opens using the Help command in the menu button (![](../../../assets/images/Menu_Button_pic.GIF)) list that appears with that field.

<table width="100%">
<tbody>
<tr>
<th style="width: 25.929%"><p>Field</p></th>
<th style="width: 74.071%"><p>Use</p></th>
</tr>
&#10;<tr>
<td style="width: 25.929%"><p><strong>Name</strong></p></td>
<td style="width: 74.071%"><p>This field stores the name of the current list item. Is usually appears in dialog boxes when you could choose items from this list. It may appear in fields or dialog boxes that reference and display items from this list.</p></td>
</tr>
<tr>
<td style="width: 25.929%"><p><strong>Abbreviation</strong></p></td>
<td style="width: 74.071%"><p>This field stores the abbreviation of the name of the current list item. It may appear in fields or dialog boxes that reference and display items from this list.</p></td>
</tr>
<tr>
<td style="width: 25.929%"><p><strong>Description</strong></p></td>
<td style="width: 74.071%"><p>This field stores your description of the current list item.</p></td>
</tr>
<tr>
<td style="width: 25.929%"><p><strong>Status</strong></p></td>
<td style="width: 74.071%"><p>This field references and displays the name of an item you selected from the <strong>Status</strong> list. It indicates the status of the current list item.</p></td>
</tr>
<tr>
<td style="width: 25.929%"><p><strong>Discussion</strong></p></td>
<td style="width: 74.071%"><p>This field stores a longer discussion about the current list item. This field typically allows multiple paragraphs, and embedded writing systems and styles.</p></td>
</tr>
<tr>
<td style="width: 25.929%"><p><strong>Confidence</strong></p></td>
<td style="width: 74.071%"><p>This field references and displays the name of an item from the <strong>Confidence Levels</strong> list. It indicates your confidence in the current list item.</p></td>
</tr>
<tr>
<td style="width: 25.929%"><p><strong>Researchers</strong></p></td>
<td style="width: 74.071%"><p>This field references and displays the names of one or more people from the <strong>People</strong> list. This records who researched the current list item.</p></td>
</tr>
<tr>
<td style="width: 25.929%"><p><strong>Restrictions</strong></p></td>
<td style="width: 74.071%"><p>This field references and displays the names of one or more items from the <strong>Restrictions</strong> list. These indicate any restrictions for publishing the current named confidence level.</p>
<p>This field does <em>not</em> control any process or print features.</p></td>
</tr>
</tbody>
</table>

>
