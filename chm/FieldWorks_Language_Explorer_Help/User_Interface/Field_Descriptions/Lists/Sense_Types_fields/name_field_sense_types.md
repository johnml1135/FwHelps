# Name field (Sense Types)

*User Interface › Field Descriptions › Lists › Sense Types fields*

**Full name:** **Name**

**Location:** **Sense Type** pane of the **Sense Types** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores the name of the current sense type, such as *figurative* or *primary*.

Sense type names are displayed and referenced in the [Sense Type](../../Lexicon/Lexicon_Edit_fields/Sense_level_fields/Sense_Type_field.md) field (**Lexicon**).

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- [Insert a list item](../../../../Using_Tools/Lists_tools/Insert_a_list_item.md)

**Field type:** [Single-line text](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
