# Restrictions field (Sense Types)

*User Interface › Field Descriptions › Lists › Sense Types fields*

**Full name:** **Restrictions**

**Abbreviation:** **ox**

**Location:** **Sense Type** pane of the **Sense Types** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field references and displays the [names](../Restrictions_fields/name_field_restrictions.md) of one or more items from the **Restrictions** list. These indicate any restrictions for publishing the current [named](name_field_sense_types.md) sense type.

This field does *not* control any process or print features.

- [Choose](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) an item for a list reference field

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- [Insert a list item](../../../../Using_Tools/Lists_tools/Insert_a_list_item.md)
