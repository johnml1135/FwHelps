# Description field (Sense Types)

*User Interface › Field Descriptions › Lists › Sense Types fields*

**Full name:** **Description**

**Abbreviation:** **Sense Type** pane of the **Sense Types** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores the description of the current [named](name_field_sense_types.md) sense type.
