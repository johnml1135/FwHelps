# Questions field (Semantic Domains)

*User Interface › Field Descriptions › Lists › Semantic Domains fields*

**Full name:** **Questions**

**Location:** **Semantic Domain** pane of the **Semantic Domains** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field acts as a heading for the [Question](Question_field_Semantic_Domains.md), [Example Words](Example_Words_field_Semantic_Domains.md) and [Example Sentences](Example_Sentences_field_Semantic_Domains.md) field sets for the current [named](name_field_semantic_domains.md) semantic domain.
