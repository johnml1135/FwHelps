# Louw & Nida Codes field (Semantic Domains)

*User Interface › Field Descriptions › Lists › Semantic Domains fields*

**Full name:** **Louw & Nida Codes**

**Location:** **Semantic Domain** pane of the **Semantic Domains** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field displays any Louw & Nida code(s) that have been deemed similar to the current [named](name_field_semantic_domains.md) semantic domain.

**Tasks:**

- Edit existing content or type new content in this field.

  - [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** Text field

**Writing systems:** English only
