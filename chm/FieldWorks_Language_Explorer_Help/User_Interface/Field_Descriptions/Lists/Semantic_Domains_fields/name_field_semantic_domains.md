# Name field (Semantic Domains)

*User Interface › Field Descriptions › Lists › Semantic Domains fields*

**Full name:** **Name**

**Location:** **Semantic Domain** pane of the **Semantic Domains** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores the name of the current semantic domain.

Semantic domain names are displayed and referenced in various locations, such as in the [Semantic Domains](../../Lexicon/Lexicon_Edit_fields/Sense_level_fields/semantic_domains_field.md) field in each sense (**Lexicon Edit**) and in the [Analysis](../../Lexicon/Collect_Words_fields/Analysis_field_Collect_Words.md) field or [Vernacular](../../Lexicon/Collect_Words_fields/Vernacular_Field_Collect_Words.md) field (**Collect Words**).

**Tasks:**

- [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- [Enter the vernacular name of a semantic domain](../../../../Using_Tools/Lexicon_tools/Collect_Words/enter_the_vernacular_name_of_a_semantic_domain.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to include the [abbreviation](abbreviation_field_semantic_domains.md), name or both when you configure **Semantic Domains**.

**Field type:** [Single-line text](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:**

One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) *and* [vernacular](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

(The [Semantic Domains](../../Lexicon/Lexicon_Edit_fields/Sense_level_fields/semantic_domains_field.md) field in **Lexicon Edit** displays only analysis writing systems. If you have *only* vernacular names, they appear as asterisks.)
