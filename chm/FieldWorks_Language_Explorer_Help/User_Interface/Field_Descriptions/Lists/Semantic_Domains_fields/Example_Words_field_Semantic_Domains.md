# Example Words field (Semantic Domains)

*User Interface › Field Descriptions › Lists › Semantic Domains fields*

**Full name:** **Example Words**

**Location:** **Semantic Domain** pane of the **Semantic Domains** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

**Example Words** fields store one or more example words for the current [named](name_field_semantic_domains.md) semantic domain. Each **Example Words** field is part of a set of fields that includes a [Question](Question_field_Semantic_Domains.md) field and an [Example Sentences](Example_Sentences_field_Semantic_Domains.md) field. The example words are used in the [Example Words](../../Lexicon/Collect_Words_fields/Example_Words_Field_Collect_words.md) field in **Collect Words**.

These help prompt the discussion that leads to a faster and more complete collection of vernacular words for the semantic domain.

**Tasks:**

- Edit existing content or type new content in this field.

  - [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- [Insert a question](../../../../Using_Tools/Lists_tools/Insert_a_Question_Semantic_Domain.md) (**Semantic Domains**)

**Field type:** [Single-line text](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
