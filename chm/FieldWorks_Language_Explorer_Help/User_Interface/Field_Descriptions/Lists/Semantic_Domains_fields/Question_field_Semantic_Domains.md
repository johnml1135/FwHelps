# Question field (Semantic Domains)

*User Interface › Field Descriptions › Lists › Semantic Domains fields*

**Full name:** **Question**

**Location:** **Semantic Domain** pane of the **Semantic Domains** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

**Question** fields stores, typically, one question. Each **Question** field is part of a set that includes an [Example Words](Example_Words_field_Semantic_Domains.md) field and an [Example Sentences](Example_Sentences_field_Semantic_Domains.md) field.

Semantic domain questions are displayed in an equivalent [Question](../../Lexicon/Collect_Words_fields/Question_Field_Collect_Words.md) field (**Collect Words**) for the current [named](name_field_semantic_domains.md) semantic domain.

These help prompt the discussion that leads to a faster and more complete collection of vernacular words for the semantic domain.
