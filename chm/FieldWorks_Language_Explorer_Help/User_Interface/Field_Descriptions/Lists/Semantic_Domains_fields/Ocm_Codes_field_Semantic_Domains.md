# OCM Codes field (Semantic Domains)

*User Interface › Field Descriptions › Lists › Semantic Domains fields*

**Full name:** **OCM Codes**

**Location:** **Semantic Domain** pane of the **Semantic Domains** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores a textual mention of an *OCM* code related to the current [named](name_field_semantic_domains.md) semantic domain.

The source of these is *not* in a list you can edit. In addition, they are *independent* of the [chosen](../../../Menus/File/Create_a_new_Fieldworks_project.md) Anthropology Categories list. Those you can enter in the [Anthropology Categories](Anthropology_Categories_field_Sem_Dom.md) field.

**Tasks:**

- Edit existing content or type new content in this field.

  - [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** Text field

**Writing systems:** English only
