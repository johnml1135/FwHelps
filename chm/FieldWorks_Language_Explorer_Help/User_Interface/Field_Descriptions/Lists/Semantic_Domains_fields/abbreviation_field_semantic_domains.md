# Abbreviation field (Semantic Domains)

*User Interface › Field Descriptions › Lists › Semantic Domains fields*

**Full name:** **Abbreviation**

**Location:** **Semantic Domain** pane of the **Semantic Domains** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores the abbreviation for the current [named](name_field_semantic_domains.md) semantic domain. Abbreviations are displayed and referenced in the [Semantic Domains](../../Lexicon/Lexicon_Edit_fields/Sense_level_fields/semantic_domains_field.md) field in each sense (**Lexicon**).

**Tasks:**

- [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to include the abbreviation, name or both when you configure **Semantic Domains**.

**Field type:** [Single-line text](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
