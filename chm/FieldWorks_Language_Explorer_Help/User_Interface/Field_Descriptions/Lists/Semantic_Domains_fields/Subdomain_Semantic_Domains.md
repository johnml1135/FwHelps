# Subdomain field (Semantic Domains)

*User Interface › Field Descriptions › Lists › Semantic Domains fields*

**Full name:** **Subdomain**

**Location:** **Semantic Domain** pane of the **Semantic Domains** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

Each [Subdomains](Subdomains_Semantic_Domains.md) field acts as a header below which one or more **Subdomain** fields may appear for the current [named](name_field_semantic_domains.md) semantic domain.

Each **Subdomain** field corresponds to one subdomain of the domain or subdomain currently selected in the center pane.

**Tasks:**

- Click a subdomain in the center pane to display it in the right pane for [editing](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md).

- The menu button ![](../../../../assets/images/Menu_Button_pic.GIF) for a **Subdomains** field allows you to [insert a subdomain](../../../../Using_Tools/Lists_tools/Insert_a_list_subitem.md) to the *current* selection.

- The menu button ![](../../../../assets/images/Menu_Button_pic.GIF) for a **Subdomain** field allows you to [delete that subdomain](../../../../Using_Tools/Lists_tools/Delete_a_list_subitem.md) and its subdomains from the *current* selection.

**Field type:** Not editable

**Writing systems:** Not applicable
