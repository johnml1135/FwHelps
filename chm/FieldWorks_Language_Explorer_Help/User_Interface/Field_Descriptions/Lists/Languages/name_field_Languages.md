# Name field (Languages)

*User Interface › Field Descriptions › Lists › Languages fields*

**Full name:** **Name**

**Location:** **Language** pane of the **Languages** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field stores the name of the current language.

Language names can appear in the [Source Language](../../Lexicon/Lexicon_Edit_fields/Entry_level_fields/Source_Language_Etymology.md) field (**Lexicon Edit**).

**Tasks:**

- [Choose source languages](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_a_source_language.md)

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) to include the language name, [abbreviation](abbreviation_field_Languages.md), or both when you configure [Etymology](../../../Menus/Tools/Configure_Dictionary/Etymology.md).

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
