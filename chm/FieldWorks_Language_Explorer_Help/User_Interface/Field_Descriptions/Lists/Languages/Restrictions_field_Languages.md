# Restrictions field (Languages)

*User Interface › Field Descriptions › Lists › Languages fields*

**Full name:** **Restrictions**

**Abbreviation:** **ox**

**Location:** **Language** pane of the **Languages** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:**

This field references and displays the [names](../Restrictions_fields/name_field_restrictions.md) of one or more items from the **Restrictions** list.

These indicate any restrictions for publishing the current [named](name_field_Languages.md) language. This field does *not* control any process or print features.

- [Choose](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) an item for a list reference field
