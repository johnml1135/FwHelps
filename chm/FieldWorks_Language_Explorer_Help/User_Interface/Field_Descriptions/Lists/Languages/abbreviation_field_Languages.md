# Abbreviation field (Languages)

*User Interface › Field Descriptions › Lists › Languages fields*

**Full name:** **Abbreviation**

**Location:** **Language** pane of the **Languages** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores the abbreviation of the current [named](name_field_Languages.md) language.

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) to include the language [name](name_field_Languages.md), abbreviation, or both when you configure [Etymology](../../../Menus/Tools/Configure_Dictionary/Etymology.md).

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
