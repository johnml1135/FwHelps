# Name field (Time of Day)

*User Interface › Field Descriptions › Lists › Time of Day fields*

**Full name:** **Name**

**Abbreviation:** **Time of Day** pane of the **Time of Day** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores the name of the current list item, such as *Predawn* or *Midday*. You [choose a time of event](../../../../Using_Tools/Notebook_tools/Record_Edit_overview/Choose_Time_of_Event.md) in **Notebook**.

**Tasks:**

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
