# Status field (Time of Day)

*User Interface › Field Descriptions › Lists › Time of Day fields*

**Full name:** **Status**

**Abbreviation:** **st**

**Location:** **Time of Day** pane of the **Time of Day** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field references and displays the [name](../Status_fields/Name_field_Status.md) of an item from the **Status** list. This indicates the status of the current list item.

**Tasks:**

- [Choose](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) an item for a list reference field

- [Edit a list item](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- [Insert a list item](../../../../Using_Tools/Lists_tools/Insert_a_list_item.md)
