# Discussion field (Time of Day)

*User Interface › Field Descriptions › Lists › Time of Day fields*

**Full name:** **Discussion**

**Location:** **Time of Day** pane of the **Time of Day** list ([Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md))

**Description:** This field stores an optional discussion about the current list item.
