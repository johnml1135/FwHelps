# Multiparagraph text field

*User Interface › Field Descriptions › Field Types*

A *multiparagraph text field* permits text in multiple paragraphs. For example, the [Research Plan](../Notebook/Research_Plan_field_Ntbk.md) field in **Notebook** is a multiparagraph field.

Multiparagraph text fields contrast with [single-line text fields](Single_line_text_field.md).

Here are some features of a multiparagraph text field:

- All paragraph and character formatting options are available.

- Words you type use the default writing system (analysis or vernacular) specified for the FieldWorks project, but you can [embed text](../../Menus/Format/select_a_writing_system.md) using other writing systems.
