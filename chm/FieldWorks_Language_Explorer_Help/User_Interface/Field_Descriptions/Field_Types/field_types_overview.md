# Field Types overview

*User Interface › Field Descriptions › Field Types*

FieldWorks Language Explorer uses several types of fields:

- [Single-line text fields](Single_line_text_field.md) (and variations)

- [Multiparagraph text fields](Multiparagraph_text_field.md)

- [List reference fields](List_reference_field.md)

- [Date fields](date_field.md)

<!-- -->

- [Custom fields](../../Menus/Tools/Custom_Fields/Custom_Fields_overview.md). Any of the field types above and these:

**Number** fields store only whole numbers.

- Other unique field types you might use include:

- Fields with a check box that you can select (![](../../../assets/images/CheckedBox.PNG)) or clear (![](../../../assets/images/UncheckedBox.PNG)).

  **Affix Process Rule** fields hold rule tables for the [lexeme form](../Lexicon/Lexicon_Edit_fields/Entry_level_fields/Lexeme_Form_field.md) or an [allomorph](../Lexicon/Lexicon_Edit_fields/Alternate_Forms_level_flds/Alt_Forms_lev_flds_ov.md).

  [Media File](../Lexicon/Lexicon_Edit_fields/Entry_level_fields/media_file_field.md) fields in pronunciations.

> [!TIP]
>
> Here are some of the things you can do with fields:
>
> - [find a description](../field_descriptions_overview.md) of each field with the menu button ![](../../../assets/images/Menu_Button_pic.GIF).
>
> For "header" fields, or other fields that do not store any content, the field Help topics state **Field type:** Not Editable, or similar. The [Cross References](../Lexicon/Lexicon_Edit_fields/Entry_level_fields/cross_references_field.md) field is an example.
>
> - [change the width](change_the_width_of_the_field_label_area.md) of the field label area
>
> - [create hyperlinks](../../../Basic_Tasks/Creating_Hyperlinks/Creating_Hyperlinks_overview.md) (in some text fields)
>
> - [Move a field](../../../Basic_Tasks/Moving_fields/Move_a_field.md)
