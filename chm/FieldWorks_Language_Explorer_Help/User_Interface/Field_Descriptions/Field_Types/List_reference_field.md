# List reference field

*User Interface › Field Descriptions › Field Types*

A *list reference* field is the type of field that references and displays one or more items which are stored in another entry or in a list (usually in [Lists](../../../Using_Tools/Lists_tools/Lists_overview.md) or [Grammar](../../../Using_Tools/Grammar_tools/grammar_overview.md)). For some list reference fields, you can choose only one item, but for others you can choose many.

In most list reference fields, you can type a name or abbreviation of the list item you want to see a drop-down list of items that match. This is often called a '*type-ahead*' feature. Some fields use an ellipsis button ![](../../../assets/images/User_Interface/Field_Descriptions/Field_Types/ellipsis_button.png), and other fields use a down arrow ![](../../../assets/images/User_Interface/Field_Descriptions/Field_Types/down_arrow_button.png). Both display list items you can choose for the field.

## Find and Choose item

1.  To find items for a list reference field, do *one* of the following:

    - Click the field, and then click the ellipsis button, or the down arrow.

    - Use the `Tab` key to move the insertion point into the list reference field, and then onto the ellipsis button or down arrow. Then, for an ellipsis button press `Enter`; for a down arrow, press the `spacebar` or `Alt+Down Arrow`.

    - Type the name or abbreviation of the *existing* list item you to use want directly in the field. (This will *not add a new list item* to any list.)

    A dialog box appears *or* a drop-down [list](down_arrow_with_list_example_graphic.md) is displayed.

2.  To put the items you found into the list reference field, do *one* of the following:

    - Select one or more items in the dialog box, as permitted by the field. If necessary, click ![](../../../assets/images/User_Interface/Field_Descriptions/Field_Types/Plus_sign_box.GIF) (plus sign) to display subitems. Press **OK**.

    - Click an item in the drop-down list (the list closes automatically). In addition, if the list contains **More**, select **More** to bring up a different dialog box or catalog.

## Delete item

- To *delete* an item from a list reference field, usually you can select the item and then press the **Delete** key. There are variations, such as when you [delete a lexical relation](../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Delete_a_lexical_relation.md).

## Navigate from field content

- To *navigate* from a field to show content in another area, right-click an item in the field, and then click a [Show](../../../Basic_Tasks/Show_data/Show_data_overview.md) command on the [context-sensitive menu](../../../Basic_Tasks/Show_data/Context_sens_menus.md), *if one appears*.

> [!TIP]
>
> - Usually, if a list does *not* have field content (name, abbreviation, and so on) *in the* [default analysis writing system](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md), then Language Explorer uses any content in the next analysis writing system to populate list reference fields.
>
> - Most lists are maintained in [Lists](../../../Using_Tools/Lists_tools/Lists_overview.md) or [Grammar](../../../Using_Tools/Grammar_tools/grammar_overview.md), but you can also choose lexical entries and senses.
