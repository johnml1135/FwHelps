# Vernacular field (Collect Words)

*User Interface › Field Descriptions › Lexicon › Collect Words fields*

**Full name:** **Vernacular**

**Location:** In the **Semantic Domain** pane (**Collect Words**).

**Description:** This field displays the [name](../../Lists/Semantic_Domains_fields/name_field_semantic_domains.md) of the current semantic domain (in [Lists](../../../../Using_Tools/Lists_tools/List_item_usage_table.md)) in the *default vernacular* writing system.

**Tasks:**

- [Edit a list item or subitem](../../../../Using_Tools/Lists_tools/Edit_a_list_item_or_subitem.md)

- [Enter the vernacular name of a semantic domain](../../../../Using_Tools/Lexicon_tools/Collect_Words/enter_the_vernacular_name_of_a_semantic_domain.md)

- **See also:** [Collect Words overview](../../../../Using_Tools/Lexicon_tools/Collect_Words/Collect_Words_overview.md)

**Field type:** (*Editable*) [Single-line text](../../Field_Types/Single_line_text_field_example_graphic.md) – you *cannot* embed styles or writing systems. You can also edit this content in the [Lists](../../Lists/Semantic_Domains_fields/Semantic_Domains_fields_overview.md) area.

**Writing system:** Default [vernacular](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Note:** Compare with the [Analysis field](Analysis_field_Collect_Words.md)
