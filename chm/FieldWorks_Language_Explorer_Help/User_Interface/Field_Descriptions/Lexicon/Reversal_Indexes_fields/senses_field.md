# Referenced Senses field

*User Interface › Field Descriptions › Lexicon › Reversal Indexes fields*

**Full name:** **Referenced Senses**

**Location:**

In the **Reversal Entry** pane (**Reversal Entries**).

One or more **Referenced Senses** fields appear. The first occurrence is near the top of the pane. Other occurrences, if any, appear under a [Subentries](Subentries_field.md) field.

**Description:**

This field references one or more lexical senses or subsenses, and displays content from the following fields:

- **Headword** ([Lexeme](../Lexicon_Edit_fields/Entry_level_fields/Lexeme_Form_field.md) *or* [Citation](../Lexicon_Edit_fields/Entry_level_fields/Citation_Form_field.md) form),

- [Grammatical Info](../Lexicon_Edit_fields/Sense_level_fields/Grammatical_Info_field.md),

- the number of the selected sense (such as "2" from **Sense 2**), and

- [Gloss](../Lexicon_Edit_fields/Sense_level_fields/Gloss_field_Sense.md).

**See Also:** [About Reversal Entries](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/About_Reversal_Entries.md).

**See Also:** [Reversal Indexes overview](../../../../Using_Tools/Lexicon_tools/Reversal_Indexes/reversal_indexes_overview.md).

**Field type:** [List reference field](../../Field_Types/List_reference_field.md) (populated with content from fields in the **Lexicon Edit** area, not from a list)

**Writing systems:** Vernacular and analysis writing systems, as needed, for the various fields described above

**Tip:** You can [export a reversal index](../../../Menus/File/Export/Export_a_reversal_index.md) and include content from various fields in the associated sense or subsense.
