# Reversal Form field

*User Interface › Field Descriptions › Lexicon › Reversal Indexes fields*

**Full name:** **Reversal Form**

**Location:**

In the **Reversal Entry** pane (**Reversal Entries**).

One or more **Reversal Form** fields appear. The first occurrence is near the top of the pane. Other occurrences, if any, appear under a [Subentries](Subentries_field.md) field.

**Description:**

This field shares content with the [Reversal Entries](../Lexicon_Edit_fields/Sense_level_fields/reversal_entries_field.md) field of one or more lexical entries, if entered in the writing system of the selected [reversal index](../../../../Using_Tools/Lexicon_tools/Reversal_Indexes/reversal_indexes_overview.md). This content becomes the headword for the reversal index.

**See Also:** [About Reversal Entries](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/About_Reversal_Entries.md).
