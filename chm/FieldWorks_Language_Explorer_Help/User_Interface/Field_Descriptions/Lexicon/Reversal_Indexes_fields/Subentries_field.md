# Subentries field

*User Interface › Field Descriptions › Lexicon › Reversal Indexes fields*

**Full name:** **Subentries**

**Location:** In the **Reversal Entry** pane (**Reversal Entries**).

**Description:**

This field is a heading under which any subentries of the current reversal entry appear. Typically, you create reversal entries and subentries in the [Reversal Entries](../Lexicon_Edit_fields/Sense_level_fields/reversal_entries_field.md) field (**Lexicon Edit**).

Each subentry contains a

- [Reversal Form](form_field.md) field,

- [Reversal Category](category_field.md) field,

- [Referenced Senses](senses_field.md) field, and

- another **Subentries** heading for another level of [reversal subentries](../../../Menus/Tools/Configure_Reversal_Index/Reversal_Subentries.md).

**Tasks:**

- [Configuring a reversal index layout](../../../Menus/Tools/Configure_Reversal_Index/Configuring_a_reversal_index_view.md)

- [Insert a reversal subentry](../../../../Using_Tools/Lexicon_tools/Reversal_Indexes/Insert_a_reversal_subentry.md)

**See Also:** [Reversal Indexes overview](../../../../Using_Tools/Lexicon_tools/Reversal_Indexes/reversal_indexes_overview.md).

**Field type:** Not editable

**Writing systems:** Not applicable
