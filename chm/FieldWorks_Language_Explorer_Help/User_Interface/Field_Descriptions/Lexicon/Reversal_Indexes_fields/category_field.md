# Reversal Category field

*User Interface › Field Descriptions › Lexicon › Reversal Indexes fields*

**Full name:** **Reversal Category**

**Location:**

In the **Reversal Entry** pane (**Reversal Entries**).

One or more **Reversal Category** fields appear. The first occurrence is near the top of the pane. Other occurrences, if any, appear under a [Subentries](Subentries_field.md) field.

**Description:**

This field references and displays the [name](../../Lists/Reversal_Index_Categories_fields/Name_field_Reversal_Index_Categories.md) of a grammatical category from a **Reversal Index Categories** list, which indicates the grammatical category of the [Form](form_field.md) field content.

In **Reversal Index Categories** you populate a list of categories for *each* reversal index. Each list is *separate*, although each is populated from the same [catalog](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Using_Add_from_Catalog_dialog_box.md).
