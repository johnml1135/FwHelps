# Inflection Classes field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Allomorphs level fields*

**Full name:** **Inflection Classes**

**Abbreviation:** **c****l**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field is at the [Allomorphs level](Alt_Forms_lev_flds_ov.md) for each allomorph.

(A separate **Inflection Classes** [field](../Entry_level_fields/inflection_classes_field_entry_level.md) is at the [entry level](../Entry_level_fields/Entry_level_fields_overview.md) for each affix entry.)

**Description:**

This field references and displays the [names](../../../Grammar/Category_Edit_fields/name_field_inflection_class_category_edit.md) of one or more inflection classes which are stored under the **Inflection Class Info** [field](../../../Grammar/Category_Edit_fields/Inflection_Class_Info_field_Category_Edit.md) in **Category Edit** ([Grammar](../../../Grammar/Grammar_fields_overview.md)).

[Parsers](../../../../Menus/Parser/Parsing_words_overview.md) use inflection classes.

- [Choose an inflection class](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_an_inflection_class.md) (has a table of related fields)

- [Insert an allomorph](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_an_alternate_form.md)
