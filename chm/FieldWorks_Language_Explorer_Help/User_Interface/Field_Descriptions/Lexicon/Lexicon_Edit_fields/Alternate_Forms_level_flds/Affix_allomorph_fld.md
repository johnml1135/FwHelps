# Affix Allomorph field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Allomorphs level fields*

**Full name:** **Affix Allomorph** or **Affix Allomorph (Process)**

**Abbreviation:** **al**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field is at the [Allomorphs-level](Alt_Forms_lev_flds_ov.md).

The field label changes to **Affix Allomorph (Process)** if you [insert](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_Affix_Process_Rule.md) an Affix Process or [convert](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Convert_existing_form_or_allomorph.md) an existing affix allomorph to be an Affix Process.

**Description:**

This field stores an affix allomorph of the affix [Lexeme Form](../Entry_level_fields/Lexeme_Form_field.md) or [Citation Form](../Entry_level_fields/Citation_Form_field.md).

[Parsers](../../../../Menus/Parser/Parsing_words_overview.md) use allomorphs.

**Tasks:**

- [Insert an allomorph](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_an_alternate_form.md)

- [Insert an Affix Process](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_Affix_Process_Rule.md)

- [Convert an existing allomorph into an Affix Process](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Convert_existing_form_or_allomorph.md)

- [Delete an allomorph](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/delete_an_alternate_form.md)

- [Merge allomorphs](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Merge_allomorphs.md)

- [Move an allomorph](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Move_Allomorph.md) (to reorder them)

- [Show Allomorph in Concordance](../../../../../Basic_Tasks/Show_data/Show_in_from_Lexicon.md)

- [Swap Lexeme Form with Allomorph](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Swap_LexForm_with_Allomorph.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) to display [allomorphs](../../../../Menus/Tools/Configure_Dictionary/alternate_forms.md) and related information.

**Field type:** [Single-line text field](../../../Field_Types/Single_line_text_field.md) - you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [vernacular](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Note:**

- To convert a *process* affix allomorph back to a regular affix allomorph, right-click this field label, and then click **Convert to Affix Allomorph**.

- Allomorph order is *very important* for the [parsers](../../../../Menus/Parser/Parsing_words_overview.md).

- When you insert an *affix* allomorph, the **Affix Allomorph** field and these associated fields appear: [Is Abstract Form](Is_Abstract_Form_fld_Allomorph.md), [Morph Type](Morph_type_fld_allomorph.md) and [Environments](Environments_fld_allomorph.md).
