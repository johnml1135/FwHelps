# Required Features field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Allomorphs level fields*

**Full name:** **Required Features**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field is at the [Allomorph level](Alt_Forms_lev_flds_ov.md) for each inflectional and derivational allomorph.

(A separate **Required Features** [field](../Entry_level_fields/required_features_lex.md) is at the [entry level](../Entry_level_fields/Entry_level_fields_overview.md) for the lexeme form.)

**Description:**

For affix allomorphs, both inflectional and derivational, this field references and displays one or more inflection features that are required by the allomorph in order to be licit.

[Parsers](../../../../Menus/Parser/Parsing_words_overview.md) use features.

The inflection features displayed in this field appear in the [Grammar Sketch](../../../../../Using_Tools/Grammar_tools/Grammar_Sketch/Grammar_Sketch_overview.md) under sections **Feature System** and **Allomorphy**.
