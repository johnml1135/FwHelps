# Morph Type field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Allomorphs level fields*

**Full name:** **Morph Type**

**Abbreviation:** **mt**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field is at the [Allomorphs level,](Alt_Forms_lev_flds_ov.md) one for each allomorph. After you [insert an allomorph](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_an_alternate_form.md), this field and other fields related to allomorphs appear.

(A separate **Morph Type** field is between the **Lexeme Form** [field](../Entry_level_fields/Lexeme_Form_field.md) and the **Sense 1** [field](../Sense_level_fields/Sense_field.md). It refers to the lexeme form, not the entire entry.)

**Description:**

Initially, this field displayed the same morpheme type as specified for the headword. If the morpheme type of the allomorph is different, you may change it. Morpheme types are stored in the **Morpheme Types** [list](../../../../../Using_Tools/Lists_tools/List_item_usage_table.md).

[Parsers](../../../../Menus/Parser/Parsing_words_overview.md) use morpheme types.

**Tasks:**

- [Change the morph type](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/change_the_morph_type.md).

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to include the morph type name or abbreviation when you configure [Allomorphs](../../../../Menus/Tools/Configure_Dictionary/alternate_forms.md).

**Field type:** [List reference field](../../../Field_Types/List_reference_field.md)

**Writing systems:** Best [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Tip:** For more information, on the [Help](../../../../Menus/Help/Help_overview.md) menu point to **Resources**, and then click **Introduction to Parsing**. Section 4 includes a discussion about morpheme types that are significant to the parsers.
