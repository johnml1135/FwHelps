# Exemplar field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Exemplar**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

There can be an Exemplar field in each [sense](Sense_level_fields_overview.md) and subsense.

**Description:**

This field is used to store examples of an inflected form of a sense.

There are situations where it helps to show a specific inflected form at the beginning of a sense, especially when a specific sense may apply only to a specific inflected form.

**Tasks:**

- [Enter exemplar data](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_exemplar_data.md)

**Field type:** [Single-line text field](../../../Field_Types/Single_line_text_field.md) — allows embedded [writing systems](../../../../Menus/Format/select_a_writing_system.md) and [styles](../../../../Menus/Format/apply_a_style_to_text.md)

**Writing systems:** All vernacular
