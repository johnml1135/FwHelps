# Reversal Entries field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Reversal Entries**

**Abbreviation:** **rx**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

There is a **Reversal Entries** field in each **[sense](Sense_level_fields_overview.md) and subsense.

**Description:**

This field stores the form for one or more reversal entries for the current sense of the lexical entry.

The content from this field appears in the **Reversal Form** field in the reversal index that corresponds to the writing system in which you entered it.

You can also enter *subentries.* [About Reversal Entries](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/About_Reversal_Entries.md) and [Enter a reversal entry](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_a_reversal_entry.md) discuss how.

**Tasks:**

- [Configuring a reversal index layout](../../../../Menus/Tools/Configure_Reversal_Index/Configuring_a_reversal_index_view.md)

- [Enter a reversal entry](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_a_reversal_entry.md)

- [Export Reversal Index](../../../../Menus/File/Export/Export_a_reversal_index.md)

**Field type:** [Single-line text field](../../../Field_Types/Single_line_text_field.md) — you *cannot* embed characters in other writing systems or embed styles

**Writing systems:**

One or more [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md).

- When you add an analysis writing system, a reversal index is automatically added.

- A writing system needs to be selected (![](../../../../../assets/images/CheckedBox.PNG)) in the [Writing Systems tab](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) for the field to display the label and line.

- In the **Reversal Entries** field, you can click the menu button (![](../../../../../assets/images/Menu_Button_pic.GIF)) point to **Writing Systems** and then to select or clear the available languages. This might help you use your available screen space more efficiently.
