# Sense level fields overview

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

In the **Entry** pane (**Lexicon Edit**), these fields are below each **Sense** field:

|  |  |
|----|----|
| Field name | Field name (continued) |
| [Academic Domains](academic_domains_field.md) | [Publish Example In](Publish_In_(Example).md) |
| [Anthropology Categories](Reference_field.md) | [Publish Picture In](Publish_In_(Pictures).md) |
| [Anthropology Note](anthropology_note_field.md) | [Publish Sense In](Publish_In_(Sense).md) |
| [Bibliography](bibliography_field.md) | [Reference](Reference_field.md) |
| [Caption](caption_field.md) | [Referenced Complex Forms](Referenced_Complex_Forms_(sense).md) |
| [Complex Forms](Complex_Forms.md) | [Restrictions](restrictions_field.md) |
| [Definition](definition_field.md) | [Reversal Entries](reversal_entries_field.md) |
| [Dialect Labels (Sense)](Dialect_Labels_(Sense).md) | [Scientific Name](scientific_name_field.md) |
| [Discourse Note](discourse_note_field.md) | [Semantic Domains](semantic_domains_field.md) |
| [Discussion (Extended Note)](Extended_Note/Discussion_field_(Extended_Note).md) | [Semantics Note](semantics_note_field.md) |
| [Encyclopedic Info](encyclopedic_info_field.md) | [Sense](Sense_field.md) (e.g. **Sense 1**, **Sense 1.1**) |
| [Example (Extended Note)](Extended_Note/Example_field_(Extended_Note).md) | [Sense Type](Sense_Type_field.md) |
| [Example (sense or subsense)](example_field.md) | [SocioLinguistics Note](SocioLinguistics_Note_field.md) |
| [Exemplar field](Exemplar_field.md) | [Source](Source_field.md) |

| [General Note](general_note_field.md) | [Thumbnail](Thumbnail_field.md) |
| [Gloss](Gloss_field_Sense.md) | [Translation (Extended Note)](Extended_Note/Translation_field_(Extended_Note).md) |
| [Grammar Note](grammar_note_field.md) | [Translation (sense or subsense)](Translation_field.md) |
| [Grammatical Info](Grammatical_Info_field.md) | [Type (Extended Note)](Extended_Note/Type_field_(Extended_Note).md) |

> [!TIP]
>
> - You can [merge senses](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Merge_senses.md), [move a sense](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Move_sense_to_new_entry.md) to a new entry and [move a sense](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Move_sense_to_another_entry.md) to another entry.
>
> - You can [add custom fields](../../../../Menus/Tools/Custom_Fields/add_a_custom_field.md) to examples.
>
> - You can type USFM markers in a custom field to display data in one or more [tables](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Format_a_table.md).
>
> - The above list is sorted in the order they typically appear in the **Entry** pane.
