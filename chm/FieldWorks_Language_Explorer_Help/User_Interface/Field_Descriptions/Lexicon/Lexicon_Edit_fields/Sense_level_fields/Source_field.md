# Source field (Lexicon Edit)

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Source**

**Abbreviation:** **so**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This **Source** field is in each **[sense](Sense_level_fields_overview.md) and subsense.

(The **Etymology** field set has a separate **Source Form** field where you can [enter](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_etymological_information.md) etymological information.)

**Description:**

This field allows you to enter the source of the information in the current sense or subsense.

For example, you can enter the name or initials of the researcher or the name of the village where the information was gathered.

It is not normally included in the dictionary, although you can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) to include it. For example, you might want to include this field only in a draft copy of the dictionary. But in this case, you will want to make sure to exclude it from your final publication.

**Tasks:**

- [Enter source information](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_source_information.md)

**Field type:** This text field does not display writing system identifiers or allow paragraphs.

**Writing systems:** It defaults to the English writing system, even if English is *not* the default (top) [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) writing system. However, you can embed other analysis and vernacular [writing systems](../../../../Menus/Format/select_a_writing_system.md) and apply [styles](../../../../Menus/Format/apply_a_style_to_text.md).
