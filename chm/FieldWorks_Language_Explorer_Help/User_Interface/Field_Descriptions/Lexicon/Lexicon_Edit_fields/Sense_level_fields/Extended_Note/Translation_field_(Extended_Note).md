# Translation field (Extended Note)

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Translation**

**Abbreviation:** **xt**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This **Translation** field appears with its associated **Example** field after you [insert](../../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_an_example_in_extended_note.md) an example in an extended note. Each example can have one or more **Translation** fields.

**Description:**

This field stores a translation of the content in the associated **Example** field.

You can enter (type or paste) a translation.

If you use the **Find example sentence** command, then the example sentence is copied into the **Example** field and any existing translation is copied into this **Translation** field. In this case, you can edit the copy in this field.

- [Insert an example in an extended note](../../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_an_example_in_extended_note.md)
