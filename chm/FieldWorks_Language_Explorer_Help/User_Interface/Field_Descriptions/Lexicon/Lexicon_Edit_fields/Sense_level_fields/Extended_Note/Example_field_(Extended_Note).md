# Example field (Extended Note)

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Example**

**Abbreviation:** **xv**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

[Type](Type_field_(Extended_Note).md), [Discussion](Discussion_field_(Extended_Note).md) and **Example** fields are added when you [insert](../../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_an_extended_note.md) an extended note in a sense or subsense.

A **Translation** field is added when you insert an example in an extended note.

([Senses](../Sense_level_fields_overview.md) and subsenses have a separate [Example](../example_field.md) field.)

**Description:**

**Example** fields typically store content that exemplifies a use of the headword as defined in the current sense or subsense.

*This* example specifically supports contents in the associated **Discussion** field.

**Tasks:**

- [Insert an example in an extended note](../../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_an_example_in_extended_note.md)

  - After you use **Insert Example in Note**, you can see and use the [Find example sentence](../../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Find_example_sentence.md) command.

  - Reorder examples, if an extended note has more than one:\
    Right-click one of them, and then click **Move Example Up** or **Move Example Down**.

- [Delete an example](../../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Delete_an_example.md)

- You can [configure the dictionary](../../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show content from this field and associated fields when you configure [Extended Note](../../../../../Menus/Tools/Configure_Dictionary/Extended_Note.md).

**Field type:** [Single-line text field](../../../../Field_Types/Single_line_text_field.md) — allows embedded [writing systems](../../../../../Menus/Format/select_a_writing_system.md) and [styles](../../../../../Menus/Format/apply_a_style_to_text.md)

**Writing systems:** One or more [vernacular](../../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md), which can include an [Audio](../../../../../../Basic_Tasks/Audio_files/Audio_files_overview.md) writing system so you can record the example.
