# Extended Note field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

See [Extended Note fields overview](Extended_Note_fields_overview.md) for an overview of why you might want to insert one or more extended note field sets in your entry.

**Full name:** **Extended Note**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

*Each* [sense](../Sense_field.md) and subsense can have one or more **Extended Note** fields.

**Description:**

Use this field to store information about the current sense or subsense. In contrast to other note fields, you can categorize this information by "type", and you can include one or more examples to help illustrate it.

Initially, this field has no distinguishing appearance. It becomes a *header* field (![](../../../../../../assets/images/minus_sign_box.GIF) **Extended Note**) after you [insert an Extended Note](../../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_an_extended_note.md) and a [field set](Extended_Note_fields_overview.md) appears.

Each extended note has a **Type** and **Discussion** field, and can have one or more pairs of **Example** and **Translation** fields.

**Tasks:**

- [Insert an extended note](../../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_an_extended_note.md)

- [Enter extended note information](../../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_Extended_Note.md)

  - [Choose Type (Extended Note)](../../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_a_note_type.md)

  - [Insert an example in an extended note](../../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_an_example_in_extended_note.md)

- [Delete Extended Note](../../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Delete_an_extended_note.md)

<!-- -->

- Reorder extended notes (if a sense or subsense has more than one):

Right-click one of them and then click **Move Extended Note Up** or **Move Extended Note Down**.

You can [configure the dictionary](../../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show content from the associated fields when you configure [Extended Note](../../../../../Menus/Tools/Configure_Dictionary/Extended_Note.md).

**Field type:** Header field: you can click the ![](../../../../../../assets/images/minus_sign_box.GIF) (minus sign) to collapse the field set or click the ![](../../../../../../assets/images/Plus_sign_box.GIF) (plus sign) to expand it.
