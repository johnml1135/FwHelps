# Type field (Extended Note)

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Type**

**Abbreviation:** **ty**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

**Type**, [Discussion](Discussion_field_(Extended_Note).md) and [Example](Example_field_(Extended_Note).md) fields are added when you [insert](../../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_an_extended_note.md) an extended note in a sense or subsense.

**Description:** Each **Type** field holds the [name](../../../../Lists/Extended_Note_Types/Name_field_Extended_Notes.md) of a type from the **Extended Note Type** [list](../../../../../../Using_Tools/Lists_tools/List_item_usage_table.md). It categorizes the information in the associated **Discussion** field.

**Tasks:**

- [Choose Type (Extended Note)](../../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_a_note_type.md)

- You can [configure the dictionary](../../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show content from this field and associated fields when you configure [Extended Note](../../../../../Menus/Tools/Configure_Dictionary/Extended_Note.md).

**Field type:** [List reference field](../../../../Field_Types/List_reference_field.md)

**Writing systems:** The list item is displayed in the default [analysis](../../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) writing system or in another analysis writing system (if there is not one in the default). If there is no content in the [Name field](../../../../Lists/Extended_Note_Types/Name_field_Extended_Notes.md), then this field shows \*\*\*.
