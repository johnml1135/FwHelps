# Discussion field (Extended Note)

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Discussion**

**Abbreviation:** `enn`

**Location:**

In the **Entry** pane (**Lexicon Edit**).

[Type](Type_field_(Extended_Note).md), **Discussion** and [Example](Example_field_(Extended_Note).md) fields are added when you [insert](../../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_an_extended_note.md) an extended note in a sense or subsense.

**Description:** Use this field to record information about the sense or subsense, such as information about a semantic or grammatical aspect. You can categorize this information by [type](Type_field_(Extended_Note).md).

**Tasks:**

- [Enter extended note information](../../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_Extended_Note.md)

- You can [configure the dictionary](../../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show content from this field and associated fields when you configure [Extended Note](../../../../../Menus/Tools/Configure_Dictionary/Extended_Note.md).

**Field type:** [Single-line text field](../../../../Field_Types/Single_line_text_field.md) — allows embedded [writing systems](../../../../../Menus/Format/select_a_writing_system.md) and [styles](../../../../../Menus/Format/apply_a_style_to_text.md)

**Writing systems:** One or more [analysis](../../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
