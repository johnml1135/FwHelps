# Academic Domains field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Academic Domains**

**Abbreviation:** **is**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

There is an **Academic Domains** field in each [sense](Sense_level_fields_overview.md) and subsense.

**Description:** This field references and displays the [name](../../../Lists/Academic_Domains_fields/Name_field_Academic_Domains.md) of one or more items from the **Academic Domains** [list](../../../../../Using_Tools/Lists_tools/List_item_usage_table.md) so you can categorize the sense within one or more academic domains.

**Tasks:**

- [Choose academic domains](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_academic_domains.md)

- [Bulk choose academic domains](../../../../../Using_Tools/Lexicon_tools/Bulk_Edit_Entries/Bulk_choose_academic_domains.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to include the name or abbreviation when you configure **Academic Domains**.
