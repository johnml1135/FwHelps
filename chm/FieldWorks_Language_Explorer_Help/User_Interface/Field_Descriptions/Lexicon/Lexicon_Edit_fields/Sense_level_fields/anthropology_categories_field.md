# Anthropology Categories field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Anthropology Categories**

**Abbreviation:** **ac**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

There is an **Anthropology Categories** field in each [sense](Sense_level_fields_overview.md) and subsense.

**Description:** This field references and displays the [name](../../../Lists/Anthropology_Categories_fields/Name_field_Anthropology_Categories.md) of one or more items from the **Anthropology Categories** [list](../../../../../Using_Tools/Lists_tools/List_item_usage_table.md) so you can categorize the sense within one or more anthropological categories.

**Tasks:**

- [Choose anthropology categories](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/choose_anthropology_categories.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to include the name or abbreviation when you configure **Anthropology Categories**.

**Field type:** [List reference](../../../Field_Types/List_reference_field.md) (permits type-ahead)

**Writing systems:** Best [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Right-click menu commands:**

Right-click a category in this field, and then click one of the following:

- **Show in Anthropology Categories list**:

  Opens the **Lists** area to the **Anthropology Categories** list, and displays the category you right-clicked. Any other filters are turned off.

- **Filter for Lexical Entries with this category**:

  Adds the **Anthropology Categories** column to the **Entries** pane, if it is not already displayed, and then sets a filter to show only entries that use the category you right-clicked. Any other filters are turned off.

- **Filter for Notebook Records with the category**:

  Opens the **Notebook** area, and adds the **Anthropology Categories** column to the **Records** pane, if it is not already displayed, and then sets a filter to show only records that use the category you right-clicked. Any other filters are turned off.
