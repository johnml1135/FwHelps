# Status field (Lexicon Edit)

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Status**

**Abbreviation:** **st**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field appears in each [sense](Sense_level_fields_overview.md) and subsense.

**Description:**

This field references and displays the [name](../../../Lists/Status_fields/Name_field_Status.md) of an item from the **Status** [list](../../../../../Using_Tools/Lists_tools/List_item_usage_table.md), which identifies the status of content of the fields in the current sense. You can specify *Confirmed*, *Disproved*, *Pending,* *Tentative,* or other status terminology that you insert in the **Status** list.

It is not normally included in the dictionary, although you can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) to include it. For example, you might want to include this field in a draft copy of the dictionary. But you should *not* put anything in this field that you want in your final publication.

You may want to [filter](../../../../../Basic_Tasks/Filtering_data/filtering_data_overview.md) your lexical data based on this field to help you determine [publishable data](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Specify_publishable_lexical_data.md).
