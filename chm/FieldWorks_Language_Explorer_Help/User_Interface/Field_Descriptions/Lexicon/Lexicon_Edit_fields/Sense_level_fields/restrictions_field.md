# Restrictions field (lex senses)

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Restrictions**

**Abbreviation:** **ox**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This **Restrictions** fields is in each **[sense](Sense_level_fields_overview.md) and subsense.

(A separate [Restrictions](../Entry_level_fields/Restrictions_field.md) field appears at the [entry level](../Entry_level_fields/Entry_level_fields_overview.md).)

**Description:**

This field is used for semantic or grammatical restrictions pertinent to the use of this sense.

For example, you can enter **human**, **female**, **only said of the opposite sex** and so on.

The **Usages** field may contain similar content and has the advantage of being a [list reference field](../../../Field_Types/List_reference_field.md), so you may prefer to normally use it. However, there may be times when a prose restriction is desirable.

**Tasks:**

- [Enter restrictions](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_restrictions.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show data from this field when you configure **Restrictions**.

**Field type:**

[Single-line text field](../../../Field_Types/Single_line_text_field.md) — allows embedded [writing systems](../../../../Menus/Format/select_a_writing_system.md) and [styles](../../../../Menus/Format/apply_a_style_to_text.md)

**Writing systems:** One or more [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
