# Dialect Labels (Sense)

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Dialect Labels (Sense)**

**Location:** **Entry** pane (**Lexicon Edit**), in each sense and subsense

**Description:** This field references and displays the [abbreviation](../../../Lists/Dialect_Labels/Abbreviation_field_(Dialect_Labels).md) of one or more items from the **Dialect Labels** [list](../../../../../Using_Tools/Lists_tools/List_item_usage_table.md). It identifies the dialect or dialects that use the definition of the current sense or subsense.

**Tasks:**

- [Choose Dialect Labels](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_a_dialect_label.md)

If you chose more than one dialect label, you can right-click one of them and then click **Move Right** or **Move Left**. The order in the field affects the order in **Dictionary**.

- Right-click a dialect label and then click **Show** to see it in **Lists**.

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) to include the [abbreviation](../../../Lists/Dialect_Labels/Abbreviation_field_(Dialect_Labels).md) or full name when you configure [Dialect Labels](../../../../Menus/Tools/Configure_Dictionary/Dialect_Labels.md).

**Field type:** [List reference field](../../../Field_Types/List_reference_field.md)

**Writing systems:** Best [vernacular or analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
