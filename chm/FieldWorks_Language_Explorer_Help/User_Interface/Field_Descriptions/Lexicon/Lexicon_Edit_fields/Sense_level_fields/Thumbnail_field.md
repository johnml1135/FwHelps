# Thumbnail field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Thumbnail**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

**Thumbnail** fields can appear in each [sense](Sense_level_fields_overview.md) and subsense. Each time you insert a picture, these fields appear: [Picture](Picture_field.md), **Thumbnail**, [Caption](caption_field.md), [File](File_field.md) and [Publish Picture In](Publish_In_(Pictures).md).

**Description:**

This field stores a thumbnail-sized version of the picture in the **Picture** field. You can hide the larger **Picture** field and display this field to save space in the **Entry** pane. This does *not* change or affect what is displayed in **Dictionary**.

**See:** [File field](File_field.md) for important information.

**Tasks:**

- [Delete Picture](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Delete_a_picture.md)

- [Insert a picture](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_a_picture.md) (includes **Picture Properties** dialog box)

- [Move Picture Up or Down](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/move_picture.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show the pictures and related data when you configure [Pictures](../../../../Menus/Tools/Configure_Dictionary/Pictures.md).

**Field type:** Picture field

**Writing systems:** Not applicable

**Tip:**

To open the **Picture Properties** dialog box, do these steps:

1.  Click the field label.

2.  Click the menu button (![](../../../../../assets/images/Menu_Button_pic.GIF)) and then click **Picture Properties**.

In the dialog box, you can see the path (URL) to the picture. You can use the **Choose Picture** button to find a different picture.
