# Semantics Note field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Semantics Note**

**Abbreviation:** **sm**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

There is a **Semantics Note** field in each **[sense](Sense_level_fields_overview.md) and subsense.

**Description:**

This field provides a place for you to record notes to yourself regarding the semantics of the current sense.

For example, you can include a question such as, "Does this word mean to accidentally scratch yourself or to deliberately itch yourself?"

It is not intended to be included in the dictionary, although you can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) to include it. For example, you might want to include this field in a draft copy of the dictionary to alert yourself to the need to do further research. But you probably should *not* put anything in this field that you want in your final publication.
