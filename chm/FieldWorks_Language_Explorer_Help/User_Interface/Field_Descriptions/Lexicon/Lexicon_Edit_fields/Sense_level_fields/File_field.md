# File field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **File**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

A **File** field can appear in each [sense](Sense_level_fields_overview.md) and subsense. Each time you insert a picture, these fields appear: [Picture](Picture_field.md), [Thumbnail](Thumbnail_field.md), [Caption](caption_field.md), **File** and [Publish Picture In](Publish_In_(Pictures).md).

**Description:**

Each **File** field displays the path to the associated picture.

When you insert a picture that is *not* already in a [folder](../../../../Menus/File/Backup_and_Restore/Folder_Structure.md) which you can [back up](../../../../Menus/File/Backup_and_Restore/Back_up_this_Project.md), the **Picture Properties** dialog box lets you copy or move the picture, or leave it in its current location. This choice determines the path.

**Tasks:**

- [Delete Picture](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Delete_a_picture.md).

- [Insert a picture](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_a_picture.md) (includes **Picture Properties** dialog box).

- [Move Picture Up or Down](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/move_picture.md).

- Click **Picture Properties** on the menu button (![](../../../../../assets/images/Menu_Button_pic.GIF)) menu, or click the picture, to reopen the **Picture Properties** dialog box.

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show pictures (**Thumbnail**) and related data when you configure [Pictures](../../../../Menus/Tools/Configure_Dictionary/Pictures.md), but *not* data from this field.

**Note:**

- You *cannot* edit the path in this field. Instead, use the **Picture Properties** dialog box to choose a picture in a different path.

- If you delete a picture, any copy remains in the **Pictures** folder. Manually delete pictures from the folder that you will never use or that others should never see.

**Field type:** A unique non-editable field.

**Writing systems:** English

**Tip:**

To open the **Picture Properties** dialog box, do these steps:

1.  Click the field label.

2.  Click the menu button (![](../../../../../assets/images/Menu_Button_pic.GIF)) and then click **Picture Properties**.

In the dialog box, you can see the path (URL) to the picture. You can use the **Choose Picture** button to find a different picture.

[Upload to Webonary](../../../../Menus/File/Upload_to_Webonary.md) describes picture file formats that [Webonary](../../../../Menus/File/Export/Webonary.md) supports.
