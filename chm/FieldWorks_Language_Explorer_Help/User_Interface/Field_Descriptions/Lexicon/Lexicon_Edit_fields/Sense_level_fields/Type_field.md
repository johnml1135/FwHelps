# Type field (Translation)

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Type**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

[Example](example_field.md), [Translation](Translation_field.md), **Type**, [Reference](Reference_field.md) and [Publish Example In](Publish_In_(Example).md) fields are added when you [insert an example](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_an_example_in_a_sense.md) in a sense or subsense.

More specifically, each **Example** field can have one or more corresponding **Translation** fields, and each **Translation** field has a corresponding **Type** field.

**Description:** Each **Type** field holds the [name](../../../Lists/Translation_Types_fields/Name_field_Translation_Types.md) of a type from the **Translation Types** [list](../../../../../Using_Tools/Lists_tools/List_item_usage_table.md). This categorizes that translation.

**Tasks:**

- Click the down arrow and then click the desired type.

- [Insert an example in a sense](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_an_example_in_a_sense.md)

- [Insert a translation in an example](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_translation_in_example.md)

  - [Delete a translation](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Delete_a_translation.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show content from this field and associated fields when you configure [Examples](../../../../Menus/Tools/Configure_Dictionary/Examples.md).

**Field type:** [List reference field](../../../Field_Types/List_reference_field.md)

**Writing systems:** One or more [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Tip:** The [Find example sentence](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Find_example_sentence.md) feature *copies* content from the **Free** or **Lit** [interlinear lines](../../../../Menus/Tools/Configure_interlinear_lines_dialog_box.md) into the **Translation** field and copies the translation type into this field.
