# Encyclopedic Info field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Encyclopedic Info**

**Abbreviation:** **ex**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

There is an **Encyclopedic Info** field in each **[sense](Sense_level_fields_overview.md) and subsense.

**Description:**

This field stores the encyclopedic (and ethnographic) information about the current sense.

Some lexicographers do not distinguish between the definition and encyclopedic information, and include both in the definition field. In this case you would not use the **Encyclopedic Info** field. However other lexicographers prefer to separate encyclopedic information as a comment or extended discussion after the definition proper. In this case this field would be set apart, for example within square brackets in the dictionary entry.

**Tasks:**

- [Enter encyclopedic information](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_encyclopedic_information.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show data from this field when you configure **Encyclopedic Info**.
