# Caption field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Caption**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

**Caption** fields can appear in each [sense](Sense_level_fields_overview.md) and subsense. Each time you insert a picture, these fields appear: [Picture](Picture_field.md), [Thumbnail](Thumbnail_field.md), **Caption**, [File](File_field.md) and [Publish Picture In](Publish_In_(Pictures).md).

**Description:** This field stores the caption (subtitle) that you want to appear below the associated picture. You can edit it here or in the **Picture Properties** dialog box, however the **Caption** pane in the dialog box displays only the default analysis writing system.

**Tasks:**

- [Delete Picture](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Delete_a_picture.md)

- [Insert a picture](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_a_picture.md)

- [Move Picture Up or Down](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/move_picture.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show pictures (**Thumbnail**) and related data when you configure [Pictures](../../../../Menus/Tools/Configure_Dictionary/Pictures.md).

**Field type:** [Single-line text field](../../../Field_Types/Single_line_text_field.md) — allows embedded [writing systems](../../../../Menus/Format/select_a_writing_system.md) and [styles](../../../../Menus/Format/apply_a_style_to_text.md)

**Writing systems:** One or more [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Tip:**

To open the **Picture Properties** dialog box, do these steps:

1.  Click the field label.

2.  Click the menu button (![](../../../../../assets/images/Menu_Button_pic.GIF)) and then click **Picture Properties**.

In the dialog box, you can see the path (URL) to the picture. You can use the **Choose Picture** button to find a different picture.
