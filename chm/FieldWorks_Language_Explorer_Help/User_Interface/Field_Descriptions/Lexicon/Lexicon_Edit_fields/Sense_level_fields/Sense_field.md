# Sense field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Sense 1**, **Sense 1.1**, **Sense 2**, and so on

**Location:**

In the **Entry** pane (**Lexicon Edit**).

A **Sense** field appears with each **sense (**Sense 1**, **Sense 2**, **Sense 3** and so on) and *each* subsense (**Sense 1.1**, **Sense 1.2**, **Sense 2.1** and so on). Click the ![](../../../../../assets/images/minus_sign_box.GIF) (minus sign) to collapse the group of fields; click the ![](../../../../../assets/images/Plus_sign_box.GIF) (plus sign) to expand them.

**Description:** Each field acts as a header below which individual sense fields and subsense fields appear.

**Tasks:**

- Click the label to display a menu button ![](../../../../../assets/images/Menu_Button_pic.GIF) that opens a menu with commands you can use when working with senses. You can also right-click the label to open the same menu. Some of the menu commands appear as hyperlinks on the same line as the field label.
