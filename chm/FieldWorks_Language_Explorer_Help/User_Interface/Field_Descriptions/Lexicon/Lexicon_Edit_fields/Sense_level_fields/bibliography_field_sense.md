# Bibliography field Sense

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Bibliography**

**Abbreviation:** **bb**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This **Bibliography** field is in each **[sense](Sense_level_fields_overview.md) and subsense.

(There is a separate **Bibliography** field is at the [entry level](../Entry_level_fields/Entry_level_fields_overview.md).)

**Description:**

This field stores bibliographical information about the current sense or subsense.

For example, if the current sense refers to a cultural practice that is described in a published ethnography, you would use this field to give the bibliographical reference to the published work.

This field is normally included in the dictionary.

**Tasks:**

- [Enter bibliographical information](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_bibliographical_information.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show data from this field when you configure **Bibliography**.

**Field type:** [Single-line text field](../../../Field_Types/Single_line_text_field.md) — allows embedded [writing systems](../../../../Menus/Format/select_a_writing_system.md) and [styles](../../../../Menus/Format/apply_a_style_to_text.md)

**Writing systems:** One or more [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
