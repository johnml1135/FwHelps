# Scientific Name field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Scientific Name**

**Abbreviation:** **sc**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

There is a **Scientific Name** field in each **[sense](Sense_level_fields_overview.md) and subsense.

**Description:** This field stores the scientific name pertinent to the current sense.

**Tasks:**

- [Enter a scientific name](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_a_scientific_name.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show data from this field when you configure **Scientific Name**.

**Field type:** This text field neither displays writing system identifiers, nor allows paragraphs.

**Writing systems:** It defaults to the English writing system, even if English is *not* the default (top) [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) writing system. However, you can embed other analysis and vernacular [writing systems](../../../../Menus/Format/select_a_writing_system.md) and apply [styles](../../../../Menus/Format/apply_a_style_to_text.md).
