# Lexical Relations field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Lexical Relations**

**Abbreviation:** **rl**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

There is a **Lexical Relations** field in each **[sense](Sense_level_fields_overview.md) and subsense.

**Description:** This field acts as a header field below which one or more [named](../../../Lists/Lexical_Relations_fields/name_field_lexical_relations.md) sets of lexical relations are displayed.

**Discussion:**

Typically, you will want to use this *sense-level* lexical relations field.

However, there may be an occasional use for the **Cross References** field which is at the [entry-level](../Entry_level_fields/Entry_level_fields_overview.md).

**Tasks:**

- [Add reference to lexical relation](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Add_Reference_to_Lexical_Relation.md)

- [Delete a lexical relation](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Delete_a_lexical_relation.md)

- [Insert a lexical relation](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_a_lexical_relation.md)

- [Move an entry in a sequence](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/move_sequence_entry.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show lexical relation data in associated fields when you configure [Lexical Relations](../../../../Menus/Tools/Configure_Dictionary/Lexical_Relations.md).

**Field type:** Not Editable

**Writing systems:** Not Applicable

**Tip:**

- Right-click an entry in a subordinate field, and then click **Show Entry in Concordance** to [show](../../../../../Basic_Tasks/Show_data/Show_data_overview.md) the entry in [Concordance](../../../../../Using_Tools/Texts_%26_Words_tools/Concordance/Concordance_overview.md).

- Right-click an entry in a subordinate, and then click **Show Entry in Lexicon** to navigate between the associated fields.

- Typically, there is no way to reorder the lexical entries in the field. They will appear in alphabetical order in other views, such as **Dictionary**.
