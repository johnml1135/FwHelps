# Picture field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Picture**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

There can be **Picture** fields in each **[sense](Sense_level_fields_overview.md) and subsense. Each time you insert a picture, these fields appear: **Picture**, [Thumbnail](Thumbnail_field.md), [Caption](caption_field.md), [File](File_field.md) and [Publish Picture In](Publish_In_(Pictures).md).

**Description:**

This field displays a picture that is larger than the one in the **Thumbnail** field (it varies according to the size of the current window). You can insert a picture from any folder on your computer or removable media such as CD-ROMs, thumb drives (flash drives) and so on.

**See:** [File field](File_field.md) for important information.

**Tasks:**

- [Change the visibility](../../../../../Basic_Tasks/Showing_and_hiding_fields/change_the_visibility_of_fields.md) of this field.

- [Delete Picture](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Delete_a_picture.md)

- [Insert a picture](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_a_picture.md)

- [Move Picture Up or Down](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/move_picture.md)

- [Specify publishable lexical data](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Specify_publishable_lexical_data.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show pictures (**Thumbnail**) and related data when you configure [Pictures](../../../../Menus/Tools/Configure_Dictionary/Pictures.md).

**Field type:** Picture field

**Writing systems:** Not applicable

**Tip:**

To open the **Picture Properties** dialog box, do these steps:

1.  Click the field label.

2.  Click the menu button (![](../../../../../assets/images/Menu_Button_pic.GIF)) and then click **Picture Properties**.

In the dialog box, you can see the path (URL) to the picture. You can use the **Choose Picture** button to find a different picture.

[Upload to Webonary](../../../../Menus/File/Upload_to_Webonary.md) describes picture file formats that [Webonary](../../../../Menus/File/Export/Webonary.md) supports.
