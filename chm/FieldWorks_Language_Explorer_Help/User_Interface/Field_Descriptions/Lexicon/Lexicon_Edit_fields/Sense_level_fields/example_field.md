# Example field (sense)

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Example**

**Abbreviation:** **xv**

**Location:**

In the **Entry** pane (**Lexicon Edit**), at the [sense level](Sense_level_fields_overview.md).

**Example**, [Translation](Translation_field.md), [Type](Type_field.md), [Reference](Reference_field.md) and [Publish Example In](Publish_In_(Example).md) fields are added when you [insert an example](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_an_example_in_a_sense.md) in a sense or subsense.

([Extended Notes](Extended_Note/Extended_Note_field.md) have a separate [Example](Extended_Note/Example_field_(Extended_Note).md) field.)

**Description:**

Examples exemplify a use of the headword as defined in the current sense or subsense.

The [Find example sentence](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Find_example_sentence.md) feature *copies* selected sentences from interlinearized texts into this field. Any associated translations and their types (*Free* and *Literal*) are also copied to one or more **Translation** and **Type** fields.

Examples are normally included in the dictionary.

**Tasks:**

- [Insert an example in a sense](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_an_example_in_a_sense.md)

  - [Add a custom field](../../../../Menus/Tools/Custom_Fields/add_a_custom_field.md) (to **Example Sentence**)

  - [Insert a translation](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_translation_in_example.md) (to an example)

- [Delete an example](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Delete_an_example.md)

- [Delete a translation](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Delete_a_translation.md)

- [Find example sentence](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Find_example_sentence.md)

- [Move an example](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/move_example.md) (up or down, or to another entry or sense)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show content from this field and associated fields when you configure [Examples](../../../../Menus/Tools/Configure_Dictionary/Examples.md).

**Field type:** [Single-line text field](../../../Field_Types/Single_line_text_field.md) — allows embedded [writing systems](../../../../Menus/Format/select_a_writing_system.md) and [styles](../../../../Menus/Format/apply_a_style_to_text.md)

**Writing systems:** One or more [vernacular](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md), which can include an [Audio](../../../../../Basic_Tasks/Audio_files/Audio_files_overview.md) writing system so you can record the example.
