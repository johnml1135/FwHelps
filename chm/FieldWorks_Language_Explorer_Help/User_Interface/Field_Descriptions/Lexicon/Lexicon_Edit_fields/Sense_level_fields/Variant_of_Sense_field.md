# Variant of Sense field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Variant of Sense**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

There is a **Variant of Sense** fields in each [sense](Sense_level_fields_overview.md) and subsense.

**Description:**

This field references and displays one or more variant entries that point to the sense from a corresponding **Variant of** field ([entry level](../Entry_level_fields/Entry_level_fields_overview.md)).

Specifically, in a **Variant of** field of an entry that is a variant, you can [choose](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_Variant_of_entry.md) an entry or a sense of the entry. If you choose an *entry*, that variant entry appears in a **Variant Form** field ([Variants level](../Variants_level_fields/Variant_level_fields_overview.md)). If you choose a *sense*, the variant entry appears in a **Variant of Sense** field.

**Tasks:**

- [Choose Variant of](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_Variant_of_entry.md)

<!-- -->

- Right-click an entry in the field, and then click:

  - **Show Entry in Concordance** to [show](../../../../../Basic_Tasks/Show_data/Show_data_overview.md) the entry in **Concordance**.

  - **Show Entry in Lexicon** to see that entry in **Lexicon Edit**.

<!-- -->

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show associated fields when you configure [Variant of Sense](../../../../Menus/Tools/Configure_Dictionary/Variants_of_Sense.md), and so on.

**Field type:** Non-editable

**Writing systems:** Default [vernacular](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
