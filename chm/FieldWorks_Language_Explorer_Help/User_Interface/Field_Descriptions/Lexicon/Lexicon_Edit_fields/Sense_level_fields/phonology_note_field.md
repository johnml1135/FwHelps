# Phonology Note field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Phonology Note**

**Abbreviation:** **np**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

There is a **Phonology Note** field in each **[sense](Sense_level_fields_overview.md) and subsense.

**Description:**

This field provides a place for you to record notes to yourself regarding the phonology of the current sense.

For example, you can include a question such as, "When this word is used with this sense, is the fast speech variant always used?"

It is not intended to be included in the dictionary, although you can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) to include it. For example, you might want to include this field in a draft copy of the dictionary to alert yourself to the need to do further research. But you should *not* put anything in this field that you want in your final publication.
