# Sense Type field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Sense Type**

**Abbreviation:** **ts**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field appears in each **[sense](Sense_level_fields_overview.md) and subsense.

**Description:**

This field references and displays the [name](../../../Lists/Sense_Types_fields/name_field_sense_types.md) of an item from the **Sense Type** [list](../../../../../Using_Tools/Lists_tools/List_item_usage_table.md) to categorize the sense, for example, as *figurative* or *primary*.

This field is normally included in the dictionary.

**Tasks:**

- [Choose a sense type](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/choose_a_sense_type.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to include the name or abbreviation of the item when you configure **Sense Type**.

**Field type:** [List reference](../../../Field_Types/List_reference_field.md) (permits type-ahead)

**Writing systems:** Best [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
