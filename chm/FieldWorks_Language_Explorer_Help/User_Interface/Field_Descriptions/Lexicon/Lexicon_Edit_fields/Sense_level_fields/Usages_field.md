# Usages field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Usages**

**Abbreviation:** **ux**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

There is a **Usages** field in each [sense](Sense_level_fields_overview.md) and subsense.

**Description:**

This field references and displays the [name](../../../Lists/Usages_fields/Name_field_Usages.md) of one or more items from the **Usages** [list](../../../../../Using_Tools/Lists_tools/List_item_usage_table.md). It provides sociolinguistic and pragmatic factors that restrict how the lexeme is used.

For example, you can indicate pragmatic connotations such as negative overtones if it is not clear from the **Definition** field. This information is normally included in the dictionary.

The **Usages** field and the **Publish Sense In** field can be used to specify publishable lexical data. For example, if some senses are marked as *obscene* in the **Usages** field, one could filter for all senses marked as *obscene*, and then use the **Publish Sense In** field to exclude them from publication.

**Tasks:**

- [Choose usages](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_Usages.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to include the name or abbreviation of the item when you configure **Usages**.

**Field type:** [List reference field](../../../Field_Types/List_reference_field.md)

**Writing systems:** Best [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

>
