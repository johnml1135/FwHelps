# Semantic Domains field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Sense level fields*

**Full name:** **Semantic Domains**

**Abbreviation:** **sd**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

There is a **Semantic Domains** field in each **[sense](Sense_level_fields_overview.md) and subsense.

**Description:**

This field references and displays the [abbreviation](../../../Lists/Semantic_Domains_fields/abbreviation_field_semantic_domains.md) and [name](../../../Lists/Semantic_Domains_fields/name_field_semantic_domains.md) of one or more items from the [Semantic Domain list](../../../../../Using_Tools/Lists_tools/List_item_usage_table.md), which categorizes the sense semantically.

When you use [Collect Words](../../../../../Using_Tools/Lexicon_tools/Collect_Words/Collect_Words_overview.md) to create lexical entries, the semantic domain information is automatically placed in this field.

The contents of this field are normally included in an alphabetized dictionary, for example to refer the user to an appendix containing selected semantic domains. In addition, the contents are used to organize the [classified dictionary](../../../../../Using_Tools/Lexicon_tools/Classified_Dictionary/Classified_Dictionary_overview.md).

**Tasks:**

- [Choose semantic domains](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/choose_semantic_domains.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to include the name or abbreviation when you configure **Semantic Domains**.
