# Source Language (Etymology)

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Entry level fields*

**Full name:** **Source Language**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field is between the **Lexeme Form** [field](Lexeme_Form_field.md) and the **Sense 1** [field.](../Sense_level_fields/Sense_field.md) at the [entry level](Entry_level_fields_overview.md). It is part of the set of **Etymology** [fields](Etymology_fields_overview.md).

**Description:**

This field stores the [name](../../../Lists/Languages/name_field_Languages.md) of a language from the **Languages** [list](../../../../../Using_Tools/Lists_tools/List_item_usage_table.md). It indicates the language of the form in the **Source Form** field.

You can [choose](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_a_source_language.md) more than one source language. You can use the **Source Language Notes** field for information about the chosen languages.

**Tasks:**

- [Enter etymological information](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_etymological_information.md)

  - [Choose source languages](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_a_source_language.md)

- Right-click a language in this field, and then click **Show in Language List** to jump the see the language in the **Languages** [list](../../../../../Using_Tools/Lists_tools/List_item_usage_table.md).

- Right-click a language in this field, if there are more than one, and then click **Move Left** or **Move Right** to reorder them.

- Right-click the field label, or click the menu button (![](../../../../../assets/images/Menu_Button_pic.GIF)), and then point to **Writing Systems** and click [Configure](../../../../../Basic_Tasks/Showing_Writing_Systems/Show_WSs_overview.md).

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to include content from this field when you configure [Etymology](../../../../Menus/Tools/Configure_Dictionary/Etymology.md).

**Field type:** [List reference field](../../../Field_Types/List_reference_field.md)

**Writing systems:** One or more [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) writing system

**Note:** If you have data in the **Source** fields in previous versions of FieldWorks Language Explorer, those data are migrated to **Source Language** fields in the current version.
