# Note field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Entry level fields*

**Full name:** **Note**

**Abbreviation:** **nt**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field is between the **Lexeme Form** [field](Lexeme_Form_field.md) and the **Sense 1** [field](../Sense_level_fields/Sense_field.md), at the [entry level](Entry_level_fields_overview.md).

**Description:**

Use this field to store a note about the current entry.

You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) to include the note. Therefore, to help you decide what to put in this field, consider the following:

- You might want notes that are intended only for display in a *draft* copy.

These could, for example, alert you that further research is needed.

- Those who use the [Hybrid](../../../../Menus/Tools/Configure_Dictionary/About_the_Hybrid_Dictionary_view.md) layout and others might want to include notes in the *final* publication.

They can be part of the [\[References Section\]](../../../../Menus/Tools/Configure_Dictionary/References_Section_(Config._Dict.).md) collection and can help the reader of the dictionary understand the entry.

**Tasks:**

- [Enter note content at the entry level](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_note_content_at_the_entry_level.md)

**Field type:** [Single-line text field](../../../Field_Types/Single_line_text_field.md) — allows embedded [writing systems](../../../../Menus/Format/select_a_writing_system.md) and [styles](../../../../Menus/Format/apply_a_style_to_text.md)

**Writing systems:** One or more [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Additional Considerations:**

- You may want to enter any notes which may not fit into any \<name\> **Note** field at the [sense level](../Sense_level_fields/Sense_level_fields_overview.md), or in other fields, such as [Literal Meaning](Literal_Meaning_field.md), [Summary Definition](Summary_Definition_field.md), or [Comment](Comment_field.md).

- You could use this field as a "buffer" while you [import data](../../../../../Beginning_Tasks/Importing_Data/Import_overview.md), particularly when you are not sure which Language Explorer field should receive some source file content.
