# Media File field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Entry level fields*

**Full name:** **Media File**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field is between the **Lexeme Form** [field](Lexeme_Form_field.md) and the **Sense 1** [field,](../Sense_level_fields/Sense_field.md) at the [entry level](Entry_level_fields_overview.md).

This field and the **Label** field appear as part of the **Pronunciation** field set *after* you insert a link to a sound or movie file.

There is a separate **Media File** field for each sound or movie file you link to a pronunciation.

**Description:**

For [pronunciations](Pronunciation_field.md) with links to one or more sound or movie files, each **Media File** field shows the path to the associated file.

If you insert a link to a file that is *not* already in a [folder](../../../../Menus/File/Backup_and_Restore/Folder_Structure.md) that you can [back up](../../../../Menus/File/Backup_and_Restore/Back_up_this_Project.md), the **Move or Copy Files** dialog box lets you copy (recommended) or move the file to the folder, or leave it in the original location. This choice determines the path.

When you click this field, a play button ![](../../../../../assets/images/User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Play_button.PNG) appears in the field. Click the button to play the file with the appropriate media player (if installed).

**Tasks:**

- [Delete This Media Link](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/delete_a_sound_movie_file_link.md)

- [Insert a sound or movie file](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_link_to_sound_or_movie.md)

- [Play a sound or movie file](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/play_sound_or_movie.md) or [Play a movie file in Dictionary](../../../../../Using_Tools/Lexicon_tools/Dictionary/Play_a_movie_file_in_Dictionary.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to include the media data and play buttons (![](../../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/AudioVideoMedia.png) (audio) or ![](../../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/VideoMedia.png) (video)) when you configure [Pronunciations](../../../../Menus/Tools/Configure_Dictionary/Pronunciations.md).

**Note:**

- You *cannot* edit the path in this field. Instead, delete it and insert a link to a different file.

- If you delete a link, any copy of that file remains in the folder. Manually delete files that you will never use or that others should never hear or watch.

- [Audio files](../../../../../Basic_Tasks/Audio_files/Audio_files_overview.md) (\*.wav) can appear in other fields if you [add](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/Add_a_new_writing_system.md) an **Audio** writing system.

- The [Publish Pronunciation In](Publish_In_(Pronunciations).md) field for the particular pronunciation controls the publication of the associated media.

- **See Also:** [Label field](label_field.md).

**Field type:** A unique non-editable field.

**Writing systems:** English
