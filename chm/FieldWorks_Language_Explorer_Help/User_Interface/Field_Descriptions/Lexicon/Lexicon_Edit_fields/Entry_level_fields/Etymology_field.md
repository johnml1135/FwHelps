# Etymology field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Entry level fields*

**Full name:** **Etymology**

**Abbreviation:** **et**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field is between the **Lexeme Form** [field](Lexeme_Form_field.md) and the **Sense 1** [field](../Sense_level_fields/Sense_field.md), at the [entry-level](Entry_level_fields_overview.md).

**Description:**

Use this field set to store information about the etymon or proto form of the current headword.

Initially, this field has no distinguishing appearance. It becomes a *header* field (![](../../../../../assets/images/minus_sign_box.GIF) **Etymology**) after you [insert](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_Etymology.md) the set of **Etymology** [fields](Etymology_fields_overview.md).

**Tasks:**

- [Insert Etymology](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_Etymology.md)

- [Enter etymological information](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_etymological_information.md)

  - [Choose source languages](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_a_source_language.md)

- [Delete this Etymology](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Delete_this_Etymology.md)

- [Reorder Etymologies](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Reorder_Etymologies.md)

- Right-click the field label, or click the menu button (![](../../../../../assets/images/Menu_Button_pic.GIF)), point to **Field Visibility** and then click the desired [visibility](../../../../../Basic_Tasks/Showing_and_hiding_fields/change_the_visibility_of_fields.md) option.

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to include content from this field and *most* of the associated fields when you configure [Etymology](../../../../Menus/Tools/Configure_Dictionary/Etymology.md).

**Field type:** Non-editable (Header)

**Writing systems:** Not Applicable

**Note:**

- As a *header* field, you can click the ![](../../../../../assets/images/minus_sign_box.GIF) (minus sign) to collapse the field set or click the ![](../../../../../assets/images/Plus_sign_box.GIF) (plus sign) to expand it.

- If you have data in the **Etymology** fields in previous versions of FieldWorks Language Explorer, those data are migrated to **Source Form** fields in the current version.
