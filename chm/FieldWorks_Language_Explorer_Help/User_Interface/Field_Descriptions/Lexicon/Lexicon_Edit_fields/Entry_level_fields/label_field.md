# Label field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Entry level fields*

**Full name:** **Label**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field is between the **Lexeme Form** [field](Lexeme_Form_field.md) and the **Sense 1** [field](../Sense_level_fields/Sense_field.md) *after* you [insert a link](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_link_to_sound_or_movie.md) to a sound or movie file. It is at the [entry level](Entry_level_fields_overview.md).

This field and the [Media](media_file_field.md) field appear as part of the **Pronunciation** field set *after* you [insert a sound or movie file](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_link_to_sound_or_movie.md).

**Description:**

Currently, it does not appear in the printed dictionary or as part of an exported dictionary.

You can use this field to record a brief description of the associated **Media File** [field](media_file_field.md). You could, for example, enter the name of person who spoke the particular pronunciation that was recorded.
