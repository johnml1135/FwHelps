# Variant Type field (Entry-level)

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Entry level fields*

**Full name:** **Variant Type**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

One or more **Variant Type** fields appear between the **Lexeme Form** [field](Lexeme_Form_field.md) and the **Sense 1** [field,](../Sense_level_fields/Sense_field.md) at the [entry level](Entry_level_fields_overview.md).

For *variant* entries (that is, you already [chose](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_Variant_of_entry.md) an entry in a **Variant of** field or clicked **Lexeme Form is a variant** on the [Information bar](../../../../Toolbars/information_bar_overview.md) menu button.)

Each **Variant Types** field appears with these fields: [Variant of](Variant_of_field.md), [Show Minor Entry](../Publication_Settings_flds/Show_Minor_Entry_Pub_Set_level.md) and [Comment](Comment_field.md). The field menu button ![](../../../../../assets/images/User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Menu_Button_pic.GIF) commands refer to this set as **Variant Info**.

**Note:** In the entries that *have* variants, associated **Variant Type** fields appear at the [variants level](../Variants_level_fields/Variant_level_fields_overview.md).

**Description:**

This field reference and display one or more items from the **Variant Types** list, which can include **Unspecified Variant**.

[About Variants](../../../../../Using_Tools/Lists_tools/About_Variants.md) and [About entry types](../../../../../Using_Tools/Lists_tools/About_Entry_Types.md) describe variants.

**Tasks:**

- [Choose Variant Types](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_variant_types.md)

- [Add another Variant Info section](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Add_another_Variant_Info_section.md)

  - [Move Variant Info Up or Down](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Move_Variant_Info_Up_Down.md)

- [Delete Variant Info](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Delete_Variant_Info.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show variant types under [Variant Forms](../../../../Menus/Tools/Configure_Dictionary/Variant_Forms.md).

- Right-click a variant type in this field, and then click one of these commands:

  - **Show in Variant Types** list to [show](../../../../../Basic_Tasks/Show_data/Show_data_overview.md) the item in that list.

  - **Move Left** or **Move Right** (The order here can set the order in **Dictionary**.)

- If you do not [choose](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_Variant_of_entry.md) an entry or sense for the **Variant of** field, then the **Variant Type** and **Variant of** field set are deleted when you leave the entry.

**Field type:** Non-editable

**Writing systems:** Best [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
