# Comment field (entry level)

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Entry level fields*

↵

## Comment field

**Full name:** **Comment**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field is between the **Lexeme Form** [field](Lexeme_Form_field.md) and the **Sense 1** [field](../Sense_level_fields/Sense_field.md), at the [entry-level](Entry_level_fields_overview.md).

- Variants:\
  In an entry that *is* a variant, a **Comment** field appears with each [Variant Type](Variant_Type_field.md) field set.\
  **See Also:** **Comment** [field](../Variants_level_fields/Comment_field_Variants.md) ([Variants level](../Variants_level_fields/Variant_level_fields_overview.md)).

- Complex forms:\
  A **Comment** field appears with each **Complex Form Type** [field](Complex_Form_Type_field.md) set.

**Description:** This field allows you to [enter](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_a_comment.md) a comment about a particular complex form or variant form.

**Tasks:**

- [Add another Variant Info section](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Add_another_Variant_Info_section.md)

- [Delete Complex Form Info](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/change_the_entry_type.md)

- [Enter a comment](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_a_comment.md)

- [Specify that a form is complex](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Specify_that_Form_is_Complex.md)

- [Specify that a form is a variant](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Specify_that_a_form_is_a_variant.md)

- In the **Configure Dictionary** [dialog box](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md), you configure this comment under [Component References](../../../../Menus/Tools/Configure_Dictionary/Component_References.md), [Variant Forms](../../../../Menus/Tools/Configure_Dictionary/Variant_Forms.md) and so on.

**Field type:** [Single-line text field](../../../Field_Types/Single_line_text_field.md) — allows embedded [writing systems](../../../../Menus/Format/select_a_writing_system.md) and [styles](../../../../Menus/Format/apply_a_style_to_text.md)

**Writing systems:** One or more [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Tip:** When you create a complex entry, you typically select a [complex form type](../../../../../Using_Tools/Lists_tools/About_complex_forms.md) in the [New Entry](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Create_a_lexical_entry.md) dialog box. Then the appropriate fields are added to the **Entry** pane. Otherwise, these fields appear after you click the **Lexeme Form as components** command on the [Information bar](../../../../Toolbars/information_bar_overview.md) menu button.
