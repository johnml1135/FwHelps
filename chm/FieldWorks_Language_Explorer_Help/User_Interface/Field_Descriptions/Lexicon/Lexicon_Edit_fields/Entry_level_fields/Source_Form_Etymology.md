# Source Form (Etymology)

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Entry level fields*

**Full name:** **Source Form**

**Abbreviation:** **so**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field is between the **Lexeme Form** [field](Lexeme_Form_field.md) and the **Sense 1** [field](../Sense_level_fields/Sense_field.md), at the [entry level](Entry_level_fields_overview.md).

It is part of the set of **Etymology** [fields](Etymology_fields_overview.md).

**Description:**

This field stores the etymon or proto form. It is the form, borrowed or inherited, from which the headword ([lexeme](Lexeme_Form_field.md) or [citation](Citation_Form_field.md) form) was derived. It may have Greek or Romanized forms.

If necessary, [add](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) a writing system to use in this field.

**Tasks:**

- [Enter etymological information](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_etymological_information.md)

- Record [Audio Files](../../../../../Basic_Tasks/Audio_files/Audio_files_overview.md)

- Right-click the field label, or click the menu button (![](../../../../../assets/images/Menu_Button_pic.GIF)), and then point to **Writing Systems** and click [Configure](../../../../../Basic_Tasks/Showing_Writing_Systems/Show_WSs_overview.md).

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to include content from this field when you configure [Etymology](../../../../Menus/Tools/Configure_Dictionary/Etymology.md).

**Field type:** [Single-line text field](../../../Field_Types/Single_line_text_field.md) – you can embed characters in other writing systems or embed styles

**Writing systems:** One or more [vernacular](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) and analysis writing systems

**Tip:** Each sense has a **Source** field so you can [enter](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_source_information.md) source information related to the sense.
