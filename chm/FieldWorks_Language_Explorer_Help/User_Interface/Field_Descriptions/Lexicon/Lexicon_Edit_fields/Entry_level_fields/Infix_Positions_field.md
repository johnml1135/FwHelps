# Infix Positions field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Entry level fields*

**Full name:** **Infix Positions**

**Abbreviation:** **in**

**Location:**

This field is between the **Lexeme Form** [field](Lexeme_Form_field.md) and the **Sense 1** [field](../Sense_level_fields/Sense_field.md), at the [entry-level](Entry_level_fields_overview.md).

For an infix entry ([Morph Type](Morph_Type_Field.md) field contains **infix**), this **Infix Positions** field is at the [entry-level](Entry_level_fields_overview.md).

(A separate **Infix Positions** field is at the [allomorphs level](../Alternate_Forms_level_flds/Alt_Forms_lev_flds_ov.md) for each allomorph that uses infix positions ([Morph Type](../Alternate_Forms_level_flds/Morph_type_fld_allomorph.md) field contains **infix**).)

**Description:**

These fields reference and display [environments](../../../../../Using_Tools/Grammar_tools/Environments/Environments_overview.md) which identify the phonological constraint for the infix.

[Parsers](../../../../Menus/Parser/Parsing_words_overview.md) use **Infix Positions** field contents.

**Tasks:**

- [Choose infix positions](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_infix_positions.md)

**Field type:** [List reference field](../../../Field_Types/List_reference_field.md) — allows embedded [writing systems](../../../../Menus/Format/select_a_writing_system.md) and [styles](../../../../Menus/Format/apply_a_style_to_text.md)

**Writing systems:** One or more [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) or vernacular

**Note:**

[Environments field](Environments_field.md) has additional information.

For more information, on the [Help](../../../../Menus/Help/Help_overview.md) menu point to **Resources**, and then click **Introduction to Parsing**. Section **3.3 Infixation** provides additional explanation and examples
