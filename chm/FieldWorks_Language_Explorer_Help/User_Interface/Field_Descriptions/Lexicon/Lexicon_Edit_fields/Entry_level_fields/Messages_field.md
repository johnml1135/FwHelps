# Messages field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Entry level fields*

**Full name:** **Messages**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field is between the **Lexeme Form** [field](Lexeme_Form_field.md) and the **Sense 1** [field](../Sense_level_fields/Sense_field.md), at the [entry level](Entry_level_fields_overview.md).

**Description:**

This field displays buttons that you and your collaborators use to discuss the *current* entry or a Send/Receive merge conflict or notification related to the *current* entry.

Hover your mouse pointer over each button displayed in the field to see a pop-up window. It displays the particular question, conflict or notification.

Click the appropriate button:

- ![](../../../../../assets/images/User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Question_ADD.png) opens the **Question about** dialog box so you can [add a new question](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Add_and_resolve_questions.md).

The current headword (lexeme or citation form) is shown near the top of the dialog box.

- ![](../../../../../assets/images/User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Question_Has.png) / ![](../../../../../assets/images/User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/ResolvedQuestion.jpg) indicate one question / *resolved* question.

These open the **Question about** dialog box.

- ![](../../../../../assets/images/User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/ConflictIcon.png) / ![](../../../../../assets/images/User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/ResolovedConflictIcon.png) indicate one merge conflict / *resolved* conflict.

These open the **Merge Conflict** dialog box.

Example conflict: someone edited what someone else had deleted (item not deleted.)

- ![](../../../../../assets/images/User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/NotificationIcon.png) / ![](../../../../../assets/images/User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/resolvedNotification.png) indicate one merge notification / *resolved* notification.

These open the **Merge Report** dialog box.

Example notification: two people added something in the same place (both additions kept).\

Select ![](../../../../../assets/images/User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Resolved.gif) **Resolved** or clear ![](../../../../../assets/images/User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/UNresolved.gif) **Resolved** in the dialog boxes as applicable.

These questions, notifications, and conflicts *also* appear in the **Messages** dialog box. Open it with the **Send/Receive** menu.

**Tasks:**

- [Add and resolve questions](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Add_and_resolve_questions.md)

- [Resolve conflicts and notifications](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Resolve_conflicts_and_notifications.md)

- [Send/Receive menu](../../../../Menus/Send_Receive/Send_Receive_menu.md)

- [Send/Receive overview](../../../../../Basic_Tasks/Collaborating_with_Others/Send_Receive_overview.md)

**Field type:** This is a unique field that displays only the buttons discussed above.

**Writing systems:**

Currently, you *cannot* control the writing system used in the dialog boxes opened by these buttons.

But, you can manually choose a keyboard and type any characters that the default font supports, such as IPA characters.

> [!IMPORTANT]
>
> - These questions and messages are metadata, and are *not* available for inclusion in the **Dictionary** view. You cannot display a **Messages** **column in the **Entries** pane of **Lexicon Edit**, nor in **Bulk Edit Entries**.
>
> - *Context-sensitive* right-click menus are available in the dialog boxes.
>
> - - **Print Preview**, **Print**, **Export**, **Send to** and more commands are listed, depending whether you have used **Select All** or not.
