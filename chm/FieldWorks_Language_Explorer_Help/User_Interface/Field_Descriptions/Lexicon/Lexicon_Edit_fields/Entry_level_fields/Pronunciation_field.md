# Pronunciation field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Entry level fields*

**Full name:** **Pronunciation**

**Abbreviation:** **ph**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field is between the **Lexeme Form** [field](Lexeme_Form_field.md) and the **Sense 1** [field](../Sense_level_fields/Sense_field.md), at the [entry level](Entry_level_fields_overview.md).

Each time you insert a pronunciation, these fields appear: **Pronunciation**, [CV Pattern](cv_pattern_field.md), [Tone](Tone_field.md), [Location](Location_field.md) and [Publish Pronunciation In](Publish_In_(Pronunciations).md).

**Description:** This field stores the pronunciation of the current headword ([lexeme form](Lexeme_Form_field.md) or [citation form](Citation_Form_field.md)).

**Tasks:**

- [Enter a pronunciation](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_a_Pronunciation.md)

- [Delete a pronunciation](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/delete_a_pronunciation.md)

- [Insert a pronunciation](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_a_pronunciation.md)

- [Insert a sound or movie file](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_link_to_sound_or_movie.md)

- [Move a pronunciation](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Move_Pronunciation.md) (to a different entry)

- **Move Pronunciation Up** or **Down** (to [reorder pronunciations](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/reorder_pronunciations.md))

- [Select pronunciation writing systems](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/select_pronunciation_writing_systems.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to include the pronunciations and related data when you configure [Pronunciations](../../../../Menus/Tools/Configure_Dictionary/Pronunciations.md).

**Field type:** It is a unique [single-line text field](../../../Field_Types/Single_line_text_field.md).

**Writing systems:**

- Typically, you would indicate the pronunciation using a phonetic or IPA writing system. However, you can also use a phonemic writing system or even the orthographic writing system.

- You can select which writing systems are displayed in this field, but not their order. That is, this field is *not* affected by the order in the **Writing System Properties** dialog box.

- To be available for selection, a writing system must be listed in the **Writing Systems** pane in the **Vernacular Writing System Properties** dialog box. But, they do not need to be selected (![](../../../../../assets/images/CheckedBox.PNG)).

- You *cannot* embed characters using a different writing system or apply styles. If you [paste](../../../../Menus/Edit/Cut_copy_and_paste.md) in a pronunciation, any styles are automatically removed.

> [!NOTE]
>
> - You can [edit](../../../../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Writing_System_Properties_General_tab.md) the displayed abbreviations of writing systems in the **Abbreviation** box.
>
> - If you insert a sound or movie file, [Media File](media_file_field.md) and [Label](label_field.md) fields are added to the **Pronunciation** field set.
