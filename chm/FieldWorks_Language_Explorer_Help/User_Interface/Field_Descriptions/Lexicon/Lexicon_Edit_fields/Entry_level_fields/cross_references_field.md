# Cross References field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Entry level fields*

**Full name:** **Cross References**

**Abbreviation:** **c****f**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field is between the **Lexeme Form** [field](Lexeme_Form_field.md) and the **Sense 1** [field](../Sense_level_fields/Sense_field.md), at the [entry-level](Entry_level_fields_overview.md).

**Description:** This field acts as a heading field below which one or more [named](../../../Lists/Lexical_Relations_fields/name_field_lexical_relations.md) sets of cross reference lexical relations are displayed.

**Discussion:**

Typically, you will want to use the sense-level **Lexical Relations** [field](../Sense_level_fields/lexical_relations_field.md).

However, there may be an occasional use for this entry-level **Cross References** field.

For a discussion about lexical relations, point to **Resources** on the [Help](../../../../Menus/Help/Help_overview.md) menu, and then click **Introduction to Lexicography**.

**Tasks:**

- [Add a lexical relation](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Add_Reference_to_CR_lexical_relation.md)

- [Insert a cross reference lexical relation](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_a_CR_lexical_relation.md)

- [Delete a lexical relation](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Delete_a_lexical_relation.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show cross reference information when you configure [Cross References](../../../../Menus/Tools/Configure_Dictionary/Cross_References.md).

**Field type:** Not Editable

**Writing systems:** Not Applicable

**Tip:**

- Right-click an entry in a subordinate field, and then click **Show Entry in Concordance** to [show](../../../../../Basic_Tasks/Show_data/Show_data_overview.md) the entry in the [Concordance](../../../../../Using_Tools/Texts_%26_Words_tools/Concordance/Concordance_overview.md).

- Right-click an entry in a subordinate, and then click **Show Entry in Lexicon** to navigate between the associated fields.

- This field has, incidentally, the same [abbreviation](../../../Lists/Lexical_Relations_fields/abbreviation_field_lexical_relations.md) as the default abbreviation used for the **Compare** lexical relation. This implies no special relationship between the two.
