# Complex Form Type field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Entry level fields*

**Full name:** **Complex Form Type**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field is between the **Lexeme Form** [field](Lexeme_Form_field.md) and the **Sense 1** [field](../Sense_level_fields/Sense_field.md), at the [entry-level](Entry_level_fields_overview.md). You only see it in entries that have components.

There are two ways to make it and its associated fields ([Components](Components_field.md) and [Comment](Comment_field.md), and also [Show Subentry under](../Publication_Settings_flds/Show_Subentry_under.md) and [Show Minor Entry](../Publication_Settings_flds/Show_Minor_Entry_Pub_Set_level.md)) appear:

- When you [create](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Create_a_lexical_entry.md) a complex entry, select a complex form type in the **New Entry** dialog box.

- In an existing entry, use the **Lexeme Form has components** command on the [Information bar](../../../../Toolbars/information_bar_overview.md) (![](../../../../../assets/images/Information_bar_Menu_button.PNG)).

**Description:**

This field reference and display one or more items from the **Complex Form Types** list, which can include **Unspecified Complex Form**.

[About Complex Forms](../../../../../Using_Tools/Lists_tools/About_complex_forms.md), and [About "entry types"](../../../../../Using_Tools/Lists_tools/About_Entry_Types.md) describe complex forms.

- [Specify that a form is complex](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Specify_that_Form_is_Complex.md)

- Right-click an entry in the field, and then click any of the following:

  - **Show in Complex Form Types list**

  - **Move Left** or **Move Right** to reorder the types in the field.

- In the **Configure Dictionary** [dialog box](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md), you configure complex form types under various nodes. See [Complex Forms](../../../../Menus/Tools/Configure_Dictionary/Complex_Forms.md).
