# Restrictions field (lex entries)

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Entry level fields*

**Full name:** **Restrictions**

**Abbreviation:** **ox**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field is between the **Lexeme Form** [field](Lexeme_Form_field.md) and the **Sense 1** [field](../Sense_level_fields/Sense_field.md), at the [entry level](Entry_level_fields_overview.md).

(A separate **Restrictions** field is at the [sense level](../Sense_level_fields/Sense_level_fields_overview.md) for each sense and subsense.)

**Description:**

This field stores a prose semantic or grammatical restriction pertinent to the use of this headword.

For example, you can enter **human**, **female**, **only said of the opposite sex** and so on.

**Tasks:**

- [Enter restrictions](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_restrictions.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show data from this field when you configure **Restrictions**.

**Field type:** [Single-line text field](../../../Field_Types/Single_line_text_field.md) — allows embedded [writing systems](../../../../Menus/Format/select_a_writing_system.md) and [styles](../../../../Menus/Format/apply_a_style_to_text.md)

**Writing systems:** One or more [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
