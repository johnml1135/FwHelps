# Variant of field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Entry level fields*

**Full name:** **Variant of**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

One or more **Variant of** fields can appear between the **Lexeme Form** [field](Lexeme_Form_field.md) and the **Sense 1** [field,](../Sense_level_fields/Sense_field.md) at the [entry level](Entry_level_fields_overview.md).[](../Sense_level_fields/Sense_field.md)

(**Variant of Sense** fields appear in [senses](../Sense_level_fields/Sense_level_fields_overview.md) and subsenses.)

**Description:**

Each **Variant of** field can reference and display one or more entries or senses of which the current entry is a variant. This reference can include [dialect labels](../Variants_level_fields/Dialect_Labels_(Entry)_variant.md).

- You specify that the current form *is a variant* when you [choose](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_Variant_of_entry.md) an entry or sense in a **Variant of** field. You can also use **Lexeme Form is a variant** on the [Information bar](../../../../Toolbars/information_bar_overview.md) menu button. Then, the [Variant Type](Variant_Type_field.md) and [Comment](Comment_field.md) fields appear.\
  The homograph number will appear, if the selected entry has one. The sense number also appears, if a particular sense was selected.

- If you [insert a variant form](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_a_variant_form.md) in an entry, a variant entry is added. In that variant entry, the **Variant of** field references and displays the entry in which you inserted the variant form.

- Right-click the content in the field, and then click any of the following:

  - **Show Entry in Lexicon**

  - **Show Entry in Concordance** to [show](../../../../../Basic_Tasks/Show_data/Show_data_overview.md) the entry in the [Concordance](../../../../../Using_Tools/Texts_%26_Words_tools/Concordance/Concordance_overview.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show associated fields when you configure [Variant Of](../../../../Menus/Tools/Configure_Dictionary/Variant_of.md), and so on.

**Note:**

- FLEx *deletes* the associated **Variant Type** and **Variant of** fields when you leave the entry if you do not choose an entry or sense for the **Variant of** field. This prevents partially-defined entries.

- If you [swap the lexeme form with an allomorph](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Swap_LexForm_with_Allomorph.md), the content in this field changes.

**Field type:** [List reference](../../../Field_Types/List_reference_field.md) (Initially this field appears alone. But after use, it appears in a set of associated fields as described above.)
