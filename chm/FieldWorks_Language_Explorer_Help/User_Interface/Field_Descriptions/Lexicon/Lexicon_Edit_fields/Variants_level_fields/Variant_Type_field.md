# Variant Type field (Variants)

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Variant level fields*

**Full name:** **Variant Type**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

In an entry that *has* a variant, this field is at the [Variants level](Variant_level_fields_overview.md).

**Note:** In variant entries, one or more **Variant Type** fields are at the [entry level](../Entry_level_fields/Entry_level_fields_overview.md).

**Description:** This **Variant type** field references and displays one or more items from the **Variant Types** list.

**Tasks:**

- [Choose Variant Types](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_variant_types.md)

- Right-click the content in the field, and then click one of these commands:

  - **Show in Variant Types list**

  - **Move Left** or **Move Right** (The order here can set the order in **Dictionary**.)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to include the variants when you configure [Variant Forms](../../../../Menus/Tools/Configure_Dictionary/Variant_Forms.md).

**Field type:** [List reference](../../../Field_Types/List_reference_field.md)

**Writing systems:** one or more [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Tip:** **Dialect Labels** can be used to help distinguish the variant.\
**See:** [Dialect Labels (entry)](Dialect_Labels_(Entry)_variant.md).
