# Show Minor Entry (Variants level)

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Variant level fields*

**Full name:** **Show Minor Entry**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

In an entry that *has* a variant, this field is at the [Variants level](Variant_level_fields_overview.md).

(The **Show Minor Entry** field at the [Publication Settings level](../Publication_Settings_flds/Publ_Set_level_fields_overview.md) in the *variant entry* functions as another instance of this **Show Minor Entry** field. So, if you select or clear either of the check boxes, *both* are selected or cleared.)

**Description:**

- Select (![](../../../../../assets/images/CheckedBox.PNG)) the check box to make the particular variant form available for display as a [minor entry](../../../../Menus/Tools/Configure_Dictionary/Main_Minor_entry.md) in [Dictionary](../../../../../Using_Tools/Lexicon_tools/Dictionary/Dictionary_overview.md).

- Clear (![](../../../../../assets/images/UncheckedBox.PNG)) the check box to make the particular variant form unavailable for display.

**Tasks:**

- [Insert a variant form](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_a_variant_form.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to include the variants and associated fields when you configure [Minor Entries](../../../../Menus/Tools/Configure_Dictionary/Main_Minor_entry.md).

**Field type:** Check box

**Writing systems:** Not Applicable
