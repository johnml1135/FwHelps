# Comment field (Variants level)

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Variant level fields*

**Full name:** **Comment**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

In an entry that *has* a variant, this field is at the [Variants level](Variant_level_fields_overview.md).

**Description:** When you [insert the variant form](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_a_variant_form.md), you can enter a comment about the variant in this **Comment** field.

**Tasks:**

- [Enter a comment](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Enter_a_comment.md)

- In the [Configure Dictionary View](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) dialog box, you configure this comment under [Variant Of](../../../../Menus/Tools/Configure_Dictionary/Variant_of.md), [Variant Forms](../../../../Menus/Tools/Configure_Dictionary/Variant_Forms.md), and so on.

**Field type:** [Single-line text field](../../../Field_Types/Single_line_text_field.md) — allows embedded [writing systems](../../../../Menus/Format/select_a_writing_system.md) and [styles](../../../../Menus/Format/apply_a_style_to_text.md)

**Writing systems:** One or more [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Tip:**

In the **Variant Form** field, right-click the variant form, and then select **Show Entry in Lexicon**. Notice that the [Comment](../Entry_level_fields/Comment_field.md) field in that variant entry contains the *same content* as this field.

Specifically, these two **Comment** fields are really two views to the same data.
