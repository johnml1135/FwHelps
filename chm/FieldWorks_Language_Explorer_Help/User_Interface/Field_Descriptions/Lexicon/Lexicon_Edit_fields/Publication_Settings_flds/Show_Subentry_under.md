# Show Subentry under

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Publication Settings level fields*

**Full name:** **Show Subentry under**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field is at the [Publication Settings level](Publ_Set_level_fields_overview.md).

**Description:**

This field is used for [root-based](../../../../Menus/Tools/Configure_Dictionary/Dictionary_views.md) and [hybrid](../../../../Menus/Tools/Configure_Dictionary/About_the_Hybrid_Dictionary_view.md) dictionary layouts.

In complex form entries (entries that have components), this field references and displays the component entries below which you want the complex forms to appear as indented subentries.

Entries previously selected as [components](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_components_for_Components_field.md) are available for selection in this field. If you delete a component from the **Components** field, it is also deleted from this field.

(In the component entry, the [Complex Form](../Entry_level_fields/Complex_Forms_entry.md) field shows the complex form.)

**Note:** In a variant entry, it may be possible to select a complex form entry in this field. However, variant entries currently *cannot* display subentries in **Dictionary**.

**Tasks:**

- [Choose components for Show Subentry under field](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_components_for_Show_Subentry_Under.md)

- Right-click an entry in the field, and then click any of the following:

  - **Show Entry in Lexicon**

  - **Show Entry in Concordance**

  - **Move Left** or **Move Right** to manually reorder the entries.

- For the [hybrid](../../../../Menus/Tools/Configure_Dictionary/About_the_Hybrid_Dictionary_view.md) layout, see also: [\[References section\]](../../../../Menus/Tools/Configure_Dictionary/References_Section_(Config._Dict.).md) and [Minor Subentries](../../../../Menus/Tools/Configure_Dictionary/Minor_Subentries_(Hybrid_view).md).

**Field type:** [List reference](../../../Field_Types/List_reference_field.md)

**Writing systems:** One or more [vernacular](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Important:** When the components listed in this [Show Subentry under](Show_Subentry_under.md) field and in the [Components](../Entry_level_fields/Components_field.md) field are an exact match (components *and* order), then the "see under" references is not displayed in **Dictionary** for the current entry. You can use **Move Left** or **Move Right** to experiment with this feature.

**Tip:**

- When you create a complex entry, you typically select a [complex form type](../../../../../Using_Tools/Lists_tools/About_complex_forms.md) in the [New Entry](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Create_a_lexical_entry.md) dialog box. Then the appropriate fields are added to the **Entry** pane. Otherwise, these fields appear after you click the **Lexeme Form as components** command on the [Information bar](../../../../Toolbars/information_bar_overview.md) menu button.

- To display the complex form as a [minor entry](../../../../Menus/Tools/Configure_Dictionary/Main_Minor_entry.md), `see:` [Show Minor Entry field](Show_Minor_Entry_Pub_Set_level.md).

- For [lexeme-based](../../../../Menus/Tools/Configure_Dictionary/Dictionary_views.md) dictionary layouts, **see:** [Referenced Complex Forms field (entry)](Referenced_Complex_Forms_Publication_Settings.md) or [Referenced Complex Forms field (sense)](../Sense_level_fields/Referenced_Complex_Forms_(sense).md).
