# Show Minor Entry (Publication Settings level)

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Publication Settings level fields*

**Full name:** **Show Minor Entry**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

At the [Publication Settings level](Publ_Set_level_fields_overview.md), a **Show Minor Entry** field appears for [complex form](../../../../../Using_Tools/Lists_tools/About_complex_forms.md) entries and [variant](../../../../../Using_Tools/Lists_tools/About_Variants.md) entries.

**Note**:

- For an entry that is *both* a complex form and a variant, there remains only *one* **Show Minor Entry** field below the **Publication Settings** field.

- For an entry that *is a* variant, this **Show Minor Entry** field functions as another instance of the **Show Minor Entry** field which is at the [Variants level](../Variants_level_fields/Variant_level_fields_overview.md) in the *main* (parent) entry. So, if you select either of them, both are selected.

**Description:**

For *root*-based [layouts](../../../../Menus/Tools/Configure_Dictionary/Dictionary_views.md):

- Select (![](../../../../../assets/images/CheckedBox.PNG)) the check box to make the current complex form *or* variant entry available for display as a [minor entry](../../../../Menus/Tools/Configure_Dictionary/Main_Minor_entry.md) in [Dictionary](../../../../../Using_Tools/Lexicon_tools/Dictionary/Dictionary_overview.md).

- Clear (![](../../../../../assets/images/UncheckedBox.PNG)) the check box to make the current complex form *or* variant entry unavailable for display.

For *lexeme*-based or hybrid **Dictionary** layouts:

- Select (![](../../../../../assets/images/CheckedBox.PNG)) the check box to make the current variant entry available for display as a [minor entry](../../../../Menus/Tools/Configure_Dictionary/Main_Minor_entry.md) in [Dictionary](../../../../../Using_Tools/Lexicon_tools/Dictionary/Dictionary_overview.md).

- Clear (![](../../../../../assets/images/UncheckedBox.PNG)) the check box to make the current variant entry unavailable for display.

For lexeme-based or hybrid [layouts](../../../../Menus/Tools/Configure_Dictionary/Dictionary_views.md), this check box does *not* affect the display of a complex form in **Dictionary**, *unless that complex form is also a variant*.

**Tasks:**

- [Specify that a form is a variant](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Specify_that_a_form_is_a_variant.md)

- [Specify that a form is complex](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Specify_that_Form_is_Complex.md)

- You need to [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to include available [minor entries](../../../../Menus/Tools/Configure_Dictionary/Main_Minor_entry.md).

**Field type:** Check box

**Writing systems:** Not applicable
