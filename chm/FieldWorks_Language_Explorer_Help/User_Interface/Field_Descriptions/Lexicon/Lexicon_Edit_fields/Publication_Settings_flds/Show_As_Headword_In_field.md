# Show As Headword In field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Publication Settings level fields*

**Full name:** **Show As Headword In**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field is at the [Publication Settings level](Publ_Set_level_fields_overview.md).

**Description:**

This field stores the [publications](../../../Lists/Publications/What_is_a_Publication.md) in which you want the current entry to appear as a headword.

If a particular publication is *not* displayed in this field, then in *that* publication, this entry is *excluded as a headword* in **Dictionary** *and* in **Classified Dictionary**, but can appear as a *referenced entry.*

**See Also:** [Publish Entry In](Publish_In_(Publication_Settings).md).

**Tasks:**

- [Choose Show As Headword In publications](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_Show_as_Headwords_In.md)

- Right-click a publication in the field, and then click **Show in Publications list**.

**Field type:** [List reference](../../../Field_Types/List_reference_field.md)

**Writing systems:** One or more [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Note:** All publications are initially added to all fields that can reference and display publications.
