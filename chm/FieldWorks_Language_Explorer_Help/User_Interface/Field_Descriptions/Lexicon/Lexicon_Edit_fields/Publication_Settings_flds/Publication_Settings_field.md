# Publication Settings field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Publication Settings level fields*

**Full name:** **Publication Settings**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field is at the top of the [Publication Settings level](Publ_Set_level_fields_overview.md).

**Description:**

This field acts as a header below which fields relating to publication of lexical data are stored.

In some cases, fields with the same names as those that appear below this heading field also appear in each sense and each example. You use these fields to [specify publishable lexical data](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Specify_publishable_lexical_data.md).

**Tasks:**

- Click the ![](../../../../../assets/images/minus_sign_box.GIF) (minus sign) to collapse the group of fields; click the ![](../../../../../assets/images/Plus_sign_box.GIF) (plus sign) to expand them.

**Field type:** Not Editable (Header)

**Writing systems:** Not Applicable
