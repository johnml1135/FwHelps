# Exception \"Features\" field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Grammatical Info Details fields*

**Full name:** **Exception "Features"**

**Abbreviation:** **ef**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

For entries that are *not* affixes, this field is at the [Grammatical Info Details level](Gram_Info_Detls_fields_ovw.md).

**See also:** [From Exception "Features" field](from_exception_features_field.md) and [To Exception "Features" field](To_Exception_Features_field.md).

- There are separate [Exception "Features" fields](../../../Grammar/Compound_Rules_fields/Exception_Features_field_Comp_Rules.md) used with Compound Rules in **Compound Rules** (**Grammar**).

**Description:**

This field references and displays the [names](../../../Grammar/Exception_Features_fields/name_field_exception_features.md) of one or more items from the **Exception "Features"** list ([Grammar](../../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

[Parsers](../../../../Menus/Parser/Parsing_words_overview.md) use exception "features".

**Tasks:**

- [Choose exception "features"](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/choose_exception_features.md)

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to include the abbreviation of the selected exception "features" when you configure **Exception "Features"** under [Grammatical Info](../../../../Menus/Tools/Configure_Dictionary/Grammatical_Info.md).

**Field type:** [List reference field](../../../Field_Types/List_reference_field.md)

**Writing systems:** Best [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Tip:** For more information, on the [Help](../../../../Menus/Help/Help_overview.md) menu point to **Resources**, and then click **Introduction to Parsing**.
