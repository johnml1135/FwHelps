# Gram Info Details fields overview

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Grammatical Info Details fields*

In the **Entry** pane (**Lexicon Edit**), these fields are below the **Grammatical Info Details** field:

|                                                                  |
|------------------------------------------------------------------|
| Field name                                                       |
| [Grammatical Info Details](grammatical_info_details_field.md)    |
| [Attaches to Category](attaches_to_categories_field.md)          |
| [Category Info](Category_Info_field.md)                          |
| [Inflection Class](Inflection_Class_field_Lex_Edit.md)           |
| [Inflection Features](Inflection_Features_field.md)              |
| [Exception "Features"](exception_features_field.md)              |
| [Slots](Slots_field.md)                                          |
| [From Stem Allomorph Labels](From_Stem_Allomorph_Label_field.md) |
| [From Inflection Class](from_inflection_class_field.md)          |
| [From Inflection Features](from_inflection_features_field.md)    |
| [From Exception "Features"](from_exception_features_field.md)    |
| [To Inflection Class](To_Inflection_Class_field.md)              |
| [To Inflection Features](To_Inflection_Features_field.md)        |
| [To Exception "Features"](To_Exception_Features_field.md)        |

> [!TIP]
>
> - Which of these fields appear in an entry depends on the entry. In some cases, some of these fields appear as many times as there are senses with *unique* grammatical information.
>
> - For more information, on the [Help](../../../../Menus/Help/Help_overview.md) menu point to **Resources**, and then click **Introduction to Parsing**.
