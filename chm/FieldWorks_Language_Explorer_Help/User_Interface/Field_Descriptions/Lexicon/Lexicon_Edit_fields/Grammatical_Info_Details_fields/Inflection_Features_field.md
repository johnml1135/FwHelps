# Inflection Features field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Grammatical Info Details fields*

**Full name:** **Inflection Features**

**Abbreviation:** **if**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

For entries that are *not* affixes or are *inflectional* affixes, this field is at the [Grammatical Info Details level](Gram_Info_Detls_fields_ovw.md).

**Description:**

This field references and displays one or more items from the [Inflectable Features](../../../Grammar/Category_Edit_fields/Inflectable_Features_field_Category_Edit.md) field for the particular category in **Category Edit** ([Grammar](../../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

Typically, you see the **\[[feature name](../../../Grammar/Inflection_Features_fields/name_field_feature_features.md);** **[value name](../../../Grammar/Inflection_Features_fields/name_field_value_features.md)** or [**abbreviation**](../../../Grammar/Inflection_Features_fields/Abbr_field_value_features.md)**\]** or similar in this field.

[Parsers](../../../../Menus/Parser/Parsing_words_overview.md) use inflection features.

**Tasks:**

- [Choose inflection features](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/choose_inflection_features.md).

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to include the abbreviation of the selected inflection features when you configure **Features** under [Grammatical Info](../../../../Menus/Tools/Configure_Dictionary/Grammatical_Info.md).

**Field type:** [List reference field](../../../Field_Types/List_reference_field.md)

**Writing systems:** Best [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Note:**

- For inflectional affixes, **see**: [Required Features field](../Entry_level_fields/required_features_lex.md) (entry level) and [Required Features field](../Alternate_Forms_level_flds/required_features.md) (Allomorphs level).

- For entries that are *derivational* affixes, **see:** [From Inflection Features field](from_inflection_features_field.md) and [To Inflection Features field](To_Inflection_Features_field.md).

> [!TIP]
>
> - For a discussion about when you may want to use inflection *classes* versus inflection *features*, on the [Help](../../../../Menus/Help/Help_overview.md) menu point to **Resources**, and then click **Introduction to Parsing****.**
>
> - You can [bulk edit](../../../../../Using_Tools/Lexicon_tools/Bulk_Edit_Entries/bulk_edit_overview.md) inflection features.
