# Inflection Class field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Grammatical Info Details fields*

**Full name:** **Inflection Class**

**Abbreviation:** **ic**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

For entries that are *not* affixes, this **Inflection Class** field is at the [Grammatical Info Details level](Gram_Info_Detls_fields_ovw.md). There is one **Inflection Class** field for each sense that has unique grammatical info.

**Description:**

This field references and displays the [name](../../../Grammar/Category_Edit_fields/name_field_inflection_class_category_edit.md) of an item from the [Inflection Class Info area](../../../Grammar/Category_Edit_fields/Inflection_Class_Info_field_Category_Edit.md) for the particular category in **Category Edit** ([Grammar](../../../Grammar/Grammar_fields_overview.md)).

[Parsers](../../../../Menus/Parser/Parsing_words_overview.md) use inflection classes.

[Choose an inflection class](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_an_inflection_class.md) has a table of related fields.

**Tasks:**

- [Choose an inflection class](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_an_inflection_class.md).

- You can [configure the dictionary](../../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to include the abbreviation of the selected inflection class when you configure **Inflection Class** under [Grammatical Info](../../../../Menus/Tools/Configure_Dictionary/Grammatical_Info.md).

**Field type:** [List reference field](../../../Field_Types/List_reference_field.md)

**Writing systems:** Best [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Tip:**

- You can [bulk edit](../../../../../Using_Tools/Lexicon_tools/Bulk_Edit_Entries/bulk_edit_overview.md) inflection classes for entries that are *not* affixes.

- For entries that *are* affixes, there is an [Inflection Classes](../Entry_level_fields/inflection_classes_field_entry_level.md) field at the entry level, and another [Inflection Classes](../Alternate_Forms_level_flds/Inflection_classes_fld_Allomorph.md) field for each allomorph. For derivational affixes, there are also [To Inflection Class](To_Inflection_Class_field.md) and [From Inflection Class](from_inflection_class_field.md) fields at the **Grammatical Info Details** area.

- For more details about inflection classes, such as a discussion about when you may want to use inflection *classes* versus inflection *features*, on the [Help](../../../../Menus/Help/Help_overview.md) menu point to **Resources**, and then click **Introduction to Parsing**.
