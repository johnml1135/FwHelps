# Grammatical Info Details field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Grammatical Info Details fields*

**Full name:** **Grammatical Info. Details**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

This field is at the top of the [Grammatical Info Details level](Gram_Info_Detls_fields_ovw.md).

**Description:** This field acts as a header below which grammatical info-related [fields](Gram_Info_Detls_fields_ovw.md) appear. There are no fields to display here for variant entries that do not have any senses.

**Tasks:**

Click the ![](../../../../../assets/images/minus_sign_box.GIF) (minus sign) to collapse the group of [fields](Gram_Info_Detls_fields_ovw.md); click the ![](../../../../../assets/images/Plus_sign_box.GIF) (plus sign) to expand the group.

Some of the fields and content in them are *automatically included or excluded (deleted).* This is based on (*not* exhaustive)

- choices you make in *other* [fields](../Lexicon_Edit_fields_overview.md), and

- word analyses (both manual and computational [parser](../../../../Menus/Parser/Parsing_words_overview.md)-suggested analyses).

[Category Info](Category_Info_field.md) field and [Delete Grammatical Info](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Delete_grammatical_info.md) have more information.

**Field type:** Not Editable (Header)

**Writing systems:** Not Applicable
