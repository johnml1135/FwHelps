# From Stem Allomorph Label field

*User Interface › Field Descriptions › Lexicon › Lexicon Edit fields › Grammatical Info Details fields*

**Full name:** **From** **Stem Allomorph Label**

**Abbreviation:**

**Location:**

In the **Entry** pane (**Lexicon Edit**).

For derivational affixes entries (**Affix Type** is set to **Derivational**), this field is at the [Grammatical Info Details level](Gram_Info_Detls_fields_ovw.md).

**Description:**

This field displays and references a Stem Allomorph Label for derivational entries.

For each Stem Allomorph Label, you can define one or more sets of inflection features (a [Feature Set](../../../Grammar/Category_Edit_fields/Feature_Sets_field_Category_Edit.md)) that must be present for a particular stem allomorph to be licit. That is, use Stem Allomorph Label to control stem allomorphy (*not* affix allomorphy) that is dependent *not* on phonological issues, but on the presence of certain inflection features.

[Parsers](../../../../Menus/Parser/Parsing_words_overview.md) use Stem Allomorph Labels. [Insert a Stem Allomorph Label](../../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_a_Stem_Allomorph_Label.md) has more information.

The Stem Allomorph Label appears in the [Grammar Sketch](../../../../../Using_Tools/Grammar_tools/Grammar_Sketch/Grammar_Sketch_overview.md) under sections **Allomorphy**. You cannot display Stem Allomorph Labels in **Dictionary**.

**Tasks:**

- [Choose a Stem Allomorph Label](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_Stem_Allomorph_Label.md)

**Field type:** [List reference field](../../../Field_Types/List_reference_field.md)

**Writing systems:** Best [analysis](../../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Tip:**

- A **Stem Allomorph Label** [field](../Entry_level_fields/stem_allomorph_label_field_lex_form.md) refers to the lexeme form for *non-affix* entries.

- A **Stem Allomorph Label** [field](../Alternate_Forms_level_flds/Stem_Allomorph_Label_fld_Allomorph.md) appears at the [*Allomorphs* level](../Alternate_Forms_level_flds/Stem_Allomorph_Label_fld_Allomorph.md) for each *allomorph*.

- Typically, you select the **Affix Type** in the [New Entry](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Create_a_lexical_entry.md) dialog box. You may change it when you use the [Edit Grammatical Info](../../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Using_Edit_Gram_Infodlg.md) dialog box.

- For more information, on the [Help](../../../../Menus/Help/Help_overview.md) menu point to **Resources**, and then click **Introduction to Parsing**.
