# Lexicon fields overview

*User Interface › Field Descriptions › Lexicon*

In the **Lexicon** area, the topics that describe the fields are listed below.

- [Lexicon Edit fields](Lexicon_Edit_fields/Lexicon_Edit_fields_overview.md) (*not* [custom fields](../../Menus/Tools/Custom_Fields/Custom_Fields_overview.md))

- [Collect Words fields](Collect_Words_fields/Collect_Words_fields_overview.md)

- [Reversal Indexes fields](Reversal_Indexes_fields/Reversal_Indexes_fields_overview.md)

> [!NOTE]
>
> - You can usually [change the visibility](../../../Basic_Tasks/Showing_and_hiding_fields/change_the_visibility_of_fields.md) of fields individually, or [show or hide groups of fields](../../../Basic_Tasks/Showing_and_hiding_fields/Hide_show_gps_of_flds.md).
>
> - **Browse**, **Dictionary**, **Classified Dictionary** and the **Bulk Edit** tools do *not* have fields like those described in the topics listed above.
>
> - In the dictionary preview pane, right-click the part of the entry that you want to edit, and then **Jump to field**. This will move the cursor to the [field](../field_descriptions_overview.md) that stores that part of the entry.
