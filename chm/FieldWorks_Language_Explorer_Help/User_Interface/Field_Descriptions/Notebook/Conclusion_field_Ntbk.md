# Conclusion field (Notebook)

*User Interface › Field Descriptions › Notebook*

**Full name:** **Conclusion**

**Location:** In the **Record** pane of **Record Edit** ([Notebook](../../../Using_Tools/Notebook_tools/Notebook_overview.md)). It can appear in a record and any subrecords.

**Description:**

This field stores a summary of the results of your [research](Research_Plan_field_Ntbk.md) based on your [hypothesis](Hypothesis_field_Ntbk.md).

The conclusion can have embedded vernacular words. You can right-click a vernacular word in this field, and then select ![](../../../assets/images/User_Interface/Toolbars/FindInDictionary.GIF) [Find in Dictionary](../../Menus/Tools/Find_in_Dictionary_overview.md) or ![](../../../assets/images/User_Interface/Toolbars/Insert_Lexical_Entry.GIF) [New Entry](../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Create_a_lexical_entry.md). If the right-click menu contains commands related to vernacular spelling, you will need to determine whether the spelling is correct.

  - [Edit a record](../../../Using_Tools/Notebook_tools/Record_Edit_overview/Edit_a_record.md)

  - [Apply styles](../../Menus/Format/apply_a_style_to_text.md)

**Field type:** [Multiparagraph text](../Field_Types/Multiparagraph_text_field.md)—allows embedded [writing systems](../../Menus/Format/select_a_writing_system.md) and [styles](../../Menus/Format/apply_a_style_to_text.md)

**Writing systems:** One or more [analysis](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
