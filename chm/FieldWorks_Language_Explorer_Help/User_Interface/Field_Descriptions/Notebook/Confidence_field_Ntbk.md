# Confidence field (Notebook)

*User Interface › Field Descriptions › Notebook*

**Full name:** **Confidence**

**Location:** In the **Record** pane of **Record Edit** ([Notebook](../../../Using_Tools/Notebook_tools/Notebook_overview.md)). It can appear in a record and any subrecords.

**Description:** This field displays and references an item from the **Confidence Levels** [list](../../../Using_Tools/Lists_tools/List_item_usage_table.md) to indicate of the reliability of data in the current record or subrecord.

**Tasks:**

- [Choose confidence](../../../Using_Tools/Notebook_tools/Record_Edit_overview/Choose_confidence.md)

- Right-click the confidence level in the field, and then click **Show in Confidence Levels list**.

**Field type:** [List Reference](../Field_Types/List_reference_field.md) (permits type-ahead)

**Writing systems:** One or more [analysis](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
