# Date Created field (Notebook)

*User Interface › Field Descriptions › Notebook*

↵

## Date Created field (Notebook)

**Full name:** **Date Created**

**Location:** In the **Record** pane of **Record Edit** ([Notebook](../../../Using_Tools/Notebook_tools/Notebook_overview.md)). It can appear in a record and any subrecords.

**Description:**

This field stores the day, date, and time when the current record was created.

Example:

![](../../../assets/images/User_Interface/Field_Descriptions/Notebook/Date_Created_example.PNG)

If the pane becomes too narrow to display all the content in this field, then up and down arrows (![](../../../assets/images/User_Interface/Field_Descriptions/Notebook/spinbox.PNG)) appear so you can scroll up and down in the field.

You can display this field and the [Date Modified field](Date_Modified_field_Ntbk.md) in columns using the [Configure Columns](../../../Basic_Tasks/Configure_Columns/Configure_Columns_overview.md) dialog box. These dates also appear on the [status bar](../../Toolbars/status_bar.md).

**Tasks:** Not editable

**Field type:** [Date](../Field_Types/date_field.md)

**Writing systems:** One or more [analysis](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Tip:**

- The **Date of Event** field and **Time of Event** field store a date and time (of day) that you can control.

- The date and time for the **Date Created** and **Date Modified** fields are automatically entered by FieldWorks.

- You can change the format of date fields in Microsoft Windows<sup>®</sup> **Control Panel**.
