> [!IMPORTANT]
>
> - When you [insert a record](../../../Using_Tools/Notebook_tools/Record_Edit_overview/Insert_a_fieldnote_record.md), each text field in that record (except the [Title](Title_field_Ntbk.md) field, in some cases) uses the [*default* analysis writing system](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) that is *current* at that time. They continue to use that analysis writing system even if you specify a different default analysis writing system.
>
> - - Consequently, copy/paste operations can inadvertently embed words in a different writing system. This can affect [spell checking](../../../Basic_Tasks/Spell_Checking/Spell_checking_overview.md).

> [!TIP]
>
> - When the [Show Hidden Fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md) check box is cleared, the default set of fields that appears depends on the *record type* of the displayed record.
>
> - - For example, the **Hypothesis** field and **Conclusion** field only appear for analysis records.
>
>   - When the **Show Hidden Fields** check box is selected, all the fields appear, regardless of the record type.
>
>   - You can change the [visibility](../../../Basic_Tasks/Showing_and_hiding_fields/change_the_visibility_of_fields.md) of fields individually.
