# Subrecords field

*User Interface › Field Descriptions › Notebook*

**Full name:** **Subrecords**, and the below that are another headers which shows the number of the subrecords and their record types; for example,\
![](../../../assets/images/User_Interface/Field_Descriptions/Notebook/Subrecords%20field.PNG)

**Location:** In the **Record** pane of **Record Edit** ([Notebook](../../../Using_Tools/Notebook_tools/Notebook_overview.md)), above all the subrecords, and also above each subrecord of a subrecord.

**Description:**

Each **Subrecords** *field* acts as the header for all subrecords and any subrecords of subrecords. Correspondingly, the **Subrecords** *column* displays any subrecords in each record, *or* any subrecords of subrecords.

- Click or right-click the **Subrecords** field label to display a menu button ![](../../../assets/images/Menu_Button_pic.GIF) and an [Insert Subrecord](../../../Using_Tools/Notebook_tools/Record_Edit_overview/Insert_a_fieldnote_subrecord.md) link.

- Click the ![](../../../assets/images/minus_sign_box.GIF) (minus sign) to collapse *all* subrecords (**Subrecords** field) or an *individual* subrecord; click the ![](../../../assets/images/Plus_sign_box.GIF) (plus sign) to expand them.

Similarly, each subrecord, and subrecord of a subrecord, has another header field that contains the number of the subrecord, and its record type (such as ![](../../../assets/images/Plus_sign_box.GIF) **1. Observation**). You can [configure columns](../../../Basic_Tasks/Configure_Columns/Configure_Columns_overview.md) to display the numbers in a column, and [filter](../../../Basic_Tasks/Filtering_data/Filter_Notebook_records.md) or [sort](../../../Basic_Tasks/Sorting_data/Sort_Notebook_records.md) on them.
