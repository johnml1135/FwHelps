# Record Type field (Notebook)

*User Interface › Field Descriptions › Notebook*

**Full name:** **Record Type**

**Location:** In the **Record** pane of **Record Edit** ([Notebook](../../../Using_Tools/Notebook_tools/Notebook_overview.md)). It can appear in a record and any subrecords.

**Description:**

This field displays and references an item from the **Notebook Record Types** [list](../../../Using_Tools/Lists_tools/List_item_usage_table.md) (**Observation**, **Performance**, **Interview**, and so on). The selection determines the type of record. This can affect which set of [fields](Notebook_fields_overview.md) appears when **Show Hidden Fields** is selected or cleared.

When you [insert a fieldnote record](../../../Using_Tools/Notebook_tools/Record_Edit_overview/Insert_a_fieldnote_record.md), you select a record type in the **New Record** dialog box. Later, you can choose a different record type.

**Tasks:**

- [Choose (a different) record type](../../../Using_Tools/Notebook_tools/Record_Edit_overview/Choose_record_type.md)

- Right-click the record type in the field, and then click **Show in Notebook Record Types list**.

**Field type:** [List Reference](../Field_Types/List_reference_field.md)

**Writing systems:** One or more [analysis](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
