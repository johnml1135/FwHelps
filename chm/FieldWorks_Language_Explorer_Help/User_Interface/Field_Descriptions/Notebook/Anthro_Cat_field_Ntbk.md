# Anthropology Categories field (Notebook)

*User Interface › Field Descriptions › Notebook*

**Full name:** **Anthropology Categories**

**Location:** In the **Record** pane of **Record Edit** ([Notebook](../../../Using_Tools/Notebook_tools/Notebook_overview.md)). It can appear in a record and any subrecords.

**Description:**

This field displays and references one or more items from the **Anthropology Categories** [list](../../../Using_Tools/Lists_tools/List_item_usage_table.md) to categorize the current record.

For a record with content in the [Text](Text_field_(Notebook).md) field, the anthropology categories in this field also appear in the [Anthropology Categories](../Texts_&_Words/Sources_field_(Info).md) field in **Texts** **&** **Words**.

**Tasks:**

- [Choose anthropology categories](../../../Using_Tools/Notebook_tools/Record_Edit_overview/Choose_anthropology_categories.md)

**Field type:** [List Reference](../Field_Types/List_reference_field.md) (permits type-ahead)

**Writing systems:** One or more [analysis](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Right-click menu commands:**

Right-click a category in this field, and then click one of the following:

- **Show in Anthropology Categories list**:

  Opens the **Lists** area to the **Anthropology Categories** list, and displays the category you right-clicked. Any other filters are turned off.

- **Filter for Lexical Entries with this category**:

  Opens the **Lexicon** area to **Lexicon Edit**, and adds the **Anthropology Categories** column to the **Entries** pane, if it is not already displayed, and then sets a filter to show only entries that use the category you right-clicked. Any other filters are turned off.

- **Filter for Notebook Records with the category**:

  Adds the **Anthropology Categories** column to the **Records** pane, if it is not already displayed, and then sets a filter to show only records that use the category you right-clicked. Any other filters are turned off.
