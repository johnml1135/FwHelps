# Title field (Notebook)

*User Interface › Field Descriptions › Notebook*

**Full name:** **Title**

**Location:** In the **Record** pane of **Record Edit** ([Notebook](../../../Using_Tools/Notebook_tools/Notebook_overview.md)), the **Title** field appears in a record, and also any subrecords.

**Description:**

This field stores the title for the current event or analysis record. Data is initially entered into this field from the **Title** box in the [New Record](../../../Using_Tools/Notebook_tools/Record_Edit_overview/Insert_a_fieldnote_record.md) dialog box.

The title should accurately reflect the [description](Description_field_Ntbk.md) or [conclusions](Conclusion_field_Ntbk.md).

**Tasks:**

- [Edit a title](../../../Using_Tools/Notebook_tools/Record_Edit_overview/Edit_a_title.md)

**Field type:** Text—allows embedded [styles](../../Menus/Format/apply_a_style_to_text.md). You can also embed multiple [writing systems](../../Menus/Format/select_a_writing_system.md), such as proper names in a vermicular writing system. It is a variation of a [single-line text field](../Field_Types/Single_line_text_field.md). At the end of the field, you see writing system [abbreviation](../../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Writing_System_Properties_General_tab.md) for the writing system that the field is currently using (*not* including embedded writing systems).

**Writing systems:**

The writing system used in this field is set by *any* of the following:

- The default [analysis](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) writing system that was current when the record was added.

- The writing system that is set in the **Find Record** dialog box, or in one of the **Add Reference** dialog boxes, when you click **Create** to insert a new record.

- The writing system you configured to [show](../../../Basic_Tasks/Showing_Writing_Systems/Show_WSs_overview.md) for the field.

- If you select the *entire* title, and then [select a different writing system](../../Menus/Format/select_a_writing_system.md), then that particular field and its contents use that writing system. The three-letter code for the writing system also changes.

**See:** ![](../../../assets/images/Important_Icon.gif) **Important** in [Notebook fields overview](Notebook_fields_overview.md).

**Tip:** The [Subrecords](Subrecords_field.md) field allows you to expand or collapse subrecords. There is also a **Subrecords** *column*, which lists the subrecords for each record. The fields immediately below the **Subrecords** fields are numbered. You can [configure columns](../../../Basic_Tasks/Configure_Columns/Configure_Columns_overview.md) to display the numbers in columns, and [filter](../../../Basic_Tasks/Filtering_data/Filter_Notebook_records.md) or [sort](../../../Basic_Tasks/Sorting_data/Sort_Notebook_records.md) on them.
