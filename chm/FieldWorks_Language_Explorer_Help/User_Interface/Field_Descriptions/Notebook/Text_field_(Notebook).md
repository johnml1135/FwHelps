# Text field (Notebook)

*User Interface › Field Descriptions › Notebook*

**Full name:** **Text**

**Location:** In the **Record** pane of **Record Edit** ([Notebook](../../../Using_Tools/Notebook_tools/Notebook_overview.md)). It can appear in a record and any subrecords.

**Description:**

Each **Text** field stores one text that is included in the text corpus for the project. The content in each **Text** field appears in a separate **Baseline** tab. Consequently, this field is set to initially use the default vernacular writing system.

You see and [analyze](../../../Using_Tools/Texts_%26_Words_tools/Interlinear_Texts/Analyze_Text_overview.md) each of them in the [Texts & Words](../../../Using_Tools/Texts_%26_Words_tools/Texts_and_Words_overview.md) area.

**Tasks:**

- [Enter a vernacular text](../../../Using_Tools/Notebook_tools/Record_Edit_overview/Enter_a_vernacular_text.md)

  - **See also:** [Edit a record](../../../Using_Tools/Notebook_tools/Record_Edit_overview/Edit_a_record.md).

- [Right-click](../../../Basic_Tasks/Show_data/Context_sens_menus.md) the **Text** field label, and then click **Show in Interlinear Texts view**.

This displays the field's contents in **Texts & Words**.

- Right-click a word in the field, and then select ![](../../../assets/images/User_Interface/Toolbars/FindInDictionary.GIF) [Find in Dictionary](../../Menus/Tools/Find_in_Dictionary_overview.md) or ![](../../../assets/images/User_Interface/Toolbars/Insert_Lexical_Entry.GIF) [New Entry](../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Create_a_lexical_entry.md).

- [Check spelling of vernacular words](../../../Basic_Tasks/Spell_Checking/vernacular_spell_checking.md).

- [Enter text metadata](../../../Using_Tools/Texts_%26_Words_tools/Interlinear_Texts/Enter_text_metadata.md).

**Field type:** [Multiparagraph text](../Field_Types/Multiparagraph_text_field.md) - permits [styles](../../Menus/Format/apply_a_style_to_text.md). The styles applied in this field also appear in some **Texts & Words** areas.

**Writing systems:**

The default [vernacular](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) writing system.

It is possible to embed other writing systems. However, it is recommended that you avoid this or do it minimally, because you *cannot* analyze words that do not use a vernacular writing system.

**Note:** You cannot display **Text** field contents in the **Document** [view](../../../Using_Tools/Notebook_tools/Document_overview/Document_overview.md).
