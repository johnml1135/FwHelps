# Restrictions field (Notebook)

*User Interface › Field Descriptions › Notebook*

**Full name:** **Restrictions**

**Location:** In the **Record** pane of **Record Edit** ([Notebook](../../../Using_Tools/Notebook_tools/Notebook_overview.md)). It can appear in a record and any subrecords.

**Description:** This field displays and reference an item from the **Restrictions** [list](../../../Using_Tools/Lists_tools/List_item_usage_table.md). These could include any limitations on the distribution of data in this record. You can add any number of other restrictions to the list.

**Tasks:**

- [Choose restrictions](../../../Using_Tools/Notebook_tools/Record_Edit_overview/Choose_restrictions.md)

- Right-click a restriction in the field, and then click **Show in Restrictions list**.

**Field type:** [List Reference](../Field_Types/List_reference_field.md) (permits type-ahead)

**Writing systems:** One or more [analysis](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
