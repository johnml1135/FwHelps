# Description field (Ad hoc Rules)

*User Interface › Field Descriptions › Grammar › Ad hoc Rules fields*

**Full name:** **Description** or **Nested Group Description**

**Location:**

**Ad hoc Rules** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)) for an [ad hoc rule group](../../../../Using_Tools/Grammar_tools/Ad_hoc_Rules/About_Ad_hoc_Groups.md) (right pane):

- The **Description** field appears above the [Members](Members_field_Ad_hoc_Rules.md) field.

- The **Nested Group Description** field appears below the **Members** field.

**Description:** This field stores the description of the group or nested group.

**Tasks:**

- [Insert an ad hoc co-occurrence group](../../../../Using_Tools/Grammar_tools/Ad_hoc_Rules/insert_an_ad_hoc_group.md)

- [Delete an ad hoc rule](../../../../Using_Tools/Grammar_tools/Ad_hoc_Rules/delete_an_ad_hoc_rule.md)

- **See:** [Ad hoc Co-occurrence Prevention Rules overview](../../../../Using_Tools/Grammar_tools/Ad_hoc_Rules/Ad_hoc_Rules_overview.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) — allows embedded [writing systems](../../../Menus/Format/select_a_writing_system.md) and [styles](../../../Menus/Format/apply_a_style_to_text.md)

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Grammar Sketch:** Under **Residue**
