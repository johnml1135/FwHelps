# Other Morpheme(s) field (Ad hoc Rules)

*User Interface › Field Descriptions › Grammar › Ad hoc Rules fields*

**Full name:** **Other Morpheme(s)**

**Location:** **Ad hoc Rules** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), right pane

**Description:**

This field references and displays one or more lexical entries, as follows:\
\
The *morpheme* (**Citation Form**, if used, otherwise the **Lexeme** **Form**), followed by a *gloss* and *morpheme type*, and then *Grammatical Info*.

Example: `tiara: throw stem/root: verb`

(The gloss is included to help you verify that you chose the correct lexical entry.)

**Note**:

- [Parsers](../../../Menus/Parser/Parsing_words_overview.md) use content from this field.

- If two or more morphemes are selected, the relative order of them is crucial. They *must* appear in the linear order that they would appear in the word.
