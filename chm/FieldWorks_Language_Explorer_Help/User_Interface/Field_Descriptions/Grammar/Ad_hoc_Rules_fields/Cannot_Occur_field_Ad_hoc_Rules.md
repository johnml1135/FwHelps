# Cannot Occur field (Ad hoc Rules)

*User Interface › Field Descriptions › Grammar › Ad hoc Rules fields*

**Full name:** **Cannot Occur**

**Location:** **Ad hoc Rules** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), right pane

**Description:**

This field stores the positional information that specifies the prohibited positions of the following:

- [Key Allomorph](Key_Allomorph_field_Ad_hoc_Rules.md) relative to the [Other Allomorph(s)](other_allomorphs_field_ad_hoc_rules.md)

- [Key Morpheme](Key_Morpheme_field_Ad_hoc_Rules.md) relative to the [Other Morpheme(s)](other_morphemes_field_ad_hoc_rules.md)

The content of this field can appear in the [Try a Word](../../../Menus/Parser/Try_a_word.md) dialog box.

**Tasks:**

- [Insert a morpheme ad hoc rule](../../../../Using_Tools/Grammar_tools/Ad_hoc_Rules/Insert_a_morpheme_ad_hoc_rule.md)

- [Insert an allomorph ad hoc rule](../../../../Using_Tools/Grammar_tools/Ad_hoc_Rules/insert_an_allomorph_ad_hoc_rule.md)

- **See:** [Ad hoc Co-occurrence Prevention Rules overview](../../../../Using_Tools/Grammar_tools/Ad_hoc_Rules/Ad_hoc_Rules_overview.md)

**Field type:** A *list* field populated from a list you cannot edit.

**Writing systems:** Not applicable

**Grammar Sketch:** under **Residue**
