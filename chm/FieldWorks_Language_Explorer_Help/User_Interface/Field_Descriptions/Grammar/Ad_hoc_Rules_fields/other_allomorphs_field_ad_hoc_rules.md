# Other Allomorph(s) field (Ad hoc Rule)

*User Interface › Field Descriptions › Grammar › Ad hoc Rules fields*

**Full name:** **Other Allomorph(s)**

**Location:** **Ad hoc Rules** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), right pane

**Description:**

This field references and displays one or more lexical entries, as follows:\
\
The *allomorph* (**Citation** form if used, otherwise the **Lexeme** or **Allomorph**, including [tokens](../../../../Using_Tools/Lists_tools/Change_the_tokens_for_morpheme_types.md) if any), followed by the first *gloss* in parenthesis, and then the *form* (**Citation Form**, if used otherwise the **Lexeme From**).

Example: `tair: (throw): taria`

(The gloss is included to help you verify that you chose content from the correct lexical entry.)\

**Note:**

- [Parsers](../../../Menus/Parser/Parsing_words_overview.md) use content from this field.

- If there are two or more allomorphs listed, the *order* of these allomorphs is *crucial*. They *must* occur in the order they would in a word.
