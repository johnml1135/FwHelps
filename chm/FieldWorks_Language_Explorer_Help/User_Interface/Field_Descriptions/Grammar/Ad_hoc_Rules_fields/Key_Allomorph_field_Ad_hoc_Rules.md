# Key Allomorph field (Ad hoc Rules)

*User Interface › Field Descriptions › Grammar › Ad hoc Rules fields*

**Full name:** **Key Allomorph**

**Location:** **Ad hoc Rules** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), right pane

**Description:**

This field references and displays one lexical entry, as follows:\
\
The *allomorph* (**Citation** form if used, otherwise the **Lexeme** or **Allomorphs**, including [tokens](../../../../Using_Tools/Lists_tools/Change_the_tokens_for_morpheme_types.md) if any), followed by the first *gloss* in parenthesis, and then the *form* (**Citation Form**, if used otherwise the **Lexeme From**).

Example: `tair: (deitar): taria`

(The gloss is included to help you verify that you chose content from the correct lexical entry.)

[Parsers](../../../Menus/Parser/Parsing_words_overview.md) use this allomorph.

**Tasks:**

- [Insert an allomorph ad hoc rule](../../../../Using_Tools/Grammar_tools/Ad_hoc_Rules/insert_an_allomorph_ad_hoc_rule.md)

- **See:** [Ad hoc Co-occurrence Prevention Rules overview](../../../../Using_Tools/Grammar_tools/Ad_hoc_Rules/Ad_hoc_Rules_overview.md)

**Field type:** [List reference field](../../Field_Types/List_reference_field.md)

**Writing systems:** Default [vernacular](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) (allomorph and forms) and [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) (gloss)
