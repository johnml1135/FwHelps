# Name field (Ad hoc Rules)

*User Interface › Field Descriptions › Grammar › Ad hoc Rules fields*

**Full name:** **Name**

**Location:** **Group of Ad Hoc Rules** pane (top of the right pane) in **Ad hoc Rules** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)). This field appears for an [ad hoc rule group](../../../../Using_Tools/Grammar_tools/Ad_hoc_Rules/About_Ad_hoc_Groups.md), but not for morpheme or allomorph ad hoc rules that are not grouped.

**Description:**

This field stores the name of the ad hoc rule group.

For nested groups, the [Nested Group Name](Nested_Group_Name_field_Ad_hoc_Rules.md) field holds a name for the nested group. It is a secondary (subordinate) name.
