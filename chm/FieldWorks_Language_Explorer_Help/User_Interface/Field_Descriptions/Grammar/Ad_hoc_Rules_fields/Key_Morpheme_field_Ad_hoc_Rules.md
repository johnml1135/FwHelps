# Key Morpheme field (Ad hoc Rules)

*User Interface › Field Descriptions › Grammar › Ad hoc Rules fields*

**Full name:** **Key Morpheme**

**Location:** **Ad hoc Rules** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), right pane

**Description:**

This field references and displays one lexical entry, as follows:\
\
The *morpheme* (**Citation Form**, if used, otherwise the **Lexeme** **Form**), followed by a *gloss* and *morpheme type*, and then *Grammatical Info*.

Example: `taira: deitar stem/root: verbo`

(The gloss is included to help you verify that you chose the correct lexical entry.)

[Parsers](../../../Menus/Parser/Parsing_words_overview.md) use this morpheme.

**Tasks:**

- [Insert a morpheme as hoc rule](../../../../Using_Tools/Grammar_tools/Ad_hoc_Rules/Insert_a_morpheme_ad_hoc_rule.md)

- **See:** [Ad hoc Co-occurrence Prevention Rules overview](../../../../Using_Tools/Grammar_tools/Ad_hoc_Rules/Ad_hoc_Rules_overview.md)

**Field type:** [List reference field](../../Field_Types/List_reference_field.md)

**Writing systems:** Default [vernacular](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) (morpheme), and one or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) (gloss, morpheme type, and grammatical info)

**Grammar Sketch:** Under **Residue**
