# Right Gloss Separator

*User Interface › Field Descriptions › Grammar › Inflection Features fields*

**Full name:** **Abbreviation**

**Locations:** This **Right Gloss Separator** field is in the **Complex Feature** pane in **Inflection Features** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

**Description:**

This field appears and is only for use with complex features.

The contents you enter here, typically a colon and a space, is only used if the [Display label](Display_label_field_(Features).md) check box is selected. It will appear between the feature abbreviation and value abbreviation in fields where feature data is referenced and displayed.

**Tasks:**

- [Insert an inflection feature or complex feature](../../../../Using_Tools/Grammar_tools/Inflection_Features/Insert_a_Feature_or_Complex_Feature.md)

- **See** **also****:** [Inflection Features overview](../../../../Using_Tools/Grammar_tools/Inflection_Features/Inflection_Features_overview.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Grammar Sketch:** Not Applicable
