# Name field (Features - Value Name)

*User Interface › Field Descriptions › Grammar › Inflection Features fields*

**Full name:** **Value Name**

**Locations:**

The **Value Name** field is under the [Values field](Values_field_Features.md) in **Inflection** **Features** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)). Each value has its own **Value Name** field.

There is a separate [Name field](name_field_feature_features.md) for each feature or complex feature.

**Description:**

Each **Value Name** field stores the name of one value for the current feature.

Value names appear in dialog boxes for [Inflectable Features](../Category_Edit_fields/Inflectable_Features_field_Category_Edit.md) (**Grammar**) and in those used to [choose inflection features](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/choose_inflection_features.md) (**Lexicon Edit**).

[Parsers](../../../Menus/Parser/Parsing_words_overview.md) use inflection features.

**Tasks:**

- [Insert a feature or complex feature](../../../../Using_Tools/Grammar_tools/Inflection_Features/Insert_a_Feature_or_Complex_Feature.md)

- [Insert a feature value](../../../../Using_Tools/Grammar_tools/Inflection_Features/Insert_a_feature_value.md)

- **See also:** [Inflection Features overview](../../../../Using_Tools/Grammar_tools/Inflection_Features/Inflection_Features_overview.md)

**Field type:** [Single-line text](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Grammar Sketch:** Under **Morpho-syntactic Feature System**

**Tip:** For more information, point to **Resources** on the [Help](../../../Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
