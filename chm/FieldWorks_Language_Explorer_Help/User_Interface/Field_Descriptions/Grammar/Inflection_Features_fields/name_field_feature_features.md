# Name field (Feature)

*User Interface › Field Descriptions › Grammar › Inflection Features fields*

**Full name:** **Name**

**Locations:**

This **Name** field is near the top of the **Feature** or **Complex Feature** pane in **Inflection** **Features** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

There is a separate [Value Name field](name_field_value_features.md) for each value under the [Values field](Values_field_Features.md).

**Description:**

This field stores the name of the inflection feature or complex feature.

Feature names appear in dialog boxes for [Inflectable Features](../Category_Edit_fields/Inflectable_Features_field_Category_Edit.md) (**Grammar**) and in those used to [choose inflection features](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/choose_inflection_features.md) (**Lexicon Edit**).

[Parsers](../../../Menus/Parser/Parsing_words_overview.md) use inflection features.

**Tasks:**

- [Insert an inflection feature or complex feature](../../../../Using_Tools/Grammar_tools/Inflection_Features/Insert_a_Feature_or_Complex_Feature.md)

- **See also:** [Inflection Features overview](../../../../Using_Tools/Grammar_tools/Inflection_Features/Inflection_Features_overview.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Grammar Sketch:** Under **Morpho-syntactic Feature System**

**Tip:** For more information, point to **Resources** on the [Help](../../../Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
