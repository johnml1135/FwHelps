# Display label field (Features)

*User Interface › Field Descriptions › Grammar › Inflection Features fields*

**Full name:** **Display label**

**Locations:**

A **Display label** field is in the **Feature** or **Complex Feature** pane in **Inflection Features** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

There is a separate **Display label** field for each named feature and complex feature.

**Description:**

This field stores your choice to display content from the associated **Abbreviation** field in the [Grammatical Info field](../../Lexicon/Lexicon_Edit_fields/Sense_level_fields/Grammatical_Info_field.md) and consequently makes it available for display in the [Dictionary](../../../../Using_Tools/Lexicon_tools/Dictionary/Dictionary_overview.md). (These abbreviations always appear in [Inflection Features fields](../../Lexicon/Lexicon_Edit_fields/Grammatical_Info_Details_fields/Inflection_Features_field.md)).

Regarding the **Dictionary**:

- ![](../../../../assets/images/User_Interface/Field_Descriptions/Grammar/Inflection_Features_fields/CheckedBox.PNG) (selected) means that *abbreviation* of this feature or complex feature is available for inclusion in the **Dictionary**, *if* so [configured](../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md). For a complex feature, you can enter a separator in the [Right Gloss Separator](Right_Gloss_Sep.md) field.

- ![](../../../../assets/images/User_Interface/Field_Descriptions/Grammar/Inflection_Features_fields/UncheckedBox.PNG) (cleared) means the the abbreviation is not available for inclusion in the **Dictionary**.
