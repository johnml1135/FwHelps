# Values field (Features)

*User Interface › Field Descriptions › Grammar › Inflection Features fields*

**Full name:** **Values**

**Location:** The **Values** field appears in the **Feature** pane in **Features** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

**Description:**

This field acts as a header below which one or more *values* are stored for the current [feature](Features_fields_overview.md).

[Parsers](../../../Menus/Parser/Parsing_words_overview.md) use inflection features.

**Tasks:**

- Click the ![](../../../../assets/images/minus_sign_box.GIF) (minus sign) to hide the fields associated with the values; click the ![](../../../../assets/images/Plus_sign_box.GIF) (plus sign) to show them.

- Click or right-click the **Values** field label to display a menu button ![](../../../../assets/images/User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Menu_Button_pic.GIF) and the [Insert Feature Value](../../../../Using_Tools/Grammar_tools/Inflection_Features/Insert_a_feature_value.md) link so you can insert a feature value.

**Field type:** Not Editable

**Writing systems:** Not Applicable

**Grammar Sketch:** Not Applicable

**Tip:** For more information, point to **Resources** on the [Help](../../../Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
