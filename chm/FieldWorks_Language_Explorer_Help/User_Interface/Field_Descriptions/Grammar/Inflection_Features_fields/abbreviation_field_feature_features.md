# Abbreviation field (Features)

*User Interface › Field Descriptions › Grammar › Inflection Features fields*

**Full name:** **Abbreviation**

**Locations:**

This **Abbreviation** field is near the top of the **Feature** or **Complex Feature** pane in **Inflection Features** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

There is a separate [Abbreviation field](Abbr_field_value_features.md) for each value.

**Description:**

This field stores an abbreviation of the [name](name_field_feature_features.md) of the feature or complex feature.

It can appear in the [Inflection Features field](../../Lexicon/Lexicon_Edit_fields/Grammatical_Info_Details_fields/Inflection_Features_field.md), [From Inflection Features field](../../Lexicon/Lexicon_Edit_fields/Grammatical_Info_Details_fields/from_inflection_features_field.md) and [To Inflection Features field](../../Lexicon/Lexicon_Edit_fields/Grammatical_Info_Details_fields/To_Inflection_Features_field.md) (**Lexicon Edit**).

[Parsers](../../../Menus/Parser/Parsing_words_overview.md) use inflection features.

**Tasks:**

- [Insert an inflection feature or complex feature](../../../../Using_Tools/Grammar_tools/Inflection_Features/Insert_a_Feature_or_Complex_Feature.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show this abbreviation, *if* the [Display label](Display_label_field_(Features).md) field is selected (![](../../../../assets/images/User_Interface/Field_Descriptions/Grammar/Inflection_Features_fields/CheckedBox.PNG)) and you configured **Inflection Features** under [Grammatical Info](../../../Menus/Tools/Configure_Dictionary/Grammatical_Info.md).

- **See** **also****:** [Inflection Features overview](../../../../Using_Tools/Grammar_tools/Inflection_Features/Inflection_Features_overview.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Grammar Sketch:** This abbreviation does *not* appear in the **Grammar Sketch**.

**Tip:** For more information, point to **Resources** on the [Help](../../../Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**
