# Special Note field (Features)

*User Interface › Field Descriptions › Grammar › Inflection Features fields*

**Full name:** **Special Note**

**Location:** The **Special Note** field is in the **Feature** or **Complex Feature** pane in **Inflection Features** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

**Description:** This field displays the information intended to help you construct an inflection feature or a complex feature. (Additional content is planned for future versions.)

**Tasks:** **See:** [Inflection Features overview](../../../../Using_Tools/Grammar_tools/Inflection_Features/Inflection_Features_overview.md)

**Field type:** Not Editable

**Writing systems:** Not Applicable

**Grammar Sketch:** Not Applicable

**Tip:** For more information, point to **Resources** on the [Help](../../../Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
