# Exception Features field (Exception Features field Comp Rules)

*User Interface › Field Descriptions › Grammar › Compound Rules fields*

**Full name:** **Exception "Features"**

**Location:**

**Compound Rules** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), right pane.

- There is separate [Exception "Features" field](../../Lexicon/Lexicon_Edit_fields/Grammatical_Info_Details_fields/exception_features_field.md) in the **Entry** pane (**Lexicon Edit**) for entries that are not affixes.

**Description:** This field stores one or more exception "features".

**Tasks:**

- Click ![](../../../../assets/images/Ellipsis_button.PNG) to open and [use](../../../../Using_Tools/Lists_tools/choose_item_for_list_field.md) the **Choose Exception "Features"** dialog box.

These can restrict the application of a left and/or right member of a compound rule. You might want to [get more help](../../../../Overview/Technical_support.md).

**Field type:** [List reference](../../Field_Types/List_reference_field.md)
