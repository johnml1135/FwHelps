# Inflection Class field (Compound Rules)

*User Interface › Field Descriptions › Grammar › Compound Rules fields*

**Full name:** **Inflection Class**

**Location:** **Compound Rules** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)) for *non-headed* compound rules, right pane

**Description:**

This field references and displays an item from the [Inflection Class fields](../Category_Edit_fields/Inflection_Class_Info_field_Category_Edit.md) for the current **Result** field [category](../../../../Using_Tools/Grammar_tools/Compound_Rules/Edit_a_Compound_Rule.md).

[Parsers](../../../Menus/Parser/Parsing_words_overview.md) use inflection classes.

- [Insert a compound rule](../../../../Using_Tools/Grammar_tools/Compound_Rules/Insert_a_compound_rule.md)

- [Edit a compound rule](../../../../Using_Tools/Grammar_tools/Compound_Rules/Edit_a_Compound_Rule.md)

- **See** **also****:** [Compound Rules overview](../../../../Using_Tools/Grammar_tools/Compound_Rules/Compound_Rules_overview.md)

**Field type:** [List reference field](../../Field_Types/List_reference_field.md)

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Grammar Sketch:** Under **Compounding**

**Tip:**

- [Choose an inflection class](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_an_inflection_class.md) has a table of related fields.
