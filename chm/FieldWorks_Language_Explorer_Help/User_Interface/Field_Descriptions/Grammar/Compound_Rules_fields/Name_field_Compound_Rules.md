# Name field (Compound Rules)

*User Interface › Field Descriptions › Grammar › Compound Rules fields*

**Full name:** **Name**

**Location:** **Compound Rules** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), right pane

**Description:** This field stores the name of the current compound rule. The name may be used by the [Try a Word](../../../Menus/Parser/Try_a_word.md) dialog box.

**Tasks:**

- [Insert a compound rule](../../../../Using_Tools/Grammar_tools/Compound_Rules/Insert_a_compound_rule.md)

- [Delete a compound rule](../../../../Using_Tools/Grammar_tools/Compound_Rules/Delete_a_Compound_Rule.md)

- [Edit a compound rule](../../../../Using_Tools/Grammar_tools/Compound_Rules/Edit_a_Compound_Rule.md)

- **See** **also****:** [Compound Rules overview](../../../../Using_Tools/Grammar_tools/Compound_Rules/Compound_Rules_overview.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles.

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Grammar Sketch:** Under **Compounding**
