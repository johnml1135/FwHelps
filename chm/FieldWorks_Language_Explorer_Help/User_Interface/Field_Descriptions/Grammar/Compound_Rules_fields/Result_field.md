# Result field

*User Interface › Field Descriptions › Grammar › Compound Rules fields*

**Full name:** **Result**

**Location:** **Compound Rules** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)) for *non-headed* compound rules, right pane

**Description:** This field acts as a heading to identify the use of the category in the [Category field](Category_field_Compound_Rules.md) and [Inflection Class field](inflection_class_field_compound_rules.md) immediately below this field.
