# Category field (Compound Rules)

*User Interface › Field Descriptions › Grammar › Compound Rules fields*

**Full name:** **Category**

**Location:** **Compound Rules** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), right pane

**Description:**

There is a separate **Category** field below each of these fields:[\
Left Member](left_member_field.md), [Right Member](right_member_field.md), [Override Head with](Override_Head_with_field.md) and [Result](Result_field.md).

Each field references and displays a category which you select from a list or from a [catalog](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Using_Add_from_Catalog_dialog_box.md) (**More…**). You may also specify **\<Not Sure\>**.

[Parsers](../../../Menus/Parser/Parsing_words_overview.md) use each category.
