# Phonological Features field (Natural Classes)

*User Interface › Field Descriptions › Grammar › Natural Classes fields*

**Full name:** **Phonological Features**

**Location:** **Natural Class (Features)** pane of **Natural Classes** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md) ) for natural classes that are defined by phonological features.

**Description:** This field stores one or more phonological features for the current natural class. [Parsers](../../../Menus/Parser/Parsing_words_overview.md) use phonological features.

**Tasks:**

- [Choose phonological features](../../../../Using_Tools/Grammar_tools/Natural_Classes/Choose_phonological_features(NC).md)

- [Edit a natural class](../../../../Using_Tools/Grammar_tools/Natural_Classes/Edit_a_natural_class.md) (has important information)

- [Insert a Natural Class defined by Features](../../../../Using_Tools/Grammar_tools/Natural_Classes/Insert_a_Natural_Class.md)

- [Remove a phonological feature](../../../../Using_Tools/Grammar_tools/Natural_Classes/Remove_a_phonological_feature(NC).md)

- **See also:** [Phonemes overview](../../../../Using_Tools/Grammar_tools/Phonemes/Phonemes_overview.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles.

**Writing systems:** One or more [vernacular](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Grammar Sketch:** Under **Natural Classes** and under **Phonological Feature System**

**Note:** In the **Natural Classes** pane, the associated column is **Phonemes/Features**. It is shared with natural classes that are defined by [phonemes](Phonemes_field_Natural_Classes.md).
