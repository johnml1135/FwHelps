# Name field (Natural Classes)

*User Interface › Field Descriptions › Grammar › Natural Classes fields*

**Full name:** **Name**

**Location:** **Natural Class (Phonemes)** pane or **Natural Class (Features)** pane of **Natural Classes** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md))

**Description:** This field stores the name of the current natural class. It may be empty, while the associated column contains "**Created automatically for rule "\<**name**\>"**. **See:** [Edit a natural class](../../../../Using_Tools/Grammar_tools/Natural_Classes/Edit_a_natural_class.md).

**Tasks:**

- [Insert a natural class](../../../../Using_Tools/Grammar_tools/Natural_Classes/Insert_a_Natural_Class.md)

- [Delete a natural class](../../../../Using_Tools/Grammar_tools/Natural_Classes/Delete_a_natural_class.md)

- **See also:** [Natural Classes overview](../../../../Using_Tools/Grammar_tools/Natural_Classes/Natural_classes_overview.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles.

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Grammar Sketch:** Under **Natural Classes** and under **Phonological Feature System**

**Important:**

The [Abbreviation field](Abbreviation_field_Natural_Classes.md) content (*not* the **Name** field) is used to represent the natural class in [environments](../../../../Using_Tools/Grammar_tools/Environments/Environments_overview.md).

However, if you use **Insert Natural Class** when you [insert an environment](../../../../Using_Tools/Grammar_tools/Environments/Insert_an_environment.md), the **Choose Natural Class** dialog box appears and lists the available natural classes by *name*.
