# Phonemes field (Natural Classes)

*User Interface › Field Descriptions › Grammar › Natural Classes fields*

**Full name:** **Phonemes**

**Location:** **Natural Class** pane of **Natural Classes** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)) for natural classes that are defined by a set of phonemes.

**Description:** For the current natural class, this field stores one or more [phonemes](../Phonemes_fields/Phonemes_fields_overview.md) (phoneme [Name field](../Phonemes_fields/name_field_phonemes.md) content). [Parsers](../../../Menus/Parser/Parsing_words_overview.md) use natural classes and phonemes, for example as they are used by environments.

**Tasks:**

- [Insert a natural class](../../../../Using_Tools/Grammar_tools/Natural_Classes/Insert_a_Natural_Class.md)

  - [Choose phonemes for a natural class](../../../../Using_Tools/Grammar_tools/Natural_Classes/Choose_Phonemes_for_Natural_Class.md)

- [Delete a natural class](../../../../Using_Tools/Grammar_tools/Natural_Classes/Delete_a_natural_class.md)

- [Edit a natural class](../../../../Using_Tools/Grammar_tools/Natural_Classes/Edit_a_natural_class.md)

- **See also:** [Natural Classes overview](../../../../Using_Tools/Grammar_tools/Natural_Classes/Natural_classes_overview.md)

**Field type:** [List reference field](../../Field_Types/List_reference_field.md) – you cannot select individual phonemes and change their writing system or modify them in this field in any way.

**Writing systems:** Best [vernacular](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) – this field displays **Name** field content from the default (top-most) writing system, if content is present; otherwise, from the next writing system with content in the **Name** field for the phoneme. If there is no name, then **\*\*\*** appears in this field.

**Grammar Sketch:** Under **Natural Classes** and under **Phonological Feature System**

**Note:** In the **Natural Classes** pane, the associated column is **Phonemes/Features**. It is shared with natural classes that are defined by [phonological features](Phonological_Features_fld(NC).md).
