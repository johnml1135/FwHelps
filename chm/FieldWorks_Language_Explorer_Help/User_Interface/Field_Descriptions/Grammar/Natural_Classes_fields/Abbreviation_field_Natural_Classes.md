# Abbreviation field (Natural Classes)

*User Interface › Field Descriptions › Grammar › Natural Classes fields*

**Full name:** **Abbreviation**

**Location:** **Natural Class (Phonemes)** pane or **Natural Class (Features)** pane of **Natural Classes** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md))

**Description:**

This field stores the abbreviation of the [name](name_field_natural_classes.md) of the current natural class.

[Parsers](../../../Menus/Parser/Parsing_words_overview.md) use natural classes, for example, as they are used in environments.

> [!IMPORTANT]
>
> - *This abbreviation represents the natural class in* [environments](../Environments_fields/String_Representation_field_Environments.md) ([example](../Environments_fields/String_Representation_field_Environments.md)).
>
> - It can appear in the [Try a Word](../../../Menus/Parser/Try_a_word.md) dialog box.\
