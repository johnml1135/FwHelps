# Description field (Natural Classes)

*User Interface › Field Descriptions › Grammar › Natural Classes fields*

**Full name:** **Description**

**Location:** **Natural Class (Phonemes)** pane or **Natural Class (Features)** pane of **Natural Classes** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md))

**Description:**

This field stores the description of the [name](name_field_natural_classes.md) of the current natural class.

[Parsers](../../../Menus/Parser/Parsing_words_overview.md) use natural classes, for example, as used in environments.
