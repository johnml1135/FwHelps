# Text field (Problems)

*User Interface › Field Descriptions › Grammar › Problems fields*

**Full name:** **Text**

**Location:** **Problem Report** pane of **Problems** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md))

**Description:**

This field contains a brief description of the reason that the selected environment appears in **Problems**. (You select the problematic environment in the center **Records** pane.)

Problematic environments appear with a red underline in fields that contain environments, but the [parsers](../../../Menus/Parser/Parsing_words_overview.md) cannot use an environment that has a problem so they *need to be corrected* for proper parsing.

**Tasks:** [View problems with environments](../../../../Using_Tools/Grammar_tools/Problems/View_Problems_with_Environments.md)

**Field type:** [Single-line text](../../Field_Types/Single_line_text_field.md)

**Writing systems:** The text appears in the analysis writing system that was set as the *default* when the problematic environment was added and also in the UI language that was [selected](../../../Menus/Tools/Options/Change_Interface_Language.md) (if different).

**Note:**

- Environments used with *natural classes* require brackets and use the *abbreviation* of the natural class, such as **\[V\]**, for a class of vowels.

- Environments used with *phonemes* do *not* require brackets.

- **See also:** [Environment String Representation examples](../Environments_fields/String_Representation_field_Environments.md)

- For additional information about environments, point to **Resources** on the [Help](../../../Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
