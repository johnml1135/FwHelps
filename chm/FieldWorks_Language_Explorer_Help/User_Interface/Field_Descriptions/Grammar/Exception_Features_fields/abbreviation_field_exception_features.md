# Abbreviation field (Exception \"Features\")

*User Interface › Field Descriptions › Grammar › Exception \"Features\" fields*

**Full name:** **Abbreviation**

**Location:** This **Abbreviation** field is in the **Exception "Feature"** pane of **Exception "Features"** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md))

**Description:**

This field stores an abbreviation of the name of current exception "feature."

[Parsers](../../../Menus/Parser/Parsing_words_overview.md) use exception "features."

**Tasks:**

- [Delete an exception "feature"](../../../../Using_Tools/Grammar_tools/Exception_Features/Delete_an_Exception_Feature.md)

- [Insert an exception "feature"](../../../../Using_Tools/Grammar_tools/Exception_Features/insert_an_exception_feature.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to display **Abbreviation** field content when you configure **Exception Features** under [Grammatical Info](../../../Menus/Tools/Configure_Dictionary/Grammatical_Info.md).

- **See** **also****:** [Exception "Features" overview](../../../../Using_Tools/Grammar_tools/Exception_Features/exception_features_overview.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Grammar Sketch:** These abbreviations do not appear in the **Grammar Sketch**.
