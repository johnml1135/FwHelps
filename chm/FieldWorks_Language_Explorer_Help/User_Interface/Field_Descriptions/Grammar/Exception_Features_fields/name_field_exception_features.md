# Name field (Exception "Features")

*User Interface › Field Descriptions › Grammar › Exception "Features" fields*

**Full name:** **Name**

**Location:** This **Name** field is in the **Exception "Feature"** pane of **Exception "Features"** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md))

**Description:**

This field stores the name of the current exception "feature."

Exception "feature" names are used in various dialog boxes and fields, such as the [Exception "Features" field](../../Lexicon/Lexicon_Edit_fields/Grammatical_Info_Details_fields/exception_features_field.md), [From Exception "Features" field](../../Lexicon/Lexicon_Edit_fields/Grammatical_Info_Details_fields/from_exception_features_field.md) and [To Exception "Features" field](../../Lexicon/Lexicon_Edit_fields/Grammatical_Info_Details_fields/To_Exception_Features_field.md) (**Lexicon Edit**). You can use Exception Features in [Compound Rules](../Compound_Rules_fields/Compound_Rules_fields_overview.md).

[Parsers](../../../Menus/Parser/Parsing_words_overview.md) use exception "features."
