# Description field (Category - Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Description**

**Location:** This **Description** field is near the top of the **Category (or Part of Speech)** pane in **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), above the **Affix Templates** field.

**Description:** This field stores the description of the current [named](rlt1edc.md) grammatical category or subcategory.

- [Insert a category](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_a_Category.md)

- [Insert a subcategory](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_a_Subcategory.md)

- [Use the Add from Catalog dialog box](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Using_Add_from_Catalog_dialog_box.md)

- **See also:** [Category Edit overview](../../../../Using_Tools/Grammar_tools/Category_Edit/Category_Edit_overview.md)

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Grammar Sketch:** Under **Word categories**
