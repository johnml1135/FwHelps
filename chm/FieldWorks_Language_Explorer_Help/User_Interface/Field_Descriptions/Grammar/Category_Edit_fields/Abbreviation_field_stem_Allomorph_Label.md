# Abbreviation field (Stem Allomorph Labels - Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Abbreviation**

**Location:** There is an **Abbreviation** field in the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)) below *each* **Stem Allomorph Label** field.

**Description:** Each field stores the abbreviation of a [Stem Allomorph Label](Stem_Allomorph_Label_field.md). [Parsers](../../../Menus/Parser/Parsing_words_overview.md) use Stem Allomorph Labels.

**Tasks:**

- [Insert a Stem Allomorph Label](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_a_Stem_Allomorph_Label.md)

- **See also:** [Category Edit overview](../../../../Using_Tools/Grammar_tools/Category_Edit/Category_Edit_overview.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Grammar Sketch:** These abbreviations do *not* currently appear in the **Grammar Sketch**.
