# Default Inflection Class field

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Default Inflection Class**

**Location:** The **Default Inflection Class** field is in the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)). It is the lowest field under the **Inflection Class Info** field, above the **Features** field.

**Description:**

For the category or subcategory selected in the center pane, this field references and displays *one of the* inflection classes or subclasses that is displayed above this field.

[Parsers](../../../Menus/Parser/Parsing_words_overview.md) use the default inflection class for any lexical entry with this category that does *not* have an inflection class overtly [chosen](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_an_inflection_class.md) for it.
