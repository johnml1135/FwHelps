# Name field (Category - Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Name**

**Location:** This **Name** field is at the top of the **Category (or Part of Speech)** pane in **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), above the **Affix Templates** field.

**Description:**

This field stores the name of the current category, such as "`Verb`," or subcategory, such as "**Intransitive verb**."

The name is used in numerous locations, such as in the [Grammatical Info fields](../../Lexicon/Lexicon_Edit_fields/Sense_level_fields/Grammatical_Info_field.md) (**Lexicon**) and in [word focus boxes](../../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Word_Focus_Box_examples.md) (**Interlinear Texts**).

**Tasks:**

- [Insert a category](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_a_Category.md)

- [Insert a subcategory](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_a_Subcategory.md)

- [Use the Add from Catalog dialog box](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Using_Add_from_Catalog_dialog_box.md)

- **See also:** [Category Edit overview](../../../../Using_Tools/Grammar_tools/Category_Edit/Category_Edit_overview.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) - you cannot embed characters in other writing system or embed styles.

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Grammar Sketch:** Under **Word categories** and under **Inflection**
