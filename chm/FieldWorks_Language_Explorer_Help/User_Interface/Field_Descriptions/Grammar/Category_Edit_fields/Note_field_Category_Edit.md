# Note field (Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Note**

**Abbreviation:** **nt**

**Location:** There is a **Note** field in the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)) below *each* **Table** field.

**Description:** This field stores information intended to help you get started when need to [edit a template table](../../../../Using_Tools/Grammar_tools/Category_Edit/Edit_an_Affix_Template_Table.md).

**Tasks:** Not Applicable

**Field type:** Not Editable

**Writing systems:** Not Applicable

**Grammar Sketch:** Not Applicable
