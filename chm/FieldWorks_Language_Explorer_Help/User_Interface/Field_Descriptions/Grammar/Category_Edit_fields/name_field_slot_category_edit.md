# Name field (Slot Name - Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Slot Name**

**Location:** One or more **Slot Name** fields can appear in the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), below the **Affix Slots** field.

**Description:**

Each field stores the name of the current affix slot. Names of [optional](Optional_field.md) slots appear in parenthesis ([example](../../../../Using_Tools/Grammar_tools/Category_Edit/affix_template_table_example.md)).

Slot names appear in these locations:

- In each [template table](Table_field.md) heading to which you assign it.

- [Grammatical Info field](../../Lexicon/Lexicon_Edit_fields/Sense_level_fields/Grammatical_Info_field.md)

- In various [Grammatical Info Details fields](../../Lexicon/Lexicon_Edit_fields/Grammatical_Info_Details_fields/grammatical_info_details_field.md), such as the [Slots field](../../Lexicon/Lexicon_Edit_fields/Grammatical_Info_Details_fields/Slots_field.md).

- In the [Try a Word](../../../Menus/Parser/Try_a_word.md) dialog box.

[Parsers](../../../Menus/Parser/Parsing_words_overview.md) use slots.

**Tasks:**

- [Delete an affix template](../../../../Using_Tools/Grammar_tools/Category_Edit/Delete_an_Affix_Template.md)

- [Edit an affix template](../../../../Using_Tools/Grammar_tools/Category_Edit/Edit_an_Affix_Template_Table.md)

- [Insert an affix slot](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_an_Affix_Slot.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to display slot names when you configure **Slot Names** under [Grammatical Info](../../../Menus/Tools/Configure_Dictionary/Grammatical_Info.md).

- **See also:** [Category Edit overview](../../../../Using_Tools/Grammar_tools/Category_Edit/Category_Edit_overview.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you cannot embed characters in other writing systems or embed styles

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)
