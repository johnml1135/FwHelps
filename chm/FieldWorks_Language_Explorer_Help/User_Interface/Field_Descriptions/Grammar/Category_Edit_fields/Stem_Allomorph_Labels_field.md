# Stem Allomorph Labels field (Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Stem Allomorph Labels**

**Location:** This **Stem Allomorph Labels** field is in the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), below the [Features field](features_field_category_edit.md).

**Description:** This field acts as a header field below which one or more [Stem Allomorph Label fields](Stem_Allomorph_Label_field.md) and their associated [Abbreviation](Abbreviation_field_stem_Allomorph_Label.md), [Description](Description_field_Stem_Allomorph_Label.md) and [Feature Set](Feature_Sets_field_Category_Edit.md) fields are stored for the current category (part of speech).

**Tasks:**

- Click the ![](../../../../assets/images/minus_sign_box.GIF) (minus sign) to hide the fields associated with Stem Allomorph Labels; click the ![](../../../../assets/images/Plus_sign_box.GIF) (plus sign) to show them.

- Click or right-click the **Stem Allomorph Labels** field label to display a menu button ![](../../../../assets/images/User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Menu_Button_pic.GIF) and the [Insert Stem Allomorph Label](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_a_Stem_Allomorph_Label.md) link.

- [Delete a Stem Allomorph Label](../../../../Using_Tools/Grammar_tools/Category_Edit/Delete_a_Stem_Allomorph_Label.md)

- [Insert a Feature Set](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_a_Feature_Set.md)

- **See also:** [Category Edit overview](../../../../Using_Tools/Grammar_tools/Category_Edit/Category_Edit_overview.md)

**Field type:** Not Editable

**Writing systems:** Not Applicable

**Grammar Sketch:** Not Applicable

**Tip:** For more information regarding Stem Allomorph Labels, point to **Resources** on the [Help](../../../Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
