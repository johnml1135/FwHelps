# Affix Templates field (Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Affix Templates**

**Location:** The **Affix Templates** field is in the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

**Description:**

This field acts as a heading below which one or more affix templates are stored for the current category (or part of speech). *Affix templates* are also referred to as *position class diagrams* or *position class charts*.

See ![](../../../../assets/images/Important_Icon.gif) **Important - Category Hierarchy** in [Category Edit overview](../../../../Using_Tools/Grammar_tools/Category_Edit/Category_Edit_overview.md) to learn about hierarchy of categories.

[Parsers](../../../Menus/Parser/Parsing_words_overview.md) use the data in tables.

**Tasks:**

- Click the ![](../../../../assets/images/minus_sign_box.GIF) (minus sign) to hide the table and associated fields; click the ![](../../../../assets/images/Plus_sign_box.GIF) (plus sign) to show them.

- Click or right-click the **Affix Templates** field label to display the menu button ![](../../../../assets/images/User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Menu_Button_pic.GIF) and the [Insert Affix Template](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_an_affix_template.md) link. These commands appear:

  - [Delete Affix Template](../../../../Using_Tools/Grammar_tools/Category_Edit/Delete_an_Affix_Template.md)

  - [Duplicate Affix Template](../../../../Using_Tools/Grammar_tools/Category_Edit/Duplicate_an_affix_template.md)

- [Edit an affix template](../../../../Using_Tools/Grammar_tools/Category_Edit/Edit_an_Affix_Template_Table.md)

- **See also:** [Category Edit overview](../../../../Using_Tools/Grammar_tools/Category_Edit/Category_Edit_overview.md)

**Field type:** Not Editable

**Writing systems:** Not Applicable

**Grammar Sketch:** Not Applicable

**Tip:** The sample project, called **Sena 3**, is included with each typical installation of FieldWorks. It has affix template tables you can use as examples.
