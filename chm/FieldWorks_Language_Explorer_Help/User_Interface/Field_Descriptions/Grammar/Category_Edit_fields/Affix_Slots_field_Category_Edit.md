# Affix Slots field (Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Affix Slots**

**Location:** This **Affix Slots** field is in the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), below the **Affix Templates** field sets.

**Description:** The **Affix Slots** field acts as a heading below which one or more affix slots *may* be stored for the category (or part of speech). Affix slots may be stored at the top-most parent category in the hierarchical category list, *or* in a subcategory or sub-subcategory. You control where the slot is stored and its availability to the dialog box.

**Tasks:**

- Click the ![](../../../../assets/images/minus_sign_box.GIF) (minus sign) to hide the fields associated affix slots; click the ![](../../../../assets/images/Plus_sign_box.GIF) (plus sign) to show them.

- Click or right-click the **Affix Slots** field label to display a menu button ![](../../../../assets/images/User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Menu_Button_pic.GIF) and the [Insert affix slot](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_an_Affix_Slot.md) link.

- [Change the optionality of a slot](../../../../Using_Tools/Grammar_tools/Category_Edit/Change_the_optionality_of_a_slot.md)
