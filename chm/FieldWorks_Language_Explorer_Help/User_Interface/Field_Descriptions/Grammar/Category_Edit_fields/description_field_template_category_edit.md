# Description field (Template - Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Description**

**Location:** There is a **Description** field in the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)) above *each* **Table** field.

**Description:** This field stores the description of the current affix template table.

**Tasks:**

- [Edit an affix template](../../../../Using_Tools/Grammar_tools/Category_Edit/Edit_an_Affix_Template_Table.md)

- [Insert an affix template](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_an_affix_template.md)

- **See also:** [Category Edit overview](../../../../Using_Tools/Grammar_tools/Category_Edit/Category_Edit_overview.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) — allows embedded [writing systems](../../../Menus/Format/select_a_writing_system.md) and [styles](../../../Menus/Format/apply_a_style_to_text.md)

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Grammar Sketch:** Under **Inflection**
