# Features field (Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Features**

**Location:** This **Features** field appears in the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), above the **Stem Allomorph Labels** field.

**Description:** This field acts as a heading below which one [Inflectable Features field](Inflectable_Features_field_Category_Edit.md) appears.

**Tasks:**

- Click the ![](../../../../assets/images/minus_sign_box.GIF) (minus sign) to hide the fields associated with features; click the ![](../../../../assets/images/Plus_sign_box.GIF) (plus sign) to show them.

- [Choose inflectable features](../../../../Using_Tools/Grammar_tools/Category_Edit/Choose_inflectable_features.md)

- **See also:** [Category Edit overview](../../../../Using_Tools/Grammar_tools/Category_Edit/Category_Edit_overview.md)

**Field type:** Not Editable

**Writing systems:** Not Applicable

**Grammar Sketch:** Not Applicable

**Tip:** For more information regarding features, point to **Resources** on the [Help](../../../Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
