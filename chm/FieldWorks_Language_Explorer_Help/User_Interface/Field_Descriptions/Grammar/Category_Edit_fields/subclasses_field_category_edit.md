# Subclasses field (Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Subclasses**

**Location:** One or more **Subclasses** fields can appear in the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), below the **Inflection Class Info** field.

**Description:** Each field acts as a header below which a *subclass* (**Subclass Name** field, **Abbreviation** field and **Description** field) for the current *inflection class* are stored.

- [Delete an inflection class or subclass](../../../../Using_Tools/Grammar_tools/Category_Edit/delete_an_inflection_class_or_subclass.md)
