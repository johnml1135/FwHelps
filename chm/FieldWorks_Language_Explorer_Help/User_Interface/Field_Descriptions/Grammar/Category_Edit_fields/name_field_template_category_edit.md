# Name field (Template Name - Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Template Name**

**Location:** There is a **Template Name** field in the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)) above *each* **Table** field.

**Description:** Each field stores the name of the current [affix template table](../../../../Using_Tools/Grammar_tools/Category_Edit/affix_template_table_example.md). The name can appear in the [Try a Word](../../../Menus/Parser/Try_a_word.md) dialog box.

**Tasks:**

- [Insert an affix template table](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_an_affix_template.md)

- Click or right-click the **Template Name** field label to display a menu button ![](../../../../assets/images/User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Menu_Button_pic.GIF). The menu commands include:

  - [Delete Affix Template](../../../../Using_Tools/Grammar_tools/Category_Edit/Delete_an_Affix_Template.md)

  - [Duplicate Affix Template](../../../../Using_Tools/Grammar_tools/Category_Edit/Duplicate_an_affix_template.md)

  - [Move Affix Template Up or Down](../../../../Using_Tools/Grammar_tools/Category_Edit/Move_an_Affix_Template.md)

**See also:** [Category Edit overview](../../../../Using_Tools/Grammar_tools/Category_Edit/Category_Edit_overview.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you cannot embed characters in other writing systems or embed styles.

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Grammar Sketch:** Under **Inflection**

**Tip:** A sample project, called **Sena 3**, is included with each typical installation of FieldWorks. It has some affix template tables you may use as examples.
