# Table field

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Table**

**Location:** This **Table** field is in the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), below the **Affix Templates** field.

**Description:**

Each **Table** field stores one affix template table.

[Parsers](../../../Menus/Parser/Parsing_words_overview.md) and [Stem Allmorph Labels](Stem_Allomorph_Label_field.md) use the content in tables.

**Tasks:**

- [Change the optionality of a slot](../../../../Using_Tools/Grammar_tools/Category_Edit/Change_the_optionality_of_a_slot.md)

- [Delete an affix slot](../../../../Using_Tools/Grammar_tools/Category_Edit/Delete_an_Affix_Slot.md)

- [Delete an affix template](../../../../Using_Tools/Grammar_tools/Category_Edit/Delete_an_Affix_Template.md)

- [Duplicate an affix template](../../../../Using_Tools/Grammar_tools/Category_Edit/Duplicate_an_affix_template.md)

- [Edit an affix template](../../../../Using_Tools/Grammar_tools/Category_Edit/Edit_an_Affix_Template_Table.md)

- [Insert an affix slot](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_an_Affix_Slot.md)

- [Insert an affix template](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_an_affix_template.md)

- **See also:** [Category Edit overview](../../../../Using_Tools/Grammar_tools/Category_Edit/Category_Edit_overview.md)

**Field type:** Stores an editable table

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) or vernacular – you cannot embed characters in other writing systems or embed styles.

**Grammar Sketch:** Under **Inflection**

> [!TIP]
>
> - [Edit an affix template](../../../../Using_Tools/Grammar_tools/Category_Edit/Edit_an_Affix_Template_Table.md) includes steps to move slots to reorder them.
>
> - A sample project, called **Sena 3**, is included with each typical installation of FieldWorks. It has affix template tables you can use as examples.
>
> - For a [custom](../../../Menus/Tools/Custom_Fields/add_a_custom_field.md) single-line text field you add in Lexicon Edit, you can use USFM markers to format the data to make a [table](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Format_a_table.md).
