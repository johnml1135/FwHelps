# Name field (Inflection Class - Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:**

**Inflection Class Name** for each top-level inflection class.

**Subclass Name** for each inflection class subclass.

**Location:** Each **Inflection Class Name** field is in the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), below the **Inflection Class Info** field. Each **Subclass Names** field is below a [Subclasses field](subclasses_field_category_edit.md).

**Description:**

The **Inflection Class Name** field stores the name of the current inflection class.

The **Subclass Name** field stores the name of the current inflection class subclass.

These names are used in the [Inflection Class field](../../Lexicon/Lexicon_Edit_fields/Grammatical_Info_Details_fields/Inflection_Class_field_Lex_Edit.md), [From Inflection Class field](../../Lexicon/Lexicon_Edit_fields/Grammatical_Info_Details_fields/from_inflection_class_field.md) and [To Inflection Class field](../../Lexicon/Lexicon_Edit_fields/Grammatical_Info_Details_fields/To_Inflection_Class_field.md) (**Lexicon Edit**). You can [choose](../../../../Using_Tools/Grammar_tools/Category_Edit/choose_a_default_inflection_class.md) an inflection class for the [Default Inflection Class field](Default_Inflection_Class_field.md).
