# Subcategory field (Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Subcategory**

**Location:** One or more **Subcategory** fields can appear in the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), below the [Subcategories field](Subcategories_field_Category_Edit.md).

**Description:** Each **Subcategory** field references the [name](rlt1edc.md) of *one* subcategory (a category that is hierarchically under the current category). You can create your own hierarchical structure or use the one in the [Add from Catalog](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Using_Add_from_Catalog_dialog_box.md) dialog box.

**Tasks:**

- [Delete a category or subcategory](../../../../Using_Tools/Grammar_tools/Category_Edit/Delete_a_Category_or_Subcategory.md)

- [Insert a subcategory](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_a_Subcategory.md)

- It is possible to edit the content of this field, but it is recommended that you click the subcategory in the center pane. Then, you can edit that subcategory while it is fully displayed in the **Category (or Part of Speech)** pane.

- **See also:** [Category Edit overview](../../../../Using_Tools/Grammar_tools/Category_Edit/Category_Edit_overview.md)

**Field type:** [Single-line text](../../Field_Types/Single_line_text_field.md) – you cannot embed characters in other writing systems, or embed styles.

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Grammar Sketch:** Under **Word categories**
