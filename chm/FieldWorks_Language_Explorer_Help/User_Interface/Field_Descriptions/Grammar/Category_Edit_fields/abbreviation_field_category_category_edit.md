# Abbreviation field (Category - Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Abbreviation**

**Location:** This **Abbreviation** field is near the top of the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), above the **Affix Templates** field.

**Description:**

The field stores the abbreviation of the current [named](rlt1edc.md) category, such as "`V`" (for "`Verb`") or subcategory, such as "**vi**" (for "**Intransitive verb**").

The abbreviation appears in the [dictionary](../../../../Using_Tools/Lexicon_tools/Dictionary/Dictionary_overview.md) and other locations, such as:

- **Grammatical Info** [columns](../../../../Basic_Tasks/Configure_Columns/Configure_Columns_overview.md) (browse panes and views)

- **Category** box drop-down list in [New Entry](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Create_a_lexical_entry.md) dialog box

- [Try a Word](../../../Menus/Parser/Try_a_word.md) dialog box.\

**Tasks:**

- [Insert a category](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_a_Category.md)

- [Insert a subcategory](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_a_Subcategory.md)

- [Use the Add from Catalog dialog box](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Using_Add_from_Catalog_dialog_box.md)

- You can [configure the dictionary](../../../Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) to show this abbreviation when you configure **Category Info** (under [Grammatical Info](../../../Menus/Tools/Configure_Dictionary/Grammatical_Info.md)).

- **See also:** [Category Edit overview](../../../../Using_Tools/Grammar_tools/Category_Edit/Category_Edit_overview.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles.

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Grammar Sketch:** Under **Word Categories** and **Derivation**. Also, under **Compounding** if the category is used in a compound rule.
