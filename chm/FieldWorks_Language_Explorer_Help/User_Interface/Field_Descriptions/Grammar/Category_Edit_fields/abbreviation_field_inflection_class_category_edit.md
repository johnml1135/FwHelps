# Abbreviation field (Inflection Class - Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Abbreviation**

**Location:**

In the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), an **Abbreviation** field appears below *each* [Inflection Class Name field](name_field_inflection_class_category_edit.md).

For inflection class subclasses, each **Abbreviation** field is below a [Subclasses field](subclasses_field_category_edit.md).

**Description:**

Each field stores the abbreviation of the current inflection class or subclass, such as "`II`" for "`2nd nominal declension`."

Abbreviations are used in **Grammatical Info** fields and in columns displayed in the various [Lexicon area](../../../../Using_Tools/Lexicon_tools/Lexicon_overview.md) browse panes or views (**Browse**, **Bulk Edit Entries** and so on, excluding those marked "(**Full**)").

The [Try a Word](../../../Menus/Parser/Try_a_word.md) dialog box uses them.

**Tasks:**

- [Insert an inflection class](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_an_Inflection_Class.md)

- [Insert an inflection class subclass](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_an_Inflection_Class_Subclass.md)

- **See also:** [Category Edit overview](../../../../Using_Tools/Grammar_tools/Category_Edit/Category_Edit_overview.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you cannot embed characters in other writing systems or embed styles.

**Writing systems:** One or more [analysis](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Grammar Sketch:** These abbreviations do *not* currently appear in the **Grammar Sketch**.
