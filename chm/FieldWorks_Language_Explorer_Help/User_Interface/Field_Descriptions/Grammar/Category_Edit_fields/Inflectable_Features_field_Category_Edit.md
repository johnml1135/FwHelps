# Inflectable Features field (Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Inflectable Features**

**Location:** There is one **Inflectable Features** field in the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)). It is below the [Features field](features_field_category_edit.md).

**Description:**

The field references and displays one or more inflection features from [Inflection Features](../../../../Using_Tools/Grammar_tools/Inflection_Features/Inflection_Features_overview.md).

For a given category, only inflection features in this field are available for use in the various **Inflection Features** fields (**Lexicon Edit**) and in [Feature Set fields](Feature_Set_field_Category_Edit.md) (**Category Edit**).

[Parsers](../../../Menus/Parser/Parsing_words_overview.md) use these features.
