# Inflection Class Info field (Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Inflection Class Info**

**Location:** This **Inflection Class Info** field is in the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), below the [Affix Slots field](Affix_Slots_field_Category_Edit.md).

**Description:** This field acts as a heading below which one or more inflection classes and subclasses are stored for the current category (or part of speech).

**Tasks:**

- Click the ![](../../../../assets/images/minus_sign_box.GIF) (minus sign) to hide the fields associated with inflection class info; click the ![](../../../../assets/images/Plus_sign_box.GIF) (plus sign) to show them.

- Click or right-click the **Inflection Class Info** field label to display a menu button ![](../../../../assets/images/User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Menu_Button_pic.GIF) and [Insert Inflection Class](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_an_Inflection_Class.md) link.

- [Delete an inflection class or subclass](../../../../Using_Tools/Grammar_tools/Category_Edit/delete_an_inflection_class_or_subclass.md)

- [Edit an affix template](../../../../Using_Tools/Grammar_tools/Category_Edit/Edit_an_Affix_Template_Table.md)

- [Insert an inflection class subclass](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_an_Inflection_Class_Subclass.md)

- **See also:** [Category Edit overview](../../../../Using_Tools/Grammar_tools/Category_Edit/Category_Edit_overview.md)

**Field type:** Not Editable

**Writing systems:** Not Applicable

**Grammar Sketch:** Not Applicable
