# Feature Set field – Stem Allomorph Labels (Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Feature Set**

**Location:** One or more **Feature Set** fields can appear in the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), below the [Feature Sets field](Feature_Sets_field_Category_Edit.md).

**Description:**

Each **Feature Set** field stores a set of inflection features for the current [Stem Allomorph Label](Stem_Allomorph_Label_field.md).

The inflection features available for selection here are those entered in the [Inflectable Features field](Inflectable_Features_field_Category_Edit.md) for the current category *or* in a parent category. You can see the hierarchical structure in the center pane.

**Example:**

Suppose an **Inflectable Features** field contained **mood and modality** and **aspect**.

A **Feature Set** field could then contain the features *and values* such as **\[mood:commis asp:aor\]**. Correspondingly, the Grammar Sketch would include **\[mood and modality:commissive modality; aspect:aorist aspect\]**. [Insert a Stem Allomorph Label](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_a_Stem_Allomorph_Label.md) has more information.
