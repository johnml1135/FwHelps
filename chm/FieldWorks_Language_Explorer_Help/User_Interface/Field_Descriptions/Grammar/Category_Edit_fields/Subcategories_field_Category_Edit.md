# Subcategories field (Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Subcategories**

**Location:** This **Subcategories** field is near the bottom of the **Category (or Part of Speech)** pane in **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

**Description:** This field acts as a heading below which one or more [Subcategory fields](Subcategory_field_Category_Edit.md) may appear.

**Tasks:**

- Click the ![](../../../../assets/images/minus_sign_box.GIF) (minus sign) to hide the fields associated with subcategories; click the ![](../../../../assets/images/Plus_sign_box.GIF) (plus sign) to show them.

- Click or right-click the **Subcategories** field label to display a menu button ![](../../../../assets/images/User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Menu_Button_pic.GIF) and the [Insert Subcategory](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_a_Subcategory.md) link.

- [Delete a category or subcategory](../../../../Using_Tools/Grammar_tools/Category_Edit/Delete_a_Category_or_Subcategory.md)

- **See also:** [Category Edit overview](../../../../Using_Tools/Grammar_tools/Category_Edit/Category_Edit_overview.md)

**Field type:** Not Editable

**Writing systems:** Not Applicable

**Grammar Sketch:** Not Applicable
