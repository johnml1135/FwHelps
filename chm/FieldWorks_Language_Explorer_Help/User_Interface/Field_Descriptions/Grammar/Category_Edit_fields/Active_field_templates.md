# Active field Templates

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Active**

**Location:** There is an **Active** field above *each* **Table** field in the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

**Description:**

You can select or clear this check box to see what effect the associated affix template has on [parsing](../../../Menus/Parser/Parsing_words_overview.md).

- Selected (![](../../../../assets/images/CheckedBox.PNG)) means:

  - The associated template is available for use by either parser the next time you run one of them.

  - The contents in that affix template are included in the grammar sketch.

- Cleared (![](../../../../assets/images/UncheckedBox.PNG)) means:

  - The associated template is *not* available to either parser, and is therefore ignored the next time you run one of them.

    As seen in [Word Analyses](../../../../Using_Tools/Texts_&_Words_tools/Word_Analyses/Word_Analyses_overview.md), clearing this check box has the same effect as if you had deleted the template; but the template is not actually deleted.

    The font changes to a lighter color, which indicates it is not active. However, you can continue to edit inactive templates.

- The contents in the affix template are not included in the grammar sketch.\
