# Feature Sets field – Stem Allomorph Labels (Category Edit)

*User Interface › Field Descriptions › Grammar › Category Edit fields*

**Full name:** **Feature Sets**

**Location:** The **Feature Sets** field is in the **Category (or Part of Speech)** pane of **Category Edit** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), below the **Stem Allomorph Labels** field.

**Description:** This field acts as a header below which one or more [Feature Set fields](Feature_Set_field_Category_Edit.md) are stored for the current [Stem Allomorph Label](Stem_Allomorph_Label_field.md).

**Tasks:**

- Click or right-click the field label to display a menu button ![](../../../../assets/images/User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Menu_Button_pic.GIF) and the [Insert Feature Set](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_a_Feature_Set.md) link.

- [Choose inflection features for a Feature Set](../../../../Using_Tools/Grammar_tools/Category_Edit/Choose_Inflection_features.md)

- [Delete a Feature Set](../../../../Using_Tools/Grammar_tools/Category_Edit/Delete_a_Feature_Set.md)

- [Insert a Stem Allomorph Label](../../../../Using_Tools/Grammar_tools/Category_Edit/Insert_a_Stem_Allomorph_Label.md)

- **See also:** [Category Edit overview](../../../../Using_Tools/Grammar_tools/Category_Edit/Category_Edit_overview.md)

**Field type:** Not Editable

**Writing systems:** Not Applicable

**Grammar Sketch:** Not Applicable
