# Grapheme field (Phonemes)

*User Interface › Field Descriptions › Grammar › Phonemes fields*

**Full name:** **Grapheme**

**Location:** **Phoneme** pane of **Phonemes** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)), below the **In Orthography as** label.

**Description:**

This field stores one grapheme for the current phoneme, identified in the [Refer to as](name_field_phonemes.md) field. You can [insert](../../../../Using_Tools/Grammar_tools/Phonemes/Insert_a_representation.md) any number of **Grapheme** fields. Insert a **Grapheme** field for each *additional* way that the phoneme is written in your orthography

Graphemes may be used in [environments](../Environments_fields/String_Representation_field_Environments.md), and then these can be used by a [parser](../../../Menus/Parser/Parsing_words_overview.md).

**Tasks:**

- [Delete a grapheme](../../../../Using_Tools/Grammar_tools/Phonemes/Delete_a_representation.md)

- [Edit a phoneme](../../../../Using_Tools/Grammar_tools/Phonemes/Edit_a_phoneme.md)

- **See also:** [Phonemes overview](../../../../Using_Tools/Grammar_tools/Phonemes/Phonemes_overview.md)

**Field type:** [Single-line text field](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles.

**Writing systems:** One or more [vernacular](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md); enter graphemes are in whatever writing system the practical orthography is in.

**Grammar Sketch:** Under **Phonemes**

**Tip:**

- A *grapheme* is anything that functions as a distinct unit within an orthography. A grapheme may be a single character, a multigraph, or a diacritic, but in all cases graphemes are defined in relation to the particular orthography.

- Avoid using archiphonemes that are uppercase equivalents of a character in the orthography if you use the Hermit Crab [parser](../../../Menus/Parser/Phonological_Rule_Based_parser_overview.md).

Section B.2.6 in the document **A Conceptual Introduction to Morphological Parsing** has more information. It is available on the [Help menu](../../../Menus/Help/Help_overview.md).
