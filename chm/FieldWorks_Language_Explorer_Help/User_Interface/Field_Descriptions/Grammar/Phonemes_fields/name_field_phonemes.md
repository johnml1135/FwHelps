# Refer to as field (Phonemes)

*User Interface › Field Descriptions › Grammar › Phonemes fields*

**Full name:** **Refer to as**

**Location:** **Phoneme** pane of **Phonemes** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md))

**Description:**

The content in this field should be the basic phoneme, that is, the typical way people would refer to this phoneme.

This field and the *first* [Grapheme field](representation_field_phonemes.md) will usually have the same content.

([Insert a grapheme](../../../../Using_Tools/Grammar_tools/Phonemes/Insert_a_representation.md) for each *additional* way that the phoneme is written in your orthography. Use the [IPA Symbol field](Basic_IPA_Symbol_fld_(Phms).md) for the IPA character.)

The **Refer to as** field content can appear in a number of places, including the following:

- [Phonemes field](../Natural_Classes_fields/Phonemes_field_Natural_Classes.md) (when used in a [natural class](../../../../Using_Tools/Grammar_tools/Natural_Classes/Natural_classes_overview.md))

- [Rule Formula field](../Phonologocial_Rules_fields/Rule_Formula_field_(Ph_Rules).md)

- [Affix Process Rule field](../../Lexicon/Lexicon_Edit_fields/Entry_level_fields/Affix_Process_Rule_field.md)

- associated dialog boxes.\

**Writing systems:** One or more [vernacular](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)

**Grammar Sketch:** In **Phonemes**, tables display the phonemes, graphemes, IPA symbols, and so on. In **Natural Classes**, phonemes used with natural classes are listed.
