# In Orthography as field (Phonemes)

*User Interface › Field Descriptions › Grammar › Phonemes fields*

**Full name:** **In Orthography as**

**Location:** **Phoneme** pane of **Phonemes** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md))

**Description:** Below **In Orthography as** there are one or more [Grapheme fields](representation_field_phonemes.md). In them you enter all of the different ways the phoneme is written (appears) in the orthography.

**Tasks:**

- Click the ![](../../../../assets/images/minus_sign_box.GIF) (minus sign) to hide the associated fields such as **Grapheme**; click the ![](../../../../assets/images/Plus_sign_box.GIF) (plus sign) to show them.

- Click or right-click **In Orthography as** to display a menu button ![](../../../../assets/images/Menu_Button_pic.GIF) and an [Insert Grapheme](../../../../Using_Tools/Grammar_tools/Phonemes/Insert_a_representation.md) link.

- The **Field Visibility** menu command allows you to hide or show this label *and* all the fields below it. If necessary, select **Show Hidden Fields** to display fields you cannot see, and then select different **Field Visibility** options for fields individually.

- **See also:** [Phonemes overview](../../../../Using_Tools/Grammar_tools/Phonemes/Phonemes_overview.md)

**Field type:** Not Editable

**Writing systems:** Not Applicable

**Grammar Sketch:** Not Applicable
