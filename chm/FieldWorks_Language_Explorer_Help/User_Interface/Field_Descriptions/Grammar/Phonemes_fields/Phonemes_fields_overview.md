# Phonemes fields overview

*User Interface › Field Descriptions › Grammar › Phonemes fields*

The descriptions of the fields in **Phonemes** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)) are the following:

|                                                         |
|---------------------------------------------------------|
| **Field Label**                                         |
| [Refer to as](name_field_phonemes.md)                   |
| [IPA Symbol](Basic_IPA_Symbol_fld_(Phms).md)            |
| [Description](description_field_phonemes.md)            |
| [Phonological Features](Phonological_Features_field.md) |
| [In Orthography as](representations_field_phonemes.md)  |
| [Grapheme](representation_field_phonemes.md)            |

> [!TIP]
>
> - Except for the **In Orthography as** label, each of the fields above have a corresponding [column](../../../../Basic_Tasks/Configure_Columns/Configure_Columns_overview.md) in the **Phonemes** pane.
>
> - [Phonological Features field](Phonological_Features_field.md) contains a description of phonological features, rules and phonemes.
>
> - If your orthography uses multigraphs, and you will use [Pathway](../../../Menus/File/Pathway_Configuration_Tool/Export_Through_Pathway.md) to export your data, see [Pathway multigraphs](../../../Menus/File/Pathway_Configuration_Tool/Pathway_multigraphs.md).
>
> - For more information, point to **Resources** on the [Help](../../../Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
