# Active field (Ph Rules)

*User Interface › Field Descriptions › Grammar › Phonological Rules fields*

**Full name:** **Active**

**Location:** There is an **Active** field associated with *each* rule in **Phonological Rules** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

**Description:**

You can select or clear this check box to see what effect the rule has on [parsing](../../../Menus/Parser/Parsing_words_overview.md), if you use the [phonological (Hermit Crab) parser](../../../Menus/Parser/Phonological_Rule_Based_parser_overview.md).

- Selected (![](../../../../assets/images/CheckedBox.PNG)) means:

  - The rule is available for use the next time you run the phonological parser.

  - The **Active** column shows ![](../../../../assets/images/CheckedBox.PNG) **yes**.

  - The rule is included in the grammar sketch.

- Cleared (![](../../../../assets/images/UncheckedBox.PNG)) means:

  - The rule is *not* available to the phonological parser, and is therefore ignored the next time you run it.

    As seen in [Word Analyses](../../../../Using_Tools/Texts_&_Words_tools/Word_Analyses/Word_Analyses_overview.md), clearing this check box has the same effect as if you had deleted the rule; but the rule is not actually deleted.

    The font changes to a lighter color, which indicates the rule is not active. However, you can continue to edit an inactive rule.

  - The **Active** column shows ![](../../../../assets/images/UncheckedBox.PNG) **no**.

  - The rule is not included in the grammar sketch, regardless of which parser you use.

**Field type:** Check box

**Writing systems:** Not Applicable
