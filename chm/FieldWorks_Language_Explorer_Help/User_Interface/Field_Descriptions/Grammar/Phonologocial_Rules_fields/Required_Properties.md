# Required Properties

*User Interface › Field Descriptions › Grammar › Phonological Rules fields*

**Full name:** **Required Properties**

**Locations:** The **Required Properties** field is near the top of the **Phonological Rule** pane (*not* **Metathesis Rule** pane) in **Phonological Rules** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

**Description:**

This field stores exceptions "features" and inflection classes.

If you put one or more exception "features" and/or inflection classes in this field, then the phonological rule will only be applied when the stem has *all* the indicated exception "features" and inflection classes.

- [Choose required properties](../../../../Using_Tools/Grammar_tools/Phonological_Rules/Choose_required_properties.md)

**Field type:** [List Reference](../../Field_Types/Single_line_text_field.md)

**Writing systems:** English

**Grammar Sketch:** Appears in the **Grammar Sketch**, below **Phonological Rules**.

**Tip:** For more information, point to **Resources** on the [Help](../../../Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
