# Description field (Ph Rules)

*User Interface › Field Descriptions › Grammar › Phonological Rules fields*

**Full name:** **Description**

**Locations:** This **Description** field is near the top of the **Phonological Rule** pane or **Metathesis Rule** pane in **Phonological Rules** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

**Description:**

This field stores the description of the current phonological rule. Ideally, the description describes in words what the effect of the rule is. The idea is that even if someone does not understand the notations of the rule, they will still be able to understand what the rule does.

The phonological rule-based [parser](../../../Menus/Parser/Parsing_words_(HermitCrab).md) uses phonological rules.
