# Required Categories

*User Interface › Field Descriptions › Grammar › Phonological Rules fields*

**Full name:** **Required Categories**

**Locations:** The **Required Categories** field is near the top of the **Phonological Rule** pane (*not* **Metathesis Rule** pane) in **Phonological Rules** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

**Description:**

This field stores grammatical categories to constrain the phonological rule so that it will only apply when certain grammatical categories are present in the word.

*Category hierarchy is respected*. That is, if you specify that a particular phonological rule should only apply when a particular category is present, then that rule will only apply if that category or any of its subcategories (or their subcategories) are present.

This rule will apply *only* if the category of the word being parsed matches one of the categories selected in this field.
