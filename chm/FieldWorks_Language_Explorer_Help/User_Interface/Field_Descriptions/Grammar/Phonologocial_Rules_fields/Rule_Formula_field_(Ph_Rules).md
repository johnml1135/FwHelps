# Rule Formula field (Ph Rules)

*User Interface › Field Descriptions › Grammar › Phonological Rules fields*

**Full name:** **Rule Formula**

**Locations:** The **Rule Formula** field is in the **Phonological Rule** pane or **Metathesis Rule** pane in **Phonological Rules** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

**Description:**

This field stores the formula of the current rule. Rules in this field cannot be displayed in the **Phonological Rules** pane (center pane).

The phonological rule-based [parser](../../../Menus/Parser/Parsing_words_(HermitCrab).md) uses phonological rules.

**Tasks:**

- Click the ![](../../../../assets/images/minus_sign_box.GIF) (minus sign) to hide the rule formula; click the ![](../../../../assets/images/Plus_sign_box.GIF) (plus sign) to show it.

- [Insert a phonological or metathesis rule](../../../../Using_Tools/Grammar_tools/Phonological_Rules/Insert_a_phonological_rule.md)

  - [Build a phonological rule](../../../../Using_Tools/Grammar_tools/Phonological_Rules/Build_a_phonological_rule.md)

  - [Build a metathesis rule](../../../../Using_Tools/Grammar_tools/Phonological_Rules/Build_a_metathesis_rule.md)

- [Delete a phonological rule](../../../../Using_Tools/Grammar_tools/Phonological_Rules/Delete_a_phonological_rule.md)

- [Set occurrence (min. and max.)](../../../../Using_Tools/Grammar_tools/Phonological_Rules/Set_occurrence.md)

- [Set Phonological Features](../../../../Using_Tools/Grammar_tools/Phonological_Rules/Set_phonological_features.md)

- **See also:** [Phonological Rules overview](../../../../Using_Tools/Grammar_tools/Phonological_Rules/Phonological_Rules_overview.md)

**Field type:** A unique formula field

**Writing systems:** Some items use the [user interface language](../../../Menus/Tools/Options/Change_Interface_Language.md). Other items, such as [phonemes](../Phonemes_fields/name_field_phonemes.md), use a vernacular writing system. Other items, such as a natural class [abbreviation](../Natural_Classes_fields/Abbreviation_field_Natural_Classes.md), use a "best analysis" writing system. That is, if content does not exist in the default analysis writing system, then it will look for content in the next analysis writing system.

**Grammar Sketch:** Under **Phonological Rules**

**Tip:**

- [Phonological Features field](../Phonemes_fields/Phonological_Features_field.md) contains a description of phonological features, rules and phonemes.
