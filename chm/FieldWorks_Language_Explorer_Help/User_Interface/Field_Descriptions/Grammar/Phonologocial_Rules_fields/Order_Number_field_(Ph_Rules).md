# Order Number field (Ph Rules)

*User Interface › Field Descriptions › Grammar › Phonological Rules fields*

**Full name:** **Order Number**

**Locations:** The **Order Number** field is near the top of the **Phonological Rule** pane or **Metathesis Rule** pane in **Phonological Rules** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

**Description:** This field stores the number of the current rule. The order of the rules is very important to the phonological rule-based [parser](../../../Menus/Parser/Parsing_words_(HermitCrab).md).

**Tasks:**

- [Insert a phonological or metathesis rule](../../../../Using_Tools/Grammar_tools/Phonological_Rules/Insert_a_phonological_rule.md)

  - [Build a phonological rule](../../../../Using_Tools/Grammar_tools/Phonological_Rules/Build_a_phonological_rule.md)

  - [Build a metathesis rule](../../../../Using_Tools/Grammar_tools/Phonological_Rules/Build_a_metathesis_rule.md)

- [Delete a phonological rule](../../../../Using_Tools/Grammar_tools/Phonological_Rules/Delete_a_phonological_rule.md)

- [Specify the order of phonological rules](../../../../Using_Tools/Grammar_tools/Phonological_Rules/Specify_order_number.md)

- **See also:** [Phonological Rules overview](../../../../Using_Tools/Grammar_tools/Phonological_Rules/Phonological_Rules_overview.md)

**Field type:** [Single-line text](../../Field_Types/Single_line_text_field.md) – you *cannot* embed characters in other writing systems or embed styles, nor can you choose the writing system to use in this field.

**Writing systems:** English

**Grammar Sketch:** Order numbers do *not* appear in the **Grammar Sketch**.

**Tip:** For more information, point to **Resources** on the [Help](../../../Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
