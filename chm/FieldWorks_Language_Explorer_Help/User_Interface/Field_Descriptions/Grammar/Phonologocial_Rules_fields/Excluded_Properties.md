# Excluded Properties

*User Interface › Field Descriptions › Grammar › Phonological Rules fields*

**Full name:** **Excluded Properties**

**Locations:** The **Excluded Properties** field is near the top of the **Phonological Rule** pane (*not* **Metathesis Rule** pane) in **Phonological Rules** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

**Description:**

This field stores exception "features" and inflection classes.

If you put one or more of these in the **Excluded Properties** field, then the rule will be applied only when the stem does *not* have *any* of the indicated exception "features" and/or inflection classes.

**Tasks:**

- [Choose excluded properties](../../../../Using_Tools/Grammar_tools/Phonological_Rules/Choose_excluded_properties.md)

- **See also:** [Phonological Rules overview](../../../../Using_Tools/Grammar_tools/Phonological_Rules/Phonological_Rules_overview.md)

**Field type:** [List Reference](../../Field_Types/Single_line_text_field.md)

**Writing systems:** English

**Grammar Sketch:** Appears in the **Grammar Sketch**, below **Phonological Rules**.

**Tip:** For more information, point to **Resources** on the [Help](../../../Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
