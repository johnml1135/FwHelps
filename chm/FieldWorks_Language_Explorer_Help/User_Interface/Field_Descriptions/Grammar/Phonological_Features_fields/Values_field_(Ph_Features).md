# Values field (Ph Features)

*User Interface › Field Descriptions › Grammar › Phonological Features fields*

**Full name:** **Values**

**Location:** The **Values** field is in the **Phonological Feature and Values** pane in **Phonological Features** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

**Description:**

This field acts as a header below which one or more *values* are stored for the current phonological feature.

The phonological rule-based [parser](../../../Menus/Parser/Parsing_words_(HermitCrab).md) uses phonological features.

**Tasks:**

- Click the ![](../../../../assets/images/minus_sign_box.GIF) (minus sign) to hide the fields associated with values; click the ![](../../../../assets/images/Plus_sign_box.GIF) (plus sign) to show them.

- Click or right-click the **Values** field label to display a menu button ![](../../../../assets/images/User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Menu_Button_pic.GIF) and the [Insert Feature Value](../../../../Using_Tools/Grammar_tools/Phonological_Features/Insert_a_phonological_feature_value.md) link so you can insert a phonological feature value.

- See also: [Phonological Features overview](../../../../Using_Tools/Grammar_tools/Phonological_Features/Phonological_Features_overview.md)

**Field type:** Not Editable

**Writing systems:** Not Applicable

**Grammar Sketch:** Not Applicable

**Tip:** For more information, point to **Resources** on the [Help](../../../Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
