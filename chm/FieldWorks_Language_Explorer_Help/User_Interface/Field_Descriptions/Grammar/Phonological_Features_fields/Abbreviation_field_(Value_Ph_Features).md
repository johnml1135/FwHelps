# Abbreviation field (Value - Ph Features)

*User Interface › Field Descriptions › Grammar › Phonological Features fields*

**Full name:** **Abbreviation**

**Locations:**

This **Abbreviation** field is under the [Values field](Values_field_(Ph_Features).md) in the **Phonological Feature and Values** pane of **Phonological Features** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)). Each value has its own **Abbreviation** field.

There is a separate [Abbreviation field](Abbreviation_field_(Ph_Features).md) for each phonological feature.

**Description:**

Each **Abbreviation** field stores the abbreviation of one [value name](Value_Name_field_(Ph_Features).md). For custom features, you enter an abbreviation here. For features added from the [catalog](../../../../Using_Tools/Grammar_tools/Phonological_Features/Using_Add_Ph_Features_Cat_dialog_box.md), the abbreviation from that catalog is copied to this field. (You can edit it here.) Because the catalog features are binary, the value abbreviation is typically a **+** or **-**.

These abbreviations can appear in places such as the following:

- **Affix Process Rule** field for the lexeme form or the [Affix Process Rule field](../../Lexicon/Lexicon_Edit_fields/Alternate_Forms_level_flds/Affix_Process_Rule_fldAF.md) for any allomorphs in **Lexicon Edit** ([Lexicon](../../../../Using_Tools/Lexicon_tools/Lexicon_overview.md)).

- **Choose Phonological Features** dialog box (**Affix Process Rule** fields in **Lexicon Edit** and from the [Phonological Features field](../Phonemes_fields/Phonological_Features_field.md) in **Phonemes** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)))

- **Rule Formula** field in **Phonological Rules** (**Grammar**).

The phonological rule-based [parser](../../../Menus/Parser/Parsing_words_(HermitCrab).md) uses phonological features.
