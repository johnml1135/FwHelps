# Value Name field (Ph Features)

*User Interface › Field Descriptions › Grammar › Phonological Features fields*

**Full name:** **Value Name**

**Locations:**

The **Value Name** field is under the [Values field](Values_field_(Ph_Features).md) **Phonological Feature and Values** pane in **Phonological Features** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)). Each value has its own **Value Name** field.

There is a separate [Name field](Name_field_(Ph_Feature).md) for each phonological feature.

**Description:**

Each **Value Name** field stores the name of one value for the current feature. For custom features, you enter a name here. For features added from the [catalog](../../../../Using_Tools/Grammar_tools/Phonological_Features/Using_Add_Ph_Features_Cat_dialog_box.md), the name from that catalog is copied to this field. Because the catalog features are binary, the value name is typically a **positive** or **negative**.

Phonological feature values appear in the **Choose Phonological Features** dialog box which you can access from the **Affix Process Rule** fields in **Lexicon Edit** ([Lexicon](../../Lexicon/Lexicon_Edit_fields/Lexicon_Edit_fields_overview.md)) and in the **Phonological Features** field in **Phonemes** ([Grammar](../Grammar_fields_overview.md)).

The phonological rule-based [parser](../../../Menus/Parser/Parsing_words_(HermitCrab).md) uses phonological features.
