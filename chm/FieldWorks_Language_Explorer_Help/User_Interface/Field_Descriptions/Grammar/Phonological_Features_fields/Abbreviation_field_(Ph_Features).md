# Abbreviation field (Ph Features)

*User Interface › Field Descriptions › Grammar › Phonological Features fields*

**Full name:** **Abbreviation**

**Locations:**

This **Abbreviation** field is near the top of the **Phonological Feature and Values** pane in **Phonological Features** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

There is a separate [Abbreviation field](Abbreviation_field_(Value_Ph_Features).md) for each value.

**Description:**

This field stores an abbreviation of the [name](Name_field_(Ph_Feature).md) of the phonological feature. For custom features, you enter an abbreviation here. For features added from the [catalog](../../../../Using_Tools/Grammar_tools/Phonological_Features/Using_Add_Ph_Features_Cat_dialog_box.md), the abbreviation from that catalog is copied to this field. You can edit it here if desired.

These abbreviations can appear in such places as the following:

- [Affix Process Rule field](../../Lexicon/Lexicon_Edit_fields/Entry_level_fields/Affix_Process_Rule_field.md) for the lexeme form or the [Affix Process Rule field](../../Lexicon/Lexicon_Edit_fields/Alternate_Forms_level_flds/Affix_Process_Rule_fldAF.md) for any allomorphs in **Lexicon Edit** ([Lexicon](../../../../Using_Tools/Lexicon_tools/Lexicon_overview.md)).

- **Choose Phonological Features** dialog box which opens from the **Affix Process Rule** fields in **Lexicon Edit** and from the [Phonological Features field](../Phonemes_fields/Phonological_Features_field.md) in **Phonemes** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

The phonological rule-based [parser](../../../Menus/Parser/Parsing_words_(HermitCrab).md) uses phonological features.
