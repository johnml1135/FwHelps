# Description field (Value - Ph Features)

*User Interface › Field Descriptions › Grammar › Phonological Features fields*

**Full name:** **Description**

**Locations:**

This **Description** field is under the [Values field](Values_field_(Ph_Features).md) in the **Phonological Feature and Values** pane of **Phonological Features** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)). Each value has its own **Abbreviation** field. Each value has its own **Description** field.

There is a separate [Description field](Description_field_(Ph_Features).md) for each phonological feature.

The phonological rule-based [parser](../../../Menus/Parser/Parsing_words_(HermitCrab).md) uses phonological features.

**Description:** Each **Description** field stores your description of the current [named](Value_Name_field_(Ph_Features).md) value.
