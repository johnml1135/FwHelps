# Description field (Ph Features)

*User Interface › Field Descriptions › Grammar › Phonological Features fields*

**Full name:** **Description**

**Locations:**

This **Description** field is near the top of the **Phonological Feature and Values** pane in **Phonological Features** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

There is a separate [Description field](Description_field_(Value_Ph_Features).md) for each value.

**Description:**

This field stores a description of the current phonological feature. For custom features, you enter a description here. For features added from the [catalog](../../../../Using_Tools/Grammar_tools/Phonological_Features/Using_Add_Ph_Features_Cat_dialog_box.md), the description from that catalog is copied to this field. You can edit it here if desired.

The phonological rule-based [parser](../../../Menus/Parser/Parsing_words_(HermitCrab).md) uses phonological features.
