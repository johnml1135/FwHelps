# Name field (Ph Feature)

*User Interface › Field Descriptions › Grammar › Phonological Features fields*

**Full name:** **Name**

**Locations:**

This **Name** field is near the top of the **Phonological Feature and Values** pane in **Phonological Features** ([Grammar](../../../../Using_Tools/Grammar_tools/grammar_overview.md)).

There is a separate [Value Name field](Value_Name_field_(Ph_Features).md) for each value below w1xzthe [Values field](Values_field_(Ph_Features).md).

**Description:**

This field stores the name of the phonological feature. For custom features, you enter a name here. For features added from the [catalog](../../../../Using_Tools/Grammar_tools/Phonological_Features/Using_Add_Ph_Features_Cat_dialog_box.md), the name from that catalog is copied to this field. You can edit it here if desired.

Phonological feature names appear in the these places:

- **Choose Phonological Features** dialog box (**Affix Process Rule** fields in **Lexicon Edit** ([Lexicon](../../Lexicon/Lexicon_Edit_fields/Lexicon_Edit_fields_overview.md)).

- **Phonological Features** field in **Phonemes** ([Grammar](../Grammar_fields_overview.md))

- **Rule Formula** [field](../Phonologocial_Rules_fields/Rule_Formula_field_(Ph_Rules).md) in **Phonological Rules** (**Grammar**).

The phonological rule-based [parser](../../../Menus/Parser/Parsing_words_(HermitCrab).md) uses phonological features.
