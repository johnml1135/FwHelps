# Get a project

*User Interface › Menus › Send/Receive*

Do the steps below to get data from a repository that was made with [Send/Receive](../../../Basic_Tasks/Collaborating_with_Others/Get_Started_with_Send_Receive.md) into a *new empty* project. It could be a project repository or a WeSay (LIFT) repository.

The process will *not merge* the repository data into an existing project data. If that is what you want to do see [Get a lexicon](Get_a_lexicon.md) and [Get started with Send/Receive](../../../Basic_Tasks/Collaborating_with_Others/Get_Started_with_Send_Receive.md).

## Prerequisites

- Review the information in the **Chorus Help** help file.

To open it, click **Help** on the [Send/Receive menu](Send_Receive_menu.md).

- Then, if the project repository you will get is

- on a USB flash drive (or USB hard drive, or similar), then insert it in or connect it to your computer.

- on the Internet, then have Login (name), and Password and Project ID available.

- in a **ChorusHub** folder, then Chorus Hub must be running on the computer that has that folder.

## Steps

1.  Open the **Receive project** dialog box in one of these ways:

    - On the [Send/Receive](Send_Receive_menu.md) menu, click ![](../../../assets/images/User_Interface/Menus/Send_Receive/GET_Icon.png)**Get Project from a Colleague**.

    - Click **Get project from a colleague** in any of these dialog boxes: [Open Project](../File/Open_a_language_project.md), [Language Explorer](../../../Overview/Welcome_to_FieldWorks.md) or [Unable to Open Project](../File/Unable_to_Open_Project.md).

2.  In the **Receive project** dialog box, click the button that corresponds to the location of the repository:

**![](../../../assets/images/User_Interface/Menus/File/usbiconSMALL.png) USB Flash Drive**

- In the **Get Project From USB Drive** dialog box, click the project. (Be aware that \<name\>\_LIFT files are *only* lexical repositories.) Click **Copy to Computer**. When done, click **OK**.

**![](../../../assets/images/User_Interface/Menus/File/interneticonSMALL.png) Internet**

- **See:** [Use the Get Project from Internet dialog box](Use_Get_Project_from_Internet_dialog_box.md).

**![](../../../assets/images/User_Interface/Menus/File/ChorusHubButton.png) Chorus Hub**

- In the **Get Project from Chorus Hub** dialog box, click the project you want. (Be aware that \<name\>\_LIFT files are *only* lexical repositories.) Click **Copy to Computer**. Click **Get**.

The project you received opens automatically.

> [!TIP]
>
> - If the file you want is listed but is *not* available for selection in the **Get Project from** dialog box, then that file is already used by/associated with another project.
