# Use the Get Project from Internet dialog box

*User Interface › Menus › Send/Receive*

This dialog box opens if you click the **Internet** button in the **Receive project** dialog box. **See:** [Get a project](Get_a_project.md) or [Get a lexicon and merge with this project](Get_a_lexicon.md).

## Lexbox (formerly *Language Depot*)

To use Lexbox, you need to register an account on <a href="https://lexbox.org/register" target="_blank" title="https://lexbox.org/register">https://lexbox.org/register</a> and then request a project. When the project is created, you will be given the information (Project ID) you need to use to access it. You can read about this on <a href="https://lexbox.org/" target="_blank" title="https://lexbox.org/">Lexbox.org</a>.

1.  **Login**: Type or paste your Lexbox log in information.

2.  **Password**: Type or paste your password.

- Select (![pic](../../../assets/images/CheckedBoxBLACK.png)) **Remember** if you want the program to remember your password.

3.  Click the **Log in** button to display more controls.

4.  **Bandwidth**: The default setting is **High Bandwidth**.

- If you have a slow or unreliable Internet connection or you have difficulty when **High Bandwidth** is selected, click the down arrow (![](../../../assets/images/User_Interface/Menus/Send_Receive/DownArrow.png)) and click **Low Bandwidth**.

5.  **Project ID**: Click the down arrow (![](../../../assets/images/User_Interface/Menus/Send_Receive/DownArrow.png)), and then click the desired project in the list.

6.  **Name for the folder on your computer**: Type or paste that name that you want to use as the name of the project folder.

7.  Click **Download**.

8.  When the download has finished, click **OK**.

## Another server

This is extremely unusual. You can normally ignore these steps.

1.  **Login**: Type or paste your log in information for this server.

2.  **Password**: Type or paste your password for this server.

- Select (![pic](../../../assets/images/CheckedBoxBLACK.png)) **Remember** if you want the program to remember your password.

3.  Select (![pic](../../../assets/images/CheckedBoxBLACK.png)) **Custom URL**.

4.  Type or paste the URL to the repository on that server.

5.  **Name for the folder on your computer**: Type or paste that name that you want to use as the name of the project folder.

6.  Click **Download**.

7.  When the download has finished, click **OK**.
