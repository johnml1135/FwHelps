# Get a lexicon

*User Interface › Menus › Send/Receive*

Do the following to get *lexical* data (*not a full project*) from a WeSay (LIFT) repository and merge that data into the currently open project. Otherwise, see [Get a project](Get_a_project.md). **See Also:** [Get started with Send/Receive](../../../Basic_Tasks/Collaborating_with_Others/Get_Started_with_Send_Receive.md).

1.  [Open](../File/Open_a_language_project.md) or [create](../File/Create_a_new_Fieldworks_project.md) the project into which you want to merge the lexical data.

2.  If the lexical repository (\<name\>**\_LIFT**) you want is

    - on a USB flash drive (or remote device), then insert it in or connect it to your computer.

    - on the Internet, then have the server, Project ID, Login and Password available.

    - in a **ChorusHub** folder, then Chorus Hub must be running on the computer that has that folder.

3.  On the **Send/Receive** menu, click ![](../../../assets/images/User_Interface/Menus/Send_Receive/GET_Icon.png)**Get Lexicon (WeSay) and Merge with this Project**.

The **Receive Project** dialog box opens.

4.  Click the button that corresponds to the location of the repository file:

**![](../../../assets/images/User_Interface/Menus/File/usbiconSMALL.png) USB Flash Drive**

1.  - In the **Get Project from USB Flash Drive** dialog box, click the \<name\>\_LIFT file. Click **Copy to Computer**.

**![](../../../assets/images/User_Interface/Menus/File/interneticonSMALL.png) Internet**

1.  - **See:** [Use the Get Project from Internet dialog box](Use_Get_Project_from_Internet_dialog_box.md).

**![](../../../assets/images/User_Interface/Menus/File/ChorusHubButton.png) Chorus Hub**

1.  - In the **Get Project from Chorus Hub** dialog box, click the \<name\>\_LIFT file. Click **Get**.

Writing systems are automatically added, if necessary, and the lexical data is merged into the current project.

> [!IMPORTANT]
>
> - You can only do this task one time for a project.
>
> This command on the **Send/Receive** menu becomes unavailable (grayed-out) after it has been used.
>
> - If the file you want is listed but is *not* available for selection in the **Get Project from** dialog box, then that file is already used by/associated with another project.
>

>
> - **Help** on the [Send/Receive menu](Send_Receive_menu.md) opens the *Chorus Help* file. You can learn more about it, how to configure *Chorus-enabled* dialog boxes, and more.
