> [!TIP]
>
> - If *FLEx Bridge* is not installed, the **Send/Receive** menu commands are not available.
>
> Windows<sup>®</sup>: Run the FieldWorks installer to modify or repair the installation. If you need the latest FLEx Bridge installer, email <Flex_devteam@sil.org>.
>
> - Send/Receive dialog boxes are *Chorus-enabled*. The **Help** button in the **Send/Receive Settings** dialog box *also* opens the *Chorus Help* file.
>
> - Review the [Send/Receive considerations](../../../Basic_Tasks/Collaborating_with_Others/Send_Receive_considerations.md).
>
> - *![](../../../assets/images/User_Interface/Menus/Send_Receive/SRGlobe.png)* **About FLEx Bridge** opens a page with a **FLEx Bridge Limitations** hyperlink. It has information you may want to know.
