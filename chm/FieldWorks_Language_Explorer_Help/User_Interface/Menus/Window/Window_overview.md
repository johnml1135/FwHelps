# Window overview

*User Interface › Menus › Window*

- On the **Window** menu, click **New Window**.

  An additional *FieldWorks Language Explorer* window appears, displaying the current project.

> [!TIP]
>
> - Sorts and filters may affect columns in a single open window differently than across multiple open windows. For example, see [Sort lexical entries](../../../Basic_Tasks/Sorting_data/Sort_lexical_entries.md) or [Filter lexical entries](../../../Basic_Tasks/Filtering_data/filter_lexical_entries.md).
