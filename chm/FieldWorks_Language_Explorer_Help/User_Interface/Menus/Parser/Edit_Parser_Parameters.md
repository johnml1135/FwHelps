# Edit parser parameters

*User Interface › Menus › Parser*

In the **Parser Parameters** dialog box, the values in the top pane control the **Default Parser (XAmple)**. The value in the bottom pane controls the **Phonological Rules-based Parser (Hermit Crab.NET)**.

1.  Review the [About parser parameters](About_parser_parameters.md) information.

2.  [Stop the parser](Start_or_Stop_Parser.md), if it is running.

3.  On the **Parser** menu, click **Edit Parser Parameters**.

    The **Parser Parameters** dialog box appears.

4.  Click and edit the content of the applicable row or column.

5.  Click **OK**.

> [!IMPORTANT]
>
> - It is recommended that you write down the initial values *before* you make any changes. If you may need to change one or more values back to the initial values, you will need to know what they were. **Restore Defaults** on the [Tools](../Tools/Restore_defaults.md) menu does *not* reset any parser parameter values.
>
> - A warning message may appear if you enter very large parameter values, such as "50,000" MaxNulls. FieldWorks will reduce large values to more reasonable values.
>
> - If you will use the Hermit Crab parser, see [About the Novel Root Guesser](About_the_Novel_Root_Guesser.md).
