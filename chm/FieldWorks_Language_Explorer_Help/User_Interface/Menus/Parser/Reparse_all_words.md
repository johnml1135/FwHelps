# Reparse all words

*User Interface › Menus › Parser*

1.  On the **Parser** menu, click **Reparse all words**.

2.  When the selected parser is finished, as indicated on the [status bar](../../Toolbars/status_bar.md), [refresh](../View/View_overview.md) the window.

> [!TIP]
>
> - This **Parser** menu command is available after the parser has been [started](Start_or_Stop_Parser.md).
>
> - There is also a **Parser** menu command you can use to reload the grammatical information.
