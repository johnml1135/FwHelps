# Start or stop the parser

*User Interface › Menus › Parser*

## *Start* the parser

- Click any of these **Parser** menu commands to start the *currently selected* parser:

  - **Parse all words** to parse all words in the [word list](../../../Using_Tools/Texts_&_Words_tools/Word_list_overview.md).

  - **Try a Word** to parse a particular word in the [Try a Word](Try_a_word.md) dialog box.

  - **Parse Words in Text** to parse *only* the words in the text that is currently displayed.

  - **Parse Current Word** to parse the particular word that is selected in the **Wordforms** pane (**Word List Concordance**, **Word Analyses** or **Bulk Edit Wordforms**).

In some cases, it may take 5 minutes or more to initially load the lexical and grammatical data. Reloading is usually much quicker.

## *Stop* the parser

- On the **Parser** menu, click **Stop Parser**.
