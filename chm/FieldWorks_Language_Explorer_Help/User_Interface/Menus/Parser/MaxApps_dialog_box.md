# MaxApps dialog box

*User Interface › Menus › Parser*

You can use this dialog box to set the maximum number of rule applications for each compound rule. This determines how many compounds a compound rule allows." You might want to [get more help](../../../Overview/Technical_support.md).

1.  Review the [About parser parameters](About_parser_parameters.md) information.

2.  [Stop the parser](Start_or_Stop_Parser.md), if it is running.

3.  On the **Parser** menu, click **Edit Parser Parameters**.

    The **Parser Parameters** dialog box appears.

4.  Click the **Set max applications of HC Compound Rules** button.

The **MaxApps** dialog box opens.

5.  For each compound rule, edit the number in the **MaxApps** column.

6.  Click **OK**.
