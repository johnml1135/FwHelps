# Cut, Copy, and Paste

*User Interface › Menus › Edit*

1.  Select the item you want to copy, and then do one of the following:

    - On the **Edit** menu, click **Copy**.

    - Press the [shortcut keys](../../Shortcuts/Shortcut_keys_to_edit_text.md) `Ctrl+C`.

2.  [Move the insertion point](../../Shortcuts/Shortcut_keys_to_move_the_insertion_point.md) to the destination where you want to paste the item. (If you want to paste the item in another document, switch to the destination document.)

3.  Do one of the following:

    - On the **Edit** menu, click **Paste**.

    - Press the [shortcut keys](../../Shortcuts/Shortcut_keys_to_edit_text.md) `Ctrl+V`.

> [!TIP]
>
> - To *move* an item, you can *copy* it from the source location, *paste* it to the destination, and then *delete* it from the source location. This has the same effect as **Cut** and **Paste**. Although not as quick as **Cut** and **Paste**, it minimizes accidental loss or misplacement of material, because you can see what is happening. We do not recommend the use of **Cut**.
