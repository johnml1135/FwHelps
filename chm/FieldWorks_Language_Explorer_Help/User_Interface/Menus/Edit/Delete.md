# Delete

*User Interface › Menus › Edit*

On the **Edit** menu, you can use the **Delete** *\<item\>* command, where *\<item\>* could be lexical **Entry**, **Reversal Index**, **Wordform**, **Category (or Part of Speech)**, fieldnote **Record**, and so on. For more specific help, look under **Delete** in the **Index** tab of these Helps.

1.  To delete the current selection, do one of the following:

    - On the **Edit** menu, click **Delete \<item\>**.

    - On the [Standard](../../Toolbars/Standard_toolbar.md) toolbar, click ![](../../../assets/images/RedDeleteRecordX.GIF).

    - Right-click the *\<item\>* in a columnar view, and then click **Delete Selected** *record* on the menu that appears.

    A **Delete** *\<item\>* information box appears. It identifies the current selection, and asks if you want to continue with the deletion.

2.  If you are sure you want to delete the selection identified in the warning box, click **Delete**.

    The selection identified in the information box is deleted.

    - Otherwise, click **Cancel**.

> [!IMPORTANT]
>
> - It is recommended that you consider [backing up](../File/Backup_and_Restore/Back_up_this_Project.md) your project *before* you delete anything that you might need in the future.
>
> - You can use [Undo](Undo_and_Redo.md) to restore some *but not all* the records you delete. For example you cannot use Undo after you delete a text.
>
> - The **Delete** *\<item\>* menu command is *context sensitive*, but it will *never* [delete a FieldWorks project](../File/Delete_Fieldworks_project.md).
>
> - The **Delete Reversal Index** menu command deletes the current (displayed) reversal *index*.
