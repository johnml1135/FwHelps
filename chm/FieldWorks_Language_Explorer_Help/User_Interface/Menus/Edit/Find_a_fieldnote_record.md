# Find a fieldnote record

*User Interface › Menus › Edit*

1.  In **Notebook** (**Record Edit**, **Browse** or **Document**), do one of the following:

    - On the [Insert](../../Toolbars/Insert_toolbar.md) toolbar, click ![](../../../assets/images/Using_Tools/Notebook_tools/Record_Edit_overview/Find_Record.PNG).

    - Press the [shortcut keys](../../Shortcuts/shortcut_keys_Lexicon_tools.md) `Ctrl+F`.

    - On the **Edit** menu, click **Find Record**.

    The **Find Record** dialog box appears.

2.  In the **Writing System** box, select a writing system.

3.  In the **Find** box, type characters that are in the desired title.

4.  If the desired record does not appear in the **Records** pane, do any of the following:

    - Change the spelling in the **Find** box.

    - Select a different writing system.

    - Click **Create** to open the **New Record** dialog box so you can [insert a new fieldnote record](../../../Using_Tools/Notebook_tools/Record_Edit_overview/Insert_a_fieldnote_record.md).\
      The writing system selected in the **Find Record** dialog box determines the writing system of the **Title** box in the **New Record** dialog box.

    - Click **Cancel** to close the dialog box.

5.  Click the desired entry, and then click **Go To**.
