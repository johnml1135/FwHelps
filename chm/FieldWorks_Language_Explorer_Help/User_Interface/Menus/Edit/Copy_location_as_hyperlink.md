# Copy Location As Hyperlink

*Basic Tasks › Creating Hyperlinks*

You use **Copy Location As Hyperlink** (**Edit** menu) to copy the location of the current FieldWorks Language Explorer (FLEx) window to your computer's Clipboard. Then you can use **Paste Hyperlink** to paste the address to that location as a hyperlink.

1.  To specify a location in FLEx as the *destination* of a hyperlink, do the following:

    - On the [Navigation Pane](../../Toolbars/Navigation/Navigation_Pane_overview.md), select the desired *area* (**Lexicon**, **Texts & Words** and so on) and *tool* or *view* (**Lexicon Edit**, **Word Analyses** and so on).

    - Click the desired lexical entry, wordform, grammar category, text, and so on.

    The desired location you want the link to open should now be displayed in the FLEx window.

2.  On the **Edit** menu, click **Copy Location as Hyperlink**.

    The *path* to the **current location** is copied to the clipboard.

3.  Do the steps in [Paste Hyperlink](../../../Basic_Tasks/Creating_Hyperlinks/Paste_hyperlink.md).
