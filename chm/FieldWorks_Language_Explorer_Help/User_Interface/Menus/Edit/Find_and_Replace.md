# Find and Replace (Notebook)

*User Interface › Menus › Edit*

In **Notebook**, you use the **Find** tab in the **Find and Replace** dialog box to find a string of characters (one or more letters, words, and so on) in records or subrecords. To [preserve the integrity](../../../Using_Tools/Notebook_tools/Record_Edit_overview/Edit_a_record.md) of your original fieldnotes, the **Replace** tab is *not* available.

1.  In the **Navigation Pane**, click **Notebook**, and then click **Document**.

2.  Do one of the following:

    - On the toolbar, click ![](../../../assets/images/Find_Replace_Text.GIF).

    - Press the [shortcut keys](../../Shortcuts/Shortcut_keys_Notebook_tools.md) `Ctrl+Shift+F`.

    - On the **Edit** menu, click **Find**.

      The **Find and Replace** dialog box appears.

3.  Do the following in the **Find** tab:

    - In the **Find what** box, enter the *search text* (that is, the character string, word, or phrase that you want to find).

    - If necessary, click **More** to display the [Search Options](../../../Basic_Tasks/Find_and_Replace/Search_Options.md) pane, and then specify any search options for the **Find what** text.

    - Click **Find Next** until you find the desired occurrence.

    - Click **Close**.

> [!TIP]
>
> - For special search criteria, refer to [Find or Replace Formatting](../../../Basic_Tasks/Find_and_Replace/Find_and_Replace_formatting.md) or [Find or Replace using regular expressions](../../../Basic_Tasks/Find_and_Replace/Find_and_Replace_using_regular_expressions.md).
>
> - Use the [Find Record](Find_a_fieldnote_record.md) dialog box search for records.
