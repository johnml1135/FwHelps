# Edit overview

*User Interface › Menus › Edit*

On the **Edit** menu, you can do the following:

- [Undo and Redo](Undo_and_Redo.md)\

- [Cut, Copy, and Paste](Cut_copy_and_paste.md)\

- [Paste a hyperlink](../../../Basic_Tasks/Creating_Hyperlinks/Paste_hyperlink.md)

  - [Hyperlink to a web page](../../../Basic_Tasks/Creating_Hyperlinks/hyperlink_to_web_page.md)

- [Copy Location as Hyperlink](Copy_location_as_hyperlink.md)\

- [Find a lexical entry](Find_a_lexical_entry.md)

- [Find a reversal entry](Find_a_reversal_entry.md)

- [Find a wordform (word)](Find_wordform.md)\

- [Find in Lexicon](Find_and_Replace_Lexicon.md) (**Dictionary**, **Classified Dictionary** and **Reversal Indexes**)

- [Find and Replace (Notebook)](Find_and_Replace.md)

- [Find and Replace Text](Find_and_Replace_Text.md)\

- [Select All](Select_All.md)

- [Delete \<item\>](Delete.md)

- [Delete Custom List](../../../Using_Tools/Lists_tools/Delete_a_custom_list.md)

> [!IMPORTANT]
>
> - The **Delete** *\<item\>* menu command is *context sensitive*, but it will *never* [delete a FieldWorks project](../File/Delete_Fieldworks_project.md).
