# Find a reversal entry

*User Interface › Menus › Edit*

This ![](../../../assets/images/Find_Reversal_Entry.GIF) **Find Reversal Entry** feature and ![](../../../assets/images/Find_Replace_Text.GIF) [Find in Lexicon](Find_and_Replace_Lexicon.md) are different.

Use the **Find** **Reversal** **Entry** dialog box to find a reversal entry in [Reversal Indexes](../../../Using_Tools/Lexicon_tools/Reversal_Indexes/reversal_indexes_overview.md) or [Bulk Edit Reversal Entries](../../../Using_Tools/Lexicon_tools/Bulk_Edit_Reversal_Entries/bulk_edit_reversal_entries_overview.md).

1.  On the [Information bar](../../Toolbars/information_bar_overview.md), click the menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Reversal_Indexes/Information_bar_Menu_button.PNG), and then click the writing system that has the reversal entry you want to find.

2.  Do one of the following:

    - On the [Insert](../../Toolbars/Insert_toolbar.md) toolbar, click ![](../../../assets/images/Find_Reversal_Entry.GIF).

    - On the **Edit** menu, click ![](../../../assets/images/Find_Reversal_Entry.GIF) **Find reversal entry**.

    - Press the [shortcut keys](../../Shortcuts/shortcut_keys_Lexicon_tools.md) `Ctrl+F`.

    The **Find Reversal Entry** dialog box appears.

3.  In the **Find** box, enter the form of the reversal entry you want to find.

    The **Reversal Entries** area lists any reversal entries that match **Reversal Form** [field](../../Field_Descriptions/Lexicon/Reversal_Indexes_fields/Reversal_Indexes_fields_overview.md) contents.

    - If the desired entry is listed, click it. Then, click **Go To**.

      The dialog box closes. That entry is selected in the center pane.

    - If *no* entry matches, do any of the following:

      - Change the **Find** contents.

      - Turn off any [filters](../../Toolbars/View_toolbar.md).

      - Consider if it the current [publication](../Tools/Configure_Reversal_Index/Manage_Views_Reversal_Index.md) should display it.

      - Click **Cancel**.

      - Use **![](../../../assets/images/Find_Replace_Text.GIF) Find** (**Ctrl+Shift+F**) to [search for characters](Find_and_Replace_Lexicon.md) (*optional*).
