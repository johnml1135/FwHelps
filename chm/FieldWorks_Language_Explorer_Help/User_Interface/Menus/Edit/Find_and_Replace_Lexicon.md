# Find in Lexicon

*User Interface › Menus › Edit*

These ![](../../../assets/images/User_Interface/Toolbars/Find_Replace_Text.GIF) **Find** features are different than the ![](../../../assets/images/FindEntry.GIF) [Find a lexical entry](Find_a_lexical_entry.md) and ![](../../../assets/images/Find_Reversal_Entry.GIF) [Find a reversal entry](Find_a_reversal_entry.md) features.

Here you can use a simple **Find** dialog box to find *search text* (that is, the character string, word, or phrase that you want to find). You can paste in the box or type with the current (active) [keyboard](../../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Writing_System_Properties_Keyboard_tab.md). There are no search options.

1.  In the **Navigation Pane**, click **Lexicon**, and then click **Dictionary**, **Reversal Indexes**, or **Classified Dictionary**.

2.  Do one of the following:

    - On the [toolbar](../../Toolbars/Insert_toolbar.md), click ![](../../../assets/images/Find_Replace_Text.GIF).

    - Press the [shortcut keys](../../Shortcuts/Shortcut_keys_Notebook_tools.md) `Ctrl+Shift+F`.

    - On the **Edit** menu, click **Find**.

      The **Find** dialog box appears.

3.  Do the following in the dialog box:

    - Type or paste the *search text* in the box.

    - Click **Find Next** or **Previous** until you find the desired occurrence.

    - Click **X** to close the dialog box.

> [!IMPORTANT]
>
> - This **Find** feature can only search the *displayed* set of entries.
>
> **See:** [Navigating in Dictionary](../../../Using_Tools/Lexicon_tools/Dictionary/Navigating_in_Dictionary.md) or [Navigating in Reversal Indexes](../../../Using_Tools/Lexicon_tools/Reversal_Indexes/Navigating_in_Reversal_Indexes.md). This feature is the same (and gives the same results) as a **Find** feature you would use in an Internet browser, such as Firefox.
