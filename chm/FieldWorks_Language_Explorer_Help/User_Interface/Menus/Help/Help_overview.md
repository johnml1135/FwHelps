# Help overview

*User Interface › Menus › Help*

On the **Help** menu, click any of the following:

- **Language Explorer** to open **FieldWorks Language Explorer Help**.

- **Training** to open a list training materials at this Internet site:

<a href="https://lingtran.net/FLEx%2b8" target="_blank" title="https://lingtran.net/FLEx+8">https://lingtran.net/FLEx</a>.

- **Demo movies** - see: [About Demo Movies](About_Demo_Movies.md).

<!-- -->

- **Resources**, and then click any of these documents (some are online <a href="https://software.sil.org/fieldworks/help/technical-documents/" target="_blank" title="https://software.sil.org/fieldworks/help/technical-documents/">here</a>):

  - **Introduction to Lexicography**

  - **Introduction to Parsing**

  - **Publishing FLEx Dictionaries to Word**

  - **Technical Notes on Send/Receive**

  - **Technical Notes on SFM Database Import**

  - **Technical Notes on LinguaLinks Database import**

  - **Technical Notes on Interlinear Import**

  - **Technical Notes on Writing Systems**

  - **Editing Linguistics Papers Using XLingPaper** ([Grammar Sketch](../../../Using_Tools/Grammar_tools/Grammar_Sketch/Grammar_Sketch_overview.md)*)*

- [Report a Problem](Report_a_Problem.md) to report a problem by email.

- [Make a Suggestion](Make_a_Suggestion.md) to suggest an improvement by email.

- **About Language Explorer** to see the *version and build date* of FLEx. This information is important if you need to report a problem.

> [!IMPORTANT]
>
> - The *primary* audience for **Help** is *intermediate* computer users. These are "tool" helps, with minimal methodological content.
>
> - The *primary* audience for the **Training** information and **Demo Movies** is *beginning* users.
>
>   These are neither exhaustive nor detailed, but provide you an opportunity to become more familiar with Language Explorer.
>
>   <a href="https://software.sil.org/fieldworks/download/demo-movies/index-of-demo-movies/" target="_blank" title="https://software.sil.org/fieldworks/download/demo-movies/index-of-demo-movies/">https://software.sil.org/fieldworks/download/demo-movies/index-of-demo-movies/</a>
>
> - **Resources** has documents which offer more technical explanations, and in some cases more methodological information.
>
> - Include software version numbers with all [correspondence](../../../Overview/information_for_bug_reports.md).

> [!TIP]
>
> Besides using the **Help** menu, you can do the following to access the help topics:
>
> - With a dialog box displayed, click the **Help** button or press `F1`.
>
> - At the left end of any [field](../../Field_Descriptions/field_descriptions_overview.md), click the [menu button](../../../Basic_Tasks/Show_data/Context_sens_menus.md) (![](../../../assets/images/User_Interface/Menus/Help/Menu_Button_pic.GIF)), and then click **Help**. A help topic about that field opens.
