# Make a Suggestion

*User Interface › Menus › Help*

On the [Help](Help_overview.md) menu, the **Make a Suggestion** command allows you to create and send an email to FLExDevteam@sil.org. Read the example description. Please try to include similar information in your description.

1.  On the **Help** menu, click **Make a Suggestion**.

2.  In the **Make a Suggestion** dialog box, do the following:

    - Type a description of the improvement you would like to see in future versions of FieldWorks Language Explorer.

    - Click one of the two email options.

    - Click **OK**.

3.  The dialog box will close.

    - If your email client opens with the description you typed, send that email.

    - Otherwise, manually open your email client, paste the clipboard contents into the as the body of the email, type **FLExDevteam@sil.org** into the **To** field, and then send it.

> [!NOTE]
>
> - The **OK** button is *not* available until you edit the description. The example is selected with the dialog box opens so when you begin to type it is deleted. Optionally, you can click any white space to clear the selection, then edit that example to make sure you include similar information.
