# Webonary

*User Interface › Menus › File › Export*

*Webonary* is a server-side application, that is, it is software. It is used with *both* the Webonary hosting site (<a href="https://webonary.org/" target="_blank" title="https://webonary.org/">https://webonary.org/</a>) and with other hosting services that you can choose.

## Use Webonary.org to host your data

- You do *not* need to use Pathway.

In this case, [use](../Upload_to_Webonary.md) the **Upload to Webonary** command to send your dictionary data directly from FieldWorks Language Explorer, as [configured](../../Tools/Configure_Dictionary/Configure_Dictionary.md).

## Choose a different web hosting service

- *After* you have set up a hosting service and configured a web stylesheet in the Pathway Configuration Tool, *then* a **Destination** option called **Webonary** is available in the *Set Defaults* and **Export through Pathway** dialog boxes.

In this case, [export through Pathway](../Pathway_Configuration_Tool/Export_Through_Pathway.md) using your web stylesheet and metadata.
