# Export Phonology as XML file

*User Interface › Menus › File*

Do these steps to export the lists of [phonological features](../../../Field_Descriptions/Grammar/Phonological_Features_fields/Phonological_Features_fields_overview.md), [phonemes](../../../Field_Descriptions/Grammar/Phonemes_fields/Phonemes_fields_overview.md), [Natural Classes](../../../Field_Descriptions/Grammar/Natural_Classes_fields/natural_classes_fields_overview.md) and [Phonological Rules](../../../Field_Descriptions/Grammar/Phonologocial_Rules_fields/Phonological_Rules_fields_overview.md). These can be [imported](../../../../Beginning_Tasks/Importing_Data/Import_Phonology.md) into other projects.

1.  In the **Navigation Pane**, click **Grammar**.

2.  On the **File** menu, click **Export**.

The **Export** dialog box appears.

3.  In the left pane of the dialog box, click **Phonology**.\
    The right pane displays information about that export method.

4.  Click the **Export** button.

The **Export to XML** dialog box appears. The **Save as type** box shows **XML files (\*.XML)**. Do not change this selection.

5.  In the **Export to XML** dialog box, find the desired location, and then enter a name in the **File name** box.

6.  Click **Save**.
