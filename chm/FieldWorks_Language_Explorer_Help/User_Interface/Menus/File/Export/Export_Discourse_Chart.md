# Export a discourse chart

*User Interface › Menus › File › Export*

To export the chart currently displayed in the [Text Chart](../../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Text_Chart_tab/Text_chart_overview.md) tab, do the following:

1.  In the **Navigation Pane**, click **Texts & Words**, and then click **Interlinear Texts**.

2.  In the **Texts** pane, click the text that has the chart you want to export, and then click the **Text Chart** tab.

3.  On the **File** menu, click **Export Discourse Chart**.

    The **Export Discourse Chart** dialog box appears.

4.  In the left pane of the dialog box, click the desired export method.\
    The right pane displays information about that export method.

5.  The **Show in folder** check box is selected (![](../../../../assets/images/CheckedBox.PNG)) by default. Then after export, the folder that has the export file opens and that file is selected. If you do not want this to happen, clear (![](../../../../assets/images/UncheckedBox.PNG)) this check box.

6.  Click **Export**.\
    The **Export to XML** dialog box appears. The **Save as type** box shows **XML files (\*.XML)**. Do not change this selection.

7.  In the **Export to XML** dialog box, find the desired location, and then enter a name in the **File name** box. Click **Save**.

> [!NOTE]
>
> - The **Export Discourse Chart** command is available on the [File](../File_overview.md) menu anytime the **Text Chart** tab is displayed in the [Interlinear Texts](../../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/texts_edit_overview.md), [Concordance](../../../../Using_Tools/Texts_&_Words_tools/Concordance/Concordance_overview.md) and [Word List Concordance](../../../../Using_Tools/Texts_&_Words_tools/Word_List_Concordance/Word_List_Concordance_overview.md) tools.
>
> - You cannot import a discourse chart into FieldWorks.
