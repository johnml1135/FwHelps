# Export Concordance Results

*User Interface › Menus › File › Export*

You can export the current results from [Concordance](../../../../Using_Tools/Texts_&_Words_tools/Concordance/Concordance_overview.md) or [Complex Concordance](../../../../Using_Tools/Texts_&_Words_tools/Complex_Concordance/Complex_Concordance_overview.md) to CVS (Comma Separated Values) files. You can open CVS files in a spreadsheet, such as Excel.

1.  On the **Navigation Pane**, click **Text & Words**, and then click either **Concordance** or **Complex Concordance**.

2.  When the concordance results are ready to export click the **File** menu and then click **Export Concordance Results**.

    The **Export Concordance Results** dialog box appears.

3.  Find and then click the folder that you want to hold the CVS file.

4.  Type a name for the CVS file.

5.  Click **Save**.
