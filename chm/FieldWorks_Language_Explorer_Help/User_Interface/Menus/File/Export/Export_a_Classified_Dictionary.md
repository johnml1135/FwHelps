# Export a Classified Dictionary

*User Interface › Menus › File › Export*

You can export the current [Classified Dictionary](../../../../Using_Tools/Lexicon_tools/Classified_Dictionary/Classified_Dictionary_overview.md) layout as you [configured](../../Tools/Configure_Classified_Dictionary/Configure_Classified_Dictionary_View_dlgbox.md) it into an **XHTML** format.

1.  On the **Navigation Pane**, click **Lexicon**, and then click **Classified Dictionary**.

2.  Select (![](../../../../assets/images/CheckedBox.PNG)) or clear (![](../../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)) the **Show Unused Items** check box.

3.  Use the **Configure Classified Dictionary** [dialog box](../../Tools/Configure_Classified_Dictionary/Configure_Classified_Dictionary_View_dlgbox.md) to specify the display properties for the layout you want to export.

4.  On the **File** menu, click **Export**.

    The **Export to XHTML** window appears.

5.  In the window, do the following:

    - Click the folder that you want to receive the export file.

    - Type a name in the **File name** box.

    - Leave the **Save as type** set to **XHTML files (\*.xhtml)**.

    - Click **Save**.

    The file and the style sheet (\*.css) are exported to the folder.

> [!TIP]
>
> - You can select and copy (Ctrl + C) any or all of the data in the **Classified Dictionary** layout, and then paste (Ctrl + V) it into a spreadsheet, such as Excel.
