# Export Translated Lists

*User Interface › Menus › File › Export*

You can export one or more lists (*not* [custom lists](../../../../Using_Tools/Lists_tools/Insert_a_custom_list.md)) for which list items have been translated into a different language (localized). For example, you can export the Semantic Domains lists for use with Rapid Words.

1.  In the **Navigation Pane**, click any area *except* **Texts** **&** **Words**.

2.  On the **File** menu, click **Export**.

    The **Export** dialog box appears.

3.  In the left pane, click the export method **Translated Lists**.

    - The **Show in folder** check box is selected (![](../../../../assets/images/CheckedBox.PNG)) by default. Then after export, the folder that has the export file opens and that file is selected. If you do not want this to happen, clear (![](../../../../assets/images/UncheckedBox.PNG)) this check box.

    - Click **Export**.

The **Export Translated Lists** dialog box appears.

4.  In the **Export Translated Lists** dialog box, do the following:

    - In the **Output file** box, type or paste the path to the folder where you want to export the list, or click **Browse** to find and select the folder.

    - In the **Choose list(s)** pane, select (![](../../../../assets/images/CheckedBox.PNG)) each list that you want to export, and clear (![](../../../../assets/images/UncheckedBox.PNG)) each list that you do not want to export. Click `Select All` or **Clear All**, if that is useful.

    - In the **Choose writing syste****m(s) of translated lists** pane, select (![](../../../../assets/images/CheckedBox.PNG)) the writing systems you want to include in the export.

      English is *not* listed, but *it is used* to match the list items in the export file with the existing file when you [import translated list content](../../../../Beginning_Tasks/Importing_Data/Import_Translated_List_Content.md).

5.  Click **Export**.

    The **Exporting Translated Lists** progress box appears. The progress box and dialog box close when the export is finished. The export file is an \***.xml** file.

If you compress it (\***.zip**), you can still [import](../../../../Beginning_Tasks/Importing_Data/Import_Translated_List_Content.md) that compressed file.
