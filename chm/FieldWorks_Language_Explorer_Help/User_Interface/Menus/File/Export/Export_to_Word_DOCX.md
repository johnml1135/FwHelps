# Export to Word DOCX

*User Interface › Menus › File › Export*

You can export your dictionary and reversal index data to MicroSoft Word (\*.docx format).

![](../../../../assets/images/Important_Icon.gif) **Recommended**

- On the **Help** [menu](../../Help/Help_overview.md), point to **Resources** and then click **Publishing FLEx Dictionaries Using Microsoft Word**.

The technical document that opens will help you make sure your project is ready for this export.

Then do these steps:

1.  [Sort](../../../../Basic_Tasks/Sorting_data/Sort_data.md) and [filter](../../../../Basic_Tasks/Filtering_data/filter_data.md) your lexical data.

2.  [Configure](../../Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) the **Dictionary** layout, and [configure](../../Tools/Configure_Reversal_Index/Configuring_a_reversal_index_view.md) the **Reversal Index** layout.

    - **See Also:** [Styles for export](../Pathway_Configuration_Tool/Styles_for_export.md).

3.  On the **File** menu, click to **Export**.

    The [Export](Export_overview.md) dialog box appears.

4.  Click the **Data / Format** option **Dictionary, Reversal Index / Word (DOCX)**.

5.  Click **Export**.

6.  In the **Export To Word (DOCX)** dialog box, click the folder that you want to hold the exported file, and then click **Save**.

The file is saved and will open in MicroSoft Word.
