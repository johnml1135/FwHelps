# Export Grammar Sketch

*User Interface › Menus › File*

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Grammar Sketch**.

2.  [Generate](../../../../Using_Tools/Grammar_tools/Grammar_Sketch/Generate_a_Grammar_Sketch.md) an *updated* grammar sketch, if necessary.

3.  On the **File** menu, click **Export**.

    The **Export** dialog box appears.

4.  In the left pane, click an export method that contains **Grammar Sketch**.

    - Review the information about the selected method in the right pane.

    - The **Show in folder** check box is selected (![](../../../../assets/images/CheckedBox.PNG)) by default. Then after export, the folder that has the export file opens and that file is selected. If you do not want this to happen, clear (![](../../../../assets/images/UncheckedBox.PNG)) this check box.

    - Click **Export**.

The **Export to Web page** or **Export to XLingPaper XML** dialog box appears.

In the dialog box, do the following:

- In the **File name** box, type or paste a file name. Do not change the **Save as type** selection (**HTM files (\*.htm)** or **XML (\*.xml)**).

- Click **Save**.
