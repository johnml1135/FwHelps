# Export a Configured Dictionary

*User Interface › Menus › File › Export*

You can export the current [dictionary layout](../../Tools/Configure_Dictionary/Dictionary_views.md) as you [configured](../../Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) it (including any [filters](../../../../Basic_Tasks/Filtering_data/filtering_data_overview.md) and [sorts](../../../../Basic_Tasks/Sorting_data/Sorting_data_overview.md) that you set) into an **XML**, **SFM**, **Index Cards HTML**, or **XHTML** format.

You can export an XHTML file and import it directly into a [Webonary](Webonary.md) web site that you set up on the Internet.

1.  On the **Navigation Pane**, click **Lexicon**, and then click **Dictionary**.

2.  [Use](../../Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) the **Configure Dictionary** dialog box to specify the display properties for the layout you want to export.

    (Changes made in **Dictionary** do *not* affect **Classified Dictionary** or **Reversal Index**.)

3.  On the **File** menu, click **Export**.

    The **Export** dialog box appears.

4.  In the dialog box, do the following:

    - In the left pane, select an export method that contains **Configured Dictionary**.

    - Review the information in the right pane.

    - The **Show in folder** check box is selected (![](../../../../assets/images/CheckedBox.PNG)) by default. Then after export, the folder that has the export file opens and that file is selected. If you do not want this to happen, clear (![](../../../../assets/images/UncheckedBox.PNG)) this check box.

    - Click **Export**.

    The **Export to \<format\>** dialog box appears.

5.  In the dialog box, navigate to the folder where you want to save the exported data, and then enter a file name for the exported data.

    The **Save as type** box is automatically set, and you should not change this.

6.  Click **Save**.

    A progress box appears. When the export is finished, the progress box and the **Export** dialog box close automatically.

> [!TIP]
>
> - **See also:** [What is a publication?](../../../Field_Descriptions/Lists/Publications/What_is_a_Publication.md)
>
> - If some characters do not appear correctly in the exported file, make sure the program you are using to read the file is set to display Unicode UTF-8.
>
> - If you open the exported **Index Cards HTML** file in an Editor, or Microsoft Word or Internet Explorer, the entries appear formatted to print on index cards. (In Word, you need to select the **IndexCards.xslt**.)
