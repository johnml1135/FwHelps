# Export a Configured Notebook

*User Interface › Menus › File › Export*

You can export the current **Document** [view](../../../../Using_Tools/Notebook_tools/Document_overview/Document_overview.md) as you [configured](../../Tools/Configure_Document/Configuring_a_Document_view.md) it (including any [filters](../../../../Basic_Tasks/Filtering_data/Filter_Notebook_records.md) and [sorts](../../../../Basic_Tasks/Sorting_data/Sort_Notebook_records.md) that you set) into an **XML** format or an **XHTML** format.

1.  On the **Navigation Pane**, click **Notebook**.

2.  Use the [Configure Document Layout](../../Tools/Configure_Document/Configure_Document_View_dialog_box.md) dialog box to specify the display properties for the layout you want to export.

3.  On the **File** menu, click **Export**.

    The **Export** dialog box appears.

4.  In the dialog box, do the following:

    - In the left pane, select an export method: **Configured Notebook XML** *or* **Configured XHTML Notebook**.

    - Review the information in the right pane.

    - The **Show in folder** check box is selected (![](../../../../assets/images/CheckedBox.PNG)) by default. Then after export, the folder that has the export file opens and that file is selected. If you do not want this to happen, clear (![](../../../../assets/images/UncheckedBox.PNG)) this check box.

    - Click **Export**.

    The **Export to XML** or **Export to XHTML** dialog box appears.

5.  In the dialog box, navigate to the folder where you want to save the exported data, and then enter a file name for the exported data.

    The **Save as type** box is automatically set to **XML files (\*.xml)** or **XHTML files (\*.xhtml)**, and you should not change this.

6.  Click **Save**.

    A progress box appears. When the export is finished, the progress box and the **Export** dialog box close automatically.
