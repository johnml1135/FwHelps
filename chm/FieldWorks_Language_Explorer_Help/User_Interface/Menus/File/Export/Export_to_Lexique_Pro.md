# Export to Lexique Pro

*User Interface › Menus › File › Export*

**Full Lexicon Lift 0.13 XML** is the recommended export method to export lexical data for use in *Lexique Pro*.

Do the steps in [Export a full lexicon (LIFT)](Export_full_lexicon_(LIFT).md), and then do the following in Lexique Pro:

- On the Lexique Pro **File** menu, click **Open**. Select the exported file in the **Open Lexicon** dialog box. Click **Open**.

- In Lexique Pro, use the **Tools** menu commands to configure fonts, categories, keyboards, and so on.

> [!TIP]
>
> - The exported file will has the filename extension \*.lift, such as Sena3.lift.
>
> - <a href="https://software.sil.org/lexiquepro/download/" target="_blank" title="https://software.sil.org/lexiquepro/download/">https://software.sil.org/lexiquepro/download/</a> has the latest version.
