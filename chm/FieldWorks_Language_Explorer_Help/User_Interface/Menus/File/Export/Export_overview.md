> [!NOTE]
>
> - You can also export dictionary and reversal index layout files. See [Manage Publication Layouts](../../Tools/Configure_Dictionary/Manage_Dictionary_Views.md) or [Manage Reversal Index Layouts](../../Tools/Configure_Reversal_Index/Manage_Views_Reversal_Index.md).
>
> - There are similar dialog boxes: **Export**, **Export Interlinear**, **Export Discourse Chart**, and so on.
>
>   - In each dialog box, the *right* pane describes the selected export method.
>
>   - If the export method is listed but is not available, close the dialog box, and then click a different area or tool. Then open the dialog box again.
>
>   - The **Show in folder** check box is selected (![](../../../../assets/images/CheckedBox.PNG)) by default. Then after export, the folder that has the export file opens and that file is selected. If you do not want this to happen, clear (![](../../../../assets/images/UncheckedBox.PNG)) this check box.
>
> - **All Lists XML** exports all lists into a single XML file. The instructions are in the **Export** dialog box, *not* in these Helps.
>
> - The program you use to read the exported file must be able to display **Unicode UTF-8**.
>
> - For more information and instruction for ELAN, <a href="https://www.philol.msu.ru/~languedoc/eng/help/flex2eaf.php" target="_blank" title="https://www.philol.msu.ru/~languedoc/eng/help/flex2eaf.php">https://www.philol.msu.ru/~languedoc/eng/help/flex2eaf.php</a>.
>
> - For more information about FXT (which allows some users or consultants to design custom export options), see:\
>   <a href="https://software.sil.org/fieldworks/support/technical-documents/" target="_blank" title="https://software.sil.org/fieldworks/support/technical-documents/">https://software.sil.org/fieldworks/support/technical-documents/</a>.
