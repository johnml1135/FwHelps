# Export a reversal index

*User Interface › Menus › File › Export*

You can export a reversal index to an `XML`, SFM or XHTML file. The current configuration of the **Reversal Index** pane affects exports.

1.  In the **Navigation Pane** click **Lexicon**, and then click **Reversal Indexes**. Then, in the **Reversal Index** pane, click the menu button ![](../../../../assets/images/User_Interface/Menus/File/Export/Information_bar_Menu_button.PNG) on the [Information bar](../../../Toolbars/information_bar_overview.md) and select the reversal index you want to export.

2.  [Configure the reversal index](../../Tools/Configure_Reversal_Index/Configure_Reversal_Index_dialog_box.md), as necessary.

3.  On the **File** menu, click **Export**.

    The **Export** dialog box appears.

4.  In the dialog box, do the following:

    - In the left pane, select an export method that contains **Reversal Index**.

    - In the right pane, review the information about the selected method. If necessary, select a different method in the left pane.

    - The **Show in folder** check box is selected (![](../../../../assets/images/CheckedBox.PNG)) by default. Then after export, the folder that has the export file opens and that file is selected. If you do not want this to happen, clear (![](../../../../assets/images/UncheckedBox.PNG)) this check box.

    - Click **Export**.

    A dialog box named **Export to XML**, **Export to SFM** or **Export to XHTML** appears.

5.  In the dialog box, do the following:

    - Navigate to the folder where you want to save the exported data.

    - Enter a name for the file in the **File name** box.

    - In the **Save as type** box, the file type (**\*.xml**, **\*.db** or **\*.xhtml**) is automatically selected. Do not change the selection.

6.  Click **Save**.

    A progress box appears. When the export is finished, the progress box and the **Export** dialog box close automatically.

> [!NOTE]
>
> - The program you use to read the export file must be set to display **Unicode UTF-8**.
