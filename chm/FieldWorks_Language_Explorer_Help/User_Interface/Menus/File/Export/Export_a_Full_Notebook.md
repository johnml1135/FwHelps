# Export a Full Notebook

*User Interface › Menus › File › Export*

You can export the entire current **Document** [view](../../../../Using_Tools/Notebook_tools/Document_overview/Document_overview.md) into an **SFM** format or an **XML** format.

1.  On the **Navigation Pane**, click **Notebook**.

2.  On the **File** menu, click **Export**.

    The **Export** dialog box appears.

3.  In the dialog box, do the following:

    - In the left pane, select an export method: **Full Notebook SFM** *or* **Full Notebook XML**.

    - Review the information in the right pane.

    - The **Show in folder** check box is selected (![](../../../../assets/images/CheckedBox.PNG)) by default. Then after export, the folder that has the export file opens and that file is selected. If you do not want this to happen, clear (![](../../../../assets/images/UncheckedBox.PNG)) this check box.

    - Click **Export**.

    The **Export to SFM**, or **Export to XML** dialog box appears.

4.  In the dialog box, navigate to the folder where you want to save the exported data, and then enter a file name for the exported data.

    The **Save as type** box is automatically set to **SFM files (\*.SFM)**, or **XML files (\*.xml)**, and you should not change this.

5.  Click **Save**.

    A progress box appears. When the export is finished, the progress box and the **Export** dialog box close automatically.
