# Something went wrong

*User Interface › Menus › File*

If the program had a problem as it was [opening a project](Open_a_language_project.md), you will see a dialog box informing you that there was a problem. It also asks you to choose to open with ‘factory settings,’ or to attempt to open while preserving your settings.

The ‘settings’ referred to in the dialog box text are related to such things as window size, toolbar positions, hidden/shown toolbars, and open tool ([Navigation Pane](../../Toolbars/Navigation/Navigation_Pane_overview.md) selection).

No project-related settings, such as writing systems, or keyboards are affected if you click **Yes**.
