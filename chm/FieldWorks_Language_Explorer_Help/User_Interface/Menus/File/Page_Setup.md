# Page Setup

*User Interface › Menus › File*

**![](../../../assets/images/Important_Icon.gif) Not currently implemented ![](../../../assets/images/Important_Icon.gif)**

1.  On the **File** menu, click **Page Setup**.

    The **Page Setup** dialog box appears.

2.  On the **Margins** tab, set the **Top**, **Bottom**, **Inside**, **Outside**, and **Gutter** margins relative to the edges of the page.

3.  On the **Paper** tab, do any of the following:

    - In the **Paper Size** area, select the type of paper to print on. If the size is not in the list, select **Custom**, and then set the **Width** and **Height** of the paper.

    - In the **Orientation** area, click **Portrait** or **Landscape**.

4.  On the **Layout** tab, do any of the following:

    - In the **Book start** list, select the type of page on which each book will begin.

    - In the **Header and Footers** area: Select the pages which must be different. Set the distances relative to the edges of the page.

    - In the **Footnotes** area: Set the **Maximum Height** of footnotes on a page. Select the **Separator** between the footnote and the rest of the page.

5.  Click **OK**.

> [!NOTE]
>
> - The **Page Setup** dialog box is only available in **Print Layout** tab.
>
> - To modify headers and footers: On the **View** menu, click Header/Footer Setup.
>
> - You can change measurement units on the **General** tab of the **Options** dialog box.
