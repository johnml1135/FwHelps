# Archive with RAMP

*User Interface › Menus › File*

1.  Install RAMP, if it is not installed. See ![](../../../assets/images/Important_Icon.gif) **Important** below.

2.  On the **File** menu, click ![](../../../assets/images/User_Interface/Menus/File/RAMPcommand.png) **Archive with RAMP**.

The **Archive With RAMP** dialog box opens.

If no backup file is found on the computer, the **Create a new backup** option is selected. The next step will be to back up the project. Otherwise, choose to create a new backup file *or* to use the most recent one.

3.  Select **Create a new backup** *or* **Use most recent backup**.

4.  Click **OK**.

The **Back up this Project** dialog box opens if you selected **Create a new project**. Otherwise, *or* after you click **OK** to back up the project, the **SIL FieldWorks: Archive with RAMP (SIL Only)** dialog box opens.

5.  If you see warnings that suggest you need to correct something, click **Cancel**. Otherwise, click **1) Create Package**.

A temporary package is created.

6.  When **Ready to hand the package to RAMP** appears, click **2) Launch RAMP**.

The RAMP program starts. *Some* [metadata](RAMP_Metadata.md) are added from FLEx files.

7.  Follow the steps in the RAMP window. Make sure the [metadata](RAMP_Metadata.md) is complete and correct.

8.  If you do not have an Internet connection, you can do the following:

    - In RAMP, click the **Actions** button, and then click **Export** to export the package to your computer's hard drive or to a removable device.

    - When you (or someone else with RAMP) have an internet connection (stable or intermittent), do these steps:

      - If the package is on a removable device, click the **Actions** button, and then click **Import** to import the package.

      - Click **Actions**, and then click **Upload** to upload the package to REAP.

> [!IMPORTANT]
>
> - If the ![](../../../assets/images/User_Interface/Menus/File/RAMPcommand.png) **Archive with RAMP** command is not available on the **File** menu, then RAMP is not installed.
>
> Download it from here: <a href="https://ramp.sil.org/" target="_blank" title="https://ramp.sil.org/">https://ramp.sil.org/</a>.
>
> *RAMP* (Resource and Metadata Packager) is a desktop program. It helps prepare and send files to the SIL International archive *REAP* (Repository for Electronic Archiving and Publishing).
>
> *REAP* requires login access.
>
> - Email either <REAP@sil.org> or <RAMP@sil.org> if you have questions about usage, access or permissions.
