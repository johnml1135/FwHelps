# Print

*User Interface › Menus › File*

See [Print Dictionary](Print_Dictionary_or_Reversal_Index.md) if you have *more than* 1000 entries in **Dictionary** or **Reversal Indexes**.

Otherwise, do these steps:

1.  In the **Navigation Pane** click the area (**Lexicon**, **Texts & Words**, **Notebook** and so on) and then select the tool (**Lexicon Edit**, **Dictionary**, and so on) that displays the content that you want to print.

2.  To customize the data to be printed, [sort](../../../Basic_Tasks/Sorting_data/Sorting_data_overview.md), [filter](../../../Basic_Tasks/Filtering_data/filtering_data_overview.md), or select the items such that only the content you want to print is displayed.

3.  On the **File** menu click **Print**, or press the [shortcut keys](../../Shortcuts/shortcut_keys_on_the_File_menu.md) **Ctrl+P**.

    The **Print** dialog box appears.

4.  Specify settings as necessary.

    - To print only the entries or records that are currently selected, in the **Print range** area, click **Selection**.

5.  Click **OK**.

> [!NOTE]
>
> - The [Print content](Print_content.md) `Help` topic has a table that can help correlate the displayed window with optional ways to specify *what* is printed, and *how* the print output looks.
>
> - The **Print** command sends content to the printer or to a file, such as a \*.PDF.
>
> - The print operation is limited to the range of lexical entries or reversal entries that are in the range of displayed entries. **See:** [Navigating in Dictionary](../../../Using_Tools/Lexicon_tools/Dictionary/Navigating_in_Dictionary.md) or [Navigating in Reversal Indexes](../../../Using_Tools/Lexicon_tools/Reversal_Indexes/Navigating_in_Reversal_Indexes.md).
>
> - In the **Print** dialog box, the *entire* entry or fieldnote record that has the insertion point is printed as it is configured.
>
> That is, you *cannot* print a portion of an entry or record by selecting that portion. To print more or less, configure it differently.
