# Rename a FieldWorks project

*User Interface › Menus › File › Backup and Restore*

There are two ways to do this.

## **Use Backup and Restore**

This is the recommend way if you are [getting started with Send/Receive](../../../../Basic_Tasks/Collaborating_with_Others/Get_Started_with_Send_Receive.md).

1.  [Back up](Back_up_this_Project.md) the project.

2.  [Restore](Restore_a_project.md) the project using a *different* project name according to the limitations mentioned in [FieldWorks project name](FieldWorks_project_names.md).

## Use the FieldWorks Project Properties dialog box

- In the **General** [tab](../Project_Properties/Project_Properties_General_tab.md), edit the [project name](FieldWorks_project_names.md) in the **Project Name** box.

> [!IMPORTANT]
>
> - [Collaborators](../../../../Basic_Tasks/Collaborating_with_Others/Collaborating_with_Others_overview.md) should coordinate any name changes or uses of the **Restored a Project** dialog box (*recommended*).
