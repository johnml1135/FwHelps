# Backup and Restore overview

*User Interface › Menus › File › Backup and Restore*

A FieldWorks [backup file](Backup_files.md) is a compressed file that contains project data. You can also choose to include configuration files, media files (pictures, sound files, and so on), fonts, and keyboards, if they are in appropriate [folders](Folder_Structure.md).

- On the **File** menu, point to **Project Management**, and then click one of the following:

  - [Back up this Project](Back_up_this_Project.md)

  - [Restore a Project](Restore_a_project.md)

> [!IMPORTANT]
>
> - If you and your colleagues will use Send/Receive to [collaborate](../../../../Basic_Tasks/Collaborating_with_Others/Collaborating_with_Others_overview.md), review [Get Started with Send/Receive](../../../../Basic_Tasks/Collaborating_with_Others/Get_Started_with_Send_Receive.md).

> [!NOTE]
>
> - Use the **Schedule Tasks** features in your computer's operating system [to back up projects automatically](Back_up_projects_automatically.md).
>
> - Restoring from a backup file does *not* merge data. Use restore to
>
> - - recover data if the project data file on the computer is damaged.
>
>   - undo undesired changes that you cannot undo in a FieldWorks program.
>
>   - compare data in the current version of a project to data in the backup file.
>
>   - [copy a project from another computer](Copy_a_FieldWorks_project_from_another_computer.md).
>
>   - recover from a hardware failure (If you use a backup of the local disk that includes the project data folders, you will not need to restore projects individually from FieldWorks backup files.).
>
> - The [Project Locations](../Project_Locations.md) dialog box displays the parent folder for FieldWorks project data folders.
