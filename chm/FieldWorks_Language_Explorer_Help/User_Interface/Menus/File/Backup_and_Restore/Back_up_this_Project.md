# Back up this Project

*User Interface › Menus › File › Backup and Restore*

### ![](../../../../assets/images/Important_Icon.gif) Prerequisites

- For **Additional files to back up** options:

  - Make sure the [Linked Files folder](../Project_Properties/Project_Properties_Linked_Files_tab.md) selection is correct. *The folder (and subfolders) specified there may be included in the backup.*

  - Make sure the files you want to back up are in the [appropriate folder](Folder_Structure.md).

  - If you will restore the project on [a different computer](Copy_a_FieldWorks_project_from_another_computer.md), copy any fonts or keyboards into the **SupportingFiles** [folder](Folder_Structure.md), if necessary.

- If you intend to back up projects to a removable disc (for example, a CD-RW or a USB flash drive), make sure it is inserted in the drive or connected to the computer. It is recommended that you back up to the default folder, and then use Windows<sup>®</sup> Explorer to manually copy the [backup file](Backup_files.md) to the removable media. Otherwise, you might not have a copy of the backup file if you ever need to restore it on this computer.

Do the following:

1.  On the **File** menu, point to **Project Management**, and then click **Back up this Project**.

The **Back up this Project** dialog box appears.

2.  In the **Additional files to back up** area, select (![](../../../../assets/images/CheckedBox.PNG)) [folders](Folder_Structure.md) to also back up.

3.  In the **Comment** box, enter a *brief* comment (optional). It cannot contain these characters: **/\*?”\<\>\|()\[\]**.

    Your comment is added to the file name, after the date and time, to help distinguish this [backup file](Backup_files.md).

4.  For the **Save in** box, click **Browse**, and then select the drive and [backup folder](Backup_folder.md).

    - If you want to back up projects to a removable device or disc, make sure it is connected, or in the drive.

5.  Click **OK**.

6.  If the **Change Backup Location** dialog box appears, do one of the following:

    - To make the selected folder become the default folder for this and future backups, click **Yes**.\
      The **Save in** box selection is saved and the backup file is saved in the new location.

    - If the selected folder or drive is a temporary change for this backup only, click **No**.\
      The **Save in** box selection is *not* saved, but this backup file is saved in the temporary location.
