# Back up projects automatically

*User Interface › Menus › File › Backup and Restore*

SIL FieldWorks does *not* have features for scheduling backup operations. Instead, the plan is that you will use the **Scheduled Tasks** feature which is part of Microsoft Windows<sup>®</sup>.

- However, programming for the ability for Windows<sup>®</sup> to access FieldWorks is not complete at this time.

[Manually](Back_up_this_Project.md) back up your projects.
