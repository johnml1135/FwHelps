# Files that FieldWorks does not back up

*User Interface › Menus › File › Backup and Restore*

In the [Back up this Project](Back_up_this_Project.md) dialog box, the check boxes under **Additional files to back up** allow you to choose whether to back up individual [folders](Folder_Structure.md) which are in the **LinkedFiles** folder.

Files FieldWorks does not back up:

- any [picture](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_a_picture.md) or [media](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_link_to_sound_or_movie.md) (sound or movie) files, or files that open from [external links](../../../../Basic_Tasks/Creating_Hyperlinks/Creating_Hyperlinks_overview.md) but *which are not in appropriate* [folders](Folder_Structure.md).

- any other supporting files *which you did not manually copy* to the **SupportingFiles** [folder](Folder_Structure.md). Supporting files can include

  - [encoding converters](../../../../Advanced_Tasks/Writing_Systems/Encoding_Converters/Encoding_Converters_Advanced_tab.md)

  - spelling dictionary files (**See:** [Folder Structure](Folder_Structure.md))

  - fonts

  - keyboards

  - saved [grammar sketch](../../../../Using_Tools/Grammar_tools/Grammar_Sketch/Grammar_Sketch_overview.md) files

  - other files you want to keep with the project, but for which you have not used or set links to open in the project. These could be spreadsheets, document files, spelling dictionary files, sound, movie or picture files and so on.
