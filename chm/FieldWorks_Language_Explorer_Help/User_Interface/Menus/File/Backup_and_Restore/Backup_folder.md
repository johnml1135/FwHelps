# Backup folder

*User Interface › Menus › File › Backup and Restore*

You can back up a project to a folder on any of the following types of storage devices:

- Local disk on your computer. For example, a **Backups** folder in a **My FieldWorks** folder.

<!-- -->

- Disk on a network file server or on another computer.

- Removable disc (for example, CD-RW).

- Universal Serial Bus (USB) device.

> [!IMPORTANT]
>
> - If there is not enough storage space on a disk, FieldWorks cannot back up the project.
>
> If a removable disc fills up, you need to insert another disc in the drive.
>
> - If you back up projects to a local disk, make sure to back up the FieldWorks backup folder regularly to a network file server or a removable disc. For example, whenever you back up your Documents folder.
>
> Because the default backup folder depends on the active user account, we recommend that you log on a consistent user account to back up the projects on a computer.
>
> - To delete obsolete files, go to the backup folder in Windows<sup>®</sup> Explorer and then delete the files. The default backup folder location is: C:\Users\name\Documents\My FieldWorks\Backups

## Select a backup folder

In the **Back up this Project** dialog box, the **Save in** box displays the *default* backup folder.

- You can click **Browse:**

  - To make the selected folder become the default for future backups.

  - To make a temporary change for this backup.
