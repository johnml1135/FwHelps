# FieldWorks project names

*User Interface › Menus › File › Backup and Restore*

When you [create](../Create_a_new_Fieldworks_project.md) or [rename](Rename_a_FieldWorks_project.md) a FieldWorks project, you can usually follow local orthography conventions for its name.

Be aware of these limitations:

- The name *cannot* contain: **" ; \< \> \| : \* ? \\ / ( ) \[ \]**

- The name must use only ASCII characters.

<a href="https://www.asciitable.com/" target="_blank" title="https://www.asciitable.com/">https://www.asciitable.com/</a> has a character table and descriptions.

Appropriate warnings appear depending on the violation of these limitations.

> [!TIP]
>
> - If necessary, you can copy and paste a name into the box from another Unicode-compliant source.
>
> - The project name appears in these places:
>
> - - title bar of the FieldWorks windows
>
>   - list of projects in the **Open Project** and **Restore a Project** dialog boxes
>
>   - **Project Locations** dialog box
>
>   - **General** tab of the **FieldWorks Project Properties** dialog box.
