# Delete a FieldWorks project

*User Interface › Menus › File*

A *FieldWorks project* (project) is a database that stores data and metadata related to a particular language and the people who speak it.

1.  Before you delete any projects, [back up those projects](Backup_and_Restore/Back_up_this_Project.md).

This is *optional*, but be aware that you *cannot* **Undo** a project deletion.

2.  On the **File** menu, point to **Project Management**, and then click **Delete Project**.

    The **Delete FieldWorks Project** dialog box appears.

The **Projects you can delete** pane lists projects that are stored on your computer.

The **Projects currently open** pane lists projects stored on your computer that you have open. You cannot delete a project that is open.

3.  In the **Projects you can delete** pane, click the project you want to delete.

    - If you want to delete two projects, press the **Ctrl** key and then click the other project. Now you see two projects are selected.

    - To clear a selection, press the **Ctrl** key and then click the project you do not want to delete.

4.  Click **Delete**.

    The **Delete FieldWorks Project** box appears.

Do one of these steps:

- Click **Cancel** to stop the deletion.

- If the project has *no* external files, click **OK** to delete the selected project(s).

- If the project has linked external files in [folders](Backup_and_Restore/Folder_Structure.md) (**Linked Files** [tab](Project_Properties/Project_Properties_Linked_Files_tab.md)), you can choose to *delete* those files and the folders, or *keep* them.

- Click **Yes** to delete the files and the folders, *or* click **No** to keep them.

- If you clicked **No**, it is *recommended* that you look at the files in those folders, and manually delete any files that others should not see or that you will never use.

5.  Click **Close** to close the **Delete FieldWorks Project** dialog box when you are done using it.

> [!IMPORTANT]
>
> - If you uninstall the SIL FieldWorks program from your computer, projects are *not* removed.
>
> - Refer to the **Location** data in the **FieldWorks Project Properties** dialog box (**General** tab) to learn where the project data is stored.
