# Save

*User Interface › Menus › File*

Like other database programs, FieldWorks automatically saves your changes when you do the following:

- Move from the entry, record, text, or view where you are working to another one.

- Back up the project.

- Use Send/Receive.

- Close the project or exit FieldWorks.

> [!IMPORTANT]
>
> - The save action clears the **Undo** and **Redo** memories. Then, you cannot undo or redo any changes that you made before saving.
>
> - FieldWorks does *not* have an AutoSave feature to save your work automatically according to a time interval that you choose.
>
> - In **Texts & Words**, you must deliberately undo (![](../../../assets/images/User_Interface/Menus/Data/UndoChange.GIF) or `Ctrl+Z`) *manual changes* as they are saved by default.
