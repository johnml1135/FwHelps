# Choose a project

*User Interface › Menus › File*

- In the **Open Project** dialog box, click the project in the **Choose a project** pane. Then, click **Open**.

If the project you want to open is *not* listed in the **Choose a project** pane, here are things you can do:

- Click the [Open project in another location](Open_project_in_another_location.md) link.

- If you think Language Explorer is looking in the wrong folder, [change the project locations](Project_Locations.md).
