# File overview

*User Interface › Menus › File*

On the **File** menu, you can do the following:

- [Create](Create_a_new_Fieldworks_project.md) a new FieldWorks project.

- [Open](Open_a_language_project.md) an existing FieldWorks project.

- Use **Project Management** commands:

  - [FieldWorks Project Properties](Project_Properties/Project_Properties_overview.md)

Tabs: [General](Project_Properties/Project_Properties_General_tab.md), [Linked Files](Project_Properties/Project_Properties_Linked_Files_tab.md) and [Sharing](Project_Properties/Project_Properties_Sharing_tab.md)

  - [Back up or Restore](Backup_and_Restore/Backup_and_Restore_overview.md) your FieldWorks projects

  - [Project Locations](Project_Locations.md)

  - [Delete Project](Delete_Fieldworks_project.md)

  - [Create Shortcut on Desktop](Create_Shortcut_on_Desktop.md)

- [Archive with RAMP](Archive_with_RAMP.md)

- [Upload to Webonary](Upload_to_Webonary.md)

- **Page Setup** (not implemented)

- [Print](Print.md)

  - [Print Dictionary or Reversal Index](Print_Dictionary_or_Reversal_Index.md)

- [Import](../../../Beginning_Tasks/Importing_Data/Import_overview.md) data

- [Export](Export/Export_overview.md) data

- **Close** the current FieldWorks window, and then exit FieldWorks.
