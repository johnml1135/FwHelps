# Create Shortcut on Desktop

*User Interface › Menus › File*

One **Language Explorer 9** desktop shortcut is added when you install FLEx.

- If the check box is selected (![](../../../assets/images/CheckedBox.PNG)) in the [Language Explorer](../../../Overview/Welcome_to_FieldWorks.md) or [Options](../Tools/Options/Options_overview.md) dialog box, then each time you use this shortcut, the *last* (most-recently) *edited* project is opened again. Otherwise, the **Language Explorer** dialog box opens.

You can also create a shortcut to always open a particular language project.

1.  [Open](Open_a_language_project.md) the project for which you want to create a shortcut.

2.  On the **File** menu, point to **Project Management**, and then click **Create Shortcut on Desktop**.

A desktop shortcut is added. The name matches the project name.

If necessary, right-click the shortcut and click `Rename`. Edit the name.

> [!NOTE]
>
> - Windows<sup>®</sup>: You can also right-click a shortcut, and then select **Properties**. This displays a dialog box. In the **Target** box of that dialog box, you can enter the command line arguments to set up a special shortcut.
>
> - To see a list of command line arguments, click the operating system's **Start** button, and then select **Run**.
>
>   - In the **Run** dialog box, type or paste:
>
>     C:\Program Files\SIL\FieldWorks 9\FLEx.exe -h
>
> Refer to your *Windows Help and Support* system for your operating system for more help with desktop shortcuts. On the Internet, refer to sites like this: <a href="https://msdn.microsoft.com/en-us/library/bb483085.aspx" target="_blank" title="https://msdn.microsoft.com/en-us/library/bb483085.aspx">https://msdn.microsoft.com/en-us/library/bb483085.aspx</a>.
