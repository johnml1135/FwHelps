# Project Locations

*User Interface › Menus › File*

- On the **File** menu, point to **Project Management**, and then click **Project Locations**.

The **Project Locations** dialog box opens.

**Project data folders are located in**: This box shows the path (URL) to the *folder* where FLEx initially looks for projects you can [choose](Choose_a_project.md). You can edit the path manually.

**Location of current project**: Here you see the complete path (URL) to the current *project*. It may be in a different folder.

## Change the location of the project data

1.  Click **Browse**, and then choose a different [folder](Backup_and_Restore/Folder_Structure.md). It could be a USB flash drive or other external hard drive.

2.  Click each **OK** button that you see.

    The **New Location for Project Data for Folders** dialog box appears.

3.  In the dialog box, click **Yes** to move all the project folders into the new folder.

    The open FLEx windows closes while the project [folders](Backup_and_Restore/Folder_Structure.md) are moved.

The **Open Project** dialog box will now list projects in *this* folder.
