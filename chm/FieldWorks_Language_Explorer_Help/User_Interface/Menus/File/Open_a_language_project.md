# Open a FieldWorks language project

*User Interface › Menus › File*

1.  Open the **Open Project** dialog box in *any* of these ways:

    - On the **File** menu, click **Open**.

    - Press the [shortcut keys](../../Shortcuts/shortcut_keys_on_the_File_menu.md) `Ctrl+O`.

    - [Open](../../../Overview/Welcome_to_FieldWorks.md) the **Language Explorer** dialog boxes, and click **Open a project**.

2.  Do any of the following in the **Open Project** dialog box:

    - [Choose a project](Choose_a_project.md).

    - [Get project from a colleague](../Send_Receive/Get_a_project.md).

    - [Open project in another location](Open_project_in_another_location.md).

> [!TIP]
>
> - You can [create a shortcut on your desktop](Create_Shortcut_on_Desktop.md) for each project.
>
> - The *location* of the currently-open project is shown as a path (URL) in the **FieldWorks Project Properties** dialog box (**General** tab) and also in the **Project Locations** dialog box.
>
> - - The path includes the filename extension.
>
> - You can double-click the \*.fwdata file to open that project.
>
> - Projects you [restore](Backup_and_Restore/Restore_a_project.md) open automatically.
