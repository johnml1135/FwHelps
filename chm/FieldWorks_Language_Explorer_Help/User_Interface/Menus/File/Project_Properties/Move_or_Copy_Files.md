# Move or Copy File dialog box

*User Interface › Menus › File › FieldWorks Project Properties*

Click one of the following in the dialog box that appears:

- **Move Files** to *move* the file or files to the appropriate folder.

- **Copy Files** to *copy* the file or files into appropriate folder.

- **Leave Files** to leave the file or files in the current folder.

> [!NOTE]
>
> - The **Move or Copy Files** dialog box appears if you do any of the following:
>
> - - [Insert a sound or move file](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_link_to_sound_or_movie.md) or [insert a hyperlink to a file](../../../../Basic_Tasks/Creating_Hyperlinks/Insert_a_hyperlink_to_a_file.md). The path to [folder](../Backup_and_Restore/Folder_Structure.md) currently set in the **Linked Files** tab is displayed.
>
>   <!-- -->
>
>   - [Choose](Project_Properties_Linked_Files_tab.md) a different [folder](../Backup_and_Restore/Folder_Structure.md) in the **Linked Files** tab when any of the subfolders contain a file. Paths to the previous folder *and* the new folder are displayed.
>
>   <!-- -->
>
>   - Click **Yes** in the [Review the location of Linked Files](Review_the_location_of_Linked_Files.md) question box.
>
> - [Send/Receive](../../Send_Receive/Send_Receive_menu.md) and [Upload to Webonary](../Upload_to_Webonary.md) require you to use the *default* folder.
>
> **See:** [FieldWorks Project Properties - Linked Files tab](Project_Properties_Linked_Files_tab.md).
>
> - When you [back up](../Backup_and_Restore/Back_up_this_Project.md) the project, you can choose to also backup content in specific folders, such as the **LinkedFiles** folder.
>
> - When you [insert a picture](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_a_picture.md), the **Picture Properties** dialog box allows you to copy or move the picture to the **Pictures** folder, if it is not already there. It also allows you to leave the picture in the original folder (*not* recommended).
