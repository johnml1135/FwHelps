# Review the location of Linked Files

*User Interface › Menus › File › FieldWorks Project Properties*

If this question box appears, click one of the following:

- **Yes**

  The **Move or Copy Files** dialog box opens so you can move or copy the files to the default [folder](../Backup_and_Restore/Folder_Structure.md) location (*recommended*).

Do this *before* you [back up this project](../Backup_and_Restore/Back_up_this_Project.md) to include these files in the [backup file](../Backup_and_Restore/Backup_files.md).

[Send/Receive](../../Send_Receive/Send_Receive_menu.md) and [Upload to Webonary](../Upload_to_Webonary.md) require you to use the *default* folder.

- **No**

  The files stay in the old location.
