# Project Properties, Linked Files tab

*User Interface › Menus › File › FieldWorks Project Properties*

This tab displays the path to the [folder](../Backup_and_Restore/Folder_Structure.md) that stores [pictures](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_a_picture.md), [sound or movie files](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_link_to_sound_or_movie.md), and other [linked](../../../../Basic_Tasks/Creating_Hyperlinks/Creating_Hyperlinks_overview.md) *files*.

- [Open](Project_Properties_overview.md) the **FieldWorks Project Properties** dialog box and then click the **Linked Files** tab.

## Use the default folder

[Send/Receive](../../Send_Receive/Send_Receive_menu.md) and [Upload to Webonary](../Upload_to_Webonary.md) require you to use the *default* folder.

1.  Click the **Use Default Folder** link.

2.  Click **OK**.

3.  If the **Move or Copy Files** dialog box appears, click **Move Files**, **Copy Files** or **Leave Files** ([more](Move_or_Copy_Files.md)).

## Use a custom folder

You can choose a custom folder if you do *not* use Send/Receive or Webonary.

1.  Click **Browse**.

The **Browse For Folder** dialog box appears.

2.  Navigate to the folder you want to use.

    - Add a folder and subfolders, if desired.

<!-- -->

3.  Click **OK** in the **Browse For Folder** dialog box.

4.  Click **OK** in the **FieldWorks Project Properties** dialog box.

The ![](../../../../assets/images/LargeWarning.png) **Custom Linked Files folder not supported by Send/Receive** warning box appears.

1.  - Click **OK** to set the custom location.

    - If the **Move or Copy Files** dialog box appears, click **Move Files**, **Copy Files** or **Leave Files** ([more](Move_or_Copy_Files.md)).

> [!TIP]
>
> - If you do *not* use Send/Receive or Webonary, you can also add more subfolders that are subordinate to the **Linked Files** subfolders to help organize your files.
>
> - If you use [Copy Location as Hyperlink](../../Edit/Copy_location_as_hyperlink.md) and then [Paste Hyperlink](../../../../Basic_Tasks/Creating_Hyperlinks/Paste_hyperlink.md) to create a hyperlink to a different area or view within FLEx, there is no link that is stored in these folders.
>
> - [Back up this project](../Backup_and_Restore/Back_up_this_Project.md) discusses the **SupportingFiles** folder, which is *not* related to linked files.
