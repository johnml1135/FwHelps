# Project Properties, Sharing tab

*User Interface › Menus › File › FieldWorks Project Properties*

Use this tab to control whether FLEx can share project data with other *programs* on this computer, such as *Phonology Assistant*.

Do these steps:

1.  Close any other program that is associated with FLEx.

2.  [Open](Project_Properties_overview.md) the **FieldWorks Project Properties** dialog box.

3.  Select (![](../../../../assets/images/CheckedBox.PNG)) the check box if you need to let FLEx share data.

Otherwise, clear (![](../../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)) it.

4.  Click **OK**.

> [!IMPORTANT]
>
> - If this check box is cleared (![](../../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)), you can [choose text](../../../../Basic_Tasks/Filtering_data/Choose_Texts.md) data to pull into FLEx from another program.
>
> <!-- -->
>
> - FLEx runs slower when this check box is selected (![](../../../../assets/images/CheckedBox.PNG)).
>
> - This check box does *not* affect Send/Receive or collaboration with other FLEx users.
