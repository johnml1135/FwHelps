# Project Properties, General tab

*User Interface › Menus › File › FieldWorks Project Properties*

This tab lists the project name and information about the project.

1.  [Open](Project_Properties_overview.md) the **FieldWorks Project Properties** dialog box and then click the **General** tab.

2.  Do any of the following:

    - In the **Project Name** box, edit the [project name](../Backup_and_Restore/FieldWorks_project_names.md).

    - Review **Location**, **Date Created** and **Last Modified**.\
      The location data can help you find the **Projects** folder and its subfolders.

    - In the **Description** box, edit or type the project description.\
      Currently, the project description is only viewable here.

3.  Click **OK**.
