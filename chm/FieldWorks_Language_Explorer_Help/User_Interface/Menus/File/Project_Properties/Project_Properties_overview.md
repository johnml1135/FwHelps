# Project Properties dialog box overview

*User Interface › Menus › File › FieldWorks Project Properties*

1.  Close any other programs that are associated with FieldWorks Language Explorer (FLEx).

2.  On the **File** menu, point to **Project Management**, and then click **FieldWorks Project Properties**.

3.  Use one or more of these tabs:

    |  |  |
    |----|----|
    | **Tab** | **Use to** |
    | [General](Project_Properties_General_tab.md) | rename the project, learn the location of the **Projects** folder, see **Date Created** and **Last Modified**, or edit the project's description. |
    | [Linked Files](Project_Properties_Linked_Files_tab.md) | choose the [folder](../Backup_and_Restore/Folder_Structure.md) for external files. |
    | [Sharing](Project_Properties_Sharing_tab.md) | allow or not allow FLEx to share data with programs. |
