# Create a new FieldWorks project

*User Interface › Menus › File*

1.  Do one of these steps:

    - [Open](../../../Overview/Welcome_to_FieldWorks.md) the **Language Explorer** dialog box, and then click an [option](../../../Overview/Welcome_to_FieldWorks.md) that opens the **New FieldWorks Project** dialog box.

    - Click the **File** [menu](../Menus_overview.md), and then click **New FieldWorks Project**.

The **New FieldWorks Project** dialog box opens.

2.  **Name** — type or paste the project name according to the limitations mentioned in [FieldWorks project name](Backup_and_Restore/FieldWorks_project_names.md).

<!-- -->

1.  - Click **Next**.

<!-- -->

3.  **Vernacular** — Click **Choose** and then [look up](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/Select_Language_dialog_box.md) the language you want as the default vernacular [writing system](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md).

    - Click **Next**.

4.  **Analysis** — If you do not want English as the *default* (top) analysis writing system, click **Choose** and then [look up](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/Select_Language_dialog_box.md) another language.

If you choose another language, it will be the default analysis writing system. English is also added because it is used for lists and more.

*Optional* means that you can click **Finish** now. However, you should click **Next** and review the **More** and **Anthropology** information.

5.  **More** (*optional*) — You can click **Set up Vernacular Writing Systems** or **Set up Analysis Writing Systems** to [define](../../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Modifying_a_writing_system_overview.md) or [add](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/Add_a_new_writing_system.md) writing systems.\
    Or, you can do it later.

    - Click **Next**.

6.  **Anthropology** (*optional*) — You *cannot* change this selection after the project is created.

    - Review [About Anthropology Categories](../../../Using_Tools/Lists_tools/About_Anthropology_Categories.md).

    - Select (![](../../../assets/images/SelectedRadioButton.png)) an option for your [anthropology](../../Field_Descriptions/Notebook/Anthro_Cat_field_Ntbk.md) and [lexical](../../Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/anthropology_categories_field.md) data.

7.  Click **Finish**.

8.  [Use](../../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Using_the_Writing_System_Properties_dialog_box.md) the **Writing System Properties** dialog box to [define](../../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Modifying_a_writing_system_overview.md) the writing systems ([fonts](../../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Writing_System_Properties_Fonts_tab.md), [keyboards](../../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Writing_System_Properties_Keyboard_tab.md) and so on).
