# Export Through Pathway

*User Interface › Menus › File › Pathway*

If the Pathway Configuration Tool is installed on your computer (<a href="https://software.sil.org/pathway/" target="_blank" title="https://software.sil.org/pathway/">download</a>), then its dialog boxes appear as if they were part of FieldWorks Language Explorer.

1.  [Sort](../../../../Basic_Tasks/Sorting_data/Sort_data.md) and [filter](../../../../Basic_Tasks/Filtering_data/filter_data.md) your lexical data.

    - This exports the data as XHTML for use by Pathway. See [Sorting tab](../../../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Writing_System_Properties_Sorting_tab.md) for information about controlling the order of alphabetized headers.

2.  [Configure](../../Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) the **Dictionary** view, and [configure](../../Tools/Configure_Reversal_Index/Configuring_a_reversal_index_view.md) the **Reversal Index** layout.

    - **See Also:** [Styles for export](Styles_for_export.md).

3.  On the **File** menu, click to **Export**.

    The [Export](../Export/Export_overview.md) dialog box appears.

4.  Click the **Data / Format** option **Dictionary, Reversal Index / Pathway (various outputs)**.

    The **Select Your Organization** dialog box appears.

5.  In the dialog box, do the following:

    - Select your organization, if it appears in the list.

    - If necessary, click **Other**. Type the name of your organization in the **Organization** **Name** dialog box. Click **OK**.

    - Click **OK**.

    The **Export Through Pathway** dialog box appears.

6.  In the **Export Through Pathway** dialog box, do the following:

    - Select the destination (E-book, OpenOffice/LibreOffice ODT or pdf, and so on).

    - Select the stylesheet.\
      Click ![](../../../../assets/images/User_Interface/Menus/File/Pathway_Configuration_Tool/Preview_button.png) to see a preview of sample data that uses the current stylesheet (*optional*).

    - Click **More** (*optional*).

      - Review or change the information in each of the tab, if permitted. The *Pathway Configuration Tool* Help file has more information.

    - Click the **Intellectual Property Info** link.

      The *Pathway Configuration Tool* Help file opens.

      - Read the information on intellectual property. Then, select (![](../../../../assets/images/CheckedBox.PNG)) the check box to indicate compliance with your organization's policies.

    - Click **OK**.

      The export process begins. For some output selections, the program will start and display the output (if the program is installed on your computer).

> [!IMPORTANT]
>
> - When you export a dictionary using Pathway, if the default vernacular [writing system](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) is not the writing system of the lexeme forms or citation forms, the guide words (headers) may appear in a different writing system than the dictionary headwords. Also, the sort order of the entries may be set by the wrong writing system.
>
> - [Generate a grammar sketch](../../../../Using_Tools/Grammar_tools/Grammar_Sketch/Generate_a_Grammar_Sketch.md) so you export a fresh one.
>
> - If you use the **LikeBuangPNG** stylesheet, you need to specify the following in the [Configure Dictionary](../../Tools/Configure_Dictionary/Configure_Dictionary.md) dialog box:
>
>   - In the [left pane](../../Tools/Configure_Dictionary/About_the_left_pane.md), click **Senses**. Then, in the *right* pane clear the check mark from the **If all senses share the grammatical information, show it first** check box.
>
>   - Select the **Number even a single sense** check box.
>
> <!-- -->
>
> - The **Print Via** dialog box appears if you have an old version of Pathway Configuration Tool installed. It is recommended that you <a href="http://code.google.com/p/pathway/downloads/list" target="_blank">download</a> a newer version to get the latest features.
