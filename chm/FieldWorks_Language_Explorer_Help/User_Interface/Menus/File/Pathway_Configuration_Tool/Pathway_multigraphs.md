# Pathway multigraphs

*User Interface › Menus › File › Pathway*

You can choose to [export](Export_Through_Pathway.md) your data through SIL Pathway.

- If your vernacular language has *multigraphs*, such as *digraphs*, add appropriate **Custom ICU rules** [collation rules](../../../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Collation_in_FieldWorks.md) in the [Sorting](../../../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Writing_System_Properties_Sorting_tab.md) tab to make sure the set of letters in the each multigraph is considered a single entity and is sorted correctly in the export file.
