# Styles for export

*User Interface › Menus › Format › Styles*

[Style](../../Format/Styles/Styles_overview.md) settings in FLEx can determine the appearance of [exported](../Export/Export_overview.md) data, even if you [export through Pathway](Export_Through_Pathway.md).

- **Dictionary-Normal** determines the **Dictionary** and **Reversal Indexes** views and their configured export data. But, it does *not* change the appearance of other views such as **Lexicon Edit**.

**Classified-MainEntry** and **Classified-Item** styles determine the **Classified Dictionary** view and its configured export data. But, they do *not* change the appearance of **Collect Words**.

- The Pathway stylesheets `FieldWorksStyles` and **FieldWorksArabicBased** use the *most* FieldWorks styles.

> [!TIP]
>
> - On the **Help** [menu](../../Help/Help_overview.md), point to **Resources** and then click **Publishing FLEx Dictionaries Using Microsoft Word**. The technical document that opens will help you make sure your project is ready for export to MS Word.
>
> - You can:
>
> - - modify any of the styles in FLEx
>
>   - copy and customize stylesheets in the **Pathway Configuration Tool** (<a href="https://software.sil.org/pathway/download/" target="_blank" title="https://software.sil.org/pathway/download/">https://software.sil.org/pathway/download</a>).
>
> - [Printed](../Print.md) data also uses these styles.
