# RAMP Metadata

*User Interface › Menus › File*

This table shows which metadata are pre-populated (from FLEx files) when you [archive with RAMP](Archive_with_RAMP.md). In RAMP, verify that metadata and then add the rest. Some is in English by design, and some is multi-lingual or language specific.

In RAMP, additional metadata is required (e.g. **\|** **Work Stage**); others are optional (e.g. **Additional Titles**) or recommended (e.g. **Contributors**).
