# Open project in another location

*User Interface › Menus › File*

1.  In the **Open Project** dialog box, click the **Open project in another location** link.

2.  Navigate to that project, and then click the FieldWorks project file\
    (![](../../../assets/images/User_Interface/Menus/File/FileIcon.png) \<project name\>.fwdata).

3.  Click **Open**.

The project opens.
