# Insert word glosses into Free or Lit line

*User Interface › Menus › Insert*

You can insert (that is, *copy*) word glosses from a **Word Gloss** line ([Word focus box](../../../Using_Tools/Texts_%26_Words_tools/Interlinear_Texts/Word_Focus_Box_examples.md)) into the associated **Free** or **Lit** (Literal) translation line.

1.  [Display the text in an interlinear view](../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Display_text_in_an_interlinear_view.md).

2.  If necessary, [configure interlinear lines](../Tools/Configure_interlinear_lines_dialog_box.md) to display **Free** or **Lit** lines (or the **Word Gloss** line) and select writing systems for them.

3.  To specify the insertion point, click the desired **Free** or **Lit** line.

    - If the line displays more than one writing system, click the particular line that uses the desired writing system.

4.  Do either of the following:

    - Press the **Enter** key.

    - On the **Insert** menu, click **Word Glosses**.

    The word glosses are copied into the **Free** or **Lit** line. Repeat steps 4 and 5 for each line in the text, as necessary.

> [!IMPORTANT]
>
> - If you change a word gloss, do one of the following:
>
> - - Select and delete the **Free** or **Lit** lines. Then, do the steps above again.
>
>   - Manually edit the **Free** or **Lit** lines, as necessary.
>
> - **Free** lines appear by default. There can be only *one* **Free** line and one **Lit** line for each line of text. You can more than one **Note** line.
>
> - You can *manually* [enter a free translation](../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Enter_a_Free_Translation.md) or [enter a literal translation](../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Enter_a_Literal_Translation.md).
