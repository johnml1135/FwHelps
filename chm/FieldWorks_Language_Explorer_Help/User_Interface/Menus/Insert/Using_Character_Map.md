# Using Character Map

*User Interface › Menus › Insert*

Use the **Character Map** dialog box to find characters and copy them to your computer's clipboard.

You might want a [non-breaking space](Insert_a_NBSP.md), a [section sign](Insert_a_Section_Sign.md), a trademark symbol, [custom bullets](../Format/Styles/Styles_Bullets_and_Numbering_tab.md), special mathematical characters, tone bars, a character from the character set of another writing system, and so on.

1.  On the **Insert** menu, click ![](../../../assets/images/CharMapIcon.png) **Special character**.

    The **Character Map** dialog box appears.

2.  Click the **Font** box and then click the font that has the character you want.

3.  If you know the Unicode value for a character, do these steps:

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Advanced view**.

    - Type the Unicode value in the **Go to Unicode** box.

    - Click **Select** to put the character in the **Characters to copy** box.

4.  If you do *not* know the Unicode value for a character, do these steps:

    - Type the name of the character in the **Search** **for** box, and then click **Search**. Otherwise, use the scroll bar and look for the character.

    - Click the character.

    - Click **Select** to put it in the **Characters to copy** box.

<!-- -->

5.  When the characters are in the **Characters to copy** box, click **Copy**.

The characters are copied to your clipboard so you can [paste](../Edit/Cut_copy_and_paste.md) them wherever you click to position the insertion point.

> [!TIP]
>
> - A character may not be visible, such as a non-breaking space ([example](Insert_a_NBSP.md)).
>
> - You can manually select one or more of the characters in the **Characters to copy** box and then click **Copy**. Then, only those selected characters are copied to your computer clipboard.
>
> You can also use the Backspace key or select characters and use the Delete key to remove characters from the **Characters to copy** box.
>
> - *Doulos SIL* and *Charis SIL* fonts include tone bars (tone marks) that you can copy and paste into the [tone](../../Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Tone_field.md) field, and if desired, you can use the [Font Feature](../../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Writing_System_Properties_Fonts_tab.md) called **Tone Numbers** to change the tone bars into superscript numbers. In addition, these tone bars may be *combined* for rising and falling tones.
>
> - The **Help** button accesses **User Helps** that *are in addition to* (separate from) these **User Helps**.
