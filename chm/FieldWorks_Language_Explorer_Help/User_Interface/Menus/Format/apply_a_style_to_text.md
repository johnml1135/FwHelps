# Apply Style

*User Interface › Menus › Format*

*Style formatting* determines the appearance of text with a style. A *style* is a named set of formatting attributes. When you apply a style to characters, words or paragraphs, you identify *what it is* and determine *how it looks*.

1.  Do one of the following:

    - Select the characters or paragraphs to which you want to apply a style.

    - Put the insertion point at the location where you want to type using the style you will select.

2.  Then, do one of the following:

    - On the [Format](Format_overview.md) menu, click **Apply Style**. In the **Apply Style** dialog box, click the desired style, and then click **OK**.

    - On the [Format](../../Toolbars/Format_toolbar.md) toolbar, select the style in the **Style** box.

> [!TIP]
>
> - If the **Apply Style** menu command or the **Style** box is *not available*, the [field](../../Field_Descriptions/field_descriptions_overview.md) that has the insertion point does not allow embedded styles.
>
> - - In the FieldWorks Language Explorer, you can apply *character* styles to text in many *but not all* fields, but you can apply *paragraph* styles *only* to text in [multiparagraph fields](../../Field_Descriptions/Field_Types/Multiparagraph_text_field.md).
>
>   - You can *also* specify a style for every occurrence of content from [fields](../Tools/Configure_Dictionary/About_the_left_pane.md) when you [configure views](../Tools/Tools_overview.md). Styles you apply directly to selected text in a field is retained for that particular text, and *another* style may also be [configured](../Tools/Tools_overview.md) to appear in a dictionary [layout](../Tools/Configure_Dictionary/Dictionary_views.md) or a document [layout](../../../Using_Tools/Notebook_tools/Document_overview/Document_overview.md) (the dialog boxes do *not* indicate that those styles are applied, because they are applied to individual occurrence of the field).
>
> - [Edit a record](../../../Using_Tools/Notebook_tools/Record_Edit_overview/Edit_a_record.md) discusses styles specifically intended for use in **Notebook**.
