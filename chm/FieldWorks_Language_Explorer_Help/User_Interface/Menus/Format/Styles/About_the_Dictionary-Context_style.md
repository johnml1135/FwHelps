# About the Dictionary-Context style

*User Interface › Menus › Format › Styles*

The **Dictionary-Context** *character* style (![](../../../../assets/images/User_Interface/Menus/Format/Styles/Character_symbol.GIF)) is the base style for any contents in the **Before**, **Between** and **After** boxes. These boxes appear in the [Configure Dictionary](../../Tools/Configure_Dictionary/Configure_Dictionary.md) dialog box.

**See Also:** [Surrounding Context](../../Tools/Configure_Dictionary/Surrounding_Context.md) and [Custom CSS Override Files overview](../../../../Advanced_Tasks/Custom_CSS_Override_Files/Custom_CSS_Override_Files_overview.md).

> [!NOTE]
>
> - You can [change the configuration](Styles_overview.md) of this style, or copies of it, in the **Styles** dialog box.
