# Styles, General tab

*User Interface › Menus › Format › Styles*

You *cannot* modify the general attributes of styles installed with FLEx.

1.  To specify general attributes for a style you added or copied, click the style in the **Styles** list, and then click the **General** tab.

Do any of these steps:

1.  - **Name** — edit the name to rename the style.

    - **Based on** — click the down arrow and then click the [parent style](Select_the_parent_style.md) from which your style will [inherit attributes](Inheriting_unspecified_attributes.md).

    - **Style for following paragraph** — (paragraph styles only) click the down arrow, and then click the style of the paragraph that you want to be inserted when you press `Enter`.

    - **Shortcut key** — currently not available.

    - **Usage** — type or edit a statement about the purpose the style.

    - **Description** — displays the parent style if there is one and the formatting attributes. Not editable.

<!-- -->

2.  Click **OK** or click another [tab](Styles_overview.md).

> [!NOTE]
>
> - On the **Help** [menu](../../Help/Help_overview.md), point to **Resources** and then click **Publishing FLEx Dictionaries Using Microsoft Word**.
>
> The technical document that opens offers more information about styles, particularly if you will [export](../../File/Export/Export_overview.md) to MS Word.
