# Direction

*User Interface › Menus › Format › Styles*

## Writing System

- The **General** tab of the **Writing System Properties** dialog box has a check box you use to indicate the direction of the text entered in the current [writing system](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md).

Select (![](../../../../assets/images/CheckedBox.PNG)) it for a *right-to-left* writing system.

## Style

- The `Paragraph` tab of the **Styles** dialog box has a **Direction** control. For the current [style](Styles_overview.md), it sets the direction of data in views like **Dictionary** and **Reversal Indexes**. **Unspecified** means the direction is [inherited](Inheriting_unspecified_attributes.md).

For example, when the **Direction** control for the **Dictionary-Normal** style is set is *right-to-left*, the layout aligns to the right, and the headword is correctly moved to the right, and the justification is on the right.

Carefully examine the entries to make sure *all* the data is presented correctly. You may want to [get more help](../../../../Overview/Technical_support.md).

> [!TIP]
>
> - You can use the **Format** toolbar to [select a writing system](../select_a_writing_system.md). Then if permitted, you can
>
> embed *right-to-left* words or phrases in a *left-to-right* writing system, or
>
> embed *left-to-right* words or phrases in a *right-to-left* writing system.
