# Styles, Bullets and Numbering tab

*User Interface › Menus › Format › Styles*

Select a style in the **Styles** list, click the **Bullets and Numbering** tab, and then do one of the following:

- If the style is *not for lists*, click **None**.

- If the style is *for bulleted lists*, click **Bullet**, and then select a symbol in the **Scheme** list.

  - Alternatively, type or paste a bullet symbol in the **Custom** box.\
    For example, you could copy one from the [Character Map](../../Insert/Using_Character_Map.md).\
    Any contents in the **Custom** box supersedes the **Scheme** selection.

- If the style is *for numbered lists*, click **Number**, and then select an item in the **Scheme** list. You can also do one or more of the following:

  - If the list does not start at the first value in the number scheme, select the **Start at** check box, and then select or enter a value in the box.

  - If the list format has text before the number, type the text in the **Text before** box.

  - If the list format has text after the number, type the text in the **Text after** box.

- To [inherit](Inheriting_unspecified_attributes.md) the list attributes from the [parent style](Select_the_parent_style.md), click **Unspecified**. If the parent style is not for lists, then the selected style is not for lists.

> [!NOTE]
>
> - To change the font of the bullets or numbers, click **Bullet and Number Font**. The [Font](../Font.md) dialog box appears.
>
> - A new paragraph style is initially **Unspecified**.
>
> - The **Preview** box displays the *look* of the list attributes.
>
> <!-- -->
>
> - On the **Help** [menu](../../Help/Help_overview.md), point to **Resources** and then click **Publishing FLEx Dictionaries Using Microsoft Word**.
>
> The technical document that opens offers more information about styles, particularly if you will [export](../../File/Export/Export_overview.md) to MS Word.
