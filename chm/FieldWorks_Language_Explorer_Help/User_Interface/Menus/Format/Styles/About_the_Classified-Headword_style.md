# About the Classified-Headword style

*User Interface › Menus › Format › Styles*

The **Classified-Headword** *character* style (![](../../../../assets/images/User_Interface/Menus/Format/Styles/Character_symbol.GIF)) is the base style for the headword and any contents in the **Before**, **Between** and **After** boxes. These boxes appear in the [Configure Classified Dictionary](../../Tools/Configure_Classified_Dictionary/Configure_Classified_Dictionary_View_dlgbox.md) dialog box.

> [!NOTE]
>
> - You can [change the configuration](Styles_overview.md) of this style, or copies of it, in the **Styles** dialog box.
