# About Headword Number styles

*User Interface › Menus › Format › Styles*

A "headword" consists of the lexeme or citation form plus any homograph number. *A referenced* headword can also include the sense number if a specific sense was [chosen](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_components_for_Components_field.md).

FieldWorks Language Explorer uses these character styles (![](../../../../assets/images/User_Interface/Menus/Format/Styles/Character_symbol.GIF)):

- **Homograph-Number** for homograph numbers.

- **Sense-Reference-Number** for sense numbers.

> [!NOTE]
>
> - Sense numbers can include *letters*, such as **A B C** or **a b c**. For example, you can use the **Numbering Style** control to choose letter for a [sense number configuration](../../Tools/Configure_Dictionary/Sense_No_Config_Dict.md).
>
> - The **Headword Numbers** dialog boxes display or open the **Styles** dialog box to these styles.
>
> - You can modify these styles in the **Styles** dialog box.
