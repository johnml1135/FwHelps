# Styles overview

*User Interface › Menus › Format › Styles*

A *style* is a named set of formatting attributes. Formatting attributes include font, font size, font style, alignment, margin indents, and spacing. When you apply a style to selected text, you identify *what it is* and determine *how it looks*. [Formatting Text overview](../../../../Basic_Tasks/Formatting_Text/Formatting_Text_overview.md) and [Inheriting unspecified attributes](Inheriting_unspecified_attributes.md) also discuss styles.

Here is how you open and use the **Styles** dialog box.

1.  On the **Format** menu, click **Styles**, or click a **Styles** button in a dialog box.

    The **Styles** dialog box appears.

2.  Click a style in the **Styles** list, and then do any of the following:

    - *Add* — click **Add**, and then click **Paragraph Style** or **Character Style**.

    - *Copy* — click **Copy**.

    - *Delete* a user-added style — click **Delete**.

    - Modify a *character* style (![](../../../../assets/images/User_Interface/Menus/Format/Styles/Character_symbol.GIF)) — use the [General](Styles_General_tab.md) and [Font](Styles_Font_tab.md) tabs.

    - Modify a *paragraph* style (![](../../../../assets/images/User_Interface/Menus/Format/Styles/Paragraph_symbol.GIF)) — use the **General**, **Font**, [Paragraph](Styles_Paragraph_tab.md), [Bullets and Numbering](Styles_Bullets_and_Numbering_tab.md), and [Border](Styles_Border_tab.md) tabs.

    - *Reset* a style back to factory original (default) settings — click **Reset**.

3.  To save the style changes, click **OK**.

> [!TIP]
>
> - **Usage** (**General** tab) describes the purpose for each style.
>
> - "**Classified-**" styles are used in **Classified Dictionary**.
>
> "**Dictionary-**" styles are used in **Dictionary** and in some cases **Reversal Indexes**.
>
> - ![](../../../../assets/images/User_Interface/Menus/Format/Styles/Triangular_bullet.gif) identifies the style applied to text at the insertion point or to selected text.
>
> - The **Reset** button appears for styles installed with FLEx; **Delete** for styles you added.
>
> - The **Default Paragraph Characters** style replaces a deleted character style wherever it has been applied in the project.
>
> <!-- -->
>
> - *To filter* the list in the **Styles** pane, click the **List** box, and then click one the options in the drop-down list:
>
> **All Styles** - for all the styles in this language project
>
> **Basic Styles** - for all styles *except* those used *by default* in dictionary views.
>
> **Custom Styles** - for styles you added or copied.
>
> **User-modified styles** - for styles modified by a user.
>
> - **See Also:** [About Headword Number styles](About_Headword_Number_styles.md), [About Classified-Headword style](About_the_Classified-Headword_style.md), [About Dictionary-Context style](About_the_Dictionary-Context_style.md), [About Reversal-Vernacular style](About_the_Reversal-Vernacular_style.md) or [Edit a record](../../../../Using_Tools/Notebook_tools/Record_Edit_overview/Edit_a_record.md).
>
> <!-- -->
>
> - On the **Help** [menu](../../Help/Help_overview.md), point to **Resources** and then click **Publishing FLEx Dictionaries Using Microsoft Word**.
>
> The technical document that opens offers more information about styles, particularly if you will [export](../../File/Export/Export_overview.md) to MS Word.
