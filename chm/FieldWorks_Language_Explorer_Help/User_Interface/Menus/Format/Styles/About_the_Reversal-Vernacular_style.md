# About the Reversal-Vernacular style

*User Interface › Menus › Format › Styles*

The **Reversal-Vernacular** *character* style (![](../../../../assets/images/User_Interface/Menus/Format/Styles/Character_symbol.GIF)) is used for items vernacular contents in reversal index entries. It also controls any contents in the **Before**, **Between** and **After** boxes that appear in the [Configure Reversal Index](../../Tools/Configure_Reversal_Index/Configure_Reversal_Index_dialog_box.md) dialog box.

> [!NOTE]
>
> - You can [change the configuration](Styles_overview.md) of this style, or copies of it, in the **Styles** dialog box.
