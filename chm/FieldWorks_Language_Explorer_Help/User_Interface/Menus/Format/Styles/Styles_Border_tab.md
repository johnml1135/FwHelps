# Styles, Border tab

*User Interface › Menus › Format › Styles*

Click a paragraph (![](../../../../assets/images/User_Interface/Menus/Format/Styles/Paragraph_symbol.GIF)) style in the **Styles** pane and then click the **Border** tab.\
Do one of these steps:

- Click **None** if no borders are needed for the current [style](Styles_overview.md).

- Click **All** to put borders on all four sides of content that uses this style.

- To display borders on some sides, select (![](../../../../assets/images/CheckedBox.PNG)) one or more check box:\
  **Top**, **Bottom**, **Left** or **Right**.

  **Leading** and **Trailing** replace the names of side check boxes if the project has *at least one* right-to-left [writing system](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md).

**Leading** means *left* if the [direction](Direction.md) is left-to-right; *right* if it is right-to-left.

**Trailing** means *right* if the direction is left-to-right; *left* if it is right-to-left.

![](../../../../assets/images/User_Interface/Menus/Format/Styles/InheritCheckBox.png) means that the border is [inherited](Inheriting_unspecified_attributes.md) from the [parent style](Select_the_parent_style.md).

If you chose any borders, do these steps (optional):

- **Color** — click the down arrow and then click a color for the border.

**(unspecified)** will let the style inherit the color from the parent style.

- **Width** — click the down arrow and then click a width for the border.

> [!TIP]
>
> - Consult with a publications expert.
>
> For example, titles and headings can be formatted with borders, but paragraphs should rarely use them. Paragraphs with borders can slow down FLEx.
>
> - On the **Help** [menu](../../Help/Help_overview.md), point to **Resources** and then click **Publishing FLEx Dictionaries Using Microsoft Word**.
>
> The technical document that opens offers more information about styles, particularly if you will [export](../../File/Export/Export_overview.md) to MS Word.
