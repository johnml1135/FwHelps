# Senses/Subsenses

*User Interface › Menus › Tools › Configure Dictionary*

In the [left pane](About_the_left_pane.md)**, there are multiple instances of the** **Senses** and **Subsenses** nodes in each [view](Dictionary_views.md).\
See ![](../../../../assets/images/Important_Icon.gif) **Important** below.

<table width="100%">
<tbody>
<tr>
<th><p><strong>Example</strong></p></th>
<th><p><strong>Description</strong></p></th>
</tr>
&#10;<tr>
<td><p><img src="../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/Senses.png" /></p></td>
<td><ul>
<li><p><strong>Senses</strong> configures <a href="../../../Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Sense_level_fields_overview.md">sense-level fields</a>.</p></li>
</ul>
<ul>
<li><p>In the <em>right</em> pane you can:</p></li>
<li><ul>
<li><p>Use <a href="Sense_No_Config_Dict.md">Sense Number Configuration</a> controls.</p></li>
</ul></li>
</ul>
<ul>
<li><ul>
<li><p>Select (<img src="../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/CheckedBox.PNG" />) or clear (<img src="../../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG" />) <strong>If all senses share the grammatical information, show it first</strong>.</p></li>
</ul></li>
</ul>
<ul>
<li><ul>
<li><p>Use the <a href="Display_each_sense_in_a_paragraph.md">Display each sense in a paragraph</a> check box.</p></li>
</ul></li>
</ul>
<ul>
<li><ul>
<li><p>Use the <strong>Styles</strong> button to work with the <a href="../../Format/Styles/Styles_overview.md">style</a>.</p></li>
</ul></li>
</ul></td>
</tr>
<tr>
<td><p><img src="../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/SubsensesNode.png" /></p></td>
<td><ul>
<li><p><strong>Subsenses</strong> configures <a href="../../../Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Sense_level_fields_overview.md">sense-level fields</a> used in subsenses. <strong>Subsubsenses</strong> (at bottom) inherits the configuration set for <strong>Subsenses</strong>.</p></li>
</ul>
<ul>
<li><p>In the <em>right</em> pane you can:</p></li>
<li><ul>
<li><p>Use <a href="Sense_No_Config_Dict.md">Subsense Number Configuration</a> controls.</p></li>
</ul></li>
</ul>
<ul>
<li><ul>
<li><p>Select (<img src="../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/CheckedBox.PNG" />) or clear (<img src="../../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG" />) <strong>Hide subsense grammatical info if same as parent</strong>.</p></li>
</ul></li>
</ul>
<ul>
<li><ul>
<li><p>Select (<img src="../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/CheckedBox.PNG" />) or clear (<img src="../../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG" />) <strong>Display each subsense in a paragraph</strong>.</p></li>
</ul></li>
</ul>
<ul>
<li><ul>
<li><p>Use the <strong>Before</strong>/<strong>Between</strong>/<strong>After</strong> boxes and style controls.<br />
If subsenses are displayed in paragraphs,then paragraph styles (<img src="../../../../assets/images/User_Interface/Menus/Format/Styles/Paragraph_symbol.GIF" />) are used.</p></li>
</ul></li>
</ul></td>
</tr>
<tr>
