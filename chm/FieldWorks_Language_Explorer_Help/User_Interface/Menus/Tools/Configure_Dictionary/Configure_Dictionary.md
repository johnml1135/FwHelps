# Configure Dictionary dialog box

*User Interface › Menus › Tools › Configure Dictionary*

Use this dialog box to choose *which* of the [available lexical data](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Specify_publishable_lexical_data.md) to hide (![](../../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)) and which to display (![](../../../../assets/images/CheckedBox.PNG)) and then *how* to display that data in [Dictionary](../../../../Using_Tools/Lexicon_tools/Dictionary/Dictionary_overview.md).

**See:** [About the "left pane"](About_the_left_pane.md) and [Main Entry and Minor Entry](Main_Minor_entry.md).

1.  In the **Navigation Pane**, click **Lexicon**, and then click **Dictionary** or **Lexicon Edit**.

2.  Do one of the following to open the dialog box:

    - On the **Tools** menu, point to **Configure**, and then select **Dictionary**.

    - Use a [right-click menu](../../../../Using_Tools/Lexicon_tools/Dictionary/Use_right-click_to_help_configure_Dictionary_view.md) command (*recommended* when possible).

    - In **Dictionary**, click the *right* down arrow (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/TitleBarMenuButton.PNG)) on the [Information bar](../../../Toolbars/information_bar_overview.md) and then click **Configure Dictionary**.

    The **Configure Dictionary** dialog box appears.

3.  Do one or both of these steps:

    - [Use](Manage_Dictionary_Views.md) the **Manage Dictionary Layouts** dialog box or [choose](Choose_a_dictionary_view.md) a [layout](Dictionary_views.md) to configure.

    - [Configure](Using_the_Configure_Dictionary_dialog_box.md) the layout.

> [!TIP]
>
> - **Configure Classified Dictionary** [dialog box](../Configure_Classified_Dictionary/Configure_Classified_Dictionary_View_dlgbox.md) and **Configure Reversal Index** [dialog box](../Configure_Reversal_Index/Configure_Reversal_Index_dialog_box.md) are similar to **Dictionary**.
>
> [Configuring](../Configure_Document/Configure_Document_View_dialog_box.md) a **Document** layout in **Notebook** is slightly different.
>
> - Use the **Configure Headword Numbers** dialog box to [configure](../Configure_Headword_Numbers/Config_Hdwrd_Numbers_dialog_box.md) how homograph and sense numbers appear with headwords.
>
> - Advanced users may be able to use [custom css override files](../../../../Advanced_Tasks/Custom_CSS_Override_Files/Custom_CSS_Override_Files_overview.md).
