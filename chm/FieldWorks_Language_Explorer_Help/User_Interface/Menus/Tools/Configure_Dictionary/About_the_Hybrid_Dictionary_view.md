# About the Hybrid Dictionary layout

*User Interface › Menus › Tools › Configure Dictionary*

**Hybrid (complex forms as main entries and mini subentries)** is one of the [layouts](Dictionary_views.md) you can [choose](Choose_a_dictionary_view.md).

Based on the “Bartholomew” dictionary configuration, the **Hybrid** layout has three distinctives:

1.  focus on native speaker = simplify entry up front

2.  display of complex forms as both main entries and as subentries

3.  extensive use of illustrative sentences to discover and display meaning.

The “Bartholomew” dictionary configuration, is based on the model of lexicography which was developed by the Mexico Branch of SIL. It has served as the basis for an extensive series of published bilingual dictionaries of Mexican indigenous languages spanning several decades (see <a href="https://mexico.sil.org/publications/i-vimsa" target="_blank" title="https://mexico.sil.org/publications/i-vimsa">https://mexico.sil.org/publications/i-vimsa</a>), as well as for languages of other countries. The theoretical basis for this model is spelled out by Doris Bartholomew and Louise Schoenhals in *Bilingual Dictionaries for Indigenous Languages* (see <a href="https://mexico.sil.org/resources/archives/2384" target="_blank" title="https://mexico.sil.org/resources/archives/2384">https://mexico.sil.org/resources/archives/2384</a>).

Adapted from **Why use the “Bartholomew” dictionary configuration?** (By Thomas Willett, SIL AmArea linguistics consultant). The PDF of the entire document in English or in Spanish is available. See <a href="https://software.sil.org/fieldworks/support/technical-documents/" target="_blank" title="https://software.sil.org/fieldworks/support/technical-documents/">https://software.sil.org/fieldworks/support/technical-documents/</a>.

> [!IMPORTANT]
>
> - **\[References Section\]** is [only used](Main_Minor_entry.md) in the Hybrid layout.
>
> <!-- -->
>
> - **Minor Subentries** is another configuration node that is only used in this layout. It allows you to display complex forms as minor (*brief*) subentries in addition to their display as main entries.
>
> Consider an entry that has a referenced complex form.
>
> If *both* the [Referenced Complex Form](../../../Field_Descriptions/Lexicon/Lexicon_Edit_fields/Publication_Settings_flds/Referenced_Complex_Forms_Publication_Settings.md) and [Subentries](../../../Field_Descriptions/Lexicon/Lexicon_Edit_fields/Publication_Settings_flds/Subentries_(Publication_Settings).md) fields in that entry contain the complex form, then it appears as a subentry, indented and below that entry. You configure it for display with a [Minor Subentries](Minor_Subentries_(Hybrid_view).md) node.
>
> If that complex form is removed from the **Subentries** field, then it is displayed as an **Other Referenced Complex Form**, and configured for display by an [Other Referenced Complex Form](Other_Referenced_Complex_Forms.md) node.
