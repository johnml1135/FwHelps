# Choose a dictionary layout

*User Interface › Menus › Tools › Configure Dictionary*

Do these steps to choose a [layout](Dictionary_views.md) from inside the **Configure Dictionary** dialog box:

1.  In the **Navigation Pane**, click **Lexicon**, and then click **Dictionary** or **Lexicon Edit**.

2.  On the **Tools** menu, point to **Configure**, and then click **Dictionary**.

    The **Configure Dictionary** dialog box opens.

3.  Do *one* of these steps:

    - Below **Choose the layout to configure**, click the down arrow (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/ChooseViewDownArrow.png)), and then click a layout.

    - Click **Manage Layouts** to [use](Manage_Dictionary_Views.md) the **Manage Dictionary Layouts** dialog box.\
      In the left pane, click a layout. Click **Close**.

The name of the layout appears at the top of the **Configure Dictionary** dialog box.

4.  Click **OK** to close the dialog box *or* [configure](Using_the_Configure_Dictionary_dialog_box.md) that layout.

> [!TIP]
>
> - Alternatively, [select](../../../../Using_Tools/Lexicon_tools/Dictionary/Select_a_dictionary_view.md) (![](../../../../assets/images/Using_Tools/Lexicon_tools/Dictionary/SelectedViewCheckBox.png)) a Dictionary layout.
>
> - The layout affects what you see in **Dictionary**, the [Dictionary preview pane](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/About_Lex_Edit_fld_levels.md), and the [Dictionary Entry](../Dictionary_Entry_dialog_box.md) **dialog box**.
>
> - When you [Configure Headword numbers](../Configure_Headword_Numbers/Config_Hdwrd_Numbers_dialog_box.md), the configuration is for the *current* layout only.
