# Pictures

*User Interface › Menus › Tools › Configure Dictionary*

In the [left pane](About_the_left_pane.md), **Pictures** appears under **Main Entry**. For [Hybrid](About_the_Hybrid_Dictionary_view.md) layouts, **Pictures** also appears below **Main Entry**/**Minor Subentries**.

<table width="100%">
<tbody>
<tr>
<th><p><strong>Example (Root-based)</strong></p></th>
<th><p><strong>Description</strong></p></th>
</tr>
&#10;<tr>
<td><p><img src="../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/Pictures.PNG" /></p></td>
<td><p>If selected (<img src="../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/CheckedBox.PNG" />), contents from these fields are displayed:</p>
<ul>
<li><p><strong>Thumbnail</strong> refers to the actual picture as stored in a <a href="../../../Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Thumbnail_field.md">Thumbnail</a> field. You can only choose to show or hide it.</p></li>
<li><p><strong>Caption (or Headword)</strong> allows you to display content from the <a href="../../../Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/caption_field.md">Caption</a> field, or the headword if there is not a caption to display.</p></li>
<li><p><strong>Caption</strong> allows you to display content from the <a href="../../../Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/caption_field.md">Caption</a> field. If <strong>Caption (or Headword)</strong> is also selected, duplicate content can appear.</p></li>
<li><p><strong>Headword</strong> allows you to display the headword (Lexeme or Citation) of the entry. If <strong>Caption (or Headword)</strong> is also selected, duplicate content can appear.</p></li>
<li><p><strong>Gloss</strong> allows you to display content from the <strong>Gloss</strong> <a href="../../../Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Gloss_field_Sense.md">field</a>.</p></li>
<li><p><strong>Creator</strong> and <strong>Copyright &amp; License</strong> content comes from the <strong>Credit, Copyright and License</strong> <a href="../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Using_Credit_Copyright_License_dialog_box.md">dialog box</a>. Be aware that Copyright information is required for <a href="../../File/Upload_to_Webonary.md">Webonary</a>.</p></li>
</ul>
<p>Some selections allow you to choose one or more writing systems, styles and surrounding context (before or after).</p>
<p><strong>Document Picture Settings</strong> has controls that help you position pictures for their appearance MS Word™ and other <a href="../../File/Export/Export_overview.md">export</a> destinations.</p>
<ul>
<li><p><strong>Alignment</strong>: You can choose <strong>Left</strong>, <strong>Center</strong> or <strong>Right</strong>.</p></li>
<li><p><strong>Max Width (inches)</strong>: Type the maximum width in inches, such as 2.1 or whatever you learn works best for the pictures.</p></li>
<li><p><strong>Max Height (inches)</strong>: Type the maximum height in inches, such as 1.1 or whatever you learn works best for the pictures.</p></li>
</ul>
<blockquote>
<p></p>
<ul>
<li><p>FieldWorks uses the max height and max width as upper bounds on the height and width.</p></li>
</ul>
<p>If a picture is <em>smaller </em>than that, nothing happens. It does not increase the size of a picture if its resolution is smaller than the upper bounds given for height/width.</p>
<p>If a picture is <em>bigger</em> than either the max height or width, it is sized down, maintaining aspect ratio, until it satisfies the max height and max width bounds you entered.</p>
</blockquote></td>
