# Display each sense in a paragraph

*User Interface › Menus › Tools › Configure Dictionary*

1.  In the [left pane](About_the_left_pane.md), click an instance of **Senses** to *highlight* it (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/Sense_Num_Config.PNG)).

2.  In the *right* pane, select (![](../../../../assets/images/CheckedBox.PNG)) or clear (![](../../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)) **Display each sense in a paragraph**.

If selected (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/CheckedBox.PNG)), the **starting with second sense** check box also appears.

1.  - If the **starting with second sense** check box is selected (![](../../../../assets/images/CheckedBox.PNG)), then the second and subsequent [senses](Senses_Subsenses.md) will appear on a *separate* paragraph for the selected [view](Dictionary_views.md). If it is cleared (![](../../../../assets/images/UncheckedBox.PNG)), then the first sense will also appear in a separate paragraph.

    - The **Before**, **Between** and **After** boxes are *hidden*.

    - You can choose a paragraph style (![](../../../../assets/images/User_Interface/Menus/Format/Styles/Paragraph_symbol.GIF)) for content.

If cleared (![](../../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)):

- You can use the **Before**, **Between** and **After** boxes.

- You choose a character style (![](../../../../assets/images/User_Interface/Menus/Format/Styles/Character_symbol.GIF)).

3.  [Configure sense number](Sense_No_Config_Dict.md), as necessary.

> [!TIP]
>
> - You can do the steps above for **Subsenses**, except the check box is called **Display each subsense in a paragraph**.
