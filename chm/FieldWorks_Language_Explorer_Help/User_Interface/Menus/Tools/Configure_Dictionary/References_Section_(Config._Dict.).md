# [References Section] (Config. Dict.)

*User Interface › Menus › Tools › Configure Dictionary*

[Hybrid](About_the_Hybrid_Dictionary_view.md) layouts only.

In the [left pane](About_the_left_pane.md), **\[References Section\]** appears below **Main Entry** and below **Main Entry (Complex Forms)**.

*Left* pane:

- Use ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/UpArrowButton2.png) (**Move Up**) or ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/DownArrowButton2.png) (**Move Down**) to move fields or other nodes (![](../../../../assets/images/Plus_sign_box.GIF)) into or out of a **\[References Section\]** node to make a custom *collection*.

  - Move fields or nodes in the collection to set their order.

- If you [duplicate](Duplicate_Dict_field.md) the **\[References Section\]** node, the copy (e.g. **\[References Section\](1)**) does not have any fields or nodes. Initially, it is an *empty* collection. You can move fields or nodes between the original and the copy, or move in other fields or nodes.

- Use up arrows or down arrows to reorder the original and copy.

*Right* pane:

- Type notes about the configuration in the box.

- Select (![](../../../../assets/images/CheckedBox.PNG)) or clear (![](../../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)) the **Display group in a paragraph** check box.\
  If selected, any contents controlled from within **\[References Section\]** is appears in a single separate paragraph, that initially uses the **Block Quote** style.\
  If cleared, the contents wrap as part of the main entry, unless one of the items, such as **Other Referenced Complex Forms**, has a separate check box that allows the contents to appear in a separate paragraph.
