# About the left pane

*User Interface › Menus › Tools › Configure Dictionary*

The "left pane" in the **Configure Dictionary** **dialog box has** a hierarchical list of fields and nodes (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/Plus_box_expand.GIF)). Each [layout](Dictionary_views.md) has a slightly different hierarchical list.

- There are two *or* three top-level nodes [(examples)](Main_Minor_entry.md).

When you expand (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/minus_sign_box.GIF)) nodes, you see fields or other nodes that form the various parts of the entry.

  - Some are [fields](../../../Field_Descriptions/field_descriptions_overview.md) that appear in **Lexicon Edit.**

  - Others are fields that do *not* appear in **Lexicon Edit**. For example, the **Location** field (under **Pronunciations**) has **Abbreviation** and **Name** fields although the abbreviation is stored *only* in **Lists**.

<!-- -->

- Fields and nodes can appear *more than one time.* You can configure the display of fields and nodes in main entries separately from their appearances in minor entries, subentries, cross references, lexical relations and so on.

- To help you find the appropriate instance of a field or node, use the [right-click command](../../../../Using_Tools/Lexicon_tools/Dictionary/Use_right-click_to_help_configure_Dictionary_view.md) whenever possible.
