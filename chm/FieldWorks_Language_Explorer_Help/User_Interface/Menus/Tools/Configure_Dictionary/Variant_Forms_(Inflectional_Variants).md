# Variant Forms (Inflectional-Variants)

*User Interface › Menus › Tools › Configure Dictionary*

[Hybrid](About_the_Hybrid_Dictionary_view.md) layouts only.

In the [left pane](About_the_left_pane.md), **Variant Forms (Inflectional Variants)** typically appears in each of the [\[References Section\]](References_Section_(Config._Dict.).md) nodes. You configure each instance separately.

- In the *right* pane, select (![](../../../../assets/images/CheckedBox.PNG)) each [variant type](../../../../Using_Tools/Lists_tools/About_Variants.md) you want to display.

Optionally, you can do the following:

  - In the *left* pane, [duplicate](Duplicate_Dict_field.md) **Variant Forms (Inflected Variants)**. Then, select different types to display in each instance.

  - Use up arrows or down arrows to reorder the instances (*left* pane) or selected types (*right* pane).

When the entry (*not* a specific sense of the entry) is [chosen](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_Variant_of_entry.md) for a variant form, you use **Variant Forms** to configure *references to variant forms* (as they appear in the primary entry).
