# Writing Systems

*User Interface › Menus › Tools › Configure Dictionary*

When you click some of the fields or nodes (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/Plus_box_expand.GIF)) in the [left pane](About_the_left_pane.md), the *right* pane displays **Writing Systems**. Depending on what you clicked in the left pane, the listed writing systems are either the vernacular or the analysis.

Typically, the top item is **Default Vernacular** or **Default Analysis**. Then, the name of that default writing system is listed, along with any others.

### Example

In this example, Sena is the default vernacular. If you select (![](../../../../assets/images/CheckedBox.PNG)) **Default Vernacular** or **Sena**, you get the same writing system.

![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/Writing_SystemsRightPane.png)

If two or more writings are selected (![](../../../../assets/images/CheckedBox.PNG)):

- Select (![](../../../../assets/images/CheckedBox.PNG)) **Display Writing System Abbreviations** if you want to display [abbreviations](../../../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Writing_System_Properties_General_tab.md).

- You can click ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/UpArrowButton2.png) (**Move Up**) or ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/DownArrowButton2.png) (**Move Down**) to reorder the writing systems.
