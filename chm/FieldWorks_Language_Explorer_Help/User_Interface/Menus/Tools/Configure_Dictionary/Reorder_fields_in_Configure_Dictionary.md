# Reorder fields or Nodes in Configure Dictionary

*User Interface › Menus › Tools › Configure Dictionary*

In the **Configure Dictionary** dialog box, you can move fields and nodes (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/Plus_box_expand.GIF)) to change their order. This changes the display of data in the [Dictionary](../../../../Using_Tools/Lexicon_tools/Dictionary/Dictionary_overview.md), [preview pane](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/About_Lex_Edit_fld_levels.md), [Dictionary Entry](../Dictionary_Entry_dialog_box.md) dialog box and in configured [exports](../../File/Export/Export_a_configured_dictionary.md).

In the [left pane](About_the_left_pane.md), do these steps:

1.  Click the label of the field or node that you want to move.

    The name is highlighted, such as ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/Selected_duplication_item.PNG).

2.  Click ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/UpArrowButton2.png) (**Move Up**) or ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/DownArrowButton2.png) (**Move Down**) to move it up or down in the list.

    - Click the button until it is in the desired location *or* you come to the limit of where it can appear.

> [!TIP]
>
> - You can [duplicate](Duplicate_Dict_field.md) and [delete](Delete_dup_Dict_field.md) duplicated fields or nodes.
>
> - For the [Hybrid](About_the_Hybrid_Dictionary_view.md) layout, you do this to move fields and nodes into or out of the [\[References Section\]](References_Section_(Config._Dict.).md) collection.
>
> - You can also reorder fields and nodes in similar dialog boxes, such as **Configure Reversal Index**.
