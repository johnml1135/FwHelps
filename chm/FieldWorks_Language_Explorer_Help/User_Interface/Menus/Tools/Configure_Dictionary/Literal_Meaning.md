# Literal Meaning

*User Interface › Menus › Tools › Configure Dictionary*

In the [left pane](About_the_left_pane.md), **Literal Meaning** appears under **Main** **Entry**, **Minor Entry (Complex Forms)**, **Minor Entry (Variants)** and **Subentries**.
