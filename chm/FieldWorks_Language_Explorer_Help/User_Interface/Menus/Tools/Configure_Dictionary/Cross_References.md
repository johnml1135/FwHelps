# Cross References

*User Interface › Menus › Tools › Configure Dictionary*

In the [left pane](About_the_left_pane.md), **Cross References** appears under **Main Entry**, **Minor Entry (Complex Form)**, **Minor Entry (Variants)** and **Subentries**. For [Hybrid](About_the_Hybrid_Dictionary_view.md) layouts, see also [\[References Section\]](References_Section_(Config._Dict.).md) and [Variant Forms (Inflected Variants)](Variant_Forms_(Inflectional_Variants).md).
