# Variants of Sense

*User Interface › Menus › Tools › Configure Dictionary*

In the [left pane](About_the_left_pane.md), there are multiple instances of **Variants of Sense** in all [layouts](Dictionary_views.md). You configure each instance separately.

- In the *right* pane, select (![](../../../../assets/images/CheckedBox.PNG)) each [variant type](../../../../Using_Tools/Lists_tools/About_Variants.md) you want to display.

Optionally, you can do the following:

  - In the *left* pane, [duplicate](Duplicate_Dict_field.md) **Variants of Sense**. Then, select different types to display in each instance.

  - Use up arrows or down arrows to reorder the instances (*left* pane) or selected types (*right* pane).

When a *specific sense* of the primary entry is [selected](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_Variant_of_entry.md) for a [variant form](../../../../Using_Tools/Lists_tools/About_Variants.md), you use **Variant of Sense** to configure *references to variant forms* (as they appear in the primary entry).
