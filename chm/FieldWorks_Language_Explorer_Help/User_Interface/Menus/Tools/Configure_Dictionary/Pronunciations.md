# Pronunciations

*User Interface › Menus › Tools › Configure Dictionary*

In the [left pane](About_the_left_pane.md), **Pronunciations** appears under **Main** **Entry**, **Minor Entry (Complex Forms)**, **Minor Entry (Variants)** and **Subentries**.

<tbody>
<tr>
<th><p><strong>Example</strong></p></th>

&#10;<tr>
<td><p><img src="../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/Pronunciations.PNG" /></p></td>

<tr>
<td><p>If selected (<img src="../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/CheckedBox.PNG" />), contents from these fields are displayed:</p>
<ul>
<li><p><a href="../../../Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Pronunciation_field.md">Pronunciation</a> field</p></li>
</ul>

A play button <img src="../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/AudioPronunciation.png" /> is displayed.</p>
<ul>
<li><p><a href="../../../Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/cv_pattern_field.md">CV Pattern</a> field</p></li>

<li><p><a href="../../../Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Location_field.md">Location</a> field: <a href="../../../Field_Descriptions/Lists/Locations_fields/abbreviation_field_locations.md">abbreviation</a>, <a href="../../../Field_Descriptions/Lists/Locations_fields/location_name_field_locations.md">name</a> and <a href="../../../Field_Descriptions/Lists/Locations_fields/alias_field_locations.md">alias</a> from the <strong>Locations</strong> <a href="../../../../Using_Tools/Lists_tools/List_item_usage_table.md">list</a>.</p></li>
<li><p><strong>Pronunciation Media -</strong> You can choose the style or add contents in the <strong>Before</strong>, <strong>Between</strong> or <strong>After</strong> boxes.</p></li>
</ul>
<p>If you <a href="../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_link_to_sound_or_movie.md">inserted</a> a sound or movie file in a pronunciation, select (<img src="../../../../assets/images/CheckedBox.PNG" />) <strong>Media Files</strong> to display a play button: <img src="../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/AudioVideoMedia.png" /> (audio), <img src="../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/VideoMedia.png" /> (video).</p></td>
