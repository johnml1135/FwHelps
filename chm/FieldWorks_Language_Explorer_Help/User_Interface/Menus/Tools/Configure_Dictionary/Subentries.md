# Subentries

*User Interface › Menus › Tools › Configure Dictionary*

[Root-based](Dictionary_views.md) layouts only.

In the [left pane](About_the_left_pane.md)**,** **Subentries** appears under **Main** **Entry**.

(For [Hybrid](About_the_Hybrid_Dictionary_view.md) layouts, see [Minor Subentries](Minor_Subentries_(Hybrid_view).md).)

<table width="100%">
<tbody>
<tr>
<th><p><strong>Example</strong></p></th>
<th><p><strong>Description</strong></p></th>
</tr>
&#10;<tr>
<td><p><img src="../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/Subentries.PNG" /></p></td>
<td><p>With <strong>Subentries</strong> selected, you can do the following (<em>optional</em>):</p>
<ul>
<li><p>In the <em>left</em> pane, you can <a href="Duplicate_Dict_field.md">duplicate</a> <strong>Subentries</strong>, and then select different complex forms to display in each instance.</p></li>
<li><ul>
<li><p>Reorder the instances (<em>left</em> pane) using up arrows or down arrows.</p></li>
</ul></li>
<li><p>In the <em>right</em> pane, select (<img src="../../../../assets/images/CheckedBox.PNG" />) each <a href="../../../../Using_Tools/Lists_tools/About_complex_forms.md">complex form type</a> you want to display.</p></li>
<li><ul>
<li><p>Reorder the selected types (<em>right</em> pane) using up arrows or down arrows.</p></li>
</ul></li>
<li><p>Select (<img src="../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/CheckedBox.PNG" />) or clear (<img src="../../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG" />) <strong>Display each Subentry in a paragraph</strong>. If selected, the <strong>Before</strong>, <strong>Between</strong> and <strong>After</strong> boxes are hidden (<em>right</em> pane).</p></li>
<li><p>Choose a paragraph style for content or use the <strong>Styles</strong> button to work with the style.</p></li>
</ul>
<p>Set the order of subentries in the <a href="../../../Field_Descriptions/Lexicon/Lexicon_Edit_fields/Publication_Settings_flds/Subentries_(Publication_Settings).md">Subentries</a> field (<strong>Publication Settings</strong>) and <a href="../../../Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Subentries_(Sense).md">Subentries</a> field (<strong>Senses</strong>).</p></td>
</tr>
<tr>
<td colspan="2"><p>Below <strong>Subentries</strong> is set of fields that is similar to <strong>Main Entry</strong>. You can:</p>
<ul>
<li><p>display different content in indented subentries as compared to content in main entries or minor entries</p></li>
<li><p>configure similar content separately</p></li>
<li><p>display <strong>Subsubentries</strong> (subentries <em>of subentries</em>). It will be configured the same as <strong>Subentries</strong>. You can add a custom paragraph style for subsubentries and customize the indentation values.</p></li>
</ul></td>
</tr>
