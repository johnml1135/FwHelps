# Delete a duplicated field or node

*User Interface › Menus › Tools › Configure Dictionary*

The **Configure Dictionary** **dialog box allows you to** [duplicate](Duplicate_Dict_field.md) (copy) a field or node (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/Plus_box_expand.GIF)).

To delete an unwanted copy, do these steps:

1.  In the [left pane](About_the_left_pane.md), click the unwanted copy.

If you click an *original* layout, then the button is *not* available (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/RemoveButtonUnavailable2.png)).

2.  Click ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/DeleteConfiguration.png) (**Delete**).

The copy of the field or node is deleted.
