# Dictionary Entry dialog box

*User Interface › Menus › Tools › Find in Dictionary*

A ![](../../../assets/images/User_Interface/Menus/Tools/FindInDictionary.GIF) **Find in Dictionary** *command* is available on the [Insert](../../Toolbars/Insert_toolbar.md) toolbar, [Tools](Tools_overview.md) menu and [right-click](../../../Basic_Tasks/Show_data/Context_sens_menus.md) menu when you click a vernacular word in a [Texts & Words](../../../Using_Tools/Texts_%26_Words_tools/Texts_and_Words_overview.md) **Baseline** tab or in a [Notebook](../../../Using_Tools/Notebook_tools/Record_Edit_overview/Record_Edit_overview.md) record.

This *command* opens the ![](../../../assets/images/FindEntry.GIF) **Find in Dictionary** *dialog box* if FLEx cannot find the word nor any of its morphemes in **Lexicon Edit**. Otherwise, the **Dictionary Entry** dialog box appears.

The **Dictionary Entry** dialog box displays any of these lexical data:

- Roots/stems/affixes used in the word analysis or analyses.

- Multiple entries, such as when an analysis identified one root/stem entry and the lexicon also contains one or more other matches.

- Entries with homograph numbers (homophones).

## Things you can do

- Click an entry in the **Dictionary Entry** dialog box and then click the **Open Lexicon** button to go to that entry in [Lexicon Edit](../../../Using_Tools/Lexicon_tools/Lexicon_Edit/lexicon_edit_overview.md).

- Click the **Other** button to open the ![](../../../assets/images/User_Interface/Menus/Tools/FindEntry.GIF) **Find in Dictionary** dialog box.

> [!TIP]
>
> - This preview reflects the [configurations](Configure_Dictionary/Configure_Dictionary.md) set for the **Dictionary** layout.
>
> - For a word [flagged](../../../Basic_Tasks/Spell_Checking/Spell_checking_overview.md) with a wavy red underline, the right-click menu will not show **Find in Dictionary**.
>
> - In [Concordance](../../../Using_Tools/Texts_%26_Words_tools/Concordance/Concordance_overview.md), specify concordance criteria, either [manually](../../../Using_Tools/Texts_%26_Words_tools/Concordance/Manually_specify_concordance_criteria.md) or "[automatically](../../../Using_Tools/Texts_%26_Words_tools/Concordance/specify_concordance_criteria.md)" as necessary.
