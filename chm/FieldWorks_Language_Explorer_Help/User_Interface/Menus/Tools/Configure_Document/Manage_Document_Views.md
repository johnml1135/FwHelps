# Manage Document Layouts

*User Interface › Menus › Tools › Configure Document*

1.  On the Navigation Pane, click **Notebook**, and then click **Document**.

2.  On the **Tools** menu, point to **Configure**, and then click **Document**.

    The **Configure Document Layout** dialog box appears.

3.  Below **Choose document layout to configure**, click the **Manage Layouts** link.

    The **Manage Document Layout** dialog box appears.

4.  Do any of the following:

    - Add a custom layout:

      Click the layout you want to copy, and then click **Copy**. Then, [configure](Configuring_a_Document_view.md) that layout.

    - Rename a previously-added custom layout:

      Click the layout to make the name editable. Edit the name.

    - Delete a layout:

      Click a previously-added custom layout, and click **Delete**. The **Delete Document Layout** question box appears. Click **Yes**.

5.  Click **OK**.

> [!TIP]
>
> Shortcut keys for the **Manage Document Layout** dialog box are:
>
> - `Alt+C` for copy
>
> - `Alt+D` for delete
>
> - `Alt+H` for Help
>
> - The `Tab` key moves the focus from top to bottom, and then left to right through the layouts and buttons.
>
> - - Pressing the **Enter** key is the same as clicking the button with the focus.
