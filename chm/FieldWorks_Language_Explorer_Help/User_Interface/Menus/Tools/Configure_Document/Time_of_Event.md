# Time of Event

*User Interface › Menus › Tools › Configure Document*

Here is an example of subordinate (under) items you can configure. Click ![](../../../../assets/images/Plus_sign_box.GIF) to expand and display subordinate items. Under [Classifications](Classifications.md) various fields are listed. Each of these fields store data that help classify the record.

One of these classifiers is the **Time of Event**.

<p><img src="../../../../assets/images/User_Interface/Menus/Tools/Configure_Document/Time%20of%20Event.PNG" /></p></td>

<h3 id="check-boxes">Check boxes</h3>
<ul>
<li><p>If the <strong>Time of Event</strong> check box is selected (<img src="../../../../assets/images/User_Interface/Menus/Tools/Configure_Document/CheckedBox.PNG" />), then the selected items under will be displayed. In this example, the <strong>Name</strong> will be displayed, but <em>not</em> the <strong>Abbreviation</strong>.</p></li>
<li><p>If the <strong>Time of Event</strong> check box is cleared (<img src="../../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG" />), then the <strong>Name</strong> is not display, even though it is selected.</p></li>
</ul>

Then, the right pane shows the appropriate configuration options so you can <a href="Configuring_a_Document_view.md">configure</a> the appearance of the item, including surrounding context and <a href="Configuring_Document_view_styles.md">styles</a>.</p></li>
</ul></td>
