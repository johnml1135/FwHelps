# User interface languages for lists

*User Interface › Menus › Tools › Options*

List content in languages other than English are available in [language packs](Language_Packs_example.md). You can [import](../../../../Beginning_Tasks/Importing_Data/Import_Translated_List_Content.md) translated lists. Also, if you [add a writing system](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) that has translated list data, that data is included when you add the writing system.

- *You see this list content when the* default *analysis [writing system](../../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) matches the installed language pack.*

List content can include (*not* exhaustive):

- list item names, abbreviations and descriptions

- **Semantic Domain** list questions

- Parts of speech

- Words like prefix, suffix, inflectional, compound, and synonym.

After you have installed the language pack, that content will be available for any *new* project you *subsequently* [create](../../File/Create_a_new_Fieldworks_project.md).
