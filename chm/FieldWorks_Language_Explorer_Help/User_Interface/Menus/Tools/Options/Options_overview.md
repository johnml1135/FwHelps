# Options overview

*User Interface › Menus › Tools › Options*

On the **Tools** menu, click **Options**. The **Options** dialog box has three tabs:

## **General**

Do any of the following, then click **OK**:

- [Change the UI language](Change_Interface_Language.md) / [Install a UI language pack](Change_Interface_Language.md)

**See Also****:** [User interface languages for lists](User_interface_languages_for_lists.md), [Configure List](../Configure_List.md) and [Import translated list content](../../../../Beginning_Tasks/Importing_Data/Import_Translated_List_Content.md).

- Below **Advanced**:

- Select (![](../../../../assets/images/CheckedBox.PNG)) or clear (![](../../../../assets/images/UncheckedBox.PNG)) the **When I start Language Explorer, always open the last edited project automatically** check box. Another instance of this check box is available in the [Language Explorer](../../../../Overview/Welcome_to_FieldWorks.md) dialog box.

## **Plugins**

*Plugins* are user-created; consequently, they are not discussed in these User Helps. [Technical support](../../../../Overview/Technical_support.md) is probably necessary.

- Select a "plugin", if one is listed. Click **OK**.

## **Privacy**

- Select (![](../../../../assets/images/CheckedBox.PNG)) or clear (![](../../../../assets/images/UncheckedBox.PNG)) the **Send usage statistics to the FLEx developers** check box. Click **OK**.

- **See Also:** [Collection of Locale Data](../../../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Collection_of_Locale_data.md).

## **Updates (Windows® only)**

1.  Select (![](../../../../assets/images/CheckedBox.PNG)) or clear (![](../../../../assets/images/UncheckedBox.PNG)) the **Automatically download updates for FieldWorks** check box.

    - If selected, click the **Channel** control and then click which build you want: **Stable**, **Beta**, or **Alpha**.

In this case, you will be informed when an update from that channel has been downloaded.

You will be asked to restart FieldWorks to install it. Then, you will be asked if you want to install now.

2.  Click **OK**.

> [!TIP]
>
> - An index of updates that have been downloaded to your computer is here:
>
> C:\ProgramData\SIL\FieldWorks\DownloadedUpdates.
