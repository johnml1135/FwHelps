# Sense Number Configuration (ClassifiedDict)

*User Interface › Menus › Tools › Configure Classified Dictionary*

In the left pane of the **Configure Classified Dictionary Layout** [dialog box](Configure_Classified_Dictionary_View_dlgbox.md), if you click **Subsenses**, you see the **Sense Number Configuration** area. You can configure the display of subsenses.

1.  In the *left* pane of the **Configure** area, click **Subsenses** to *highlight* it (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Classified_Dictionary/HighlightedItem.png)).

    In the *right* pane, the center area is **Sense Number Configuration**.

2.  For **Sense Number Configuration**, do *one* of the following:

    - In the **Character** **Style** box, select **None**.

      **None** removes the sense number from dictionary entries the **Entries** pane, and also *disables* the other features in the **Sense Number Configuration** area.

    - In the **Character** **Style** box, select a number style. Then, do any of the following:

      - **Styles** button: If you want to work with [styles](../../Format/Styles/Styles_overview.md), click it to open the **Styles** dialog box.

      - **Before** box: enter any character or symbol you want to display before the sense numbers.

      - **Numbering Style** box: Click it and then click the numbering style you want to use.

      - **After** box: enter any character or symbol you want to display after the sense numbers.

      - If you want to display sense numbers even in entries with only one sense, select (![](../../../../assets/images/CheckedBox.PNG)) **Number even a single sense**. Otherwise, sense numbers will only appear in entries with multiple senses.

    3.  Select (![](../../../../assets/images/CheckedBox.PNG)) or clear (![](../../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)) any of these options:

- **If all senses share the grammatical information, show it first**. [Grammatical Info](../Configure_Dictionary/Grammatical_Info.md) has more details about this option.

- **Display each sense in a paragraph**.

- **Starting with the second sense**.

4.  If necessary, choose a style for the **Paragraph Style for Content**, or click the **Styles** button to work with styles.

5.  Continue to [configure](Configuring_a_Classified_Dictionary_view.md) the layout, or click **OK** to close the dialog box.
