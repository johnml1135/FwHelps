# Duplicate a field (ClassifiedDict)

*User Interface › Menus › Tools › Configure Classified Dictionary*

In the **Configure Classified Dictionary Layout** [dialog box](Configure_Classified_Dictionary_View_dlgbox.md), you can duplicate a field or node (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Classified_Dictionary/Plus_box_expand.GIF)) for display in the [Classified Dictionary](../../../../Using_Tools/Lexicon_tools/Classified_Dictionary/Classified_Dictionary_overview.md), and configured [exports](../../File/Export/Export_a_Classified_Dictionary.md). You configure the duplicate and original separately, such as with different writing systems or surrounding context.

In the left side of the **Configure** pane, do the following:

1.  Click the name of the field or node that you want to duplicate.

    The name is *highlighted* (such as ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Classified_Dictionary/Definition.png)).

2.  Click ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Reversal_Index/DuplicateButton.png) (Duplicate).

    A copy appears in the *left* pane, below the original. It has a copy number in parentheses (such as ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Classified_Dictionary/Definition1.png)).

3.  [Configure](Configuring_a_Classified_Dictionary_view.md) the copy and original *separately*.

### Example

Suppose a field has data in two different analysis writing systems and you want to change the order in which they are presented for this field.

- You could do this:

  Click the name of the field in the *left* pane. Then in the *right* pane, click the name of one of the writing systems and click the up arrow ![](../../../../assets/images/User_Interface/Menus/Tools/Up_arrow.PNG) or down arrow ![](../../../../assets/images/User_Interface/Menus/Tools/Down_arrow.PNG) to change the order of the writing systems.

- Alternatively, you could do this:

  Click the name of the field in the *left* pane, and then click **Duplicate**. In the *right* pane, select (![](../../../../assets/images/CheckedBox.PNG)) the analysis writing system you want to display *last*. Clear the check box (![](../../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)) for the other writing system.\
  In the *left* pane, click the original field name. Then in the *right* pane, select (![](../../../../assets/images/CheckedBox.PNG)) the analysis writing system you want to display *first*. Clear the check box for the other writing system.

  Only the duplicate method lets you apply character styles and surrounding context independently.

> [!TIP]
>
> In the *left* pane, the order of the fields or field sets determines the order that their data are displayed.
>
> - You can use the up arrow or down arrow in the *left* pane to change the order of fields or field sets, such as to move the duplicate field above the original field.
