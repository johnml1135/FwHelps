# Configure Classified Dictionary dialog box

*User Interface › Menus › Tools › Configure Classified Dictionary*

1.  In the **Navigation Pane**, click **Lexicon**, and then click **Classified Dictionary**.

2.  Do one of these steps:

    - In the **Classified Dictionary** pane, [use](../../../../Using_Tools/Lexicon_tools/Classified_Dictionary/Use_right-click_to_help_configure_Classified_Dictionary_view.md) the right-click menu command.

    - On the **Tools** menu, point to **Configure**, and then click **Classified Dictionary**.

The **Configure Classified Dictionary** dialog box opens.

3.  In the **Configure Classified Dictionary** dialog box, do any of the following:

    - Click the **Manage Layouts** button to open the **Manage Classified Dictionary Layouts** [dialog box](Manage_Classified_Dictionary_Views.md).

This includes duplicating, renaming, importing, exporting and more.

- [Configure a layout](Configuring_a_Classified_Dictionary_view.md).
