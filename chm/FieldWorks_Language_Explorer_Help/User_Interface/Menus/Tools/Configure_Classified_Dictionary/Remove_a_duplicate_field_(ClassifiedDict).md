# Remove a duplicate field (ClassifiedDict)

*User Interface › Menus › Tools › Configure Classified Dictionary*

The **Configure Classified Dictionary Layout** [dialog box](Configure_Classified_Dictionary_View_dlgbox.md) **allows you to** [duplicate](Duplicate_a_field_(ClassifiedDict).md) a field or node (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Classified_Dictionary/Plus_box_expand.GIF)) so you can configure each one separately.

Do these steps to remove an unwanted copy:

1.  In the **Configure Classified Dictionary Layout** dialog box, click the unwanted copy.

2.  Click ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/DeleteConfiguration.png) (Delete).

3.  Click **OK**.

> [!NOTE]
>
> - If you click the *original*, the button is *not* available (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/RemoveButtonUnavailable2.png)).
>
> <!-- -->
>
> - Each duplicate has a number, such as with a **(1)**, **(2)** and so on. The originals are *not* numbered.
