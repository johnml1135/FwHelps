# Related Words dialog box

*User Interface › Menus › Tools › Find in Dictionary*

Some linguistic software integrates with FieldWorks Language Explorer (FLEx) to provide a command: **Find Related Words**. Typically, you right-click a word to display the command in a pop-up menu. It opens the **Find Related Words** dialog box, which is part of FLEx.

The dialog box lists any words that have the same gloss, and any words that are related by semantic domains ([chosen](../../../Using_Tools/Lexicon_tools/Lexicon_Edit/choose_semantic_domains.md) for the word in FLEx)

- If *no* related words are found, an information box appears. Click **OK**.

- If related words are found, click a word in the dialog box, and then use any of these buttons:

  - **Lookup** displays the dictionary entry for the word in the lower portion of this dialog box.

  - **Copy** copies the word to the clipboard, so it is available to paste.

  - **Close** closes the dialog box.

> [!TIP]
>
> - If FLEx is open, you might have to minimize the other software window to see the **Related Words** dialog box.
>
> - You cannot display this dialog box from inside FLEx.
