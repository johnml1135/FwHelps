# Find in Dictionary overview

*User Interface › Menus › Tools › Find in Dictionary*

A ![](../../../assets/images/User_Interface/Menus/Tools/FindInDictionary.GIF) **Find in Dictionary** *command* is available on the [Insert](../../Toolbars/Insert_toolbar.md) toolbar, [Tools](Tools_overview.md) menu and [right-click](../../../Basic_Tasks/Show_data/Context_sens_menus.md) menu when you click a vernacular word in a [Texts & Words](../../../Using_Tools/Texts_&_Words_tools/Texts_and_Words_overview.md) **Baseline** tab or in a [Notebook](../../../Using_Tools/Notebook_tools/Record_Edit_overview/Record_Edit_overview.md) record.

This *command* opens the ![](../../../assets/images/FindEntry.GIF) **Find in Dictionary** *dialog box* if FLEx cannot find the word nor any of its morphemes in **Lexicon Edit**. Otherwise, the [Dictionary Entry](Dictionary_Entry_dialog_box.md) dialog box appears.

## Things you can do

1.  In the **Find** box, type the lexical entry that you want to find.

Any matching entries appear in the **Lexical Entries** pane as you type.

2.  If the entry you want appears, click it and then click the **Show** button to see it in the **Dictionary Entry** dialog box.

3.  If the entry you want does *not* appear or many appear (so you cannot isolate the one you want), do any of these steps:

    - Change the spelling of the **Find** box content.

For example, type the spelling of the lexeme form or citation form.

2.  - Select a different writing system. Then, you can search for the lexical entry using that writing system.

For example, search for a gloss or definition. Or, you could search for it with a different vernacular writing system that is used in the project.

2.  - Click the ![](../../../assets/images/User_Interface/Menus/Tools/Conf_Columns_Button.GIF) button in the **Lexical Entries** pane to hide or display columns.

This does not affect the **Find** operation. However, the changed display may hint to you other ways to search for the entry.

1.  - Click the **Create** button to open the **New Entry** dialog box.

<!-- -->

4.  Click **Cancel**.

> [!TIP]
>
> - In the **Dictionary Entry** dialog box, the **Other** button opens this ![](../../../assets/images/FindEntry.GIF) **Find in Dictionary** dialog box.
>
> - For a word [flagged](../../../Basic_Tasks/Spell_Checking/Spell_checking_overview.md) with a wavy red underline, the right-click menu will not show **Find in Dictionary**.
>
> - In **Concordance**, specify concordance criteria, either [manually](../../../Using_Tools/Texts_&_Words_tools/Concordance/Manually_specify_concordance_criteria.md) or "[automatically](../../../Using_Tools/Texts_&_Words_tools/Concordance/specify_concordance_criteria.md)" as necessary.
