# Configure Headword Numbers dialog box - Classified Dictionary

*User Interface › Menus › Tools › Configure Headword Numbers*

A "headword" consists of the lexeme or citation form plus any homograph number. *A* *referenced* headword can also include the sense number if a specific sense was [chosen](../../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Choose_components_for_Components_field.md).

Use this dialog box to choose whether to hide homograph and sense numbers. If you choose to display them, you can work with styles.

The configuration you specify is for only the *current* **Classified Dictionary** [layout](../Configure_Classified_Dictionary/Manage_Classified_Dictionary_Views.md). So you configure headword numbers for each layout individually.

1.  Choose the **Classified Dictionary** layout that you want to change.

2.  Click a **Configure Headword Numbers** hyperlink to open the **Configure Headword Numbers** dialog box:

The hyperlink is displayed when you configure any node that controls the display of headwords.

3.  To hide all headword numbers, select (![](../../../../assets/images/SelectedRadioButton.png)) **Hide**. Then, click **OK**.

4.  To display headword numbers, select (![](../../../../assets/images/SelectedRadioButton.png)) **Before** or **After** to display numbers and to control whether they appear *before* or *after* the headword.

Then, do any of the following:

- Click the **Configure Style of Homograph Number** link to configure the **Homograph-Number** style.

- Below **References in Classified Dictionary should include (if significant)**, select or clear **Homograph Numbers**.

If selected (![](../../../../assets/images/CheckedBox.PNG)), any homograph numbers will appear with *referenced* headwords.

If cleared (![](../../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)), no homograph numbers are displayed.

- Below **References in Classified Dictionary should include (if significant)**, select or clear **Sense Numbers**.

If selected (![](../../../../assets/images/CheckedBox.PNG)), any sense numbers will appear with *referenced* headwords.

If cleared (![](../../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)), no sense numbers are displayed.

- Click the **Configure Style of Sense Reference Number** link to configure the **Sense-Reference-Number** style.

5.  Click **OK**.

> [!IMPORTANT]
>
> - **(if significant)** means that there is a homograph or sense number.
