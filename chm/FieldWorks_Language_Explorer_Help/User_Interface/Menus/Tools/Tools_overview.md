## Use or Accomplish

|  |  |
|----|----|
| To | Click |
| [add](Custom_Fields/add_a_custom_field.md), [modify](Custom_Fields/modify_a_custom_field.md) or [delete](Custom_Fields/Delete_a_custom_field.md) custom fields | **Custom Fields** |
| [merge lexical entries](../../../Using_Tools/Lexicon_tools/Lexicon_Edit/Merge_entries.md) | **Merge with entry** |
| open the [FieldWorks Project Utilities](Language_Project_Utilities_overview.md) dialog box | **Utilities** |
| use [Add Words to Lexicon](../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/About_Add_Words_to_Lexicon.md) ([Gloss](../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/texts_edit_overview.md) tab) | **Add Words to Lexicon** |
| preview a dictionary entry in the [Dictionary Entry](Dictionary_Entry_dialog_box.md) dialog box, or [Find in Dictionary](Find_in_Dictionary_overview.md) dialog box | **Find in Dictionary** |
| open the [Options](Options/Options_overview.md) dialog box to [change the User Interface language](Options/Change_Interface_Language.md), control automatic updates, or add a plug-in | **Options** |

## Spelling

|  |  |
|----|----|
| To | Point to Spelling, and then click |
| [specify the spelling status](../../../Using_Tools/Texts_%26_Words_tools/Bulk_Edit_Wordforms/bulk_change_spelling_status.md) of multiple words in **Bulk Edit Wordforms** | **Edit Spelling Status** |
| see the [spelling status](../../../Using_Tools/Texts_&_Words_tools/Word_Analyses/Specify_spelling_status.md) of multiple words in **Words Analyses** | **View Incorrect Words in Use** |
| show [flags](../../../Basic_Tasks/Spell_Checking/Spell_checking_overview.md) for possible *default vernacular* spelling errors (and create a [vernacular spelling dictionary](../../../Basic_Tasks/Spell_Checking/vernacular_spell_checking.md)) | ![](../../../assets/images/User_Interface/Menus/Tools/UnCheckMarkedSpellingCmd.PNG) **Show Vernacular Spelling Errors** (*to select it*) |
| hide flags for possible *default vernacular* spelling errors | ![](../../../assets/images/User_Interface/Menus/Tools/CheckMarkedSpellingCmd.PNG) **Show Vernacular Spelling Errors** (*to clear it*) |
| [change](../../../Using_Tools/Texts_%26_Words_tools/Word_Analyses/Change_Spelling/change_spelling_overview.md) multiple occurrences of a spelling | **Change Spelling** |
