# Configure Interlinear Lines dialog box

*User Interface › Menus › Tools › Configure Interlinear*

Use this dialog box to control which interlinear lines are displayed, the languages for each one and the order the lines appear.

1.  In the **Navigation Pane**, click **Texts & Words**, and then click **Interlinear Text**, **Concordance**, or **Word List Concordance**.

2.  Select the tab you want to configure (**Gloss**, **Analyze**, **Print View** or **Text Chart**).

3.  Do one of the following to open the **Configure Interlinear Lines** dialog box:

    - [Right-click](../../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Configure_Interlinear_lines_right_click.md) any of the headers for displayed interlinear lines (**Word**, **Morphemes**, **Free**, and so on), and then click **Configure Interlinear**.

    - On the **Tools** menu, point to **Configure**, and then click **Interlinear**.

      The **Configure Interlinear Lines** dialog box appears.

4.  In the dialog box, do *any* of the following:

    - To display a line in a particular writing system, select (![](../../../assets/images/CheckedBox.PNG)) a check box in the column.

    - To hide a line that uses a particular writing system, clear (![](../../../assets/images/UncheckedBox.PNG)) the check box in the column.

    - To reorder lines, click ![](../../../assets/images/User_Interface/Menus/Tools/DragLinesIcon.png) and drag one, or the set with a colored background, that you want to move up or down. Release the mouse button when it is where you want it. Repeat this step for other lines as desired.

5.  Click **OK**.

> [!NOTE]
>
> - Columns are writing systems.
>
> **Baseline** matches the writing system that was set for the **Baseline** tab. See: [Baseline text writing system](../../../Using_Tools/Texts_%26_Words_tools/Interlinear_Texts/baseline_text_writing_systems.md).
>
> **Best Analysis** is a smart column. See: [About writing systems](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md).
>
> - Selecting (![](../../../assets/images/CheckedBox.PNG)) a **Note** line does *not* insert one. [Insert](../../../Using_Tools/Texts_%26_Words_tools/Interlinear_Texts/Enter_a_Note.md) (![](AddNote_Texts.GIF) or **Ctrl+N**) them manually.
>
> - To reorder the writing systems for one particular field, [right-click](../../../Using_Tools/Texts_%26_Words_tools/Interlinear_Texts/Configure_Interlinear_lines_right_click.md) a writing system label used in that field in the interlinear view, and then click **Move Up** or **Move Down**.
>
> - You can display or hide [custom fields](Custom_Fields/Custom_Fields_overview.md).
>
> - To hide a line, see [Delete or hide an annotation](../../../Using_Tools/Texts_%26_Words_tools/Interlinear_Texts/Delete_Hide_an_annotation.md).
>
> - **Media** can display a line that shows a play button (![](../../../assets/images/User_Interface/Menus/Tools/PlayMedialineInterlinear.png)), with the start and stop times and speaker name. These are used if you [imported a FLExText file](../../../Beginning_Tasks/Importing_Data/Import_interlinear_data.md) that had an audio recording. These files could be from ELAN or SayMore.
>
> - You may want to select (![](../../../assets/images/CheckedBox.PNG)) all the check boxes to see the results, and then clear check boxes until what remains is what you want to see.
