# Custom Fields limits

*User Interface › Menus › Tools › Custom Fields*

There is a limit to the number of custom fields you can add. The maximum number can depend on the location (lexical entry, lexical sense, Notebook, and so on) and writing system(s) you select when you [add the custom fields](add_a_custom_field.md).

Tests show that you can add at least 100 custom fields.

*However*, the need for a large number of custom fields should prompt you to reconsider what you are trying to do. A large number of custom fields is not normally needed. If necessary, request advice from a language consultant, an experienced peer, or get [technical support](../../../../Overview/Technical_support.md).
