# Modify a custom field

*User Interface › Menus › Tools › Custom Fields*

Do the following steps:

1.  In the **Navigation** **Pane**, click the [area](../../../Toolbars/Navigation/Navigation_Pane_overview.md) that has the custom field you want to change.

2.  On the **Tools** menu, point to **Configure**, and then click **Custom Fields**.

    The **Custom Fields** dialog box appears.

3.  In the **Custom Fields** pane, click the custom field you want to change.

4.  In the **Settings** area, edit the contents in the **Custom Field Name** box or in the **Description** box.

5.  Click **OK**.

> [!TIP]
>
> - You cannot change the **Location** or **Writing System(s)** selections of an existing custom field.
>
> - If you edited the name, but the field label does not change [refresh](../../View/View_overview.md) the window, or close and reopen the project.
