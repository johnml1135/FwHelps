# Duplicate a field (Reversal Indexes)

*User Interface › Menus › Tools › Configure Reversal Index*

In the **<a href="Configure_Reversal_Index_dialog_box.md" style="font-weight: normal;">Configure Reversal Index</a> dialog box**, you can duplicate a field or node (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/Plus_box_expand.GIF)) for display in the **Reversal Indexes**. You can configure the original and copy separately, such as with different writing systems or surrounding context.

In the *left* pane, do the following:

1.  Click the label of field or node that you want to duplicate.

    The label is highlighted, such as ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Reversal_Index/Example.png).

2.  Click ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Reversal_Index/DuplicateButton.png) (**Duplicate**).

    A copy appears in the left pane, below the original. It has a copy number in parentheses. The copy is highlighted so you can edit the label and configure it.

3.  Optionally, click ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Reversal_Index/RenameDuplicateButton2.png) (**Edit Label**).

    - In the **Rename** dialog box, type a new "copy identifier" to replace the number in parentheses.

    - Click **OK**.

The copy identifier you typed appears after the name, which does *not* change.

4.  [Configure](../Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) the original and copy separately.

5.  Click **OK**.

> [!TIP]
>
> - In the *left* pane, the order of the fields or nodes determines the order that their data are displayed.
>
> You can use ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Reversal_Index/UpArrowButton2.png) or ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Reversal_Index/DownArrowButton2.png) (up or down arrow) in the *left* pane to change the order of fields or field sets, such as to move the copy above the original.
>
> - The example given in the [Duplicate a field (Dictionary)](../Configure_Dictionary/Duplicate_Dict_field.md) topic may also help you with reversal indexes.
