# Configure Reversal Index dialog box

*User Interface › Menus › Tools › Configure Reversal Index*

You use this dialog box to choose *which* data to display and *how* to display it in **Reversal Indexes** and in [exported](../../File/Export/Export_a_reversal_index.md) files.

1.  In the **Navigation Pane**, click **Lexicon**, and then click **Reversal Indexes**.

2.  Do one of the following to open the dialog box:

    - [Use a right-click menu command](../../../../Using_Tools/Lexicon_tools/Reversal_Indexes/Use_right-click_to_help_configure_Reversal_Index_view.md).

    - On the [Information bar](../../../Toolbars/information_bar_overview.md), click the down arrow (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Reversal_Index/TitleBarMenuButton.PNG)), and then click **Configure** **Reversal Index**.

    - On the **Tools** menu, point to **Configure**, and then click **Reversal Index**.

      The **Configure Reversal Index** dialog box appears.

3.  In the dialog box, do any of the following

    - Click **Manage Layouts** to [use](Manage_Views_Reversal_Index.md) the **Manage Reversal Index Layouts** dialog box.

    - Below **Choose the layout to configure** click the down arrow (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/ChooseViewDownArrow.png)) and then click an analysis writing system or **All Reversal Indexes**.

    - [Configure](Configuring_a_reversal_index_view.md) the selected layout.

4.  Click **OK**.

> [!TIP]
>
> - [Manage Views](Manage_Views_Reversal_Index.md) describes **All Reversal Indexes**.
