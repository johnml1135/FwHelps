# Choose a Reversal Index Layout

*User Interface › Menus › Tools › Configure Reversal Index*

Do these steps to choose a reversal index layout (writing system) from inside the **Configure Reversal Index** dialog box:

1.  In the **Navigation Pane**, click **Lexicon**, and then click **Reversal Indexes**.

2.  On the **Tools** menu, point to **Configure**, and then click **Reversal Index**.

    The **Configure Reversal Index** dialog box opens.

3.  Do *one* of these steps:

    - Below **Choose the layout to configure**, click the down arrow (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/ChooseViewDownArrow.png)), and then click a writing system.

    - Click **Manage Layouts** to [use](Manage_Views_Reversal_Index.md) the **Manage Reversal Index Layouts** dialog box.\
      In the left pane, click a layout. Click **Close**.

The name of the layout appears at the top of the **Configure Reversal Index** dialog box.

You can [configure](../Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) that layout, or simply click **OK** to close the dialog box.

> [!TIP]
>
> - Alternatively, [select](../../../../Using_Tools/Lexicon_tools/Reversal_Indexes/Select_a_Reversal_index_view.md) (![](../../../../assets/images/Using_Tools/Lexicon_tools/Dictionary/SelectedViewCheckBox.png)) a reversal index layout.
>
> - When you [Configure Headword numbers](../Configure_Headword_Numbers/Config_Hdwrd_Numbers_dialog_box.md), the configuration is for the *current* layout only.
