# Sense Number Configuration - Reversal Indexes

*User Interface › Menus › Tools › Configure Reversal Index*

In the **Configure Reversal Index** dialog box, a set of **Sense Number Configuration** controls appears when you click an instance of **Referenced Senses**.

1.  Click **Referenced Senses** (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Reversal_Index/Referenced_Senses.PNG)) if you want to configure the display the sense numbers that indicate how many senses a reversal index entry has.

2.  Do *one* of these steps in the **Sense Number Configuration** area:

    - In the **Numbering Style** box, select **(none)**.

**(none)** removes the sense number from reversal entries the **Reversal Index** pane. It also disables the other features in the **Sense Number Configuration** area.

1.  - In the **Numbering Style** box, select a numbering style (**1 2 3**, **A B C**, and so on).

Then, do *any* of the following:

1.  1.  - Choose a style using the **Character Style** down arrow.

        - Use the **Style** button to makes changes to [styles](../../Format/Styles/Styles_overview.md).

        - In the **Before** box enter any character or symbol you want to display *before* the sense numbers.

        - In the **Between** box, enter any character or symbol you want to display *between* the sense numbers.

        - In the **After** box, enter any character or symbol you want to display *after* the sense numbers.

        - Select (![](../../../../assets/images/CheckedBox.PNG)) **Number even a single sense** if you want to display sense numbers even if there is only one. Otherwise, sense numbers will only appear in reversal index entries that reference multiple senses.

> [!TIP]
>
> - [Referenced Headword](Referenced_Headword_Referenced_Senses.md) describes how to configure the sense numbers that are part of the referenced lexical headword.
>
> - [Configuring a Reversal Index Layout](Configuring_a_reversal_index_view.md) describes how to use the controls that are *below* the **Sense Number Configuration** controls.
