# Configuring a Reversal Index layout

*User Interface › Menus › Tools › Configure Reversal Index*

- [Use right-click to help configure the Reversal Index](../../../../Using_Tools/Lexicon_tools/Reversal_Indexes/Use_right-click_to_help_configure_Reversal_Index_view.md) (*optional*).

Do these steps in the **Configure Reversal Index** dialog box:

1.  [Choose the layout](Choose_a_Reversal_Index_view.md) you want to configure or **All Reversal Indexes**.

Click **Manage Layouts** to select layouts for publications, or to add, rename, delete, reset, export or import a layout.

2.  In the *left* pane, do any of these steps:

    - Click any node (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/Plus_box_expand.GIF)) to expand (![](../../../../assets/images/minus_sign_box.GIF)) that hierarchical list.

    - Select (![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/CheckedBox.PNG)) or clear (![](../../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)) check boxes to display or exclude data.

    - Click a label to *highlight* it (such as ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Reversal_Index/Example.png)). Then do any of these steps:

      - Use ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Reversal_Index/UpArrowButton2.png) (**Move Up**) or ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Reversal_Index/DownArrowButton2.png) (**Move Down**) to reorder fields or nodes.

      - Use ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Reversal_Index/DuplicateButton.png) (**Duplicate**), ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Reversal_Index/DeleteConfiguration.png) (**Delete**) or ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Reversal_Index/RenameDuplicateButton2.png)(**Edit Label**).

      - Click ![](../../../../assets/images/User_Interface/Menus/Tools/Configure_Dictionary/HighlightButton.png) (*Highlight Affected Content*). Data controlled by the highlighted item gets a yellow background in the preview pane.

3.  In the *right* pane, there are many optional things you can do for a selected *and* highlighted field or node.

    - **See:** [Reversal Form](Reversal_Form.md), [Reversal Category](Reversal_Category.md), [Referenced Senses](Referenced_Senses.md), [Reversal Subentries](Reversal_Subentries.md), and [Referenced Complex Forms (Reversal Indexes)](Referenced_Complex_FormsRI.md).

    - **See Also:** Because the controls are similar, refer to the examples presented in [Using the Configure Dictionary dialog box](../Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md).

4.  Click **OK**.
