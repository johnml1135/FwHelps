# Configure List

*User Interface › Menus › Tools › Configure List*

You can configure a [custom list](../../../Using_Tools/Lists_tools/Insert_a_custom_list.md), or a list that was installed with FieldWorks.

1.  For an existing list, if the **Configure List** dialog box is not already displayed, do the following:

    - In the **Navigation** **Pane**, click **Lists**, and then click the list you will configure.

    - On the **Tools** menu, point to **Configure**, and then click **List**.

      The **Configure List** dialog box appears.

2.  In the **Configure List** or [New List](../../../Using_Tools/Lists_tools/Insert_a_custom_list.md) dialog box, do the following:

    - In the **Name of List** box, edit or type a list name. See: ![](../../../assets/images/Important_Icon.gif) **Important** below.

    - Under **Options**, select the options you want to use for the list.\
      **See:** **Note** below.

    - In the **This list contains data in** box, select the appropriate set of writing systems.

    - In the **Display items in the list by** box, select **Name**, **Abbreviation-Name**, or **Abbreviation** to set the way list items appear in the center pane (**Lists**), and in dialog boxes that display the list items.

    - In the **Description** box, edit or type a list description.

    - Click **OK**.

> [!IMPORTANT]
>
> - The **Name of List** box and the **Description** box display the current [user interface language](Options/Change_Interface_Language.md) and English. Lists that are installed with FieldWorks have English names, and in some cases, English descriptions.
>
> - [Analysis writing systems](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) appear in the **Name** field for each list item. Typically, the user interface language would also be an analysis writing system.

> [!NOTE]
>
> - **Options:**
>
> - - Select (![](../../../assets/images/CheckedBox.PNG)) **Support hierarchy** to enable list subitems.
>
>   - Select (![](../../../assets/images/CheckedBox.PNG)) **Sort items by name** to use names of list items to set the sort in the center pane and in dialog boxes that display the list items. Otherwise, the items are sorted by when they were inserted into the list.
>
>   - Clear (![](../../../assets/images/UncheckedBox.PNG)) the **Allow Duplicate item names and abbreviations** check box to require that item names and abbreviation be *unique.*
>
> - The **Display item in the list by** box sets list items to appear by **Name**, **Abbreviation - Name**, or **Abbreviation**.
