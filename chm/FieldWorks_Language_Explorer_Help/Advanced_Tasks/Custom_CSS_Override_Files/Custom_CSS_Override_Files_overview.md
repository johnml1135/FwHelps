# Custom CSS Override Files overview

*Advanced Tasks › Custom CSS Override Files*

Some advanced users can work with custom CSS override files. These files would override the CSS files which are generated by the **Configure Dictionary** dialog box or the **Configure Reversal Index** dialog box.

The ability to do this was added to specifically allow user-customized **Before**, **Between** and **After** box contents (surrounding context). But it can be done for other customizations that are not handled by the dialog boxes.

Details about how to do this are beyond the scope of these User Helps, but here is an overview to help you get started:

- The generated **Preview.css** files and the **Override.css** (initially-empty) files are stored in these locations:

  - C:\ProgramData\SIL\FieldWorks\Projects\\project name\>\ConfigurationSettings\Dictionary

  - C:\ProgramData\SIL\FieldWorks\Projects\\project name\>\ConfigurationSettings\ReversalIndex

- You can copy and paste rules from a generated **Preview.css** file into the **Override.css** file and modify them there ([example](Custom_CSS_Override_example.md)).

> [!TIP]
>
> - Remember that these overrides will remain in effect regardless of how you change things in the **Configure Dictionary** dialog, and they are not visible in any configuration tool inside of Flex. So it could lead you to questions about why your subsequent configuration changes do not seem to affect the view.
>
> - These files are included in [backup files](../../User_Interface/Menus/File/Backup_and_Restore/Backup_and_Restore_overview.md) and [Send/Receive](../../User_Interface/Menus/Send_Receive/Send_Receive_menu.md) processes.
>
> - XHTML files references these files. So, their effects will be seen in [exported](../../User_Interface/Menus/File/Export/Export_overview.md) or [uploaded](../../User_Interface/Menus/File/Upload_to_Webonary.md) files, but not in the FLEx preview.
>
> - These files are not touched when upgrading.
>
> - You may want to get [technical support](../../Overview/Technical_support.md) to request help. You may ask if others have CSS override files that they could share with you.
