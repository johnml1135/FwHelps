# Select language overview

*Advanced Tasks › Writing Systems › Add a new writing system*

When you [create](../../../User_Interface/Menus/File/Create_a_new_Fieldworks_project.md) a new project or [add](Add_a_new_writing_system.md) a new writing system you use the **Lookup Language Code** dialog box.

When you use this dialog box, you are [looking up](Select_Language_dialog_box.md) the language you need from the Ethnologue database *that is in FieldWorks*. Even though this database is updated from time to time, it may not be as up-to-date as the on-line database.

It is primarily the Ethnologue code that needs to be found.

- If you [search](Select_Language_dialog_box.md) repeatedly but cannot find the correct language, you can use a temporary [private-use code](Privatel_Use_codes.md).

Avoid associating a writing system with an *incorrect* language. You probably should get [technical support](../../../Overview/Technical_support.md).

- Later, such as after you install a newer version of FieldWorks, you may be able to change the writing system to stop using the private-use code.

> [!TIP]
>
> - In the **Writing System Properties** dialog box, there is a pane is labeled **Language** and a pane labeled **Writing Systems**.
>
> Its [tabs](../Modifying_a_Writing_System/Modifying_a_writing_system_overview.md) help you define the [writing systems](About_Writing_Systems.md) used for a language.
