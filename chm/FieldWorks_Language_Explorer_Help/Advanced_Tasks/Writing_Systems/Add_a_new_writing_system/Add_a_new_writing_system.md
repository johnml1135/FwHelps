# Add a new writing system

*Advanced Tasks › Writing Systems › Add a new writing system*

### Prerequisites

- Review [About writing systems](About_Writing_Systems.md) and [Writing system codes](Writing_system_codes.md).

- [Obtain](../../../Basic_Tasks/Spell_Checking/Obtaining_spelling_dictionary_files.md) any [spelling dictionary](../../../Basic_Tasks/Spell_Checking/Spell_checking_overview.md) files if you will use a spelling dictionary.

- Install the font you need, if it is not already on your computer.

Refer to Fonts in your computer's operating system Help if necessary.

Do these steps:

1.  [Open](../Modifying_a_Writing_System/Open_Writing_System_Properties_dlgbox.md) the **Writing System Properties** dialog box.

2.  To add a *writing system* for a language, click the name of that language in the **Writing Systems** pane.

Click ![](../../../assets/images/Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Add_Button.png) (**Add**) and then click one of the commands in the list:

- **Add IPA for** \<language\>

FLEx chooses **IPA Transcription** in the **Special** box.

- **Add Audio for** \<language\>

FLEx chooses **Voice** in the **Special** box.

- **Add variation of** \<language\>

FLEx chooses **Script/Region/Variant** in the **Special** box.

4.  To add a language click ![](../../../assets/images/Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Add_Button.png) (**Add**) and then click **Add new language**.

    - [Select](Select_Language_dialog_box.md) the language in the **Lookup Language Code** dialog box.

5.  [Use each tab](../Modifying_a_Writing_System/Modifying_a_writing_system_overview.md) to define the writing system.

> [!IMPORTANT]
>
> - In most projects, you should have only *one* vernacular language and then add multiple writing systems for it. If you need to have multiple vernacular languages, [get technical support](../../../Overview/Technical_support.md) to avoid problems.
