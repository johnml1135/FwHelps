# Select language for writing system

*Advanced Tasks › Writing Systems › Add a new writing system*

When you [create](../../../User_Interface/Menus/File/Create_a_new_Fieldworks_project.md) a new project or [add](Add_a_new_writing_system.md) a new writing system you use the **Lookup Language Code** dialog box.

1.  In the *search* box (![](../../../assets/images/Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/SearchIcon.png)), type the name of the language, its [code](Writing_system_codes.md) or a country where that language is spoken.

As you type, the main pane displays languages.

If you cannot find the desired language, try any of these options:

2.  - Select (![](../../../assets/images/CheckedBox.PNG)) **Show regional dialects**.

    - Try a different spelling of the language name, code or country name.

    - Click the **Can't find your language** link to open the **About The ISO Language Registry** dialog box.

Click **OK** to close this dialog box. Then, notice that **Unlisted Language** with a code of **qaa** is selected.

At this point, you can use this code for a [private-use code](Privatel_Use_codes.md) or do another search. The [code](Writing_system_codes.md) will start with **qaa-**. You may want to get [technical support](../../../Overview/Technical_support.md).

2.  Click the desired language to select it if it is not already selected.

    - Edit the name or enter a name for the unlisted language **qaa** code.

You can also edit the name in the **Name** box which is in the **Writing System Properties** dialog box.

3.  Click **OK**.

4.  [Use](../Modifying_a_Writing_System/Using_the_Writing_System_Properties_dialog_box.md) the **Writing System Properties** dialog box to [define](../Modifying_a_Writing_System/Modifying_a_writing_system_overview.md) the writing systems ([fonts](../Modifying_a_Writing_System/Writing_System_Properties_Fonts_tab.md), [keyboards](../Modifying_a_Writing_System/Writing_System_Properties_Keyboard_tab.md), and so on).
