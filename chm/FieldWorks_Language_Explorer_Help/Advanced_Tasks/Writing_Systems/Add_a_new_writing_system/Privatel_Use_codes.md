# Private-Use codes

*Advanced Tasks › Writing Systems › Add a new writing system*

If you cannot find a language using the search feature in **Select Language for New Writing System** dialog or the **Lookup Language Code** dialog box, nor in the Ethnologue, it is possible that you can use a private-use code.

- See [Select a language for a writing system](Select_Language_dialog_box.md) for the sequence of steps.

The result is a [code](Writing_system_codes.md) that starts with **qaa**.

> [!IMPORTANT]
>
> - This is *not the same* as the **Private use** option in the **Region name** list used in the [General](../Modifying_a_Writing_System/Writing_System_Properties_General_tab.md) tab.
>
> - It is important to associate a writing system with the *correct* language code whenever possible. Otherwise, use a private-use code when the following is true:
>
> - - The Ethnologue does not have a language code.
>
>   - The Ethnologue has a language code, but FLEx does not recognize it—its copy of the Ethnologue database could be older than the on-line database (<a href="https://www.ethnologue.com/browse/codes" target="_blank" title="https://www.ethnologue.com/browse/codes">https://www.ethnologue.com/browse/codes</a>).
>
>   - You are not sure which language code is the correct one.
>
> - Replace the private-use code with the correct code as soon as it becomes available.
>
> - - To do this, use the **Change** button in the **Writing System Properties** dialog box.
