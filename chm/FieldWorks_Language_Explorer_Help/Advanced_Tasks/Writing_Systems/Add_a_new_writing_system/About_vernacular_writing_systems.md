# About vernacular writing systems

*Advanced Tasks › Writing Systems › Add a new writing system*

In addition to the information in [About writing systems](About_Writing_Systems.md), consider the following:

- Typically, a project should have only one vernacular *language*.

- That language can have any number of *writing systems* (IPA, audio and so on).

When you need to add a writing system, you should not need to add another vernacular *language.*

If you want to represent a dialect as a different writing system, click **Add variation of** \<language\> and choose something in the **Region** box or type something in the **Variant** box to define the dialect.

Equivalent translations in other languages should be entered as glosses in an analysis language rather than in a vernacular language.

In the past, some who did not know what they were doing, added a new language for each variation, such as for IPA. This caused problems and other undesirable results in those projects.

Consequently, here are 2 reasons that could cause you to add (temporarily) another vernacular language:

- The project has multiple vernacular languages and it needs to be cleaned up. This can be done by adding the languages you want to delete or merge, and then merge them into the correct writing system for the vernacular language.

- Someone has messed up vernacular fields such as example sentences and have some forms in English, for example. So by adding English to vernacular temporarily, they can filter on examples with English and correct the mistakes.
