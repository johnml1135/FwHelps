# Input language for a Keyman keyboard

*Advanced Tasks › Writing Systems › Keyboards*

For FieldWorks to correctly select a writing system and a Keyman keyboard, you must select a corresponding *input language* in Microsoft Windows<sup>®</sup> that you do *not* use for any other purpose (for example, Icelandic). Then, associate that Keyman keyboard with that input language.

> [!IMPORTANT]
>
> - You must [add an input language](Add_an_input_language_Windows.md) in Windows<sup>®</sup> *before* you select it in the **System Language for keyboard input** list on **Step 4** of the **Writing System Wizard** or in the [Keyboards tab](../Modifying_a_Writing_System/Writing_System_Properties_Keyboard_tab.md) of the **Writing System Properties** dialog box.
>
> - Documentation is usually installed on your computer's hard drive when you download a keyboard. The documentation includes keyboard layout charts and more. Examples to look for on your computer:
>
>   - *IPA Unicode 5.1 (ver 1.2) KMN.pdf* used with Keyman.
>
>   - *IPA Unicode 5.1 (ver 1.2) MSK.pdf* for use with Microsoft Keyboard Layout Creators.
