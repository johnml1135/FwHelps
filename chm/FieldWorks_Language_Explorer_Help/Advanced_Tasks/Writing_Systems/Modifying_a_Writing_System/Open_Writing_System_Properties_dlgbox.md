# Open the Writing System Properties dialog box

*Advanced Tasks › Writing Systems › Modifying a Writing System*

You [use](Using_the_Writing_System_Properties_dialog_box.md) the **Writing System Properties** dialog box when you [add](../Add_a_new_writing_system/Add_a_new_writing_system.md), [delete](Delete_a_writing_system.md), [hide or show](Hide_or_show_a_writing_system.md), [merge](Merge_writing_systems.md), [modify](Modifying_a_writing_system_overview.md), [reorder](Reorder_writing_systems.md) or [update](Update_a_writing_system.md) writing systems.

- Versions (vernacular or analysis) of this dialog box are discussed in [About Writing Systems](../Add_a_new_writing_system/About_Writing_Systems.md).

Open this dialog box in any of these ways:

- **Format** [menu](../../../User_Interface/Menus/Format/Format_overview.md):

Click **Set up Vernacular Writing Systems** *or*

Click **Set up Analysis Writing Systems**.

- **Tools** [menu](../../../User_Interface/Menus/Tools/Tools_overview.md):

Point to **Configure** and then click one of these commands:

**Set up Vernacular Writing Systems** *or*

**Set up Analysis Writing Systems**.

- When you [create](../../../User_Interface/Menus/File/Create_a_new_Fieldworks_project.md) a project, you [select a language](../Add_a_new_writing_system/Select_Language_dialog_box.md).

<!-- -->

- When you [import data](../../../Beginning_Tasks/Importing_Data/Import_overview.md), you may need to add a writing system.

Various dialog boxes have an **Add** button, such as **Add language mapping**.

Examples: [Step 3 of 8: Language Mapping](../../../Beginning_Tasks/Importing_Data/Step_3_of_8_Language_mapping.md), [Import Contact Mapping Settings](../../../Beginning_Tasks/Importing_Data/Import_Notebook_Data/Import_Content_Mapping_Settings.md) or [Step 3 of 7: Encoding Conversion](../../../Beginning_Tasks/Importing_Data/Import_Notebook_Data/Step_3_of_7_Encoding_conversion.md).
