# Using the Writing System Properties dialog box

*Advanced Tasks › Writing Systems › Modifying a Writing System*

1.  [Open](Open_Writing_System_Properties_dlgbox.md) the appropriate [version](../Add_a_new_writing_system/About_Writing_Systems.md) (vernacular or analysis) of this dialog box.

2.  In the **Writing Systems** pane, click the writing system you will change.

3.  In the pane above the [tabs](Modifying_a_writing_system_overview.md), do any of the following:

<!-- -->

1.  - **Language Name** — Edit the name in the box.

    - **Language Code** — Observe the language [code](../Add_a_new_writing_system/Language_codes.md).

    - **Change** — Click this link to [select](../Add_a_new_writing_system/Select_Language_dialog_box.md) a *replacement* language.

<!-- -->

1.  - **Ethnologue entry for** — Click this link to open <a href="https://www.ethnologue.com/" target="_blank" title="https://www.ethnologue.com/">ethnologue.com</a>.

    - **Share writing system data with SLDR** — Clear (![](../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)) the check box if do not want it available for [collection](Collection_of_Locale_data.md).

<!-- -->

4.  As necessary, [add](../Add_a_new_writing_system/Add_a_new_writing_system.md), [reorder,](Reorder_writing_systems.md) [modify,](Modifying_a_writing_system_overview.md) [merge](Merge_writing_systems.md), [update,](Update_a_writing_system.md) [hide or show](Hide_or_show_a_writing_system.md), or [delete](Delete_a_writing_system.md) writing systems.

5.  If you clear (![](../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)) a writing system that has data in [fields](../../../User_Interface/Field_Descriptions/Field_Types/field_types_overview.md), those data remain in view. But, the writing system is not displayed in fields that did not have data when you cleared the check box or in custom fields you [add](../../../User_Interface/Menus/Tools/Custom_Fields/add_a_custom_field.md) later. The vernacular and analysis writing systems remain available when you configure a vernacular dictionary or reversal dictionary.

Each writing system that is selected (![](../../../assets/images/CheckedBox.PNG)) is visible in fields, even if empty.

**Note**: You can also [configure](../../../Basic_Tasks/Showing_Writing_Systems/configure_field_WSs.md) which writing systems are displayed in each field individually.

> [!IMPORTANT]
>
> - A colored (red) box appears around any area where required choices have not been made. For example, the colored box appears around the **Writing Systems** pane if no writing systems are selected (![](../../../assets/images/CheckedBox.PNG)).
>
> - The **Share writing system data with SLDR** check box only appears in the **Vernacular Writing Systems Properties** dialog box. It is selected (![](../../../assets/images/CheckedBox.PNG)) by default.
>
> <!-- -->
>
> - When you click the **Change** link and select another language, it will *replace* the language of the current (highlighted) writing system and all others added for that language. Example:
>
> Suppose that for Spanish (es) you had an orthographic writing system, an **IPA** writing system and an **Audio** writing system. If you changed the orthographic writing system from Spanish (es) to Spanish (spq), the IPA and Audio also change. Observe the [codes](Writing_System_Properties_General_tab.md) to see the changes.
