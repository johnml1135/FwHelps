# Collection of Locale Data

*Advanced Tasks › Writing Systems › Modifying a Writing System*

\*.[ldml files](../Add_a_new_writing_system/Writing_System_files.md) store *locale data*, which is referred to as writing system definitions. You define a writing system in the **Writing System Properties** dialog box.

The *SIL Locale Data Repository* (SLDR) is SIL's locale data repository. SIL collects data for publication for submission to the *Unicode Common Locale Data Repository* (CLDR).

SIL only collects from [repositories](../../../Basic_Tasks/Collaborating_with_Others/Send_Receive_considerations.md) on the *Lexbox* (formerly *Language Depot*) internet server, not from any local computer. So your data is only available for collection if you use [Send/Receive](../../../Basic_Tasks/Collaborating_with_Others/Send_Receive_overview.md) by way of this server.

*Locale* does not mean "location." Regional information or a country name *is* included if you [choose a region](Writing_System_Properties_General_tab.md). However, it will not contain detailed location information beyond what you can see in the FLEx user interface.

### What you can do

The **Share writing system data with SLDR** check box is near the top of the **Vernacular Writing System Properties** dialog box. This check box is *not* specific to any particular writing system in the project.

It is selected (![](../../../assets/images/CheckedBox.PNG)) by default.

- Clear it (![](../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)) if you cannot agree to this statement:

SIL International may collect the Locale Data from this project to better support my language(s). Locale data (e.g. characters used, sorting order, etc.) may be shared with the Unicode Common Locale Data Repository to provide better support for your language(s) on all computing devices.
