# Sort Same as another language

*Advanced Tasks › Writing Systems › Modifying a Writing System*

[Use](Writing_System_Properties_Sorting_tab.md) the **Sorting** tab to do these steps:

1.  Click the **Sort** down arrow (![](../../../assets/images/Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/SortDownArrow.png)) and then click **Same as another language**.

2.  Click the **Language** control and then click a language that has the exact same sort order as your language.

3.  [Test](Writing_System_Properties_Sorting_tab.md) the sort.
