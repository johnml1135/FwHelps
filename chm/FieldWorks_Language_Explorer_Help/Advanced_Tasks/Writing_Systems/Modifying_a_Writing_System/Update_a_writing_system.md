# Update a writing system

*Advanced Tasks › Writing Systems › Modifying a Writing System*

If you [modify](Modifying_a_writing_system_overview.md) a writing system that is used in a project on your computer, your changes are made in two places:

- the **WritingSystemStore** for *that* project, and

- the **WritingSystemRepository** which is the main repository for writing systems on your computer.

To update that writing system in *another* existing project that is on your computer, do these steps:

1.  [Open](Open_Writing_System_Properties_dlgbox.md) the **Writing System Properties** dialog box.

2.  Right-click a writing system in the **Writing Systems** pane and then click **Update**.

This update usually happens in a short time so there is no indication that anything happened.

If you look in the [tabs](Modifying_a_writing_system_overview.md) where the writing system changes were done, you can see those changes. Also, you can examine data that uses the updated writing system to verify the changes.
