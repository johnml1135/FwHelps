# Merge writing systems

*Advanced Tasks › Writing Systems › Modifying a Writing System*

When you merge writing systems you *also merge all data* that use those writing systems. So, if you merge writing systems that use different characters you could cause extensive changes to the data.

[Discuss](../../../Basic_Tasks/Collaborating_with_Others/Send_Receive_considerations.md) merging if you collaborate with others using [Send/Receive](../../../Basic_Tasks/Collaborating_with_Others/Send_Receive_overview.md). You might need to all synchronize so that the shared repository is updated and then [back up](../../../User_Interface/Menus/File/Backup_and_Restore/Back_up_this_Project.md) the project. Then, if the merge made large or many problems, that backup file could be restored and a new shared repository created.

1.  [Open](../../../User_Interface/Menus/File/Project_Properties/Project_Properties_overview.md) the **FieldWorks Project Properties** dialog box.

2.  In the **Writing Systems** tab, right-click the writing system you want to merge with another writing system, and then click **Merge**.

A **Warning** box appears.

1.  - Read the warning information. If you are sure you want to continue, click **Yes**.

The **Merge Writing Systems** dialog box opens.

3.  In the dialog box, click the writing system into which you want to merge the writing system.

<!-- -->

4.  Carefully read the ![](../../../assets/images/Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/MergeInfoIcon.png) information and then do any of these steps:

<!-- -->

3.  - Click **Cancel** and then select different writing systems if necessary.

    - Click **Backup** to back up if you want to name a back up file before you merge the writing systems.

    - Click **Merge**, if you are sure the merge is what you want to do.

<!-- -->

5.  If you merged writing systems, review your data.

    - If you find minor problems, fix them.

    - If you find many problems or large ones, request [technical support](../../../Overview/Technical_support.md).
