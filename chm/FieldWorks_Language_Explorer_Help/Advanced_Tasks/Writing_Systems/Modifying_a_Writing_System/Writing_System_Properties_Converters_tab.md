# Writing System Properties, Converters tab

*Advanced Tasks › Writing Systems › Modifying a Writing System*

FieldWorks uses the Unicode character encoding. The *Unicode Standard* is the universal character encoding scheme for written characters and text. It defines a consistent way of encoding multilingual text.

If you need to *import non-Unicode data* from Standard Format files, you need to select an [encoding converter](../Encoding_Converters/Encoding_Converters_overview.md).

1.  [Open](Open_Writing_System_Properties_dlgbox.md) the **Writing System Properties** dialog box if it is not already open.

2.  In the **Writing Systems** pane, click the *name* of the writing system you will change.

3.  Click the **Converters** tab.

4.  Click the **Encoding converter for importing \<language\>** down arrow (![](../../../assets/images/Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/SortDownArrow.png)) and then click a converter in the list.

<!-- -->

1.  - If the encoding converter you need is *not* in the list, you need to install or add it.

    - If there is an installer to add an encoding converter to your computer, you do *not* need to add it in FieldWorks.\
      If you cannot install it, click **More** to open the **Encoding Converters** dialog box.
