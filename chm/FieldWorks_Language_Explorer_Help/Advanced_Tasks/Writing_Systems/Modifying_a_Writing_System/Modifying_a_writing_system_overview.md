# Modifying a writing system overview

*Advanced Tasks › Writing Systems › Modifying a Writing System*

[Open](Open_Writing_System_Properties_dlgbox.md) and [use](Using_the_Writing_System_Properties_dialog_box.md) controls in the **Writing System Properties** dialog box when you [add](../Add_a_new_writing_system/Add_a_new_writing_system.md), [delete](Delete_a_writing_system.md), [hide or show](Hide_or_show_a_writing_system.md), [merge](Merge_writing_systems.md), [reorder](Reorder_writing_systems.md) or [update](Update_a_writing_system.md) writing systems.

To *modify* (distinguish or define) a writing system, [use](Using_the_Writing_System_Properties_dialog_box.md) controls in these *tabs*:

- [General tab](Writing_System_Properties_General_tab.md)

- [Font tab](Writing_System_Properties_Fonts_tab.md)

- [Keyboard tab](Writing_System_Properties_Keyboard_tab.md)

- [Converters tab](Writing_System_Properties_Converters_tab.md)

- [Sorting tab](Writing_System_Properties_Sorting_tab.md)

- [Characters tab](Writing_System_Properties_Characters_tab.md)

- [Valid Characters dialog box](Valid_Characters_dialog_box/Valid_Char_overview.md)

- [Numbers tab](Writing_System_Properties_Numbers_tab.md)

> [!IMPORTANT]
>
> - [About writing systems](../Add_a_new_writing_system/About_Writing_Systems.md) describes the two versions of this dialog box.
>
> - [Language codes](../Add_a_new_writing_system/Language_codes.md) and [Writing system codes](../Add_a_new_writing_system/Writing_system_codes.md) describe codes used.
>
> - [Writing system files](../Add_a_new_writing_system/Writing_System_files.md) and [Update a writing system](Update_a_writing_system.md) discuss how changes are stored and moved to other projects on your computer.
>
> - [Collection of Locale Data](Collection_of_Locale_data.md) describes the **Share writing system data with SLDR** check box.
>
> - [Hide or show](Hide_or_show_a_writing_system.md) a writing system can be an option for times when you want to simplify your project.
