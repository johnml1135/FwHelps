# Writing System Properties, Numbers tab

*Advanced Tasks › Writing Systems › Modifying a Writing System*

Use this tab to set the numbers that are valid for your writing system.

1.  [Open](Open_Writing_System_Properties_dlgbox.md) the **Writing System Properties** dialog box if it is not already open.

2.  In the **Writing Systems** pane, click the *name* of the writing system you will change.

3.  Click the **Numbers** tab.

4.  Click the down arrow (![](../../../assets/images/Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/SortDownArrow.png)) and then click one of these options:

    - the set of numbers that is valid for your writing system.

    - **\[Custom numbering system\]**. Then, click a box and then type or paste the number you need. Repeat for each box to account for *all* numbers from 0 through 9.

<!-- -->

5.  Click **OK**.
