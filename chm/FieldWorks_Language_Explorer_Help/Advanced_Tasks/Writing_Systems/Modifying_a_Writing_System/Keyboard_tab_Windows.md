# Keyboard tab Windows

*Advanced Tasks › Writing Systems › Modifying a Writing System*

- [Open](Open_Writing_System_Properties_dlgbox.md) the **Writing System Properties** dialog box if it is not already open.

In the **Keyboard** tab, the main pane shows two lists of keyboards. The top list shows *previously* used keyboards, with the current one selected. Below that are other keyboards that are on your computer.

Do these steps:

1.  In the **Writing Systems** pane (*lower left*), click the writing system.

2.  Choose a keyboard for that writing system:

<!-- -->

1.  - If the keyboard is available (not grayed-out) in the top list but it is not selected, *or* it appears in the lower list, click it.

    - If the keyboard you need is not listed, do the following:

      - To set up Windows<sup>®</sup>, click the **Windows keyboard settings** link.

      - Use the Windows<sup>®</sup> dialog boxes to set up the keyboard. You might need to associate a Keyman keyboard to an input language. See: [Input language for a Keyman Keyboard](../Keyboards/Input_language_for_Keyman_keyboard.md).

      - To set up Keyman, click the **Keyman Configuration** link.

You must [add an input language](../Keyboards/Add_an_input_language_Windows.md) in Microsoft Windows<sup>®</sup>(described above) before you can select it.

Depending on your version of Keyman, you might need to choose an unrelated Windows<sup>®</sup> keyboard and then select a Keyman keyboard (in the **Languages** tab of **Keyman Desktop Configuration** dialog box) as the actual keyboard.

3.  In the **Test Area**, type characters to test the writing system (font and keyboard).

If characters do not look right or you cannot type some characters, make sure you have the correct [font](Writing_System_Properties_Fonts_tab.md) and keyboard settings.

> [!NOTE]
>
> - FieldWorks currently allows only *one* keyboard for each writing system. Do not try to associate more than one keyboard with a writing system. Users who have tried this have experienced various problems.
>
> For example, you could add an input language in your computer's **Text Services and Input Languages** dialog box and associate that input language with a Keyman keyboard. Then later, you may learn of another keyboarding program or choose to try Microsoft Keyboard Layout Creator (MSKLC).
>
> - For more information, on the **Help** menu, point to **Resources** and then click **Technical Notes on Writing Systems**.
