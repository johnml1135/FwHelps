# Reorder writing systems

*Advanced Tasks › Writing Systems › Modifying a Writing System*

1.  [Open](Open_Writing_System_Properties_dlgbox.md) the **Writing System Properties** dialog box.

2.  Click a writing system in the **Writing Systems** pane.

3.  Click the up arrow (![](../../../assets/images/Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/UpArrrowWS.png)) or down arrow (![](../../../assets/images/Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/DownArrrowWS.png)) to reorder the writing systems.

If the vernacular writing system that is at the top of the list changes, homograph numbers typically need to be updated. In this case, a box appears and asks if you want to update the them.

1.  - If you want to do this, click **Yes**.

    - If you click **No**, the homograph numbers will continue to be based on the writing system that was previously on the top of the list.

> [!TIP]
>
> - The order of writing systems here determine their order in [fields](../../../User_Interface/Field_Descriptions/field_descriptions_overview.md).
>
> - You might need to [use](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) the **Configure Columns** dialog box after reordering writing systems.
>
> - The **FieldWorks Project Utilities** dialog box has a **Reassign Homographs** [utility](../../../User_Interface/Menus/Tools/Language_Project_Utilities_overview.md). It will not change the writing system that they are based on.
