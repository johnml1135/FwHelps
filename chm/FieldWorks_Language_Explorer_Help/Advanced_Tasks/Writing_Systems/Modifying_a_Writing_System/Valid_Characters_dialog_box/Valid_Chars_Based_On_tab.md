# Valid Characters, Based On tab

*Advanced Tasks › Writing Systems › Modifying a Writing System › Valid Characters dialog box*

*Similar writing systems* are those with characters you can use to populate the set of valid characters for the current writing system. The current writing system is identified between the title bar and the tabs.

1.  In the **Valid Characters** dialog box, click the **Based On** tab.

2.  Click the **Load From** button, and then select a writing system.

    The button label changes to show the *last* writing system selected.

3.  Click **Add** to copy the characters from the similar writing system into the **Valid Characters** pane.

4.  If more valid characters are needed, do one of the following:

    - Repeat the steps above with a different similar writing system. Unique characters from that writing system are added.

    - Add characters [from data](Valid_Chars_From_Data_tab.md) or [manually](Valid_Chars_Manual_Entry_tab.md).

5.  Review the characters in the **Valid Characters** pane. If there are characters that are not valid, do one of the following:

    - To remove an individual *invalid* character, click that character, and then click **Remove**.

    - To remove *all* the characters, click **Remove All**.

6.  Click **OK** in each open dialog box.
