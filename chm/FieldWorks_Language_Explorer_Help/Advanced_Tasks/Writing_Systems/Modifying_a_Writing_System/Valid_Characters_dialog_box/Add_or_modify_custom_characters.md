# Add or modify custom characters

*Advanced Tasks › Writing Systems › Modifying a Writing System › Valid Characters dialog box*

- Review [About Writing Systems](../../Add_a_new_writing_system/About_Writing_Systems.md) and [Using the Writing System Properties dialog box](../Using_the_Writing_System_Properties_dialog_box.md).

To add or modify a custom character (previously called a *PUA character*), you need to use a separate program called the **Unicode Character Properties Editor**. Use the **Add Custom Character** or **Modify Custom Character** dialog boxes to define the properties of the custom character. Otherwise, FieldWorks will not know how to process it correctly.

Most users will need [technical support](../../../../Overview/Technical_support.md) for this task.

1.  Close all FieldWorks projects on your computer.

2.  Search for **Unicode Character Properties Editor** on your computer.

3.  In the editor:

Use the Unicode Standard to learn what to enter in these dialog boxes. Search for the terms used in the box labels, such as 'decomposition' or 'bidirectional'.

1.  - Click **Add** to open the **Add Custom Character** dialog box.

    - Click an existing custom character, and then click **Edit** to open the **Modify Custom Character** dialog box.

    - Click an existing custom character, and then click **Delete** to delete that character.
