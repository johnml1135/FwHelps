# Open the Valid Characters dialog box

*Advanced Tasks › Writing Systems › Modifying a Writing System › Valid Characters dialog box*

1.  [Open](../Open_Writing_System_Properties_dlgbox.md) the **Writing System Properties** dialog box.

<!-- -->

2.  In the **Writing Systems** pane, click the *name* of the writing system you will change.

3.  Click the **Characters** tab.

The writing system name appears near the **Valid Characters** button.

4.  Click the **Valid Characters** button.

The [dialog box](Valid_Char_overview.md) opens.
