# Writing System Properties, Font tab

*Advanced Tasks › Writing Systems › Modifying a Writing System*

1.  [Open](Open_Writing_System_Properties_dlgbox.md) the **Writing System Properties** dialog box if it is not already open.

2.  In the **Writing Systems** pane, click the *name* of the writing system you will change.

3.  Click the **Font** tab.

4.  Click the **Default font** down arrow (![](../../../assets/images/Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/SortDownArrow.png)) and then click a font.

5.  If the font is Graphite-enabled, do one of the following:

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Enable Graphite**.

Then, click **Font Features** and select or clear an individual feature that affects the appearance of the glyphs.

1.  - Clear (![](../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)) `Enable Graphite` if the writing system does not need the "smart font" capability for complex behaviors.

Performance improvements are usually realized.

> [!NOTE]
>
> - If a font is not in the **Default font** list, you need to install it.
>
>   Doulos SIL and Charis SIL fonts were installed with FieldWorks.
>
> - You can test the font in the **Test Area** box on the **Keyboard** tab.
>
> - The **Default font** box contains **\<Missing:** font name**\>** if the previously selected font is not installed on the computer.
>
> - **See Also:** [Styles, Font tab](../../../User_Interface/Menus/Format/Styles/Styles_Font_tab.md).
