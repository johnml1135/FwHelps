# Python and Perl overview

*Advanced Tasks › Writing Systems › Encoding Converters*

*Python* and *Perl* are programming languages.

When you work with [encoding converters](Encoding_Converters_overview.md) or [processors](../../../Using_Tools/Lexicon_tools/Bulk_Edit_Entries/Using_Setup_Processor_dialog_box.md), the available Transduction types include *Python Scripts* and *Perl Expression*. If you will use a Python script or a Perl expression, install a 64-bit version of Python or Perl.

You can download from here: <a href="https://www.python.org/" target="_blank" title="https://www.python.org/">https://www.python.org/</a> and <a href="https://strawberryperl.com/" target="_blank" title="https://strawberryperl.com/">https://strawberryperl.com/</a>.

In the **Encoding Converters** or **Set up Processor** dialog box, click one of the available converters or processors. If Python or Perl was used when it was added, you will see the **Modify** button. Click it to open a dialog box named **Python Script** or **Perl Script**.

The dialog box has four tabs:

- **About** - this tab provides Help information for the other tabs.

- **Setup**

- **Test Area**

- **Advanced**.

You would use this dialog box, for example, if you needed to [modify an encoding converter](Encoding_Converters_Properties_tab.md) or [change the properties of a processor](../../../Using_Tools/Lexicon_tools/Bulk_Edit_Entries/change_the_properties_of_a_processor.md).

> [!IMPORTANT]
>
> - Python Encoding Converters work only with Python 2.7, not newer versions.
