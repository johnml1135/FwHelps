# Add an encoding converter

*Advanced Tasks › Writing Systems › Encoding Converters*

1.  In the **Encoding Converters** dialog box, click **Add**.

2.  In the **Converter Name** box, type a descriptive name (that is, the name that appears in the list of encoding converters).

3.  Click the **Converter Type** control.

If the converter type you need is in the list:

1.  - [Select the converter type](Select_the_converter_type.md)

    - [Select the converter mapping](Select_the_converter_mapping.md), and then

    - [Select the conversion type](Select_the_conversion_type.md).

If the converter type you need is *not* in the list:

1.  - Click **More**.

The **Choose a Transduction** **Engine** dialog box appears.

1.  - Select an implementation type, and then click **Add**.

Another dialog box appears. The **About** tab displays information about adding that converter type.

4.  Click **Close**.

> [!TIP]
>
> - If there is an installer to add an encoding converter to your computer, you do not need to add it in FieldWorks. Instead, you can select it on the [Converters](../Modifying_a_Writing_System/Writing_System_Properties_Converters_tab.md) tab of the **Writing System Properties** dialog box.
>
> - If you click **More** to add an encoding converter, the **Copy** button is not available. The **Modify** button appears.
