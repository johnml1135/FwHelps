# Encoding Converters, Advanced tab

*Advanced Tasks › Writing Systems › Encoding Converters*

To display the values of all the properties of an encoding converter, select it in the **Available Converters** list.

The following table relates the names of the properties that appear on both the **Properties** and **Advanced** tabs.

|                        |               |
|------------------------|---------------|
| Properties tab         | Advanced tab  |
| Converter Type         | ImplementType |
| Converter Mapping File | Identifier    |
| Mapping Name           | Identifier    |
| Code Page              | Identifier    |
| Data Types             | Type          |

> [!NOTE]
>
> - On the **Advanced** tab, you cannot modify the values of the properties.
>
> - The values of properties of encoding converters are in this folder: `C:\ProgramData\SIL\Repository``.`
