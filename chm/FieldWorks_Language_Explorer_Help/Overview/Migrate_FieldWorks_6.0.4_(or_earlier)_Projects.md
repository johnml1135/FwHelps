# Migrate FieldWorks 6.0.6 (or earlier) Projects

*Overview*

*Windows*<sup>®</sup> *OS only*: FieldWorks versions 7 and later have new features and use an improved [folder structure](../User_Interface/Menus/File/Backup_and_Restore/Folder_Structure.md).

You will likely need to request [technical support](Technical_support.md) if you need to migrate an older [backup](../User_Interface/Menus/File/Backup_and_Restore/Backup_files.md) or project file.
