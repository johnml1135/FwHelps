# How do I

*Overview*

*Task* topics appear in various Helps books. Here are some ways to see them:

- In the **Index** tab, type

\- a *verb* (add, choose, delete, export, insert, import, specify, and so on),

\- a *noun* (affix, allomorph, variant, a [field](../User_Interface/Field_Descriptions/field_descriptions_overview.md) name, and so on), *or*

\- the word "about".

- Each [field](../User_Interface/Field_Descriptions/field_descriptions_overview.md) displays a menu button ![](../assets/images/Menu_Button_pic.GIF) with a **Help** command. It opens a Help topic that describes the particular field and has hyperlinks to related topics.

In addition, numerous *overview* topics have links to task topics. Some examples:

- [Beginning Tasks overview](../Beginning_Tasks/Beginning_Tasks_overview.md), [Basic Tasks overview](../Basic_Tasks/Basic_Tasks_overview.md) or [Advanced Tasks overview](../Advanced_Tasks/Advanced_Tasks_overview.md) provide task help for tasks you may do only when you begin using FLEx, more often or rarely.

- [Collaborating with Others overview](../Basic_Tasks/Collaborating_with_Others/Collaborating_with_Others_overview.md) helps multiple users work in the same language project or share data.

**See Also:** [Get Started with Send/Receive](../Basic_Tasks/Collaborating_with_Others/Get_Started_with_Send_Receive.md).

- [Lexicography Tasks overview](../Lexicography_Tasks/Dictionary_and_Lexicon_overview.md) and [Morphology and Parsing Tasks overview](../Morphology_and_Parsing_Tasks/Morphology_Parsing_Tasks_overview.md) parallel some tasks discussed in documents you find under [Resources](../User_Interface/Menus/Help/Help_overview.md).

- [Spell checking overview](../Basic_Tasks/Spell_Checking/Spell_checking_overview.md) helps you get spelling dictionaries set up correctly.

- [User Interface overview](../User_Interface/User_Interface_overview.md) ([menus](../User_Interface/Menus/Menus_overview.md), [toolbars](../User_Interface/Toolbars/Toolbars_overview.md), [Information bar](../User_Interface/Toolbars/information_bar_overview.md), [status bar](../User_Interface/Toolbars/status_bar.md), and so on).

- [Using Tools overview](../Using_Tools/Using_Tools_overview.md) lists the areas (**Lexicon**, **Texts & Words**, **Grammar** and **Lists** ) with hyperlinks to tools (**Lexicon Edit**, **Interlinear Texts** and so on).

> [!TIP]
>
> - **Using Help**, available in the **Contents** tab, contains topics to help you use these User Helps.
>
> - On the [Help](../User_Interface/Menus/Help/Help_overview.md) menu, **Technical Notes on Writing Systems** helps you set up keyboards and writing systems.
>
> - <a href="https://software.sil.org/fieldworks/support/technical-documents/" target="_blank" title="https://software.sil.org/fieldworks/support/technical-documents/">https://software.sil.org/fieldworks/support/technical-documents/</a> lists technical documents that provide information which is beyond the scope of these User Helps.
>
> - The [Options](../User_Interface/Menus/Tools/Options/Options_overview.md) dialog box lets you select the user interface language.
>
> - - Your computer's display properties determine the font size and colors of menus and toolbars.
>
>   - Your Internet Explorer window *text size* determines the User Help font size.
