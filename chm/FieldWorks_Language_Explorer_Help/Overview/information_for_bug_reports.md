# Information for bug reports

*Overview*

When you submit a FieldWorks Language Explorer (FLEx) bug report, include the following:

- The *version* of FLEx you are using.

  On the [Help](../User_Interface/Menus/Help/Help_overview.md) menu, click **About Language Explorer**.

- A description of your computer:

  The manufacturer and model (e.g., Dell Optiplex-9020™).

  The operating system (Windows 10 **or 11).

- How much RAM memory your computer has (e.g., 16 GB).

- A description of the problem, that is, what you were doing or attempting to do when the problem occurred, including the following:

  The tool you were using.

  The sort(s) and filter(s), if any, which were active.

  The analysis and vernacular writing systems you were using.

  How many and which programs were open when the problem occurred.

- If you want to report a particularly slow operation, please repeat the operation a few times and report if it becomes faster with use. Reason: some operations are initially slow while FieldWorks loads data into the memory. After that, the operation should be much faster.

> [!NOTE]
>
> - If FieldWorks' settings files become out of sync, you may experience a problem. They are reset to the default (factory) settings if you use [Restore Defaults](../User_Interface/Menus/Tools/Restore_defaults.md) on the [Tools](../User_Interface/Menus/Tools/Tools_overview.md) menu.
>
> - - If you experience a problem, try this to see if the problem goes away.
>
>   - If the problem remains, please mention that you tried it as part of the description of the problem.
>
> - For some error messages, the contents of the error message are sent to the Clipboard. In this case, please paste (Ctrl+V) the contents of the Clipboard into your correspondence, along with your description of the problem.
