# Solve performance problems

*Overview*

To improve the performance of FieldWorks, do one or more of the following:

- Use a faster computer.

- Add memory. FieldWorks uses a database that can benefit from more memory. Adding memory can reduce the amount of time that FieldWorks will spend moving data to and from the hard disk.

- Close any programs that you are not using. Close any FieldWorks windows that you are not using.

- Defragment your hard disk, unless it is solid-state. Refer to the `Help information for your computer's operating system to find` information on how to defragment a hard disk.

If FieldWorks runs slower than your computer's specifications would suggest, or other users are experiencing, request [technical support](Technical_support.md).
