# Find and Replace overview

*Basic Tasks › Find and Replace*

The FieldWorks Language Explorer has numerous *find* or *find and replace* features that are available in appropriate areas. You can see different ones available on the [Edit](../../User_Interface/Menus/Edit/Edit_overview.md) menu, [Tools](../../User_Interface/Menus/Tools/Tools_overview.md) menu or various tabs, depending on the current display.

### **Lexicon**

- Each **Bulk Replace** tab (**Bulk Edit Entries** and **Bulk Edit Reversal Entries**) has a **Setup** button that opens a **Bulk** **Replace Setup** dialog box. It has only a **Replace** tab, which you use to set up a [bulk replace](../../Using_Tools/Lexicon_tools/Bulk_Edit_Entries/bulk_replace.md) operation.

- You can use a ![](../../assets/images/Find_Replace_Text.GIF) [Find in Lexicon](../../User_Interface/Menus/Edit/Find_and_Replace_Lexicon.md) feature in **Dictionary**, **Classified Dictionary** and **Reversal Indexes**.

- The ![](../../assets/images/FindEntry.GIF) [Find lexical entry](../../User_Interface/Menus/Edit/Find_a_lexical_entry.md), ![](../../assets/images/Find_Reversal_Entry.GIF) [Find reversal entry](../../User_Interface/Menus/Edit/Find_a_reversal_entry.md) and [Find Example Sentence](../../Using_Tools/Lexicon_tools/Lexicon_Edit/Find_example_sentence.md) features are also available.

### **Texts & Words**

- You can use the ![](../../assets/images/Find_Replace_Text.GIF) [Find and Replace](../../User_Interface/Menus/Edit/Find_and_Replace_Text.md) dialog box to find and replace words in texts.

- The ![](../../assets/images/Find_wordform.GIF) [Find Wordform](../../User_Interface/Menus/Edit/Find_wordform.md) dialog box helps you find a word. Further, the **Ref** and **Occurrence** columns ([Concordance](../../Using_Tools/Texts_&_Words_tools/Concordance/Concordance_overview.md)) show all occurrences of the current word with a brief reference to the texts that contain the word. If you click an occurrence, the text appears in the open tab below it and shows the word in its context.

- A ![](../../assets/images/FindInDictionaryTextWds.png) [Find in Dictionary](../../User_Interface/Menus/Tools/Find_in_Dictionary_overview.md) feature allows you to find a lexical entry and display a preview of its dictionary entry.

### **Notebook**

- You can use the **Find** tab of the ![](../../assets/images/Find_Replace_Text.GIF) [Find and Replace](../../User_Interface/Menus/Edit/Find_and_Replace.md) dialog box to search for words in the **Document** view. To [preserve the integrity](../../Using_Tools/Notebook_tools/Record_Edit_overview/Edit_a_record.md) of your fieldnotes, the **Replace** feature is *not* available.

- There is also as separate ![](../../assets/images/Using_Tools/Notebook_tools/Record_Edit_overview/Find_Record.PNG) [Find Record](../../User_Interface/Menus/Edit/Find_a_fieldnote_record.md) dialog box.
