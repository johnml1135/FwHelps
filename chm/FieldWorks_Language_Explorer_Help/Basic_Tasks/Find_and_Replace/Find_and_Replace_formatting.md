# Find and Replace formatting

*Basic Tasks › Find and Replace*

1.  In the [Bulk Replace Setup](../../Using_Tools/Lexicon_tools/Bulk_Edit_Entries/bulk_replace.md) (**Lexicon**) or [Find and Replace](../../User_Interface/Menus/Edit/Find_and_Replace_Text.md) (**Texts & Words**) dialog boxes, click **More**.

    The **More** button label changes to **Less**, and the [Search Options](Search_Options.md) features are displayed.

2.  In the **Find what** box, do one of the following:

    - To search for text *without* a specific style, type or paste the text.

      To remove any previously applied styles, select that text, and then click **Format**, point to **Style**, and then select **\<****no style****\>**.

    - To search for text *with* a specific style or writing system, type the text and then select it. Click **Format**, and then select the style or writing system you want.

      The text changes to reflect the applied style. A line labeled **Format** appears below the **Find what** box indicating the applied style.

3.  To replace the text, in the **Replace with** box type the replacement text, and then do any of the following:

    - To replace *without* specific style leave the text as you typed it.

      To remove any previously applied styles, select that text, and then click **Format** point to **Style**, and then select **\<****no style****\>**.

    - To replace the text *with* a specific style or writing system, select the text, click **Format**, point to **Style** or to **Writing System**, and then select a style or writing system.

      The text changes to reflect the applied style. A line labeled **Format** appears below the **Replace with** box, indicating the applied style.

4.  Click **OK**.

5.  If necessary, continue with the steps in [Bulk Replace](../../Using_Tools/Lexicon_tools/Bulk_Edit_Entries/bulk_replace.md).
