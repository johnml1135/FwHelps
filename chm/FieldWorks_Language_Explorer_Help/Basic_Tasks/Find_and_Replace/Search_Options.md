# Search Options

*Basic Tasks › Find and Replace*

In the **Find and Replace** dialog box and in [Bulk Replace](../../Using_Tools/Lexicon_tools/Bulk_Edit_Entries/bulk_replace.md) dialog boxes (**Bulk Edit Entries**, **Bulk Edit Reversal Entries** or **Bulk Edit Wordforms**) there is a **Search Options** area. It has a **Format** button and several check boxes.

The **Format** button allows you to apply a writing system or character styles to selected search or replacement text. Only text that matches the writing system or style of the search text will be found. Similarly, writing systems or styles applied to the replacement text will be used with each replacement.

- Click **Format**, point to **Writing Systems**, and then click a specific writing system if you want text to match *only if* it has that *writing system*.

- Click **Format**, point to **Styles**, and then click a specific style if you want text in the view to match *only if* it has that style.

The check boxes provide additional choices to control the search and replacement operations

- Select the **Match case** check box if you want text in the view to match *only if* it has the same *capitalization* as the search text (for writing systems that have case distinctions).

- Select the **Match as whole word** check box if you *do not* want the search text to match *part of a word* in the view.

- Select the **Match diacritics** check box if you want text in the view to match *only if* it has the same *diacritic* as the search text (for writing systems that have diacritics).

- Select the **Match writing system** check box if you want text in the view to match *only if* it has the same *writing system* as the search text.

- Select **Use regular expressions** to allow use of [regular expressions](Find_and_Replace_using_regular_expressions.md) with the **Find what** or **R****eplace** **with** contents.

> [!TIP]
>
> - To find *any text* with a specific format, clear the **Find what** box and the check boxes, and then click **Format** to select a *writing system*.
>
> - Here, *text* means one or more words.
