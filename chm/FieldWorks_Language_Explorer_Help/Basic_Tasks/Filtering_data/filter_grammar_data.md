# Filter Grammar data

*Basic Tasks › Filtering data*

1.  In the **Navigation** **Pane**, click **Grammar**, and then select one of the tools (except **Grammar Sketch** or **Problems**).

2.  Do the steps in [Filter data](filter_data.md).

> [!TIP]
>
> - [Category Edit](../../Using_Tools/Grammar_tools/Category_Edit/Category_Edit_overview.md) has a corresponding [Browse](../../Using_Tools/Grammar_tools/Categories_Browse/Categories_Browse_overview.md) view. So, a filter you apply in **Browse** view also affects **Category Edit**, and vise versa.
>
>   Filters do not affect any other window open to the language project.
