# About regular expressions

*Basic Tasks › Filtering data*

You can [use](Using_regular_expressions_assistance.md) *regular expressions* anywhere the **Filter for** or search feature, or a **Replace** tab is available. These include (*not* exhaustive) the following:

## **Lexicon**

- [Lexicon Edit](../../Using_Tools/Lexicon_tools/Lexicon_Edit/lexicon_edit_overview.md) **Entries** pane, and similar *browse-view* style panes in [Browse](../../Using_Tools/Lexicon_tools/Browse/Lexicon_Browse_overview.md), [Bulk Edit Entries](../../Using_Tools/Lexicon_tools/Bulk_Edit_Entries/Bulk_Edit_Entries_overview.md) and [Bulk Edit Reversal Entries](../../Using_Tools/Lexicon_tools/Bulk_Edit_Reversal_Entries/bulk_edit_reversal_entries_overview.md).

- The **Bulk Replace** tab [Bulk Replace Setup](../../Using_Tools/Lexicon_tools/Bulk_Edit_Entries/bulk_replace.md) dialog box.

## **Grammar**

- [Categories Browse](../../Using_Tools/Grammar_tools/Categories_Browse/Categories_Browse_overview.md) and other tools with a *browse-view* style center pane

## **Texts & Words**

- [Interlinear Texts](../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/texts_edit_overview.md), center **Texts** pane

- [Find and Replace Text](../../User_Interface/Menus/Edit/Find_and_Replace_Text.md) dialog box

- [Concordance](../../Using_Tools/Texts_&_Words_tools/Concordance/Concordance_overview.md) tool [Specify Concordance Criteria](../../Using_Tools/Texts_&_Words_tools/Concordance/Manually_specify_concordance_criteria.md) pane

- [Word list columns](../../Using_Tools/Texts_&_Words_tools/Word_list_columns.md)

## **Lists**

- [Reversal Index Categories](../../Using_Tools/Lists_tools/about_reversal_index_categories.md)

> [!TIP]
>
> - Numerous Internet sites contain instructions, examples and tutorials regarding the use of ICU regular expressions. Therefore, these user helps do not contain extensive instructions or examples. Refer to <a href="https://unicode-org.github.io/icu/" target="_blank" title="https://unicode-org.github.io/icu/">https://unicode-org.github.io/icu/</a>.\
>   In addition, the following sources may be useful, **but be careful to consider that FieldWorks uses ICU**.
>
>   - <a href="https://www.regular-expressions.info/" target="_blank" title="https://www.regular-expressions.info/">https://www.regular-expressions.info/</a>
>
>   - <a href="https://www.codeproject.com/" target="_blank" title="https://www.codeproject.com/">https://www.codeproject.com/</a>
>
>   - <a href="https://perldoc.perl.org/perlrequick.html" target="_blank" title="https://perldoc.perl.org/perlrequick.html">https://perldoc.perl.org/perlrequick.html</a> (a tutorial based on *Perl*)
>
>   - <a href="https://visca.com/regexdict/tutorial.html#beg-end" target="_blank" title="https://visca.com/regexdict/tutorial.html#beg-end">https://visca.com/regexdict/tutorial.html#beg-end</a>
>
> - You can *save* complex regular expressions you might reuse regularly in a Unicode-compliant program. Then you can copy and paste the expressions into the applicable feature.
