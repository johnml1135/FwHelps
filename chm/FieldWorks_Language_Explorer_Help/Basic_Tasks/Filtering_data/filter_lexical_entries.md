# Filter lexical entries

*Basic Tasks › Filtering data*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**, **Browse**, **Bulk Edit Entries** or **Bulk Edit Reversal Entries**

2.  Do the steps in [Filter data](filter_data.md).

> [!TIP]
>
> - Filters you set in **Lexicon Edit**, **Browse** or **Bulk Edit Entries** affect *all three* views in the *same* open [window](../../User_Interface/Menus/Window/Window_overview.md). Filters do not affect other windows that are open to the language project.
>
> - If you remove a column from a view that has a filter which you set in a *different* view, then, in the view where you set the filter you will see that filter is turned off, but the column remains displayed.
>
>   For example, if you set a filter in a column in **Bulk Edit Entries**, and then go to **Lexicon Edit**, that column and filter is displayed there. If you remove the column in **Lexicon Edit**, the column remains in **Bulk Edit Entries** but is no longer filtered.
>
> - Currently, you cannot sort or filter reversal index entries in **Reversal Indexes**.
