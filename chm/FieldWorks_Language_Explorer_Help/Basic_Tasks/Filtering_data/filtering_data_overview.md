# Filtering data overview

*Basic Tasks › Filtering data*

You can filter data that is displayed in columns. Click the [down arrow](Filter_data_down_arrow_menu_pic.md) below any column heading in a **Browse** view or *browse-style* tool or pane (such as [Word list columns](../../Using_Tools/Texts_&_Words_tools/Word_list_columns.md)) to display a context-sensitive list of filter options, such as these (*not* exhaustive):

- **Show All**, **Blanks**, **Non-blanks** and **Filter for** ([Filter for](Using_Filter_for.md) is a custom filter. You can use regular expressions.)

- **Spelling Errors** - filters for incorrectly spelled words in columns that use a writing system for which a spelling dictionary is available. Red wavy underlines [flag](../Spell_Checking/Spell_checking_overview.md) incorrectly spelled words.

- **Choose** - for columns populated by [list reference fields](../../User_Interface/Field_Descriptions/Field_Types/List_reference_field.md).

- **Restrict** - for columns with numerical values.

- **Yes** or **No** - for columns that display the answer to *Yes* or *No* questions.

> [!NOTE]
>
> - To turn off any active filter(s), click![](../../assets/images/Basic_Tasks/Filtering_data/Clear_Filters.GIF)on the [View](../../User_Interface/Toolbars/View_toolbar.md) toolbar or select **No Filter** in the **View** menu.
>
> - The [status bar](../../User_Interface/Toolbars/status_bar.md) displays the current record and total number of records, which are affected by filters and [sorts](../Sorting_data/Sorting_data_overview.md).
>
> <!-- -->
>
> - **Lists** area data (except **Reversal Index Categories**) is *not* displayed in columns with active headers, so lists cannot be filtered.
