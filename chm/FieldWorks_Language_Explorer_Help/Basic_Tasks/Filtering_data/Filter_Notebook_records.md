# Filter Notebook records

*Basic Tasks › Filtering data*

To filter the **Document** [view](../../Using_Tools/Notebook_tools/Document_overview/Document_overview.md), filter the **Browse** [view](../../Using_Tools/Notebook_tools/Browse_overview/Notebook_Browse_overview.md) or the **Records** pane in [Record Edit](../../Using_Tools/Notebook_tools/Record_Edit_overview/Record_Edit_overview.md).

1.  In the **Navigation** **Pane**, click **Notebook**, and then click **Browse**, or **Record Edit**.

2.  Do the steps in [Filter data](filter_data.md).

> [!TIP]
>
> - In [Notebook](../../Using_Tools/Notebook_tools/Notebook_overview.md), fieldnote records can have *subrecords,* and *subrecords of subrecords*. In the **Title** column, record titles are shown in bold font; subrecord titles are *not*.
>
> - In **Browse** or **Record Edit**, if you have not [displayed](../Configure_Columns/Configure_Columns_overview.md) the Subrecords column, you can filter Notebook data such that only a record is displayed, but not any of its subrecords.
>
> - - However in Document, if Subrecords is selected (![](../../assets/images/CheckedBox.PNG)) in the [Configure Document Layout](../Configure_Columns/Using_Configure_Columns_dialog_box.md) dialog box, then any subrecords are displayed.
>
>   - So, to print one particular record with its subrecords, simply filter columns so only that record is displayed. Then, click Document, and [print](../../User_Interface/Menus/File/Print.md) that configured layout.
>
> - If you use the [Configure Columns](../Configure_Columns/Configure_Columns_overview.md) dialog box, you probably would want to display the **Subrecords** column, or the **Subrecord of** column, which includes the number that corresponds to the subrecord number you see below each [Subrecords field](../../User_Interface/Field_Descriptions/Notebook/Subrecords_field.md) (**Records** pane of **Record Edit**). You can use these columns when you filter or sort subrecords.
