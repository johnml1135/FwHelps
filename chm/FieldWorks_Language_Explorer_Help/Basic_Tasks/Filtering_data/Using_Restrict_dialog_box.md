# Using Restrict to items dialog box

*Basic Tasks › Filtering data*

**Restrict to items with dates** or **Restrict to items with values** dialog boxes can appear for [columns](../Configure_Columns/Using_Configure_Columns_dialog_box.md) that display *dates* or *numerical values.*

- In the column on which you want to filter the view, click the down arrow (below the column heading) and then click **Restrict**.

The **Restrict to items with dates** *or* **Restrict to items** **with values** dialog box appears.

The dialog box features change depending on the column that uses it and selections you make in them.

## Dates

For the **Restrict to items with dates** dialog box, do the following:

1.  In the left box, select the criterion for the restriction, such as **on**, **not on**, **on or before**, and so on.

2.  In the right box, type or select the date. If you will select with the calendar, use the left arrow or right arrow to scroll to the desired year and month. Then, click the day want to use as the date criterion.

3.  Select (![](../../assets/images/CheckedBox.PNG)) the **BC** check box (if available) for BC (versus AD) dates.

4.  Select or clear **Match unspecific dates** (if available) for dates with *ambiguity*, such as with **before**, **after**, or **about**, and **Unknown** selected for the day:

<!-- -->

1.  - If selected (![](../../assets/images/CheckedBox.PNG)), no ambiguous dates are filtered out.

    - If cleared (![](../../assets/images/UncheckedBox.PNG)), all ambiguous dates are filtered out.

    5.  Click **OK**.

## Numerical values

For the **Restrict to items with values** dialog box, do the following:

1.  In the left box, select the criterion for the restriction, such as **greater** **than**, **less than**, **equal to**, **between**, and so on.

2.  In the right box, type or select a numerical value.

3.  If a second box appears on the right (such as when **between** is selected), type or select a second value.

4.  Click **OK**.
