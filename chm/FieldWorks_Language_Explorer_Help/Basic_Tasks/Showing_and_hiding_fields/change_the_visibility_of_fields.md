# Change the visibility of fields

*Basic Tasks › Showing and hiding fields*

With few exceptions, you can specify when an individual field is shown or hidden. The fields you set to be normally hidden will appear only when you select [Show Hidden Fields](Show_Hidden_Fields.md).

To change the visibility of a field, do the following steps:

1.  Do one of the following:

    - If you can see the label of the field for which you will change visibility, click that field label.

    - If you cannot see the field you want to change, [show hidden fields](Show_Hidden_Fields.md), and then click the field label.

    The menu button (![](../../assets/images/Basic_Tasks/Showing_and_hiding_fields/Menu_Button_pic.GIF)) appears to the left of the label.

2.  Click the menu button, point to **Field Visibility**, and then click one of the following menu commands:

    - **Normally visibility**

      The field is always shown in the current view.

    - **Normally hidden, unless non-empty**

      The field is hidden from the current view when empty.

    - **Normally hidden**

      The field is hidden from the view.

> [!TIP]
>
> - You can also right-click the field label to open the **Field Visibility** menu.
