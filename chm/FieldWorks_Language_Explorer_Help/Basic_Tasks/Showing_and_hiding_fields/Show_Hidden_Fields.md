# Show Hidden Fields

*Basic Tasks › Showing and hiding fields*

**Show Hidden Fields** on the [Information bar](../../User_Interface/Toolbars/information_bar_overview.md) allows you to hide or show fields for which the [field visibility](change_the_visibility_of_fields.md) is set to **Normally Hidden** or **Normally Hidden, unless non-empty**. Those fields set to **Always visible** are always shown, as appropriate for the entry. See ![](../../assets/images/Important_Icon.gif) **Important** below for more explanation.

1.  To show *all* fields, do one of the following:

    - On the **View** menu, select (![](../../assets/images/Using_Tools/Lexicon_tools/Dictionary/SelectedViewCheckBox.png)) **Show Hidden Fields**.

    - On the Information bar, located below the menus and toolbars, select (![](../../assets/images/Selected_ShowHiddenFields.png)) the **Show Hidden Fields** check box.

    Fields that are normally hidden appear in the current window.

2.  To hide the fields set to be normally hidden, do one of the following:

    - On the **View** menu, clear the **Show Hidden Fields** menu command.

    - On the Information bar, clear the (![](../../assets/images/Cleared_ShowHiddenFields.png)) **Show Hidden Fields** check box.

    Fields normally hidden are hidden.

> [!IMPORTANT]
>
> Fields that may or may *not* be shown even while **Show Hidden Fields** is selected:
>
> - Selecting **Show Hidden Fields** does *not* expand sets of fields that are [collapsed](Hide_show_gps_of_flds.md).
>
> - Some fields only appear in entries that *use* those fields, based on selections in related fields.
>
>   For example, the [Inflection Classes field](../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/inflection_classes_field_entry_level.md), which is located slightly below the **Lexeme Form** field, only appears for affix entries that uses inflection classes. Similarly, for **Allomorphs**, the [Inflection Classes field](../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Alternate_Forms_level_flds/Inflection_classes_fld_Allomorph.md) appears there for an *affix* allomorph, but *not* a *stem* allomorph.
>
>   The group of field displayed [Grammatical Info Details](../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Grammatical_Info_Details_fields/Gram_Info_Detls_fields_ovw.md) area also varies depending on the particular entry.
>
> - Other fields only appear after content is entered in an *associated* field.
>
>   For example, the fields *associated with* the [Pronunciation field](../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Pronunciation_field.md) only appear after you begin to enter content in the **Pronunciation** field or insert a new one.
>
>   The [Example field](../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/example_field.md) is similar.
