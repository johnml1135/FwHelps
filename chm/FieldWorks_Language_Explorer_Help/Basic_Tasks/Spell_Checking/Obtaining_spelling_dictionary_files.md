# Obtaining spelling dictionary files

*Basic Tasks › Spell Checking*

1.  Obtain [files](dictionary_files.md) from other users of FieldWorks, OpenOffice/LibreOffice or other Hunspell-enabled programs, *or* download them from <a href="https://software.sil.org/fieldworks/download/spelling-dictionaries/" target="_blank" title="https://software.sil.org/fieldworks/download/spelling-dictionaries/">https://software.sil.org/fieldworks/download/spelling-dictionaries/</a>.

Please help us populate this site with a good supply of quality dictionary files.

2.  [Copy](Copy_spelling_dictionary_files.md) the files to make them available to FieldWorks.

> [!TIP]
>
> - These sites have offered them in the past (but may not anymore) - *Beware of viruses, adware and spyware when you download from the Internet.*
>
> - - <a href="https://addons.mozilla.org/en-US/thunderbird/language-tools/" target="_blank" title="https://addons.mozilla.org/en-US/thunderbird/language-tools/">https://addons.mozilla.org/en-US/thunderbird/language-tools/</a>
>
>   - <a href="https://extensions.services.openoffice.org/dictionary" target="_blank" title="https://extensions.services.openoffice.org/dictionary">https://extensions.services.openoffice.org/dictionary</a>
>
>   - <a href="https://sourceforge.net/projects/hunspell/files/" target="_blank" title="https://sourceforge.net/projects/hunspell/files/">https://sourceforge.net/projects/hunspell/files/</a>
>
>   - <a href="https://wiki.openoffice.org/wiki/Dictionaries" target="_blank" title="https://wiki.openoffice.org/wiki/Dictionaries">https://wiki.openoffice.org/wiki/Dictionaries</a>
>
> <!-- -->
>
> - If you have a recent version of LibreOffice 4 installed, and spell checking is working there, you can copy its spelling dictionary files. They *may be* here:
>
> %appdata%\Roaming\LibreOffice\4\user\extensions\tmp\extensions.
>
> - If you download \*.oxt files from a LibreOffice you need to change the filename extension to .zip. Then search the .zip file for the desired \*.aff and \*.dic [files](dictionary_files.md).
