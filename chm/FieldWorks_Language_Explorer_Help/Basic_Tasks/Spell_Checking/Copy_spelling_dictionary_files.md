# Copy spelling dictionary files

*Basic Tasks › Spell Checking*

To enable spell checking of an *analysis* writing system, you need to make spelling dictionary [files](dictionary_files.md) available to FieldWorks.

1.  [Obtain](Obtaining_spelling_dictionary_files.md) the spelling dictionary files.

2.  In the Address bar of your Windows<sup>®</sup> explorer, type `%appdata%`. The **hunspell** folder is typically in the **Roaming** folder and contains the spelling dictionary files.

3.  Copy the spelling dictionary files you obtained into the **hunspell** folder.

> [!TIP]
>
> - If necessary, you can duplicate and rename these files. Then, additional spelling dictionary files available to FieldWorks. [Create multiple vernacular spelling dictionaries](Create_multiple_vern_spell_dicts.md) is one way to do this.
>
> - The [General](../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Writing_System_Properties_General_tab.md) tab of the **Writing System Properties** dialog box shows the spelling dictionary [selected](../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Writing_System_Properties_General_tab.md) for a writing system.
