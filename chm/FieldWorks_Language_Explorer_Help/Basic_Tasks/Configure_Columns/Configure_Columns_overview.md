# Configure Columns overview

*Basic Tasks › Configure Columns*

When you see a columnar "browse" style view in the pane of a window or dialog box, there is usually a [Configure Columns button](configure_column_button_graphic.md) (![](../../assets/images/Basic_Tasks/Configure_Columns/Conf_Columns_Button.GIF)) at the end of the row of column headings. Click it to display a list of columns, and also **More Column Choices**.

- If the list has the column you want to show or hide, click that column.

  - Columns with a check mark (![](../../assets/images/Basic_Tasks/Configure_Columns/CheckMark.PNG)) are shown using the "best" or "default" [writing system](../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md). Columns without a check mark are hidden *or* are shown with a writing system other than the "best" or "default" writing system. (Sometimes you can add multiple instances of the *same column* and specify a *different writing system* for each one.)

- Alternatively, click **More Column Choices** to open the [Configure Columns](Using_Configure_Columns_dialog_box.md) dialog box so you can:

  - show or hide columns

  - specify the writing system used in individual columns

  - specify the order in which the columns are displayed

> [!TIP]
>
> - To specify the order of columns *without* using the dialog box, click the column header and drag it to the position where you want it. Release the mouse to drop the column there.
>
> - Click and drag the edge of a column to change the column's width.
>
> - "Browse" style views are used in many window panes and dialog boxes.
>
> - - Window pane examples (*not* exhaustive):\
>     **Lexicon Edit**: **Entries**, **Browse**, **Collect Words\
>     Grammar**: **Categories Browse\
>     Texts & Words**: **Texts**.
>
>   - Dialog boxes (*not* exhaustive):\
>     **New Entry**, **Change Spelling**, and **Choose Inflectional Affixes** (used in an affix template).
>
> - [Bulk Edit overview](../../Using_Tools/Lexicon_tools/Bulk_Edit_Entries/bulk_edit_overview.md) describes features in this dialog box when used in a bulk edit tool.
>
> - [Collect Words with Dialect Labels](../../Using_Tools/Lexicon_tools/Collect_Words/Collect_Words_with_Dialect_Labels.md) describes collecting words and add [dialect labels](../../Using_Tools/Lists_tools/About_Dialect_Labels.md).
>
> - [Filter Notebook records](../Filtering_data/Filter_Notebook_records.md) and [Sort Notebook records](../Sorting_data/Sort_Notebook_records.md) describe a column you likely want to display when you filter and sort.
