# Showing writing systems overview

*Basic Tasks › Showing Writing Systems*

If you have multiple writing systems, each field can use a lot of space. So to see all the fields, you might need to scroll up and down too much.

Here are two ways to help solve this:

- You can hide or show an *entire* writing system *everywhere* in the project. In this case, see [Hide or show a writing system](../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Hide_or_show_a_writing_system.md).

- You can [configure writing systems for fields](configure_field_WSs.md) to choose which of the available writing systems you want see in *individual* [single-line text fields](../../User_Interface/Field_Descriptions/Field_Types/Single_line_text_field.md).

For most single-line text fields, the menu button (![](../../assets/images/Basic_Tasks/Showing_Writing_Systems/Menu_Button_pic.GIF)) menu has a **Writing Systems** command. It has the following commands on a submenu:

  - **Show all right now**

    This command allows you to temporarily see and use all available writing systems, *without* showing them in other occurrences of the field. Writing systems that are *not* normally shown become shown while the insertion point (cursor) remains in the field.

    If you click this command, and then enter data in a writing system that is normally *not* shown, the writing system and data remain shown. If you delete the data, the writing system becomes hidden again. This helps you use screen space efficiently.

  - List of available writing systems

    The list disappears each time you select or clear a writing system, so you can only make one change at a time.

  - **Configure**

    This opens the **Writing System for \<name\> field** dialog box so you can configure all the writing systems for the field at the same time.

The selections in the list of available writing systems match the selections in the **Writing System for \<name\> field** dialog box. These selections affect *every* occurrence of the field, which is different than **Show all right now**.

> [!IMPORTANT]
>
> - Use the **Writing Systems** [pane](../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Using_the_Writing_System_Properties_dialog_box.md) controls to specify which writing systems are available for use in the language project, and their [order](../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Reorder_writing_systems.md).
>
> Usually single-line text fields use only vernacular or only analysis writing system. However, [custom](../../User_Interface/Menus/Tools/Custom_Fields/Custom_Fields_overview.md) single-line text fields may use both.
>
> "Available" writing systems are listed in the **Writing Systems** pane, even if *not* selected there.
>
> - [Title fields](../../User_Interface/Field_Descriptions/Notebook/Title_field_Ntbk.md) in **Notebook**, do *not* use the **Show all right now** command. These **Title** field can show only *one* writing system at a time.
