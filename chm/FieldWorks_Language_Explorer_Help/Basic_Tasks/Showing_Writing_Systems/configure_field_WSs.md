# Configure writing systems for fields

*Basic Tasks › Showing Writing Systems*

To select which writing systems are displayed in the field, do the following steps:

1.  Click the [field](../../User_Interface/Field_Descriptions/Field_Types/Single_line_text_field.md) that you want to configure, and then click the menu button (![](../../assets/images/Basic_Tasks/Showing_Writing_Systems/Menu_Button_pic.GIF)) that appears.

    If the field permits it, **Writing Systems** appears as a command on the menu button menu.\
    Some fields, such as the [Pronunciation field](../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Pronunciation_field.md) or [Etymology field](../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Etymology_field.md), need to be expanded before you can see the **Writing Systems** command. To expand such fields, enter data in them or use the **Insert \<name\>** command on the menu button (![](../../assets/images/Basic_Tasks/Showing_Writing_Systems/Menu_Button_pic.GIF)) menu.

2.  If the **Writing Systems** command appears, point to it, and then do one of the following:

    - Click **Show all right now**

      To use a particular writing system in the field ([example](../../User_Interface/Field_Descriptions/Field_Types/Single_line_text_field_example_graphic.md)) *without displaying it in every occurrence of the field*, select **Show all right now**, and then enter the data.

      When you click another field or refresh the window, writing systems that are not used, and that do not have a check mark, are no longer shown in the field.

    - Click an available writing system

      If the writing system has a check mark (![](../../assets/images/Basic_Tasks/Showing_Writing_Systems/CheckedWS.PNG)), the check mark is removed. Then, the writing system is only shown in fields that have existing data in that writing system. Otherwise, the writing system is no longer shown in the field.

      If the writing system does *not* have a check mark, then a check mark is added, and that writing system is shown in the field.

    - Click **Configure**

      The **Writing Systems for \<name\> field** dialog box opens.

      Select (![](../../assets/images/CheckedBox.PNG)) each writing system you want shown, whether it contains data or not.

      Clear (![](../../assets/images/UncheckedBox.PNG)) each writing systems you want shown *only* when it contains data. ( **Tip:** Use **Show all right now** when you want to enter data.)

      Click **OK**. If the changes you expected do not appear, refresh (**F5**) the window.

> [!NOTE]
>
> - [Title fields](../../User_Interface/Field_Descriptions/Notebook/Title_field_Ntbk.md) in **Notebook**, do *not* use the **Show all right now** command. These **Title** field can show only *one* writing system at a time.
