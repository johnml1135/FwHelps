# Sorting data overview

*Basic Tasks › Sorting data*

You can sort data according to content in one or more *columns*, which provides a primary sort, secondary sort and tertiary sort. This is *not* to be confused with the ability to [change the secondary order](../../Using_Tools/Lists_tools/Change_the_secondary_sort_order.md) or to [set the primary sort order](../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Writing_System_Properties_Sorting_tab.md) of dictionary entries. You can also sort by length and sort by the trailing end of the content.

The `Help` topics related to sorting columnar data are the following:

- [Sort data](Sort_data.md)

  - [Sort Grammar data](Sort_Grammar_data.md)

  - [Sort lexical entries](Sort_lexical_entries.md)

  - [Sort Notebook records](Sort_Notebook_records.md)

  - [Sort Texts & Words](Sort_Texts_Words.md)

> [!NOTE]
>
> - Except for [Reversal Index Categories](../../Using_Tools/Lists_tools/about_reversal_index_categories.md), **Lists** area data are not displayed in columns and are not sorted like other data.
