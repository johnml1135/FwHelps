# Sort Grammar data

*Basic Tasks › Sorting data*

1.  In the **Navigation** **Pane**, click **Grammar**, and then select any of the tools (except **Grammar Sketch** or **Problems**).

2.  Do the steps in [Sort data](Sort_data.md).

> [!NOTE]
>
> - The sort order in the [Categories Browse](../../Using_Tools/Grammar_tools/Categories_Browse/Categories_Browse_overview.md) controls the order in the center pane of **Category Edit**.
