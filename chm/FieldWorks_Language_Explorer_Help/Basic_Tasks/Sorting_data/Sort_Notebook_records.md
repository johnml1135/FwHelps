# Sort Notebook records

*Basic Tasks › Sorting data*

To sort the **Document** [view](../../Using_Tools/Notebook_tools/Document_overview/Document_overview.md), sort the **Browse** [view](../../Using_Tools/Notebook_tools/Browse_overview/Notebook_Browse_overview.md).

1.  In the **Navigation** **Pane**, click **Notebook**, and then click **Browse**.

2.  If necessary, use the [Configure Columns](../Configure_Columns/Configure_Columns_overview.md) dialog box to add or remove columns in the displayed view.

    - You probably would want to display the **Subrecords** column, or the **Subrecord of** column which includes the number that corresponds to the subrecord number you see below each [Subrecords field](../../User_Interface/Field_Descriptions/Notebook/Subrecords_field.md) (**Records** pane of **Record Edit**). You can use these columns when you filter or sort subrecords.

3.  Do the steps in [Sort data](Sort_data.md).

> [!TIP]
>
> - In [Notebook](../../Using_Tools/Notebook_tools/Notebook_overview.md), fieldnote records can have subrecords, and subrecords of subrecords.
>
> - - In the **Title** column, subrecord titles are *not* displayed in bold font.
