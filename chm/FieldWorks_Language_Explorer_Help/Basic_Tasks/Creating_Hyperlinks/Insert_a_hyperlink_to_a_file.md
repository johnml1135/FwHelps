# Insert a hyperlink to a file

*Basic Tasks › Creating Hyperlinks*

You use the **Link to File** command to find a file, and then make selected words into a [hyperlink](Creating_Hyperlinks_overview.md), or to paste the path to the file as a hyperlink.

1.  To change one or more words into a hyperlink, select the words. Otherwise, put the insertion point at the location where you want the path to appear as a hyperlink.

2.  On the [Insert](../../User_Interface/Menus/Insert/Insert_overview.md) menu, click **Link to File**.

    If **Link to File** is *not* available, the field with the selection or insertion point cannot contain hyperlinks. Use another field, or [add a custom field](../../User_Interface/Menus/Tools/Custom_Fields/add_a_custom_field.md).

    The **Open** dialog box appears.

3.  In the dialog box, select a file, and then click **Open**.

    If the file you selected is *not* in a [Linked Files folder](../../User_Interface/Menus/File/Backup_and_Restore/Folder_Structure.md) subfolder, the **Move or Copy Files** dialog box appears.

    - Click the **Copy Files** (recommended), or another button, in the dialog box. (Your choice has [backup](../../User_Interface/Menus/File/Backup_and_Restore/Back_up_this_Project.md) implications.)

The selected text becomes a hyperlink and inherits the **Hyperlink** *character* [style](../../User_Interface/Menus/Format/Styles/Styles_overview.md).

> [!NOTE]
>
> - *Only* files in an appropriate [folders](../../User_Interface/Menus/File/Backup_and_Restore/Folder_Structure.md) are [backed up](../../User_Interface/Menus/File/Backup_and_Restore/Back_up_this_Project.md).
>
> - When you rest the mouse pointer on the hyperlink text, the pointer becomes a ![](../../assets/images/Basic_Tasks/Creating_Hyperlinks/Pointing_hand.gif).
>
> - You can insert hyperlinks in [text](../../User_Interface/Field_Descriptions/Field_Types/field_types_overview.md) fields, but not in [list reference](../../User_Interface/Field_Descriptions/Field_Types/List_reference_field.md) or [date](../../User_Interface/Field_Descriptions/Field_Types/date_field.md) fields.
>
> - You can [cut, copy and paste](../../User_Interface/Menus/Edit/Cut_copy_and_paste.md) a hyperlink to another location or FieldWorks program.
>
> - To edit the *text* of a hyperlink, use the keyboard instead of the mouse to [move the insertion point](../../User_Interface/Shortcuts/Shortcut_keys_to_move_the_insertion_point.md). You *cannot* edit the path or properties of a link.
>
> - If you did *not* select any text, the path to the file is inserted as the link text at the insertion point.
>
> - The [Paste a Hyperlink](Paste_hyperlink.md) command on the **Edit** menu is different.
