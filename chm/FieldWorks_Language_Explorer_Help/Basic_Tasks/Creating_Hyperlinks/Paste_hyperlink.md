# Paste hyperlink

*Basic Tasks › Creating Hyperlinks*

You use the **Paste Hyperlink** command (**Edit** menu) to paste the path that is on your computer's Clipboard into selected words. This makes them [hyperlinks](Creating_Hyperlinks_overview.md).

1.  If you do not already have the desired path on your Clipboard, do the following:

    - For a path to a FLEx window, use [Copy Location as Hyperlink](../../User_Interface/Menus/Edit/Copy_location_as_hyperlink.md).

    - For an Internet address (URL), see [Hyperlink to a web page](hyperlink_to_web_page.md).

    - For a file address path, it is recommended that you use the [Link to File](Insert_a_hyperlink_to_a_file.md) command (**Insert** menu). However, you can do the following (manually):

      Navigate to the file on your computer and then copy the path from the Address bar. If necessary, paste the path into a text editor, and then edit the path to include the particular file name. Then copy the edited path again to update the Clipboard.

2.  Go to the location in FieldWorks Language Explorer where you want to create a hyperlink.

3.  In a [text field](../../User_Interface/Field_Descriptions/Field_Types/field_types_overview.md) (or a [custom text field](../../User_Interface/Menus/Tools/Custom_Fields/add_a_custom_field.md)) select the words that you want to use as the hyperlink text. Type and select new words if necessary.

4.  On the **Edit** menu, click **Paste Hyperlink**.

    The selected words become a hyperlink.

    If you mistakenly clicked **Paste** on the **Edit** menu or the shortcut keys `Ctrl+V`, then the pasted Clipboard content is only regular text. In this case, select the words again, and then use **Paste Hyperlink**. Then, delete any unwanted path text from the field.

> [!NOTE]
>
> - *Only* files in an appropriate [folder](../../User_Interface/Menus/File/Backup_and_Restore/Folder_Structure.md) are [backed up](../../User_Interface/Menus/File/Backup_and_Restore/Back_up_this_Project.md).
>
> - When you rest the mouse pointer on the hyperlink text, the pointer becomes a ![](../../assets/images/Basic_Tasks/Creating_Hyperlinks/Pointing_hand.gif).
>
> - You can [cut, copy and paste](../../User_Interface/Menus/Edit/Cut_copy_and_paste.md) a hyperlink to another location or FieldWorks program.
>
> - If there is not a valid address in the Clipboard, then **Paste Hyperlink** has no effect.
>
> - If you did not select any text, the path to the file is inserted as the link text at the insertion point.
>
> - To edit the *text* of a hyperlink, use the keyboard instead of the mouse to [move the insertion point](../../User_Interface/Shortcuts/Shortcut_keys_to_move_the_insertion_point.md).
