# Creating Hyperlinks overview

*Basic Tasks › Creating Hyperlinks*

A *hyperlink* is a highlighted word or phrase that, when clicked, displays related resources (for example, an external file, a web page, or data in a FieldWorks project). The **Hyperlink** [character style](../../User_Interface/Menus/Format/Styles/Styles_overview.md) is applied to distinguish it from the rest of the text. When you click a hyperlink, the file or data is opened in the associated program, if it is installed.

You can paste or insert various hyperlinks, such as the following:

- specific views in the *current* FieldWorks language project, or in *a different* one:

  Use [Copy Location as Hyperlink](../../User_Interface/Menus/Edit/Copy_location_as_hyperlink.md), and then [Paste Hyperlink](Paste_hyperlink.md).

- pictures:

  You can [insert a picture](../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_a_picture.md), or [insert a link to a file](Insert_a_hyperlink_to_a_file.md).

- sound and movie or video clips:

  You can [insert a sound or movie file](../../Using_Tools/Lexicon_tools/Lexicon_Edit/Insert_link_to_sound_or_movie.md), or [insert a link to a file](Insert_a_hyperlink_to_a_file.md).

- other kinds of files, such as text files, spreadsheets, PowerPoint presentations:

  Use [insert a link to a file](Insert_a_hyperlink_to_a_file.md), or [Paste Hyperlink](Paste_hyperlink.md).

- [Internet (web) pages](hyperlink_to_web_page.md).

> [!CAUTION]
>
> - Be careful *where* you create hyperlinks because even linked text may appear in the [dictionary](../../Using_Tools/Lexicon_tools/Dictionary/Dictionary_overview.md).
>
> - *Only* files in an appropriate [folders](../../User_Interface/Menus/File/Backup_and_Restore/Folder_Structure.md) are [backed up](../../User_Interface/Menus/File/Backup_and_Restore/Back_up_this_Project.md).

> [!NOTE]
>
> - Link to resources on your own computer whenever possible, rather than to removable media or remote computers. However, linked resources can be in any of the following locations:
>
> - - On your own computer hard drive.
>
>   - On removable media (for example, CD-ROMs, thumb drives (flash drives) and so on).
>
>   - On other computers over a network connection.
>
>   - On a web site or FTP server.
