# Cannot follow link

*Basic Tasks › Creating Hyperlinks*

The **Cannot follow link** message box appears if a link to an [external file](../../User_Interface/Menus/File/Project_Properties/Project_Properties_Linked_Files_tab.md) does not have a correct path, the file is no longer there, or the device that has the file is not available to your computer.

The message box displays the path (URL) stored in the link.

If you see this message box, do the following:

1.  If the link was to a removable device, such as a CD-ROM or thumb drive, make that device available to your computer.

2.  If you have a copy of the file, paste it in the folder displayed in the message box path. Then, do the following:

    - Click **OK** to close to close the message box.

    - Try the link again. If it still does not work, continue.

3.  If you do not have a copy of the file or the link does not work, do the following:

    - Click **OK** to close to close the message box.

    - [Remove](Remove_a_hyperlink.md) the hyperlink.

    - [Insert a new hyperlink](Insert_a_hyperlink_to_a_file.md) to another file.
