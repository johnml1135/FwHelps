# Remove a hyperlink

*Basic Tasks › Creating Hyperlinks*

**Currently, the programming has** *not* **been completed for any right-click commands to remove links.**

- **Instead, select the linked text, and then <a href="../../User_Interface/Menus/Format/apply_a_style_to_text.md" style="font-weight: normal;">apply</a> the** **Default Paragraph Characters** **style.**

- **Otherwise, you can delete the linked text and then enter it again.**
