# Move a field

*Basic Tasks › Moving fields*

With a few exceptions, you can use the **Move Field** command that appears in [context-sensitive](../Show_data/Context_sens_menus.md) menus.

To move a field, do these steps:

1.  Select (![](../../assets/images/CheckedBoxBLACK.png)) the **Show Hidden Fields** check box, if it is not already selected.

2.  Click the menu button (![](../../assets/images/Basic_Tasks/Showing_and_hiding_fields/Menu_Button_pic.GIF)), point to **Move Field**, and then click **Move Up** or **Move Down**.

- Do the step above until the field is where you want it to appear.
