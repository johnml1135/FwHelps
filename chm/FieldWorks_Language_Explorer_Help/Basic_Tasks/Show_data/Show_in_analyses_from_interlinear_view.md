# Show in Word Analyses from interlinear text

*Basic Tasks › Show data*

1.  In a **Gloss** or **Analyze** tab, click the desired word.

    The word appears in a [word focus box](../../Using_Tools/Texts_%26_Words_tools/Interlinear_Texts/Word_Focus_Box_examples.md).

2.  Right-click any line (**Word**, **Morpheme** and so on) in the word focus box, and then select **Show in Word Analyses**.

    The window changes to display that word in **Word Analyses**.
