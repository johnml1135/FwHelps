# Show data overview

*Basic Tasks › Show data*

The *Show* feature uses [context-sensitive menus](Context_sens_menus.md). These menus are available in numerous contexts. For example, you can *right-click* data in columns or fields, and use [field](../../User_Interface/Field_Descriptions/field_descriptions_overview.md) or [Information bar](../../User_Interface/Toolbars/information_bar_overview.md) menu buttons. Also, if you use the default parser with [Try a Word](../../User_Interface/Menus/Parser/Try_a_word.md), you can right-click the analysis, if displayed, above the **Results** pane.

> [!IMPORTANT]
>
> - It is the *only* way to [specify concordance criteria](../../Using_Tools/Texts_&_Words_tools/Concordance/specify_concordance_criteria.md) that is *specific to a particular item* (lexical entry, morpheme, sense, allomorph, analysis and so on).
>
>   If you [manually](../../Using_Tools/Texts_&_Words_tools/Concordance/Manually_specify_concordance_criteria.md) type or paste the same characters that are used in the item, then the search is based on that simple string of characters, which is *not* specific to a particular item. In that case, the concordance results could include other occurrences, such as homographs.
>
> - It enables you to conveniently move ("jump") from one area, tool or entry to another so you can see an item (word, analysis, morpheme and so on) there.
>
