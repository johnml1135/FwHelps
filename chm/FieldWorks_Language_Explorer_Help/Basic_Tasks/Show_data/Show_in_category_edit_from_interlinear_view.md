# Show in Category Edit from interlinear view

*Basic Tasks › Show data*

1.  In any of the **Analyze** tabs, click the desired word.

    The word appears in a [word focus box](../../Using_Tools/Texts_%26_Words_tools/Interlinear_Texts/Word_Focus_Box_examples.md).

2.  For the particular lexical entry, right-click the **Lex Entries**, **Lex Gloss** or **Lex** **Gram Info** line in the word focus box, and then select **Show in Category** **Edit**.

The window changes to **Category Edit** ([Grammar](../../Using_Tools/Grammar_tools/grammar_overview.md)) and shows the category that is in the **Lex** **Gram Info** line.

> [!TIP]
>
> - Each morpheme of a multimorphemic word usually references a different lexical entry. You can show the category of any entry, depending on *where* you right-click your mouse.
>
> - Use the **Show Word Category in Category Edit** command to show the grammatical category that is in the **Word Cat** line.
