# Show in from Word Analyses

*Basic Tasks › Show data*

From [Words Analyses](../../Using_Tools/Texts_%26_Words_tools/Word_Analyses/Word_Analyses_overview.md) (**Texts & Words**), you can right-click items in fields to display a [context-sensitive menu](Context_sens_menus.md) with various **Show concordance of** or **Show** **\<item\>** **in** commands.

|  |  |  |
|----|----|----|
| To Show | Right-click | Then, Select |
| analysis in **Concordance** | [Analysis 1](../../User_Interface/Field_Descriptions/Texts_%26_Words/analysis_1_field.md) field, (**2**, **3** and so on) | **Show Analyses in Concordance** |
| grammatical category of a *wordform* in **Category Edit** | **Lex Gram Info** line ([Analysis field](../../User_Interface/Field_Descriptions/Texts_%26_Words/Analysis_field.md)) | **Show in Category Edit** |
| grammatical category of a particular *morpheme* (of a wordform) in **Category Edit** | **Morphemes** line ([Analysis field](../../User_Interface/Field_Descriptions/Texts_%26_Words/Analysis_field.md)) | **Show Word Cat. in Category Edit** |
| lexical entry used in an analysis in **Lexicon Edit** | **Lex Entries** line ([Analysis field](../../User_Interface/Field_Descriptions/Texts_%26_Words/Analysis_field.md)) | **Show Entry in Lexicon** |
| a *wordform* (word) in **Concordance** | the row with the word in the **Wordforms** pane | **Show Wordform in Concordance** |
| *word gloss* assigned to an analysis in **Concordance** | [Word Gloss field](../../User_Interface/Field_Descriptions/Texts_%26_Words/Word_Gloss_field.md) label | **Show Word Gloss in Concordance** |

|  |  |  |
|----|----|----|
| To Show | Right-click | Then, Point to |
| an item from **Morphemes**, **Lex Entries**, **Lex Gloss** or **Lex Gram Info** line in **Concordance** | **Morphemes**, **Lex Entries**, **Lex Gloss** or **Lex Gram Info** line ([Analysis field](../../User_Interface/Field_Descriptions/Texts_%26_Words/Analysis_field.md)) | **Show Concordance of**, and then select the item in the submenu |
