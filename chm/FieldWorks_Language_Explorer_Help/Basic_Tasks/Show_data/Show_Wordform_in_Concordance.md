# Show Wordform in Concordance from Baseline tab

*Basic Tasks › Show data*

- In any **Baseline** tab, right-click the desired wordform (word) and then click **Show Wordform in Concordance**.

  The window changes to [Concordance](../../Using_Tools/Texts_&_Words_tools/Concordance/Concordance_overview.md). Occurrences of the word, if any, appear in the **Concordance Results** pane. You do *not* need to click **Search**.

> [!IMPORTANT]
>
> - If **Show Vernacular Spelling Errors** is selected on the [Tools](../../User_Interface/Menus/Tools/Tools_overview.md) menu and the word has a wavy red underline, you will need to either correct or [approve](../../Using_Tools/Texts_&_Words_tools/Word_Analyses/Specify_spelling_status.md) the spelling, or clear the check mark from the **Show Vernacular Spelling Errors** menu command. Otherwise, the right-click menu will only list [spell checking](../Spell_Checking/Spell_checking_overview.md) commands.
>
>   - Be aware that if you edit a word in the **Baseline** tab, you can negatively affect other tabs, such as the [Text Chart tab](../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Text_Chart_tab/Text_chart_overview.md).
>
>   - If you clear the **Show Vernacular Spelling Errors** command, you may need to refresh (`F5`) the window to hide the red underlines and change the right-click menu.
