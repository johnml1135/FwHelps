# Show in from Lists

*Basic Tasks › Show data*

In **Lists**, the **Show in** commands are currently limited to [list-reference fields](../../User_Interface/Field_Descriptions/Field_Types/List_reference_field.md) used in a list. These allow you to see a list item in its own list. You could use this feature to edit that list item's metadata or to add another item to that list.

For example, if you had selected a **Status** list item for the **Status** field in the **Academic Domains** list, you could right-click that status item, and then click **Show in Status list**.
