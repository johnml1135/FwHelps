# Show in from Categories Browse

*Basic Tasks › Show data*

- In the **Categories (or Parts of Speech)** pane in **Categories Browse**, right-click the desired category (row), and then click *one* of the following:

  - **Show in Category Edit**.

    The window changes to show that category in [Category Edit](../../Using_Tools/Grammar_tools/Category_Edit/Category_Edit_overview.md).

  - **Show Category in Concordance**.

The window changes to show the concordance of that particular grammatical category in **Concordance**.
