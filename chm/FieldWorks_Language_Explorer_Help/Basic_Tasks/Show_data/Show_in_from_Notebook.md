# Show in from Notebook

*Basic Tasks › Show data*

In **Notebook**, **Show in** commands are available in these fields:

- In [list-reference fields](../../User_Interface/Field_Descriptions/Field_Types/List_reference_field.md) that reference items from a list, right-click a list item, and then click **Show in** \<name\> **list**.

- In list-reference fields that reference other **Notebook** records, right-click a record, and then click **Show Record in Notebook**.
