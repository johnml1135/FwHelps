# Show Word Cat in Category Edit from interlinear text

*Basic Tasks › Show data*

The **Show Word Category in Category Edit** command appears for approved analyses (without [colored background](../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/interlinear_views_colors.md)) that have content in both the **Word Gloss** and **Word Cat** lines.

1.  In a **Gloss** or **Analyze** tab, click the desired word.

    The word appears in a [word focus box](../../Using_Tools/Texts_%26_Words_tools/Interlinear_Texts/Word_Focus_Box_examples.md).

<!-- -->

2.  Right-click any line, and then select **Show Word Category in Category Edit**.

    The window changes to **Category Edit** ([Grammar](../../Using_Tools/Grammar_tools/grammar_overview.md)) and displays the grammatical category in the **Word Cat** line.

> [!TIP]
>
> - Use the **Show in Category Edit** command to show the grammatical category that is in the **Lex Gram Info** line.
