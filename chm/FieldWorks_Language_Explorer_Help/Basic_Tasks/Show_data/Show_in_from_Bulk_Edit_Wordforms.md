# Show in from Bulk Edit Wordforms

*Basic Tasks › Show data*

- In the **Wordforms** pane, right-click the desired wordform (row), and then click *one* of the following:

  - **Show in Word Analyses**.

    The window changes to show the wordform in [Word Analyses](../../Using_Tools/Texts_%26_Words_tools/Word_Analyses/Word_Analyses_overview.md).

  - **Show Wordform in Concordance**.

    This [specifies concordance criteria](../../Using_Tools/Texts_%26_Words_tools/Concordance/specify_concordance_criteria.md). The window changes to show the concorded wordform in **Concordance**.
