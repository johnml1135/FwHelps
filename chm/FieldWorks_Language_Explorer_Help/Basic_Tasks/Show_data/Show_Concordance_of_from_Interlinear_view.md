# Show Concordance of from interlinear view

*Basic Tasks › Show data*

1.  In any of the **Gloss** or **Analyze** tabs, click the desired word.

    The word appears in a [word focus box](../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Word_Focus_Box_examples.md).

2.  In the word focus box, right-click the particular item that you want to see in [Concordance](../../Using_Tools/Texts_&_Words_tools/Concordance/Concordance_overview.md), point to **Show concordance of**, and then click one of these submenu commands:

|  |  |  |
|----|----|----|
| Click | To show a concordance of the (item) |  |
| **Wordform** | *word* shown on the **Word** line |  |
| **Analysis** | *analysis* in the current word focus box |  |
| **Morph** | *morpheme* that you right-clicked |  |
| **Entry** | *lexical entry* that you right-clicked |  |
| **Sense** | *sense* of the lexical entry that you right-clicked |  |
| **Category** | *category* of the lexical entry or sense you right-clicked |  |
| **Word Gloss** | *word gloss* displayed in the **Word Gloss** line |  |
| **Word Category** | *category* displayed in the **Word Cat** line |  |

The window changes to **Concordance**. The item appears in the **Concorded on** line at the top of the **Specify Concordance Criteria** pane. Occurrences of the item, if any, appear in the **Concordance Results** pane.

> [!IMPORTANT]
>
> - Each morpheme of a multimorphemic word usually references a different lexical entry. What is shown in **Concordance** can depend on *where* you right-click.
>
> - Some commands are *not always available*. For example, some appear only for approved analyses (without a [colored background](../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/interlinear_views_colors.md)).
>
> - Similar commands are available in the **Wordform Analyses** pane for analyses under **User Approved (Analyses)** in [Word Analyses](../../Using_Tools/Texts_&_Words_tools/Word_Analyses/Word_Analyses_overview.md).
