# Chorus Hub overview

*User Interface › Menus › Send/Receive*

Chorus Hub is intended to simplify the setup and use of [Send/Receive](Send_Receive_overview.md) on a local network. It works with FLEx Bridge.

1.  Designate *one* of the computers on your network as "the server".

2.  Download and install Chorus Hub:

    - On the **Send/Receive** [menu](../../User_Interface/Menus/Send_Receive/Send_Receive_menu.md), click **About FLEx Bridge**.

    - On the page that appears, click the **Download Chorus Hub** link.

3.  Find and click the ChorusHubInstaller (\*.msi) file to open the **Chorus Hub Setup Wizard**.

4.  Follow the steps in the wizard to install Chorus Hub.

It will create a folder at C:\\ChorusHub on that computer.

- If you are prompted to restart your computer, restart it.

Now, Chorus Hub is available to your computer and others on your network.

You can see this, for example, in the **Send/Receive Projects** dialog box, which you open from the **Send/Receive** [menu](../../User_Interface/Menus/Send_Receive/Send_Receive_menu.md).

> [!IMPORTANT]
>
> - Your firewall may need to be set to permit the server and the client machines to communicate. Refer to the Help files for *your* firewall.
>
> <!-- -->
>
> - Programs that can collaborate with Chorus Hub typically have a Help topic called **Get Started with Sent/Receive**. Those Help topics give information related to using Send/Receive with that program, and additional Chorus Hub setup.
>
> - **Technical Notes on FieldWorks Send-Receive** is available under **Resources** on the [Help](../../User_Interface/Menus/Help/Help_overview.md) menu.
