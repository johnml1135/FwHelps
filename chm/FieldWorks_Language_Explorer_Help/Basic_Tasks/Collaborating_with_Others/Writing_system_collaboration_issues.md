# Writing system collaboration issues

*Basic Tasks › Collaborating with Others*

If you will use [Send/Receive](Send_Receive_overview.md) (Lexicon) to collaborate with WeSay users, be aware that currently FLEx and WeSay have slightly different writing system lists and capabilities. Specifically:

- You cannot create a writing system for a macro-language in FLEx, but you can in WeSay.

- FLEx allows you to create custom writing systems that WeSay may not handle properly.

You are unlikely to experience writing system problems if you use standard writing systems (neither macro-language or custom). However, if you are unsure, or you are already using a non-standard writing system, consider the following until this is resolved:

- Before you and collaborators begin using Send/Receive, make sure the writing systems used in the project work in both WeSay and FLEx.

You could create test projects with those writing systems and test Send/Receive with sample data.

In the **Writing System Properties** dialog box, you can access the Ethnologue internet site and learn if the code for your writing system is a standard language code. For example, the Afro-Asiatic languages *afa* does not appear in the list at <a href="https://www.ethnologue.com/browse/codes" target="_blank" title="https://www.ethnologue.com/browse/codes">https://www.ethnologue.com/browse/codes</a> as it is a macro-language.
