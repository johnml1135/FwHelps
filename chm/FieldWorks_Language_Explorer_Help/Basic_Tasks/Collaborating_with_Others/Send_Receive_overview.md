# Send Receive overview

*Basic Tasks › Collaborating with Others*

In general, Send/Receive transmits data and merges changes done by other [collaborators](Collaborating_with_Others_overview.md).

- [Get Started with Send/Receive](Get_Started_with_Send_Receive.md) describes how to get started *correctly*.

- [Send/Receive considerations](Send_Receive_considerations.md) lists information and practices that you and your collaborators need to discuss.

- [Send/Receive menu overview](../../User_Interface/Menus/Send_Receive/Send_Receive_menu.md) describes the menu commands that you use to collaborate with others using Send/Receive features.

- On the [Standard toolbar](../../User_Interface/Toolbars/Standard_toolbar.md), the **Send/Receive** button (![](../../assets/images/User_Interface/Toolbars/Send_Receive_Icon.png)) initiates **Project** *or* **Lexicon**, depending on which command was most recently used.

- **Technical Notes on FieldWorks Send-Receive** is available under **Resources** on the [Help](../../User_Interface/Menus/Help/Help_overview.md) menu.

- **Help** on the **Send/Receive** menu opens the *Chorus Help* file. It has additional information which is specific to Chorus-enabled features.

> [!IMPORTANT]
>
> - **Get project from a colleague** opens the [Receive project](../../User_Interface/Menus/Send_Receive/Get_a_project.md) dialog box.
>
> You see this command in the [Open Project](../../User_Interface/Menus/File/Open_a_language_project.md), [Language Explorer](../../Overview/Welcome_to_FieldWorks.md), or [Unable to Open Project](../../User_Interface/Menus/File/Unable_to_Open_Project.md) dialog boxes.
>
> - If you use Send/Receive:
>
> 1.  - [Renaming a project](../../User_Interface/Menus/File/Backup_and_Restore/Rename_a_FieldWorks_project.md) will force collaborators to [receive the project](../../User_Interface/Menus/Send_Receive/Get_a_project.md) as a new project. In this case, there will be another set of local and shared [repositories](Get_Started_with_Send_Receive.md).
>
>     - The project name *cannot* contain non-ASCII characters.
>
>     - *D**o not* change the **Linked Files** folder [location](../../User_Interface/Menus/File/Project_Properties/Project_Properties_Linked_Files_tab.md).
>
>     - Send/Receive *stops* a [parser](../../User_Interface/Menus/Parser/Parser_menu_overview.md). You need to restart it manually.
>
> - As a general rule, data are included when you use the send/receive feature; Personal settings, such as views, are *not* included. You need to install fonts and keyboards on each computer or device separately.\
>   For more details, see <a href="https://software.sil.org/fieldworks/support/using-sendreceive/" target="_blank" title="https://software.sil.org/fieldworks/support/using-sendreceive/">https://software.sil.org/fieldworks/support/using-sendreceive/</a>.
