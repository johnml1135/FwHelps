# Outdated Version of FieldWorks

*Basic Tasks › Collaborating with Others*

An older version of FieldWorks does not understand new features. The **Outdated Version of FieldWorks** dialog box appears when you try to do the following:

- [Open a FieldWorks project](../../User_Interface/Menus/File/Open_a_language_project.md) in an older version of FieldWorks that has been created by a newer version of FieldWorks or upgraded to a newer version.

- [Restore a project](../../User_Interface/Menus/File/Backup_and_Restore/Restore_a_project.md) that was backed up using a newer version of FieldWorks.

> [!TIP]
>
> - If you open a FieldWorks project on multiple computers, use the same version of FieldWorks. When you want to upgrade to a new version of FieldWorks, choose a time when you can install it on all the computers that you and your team members use.
>
> - Before you upgrade to a newer version of FieldWorks, [back up](../../User_Interface/Menus/File/Backup_and_Restore/Back_up_this_Project.md) all your projects in the old version.
