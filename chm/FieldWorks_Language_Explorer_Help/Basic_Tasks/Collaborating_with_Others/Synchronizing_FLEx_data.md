# Synchronizing FLEx data

*Basic Tasks › Collaborating with Others*

Consider the following:

- The import processes have *limited* or *no* capability for merging an imported entry with an existing entry.

- The [Import/Merge from LIFT File](../../Beginning_Tasks/Importing_Data/import_lift_lex.md) dialog box has some options to help you work with conflicting data, but does not provide a true full-merge function.

- *Collaboration and networking* on the Internet at <a href="https://software.sil.org/fieldworks/support/technical-documents/" target="_blank" title="https://software.sil.org/fieldworks/support/technical-documents/">https://software.sil.org/fieldworks/support/technical-documents/</a> provides a more technical view.

> [!TIP]
>
> - Send/Receive operations synchronize changes to data. The [Send/Receive](../../User_Interface/Menus/Send_Receive/Send_Receive_menu.md) menu has commands that let you work with messages (questions, merge notifications and merge conflicts).
