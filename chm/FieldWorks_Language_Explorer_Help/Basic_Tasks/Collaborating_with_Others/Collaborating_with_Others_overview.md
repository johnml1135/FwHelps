# Collaborating with Others overview

*Basic Tasks › Collaborating with Others*

It is possible to collaborate with others in a number of ways.

## Send/Receive

- Use [Send/Receive](Send_Receive_overview.md) **Project** to transmit and merge data with others who are working with the same language project in FieldWorks Language Explorer on separate computers.

- Use [Send/Receive](Send_Receive_overview.md) **Lexicon** to transmit and merge *lexical* data (only) with other programs that support LIFT, such as WeSay.

These **Send/Receive** [menu](../../User_Interface/Menus/Send_Receive/Send_Receive_menu.md) commands are the *recommended* way to maintain a common database because Send/Receive uses [Chorus](../../Glossary_of_Terms.md#C) repositories. One of the repositories is the *shared* (or 'master') repository, while each user has a *personal* repository.

[Get Started with Send/Receive](Get_Started_with_Send_Receive.md) has more information.

**Note:** Collaborators need to use the same [version](../../User_Interface/Menus/Help/Help_overview.md) of FLEx.

## Other LIFT-compatible programs, such as Lexique Pro

- You can [export](../../User_Interface/Menus/File/Export/Export_overview.md) and [import](../../Beginning_Tasks/Importing_Data/Import_overview.md) lexical data in the **LIFT 0.13 XML** format.

  In these cases, the **LIFT** files typically contain the data and information that is required by these programs. Read the information in the dialog boxes and associated Help topics for additional information.

- Other export and import formats include various **SFM**, **Tab-delimited** and **XML** formats.

## Additional options

- Multiple users can share data with each other or with consultants using [backup](../../User_Interface/Menus/File/Backup_and_Restore/Back_up_this_Project.md) and [restore](../../User_Interface/Menus/File/Backup_and_Restore/Restore_a_project.md), or [export](../../User_Interface/Menus/File/Export/Export_overview.md) and [import](../../Beginning_Tasks/Importing_Data/Import_overview.md).

The export and import options *not* provide a *complete* exchange of all the data and metadata that is in a language project. Also, they may not compare and merge data or metadata.

If you [import LIFT lexical data](../../Beginning_Tasks/Importing_Data/import_lift_lex.md), lexical data is merged, but there are limitations.

- [Import](../../Beginning_Tasks/Importing_Data/Import_overview.md) LinguaLinks data.

- [Import](../../Beginning_Tasks/Importing_Data/Import_overview.md) and [export](../../User_Interface/Menus/File/Export/Export_overview.md) interlinear or anthropological data.

- Copy and paste to copy a text from another Unicode program into Language Explorer.
