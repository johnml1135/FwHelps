# Updating Database

*Basic Tasks › Collaborating with Others*

A newer version of FieldWorks can upgrade a project that was created by an older version. The **Updating Database** progress indicator appears when you do the following:

- [Open a FieldWorks project](../../User_Interface/Menus/File/Open_a_language_project.md) after you install a newer version of FieldWorks.

- [Restore a project](../../User_Interface/Menus/File/Backup_and_Restore/Restore_a_project.md) that was backed up using an older version of FieldWorks.

> [!TIP]
>
> - After you upgrade a project, you will probably not be able to open it in older versions of FieldWorks.
>
> - If you open a FieldWorks project on multiple computers, use the same version of FieldWorks. When you want to upgrade to a new version of FieldWorks, choose a time when you can install it on all the computers that you and your team members use.
>
> - Before you upgrade to a new version of FieldWorks, [back up](../../User_Interface/Menus/File/Backup_and_Restore/Back_up_this_Project.md) all your projects in the old version.
