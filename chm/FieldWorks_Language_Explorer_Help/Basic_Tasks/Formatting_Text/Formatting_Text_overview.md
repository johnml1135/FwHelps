# Formatting Text overview

*Basic Tasks › Formatting Text*

*Style formatting* changes the appearance of text by applying a [style](../../User_Interface/Menus/Format/Styles/Styles_overview.md).

*Direct formatting* changes the appearance of text without the use of a style. You *cannot* apply direct formatting to text in FLEx.

Specific formatting attributes supersede more general attributes. In order from general to specific, the appearance of text depends on the following:

- Each writing system has a [default font](../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Writing_System_Properties_Fonts_tab.md)*.* It is used in the **Normal** style (as seen in the [Font](../../User_Interface/Menus/Format/Styles/Styles_Font_tab.md) tab).

<!-- -->

- You can [apply a style](../../User_Interface/Menus/Format/apply_a_style_to_text.md) in many *but not all* text fields.

- You can [remove formatting](Remove_formatting.md) to return to the default style for the writing system.

> [!TIP]
>
> - You can select the *default* font for a writing system on the [Font](../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Writing_System_Properties_Fonts_tab.md) tab of the **Writing** **System Properties** dialog box.
>
> - You can modify the character formatting attributes (for example, font, font size, and font style) of a style on the [Font](../../User_Interface/Menus/Format/Styles/Styles_Font_tab.md) tab of the **Styles** dialog box.
>
> - You can modify the paragraph formatting attributes (for example, alignment, margin indents, and spacing) of a style on the [Paragraph](../../User_Interface/Menus/Format/Styles/Styles_Paragraph_tab.md), [Bullets and Numbering](../../User_Interface/Menus/Format/Styles/Styles_Bullets_and_Numbering_tab.md), and [Border](../../User_Interface/Menus/Format/Styles/Styles_Border_tab.md) tabs of the **Styles** dialog box.
>
> - You can select styles for field content when you [configure views](../../User_Interface/Menus/Tools/Tools_overview.md).
>
> - **See Also:** [Inheriting unspecified attributes](../../User_Interface/Menus/Format/Styles/Inheriting_unspecified_attributes.md) and [Styles for exporting](../../User_Interface/Menus/File/Pathway_Configuration_Tool/Styles_for_export.md).
