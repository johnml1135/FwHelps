# Import Phonology

*Beginning Tasks › Importing Data*

Do these steps help to import the lists of [phonological features](../../User_Interface/Field_Descriptions/Grammar/Phonological_Features_fields/Phonological_Features_fields_overview.md), [phonemes](../../User_Interface/Field_Descriptions/Grammar/Phonemes_fields/Phonemes_fields_overview.md), [Natural Classes](../../User_Interface/Field_Descriptions/Grammar/Natural_Classes_fields/natural_classes_fields_overview.md) and [Phonological Rules](../../User_Interface/Field_Descriptions/Grammar/Phonologocial_Rules_fields/Phonological_Rules_fields_overview.md) that were [exported](../../User_Interface/Menus/File/Export/Export_Phonology_as_XML_file.md) as an XML file.

1.  In the **Navigation** **Pane**, click **Grammar**.

2.  On the [File](../../User_Interface/Menus/File/File_overview.md) menu, point to **Import**, and then click **Phonology**.

The **Phonology XML Files** dialog box appears.

3.  Find the XML file with the phonological data you want to import.

4.  Click the XML file.

    The path and file name appear in the box next to the **Open** button.

5.  Click **Open**.

6.  A question box appears and asks if you are sure you want to delete and replace all the phonology in the project.

- If you want to continue, click **Yes**.
