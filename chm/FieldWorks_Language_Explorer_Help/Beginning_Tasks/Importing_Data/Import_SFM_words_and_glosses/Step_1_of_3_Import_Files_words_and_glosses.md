# Step 1 of 3: Import Files - words and glosses

*Beginning Tasks › Importing Data › Import Standard Format Words and Glosses*

When you [import](Import_Standard_Format_words_and_glosses.md) Standard Format words and glosses, do the following in **Step 1 of 3: Import Files**:

1.  For the **Import files** box, click **Browse**. Select the file or files you want to import, and then click **Open**.

    The path to the file or files appears in the **Import Files** box. If you selected more than one file, the paths are separated by a comma.

    The path to an associated setting file (\*.map) appears in the **Settings** box, if there is one. Otherwise, the *default settings file* appears.

2.  If the **Settings** box shows the correct file, then continue to the next step. Otherwise, do the following:

    - Click **Browse**, select the desired settings file, and then click **Open**.

    - If you want to save a set of field mappings in a \*.map file with a *different* file name, edit the file name directly in the **Settings** box (*optional*).

    - Click the **Use default settings file** link, if you want to use the [default settings](Import_Standard_Format_wWords_and_glosses_-_Pre-defined_Mappings.md) file that was supplied with FLEx.

3.  Click **Next**.

    [Step 2 of 3: Field Mapping](Step_2_of_3_Field_Mapping_words_and_glosses.md) appears.

> [!NOTE]
>
> - The *default settings file* (\<name\>.map) was installed with FLEx at: C:\Program Files\SIL\FieldWorks 9\Language Explorer\Import
>
> - In [Step 3 of 3](Step_3_of_3_Ready_to_Import_words_and_glosses.md), the **Save Settings as** box shows the mapping file in which your settings will be saved. It is associated with the import file, and will be available for use in the future. It is the same settings file as you select here, unless you chose the default settings file.
>
> - - If you click **Cancel**, the **Save Settings** question box appears. If you click **Yes**, your settings are saved for the current import file. If you chose to use the default settings file, a new file is created.
