# Step 2 of 8: File & Setting

*Beginning Tasks › Importing Data*

1.  For the **Database File** box, if the correct file is not already selected, do the following:

    - Click the ellipsis button ![](../../assets/images/Ellipsis_button.PNG).

      The **Select the 'Database' file to use** dialog box appears.

    - Select the file, and then click **Open**.

      The file path appears in the **Database File** box.

2.  For the **Settings** box, if the correct setting file is not already selected, do the following:

    - Click the ellipsis button.

      The **Select the 'Settings' file to use** dialog box appears.

    - Select the file, and then click **Open**.

      The file path appears in the **Settings** box.

3.  For the **Save As** box, to save your import settings for future use, do the following:

    - If the correct file is not already selected, click the ellipsis button.

      The **Select the "SaveAs' file to use** dialog box appears.

    - Select the file or type a name in the **File name** box, and then click **Open**.

      The file path appears in the **Save as** box.

4.  Click the **Next** button.

    [Step 3 of 8: Language mapping](Step_3_of_8_Language_mapping.md) appears.

> [!TIP]
>
> - You can click **Save** to save any changes you have made in any of the wizard's steps.
