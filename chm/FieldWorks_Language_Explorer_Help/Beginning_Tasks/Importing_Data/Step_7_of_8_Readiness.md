# Step 7 of 8: Readiness

*Beginning Tasks › Importing Data*

1.  Click **Generate Report**.

    The **Import Preview Results** report generated for the import process as currently mapped.

2.  [Examine the errors](Examine_import_preview_results_errors.md), if any.

    When errors occur, you can continue and load the rest of the data into FieldWorks, or go back and make corrections to the import file or to your settings. We recommend that you try to correct errors before continuing. See [Step 1 of 8: Overview and Backup](step_1_of_8_overview_and_backup.md) for additional comments about importing data.

3.  Return to the applicable step in the wizard and alter your settings, or alter your import file to correct the problem.

4.  When your errors are corrected, click **Next**.

    [Step 8 of 8: Ready to Import](Step_8_of_8_Ready_to_Import.md) appears.

> [!TIP]
>
> - You can click **Save** to save any changes you have made in any of the wizard's steps.
>
> - The import preview report is put here:
>
> C:/Users/\<your name\>/AppData/Local/Temp/Language%20Explorer/ImportPreviewReport.htm
>
> - For more information about importing, point to **Resources** on the [Help](../../User_Interface/Menus/Help/Help_overview.md) menu, and then click **Technical Notes on SFM Database Import**.
