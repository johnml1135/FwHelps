# Prepare LinguaLinks data

*Beginning Tasks › Importing Data*

You need to export the LinguaLinks data into an `.xml` file that you can then [import](import_lingualinks_data.md) into FieldWorks. First, you need to install one or more `XML Dump` patch(es) in LinguaLinks.

- Follow the steps in **Section 2.1 LinguaLinks export** in the *Technical Notes on LinguaLinks Database Import* document.

  To access this document, on the [Help](../../User_Interface/Menus/Help/Help_overview.md) menu point to **Resources**, and then click **Technical Notes on LinguaLinks Import**.
