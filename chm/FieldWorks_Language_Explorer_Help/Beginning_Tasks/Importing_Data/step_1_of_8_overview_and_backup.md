# Step 1 of 8: Overview and Backup

*Beginning Tasks › Importing Data*

In this step, you are given the opportunity to [back up](../../User_Interface/Menus/File/Backup_and_Restore/Backup_and_Restore_overview.md) the project before importing Lexical data. It is highly recommended because a backup copy and a saved settings file (**Step 2 of 8**) allows for an '*iterative approach*' to the import task. That is, if the result of the import is not satisfactory, you can [restore the project](../../User_Interface/Menus/File/Backup_and_Restore/Restore_a_project.md) from the backup copy. Then you can do the import process again, making changes to the mappings or languages in the various steps of this wizard, or to the data you will import (discussed in [Step 7 of 8](Step_7_of_8_Readiness.md)).

Consider this iterative approach *before* you spend a significant amount of time changing the *imported* data in FieldWorks. You will lose your changes if you choose to restore the project and import the data again.

Do the following:

1.  If the **Import Standard Format lexical data wizard** is not already displayed, on the **File** menu, point to **Import** and then click **Standard Format Lexicon**.

    The **Import Standard Format lexical data wizard** appears at **Step 1 of 8: Overview and Backup**.

2.  Click **Backup**.

    The [Back up this project](../../User_Interface/Menus/File/Backup_and_Restore/Back_up_this_Project.md) dialog box appears.

3.  When the selections, comments and **Save in** file are correct, click **OK**.

4.  When the backup operation is done, click **Next**.

    [Step 2 of 8: File & Settings](Step_2_of_8_File_and_Setting.md) appears.

> [!TIP]
>
> - **See Also:** [Language Explorer](../../Overview/Welcome_to_FieldWorks.md) or [Unable to Open Project](../../User_Interface/Menus/File/Unable_to_Open_Project.md) dialog boxes.
>
> - You can click **Save** to save any changes you have made in any of the wizard's steps.
>
> - For more information about importing, point to **Resources** on the [Help](../../User_Interface/Menus/Help/Help_overview.md) menu, and then click **Technical Notes on SFM Database Import**.
