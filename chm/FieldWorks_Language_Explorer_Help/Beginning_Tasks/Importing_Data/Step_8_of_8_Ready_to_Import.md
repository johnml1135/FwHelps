# Step 8 of 8: Ready to Import

*Beginning Tasks › Importing Data*

1.  If you *not* want to display an import report, *clear* the **Display the import report** check box. (This check box is selected by default.)

2.  Click **Finish**.

    An import progress indicator appears and then closes after the import process is completed. Then, if the **Display the import report** check box is selected, the **Import Log for** **\<file name\>** appears in a separate window. It lists statistics and any problems with the import. This report may include warning or errors *not included* in the report generated in [Step 7 of 8](Step_7_of_8_Readiness.md) as that report did not reflect results from the actual import process.

    If you see an **Import Log for** window, [examine](Examine_import_preview_results_errors.md) the **Warning(s)**, if any, as they can indicate a problem that may affect the imported data.

    If your data is not satisfactory, you can [restore](../../User_Interface/Menus/File/Backup_and_Restore/Restore_a_project.md) the project to the pre-import content. Then you can make changes to the source data or to the import wizard settings, and then try the import process [again](step_1_of_8_overview_and_backup.md).

> [!TIP]
>
> - You can click **Save** to save any changes you have made in any of the wizard's steps.
