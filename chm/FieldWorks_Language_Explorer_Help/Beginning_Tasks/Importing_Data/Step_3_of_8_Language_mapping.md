# Step 3 of 8: Language mapping

*Beginning Tasks › Importing Data*

1.  In the **Language mapping** area, do any of the following:

    - To *change* the name (descriptor), writing system, or encoding converter of a language, click that language row and then click **Modify**.

      The **Modify language mapping** dialog box appears.

    - To *add* a language for use with the data you will import, click **Add**.

      The **Add language mapping** dialog box appears.

    <!-- -->

    - In the current version, you *cannot* delete an unwanted language mapping.

      In this case, you can set its writing system to **ignore** using the **Modify** button.

2.  In the dialog box that appears, do one or more of the following:

    - Enter or edit the language descriptor.

    - In the **Writing System** box, select a writing system or select **ignore** in the list.

      If a writing system is *not* in the list, click **Add** and then point to **Vernacular Writing System** or **Analysis Writing System** to display a longer list. Select a writing system from that list or select **New** to [add a new writing system](../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/Add_a_new_writing_system.md).

    - In the **Encoding Converters** box, select an [encoding convert](About_encoding_converters.md) from the list.

      If an encoding converter is *not* in the list, click **Add** to open the [Encoding Converter, Properties tab](../../Advanced_Tasks/Writing_Systems/Encoding_Converters/Encoding_Converters_Properties_tab.md), which allows you to add an encoding converter.

    - Click **OK**.

      If the **OK** button is *not* available, you need to add content to an empty box or change any contents that could result in a duplicate language mapping, which FieldWorks will *not* allow.

3.  Click **Next**.

    [Step 4 of 8: Content mapping](Step_4_of_8_Content_mapping.md) appears.

> [!TIP]
>
> - You can click **Save** to save any changes you have made in any of the wizard's steps.
