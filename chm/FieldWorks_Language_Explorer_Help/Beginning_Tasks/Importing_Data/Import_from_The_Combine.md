# Import from The Combine

*Beginning Tasks › Importing Data*

You can export a Combine LIFT file (\*.zip) from *The Combine* (<a href="https://thecombine.app/login" target="_blank" title="https://thecombine.app/login">https://thecombine.app/</a>) and import lexical data from that file into FieldWorks (FLEx).

> [!IMPORTANT]
>
> These scenarios can help you understand your situation:
>
> - *FLEx* was the original source of the data.\
>   Those data were [exported](../../User_Interface/Menus/File/Export/Export_full_lexicon_(LIFT).md) from FLEx, and word and senses were added in *The Combine*.
>
> - *The Combine* was the original source of the lexical data.\
>   You can import that data into an existing project to add more entries or senses. Or, you can import into an empty FLEx project.\
>   In either case, the writing systems need to match.
>
> 1.  Do one of these steps:
>
>     - If you do not have an existing FLEx project, [create](../../User_Interface/Menus/File/Create_a_new_Fieldworks_project.md) it.
>
> <!-- -->
>
> 1.  - If you have an existing FLEx project [open](../../User_Interface/Menus/File/Open_a_language_project.md) it and then [back it up](../../User_Interface/Menus/File/Backup_and_Restore/Back_up_this_Project.md) (recommended).
>
> <!-- -->
>
> 2.  On the [File](../../User_Interface/Menus/File/File_overview.md) menu, point to **Import**, and then click **Lexicon from The Combine**.
>
>     The **Import/Merge From Combine** dialog box appears.
>
> 3.  Click **Browse**.
>
> 4.  Click the ZIP file and then click **Open**.
>
>     The path and file name appear in the box next to the **Browse** button.
>
> 5.  Click **OK**.
>
> When the import is finished, an import log appears in your default browser.
