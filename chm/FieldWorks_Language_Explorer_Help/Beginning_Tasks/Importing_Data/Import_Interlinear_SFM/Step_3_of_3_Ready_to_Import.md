# Step 3 of 3: Ready to Import

*Beginning Tasks › Importing Data › Import Standard Format interlinear texts*

1.  The field mappings you did in **Step 2 of 3** will be saved in a setting file (\<name\>.map) file. The **Saved Settings** **as** box shows the path to that file.

    *If* you want to change the file, do one of the following:

    - Click **Browse**, select a different file, and then click **Open**.

    - Edit the path or file name directly in the **Save Settings as** box.

2.  If you are think the mappings you set are correct, click **Finish**.

    - Otherwise, click **Back** to return to [Step 2 of 3](Step_2_of_3_Field_Mapping.md) so you can make changes.

3.  Review the results of the import.

    - If necessary, do the following:

      - [Restore the project](../../../User_Interface/Menus/File/Backup_and_Restore/Restore_a_project.md).

      - [Import](Step_1_of_3_Import_Files.md) the file or files again, but with different field mappings, writing systems, or encoding converter, as necessary.

> [!TIP]
>
> - If you click **Cancel**, the **Save Settings** question box appears.
>
>   - If you click **Yes**, your settings are saved for the current import file. Then you will not need to specify them all again for that file.
>
>   - If you click **No**, your setting are not saved.
