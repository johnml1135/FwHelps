# Step 4 of 7: Content mapping

*Beginning Tasks › Importing Data › Import Notebook Data*

In this step, you make sure the destination of each marker is correct. You can click the **View File** button to see data the uses the selected marker. You can also click **Save** at any time to save the destination settings.

1.  In the **Content mapping** area, for each marker for which you need to change or add a mapping, click the row for that marker, and then click **Modify**.

    The **Import Content Mapping Settings** dialog box appears.

2.  In the dialog box, [map the data](Import_Content_Mapping_Settings.md) for the current field.

3.  Repeat the steps above for each marker.

4.  When each destination for each marker is set, click **Next**.

    [Step 5 of 7: Key markers](Step_5_of_7_Key_markers.md) appears.
