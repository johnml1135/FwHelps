# Import Standard Format anthropology data

*Beginning Tasks › Importing Data › Import Notebook Data*

When **Notebook** is selected in the Navigation Pane, you can import standard format anthropology data.

1.  Open the language project into which you will import the data.

2.  Click **Notebook** in the [Navigation Pane](../../../User_Interface/Toolbars/Navigation/Navigation_Pane_overview.md).

3.  [Stop the parser](../../../User_Interface/Menus/Parser/Start_or_Stop_Parser.md), if it is running.

4.  If necessary, [insert a custom list](../../../Using_Tools/Lists_tools/Insert_a_custom_list.md) and a corresponding [custom field](../../../User_Interface/Menus/Tools/Custom_Fields/Custom_Fields_overview.md) for each set of data that does not already have a field in the `Notebook` area.\
    (For example, *Weather* data.)

5.  On the **File** menu, point to **Import**, and then click **Standard Format Notebook data**.

6.  Follow the instructions in the import wizard that appears, starting with [Step 1 of 7: Overview and Backup](Step_1_of_7_Overview_and_Backup.md).
