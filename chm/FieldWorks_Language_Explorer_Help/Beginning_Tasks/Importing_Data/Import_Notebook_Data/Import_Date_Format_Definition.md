# Import Date Format Definition dialog box

*Beginning Tasks › Importing Data › Import Notebook Data*

FieldWorks imports the dates in a Standard Format file according to one or more formats that you define. Here are some examples of date formats:

|              |               |
|--------------|---------------|
| Date Format  | Example       |
| yyyy-MM-dd   | 2022-03-02    |
| dd/MMM/yyyy  | 02/Mar/2022   |
| dd/MMM/yy    | 02/Mar/22     |
| M-d-yy       | 3-2-22        |
| MMMM d, yyyy | March 2, 2022 |

1.  In the **Date format** box, do the following:

    - Type punctuation and spaces exactly as they occur in the imported data.

    - To represent the year, month, and day, type three of the following elements: `yyyy`, `yy`, `MMMM`, `MMM`, `MM`, `M`, `dd`, and `d`.

2.  To see an example of the format, click **Apply**.

3.  Click **OK**.
