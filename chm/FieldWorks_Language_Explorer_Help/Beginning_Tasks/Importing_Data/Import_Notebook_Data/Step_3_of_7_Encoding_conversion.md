# Step 3 of 7: Encoding Conversion

*Beginning Tasks › Importing Data › Import Notebook Data*

In the **Encoding Conversion** area, you need to choose an encoding converter for each writing system that uses a legacy font (not Unicode).

1.  To *choose* or *change* the encoding converter for a writing system, *or* to specify that the writing system is already in Unicode, click the writing system, and then click **Modify**.\
    Then, do *one* of the following in the **Choose Encoding Converter for Import** dialog box:

    - Select an encoding converter, and then click **OK**.

    - Click **Add** to open the **Encoding Converters** dialog box so you can [add an encoding converter](../../../Advanced_Tasks/Writing_Systems/Encoding_Converters/Add_Encoding_Converter.md).

    - If the writing system is already in Unicode, select **\<Already in Unicode\>**, and then click **OK**.

2.  To *add* a writing system to use with data you will import, click **Add**, point to **Vernacular Writing System** *or* **Analysis Writing System**, and then click a writing system or **Define New**.

    - If you clicked *Define New*, [add a new writing system](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/Add_a_new_writing_system.md).

3.  When all the writing systems show **Already in Unicode** or an appropriate encoding converter, click **Next**.

    [Step 4 of 7: Content mapping](Step_4_of_7_Content_mapping.md) appears.
