# Step 5 of 7: Key markers

*Beginning Tasks › Importing Data › Import Notebook Data*

In this step, you specify which unique standard format markers can *begin* a record.

- In the **Record Marker** box, select the marker that is at the top of each record in your import data, and then click **Next**.

[Step 6 of 7: Character Mapping](Step_6_of_7_Character_mapping.md) appears.
