# List Import Options dialog box

*Beginning Tasks › Importing Data › Import Notebook Data*

If needed, FieldWorks can substitute imported text items in a Standard Format file with items that match in a list.

1.  In the **Text to match** box, type an imported text item.

2.  In the **Text to substitute** box, type the *name* or *abbreviation* of the corresponding topics list item.

3.  Click **OK**.

> [!IMPORTANT]
>
> - Whether you substitute the *name* or *abbreviation* depends on whether you click **Match list items against names** or **Match list items against abbreviations** in the [Import Content Mapping Settings](Import_Content_Mapping_Settings.md) dialog box
