# Step 7 of 7: Add or replace

*Beginning Tasks › Importing Data › Import Notebook Data*

1.  Do one of the following:

    - To delete all of the data in the **Notebook** area and replace it with the data that is in the imported file, click **Overwrite**.

    - To add the data that is in the imported file to the data that is already in the Notebook area, click **Add**.

2.  Select **Display the import report** if you want to see report that shows the results of the import.

3.  Click **Finish**.
