# Step 2 of 7: File & Setting

*Beginning Tasks › Importing Data › Import Notebook Data*

1.  In the **Database File** box, if the database file (\*.db) is not already selected, do the following:

    - Click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG).

      The **Select the Shoebox Anthropology Database file to import** dialog box appears.

    - Select the file, and then click **Open**.

      The file path appears in the **Database File** box.

2.  In the **Project File** box, if the project file (`*.prj`) is not already selected, and you do *not* have a project file to use, leave this box empty. If you do have a project file to use, do the following steps:

    - Click the ellipsis button.

      The **Select the Shoebox Project file to use** dialog box appears.

    - Select the file, and then click **Open**.

      The file path appears in the **Project File** box.

3.  In the **Settings** box, if the correct setting file (\*.map) is not already selected, do the following:

    - Click the ellipsis button.

      The **Select the Import Settings file to load** dialog box appears.

    - Select the file, and then click **Open**.

      The file path appears in the **Settings** box.

4.  In the **Save As** box, to save your import settings for future use in an import mapping file (\*.map), do the following:

    - If the correct file is not already selected, click the ellipsis button.

      The **Select the Import Settings file to save** dialog box appears.

    - Select the file or type a name in the **File name** box, and then click **Open**.

      The file path appears in the **Save as** box.

5.  Click the **Next** button.

    [Step 3 of 7: Encoding Conversion](Step_3_of_7_Encoding_conversion.md) appears.

> [!NOTE]
>
> - A **Save** button appears in each step of this import wizard when the **Save as** box has a file. Click **Save** at any time to save your settings.
