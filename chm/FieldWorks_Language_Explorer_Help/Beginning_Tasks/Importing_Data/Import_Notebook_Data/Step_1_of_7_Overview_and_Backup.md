# Step 1 of 7: Overview and Backup

*Beginning Tasks › Importing Data › Import Notebook Data*

In this step, you can [back up](../../../User_Interface/Menus/File/Backup_and_Restore/Backup_and_Restore_overview.md) the project before importing **Notebook** data. It is highly recommended because a backup copy and a saved settings file (**Step 2 of 7**) allows for an *iterative approach* to the import task. That is, if the result of the import is not satisfactory, you can [restore the project](../../../User_Interface/Menus/File/Backup_and_Restore/Restore_a_project.md) from the backup copy. Then you can do the import process again, making changes to the mappings or languages in the various steps of this wizard, or to the data you will import.

Consider this iterative approach *before* you spend a significant amount of time changing the *imported* data in FieldWorks because. You will lose your changes if you choose to restore the project and import the data again.

Do the following:

1.  If the **Import Standard Format anthropology data** wizard is not already displayed, do the steps in [Import Standard Format anthropology data](Import_SF_anthro_data.md).

2.  The wizard appears at **Step 1 of 7: Overview and Backup**.

3.  Click **Backup**.

    The [Back up this Project](../../../User_Interface/Menus/File/Backup_and_Restore/Back_up_this_Project.md) dialog box appears.

4.  When the selections, comments and **Save in** file are correct, click **OK**.

5.  When the backup operation is done, click **Next**.

    [Step 2 of 7: File & Settings](Step_2_of_7_File_&_Setting.md) appears.
