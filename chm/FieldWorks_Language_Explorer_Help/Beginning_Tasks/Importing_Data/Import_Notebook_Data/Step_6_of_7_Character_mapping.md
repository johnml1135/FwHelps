# Step 6 of 7: Character Mapping

*Beginning Tasks › Importing Data › Import Notebook Data*

A pair of beginning and ending in-line *markers* identify a text element within a field in a Standard Format file. You can map inline markers to a writing system, character style, or direct formatting. Here are some examples:

\desc A description in English that contains **\|fv{Lela-Teli words}**.

|        |      |                                  |     |
|--------|------|----------------------------------|-----|
| Begins | Ends | FieldWorks Destination           |     |
| \|fv{  | }    | Writing system: Lela-Teli        |     |
| \em    | \\em | Character style: Emphasized Text |     |
| \|b    | \|r  | Bold                             |     |

1.  If you need to change the mappings, do any of the following:

    - Click **Add**.

      The [Import Character Mapping](Import_Character_Mapping.md) dialog box appears.

    - Select a mapping in the list, and then click **Modify**.

      The [Import Character Mapping](Import_Character_Mapping.md) dialog box appears.

    - Select a mapping in the list, and then click **Delete**.

2.  Click **Next**.

    [Step 7 of 7: Add or Replace Notebook Records](Step_7_of_7_Add_or_replace.md) appears.
