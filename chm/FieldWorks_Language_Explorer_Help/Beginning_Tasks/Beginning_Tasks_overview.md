# Beginning Tasks overview

*Beginning Tasks*

Tasks that typical new users of this program need to do include the following:

- [Create a new FieldWorks project](../User_Interface/Menus/File/Create_a_new_Fieldworks_project.md)

- [Open a FieldWorks project](../User_Interface/Menus/File/Open_a_language_project.md)

- [Import data](Importing_Data/Import_overview.md)

- [Enter data](Entering_Data/Entering_Data_overview.md)

- [Back up](../User_Interface/Menus/File/Backup_and_Restore/Backup_and_Restore_overview.md) the FieldWorks project regularly to protect the data.

  If necessary, you can [restore](../User_Interface/Menus/File/Backup_and_Restore/Restore_a_project.md) the data from a [backup file](../User_Interface/Menus/File/Backup_and_Restore/Backup_files.md).

- Use the [Navigation Pane](../User_Interface/Toolbars/Navigation/Navigation_Pane_overview.md) to find the desired *area* (**Lexicon**, **Grammar** and so on) and *tool* **(Lexicon Edit**, **Category Edit** and so on).
