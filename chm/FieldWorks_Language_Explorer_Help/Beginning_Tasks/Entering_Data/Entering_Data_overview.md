# Entering Data overview

*Beginning Tasks › Entering Data*

Language data in Language Explorer includes lexical entries and their corresponding reversal index entries in the **Lexicon** area, and a text corpus in the **Texts & Words** area. The **Notebook** area has language and cultural field notes, and can also include vernacular texts.

Create lexical entries in the following ways:

- [Create lexical entries](../../Using_Tools/Lexicon_tools/Lexicon_Edit/Create_a_lexical_entry.md) directly in the Lexicon.

- Use [Collect Words](../../Using_Tools/Lexicon_tools/Collect_Words/Collect_Words_overview.md).

- Create a lexical entry as you [analyze](../../Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Analyze_Text_overview.md) a word in a text.

Create texts in the following ways:

- Insert a text and type a content directly into Language Explorer.

- Copy a text into Language Explorer from another source.

- Include texts from other FieldWorks programs.

> [!NOTE]
>
> - You can also [import](../Importing_Data/Import_overview.md) data, or [get lexical data](../../User_Interface/Menus/Send_Receive/Get_a_lexicon.md) or [get a project](../../User_Interface/Menus/Send_Receive/Get_a_project.md).
