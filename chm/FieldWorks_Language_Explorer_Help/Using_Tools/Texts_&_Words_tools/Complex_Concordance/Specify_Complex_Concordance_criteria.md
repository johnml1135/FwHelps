# Specify Complex Concordance criteria

*Using Tools › Texts & Words tools › Complex Concordance*

1.  [Filter](../../../Basic_Tasks/Filtering_data/filter_Texts_Words.md) texts or [choose](../../../Basic_Tasks/Filtering_data/Choose_Texts.md) texts so you search only particular texts (*optional*).

<!-- -->

2.  In the Navigation pane, click **Texts & Words**, and then click **Complex Concordance**.

<!-- -->

3.  Click one of the **Insert options** to:

- [Morph](Set_Morph_Criteria.md)

- [Word](Set_Word_Criteria.md)

- [Tag](Select_Tag.md)

- **Word Boundary (#)**

A *\#* is added to the criteria.

The criteria you specified appear within tall square brackets **\[ \]** ([examples](Complex_Concordance_examples.md)).**\
OR** (Boolean logical disjunction) is added as an **Insert option** after the first criteria element is inserted.

4.  Repeat step 3 as needed to insert the desired criteria.

    - You can click the location where you want to insert the subsequent criteria (the *insertion point*).

    - You can right click criteria in the brackets, and select any of the following:

      **Occurs exactly once**

      **Occurs zero or more times**

      **Occurs one or more times**

      **Set occurrence (min. and max.**) to use the [Set Occurrence](Set_Occurrence_(Complex_Concordance).md) dialog box

      **Set criteria** to reopen the dialog box used previously to set that criteria.

5.  Click **Search** to update the results in the **Concordance Results** pane.

6.  In the **Concordance Results** pane, do the following:

<!-- -->

1.  - [Configure columns](../../../Basic_Tasks/Configure_Columns/Configure_Columns_overview.md), [sort](../../../Basic_Tasks/Sorting_data/Sorting_data_overview.md) and [filter](../../../Basic_Tasks/Filtering_data/filtering_data_overview.md) the results to further refine them (*optional*).

For example, you could filter the results based on the **Genre** column.

1.  - Click a row to display that result in the tabs (**Info**, **Baseline**, **Gloss**, and so on) in the right pane.
