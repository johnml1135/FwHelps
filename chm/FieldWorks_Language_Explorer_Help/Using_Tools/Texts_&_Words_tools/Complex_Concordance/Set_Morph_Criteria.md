# Set Morph Criteria

*Using Tools › Texts & Words tools › Complex Concordance*

In the **Set Morph Criteria** dialog box, you can use *any or none* of the controls. For example, you may want to only enter a gloss or only choose a grammatical category to find particular morphemes ([more](Complex_Concordance_examples.md)).

Do any of the following:

1.  **Form** (of morpheme): Choose a writing system, and then type the morpheme (without any [tokens](../../Lists_tools/About_Morpheme_Types.md) **-**, **\***, **=**, and so on) you want to find.

2.  **Gloss**: Choose a writing system, and then type the gloss of the morpheme you want to find.

3.  **Lexical Entry**: Choose a writing system, and then type the form (lexeme or citation) you want to find.

4.  **Category**: Click the down arrow and choose a grammatical category.

    - Optionally, select (![](../../../assets/images/CheckedBox.PNG)) *Not* to specify you want the results to not include morphemes with this grammatical category.

5.  **Inflection Features**: For *each* feature that you want to be criteria, do the following:

    - Select (![](../../../assets/images/CheckedBox.PNG)) the check box in the **Not** column, and then choose a value in the **Value** column.

This specifies that the results do *not* include occurrences that have this value.

1.  - Clear (![](../../../assets/images/UncheckedBox.PNG)) the Not check box, and then choose a value in the **Value** column.

This specifies that the results include occurrences that have this value

6.  Click **OK**.

7.  Review the criteria that appears in the **Specify Concordance Criteria** pane.

    - If necessary, right-click that criteria, and then click **Set criteria** to open the dialog box again.

8.  Continue to [specify complex concordance criteria](Specify_Complex_Concordance_criteria.md).
