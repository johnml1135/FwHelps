# Select Tag

*Using Tools › Texts & Words tools › Complex Concordance*

When you [specify](Specify_Complex_Concordance_criteria.md) criteria in **Complex Concordance**, you can click one of the **Insert options** called **Tag**. This opens the **Select Tag** dialog box.

1.  Do any of the following in the **Select Tag** dialog box:

    - Select the particular tag you want to set as criteria.

    - Select **\<Any\>** to remove the tag as criteria.

2.  Click **OK**.

3.  Review the tag criteria that appears in the **Specify Concordance Criteria** pane.

    - If necessary, right-click that criteria, and then click **Set criteria** to open this dialog box again.

4.  Continue to [specify complex concordance criteria](Specify_Complex_Concordance_criteria.md).
