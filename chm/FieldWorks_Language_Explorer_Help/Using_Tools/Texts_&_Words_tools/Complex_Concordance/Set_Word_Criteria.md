# Set Word Criteria

*Using Tools › Texts & Words tools › Complex Concordance*

In this dialog box, you can use *one or more* of the controls. For example, you may want to only enter a gloss, or only choose a grammatical category ([more](Complex_Concordance_examples.md)).

Do any of the following in the **Set Word Criteria** dialog box:

1.  **Form** (of word): Choose a writing system, and then type the word you want to find.

2.  **Gloss**: Choose a writing system, and then type the gloss of the word you want to find.

3.  **Category**: Click the down arrow and choose a grammatical category.

    - Optionally, select (![](../../../assets/images/CheckedBox.PNG)) *Not* to specify you want the results to not include words with this grammatical category.

4.  **Inflection Features**: For *each* feature that you want to be criteria, do the following:

    - Select (![](../../../assets/images/CheckedBox.PNG)) the check box in the **Not** column, and then choose a value in the **Value** column.

This specifies that the results do *not* include occurrences that have this value.

1.  - Clear (![](../../../assets/images/UncheckedBox.PNG)) the Not check box, and then choose a value in the **Value** column.

This specifies that the results include occurrences that have this value

5.  Click **OK**.

6.  Review the criteria that appears in the **Specify Concordance Criteria** pane.

    - If necessary, right-click that criteria, and then click **Set criteria** to open the dialog box again.

7.  Continue to [specify complex concordance criteria](Specify_Complex_Concordance_criteria.md).
