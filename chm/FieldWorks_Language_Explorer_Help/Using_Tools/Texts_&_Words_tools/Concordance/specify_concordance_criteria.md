# Specify concordance criteria

*Using Tools › Texts & Words tools › Concordance*

In contrast to *manually* specifying concordance criteria in the **Specify Concordance Criteria** pane, [Show data overview](../../../Basic_Tasks/Show_data/Show_data_overview.md) lists topics that automatically specify *more-specific* criteria. In fact, using **Show** commands is the *only* way to specify concordance criteria that yield results that are *specific to a particular item* (lexical entry, morpheme, sense, allomorph, and so on).

When you use a **Show** command, the window automatically changes to show the concorded results in the **Concordance Results** pane.

You can then do any of the following:

- The **Specify Concordance Criteria** pane appears empty, but if you need to change the criteria, click the **Specify concordance criteria** link to restore the pane. Make your changes, and then click **Search**.

<!-- -->

- [Configure columns](../../../Basic_Tasks/Configure_Columns/Configure_Columns_overview.md), [sort](../../../Basic_Tasks/Sorting_data/Sorting_data_overview.md) and [filter](../../../Basic_Tasks/Filtering_data/filtering_data_overview.md) the results to further refine the **Concordance Results** pane. For example, you could filter the results based on the **Genre** column.

- Click each result (an *occurrence*) to display it in a **Full Context** pane [tab](../Interlinear_Texts/texts_edit_overview.md).

> [!TIP]
>
> - If you [manually](Manually_specify_concordance_criteria.md) type or paste the characters in the **For the text** box, then the search is based on that simple character string and is *not specific to any particular item*. In this case, the concordance results can include *other* occurrences, such as homographs.
>
> - When you initiate the search from outside the **Concordance** area, the default selections are **Match diacritics** and **Whole item**. You can change the selections, and then click **Search** for different results.
