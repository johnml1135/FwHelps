# Concordance overview

*Using Tools › Texts & Words tools › Concordance*

**Concordance** tool is in the [Navigation Pane](../../../User_Interface/Toolbars/Navigation/Navigation_Pane_graphic.md) when [Texts & Words](../Texts_and_Words_overview.md) is selected. It allows you to see occurrences of [text](../Interlinear_Texts/texts_edit_overview.md) content (words, morphemes, glosses, characters, diacritics, and so on) from particular [word focus box](../Interlinear_Texts/Word_Focus_Box_examples.md) rows, or from **Free Translation**, **Literal Translation** or **Note** lines.

Generally speaking, you first use the **Specify Concordance Criteria** pane, select an occurrence in the **Concordance Results** pane, and then select a [tab](../Interlinear_Texts/texts_edit_overview.md).

This `Help` book contains the following topics:

- [Manually specify concordance criteria](Manually_specify_concordance_criteria.md)

- [Specify concordance criteria](specify_concordance_criteria.md)

> [!IMPORTANT]
>
> - If you *manually* enter characters in the **For the text** box as concordance criteria, the search is based on that string of characters, *not* on a particular item such as a lexical entry with a particular homograph number.
>
> - To specify that you want to search for a particular item, such as a particular lexical entry, morpheme, sense, then you need to use a **Show \<item\> in Concordance** feature to [specify concordance criteria](specify_concordance_criteria.md). Then, the **Concordance Results** are limited to [show](../../../Basic_Tasks/Show_data/Show_data_overview.md) more specific results.\
>   For example, if you have homographs in your lexicon, you could search for one of them. When you use this feature, the normal boxes and buttons are removed from the **Specify Concordance Criteria**. A **Specify concordance criteria** link appears instead. If you click this link, the normal boxes and buttons appear again in the pane and the link changes to read **Back to concorded item**.

###  Tips

- You can search for occurrences of words (**Word** line) using [Word List Concordance](../Word_List_Concordance/Word_List_Concordance_overview.md) features.

- You can search with [regular expressions](../../../Basic_Tasks/Filtering_data/About_Regular_Expressions.md).

- **Complex Concordance** allows you to [specify](../Complex_Concordance/Complex_Concordance_overview.md) more [complex](../Complex_Concordance/Complex_Concordance_overview.md) searches.
