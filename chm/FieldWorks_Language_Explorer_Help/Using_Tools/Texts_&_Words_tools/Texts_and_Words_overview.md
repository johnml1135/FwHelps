# Texts & Words overview

*Using Tools › Texts & Words tools*

The **Texts & Words** area is where you work with your text corpus and the words in texts.

As a high-level overview, you can do the following:

|  |  |  |
|----|----|----|
| With *texts*, you can | With the *wordforms (words)* in texts, you can |  |
| [insert texts](Interlinear_Texts/Insert_new_Text.md) | [parse words](../../User_Interface/Menus/Parser/Parsing_words_overview.md) or [gloss words](Interlinear_Texts/specify_the_word_gloss.md) |  |
| [enter text metadata](Interlinear_Texts/Enter_text_metadata.md) | [tag](Interlinear_Texts/Tagging_a_text.md) or [chart](Interlinear_Texts/Text_Chart_tab/Text_chart_overview.md) |  |
| [sort](../../Basic_Tasks/Sorting_data/Sort_Texts_Words.md), [choose](../../Basic_Tasks/Filtering_data/Choose_Texts.md), and [filter](../../Basic_Tasks/Filtering_data/filter_Texts_Words.md) | more (see below) |  |
| [see statistics](Statistics_overview.md) |  |  |

Here are Help topics that help you learn the various things you can do with the words in texts and the various ways to accomplish them:

- [Interlinear Texts overview](Interlinear_Texts/texts_edit_overview.md) lists all the tabs.

  - [Parsing words overview](../../User_Interface/Menus/Parser/Parsing_words_overview.md) gives an *important* overview for using the **Analyze** tab.

  - [Analyze text overview](Interlinear_Texts/Analyze_Text_overview.md) lists tasks that you typically do *manually* in the **Analyze** tab.

<!-- -->

- [Interlinear views colors](Interlinear_Texts/interlinear_views_colors.md) helps you understand the colors you see.

<!-- -->

- [Specify a word gloss](Interlinear_Texts/specify_the_word_gloss.md) gives steps to manually only add word glosses.

- [Concordance overview](Concordance/Concordance_overview.md) and [Complex Concordance](Complex_Concordance/Complex_Concordance_overview.md) help you with basic or more complex searching of texts.

- [Word List Concordance](Word_List_Concordance/Word_List_Concordance_overview.md):

  **Interlinear Texts**, **Concordance** and **Word List Concordance** each display the same set of tabs ([Info](Interlinear_Texts/Enter_text_metadata.md), [Baseline](Interlinear_Texts/Insert_new_Text.md), [Gloss](Interlinear_Texts/specify_the_word_gloss.md), [Analyze](Interlinear_Texts/Analyze_Text_overview.md), [Tagging](Interlinear_Texts/Tagging_a_text.md) and [Text Chart](Interlinear_Texts/Text_Chart_tab/Text_chart_overview.md)). You can do the same work in each tool, but they provide different ways to find or [concord](Concordance/Concordance_overview.md) on words, forms, morphemes, analyses and so on.

- [Word Analyses](Word_Analyses/Word_Analyses_overview.md) allows you to approve and assign analyses, [change spelling](Word_Analyses/Change_Spelling/change_spelling_overview.md) and to [specify the spelling status](Word_Analyses/Specify_spelling_status.md) of vernacular words.

- [Bulk Edit Wordforms](Bulk_Edit_Wordforms/Bulk_Edit_Wordforms_overview.md) allows you to change multiple words (or metadata) at the same time, including spelling status.

- [Statistics overview](Statistics_overview.md)
