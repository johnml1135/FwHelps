# Bulk Edit Wordforms overview

*Using Tools › Texts & Words tools › Bulk Edit Wordforms*

**Bulk Edit Wordforms** is in the [Navigation Pane](../../../User_Interface/Toolbars/Navigation/Navigation_Pane_graphic.md) when **Texts & Words** is selected. **Texts & Words** contains the [word list](../Word_list_overview.md). You can [sort](../../../Basic_Tasks/Sorting_data/Sort_Texts_Words.md) and [filter words](../../../Basic_Tasks/Filtering_data/filter_Texts_Words.md), and change multiple words at the same time.

Some of the tasks you can do are listed below (*not* exhaustive):

|  |  |
|----|----|
| Tab | Task |
| **List Choice** | [Bulk change Spelling Status](bulk_change_spelling_status.md) |
| **Bulk Copy** | [Bulk copy forms](Bulk_copy_forms.md) |
| **Click Copy** | [Click copy forms](Click_copy_forms.md) |
| **Process** | [Bulk process forms](Bulk_process_forms.md) |
| **Bulk Replace** | [Bulk replace forms](Bulk_replace_forms.md) |
| **Delete** | [Bulk delete forms or wordforms](Bulk_delete_form_wordform.md) |

> [!IMPORTANT]
>
> - For words with a **Number in Corpus** greater than **0** (zero), some bulk edit operations are programmatically *prohibited*, but other operations are allowed. For example, you cannot change the **Form** column for words used in a text, but you may be able to use [Change Spelling](../Word_Analyses/Change_Spelling/change_spelling_overview.md) to accomplish the desired result.
>
> - In some columns, you can type words. See: [Baseline text writing systems](../Interlinear_Texts/baseline_text_writing_systems.md).
>
> - Typically, you will change many words at the same time. So use **Bulk Edit Wordforms** carefully.
>
> - - It is recommended that you [back up](../../../User_Interface/Menus/File/Backup_and_Restore/Back_up_this_Project.md) the language project before you use this tool.
>
>   - Changes *may* negatively affect [interlinearized](../Interlinear_Texts/Analyze_Text_overview.md) or [charted](../Interlinear_Texts/Text_Chart_tab/Text_chart_overview.md) texts. Change only as many words at the same time as you can while remaining reasonably sure that each change is appropriate.
>
>   - The **Configure Columns** dialog box uses the ![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Bulk_Edit_Wordforms/Bulk_Edit_Symbol.GIF) symbol to indicate the fields that *may* be available for bulk editing, depending on the operation you want to do.
