# Bulk replace forms

*Using Tools › Texts & Words tools › Bulk Edit Wordforms*

In [Bulk Edit Wordforms](Bulk_Edit_Wordforms_overview.md), the **Bulk** **Replace** tab allows you to use a *find and replace* feature to change multiple wordforms (words) at the same time. Currently, this is limited to the **Form** field content and for only wordforms that are *not* used in any texts (**Number in Corpus** is **0**). However, you could display the **Form** field in the orthographic writing system and also in a phonetic or phonemic writing system.

1.  In the **Navigation** **Pane**, click **Texts & Words**, and then click **Bulk Edit Wordforms**.

2.  Click the **Bulk Replace** tab.

3.  [Filter](../../../Basic_Tasks/Filtering_data/filtering_data_overview.md) or [sort](../../../Basic_Tasks/Sorting_data/Sorting_data_overview.md) the data as needed.

4.  Use the [Configure Columns](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) dialog box to hide/show/move columns (fields), and specify the writing systems displayed.

5.  In the left column, [select the rows](Bulk_Edit_Change_Spellings_selections.md) you want to change.

6.  In the **Bulk Edit Operation** pane, do the following:

    - In the **Target Field** box, select the **Form** field in which you want to find and replace content.

    - Click **Setup**.

      The **Bulk Replace Setup** dialog box opens.

7.  Do the following in the dialog box:

    - Specify any [Search Options](../../../Basic_Tasks/Find_and_Replace/Search_Options.md).

    - In the **Find what** box, enter the *search text* (that is, the character string, word, or phrase that you want to search for).

      The **Preview** and **Apply** buttons are *not* available in the **Bulk Replace** tab if the **Find What** box is left empty.

    - In the **Replace with** box, enter the *replacement text*.

    - Click **OK**.

8.  Click **Preview**, review the pending changes, and then click **Apply**.

    Wordforms with a check mark in the left column change.

> [!TIP]
>
> - For special search or replacement criteria, refer to [Find or Replace Formatting](../../../Basic_Tasks/Find_and_Replace/Find_and_Replace_formatting.md) or [Find or Replace using regular expressions](../../../Basic_Tasks/Find_and_Replace/Find_and_Replace_using_regular_expressions.md).
