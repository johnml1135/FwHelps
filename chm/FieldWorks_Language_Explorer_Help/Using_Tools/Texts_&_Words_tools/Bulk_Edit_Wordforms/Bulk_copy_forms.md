# Bulk copy forms

*Using Tools › Texts & Words tools › Bulk Edit Wordforms*

In [Bulk Edit Wordforms](Bulk_Edit_Wordforms_overview.md), the **Bulk Copy** tab allows you to copy text from one field to another for multiple wordforms (words).

Currently, this is limited to the **Form** field content. However, you could display the **Form** field in the orthographic writing system and also in a phonetic or phonemic writing system and then copy between them. Then, you may be able to create a process in the [Process](Bulk_process_forms.md) tab to change the forms as needed, or edit the copied forms manually, such as to add or remove tone marks.

1.  In the **Navigation pane** click **Text & Words**, and then click **Bulk Edit Wordforms**.

2.  In the **Wordforms** pane, click the **Bulk Copy** tab.

3.  [Filter](../../../Basic_Tasks/Filtering_data/filtering_data_overview.md) or [sort](../../../Basic_Tasks/Sorting_data/Sorting_data_overview.md) the data to display only applicable wordforms.

4.  In the left column, [select the rows](Bulk_Edit_Change_Spellings_selections.md) you want to change.

5.  Use the [Configure Columns](../../../Basic_Tasks/Configure_Columns/Configure_Columns_overview.md) dialog box to hide/show/move columns, and specify the writing systems displayed.

6.  In the **Bulk Edit Operation** pane, do the following:

    - In the **Source Field** box, select the field that has the content you want to copy.

    - In the **Target Field** box, select the field into which you want to paste the content.

    - In the **If the Target Field is not empty** **area**, select the desired result and enter a symbol or character as a separator, if necessary.

7.  Click **Preview**, review the pending changes, and then click **Apply**.

    The wordforms with a check mark in the left column change.
