# Bulk process forms

*Using Tools › Texts & Words tools › Bulk Edit Wordforms*

In [Bulk Edit Wordforms](Bulk_Edit_Wordforms_overview.md), the **Process** tab is currently limited to the **Form** field content and to wordforms that are not used in any texts (**Number in Corpus** is **0**). However, you could display the **Form** field in the orthographic writing system and also in a phonetic or phonemic writing system.

1.  In the **Navigation** **Pane**, click **Texts & Words**, and then click **Bulk Edit Wordforms**.

2.  Click the **Process** tab.

3.  Use the [Configure Columns](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) dialog box to hide/show/move columns (fields), and specify the writing systems displayed, if permitted.

4.  [Filter](../../../Basic_Tasks/Filtering_data/filtering_data_overview.md) or [sort](../../../Basic_Tasks/Sorting_data/Sorting_data_overview.md) the data to display only applicable senses.

5.  In the left column, [select the rows](Bulk_Edit_Change_Spellings_selections.md) you want to change.

6.  In the **Bulk Edit Operation** pane, do the following:

    - In the **Source Field** box, select the field that has the content you want to copy.

    - In the **Target Field** box, select the field into which you want to paste the processed content.

    - In the **If the Target field is not empty** area, select the desired result, and, if necessary, enter a symbol or character as a separator.

    - In the **Process** box, select an existing processor, or click **Setup** to open the [Setup Processor](../../Lexicon_tools/Bulk_Edit_Entries/Using_Setup_Processor_dialog_box.md) dialog box so you can [add](../../Lexicon_tools/Bulk_Edit_Entries/add_a_processor.md) or [change the properties of](../../Lexicon_tools/Bulk_Edit_Entries/change_the_properties_of_a_processor.md) a processor.

7.  Click **Preview**, review the pending changes, and then click **Apply**.

    The wordforms with a check mark in the left column change.
