# Insert Row Below

*Using Tools › Texts & Words tools › Interlinear Texts › Text Chart tab*

When you use the **Text Chart** tab, you insert [glossed](../specify_the_word_gloss.md) or [analyzed](../specify_the_word_gloss.md) vernacular words and their word glosses into the chart. You may insert a row (clause) *below* an existing row in the chart.

- In a [Text Chart](Text_chart_overview.md) tab, click the appropriate row in the chart, and then select **Insert Row Below** on the menu that appears.

An empty row appears below the row you clicked.

You can then [move a word](move_word.md) or [move a cell](move_cell.md) to this new row.
