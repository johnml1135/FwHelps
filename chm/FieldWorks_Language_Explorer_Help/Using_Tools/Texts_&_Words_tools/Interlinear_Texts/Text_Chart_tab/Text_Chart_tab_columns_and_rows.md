# Text Chart tab columns and rows

*Using Tools › Texts & Words tools › Interlinear Texts › Text Chart tab*

The **Text Chart** tab contains a chart with columns and rows.

## Columns

- [Columns](../../../Lists_tools/Text_Chart/default_chart_columns.md) are stored in **Lists**. Column header labels, except for the **Notes** column, are stored in the **Text Constituent Chart Templates** list [Name fields](../../../../User_Interface/Field_Descriptions/Lists/Text_Chart_Temp_fields/name_field_tctemp.md).

- Darker vertical lines separate the **Nucleus** group from the other groups.

- The **Notes** column is an editable text column where you can type short notes about the row.

## Rows

- Each row represents one clause.

- You manually [mark the last row](Mark_last_row.md) of sentences and paragraphs with different [line weights](Text_Chart_tab_colors_lines.md).

- Numbers (1, 2, 3, and so on) followed by a letter (a, b, c, and so on) automatically indicate sentences and clauses. For example, **2c** indicates the second sentence, third clause.

  - For *left-to-right* writing systems, they appear in the leftmost column.

  - For *right-to-left* writing systems, they appear in the rightmost column.
