# Mark Last Row

*Using Tools › Texts & Words tools › Interlinear Texts › Text Chart tab*

When you use the **Text Chart** tab, you insert [glossed](../specify_the_word_gloss.md) or [analyzed](../specify_the_word_gloss.md) vernacular words and their word glosses into the chart. Then, you specify the end of each sentence and paragraph.

## Mark end of sentence or paragraph

In a [Text Chart](Text_chart_overview.md) tab, do one of the following to mark the end of a sentence or paragraph:

- Click the row you want as the last row in the *sentence*, and then select **Last Row in Sentence.**

The [line-weight](Text_Chart_tab_colors_lines.md) of the line at the bottom of the row changes to the *medium* weight, indicating the end of a sentence.

- Click the row you want as the last row in the *paragraph*, and then select **Last Row in Paragraph**.

The [line-weight](Text_Chart_tab_colors_lines.md) of the line at the bottom of the row changes to the *heaviest* weight, indicating the end of a paragraph.

## Remove an 'end of a sentence' or 'end of paragraph' mark

1.  In a **Text Chart** tab, click the row that is currently marked as the end of a sentence or end of paragraph, but that you want to change.

    Notice the following in the menu that appears:

    For a row that is currently marked as the last row of a paragraph, check marks appear next to both **Last Row in Sentence** and **Last Row in Paragraph**. For a row that is currently marked as the last row in the sentence, then a check mark appears next to **Last Row in Sentence**.

2.  Click one of the following:

    - To change a row from being the last row in the *paragraph* to instead be only the last row in the *sentence*, click the **Last Row in Paragraph** menu command (which clears the check mark from that menu command).

    - To change a row from being the last row in the *paragraph*, to be *neither* the last row in the sentence or paragraph, click the **Last Row in** **Sentence** menu command (which clears the check mark from both menu commands).

    - To change a row from being the last row in the *sentence*, to no longer being a last row, click the **Last Row in** **Sentence** menu command (which clears the check mark from that menu command).

    The [line-weight](Text_Chart_tab_colors_lines.md) of the line at the bottom of the row changes and the numbering at the end of each affected row changes. You may want to repeat the steps in the first task above to mark the ends of sentences and paragraphs again.
