# Change Text Chart tab font attributes

*Using Tools › Texts & Words tools › Interlinear Texts › Text Chart tab*

**Text Chart** tabs use font attributes set in the **Normal** paragraph style. You can select font attributes to change how charts appear.

- You cannot change the charts independently from other areas or views. Your changes can also affect styles that are [based on](../../../../User_Interface/Menus/Format/Styles/Select_the_parent_style.md) **Normal**.

- **Font color** is ignored by **Text Chart** tabs. **See:** [Colors and line weights](Text_Chart_tab_colors_lines.md).

Do the following:

1.  On the **Format** menu, click **Styles**, and then click the [Font](../../../../User_Interface/Menus/Format/Styles/Styles_Font_tab.md) tab.

2.  In the **Styles** pane, click **Normal**, if it is not already selected.

3.  In the **Writing systems** list, do one of the following:

    - Select a writing system, such as the vernacular or analysis writing system used in the chart.

    - To set font attributes for *all* writing systems, select **\<****default** **settings****\>**.

4.  In the **Attributes** pane, do any of the following:

    - In the **Font** list, select the font name (typeface).

    - In the **Size** list, select the font size.

    - Change other font attribute selections, as desired.

    (Some font attributes are *not useful* in **Text Chart** tabs, such as **Superscript**. Changing other font attributes can be very useful, particularly font **Size**.)

5.  Click **OK**.

> [!TIP]
>
> - To improve readability and help use screen space efficiently when you display text charts on a screen with a projector, *temporarily* change the font **Size** for a vernacular or analysis writing system, or both. You might also select **Bold** in this case.
>
> <!-- -->
>
> - The *default* font for each writing system is set in the **Font** tab of the [Writing System Properties](../../../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Writing_System_Properties_Fonts_tab.md) dialog box.
>
> - Font attribute changes do *not* affect the fonts used in [exported](../../../../User_Interface/Menus/File/Export/Export_Discourse_Chart.md) text charts.
