# Change Text Chart gloss writing system

*Using Tools › Texts & Words tools › Interlinear Texts › Text Chart tab*

As mentioned in [About the Text Chart tab](About_Text_Chart_tab.md), the bottom pane of the **Text Chart** tab contains the vernacular interlinearized words from the current text. The word glosses appear below the vernacular words in only the *default* (top) analysis writing system.

To change the analysis writing system in which those word glosses are displayed, [reorder](../../../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Reorder_writing_systems.md) the analysis writing system in the **Writing System Properties** dialog box.
