# Mark as Missing

*Using Tools › Texts & Words tools › Interlinear Texts › Text Chart tab*

When you use the **Text Chart** tab, you insert glossed or analyzed vernacular words and their word glosses into the chart. Some implicit items, such as implicit subjects and verbs are *automatically* marked by three dashes: **---**.

To *manually* insert a marker for other implied or “missing” content, do the step below.

## Mark as Missing

- In a **Text Chart** tab, click (or right-click) the cell in which you will mark, and then select **Mark as Missing** on the menu that appears.

  The marker, **---**, is inserted in the cell. Also, a check mark is added to the menu command.

## Remove a Mark as Missing marker

- In a **Text Chart** tab, click (or right-click) the cell that was manually marked, and then click **Mark as Missing** on the menu that appears (the menu command will have a check mark).

  The check mark is removed from the menu command, and the marker is removed from the cell.

> [!IMPORTANT]
>
> - The **Mark as Missing** command is only available in *empty* cells. The marker cannot coexist with any other cell content.
>
>   - Markers are removed automatically anytime any word or any other marker is added or moved into to the cell.
>
>   - Manually inserted markers do not interact with automatically inserted markers in any programmatic way.
>
> - You cannot move one of these markers. Instead, remove the unwanted marker and then mark a different cell.
>
> - In the current version, the visually presentation (such as style or unique bracketing options) of the manually inserted marker is not user-configurable and looks like those inserted automatically. However, you can examine the **Mark as Missing** command for a check mark to help you learn if a **---** marker was manually inserted.
