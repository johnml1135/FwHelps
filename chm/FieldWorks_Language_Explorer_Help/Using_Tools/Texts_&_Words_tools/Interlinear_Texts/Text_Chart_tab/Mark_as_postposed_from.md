# Mark as Postposed from

*Using Tools › Texts & Words tools › Interlinear Texts › Text Chart tab*

When you use the **Text Chart** tab, you insert [glossed](../specify_the_word_gloss.md) or [analyzed](../specify_the_word_gloss.md) vernacular words and their word glosses into the chart. You can mark words that were inserted *later* than the default word order (marked order) as *postposed*.

Two [colored](Text_Chart_tab_colors_lines.md) markers are used:

- Words marked as postposed become red in color.

- A pink \>\> marker appears in the cell (row and column) that is the default position of the word(s).

## Mark as Postposed from

1.  In a **Text Chart** tab, click the cell that has the word or words you want to mark as postposed.

2.  Point to **Mark as Postposed from** on the menu that appears, and then select the desired column in the current clause or select **Another clause**.

- If the **Mark As Postposed from another Clause** dialog box appears, select the **Row** (clause) and **Column** that you want to mark as the default position of the word(s). Click **OK**.

The two colored markers appear in the chart. Also, a check mark is added to the submenu command that you selected.

## Remove Postposed from markers

1.  In a **Text Chart** tab, click the cell with the word or words that are marked as postposed.

2.  Point to **Mark as Postposed from** on the menu that appears, and then select the column that has a check mark or select **Another clause**. (The column with a check mark must match the column with the associated pink \>\> marker.)

The two colored markers are removed from the chart. The check mark is cleared from the submenu.
