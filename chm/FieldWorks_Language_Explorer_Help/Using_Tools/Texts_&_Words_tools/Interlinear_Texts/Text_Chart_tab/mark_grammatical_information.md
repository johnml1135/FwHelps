# Mark Grammatical Information

*Using Tools › Texts & Words tools › Interlinear Texts › Text Chart tab*

In the **Text Chart** tab, you can mark cell (row and column) content with grammatical information concerning **TenseAspectMood** (TAM), pronoun type or demonstrative type. These are stored in the [Text Chart Markers](../../../Lists_tools/Text_Chart/Text_Chart_Markers.md) list. Because you can edit this list, the grammatical information markers that appear as the commands in *your* submenus may be *different* that these *default* menu command:

- **Mark TenseAspectMood**

- **Mark Pronouns**

- **Mark Demonstratives**

## Mark grammatical information

1.  In a **Text Chart** tab, click the cell (row and column) which has the content that you want to mark with grammatical information.

2.  In the menu that appears, point to one of the menu commands, such as those listed above. Then, select the desired grammatical marker on a submenu.

The selected grammatical marker appears in the cell, [colored](Text_Chart_tab_colors_lines.md) and in a parentheses. Also a check mark is displayed next to that marker in the submenu, which indicates that it is used in the current cell.

## Remove grammatical information markers

1.  In a **Text Chart** tab, click the cell that has the grammatical information marker you want to remove.

2.  Follow the submenus from the appropriate menu command (such as those listed above) to the particular grammatical information marker, which will have a check mark. Click that marker in the submenu.

That marker is removed from the cell and the check mark is cleared from the submenu.
