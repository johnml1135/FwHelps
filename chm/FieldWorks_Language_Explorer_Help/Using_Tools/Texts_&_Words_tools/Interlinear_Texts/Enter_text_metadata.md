# Enter text metadata

*Using Tools › Texts & Words tools › Interlinear Texts*

**Info** tab fields allow you to enter and edit metadata ([source](../../../User_Interface/Field_Descriptions/Texts_%26_Words/Source_field_info.md), [comment](../../../User_Interface/Field_Descriptions/Texts_%26_Words/Comment_field_info.md), genre, and so on) about the current text. [Info tab fields](../../../User_Interface/Field_Descriptions/Texts_%26_Words/Texts_%26_Words_fields_overview.md) determine some [Print View](Print_View_Tab_overview.md) tab contents.

1.  In the Navigation Pane, click **Texts & Words**, and then click [Interlinear Texts](texts_edit_overview.md).

2.  Click the text for which you will work with metadata.

3.  Click the **Info** tab.

4.  In the **Info** tab [fields](../../../User_Interface/Field_Descriptions/Texts_%26_Words/Texts_%26_Words_fields_overview.md), do any of the following:

    - Enter or edit the text title, abbreviation, source, or comments for the current text in one or more writing systems. (Optionally, examine the results in the **Print View** tab. Change the metadata as needed.)

    - If the **Text is a translation** field check box is available for change, select or clear the check box to indicate whether the text has been translated or is an original text.

    - In the **Genres** field, click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) to open the **Choose Genres** dialog box. Choose one or more genres, and then click **OK**.

      If the genre you need is *not* in the list, click the **Edit the Genres** link in the **Choose Genres** dialog box so you can [insert](../../Lists_tools/Insert_a_list_item.md) a new genre.

    - [Additional fields](../../../User_Interface/Field_Descriptions/Texts_%26_Words/Texts_%26_Words_fields_overview.md) appear in the **Info** tab if the text was entered in the [Text](../../../User_Interface/Field_Descriptions/Notebook/Text_field_(Notebook).md) field of a **Notebook** record. Each of them is another instance of a **Notebook** record [field](../../../User_Interface/Field_Descriptions/Notebook/Notebook_fields_overview.md). Choose list items in either instance of these fields.

> [!NOTE]
>
> - You can [configure the columns](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) in the center **Texts** pane (**Interlinear Texts**), the **Concordance Results** pane (**Concordance**) and in the upper-right pane in **Word List Concordance** to display text metadata. Also, the title and abbreviation can appear in the **Title** and **Ref** column in panes that show [occurrences](../Concordance/Manually_specify_concordance_criteria.md) of words.
>
> - For texts that were [included](../../../Basic_Tasks/Filtering_data/Choose_Texts.md) from another FieldWorks program, some fields are *not* displayed or available for change.
>
> - You can use the **Choose Genres** dialog box when you run [parser tests](../../../User_Interface/Menus/Parser/Parser_Test_Reports.md).
