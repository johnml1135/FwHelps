# Enter a literal translation

*Using Tools › Texts & Words tools › Interlinear Texts*

For a [glossed](specify_the_word_gloss.md) or [analyzed](Analyze_Text_overview.md) text, you can [insert word glosses](../../../User_Interface/Menus/Insert/Insert_Word_Glosses.md) into a **Lit** line.

Alternatively, you can *manually* type or paste (enter) content into a **Lit** line, as follows:

1.  [Display the text in an interlinear view](Display_text_in_an_interlinear_view.md).

2.  If necessary, configure interlinear lines to display the **Lit** line and select the writing systems for it.

3.  Click the **Lit** line, and then enter the desired translation.

    - If **Lit** line displays more than one writing system, click the line that used the appropriate writing system. Repeat this step for each writing system as necessary.

    - You can also embed words in different writing systems in each **Lit** line. Change the writing system on the [Format toolbar](../../../User_Interface/Toolbars/Format_toolbar.md) and then type the words, or select existing words and then change the writing system.
