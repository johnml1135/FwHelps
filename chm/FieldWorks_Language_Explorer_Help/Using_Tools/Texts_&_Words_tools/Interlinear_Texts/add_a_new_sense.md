# Add a new sense

*Using Tools › Texts & Words tools › Interlinear Texts*

While you manually [analyze a word in a text](Analyze_Text_overview.md), you can add a new sense to an *existing* lexical entry and link it to the word or morpheme.

1.  [Display the text in an interlinear view](Display_text_in_an_interlinear_view.md).

2.  Click the word you want to analyze.

    The word appears in a [focus box](Word_Focus_Box_examples.md).

3.  On the **Lex Entries** line, click the down arrow ![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Down_Arrow_pic.PNG) for the word or a morpheme, and then select the *applicable* **Add New Sense** command.

    An **Add New Sense** command appears for *each* lexical entry, so multiple occurrences may appear in the drop down list. A *homograph* number may appear as a subscript for each entry. **Add New Sense for \<morpheme\>** appears when the morpheme is a *variant* entry that has no existing sense.

    The **Add New Sense** dialog box appears.

4.  In the dialog box, do the following:

    - Enter a gloss.

    - Select the grammatical information ([examples](Add_New_Sense_dialog_box_graphic.md)).

    - Click **OK**.

    A new sense is added to the lexical entry.

    The **Lexeme Form** (or **Citation Form** if the **Lexeme Form** field is empty) from the lexical entry appears in the **Lex Entries** line. The gloss from the new sense appears in the **Lex Gloss** line and its grammatical information appears in the **Lex Gram Info** line.
