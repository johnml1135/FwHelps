# Enter a free translation

*Using Tools › Texts & Words tools › Interlinear Texts*

For a [glossed](specify_the_word_gloss.md) or [analyzed](Analyze_Text_overview.md) text, you can [insert Word Gloss line content](../../../User_Interface/Menus/Insert/Insert_Word_Glosses.md) into a **Free** line. *Alternatively*, you can *manually* type or paste (enter) content into a **Free** line, as follows:

1.  [Display the text in an interlinear view](Display_text_in_an_interlinear_view.md).

2.  If necessary, configure interlinear lines to select the writing systems for the **Free** line.

3.  Click the **Free** line, and then enter a free translation.

    - If the **Free** line displays more than one writing system, click the line that uses the appropriate writing system. Repeat for each writing system.

    - You can also embed words in different writing systems in each **Free** line. Change the writing system on the [Format toolbar](../../../User_Interface/Toolbars/Format_toolbar.md) and then type the words, or select existing words and then change the writing system.

> [!NOTE]
>
> - **Free** lines appear by default. There can be only *one* **Free** line for each line of text, but it can use more than one writing system.
