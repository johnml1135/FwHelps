# Add morpheme as allomorph of lexical entry

*Using Tools › Texts & Words tools › Interlinear Texts*

While you manually [analyze a word](Analyze_Text_overview.md), you can add a morpheme to an *existing* lexical entry as an allomorph.

1.  [Display the text in an interlinear view](Display_text_in_an_interlinear_view.md).

2.  Click the word you want to analyze.

    The word appears in a [word focus box](Word_Focus_Box_examples.md).

3.  On the **Lex Entries** line, click the down arrow ![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Down_Arrow_pic.PNG), and then select **Allomorph of**.

    The **Find entry to add allomorph** dialog box appears.

4.  In the **Lexical Entries** pane, look for the desired entry. If the entry is not listed, do any of the following:

    - In the **Go To** box, edit the morpheme.

    - [Configure the columns](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) to show more columns (such as **Grammatical Information** or **Morph Type**) or display data in different writing systems in the **Lexical Entries** pane.

    - Select an appropriate writing system in the **Writing System** box, and then enter a different *form* or a *gloss* in the **Go To** box.

    - If no appropriate entry is listed, click **Cancel**. Then [create a new entry](Create_new_lex_entry_interlinear_view.md).

5.  In the **Lexical Entries** pane, select the desired entry.

    If the current morpheme already exists as an allomorph of that entry, the left button is **Use Allomorph**. Otherwise, the button is **Add Allomorph**.

6.  Click **Use Allomorph** or **Add Allomorph**.

    One of the following occurs:

    - The existing allomorph *or* the newly added allomorph appears in the analysis with information from the lexical entry (the lexeme form, and the gloss and grammatical info from **Sense 1**).

    - The **Add allomorph to lexical entry** (**Mismatching morpheme types**) warning box appears if the entry and current morpheme have different morpheme types. In this case, click *one* of the following:

      - **No** to *close* the warning box so you can choose another entry

      - **Yes** to *add* the morpheme as an allomorph (*not* *recommended* to prevent an affix allomorph in a stem entry or a stem allomorph in an affix entry)

      - **Create New Entry** to [create an entry](../../Lexicon_tools/Lexicon_Edit/Create_a_lexical_entry.md) in the **New Entry** dialog box.
