# Specify Unknown lexical relationship for a morpheme

*Using Tools › Texts & Words tools › Interlinear Texts*

While you manually [analyze words in a text](Analyze_Text_overview.md), you can specify that the morpheme's relationship with any existing lexical entries is currently not known.

1.  [Display the text in an interlinear view](Display_text_in_an_interlinear_view.md), **Analyze** tab.

2.  If the desired word is not already in a [word focus box](Word_Focus_Box_examples.md), click that word.

3.  In the **Lex Entries** line, click the down arrow ![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Down_Arrow_pic.PNG), and then select **Unknown**.

    The **Lex Entries**, **Lex Gloss** and **Lex Gram Info** lines change to **\*\*\***. The **Word Gloss** line appears empty or displays **\*\*\***.

4.  When you are finished, [move to another word](../../../User_Interface/Menus/Data/Data_overview.md).
