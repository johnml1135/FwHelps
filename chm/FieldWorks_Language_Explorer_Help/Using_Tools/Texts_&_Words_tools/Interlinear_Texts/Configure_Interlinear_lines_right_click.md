# Configure Interlinear lines right-click

*Using Tools › Texts & Words tools › Interlinear Texts*

The [Configure Interlinear Lines](../../../User_Interface/Menus/Tools/Configure_interlinear_lines_dialog_box.md) dialog box allows you to specify which interlinear lines are displayed, their order, and so on. *Right-click* menu commands allow you to do limited changes or open the dialog box.

1.  With a text displayed in [an interlinear view](Display_text_in_an_interlinear_view.md), click one of the line headers (**Word**, **Morphemes**, **Free**, and so on), and then right-click that same line header.

    Do any of the following on the right-click menu that appears:

    - Click **Hide** \<current line\> (to [hide](Delete_Hide_an_annotation.md) that annotation).

    - Point to **Add Writing System**, and then click a writing system (available only if you have more than one vernacular or analysis [writing system](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md)).

    - Click **Move Up** or **Move Down**\
      If two or more writing systems are [displayed](../../../User_Interface/Menus/Tools/Configure_interlinear_lines_dialog_box.md) for a field, you can reorder them for that particular field.

    <!-- -->

    - Click **Add Line** (**Lit.** or **Note**).

    - Click **Configure Interlinear** to open the **Configure Interlinear Lines** dialog box.

> [!TIP]
>
> - To *delete* a **Note** line, see [Delete or hide an annotation](Delete_Hide_an_annotation.md).
