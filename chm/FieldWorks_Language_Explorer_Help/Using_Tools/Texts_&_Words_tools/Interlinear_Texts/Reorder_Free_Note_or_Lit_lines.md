# Reorder Free Note or Lit lines

*Using Tools › Texts & Words tools › Interlinear Texts*

With one or more **Free**, **Note**, or **Lit** annotation lines displayed, you can move them up or down to reorder them *without* using the [Configure Interlinear Lines](../../../User_Interface/Menus/Tools/Configure_interlinear_lines_dialog_box.md) dialog box.

1.  [Display the text in an interlinear view](Display_text_in_an_interlinear_view.md).

2.  Right-click the line you want to move, and then click **Move Up** or **Move Down**.

    - Repeat this step until the desired order is shown.
