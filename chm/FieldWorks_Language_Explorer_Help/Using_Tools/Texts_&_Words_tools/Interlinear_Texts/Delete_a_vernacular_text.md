# Delete a vernacular text

*Using Tools › Texts & Words tools › Interlinear Texts*

1.  In the **Navigation Pane**, click **Texts & Words**, and then click **Interlinear Texts**.

2.  In the **Texts** pane, click the text you want to delete.

3.  Do one of the following:

    - On the [Standard](../../../User_Interface/Toolbars/Standard_toolbar.md) toolbar, click ![pic](../../../assets/images/RedDeleteRecordX.GIF).

    - On the **Edit** menu, click **Delete Text**.

    - Right-click the text in a **Texts** pane, and then click **Delete selected Text** on the menu that appears.

    A **Delete** **Text** warning box appears. It identifies the current text, and asks if you want to continue with the deletion.

4.  If you are sure you want to delete the text identified in the warning box, click **Delete**.

    The selected text is deleted. If the text was entered in a [Text](../../../User_Interface/Field_Descriptions/Notebook/Text_field_(Notebook).md) field (Notebook), that field becomes empty. The [Number in Corpus value](../Word_list_columns.md) is reduced.

    - Otherwise, click **Cancel**.

> [!IMPORTANT]
>
> - It is recommended that you consider [backing up](../../../User_Interface/Menus/File/Backup_and_Restore/Back_up_this_Project.md) your project *before* you delete anything that you might need in the future.
>
> - If you [delete a fieldnote record](../../Notebook_tools/Record_Edit_overview/Delete_a_fieldnote_record.md) that has the text, the text is *not* deleted from **Texts & Words**.
