# Add variant of lexical entry

*Using Tools › Texts & Words tools › Interlinear Texts*

While you manually [analyze a word in a text](Analyze_Text_overview.md), you can add a variant to an *existing* lexical entry and associate it with the current morpheme.

1.  [Display the text in an interlinear view](Display_text_in_an_interlinear_view.md).

2.  Click the word you want to analyze.

    The word appears in a [word focus box](Word_Focus_Box_examples.md).

3.  On the **Lex Entries** line, click the down arrow ![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Down_Arrow_pic.PNG), and then select **Variant of**.

    The **Find entry to add variant** dialog box appears.

4.  In the **Variant of** box, type the form of the lexical headword for which the current word is a variant.

    - You can also select an appropriate writing system in the **Writing System** box.

    - If necessary, [configure the columns](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) in the **Lexical Entries** area so you can see other columns or display data in different writing systems.

    - If *no* appropriate entry appears in the **Lexical Entries** area, click **Create Entry** so you can [create a new entry](../../Lexicon_tools/Lexicon_Edit/Create_a_lexical_entry.md).

    - If the appropriate entry appears in the **Lexical Entries** area, click it and then do these steps:

<!-- -->

1.  In the **Variant of Entry or Sense** pane, select **Entry** or **Specific Sense**. Select a sense, if necessary.

2.  In the **Variant Type** box, choose the type of variant.

3.  Click **Link Selected**.

The *form* of the variant appears in the **Lex Entries** line. The gloss from the sense appears in the **Lex** **Gloss** line and its grammatical properties appear in the **Lex** **Gram Info** line.
