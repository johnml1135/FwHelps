# Tagging a text

*Using Tools › Texts & Words tools › Interlinear Texts*

In [Texts & Words](../Texts_and_Words_overview.md), you use the **Tagging** tab to tag one or more words with one or more list items (“tags”) from the [Text Markup Tags list](../../../User_Interface/Field_Descriptions/Lists/Text_Markup_Tags_fields/txtmkup_fields_overview.md). This list has two hierarchical levels, so you will select each tag from a submenu.

To mark up a text that is in a **Text Chart** tab, see [Text Chart tab overview](Text_Chart_tab/Text_chart_overview.md).

## Tag a text

1.  In the **Tagging** tab, do one of the following:

    - To tag *one* word, click that word to select it.

    - To tag *multiple* adjacent words, such as a phrase, click a word. Then, press and hold the `Shift` key and click another word in the same section.

    That word or set of words is selected. It has a dark background color.

2.  Right-click a selected word, point to an item on the menu that appears, and then click the desired tag on the submenu.

    The menu and submenu close. A check mark (![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Tag_CheckMark.GIF)) is added next to the tag in the submenu, which indicates that it is used with the current word.

    If you tagged one word, it appears in square brackets, such as ![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Tag_short.PNG) under the word.

    If you tagged multiple adjacent words, the tag appears under the first of those words, but the ending bracket appears under the last of those words, such as ![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Tag_Long.PNG).

3.  You can repeat the steps above to put another tag on the same word or words.

## Remove or change a tag

1.  In the **Tagging** tab, click the word that has the tag you want to remove or change.

2.  Do one of the following:

    - To *remove* the tag, right-click that word, point to the item on the menu that has the submenu with the current tag, and then click the item on the submenu that has the check mark (![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Tag_CheckMark.GIF)).

      The check mark displayed next to the current tag is removed and that tag is removed from the word.

    - To *change* the tag, right-click that word, point to an item on the menu, and then click the desired tag on the submenu.

      The check mark displayed next to a tag is removed from the previous tag and is added to the tag you just selected. The selected tag replaces the tag below the word.

> [!NOTE]
>
> - You can select **Tagging** in [Concordance](../Concordance/Manually_specify_concordance_criteria.md) to see everywhere a particular tag is used.
>
> - The tags do *not* appear in the **Print View** tab or in any of the other tab or view.
