# Display text in an interlinear view

*Using Tools › Texts & Words tools › Interlinear Texts*

This topic gives some ways (*not* exhaustive) to display text data in an interlinear view. Here, *interlinear view* refers to a text displayed in a **Gloss** tab, **Analyze** tab or **Tagging** tab.

## From Lexicon

**Lexicon Edit**, **Browse** or **Bulk Edit Entries**

- On a [context-sensitive menu](../../../Basic_Tasks/Show_data/Context_sens_menus.md), use a **Show \<item\> in Concordance** command.

  The window changes to **Concordance** (see below).

## From Texts & Words

### **Interlinear Texts**

- In the **Texts** pane, select a text. Then in the **Text** pane, click the desired tab. Click a word to put it into a [word focus box](Word_Focus_Box_examples.md). (See **Tip** below.) Alternatively, click the **Tagging** tab if you will tag words with items from the [Text Markup Tags list](../../../User_Interface/Field_Descriptions/Lists/Text_Markup_Tags_fields/txtmkup_fields_overview.md).

### **Word List Concordance**

- In the **Wordforms** pane, click the word. Then in the **Concordance** pane, click an occurrence (*top*) and the desired tab (*bottom*).

### **Word Analyses**

- In the **Wordforms** pane, click the word. In the **Wordform Analyses** pane, right-click an approved analysis, point to **Show Concordance of**, and then click a submenu command (**Analysis**, **Entry** or **Sense** and so on).

  The window changes to **Concordance** (see below).

### **Bulk Edit Wordform**

- Right-click the desired wordform (row), and then click **Show in Concordance**.

  The window changes to **Concordance** (see below).

### **Concordance**

[Specified concordance criteria](../Concordance/specify_concordance_criteria.md) with a context-sensitive menu *or* menu-button command, such as discussed above. Alternatively, [manually specify concordance criteria](../Concordance/Manually_specify_concordance_criteria.md). Then, do the following:

1.  In the **Concordance Results** pane, click an occurrence.

2.  In the **Full Context** pane, click the desired tab.

> [!TIP]
>
> - In any **Baseline** tab, click the desired word, and then click the **Gloss** or **Analyze** tab. For long texts, you can use the **Find** tab in the [Find and Replace](../../../User_Interface/Menus/Edit/Find_and_Replace_Text.md) dialog box to find the desired word.
