# Select New analysis or New word gloss

*Using Tools › Texts & Words tools › Interlinear Texts*

For words with one or more existing analyses, the [Select an existing analysis](Select_existing_analysis.md) topic helps you select a different analysis for the word in a [word focus box](Word_Focus_Box_examples.md).

The topic presented here is intended to help you use the following *alternative* commands:

- **New analysis** to clear the current analysis. Specifically, the **Morpheme** line will display the word, without any morpheme breaks. The **Word Gloss** line will display an editable box. Other fields will display **\*\*\***.

- **New word gloss** to clear the **Word Gloss** line.

> [!IMPORTANT]
>
> - *Each* analysis has its own **New word gloss** command, which *assigns the associated analysis* to the word, but without a word gloss. The example in [Select an existing analysis](Select_existing_analysis.md) shows this.
>
> Do the steps that follow:
>
> 1.  [Display the text in an interlinear view](Display_text_in_an_interlinear_view.md), in either an **Analyze** tab or a **Gloss** tab.
>
> 2.  If the desired word is not already in a [word focus box](Word_Focus_Box_examples.md), click that word.
>
> 3.  Do one of the following:
>
>     - In the **Word** line, click the down arrow ![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Down_Arrow_pic.PNG), and then click either **New analysis** *or* the **New word gloss** command that is associated with the existing analysis you want.
>
>     - In the **Word Gloss** line, click the down arrow ![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Down_Arrow_pic.PNG), and then click **New word gloss**.
>
> 4.  [Analyze](Analyze_Text_overview.md) the word again or enter (type or paste) a new word gloss.
>
> <!-- -->
>
> 5.  When you are finished, [move to another word](../../../User_Interface/Menus/Data/Data_overview.md).
