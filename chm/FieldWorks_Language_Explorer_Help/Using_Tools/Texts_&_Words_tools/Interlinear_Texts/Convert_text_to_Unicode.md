# Convert text to Unicode

*Using Tools › Texts & Words tools › Interlinear Texts*

While the actual steps or process of converting text to Unicode are beyond the scope of these `User Helps`, it is important to mention that there are converters available that you can use in Microsoft Word. These can help you [prepare your text](Text_preparation_before_analyzing.md) before you paste it into the FieldWorks Language Explorer.
