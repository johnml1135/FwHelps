# Analyze text overview

*Using Tools › Texts & Words tools › Interlinear Texts*

This overview is intended to help you *manually* *analyze* words in a text. It does *not* include any preparation for or use of a computational [parser](../../../User_Interface/Menus/Parser/Parsing_words_overview.md). To only [gloss](specify_the_word_gloss.md) the words, such as for use in a [text chart](Text_Chart_tab/Text_chart_overview.md), you can use the **Gloss** tab.

You use the **Analyze** tab to do morphological analyses of words. The process changes slightly as your lexicon matures and as other similar or identically-spelled words are analyzed.

To manually analyze words, do the following tasks:

- [Prepare the text](Text_preparation_before_analyzing.md) before you analyze any words.

- [Link all the words](Link_words_in_phrase.md) in each phrase so they appear in one [word focus box](Word_Focus_Box_examples.md). (See **Important** below.)

- If the word has *no existing analysis*, the **Word** line ([word focus box](Word_Focus_Box_examples.md)) will have *not* have a down arrow ![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Down_Arrow_pic.PNG). The **Morpheme** line displays the contents of the **Word** line. The other lines contain \*\*\* or are empty. In this case, you can do the following tasks:

  - [Specify case (upper or lower)](Specify_case.md)

  - [Insert or remove morpheme breaks](Insert_or_remove_morpheme_breaks.md) ([Examples](Morpheme_Break_examples.md))

  - [Select the lexical sense for a morpheme](Select_the_lexical_sense_for_a_morpheme.md)

  - [Specify the word gloss](specify_the_word_gloss.md)

  - [Select a word category](specify_a_word_category.md)

  - [Enter a free translation](Enter_a_Free_Translation.md) or [Insert (copy) Word Glosses into Free or Lit line](../../../User_Interface/Menus/Insert/Insert_Word_Glosses.md)

  - [Enter a literal translation](Enter_a_Literal_Translation.md)

  - [Enter a note](Enter_a_Note.md)

- If the word has *one or more analyses*, you can do any of the tasks above, or you can use the down arrow ![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Down_Arrow_pic.PNG) on the **Word** line to do the following tasks:

  - [Select New analysis or New word gloss](Select_New_Analysis.md)

  - [Use the default analysis](Use_the_default_word_analysis.md)

- If there is a down arrow ![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Down_Arrow_pic.PNG) on the **Word Gloss** line, you can use it to select a word gloss. Otherwise, you can type a new word gloss or edit an existing one. **See also:** [Specify a word gloss](specify_the_word_gloss.md).

> [!IMPORTANT]
>
> - Review the information in [Baseline text writing systems](baseline_text_writing_systems.md) *before* you [display text in an interlinear view](Display_text_in_an_interlinear_view.md). It is possible to inadvertently create *duplicate words* in the [word list](../Word_list_overview.md) or lexical entries without proper headwords. This can take a lot of time to correct.
>
> - For a lexical phrase, such as an [idiom](../../../User_Interface/Field_Descriptions/Lists/Complex_Form_Types_flds/Idiom_entry_type.md), see [Analyzing a lexical phrase](Analyzing_a_phrase.md) or *Introduction to Parsing*, which is available on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu.
>
> - You use the [Configure Interlinear Lines](../../../User_Interface/Menus/Tools/Configure_interlinear_lines_dialog_box.md) dialog box or [right-click](Configure_Interlinear_lines_right_click.md) menu commands to hide, show, and order the lines that are displayed in the **Gloss** or **Analyze** tab. The *default* lines that appear in the [word focus box](Word_Focus_Box_examples.md) are the only difference between the **Gloss** and **Analyze** tabs. Otherwise, they are simply two views of the same content.
>
> - To change the size of vernacular characters, you can change the font size in the **Normal** [style](../../../User_Interface/Menus/Format/Styles/Styles_Font_tab.md) for that vernacular writing system.
>
> - [Show data overview](../../../Basic_Tasks/Show_data/Show_data_overview.md) describes how to use right-click menu commands to “jump” from a word focus box to another area or tool.
>
> - [Swap Lexeme Form with Allomorph](../../Lexicon_tools/Lexicon_Edit/Swap_LexForm_with_Allomorph.md) allows you to exchange the forms in **Lexicon Edit** with the change also shown in analyses that use those forms.
