# Enter a note

*Using Tools › Texts & Words tools › Interlinear Texts*

You can have one or more **Note** lines. You can insert, [delete or hide](Delete_Hide_an_annotation.md) them for individual text lines (segments) *independently*.

1.  [Display the text in an interlinear view](Display_text_in_an_interlinear_view.md).

2.  Click the line of text below which you will enter an annotation.

3.  To insert a **Note** line, do one of the following:

    - Press the [shortcut keys](../../../User_Interface/Shortcuts/shortcut_keys_Texts_Words_tools.md) `Ctrl+N`.

    - On the [Insert](../../../User_Interface/Toolbars/Insert_toolbar.md) toolbar, click ![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Interlinear_Texts/AddNote_Texts.GIF).

    - On the **Insert** menu, click **Note**.

4.  If necessary, [configure interlinear lines](../../../User_Interface/Menus/Tools/Configure_interlinear_lines_dialog_box.md) or use the [right-click menu command](Configure_Interlinear_lines_right_click.md) to select the writing systems for the **Note** line.

5.  Click the **Note** line, and then enter the annotation.

    - If the **Note** line displays more than one writing system, click the line that uses the appropriate writing system. Repeat for each writing system.

    - You can also embed words in different writing systems in each **Note** line. Change the writing system on the [Format toolbar](../../../User_Interface/Toolbars/Format_toolbar.md) and then type the words, or select existing words and then change the writing system.

> [!TIP]
>
> - You can use [Paste Hyperlink](../../../Basic_Tasks/Creating_Hyperlinks/Paste_hyperlink.md) to make a hyperlink to a *.wav* file, such as an audio recording of the text.
