# Specify Case (upper or lower)

*Using Tools › Texts & Words tools › Interlinear Texts*

For each occurrence of wordforms (words) that appear in the **Baseline** tab with a capital initial letter, you can choose to retain that initial capital letter (such as for proper names) *or* to use a lowercase form of that word for use in the **Morphemes** line.

If you edit the content in the **Morphemes** line or leave a form with the wrong case, an unwanted allomorph may appear in the lexical entry. This may happen when you [create a new lexical entry](Create_new_lex_entry_interlinear_view.md) from an interlinear view.

Do the following:

1.  [Display the text in an interlinear view](Display_text_in_an_interlinear_view.md) (in an **Analyze** tab).

2.  If the desired word is not already in a [word focus box](Word_Focus_Box_examples.md), click that word.

3.  In the **Morphemes** line, if the form with the correct case is not already shown, click the down arrow ![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Down_Arrow_pic.PNG), and then select the uppercase or lowercase form.

4.  Finish analyzing the word as necessary.
