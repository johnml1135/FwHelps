# Print View tab overview

*Using Tools › Texts & Words tools › Interlinear Texts*

The **Print View** tab provides a print preview of a [glossed](specify_the_word_gloss.md) or [analyzed](Analyze_Text_overview.md) ("parsed") text. This tab is available in [Interlinear Texts](texts_edit_overview.md), [Concordance](../Concordance/Concordance_overview.md), and [Word List Concordance](../Word_List_Concordance/Word_List_Concordance_overview.md).

With the desired text selected (or an occurrence of a word that is in the desired text selected, such as in the **Concordance Results** pane), click the **Print View** tab and then do any of the following:

- Examine the preview for errors or omissions, as well as layout.

- [Configure interlinear lines](../../../User_Interface/Menus/Tools/Configure_interlinear_lines_dialog_box.md) to hide, show or reorder interlinear lines.

- (The configuration you set in this tab is *independent* from the **Gloss** or **Analyze** tabs.)

- Specify different [style](../../../User_Interface/Menus/Format/Styles/Styles_overview.md) features of a vernacular or analysis writing system (temporarily, if desired).

- [Enter](Enter_text_metadata.md) a [comment](../../../User_Interface/Field_Descriptions/Texts_&_Words/Comment_field_info.md) which appears as a subheading below the title.

- [Print](../../../User_Interface/Menus/File/Print.md) or [export](../../../User_Interface/Menus/File/Export/Export_Interlinear.md) the displayed text. Printed and exported content appear *as displayed*.
