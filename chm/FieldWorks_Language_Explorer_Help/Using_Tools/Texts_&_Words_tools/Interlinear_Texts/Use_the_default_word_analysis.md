# Use the default word analysis

*Using Tools › Texts & Words tools › Interlinear Texts*

While you manually [analyze words in a text](Analyze_Text_overview.md), you can select **Use default analysis** (*most-frequently-used* analysis) for the word *if* at least one previous analysis exists for this word in the current FieldWorks project. If the word does *not* have previous analyses, the **Word** line will *not* have a down arrow. In that case, you cannot specify a default analysis.

1.  [Display the text in an interlinear view](Display_text_in_an_interlinear_view.md), **Analyze** tab.

2.  Click the word for which you want to specify **Use default analysis**.

    The word appears in a [focus box](Word_Focus_Box_examples.md).

3.  In the **Word** line, click the down arrow ![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Down_Arrow_pic.PNG), and then select **Use default analysis**.

    The focus box now shows the *most-frequently-used* analysis (as used for other occurrences of that same word).

4.  Use the appropriate [shortcut keys](../../../User_Interface/Shortcuts/shortcut_keys_Texts_Words_tools.md) to approve the analysis and move to another word (such as `Ctrl+Right Arrow` or `Ctrl+Left Arrow`).
