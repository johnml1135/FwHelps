# Select the lexical sense for a morpheme

*Using Tools › Texts & Words tools › Interlinear Texts*

1.  [Display the text in an interlinear view](Display_text_in_an_interlinear_view.md), **Analyze** tab.

2.  If the desired word is not already in a [word focus box](Word_Focus_Box_examples.md), click that word.

3.  On the **Lex Entries** line, click the down arrow ![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Interlinear_Texts/Down_Arrow_pic.PNG), and then do one of the following:

    - Select the desired sense from the list.

      The **Lexeme Form** from the lexical entry appears in the **Lex Entries** line. The gloss from the sense appears in the **Lex Gloss** line, and its grammatical properties appear in the **Lex Gram Info** line.

    - If the desired sense is *not* in the list, you can click any of the following:

**Add New Sense** *or* **Add New Sense for \<morpheme\>** to [add a new sense](add_a_new_sense.md).

**Unknown** to [specify Unknown lexical relationship for a morpheme](specify_unknown_lexical_relationship_for_a_morpheme.md).

**Create New Entry** to [create a new lexical entry](Create_new_lex_entry_interlinear_view.md).

**Edit Lexical Entry** if you want to see and edit the entry in [Lexicon Edit](../../Lexicon_tools/Lexicon_Edit/lexicon_edit_overview.md).

**Allomorph of** to [add the morpheme as an allomorph](add_morpheme_as_allomorph_of_lexical_entry.md) of an existing lexical entry.

**Variant of** to [add the morpheme as a variant form](Add_variant_of_lexical_entry.md) of an existing lexical entry

4.  When you are finished, [move to another word](../../../User_Interface/Menus/Data/Data_overview.md).

> [!TIP]
>
> - To help you distinguish senses in the list, if more than one sense or similar entry exists in the Lexicon, the **Add New Sense** option appears under *each* sense for *each* lexical entry. In addition, a *homograph* number appears as a subscript.
>
> - **Add New Sense for \<morpheme\>** appears when the morpheme is a *variant* that has no existing sense.
