# Concordance in Texts & Words

*Using Tools › Texts & Words tools*

Here is a brief overview of *three* tools that allow you to search for particular data and display the results in a "concordance" style view. ([Find](../../Basic_Tasks/Find_and_Replace/Find_and_Replace_overview.md) features are different.)

## Concordance

- Use this tool to search for data (words, morphemes, glosses, characters, diacritics, and so on) in particular rows in [word focus boxes](Interlinear_Texts/Word_Focus_Box_examples.md), or from **Free Translation**, **Literal Translation** or **Note** lines.

You can [manually specify](Concordance/Manually_specify_concordance_criteria.md) concordance criteria, or use a **Show in Concordance** command to [specify concordance criteria](Concordance/specify_concordance_criteria.md).

[Concordance overview](Concordance/Concordance_overview.md) has more information.

## Complex Concordance

- This tool allows you to specify concordance criteria that searches for data that is in a particular context.

The context could be contiguous or nearby data, number of occurrences, tagged data, and more. Various dialog boxes, right-click menu commands, and insert options help you [specify](Complex_Concordance/Specify_Complex_Concordance_criteria.md) the elements of the search criteria. You can build simple or quite complex criteria, as needed.

Currently, you cannot save the criteria.

[Complex Concordance overview](Complex_Concordance/Complex_Concordance_overview.md) has more information.

## Word List Concordance

- This tool has a [word list](Word_list_overview.md) of all wordforms (words) used in texts (except deleted words). [Columns](Word_list_columns.md) show various data about the word.

Instead of specifying criteria, here you click a word in this list to see a concordance (list) of all current occurrences of that word. Then, you click an occurrence to display it in the tabs (**Info**, **Baseline**, **Gloss**, and so on).

[Word List Concordance overview](Word_List_Concordance/Word_List_Concordance_overview.md) has more information.
