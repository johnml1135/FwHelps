# Delete an analysis

*Using Tools › Texts & Words tools › Word Analyses*

1.  On the **Navigation Pane**, click **Texts & Words**, and then click **Word** **Analyses**.

2.  In the **Wordforms** pane, click the wordform for which you want to delete an analysis.

3.  In the **Wordform Analyses** pane, click the heading label for the area that currently holds the analysis you want to delete. (That is, click a label that reads: **Analysis 1**, **Analyses Candidate 1**, **Test Case 1**, and so on.)

    A menu button (![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Word_Analyses/Menu_Button_pic.GIF)) appears.

4.  Do one of the following:

    - Click the menu button, and then select **Delete Analysis**, **Delete Candidate**, or **Delete Disapproved Analysis**.

    - Right-click the label, and then select **Delete Analysis**, **Delete Candidate**, or **Delete Disapproved Analysis** on the menu.

    The **Delete Analysis** warning box appears, specifying the analysis you selected for deletion.

5.  If you are certain that you want to delete the analysis specified in the warning box, click **Delete**.

> [!TIP]
>
> - The analysis may be recreated the next time the parser runs.
