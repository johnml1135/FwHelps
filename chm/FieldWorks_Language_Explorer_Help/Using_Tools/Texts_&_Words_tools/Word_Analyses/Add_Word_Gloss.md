# Add Word Gloss

*Using Tools › Texts & Words tools › Word Analyses*

In **Word Analyses**, you can add word glosses for wordforms for which the user opinion is set to **Approved**, that is, analyses in the **User Approved (Analyses)** area.

1.  On the **Navigation Pane**, click **Texts & Words**, and then click **Word** **Analyses**.

2.  In the **Wordforms** pane, click the wordform in which you want to add a word gloss.

3.  In the **Wordform Analyses** pane, click the heading label for the area that currently holds the analysis to which you will insert a word gloss. (That is, click a label that reads **Analysis 1**, **Analyses 2**, and so on.)

    A menu button (![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Word_Analyses/Menu_Button_pic.GIF)) appears.

4.  Do one of the following:

    - Click the menu button, and then click **Add Word Gloss**.

    - Right-click the label (**Analysis 1**, **Analyses 2**, and so on), and then select **Add Word Gloss**.

    A **Word Gloss** field appears near the bottom of that analysis.

5.  Click the new [Word Gloss field](../../../User_Interface/Field_Descriptions/Texts_%26_Words/Word_Gloss_field.md), and then type (or paste) the new gloss. If necessary [change the writing systems](writing_sys_word_gloss.md) displayed in the field.
