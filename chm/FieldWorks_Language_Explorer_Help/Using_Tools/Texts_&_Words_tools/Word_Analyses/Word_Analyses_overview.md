# Word Analyses overview

*Using Tools › Texts & Words tools › Word Analyses*

**Word Analyses** is in the [Navigation Pane](../../../User_Interface/Toolbars/Navigation/Navigation_Pane_graphic.md) when [Texts & Words](../Texts_and_Words_overview.md) is selected.

- The **Wordforms** pane displays the [word list](../Word_list_overview.md).

- The **Wordform Analyses** pane shows the current word, the current spelling status for the word, and all the analyses of the word (grouped by user opinion). Only **User Approved** analyses can be assigned to occurrences of a word. **Spelling Status** determines whether a word is in the spelling dictionary for the default vernacular writing system, but does not affect the analyses for the word.

- In the **Analysis** field for **User Approved** analyses, you can accomplish *a limited number* of changes. These changes are similar to changing the analysis while [analyzing](../Interlinear_Texts/Analyze_Text_overview.md) the text. Here, the word focus box appears with different colors, but it functions like one in **Analyze** tabs.
