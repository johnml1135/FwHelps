# Merge word gloss

*Using Tools › Texts & Words tools › Word Analyses*

The **Merge Gloss** feature is available only when the current analysis has more than one [Word Gloss](../../../User_Interface/Field_Descriptions/Texts_&_Words/Word_Gloss_field.md) field. (You can [add](Add_Word_Gloss.md) any number of **Word Gloss** fields for a single analysis.) You cannot merge across different analyses.

1.  On the **Navigation Pane**, click **Texts & Words**, and then click **Word** **Analyses**.

2.  In the **Wordforms** pane, click the wordform that has word glosses that you want to merge.

3.  In the **Wordform Analyses** pane, click the **Word Gloss** field label for the word gloss you want to merge *into another* word gloss.

    A menu button (![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Word_Analyses/Menu_Button_pic.GIF)) appears.

4.  Do one of the following:

    - Click the menu button, and then select **Merge Gloss**.

    - Right-click the **Word Gloss** label for the gloss you want to merge into another gloss, and then select **Merge Gloss** on the menu that appears.

    The **Merge Word Gloss** dialog box appears.

5.  In the **Glosses** area, click the word gloss into which you want to merge the selected word gloss.

    The information area near the bottom of the dialog box shows the word glosses and the merge direction.

6.  If you are sure you want to merge as indicated in the information area, click **Merge**.

    The merged word gloss is added after the gloss in the receiving field. This happens for each line with content (in the case that multiple writing systems are used, as these are [single-line text](../../../User_Interface/Field_Descriptions/Field_Types/Single_line_text_field.md) fields.)
