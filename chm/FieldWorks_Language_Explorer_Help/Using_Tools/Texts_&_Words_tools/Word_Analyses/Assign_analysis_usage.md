# Assign analysis usage

*Using Tools › Texts & Words tools › Word Analyses*

For a wordform selected in the **Words** area, you can use the **Analysis** **Usage** dialog box to select an *analysis* and see a concordance listing all the *occurrences* of that wordform which use the selected analysis. Then, you can assign a different analysis to one or more of those occurrences.

1.  On the **Navigation Pane**, click **Texts & Words**, and then click **Word Analyses**.

2.  In the **Wordforms** pane, click the wordform for which you want to show the analysis concordance.

    - Alternatively, if you see a yellow [background color](../Interlinear_Texts/interlinear_views_colors.md) in an interlinear view, the yellow background indicates ambiguity. You can right-click the data with the yellow background, and then click **Show in Word Analyses**. Then, the analysis with ambiguity is in focus.

3.  In the **Wordform Analyses** pane, do one of the following:

    - Click the **Assign Analysis** link at the top right corner of the window (right of the selected wordform).

    - Click the **Analysis** area label (**Analysis 1**, **Analysis 2:** and so on), for a particular analysis, and then click the **Assign Analysis** link that appears to the right of the label.

    - Click the **Analysis** area label for a particular analysis. Click the menu button ![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Word_Analyses/Menu_Button_pic.GIF) that appears, and then click **Assign Analysis**. (Alternatively, you can right-click the label to open the menu.)

    The **Analysis Usage** dialog box appears. The selection in box **1** (top left corner) may be **no analysis** or a particular analysis, depending on how you accessed the dialog box. The analyses for the current wordform are listed, followed by the word gloss, if any. You may need to click the ![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Word_Analyses/Plus_box_pic.GIF) boxes to expand the hierarchical tree so you can see [all the analyses in box 1](Analysis_Usage_box_details.md).

4.  In box **1**, if necessary, select **no analysis**, a particular analysis (**Analysis 1**, **Analysis 2**, and so on), or a word gloss. Then look in box **2** (bottom box) to see any occurrences of the wordform that use that analysis.

5.  In box **2**, if one or more displayed occurrences of the wordform should not have that analysis, do the following:

    - Click the empty check box to select each occurrence to which you want to assign a different analysis.

      Alternatively, to clear *all* displayed check boxes, click the check box button ![](../../../assets/images/Using_Tools/Texts_&_Words_tools/Word_Analyses/Check_Box_Button.GIF), and then click **Clear All**. To select *all* displayed check boxes, chick the check box button and then click **Select All**. To *reverse* selected/cleared check boxes, click the check box button and then click **Toggle**.

    - In box **3**, click the analysis you want to assign to the occurrences selected in box **2**, or to remove the analysis from those occurrences, click **no analysis**.

    - Click **Assign**.

    The following changes happen:

    - The analysis selected in box **3** is applied to each occurrence with a check mark in box **2**.

    - Those occurrences disappear from view in box **2** as they no longer use the analysis selected in box **1**.

    - In some cases in **Gloss** or **Analyze** [tabs](../Interlinear_Texts/Analyze_Text_overview.md) ([Interlinear Texts](../Interlinear_Texts/texts_edit_overview.md) *or* [Concordance](../Concordance/Concordance_overview.md)), you may see different [background colors](../Interlinear_Texts/interlinear_views_colors.md).

6.  Repeat the above steps, if necessary, until each occurrence of the wordform has the desired analysis assigned to it.

7.  Click **Close**. Then, if necessary, select another wordform in the **Wordforms** pane, and then repeat the steps in this topic.

> [!TIP]
>
> - If you click in box **1** on the analysis you just assigned something to, your change will not show up until you close the dialog box and come back to it. Even though it looks like nothing changed, your changes have indeed been applied.
