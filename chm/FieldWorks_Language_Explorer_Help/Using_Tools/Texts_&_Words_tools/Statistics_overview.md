# Statistics overview

*Using Tools › Texts & Words tools*

In the Navigation pane, click **Texts & Words** and then click **Statistics**.

For the text or texts you have [chosen to display](../../Basic_Tasks/Filtering_data/Choose_Texts.md), the **Texts & Words Statistics** display includes the following numerical values:

- **Total number of unique words (types)**\
  This is the sum of the *unique* words in these writing systems:

  - default vernacular writing system

  - other vernacular writing system(s)\

- **Total word count (tokens)**\
  This is the sum of all instances of words in these writing systems:

  - default vernacular writing system

  - other vernacular writing system(s)\

- **Total number of sentences (segments)**

## Copy/Paste

Use [shortcut keys](../../User_Interface/Shortcuts/shortcut_keys_overview.md) to select (`Ctrl+A`), copy (`Ctrl+C`, or use the right-click menu command), and paste (`Ctrl+V`) to copy the **Statistics** data into a different file. The data are separated by tabs, so you can paste them into spreadsheets.

The **Edit** menu commands are not available when **Statistics** is displayed.
