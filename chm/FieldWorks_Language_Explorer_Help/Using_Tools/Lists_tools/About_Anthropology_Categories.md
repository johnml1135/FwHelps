# About Anthropology Categories

*Using Tools › Lists tools*

When you [create a new FieldWorks project](../../User_Interface/Menus/File/Create_a_new_Fieldworks_project.md), select (![](../../assets/images/SelectedRadioButton.png)) one of these options:

- **Enhanced Outline of Cultural Materials (OCM)** — selected by default.

It has *Framework for Research and Methodology in Ethnography* (FRAME). FRAME is a top-level classification system which simplifies access to OCM categories.\
Example: **![](../../assets/images/Plus_sign_box.GIF) SL - Social Life and Identity**

Also, some OCM categories are expanded with *subcategories*.\
Example: **![](../../assets/images/Plus_sign_box.GIF) 5331 - Music Subcategories**

- **Standard OCM anthropology categories** — select if you do not need FRAME or the subcategories.

The *Outline of Cultural Materials* (OCM) **is a standard system for classifying cultural data.\
Example: **533 Music**

- **Create my own set of anthropology categories (create an empty list)** — select if you will *never* need any OCM categories and prefer to [insert](Insert_a_list_item.md) your own list items.

> [!NOTE]
>
> - OCM is owned by Human Relations Area Files, Inc. (HRAF). See Also:
>
> <a href="https://hraf.yale.edu/resources/reference/outline-of-cultural-materials/" target="_blank" title="https://hraf.yale.edu/resources/reference/outline-of-cultural-materials/">https://hraf.yale.edu/resources/reference/outline-of-cultural-materials/</a>
>
> - FRAME and subcategories are SIL extensions; not part of the OCM.
>
> - You *cannot* change your selection after the project is created.
