# Delete a custom list

*Using Tools › Lists tools*

1.  In the **Navigation** **Pane**, click **Lists**, and then click the [custom list](Insert_a_custom_list.md) you want to delete.

2.  On the [Edit](../../User_Interface/Menus/Edit/Edit_overview.md) menu, click **Delete Custom List**.

    If one or more items stored in the custom list are used in any [list reference fields](../../User_Interface/Field_Descriptions/Field_Types/List_reference_field.md), a **Warning** box appears.

<!-- -->

1.  - If you are sure you want to delete the list, and references to the list, click **Yes**.

> [!NOTE]
>
> - If you have a custom field that use items from the custom list, that custom field is also deleted when you delete the custom list.
>
> - You *cannot* delete the lists that were installed with FieldWorks.
