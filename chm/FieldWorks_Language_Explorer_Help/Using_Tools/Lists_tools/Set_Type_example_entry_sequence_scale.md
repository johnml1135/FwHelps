# Set Type example - Entry Sequence/Scale

*Using Tools › Lists tools*

In this example, the lexical relation **Name** is "`Days of week`" and its **Abbreviation** is "`days`." The abbreviation appears in the dictionary entry followed by the days of the week in order.

> [!TIP]
>
> - **Sequence/Scale** types do *not* use content from the **Reverse Name** and **Reverse Abbreviation** fields.
>
> - When you create this lexical relation, the *current* entry is automatically inserted into the sequence.
>
> - To [move an entry a sequence](../Lexicon_tools/Lexicon_Edit/move_sequence_entry.md) (reorder), you can right-click an item in the **Lexical Relations** area and select **Move Left** or **Move Right**.
>
> - If you selected the "**Sense sequence/scale**" mapping type, the results would appear with the days following the definition, for example:
>
> |  |  |
> |----|----|
> |  | **Monday** *N.* the second day of the week. *days:* **Sunday**, **Monday**, **Tuesday**, **Wednesday**, **Thursday**, **Friday**, **Saturday**.) |
