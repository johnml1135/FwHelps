# About entry types

*Using Tools › Lists tools*

Language Explorer (FLEx) versions up to and including version 5.4.1 used an **Entry Types** list to specify the entry type of lexical entries. In subsequent versions, [Complex Form Types](About_complex_forms.md) and [Variant Types](About_Variants.md) lists replaced the **Entry Types** and **Variant Condition** lists.

The table below describes the complex form types and variant form types that are supplied with FLEx. You can add any number of additional custom types and subtypes in [Lists](Lists_overview.md).

|  |  |
|----|----|
| **Complex Form Type** | **Description** |
| **Compound** | A stem that is made up of more than one root. |
| **Contraction** | A combination of two lexemes that are phonologically reduced ([more](../../User_Interface/Field_Descriptions/Lists/Complex_Form_Types_flds/Contraction.md)). |
| **Derivation** | A stem that is made up of a root plus at least one affix that adds a non-inflectional component of meaning ([more](../../User_Interface/Field_Descriptions/Lists/Complex_Form_Types_flds/Derivation.md)). |
| **Idiom** | A multi-word expression (MWE) or "lexical phrase" that is recognized as a semantic unit ([more](../../User_Interface/Field_Descriptions/Lists/Complex_Form_Types_flds/Idiom_entry_type.md)). |
| **Phrasal Verb** | A combination of a lexical verb and a verbal particle that forms a single semantic and syntactic unit ([more](../../User_Interface/Field_Descriptions/Lists/Complex_Form_Types_flds/Phrasal_verb.md)). |
| **Saying** | Any pithy phrasal expression of wisdom or truth; such as an adage, proverb, or maxim. |
| **Unspecified Complex Form** | This is the default type or the type you need to [choose](../Lexicon_tools/Lexicon_Edit/Choose_Complex_Form_Type.md) if you do not know which specific type to choose. |
