# Feature Types overview

*Using Tools › Lists tools › Feature Types*

**Feature Types** are used by [complex features](../../Grammar_tools/Inflection_Features/About_Infl_Features_and_Types.md). Typically, if you use the [Morphosyntactic Gloss Assistant](../../Lexicon_tools/Lexicon_Edit/Using_Morphosyntactic_Gloss_Assistant.md) when you create an entry, or if you use the [Add Inflection Feature from Catalog](../../Grammar_tools/Inflection_Features/Insert_a_Feature_or_Complex_Feature.md) dialog box, the appropriate *feature type* is automatically created. However, you can manually insert and delete feature types.

> [!IMPORTANT]
>
> - It is *strongly recommended* that you [contact](../../../Overview/Technical_support.md) a FLEx consultant before you overtly add or edit features or feature types. If these are not handled correctly, the [parsers](../../../User_Interface/Menus/Parser/Parsing_words_overview.md) may not analyze many of your word forms.
>
> The **Feature Types** Help topics are the following:
>
> [Insert a Feature Type](Insert_a_Feature_Type.md)
>
> [Delete a Feature Type](Delete_a_Feature_Type.md)
