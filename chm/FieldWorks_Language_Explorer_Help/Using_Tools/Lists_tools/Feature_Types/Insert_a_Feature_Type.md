# Insert a Feature Type

*Using Tools › Lists tools › Feature Types*

1.  In the **Navigation** **Pane**, click **Lists**, and then select **Feature Types**.

2.  Do one of the following:

    - On the [Insert](../../../User_Interface/Toolbars/Insert_toolbar.md) toolbar, click ![](../../../assets/images/Using_Tools/Lists_tools/Feature_Types/Insert_list_item_Lists.GIF).

    - On the **Insert** menu, click **Feature Type**.

    An empty set of fields appears in the **Feature Type** pane.

3.  In the **Feature Type** pane, enter the name, abbreviation, and description.

4.  Click the **Features** field, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG).

    The **Choose Features** dialog box appears.

5.  Select the applicable feature(s), and then click **OK**.

> [!IMPORTANT]
>
> - It is *strongly recommended* that you [contact](../../../Overview/Technical_support.md) a FLEx consultant before you overtly add or edit features or feature types. If these are not handled correctly, the parser may not analyze many of your word forms.
