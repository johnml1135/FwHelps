# Delete a Feature Type

*Using Tools › Lists tools › Feature Types*

1.  In the **Navigation** **Pane**, click **Lists**, and then select **Feature Types**.

2.  In the **Feature Types** column, click the feature type you will delete, and then do one of the following:

    - On the [Standard](../../../User_Interface/Toolbars/Standard_toolbar.md) toolbar, click ![](../../../assets/images/Using_Tools/Lists_tools/Feature_Types/RedDeleteRecordX.GIF).

    - On the **Edit** menu, click **Delete Feature Type**.

    - Right click the feature type, and then click **Delete selected Feature Type**.

    The **Delete Feature Type** warning box appears and asks if want to continue with the deletion.

3.  If you are sure you want to delete the feature type specified in the warning box, click **Delete**.

    The specified feature type is deleted.

> [!IMPORTANT]
>
> - It is *strongly recommended* that you [contact](../../../Overview/Technical_support.md) a FLEx consultant before you overtly add or edit features or feature types. If these are not handled correctly, the parser may not analyze many of your word forms.
