# Delete a question (Semantic Domain)

*Using Tools › Lists tools*

In **Collect Words** ([Lexicon](../Lexicon_tools/Lexicon_overview.md)), the **Semantic Domain** pane displays questions in [Question](../../User_Interface/Field_Descriptions/Lexicon/Collect_Words_fields/Question_Field_Collect_Words.md) fields. Each **Question** field has an associated [Example Words](../../User_Interface/Field_Descriptions/Lexicon/Collect_Words_fields/Example_Words_Field_Collect_words.md) field and [Example Sentences](../../User_Interface/Field_Descriptions/Lexicon/Collect_Words_fields/Example_Sentences_Field_Collect_Words.md) field. These help prompt the discussion that leads to a faster and more complete collection of vernacular words for the semantic domain.

Each question, example word and sentence is stored and edited in equivalent fields in **Lists**.

1.  In the **Navigation** **Pane**, click **Lists**, and then click **Semantic Domains**.

2.  In the center column, select the semantic domain or subdomain from which you will delete a question. If necessary, [search for the semantic domain](../Lexicon_tools/Collect_Words/Search_Semantic_Domains.md).

3.  In the **Semantic Domain** pane, *for the question you will delete*, do one of the following:

    - Right-click the [Question](../../User_Interface/Field_Descriptions/Lists/Semantic_Domains_fields/Question_field_Semantic_Domains.md) field label, and then click **Delete Question**.

    - Click the **Question** field label, click the menu button ![](../../assets/images/Using_Tools/Lists_tools/Menu_Button_pic.GIF) that appears, and then click **Delete Question**.

    A **Delete** **Question** warning box appears.

4.  If you are sure that you want to delete the current question, click **Delete**.

    The **Question** field and all associated [Example Words](../../User_Interface/Field_Descriptions/Lists/Semantic_Domains_fields/Example_Words_field_Semantic_Domains.md) and [Example Sentences](../../User_Interface/Field_Descriptions/Lists/Semantic_Domains_fields/Example_Sentences_field_Semantic_Domains.md) fields are deleted from the semantic domain. They are no longer displayed in **Collect Words** ([Lexicon](../Lexicon_tools/Lexicon_overview.md)).
