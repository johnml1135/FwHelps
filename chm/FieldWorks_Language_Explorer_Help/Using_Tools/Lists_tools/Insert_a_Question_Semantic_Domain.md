# Insert a question (Semantic Domain)

*Using Tools › Lists tools*

In **Collect Words** ([Lexicon](../Lexicon_tools/Lexicon_overview.md)), the **Semantic Domain** pane displays questions in [Question](../../User_Interface/Field_Descriptions/Lexicon/Collect_Words_fields/Question_Field_Collect_Words.md) fields. Each **Question** field has an associated [Example Words](../../User_Interface/Field_Descriptions/Lexicon/Collect_Words_fields/Example_Words_Field_Collect_words.md) field and [Example Sentences](../../User_Interface/Field_Descriptions/Lexicon/Collect_Words_fields/Example_Sentences_Field_Collect_Words.md) field. These help prompt the discussion that leads to a faster and more complete collection of vernacular words for the semantic domain.

Each question, example word and sentence is stored and edited in equivalent fields in **Lists**.

1.  In the **Navigation** **Pane**, click **Lists**, and then click **Semantic Domains**.

2.  In the center column, select the existing *semantic domain* or *subdomain* into which you want to insert a question, example word or example sentence. If necessary, [search for the semantic domain](../Lexicon_tools/Collect_Words/Search_Semantic_Domains.md).

3.  In the **Semantic Domain** pane, do one of the following:

    - Right-click the [Questions](../../User_Interface/Field_Descriptions/Lists/Semantic_Domains_fields/Questions_field_Semantic_Domains.md) field label, and then click **Insert Question**.

    - Click the **Questions** label, click the menu button ![](../../assets/images/Using_Tools/Lists_tools/Menu_Button_pic.GIF) that appears, and then click **Insert Question**.

    A new **Question** field set is added below existing sets.

4.  In the [Question](../../User_Interface/Field_Descriptions/Lists/Semantic_Domains_fields/Question_field_Semantic_Domains.md) field, enter a question.

5.  If desired, in the [Example Words](../../User_Interface/Field_Descriptions/Lists/Semantic_Domains_fields/Example_Words_field_Semantic_Domains.md) field, enter sample words.

6.  If desired, in the [Example Sentences](../../User_Interface/Field_Descriptions/Lists/Semantic_Domains_fields/Example_Sentences_field_Semantic_Domains.md) field, enter sample sentences.

> [!TIP]
>
> - It is recommended that you number the questions. To do this, simple type a number and any symbols you want to use. For example, "(1) Which words refer to…."
