# Change the tokens for morpheme types

*Using Tools › Lists tools*

For [morpheme types](About_Morpheme_Types.md), you can change the symbols specified in the **Leading Token** field and **Trailing Token** field. These tokens are used, for example, in the [New Entry](../Lexicon_tools/Lexicon_Edit/Create_a_lexical_entry.md) dialog box. Of course, you can delete them if the use of a token is not desired or is incorrect.

1.  In the **Navigation** **Pane**, click **Lists**, and then click **Morpheme Types**.

2.  In the center pane, select a morpheme type for which you will change a token.

3.  In the **Morpheme Type** pane, change the symbol in the [Leading Token](../../User_Interface/Field_Descriptions/Lists/Morpheme_Types_fields/leading_token_field_morpheme_types.md) field or [Trailing Token](../../User_Interface/Field_Descriptions/Lists/Morpheme_Types_fields/trailing_token_field_morpheme_types.md) field.

4.  Repeat the last two steps until each morpheme type has the desired token in each field.

> [!TIP]
>
> - The token changes are also reflected in the [Insert Morpheme Breaks](../Texts_&_Words_tools/Interlinear_Texts/Insert_or_remove_morpheme_breaks.md) dialog box.
>
> - You can access the [Character Map](../../User_Interface/Menus/Insert/Using_Character_Map.md) dialog box from the **Insert** menu so you can find other characters for use as tokens.
