> [!NOTE]
>
> - In **Lists**, **Reversal Index Categories** stores the list of grammatical categories used *only* with [Reversal Indexes](../Lexicon_tools/Reversal_Indexes/reversal_indexes_overview.md). It is *not* the same list of grammatical categories, located in the [Grammar](../Grammar_tools/Category_Edit/Category_Edit_overview.md) area, which is used for the vernacular lexical entries. However, you choose categories for both from the same catalog. For more information, refer to [About Reversal Index Categories](about_reversal_index_categories.md).
