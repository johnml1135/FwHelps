# Create new Lexical Relations

*Using Tools › Lists tools*

1.  In the **Navigation** **Pane**, click **Lists**, and then click **Lexical Relations**.

2.  Do one of the following:

    - On the [Insert](../../User_Interface/Toolbars/Insert_toolbar.md) toolbar, click ![](../../assets/images/Using_Tools/Lists_tools/Insert_list_item_Lists.GIF).

    - On the **Insert** menu, click **Lexical** **Relation**.

    A new lexical relation type is added with empty fields.

3.  In the **Lexical Relation** pane, enter a name in the [Name field](../../User_Interface/Field_Descriptions/Lists/Lexical_Relations_fields/name_field_lexical_relations.md) and an abbreviation in the [Abbreviation field](../../User_Interface/Field_Descriptions/Lists/Lexical_Relations_fields/abbreviation_field_lexical_relations.md).

4.  In the [Reference set type field](../../User_Interface/Field_Descriptions/Lists/Lexical_Relations_fields/reference_set_type_field.md), select the appropriate [set type](About_reference_set_types.md).

5.  If the set type uses *two names*, enter a **Reverse Name** and **Reverse Abbreviation**. (For example, a type named **Parts** would have a reverse name of **Whole**.)

6.  Enter content in the **Description** and **Discussion** fields.
