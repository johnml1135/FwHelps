# Set Type example - Entry Collection

*Using Tools › Lists tools*

In this example, the lexical relation **Name** is "`Compare`" and its **Abbreviation** is "`cf`." The *abbreviation* can appear in the dictionary entry followed by the other entries in the collection.

<table width="100%">
<tbody>
<tr>
<td><h3 id="sample-entries"><strong>Sample entries:</strong></h3></td>
</tr>
<tr>
<td><p><strong>chauffeur</strong> <em>cf:</em> <strong>driver</strong>, <strong>pilot</strong> <em>N.</em> A person employed to drive a motor vehicle.</p></td>
</tr>
<tr>
<td><p><strong>driver</strong> <em>cf:</em> <strong>chauffeur</strong>, <strong>pilot</strong> <em>N.</em> An operator of a motor vehicle, particularly a car.</p></td>
</tr>
<tr>
<td><p><strong>pilot</strong> <em>cf:</em> <strong>chauffeur</strong>, <strong>driver</strong> <em>N.</em> A person who flies or is qualified to fly an aircraft.</p></td>
</tr>
</tbody>
</table>

> [!NOTE]
>
> - **Entry Collections** do *not* use content from the **Reverse Name** and **Reverse Abbreviation** fields.
