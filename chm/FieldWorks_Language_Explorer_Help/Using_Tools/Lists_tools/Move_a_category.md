# Move a category

*Using Tools › Lists tools*

In the [Reversal Index Categories](about_reversal_index_categories.md) list, you can move a category or subcategory to another category. The category or subcategory you move becomes a subcategory of the category or subcategory that "receives" it.

1.  In the **Navigation** **Pane**, click **Lists**, and then click **Reversal Index Categories**.

2.  In the **Categories (or Parts of Speech)** pane, use the menu button ![](../../assets/images/Using_Tools/Lists_tools/Information_bar_Menu_button.PNG) on the [Information bar](../../User_Interface/Toolbars/information_bar_overview.md) to select the reversal index list that has the category or subcategory you will move.

3.  In the **Categories (or Parts of Speech)** pane, click the category you want to move, or the category that has the subcategory you want to move.

4.  In the **Category (or Part of Speech)** pane, click the **Name** field label for the category or subcategory you will move.

    A menu button (![](../../assets/images/Using_Tools/Lists_tools/Menu_Button_pic.GIF)) appears.

5.  Click the menu button, and then select **Move Category**.

    The **Choose category to move** **to** dialog box appears.

6.  Select the category into which you want to move the current category or subcategory, and then click **OK**.

    The category or subcategory you initially selected is moved to the category or subcategory selected in the dialog box.

    The drop-down list in the [Reversal Category](../../User_Interface/Field_Descriptions/Lexicon/Reversal_Indexes_fields/category_field.md) field automatically updates, although if you have multiple windows open you may need to refresh the windows **(F5**) to see it.

7.  If necessary, [promote](Promote_or_Demote_a_list_item.md) or move the category or subcategory again to make sure it is at the correct hierarchical level.

> [!TIP]
>
> - Normally, with the [Add from catalog](../Lexicon_tools/Lexicon_Edit/Using_Add_from_Catalog_dialog_box.md) dialog box you would insert a category (such as *Verb*) and *then* insert any subcategories (such as *Transitive* *verb*) to maintain that predefined hierarchy. However, if you inadvertently insert a subcategory such that it appears as a category, you can move that subcategory under the category to restore the hierarchy.
