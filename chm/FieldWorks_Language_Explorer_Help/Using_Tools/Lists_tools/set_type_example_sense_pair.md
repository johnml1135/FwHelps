# Set Type example – Sense Pair

*Using Tools › Lists tools*

### Example 1 Sense pair – one name: "Antonym"

In this example, the lexical relation **Name** is "`Antonym`" and **Abbreviation** is "`ant`." The **Reverse Name** and the **Reverse Abbreviation** are *not* used. The abbreviation can appear in the two dictionary entries, each followed by the antonym.

<table width="100%">
<tbody>
<tr>
<td style="width: 100%"><h3 id="sample-entries"><strong>Sample entries:</strong></h3></td>
</tr>
<tr>
<td style="width: 100%"><p><strong>cold</strong> <em>Adj.</em> having a low temperature. <em>ant:</em> <strong>hot</strong>.</p></td>
</tr>
<tr>
<td style="width: 100%"><p><strong>hot</strong> <em>Adj.</em> having a high temperature; having or giving off heat. <em>ant:</em> <strong>cold</strong>.</p></td>
</tr>
</tbody>
</table>

### Example 2 Sense pair – two relational names: "Operator/Vehicle"

In this example, the lexical relation **Name** is "`Operator`" and **Abbreviation** is "`oper`." The **Reverse Name** is "`Vehicle`" and the **Reverse Abbreviation** is "`veh`."

<table width="100%">
<tbody>
<tr>
<td style="width: 100%"><h3 id="sample-entries-1"><strong>Sample entries:</strong></h3></td>
</tr>
<tr>
<td style="width: 100%"><p><strong>airplane</strong> <em>N.</em> a powered heavier-than-air vehicle with fixed wings. <em>oper:</em> <strong>pilot</strong>.</p></td>
</tr>
<tr>
<td style="width: 100%"><p><strong>pilot</strong> <em>N.</em> a person who flies or is qualified to fly an airplane. <em>veh:</em> <strong>airplane</strong>.</p></td>
</tr>
</tbody>
</table>

> [!IMPORTANT]
>
> - To ensure the proper relational *direction* for reference set types with *two* names (**Name** and **Reverse Name**) begin with the name (here "operator") and add to it the reverse name (here "vehicle").
>
>   In particular, in a sense, when you right-click the **Lexical Relations** label to add the relation, the text in the menu command reflects the available lexical relations. In Example 2 above, the right-click menu reads, "**Insert Operator Relation (to this Vehicle)**."
>
>   You can swap the **Name** and **Abbreviation** with the **Reverse Name** and **Reverse Abbreviation** in [Lists](Lists_overview.md) to reverse the relationship.
