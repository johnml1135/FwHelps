# Delete a list item

*Using Tools › Lists tools*

It is recommended that you [back up](../../User_Interface/Menus/File/Backup_and_Restore/Back_up_this_Project.md) the project before you delete any **Lists** area list items that may be used throughout the project.

In this topic, the term *\<list* *item\>* includes a category, domain, level, person, type, and so on.

1.  In the **Navigation** **Pane**, click **Lists**, and then click the list from which you will delete a list item.

2.  In the center column, select the list item that you will delete.

3.  Do one of the following:

    - On the [Standard](../../User_Interface/Toolbars/Standard_toolbar.md) toolbar, click ![](../../assets/images/Using_Tools/Lists_tools/RedDeleteRecordX.GIF).

    - On the **Edit** menu, click **Delete** *\<list item\>*.

    The **Delete** *\<list item\>* warning box appears.

4.  If you are sure you want to delete the list item specified in the warning box, click **Delete**.

    The list item *and any subitems* specified in the warning box are deleted.

> [!IMPORTANT]
>
> - In some lists, the center column has a name, such as **Categories (or Parts of Speech)** for the **Reversal Index Categories** list. For other lists, the center column has *no name*.
>
> - You cannot add or delete items in the **Morpheme Types** list.
>
> - You can delete only **Complex Form Types** that you added.
>
> - You cannot delete items from the **Text Constituent Chart Template** if any [Text Chart](../Texts_%26_Words_tools/Interlinear_Texts/Text_Chart_tab/Text_chart_overview.md) tab contains any data in the associated column.
