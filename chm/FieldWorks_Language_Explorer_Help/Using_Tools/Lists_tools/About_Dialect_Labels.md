# About Dialect Labels

*Using Tools › Lists tools*

When you use a single vernacular writing system for all dialects, you can mark entries or senses to indicate which dialects they represent.\
To do this, you [insert](Insert_a_list_item.md) dialects as list items in the **Dialect Labels** [list](List_item_usage_table.md). Then, [choose](../Lexicon_tools/Lexicon_Edit/Choose_a_dialect_label.md) these list items in **Dialect Labels (Entry)** and **Dialect Labels (Sense)** fields in **Lexicon Edit**.

However, if you use a writing system for a dominant dialect and want to include lexeme forms that are approximately equivalent in other dialects, you should use different writing systems for each dialect. To distinguish the writing systems you [add](../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/Add_a_new_writing_system.md), choose different [regional](../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Writing_System_Properties_General_tab.md) information.
