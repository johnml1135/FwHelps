# Set Type example – Entry Tree

*Using Tools › Lists tools*

In this example, the lexical relation is as follows:

- **Name** is "`Specific`" and its **Abbreviation** is "`spec`"

- **Reverse Name** is "`Generic`" and its **Reverse Abbreviation** is "`gen`"

> [!IMPORTANT]
>
> - Each **Entry Tree** uses two names: **Name** and **Reversal Name**.
>
> - To ensure the proper relational *direction* for reference set types with two names, begin in the root entry (here "Generic") and add to it the leaves (here "Specifics").
>
>   In particular, when you right-click the **Lexical Relations** label in a sense to add the relation, the text in the menu command reflects the available lexical relations. In this example, the right-click menu reads "**Insert Specific Relation (to this Generic)**."
>
>   You can swap the **Name** and **Abbreviation** with the **Reverse Name** and **Reverse Abbreviation** in [Lists area](Lists_overview.md) to reverse the root/leaves relationship.
