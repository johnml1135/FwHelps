# Insert a list item

*Using Tools › Lists tools*

In this topic, the terms *item* and *subitem* include category, domain and so on. The [list items usage table](List_item_usage_table.md) indicates that there are various lists and uses for those lists. However, the steps are similar. See ![](../../assets/images/Important_Icon.gif) **Important** below.

## Lists except Reversal Index Categories

1.  In the **Navigation** **Pane**, click **Lists**, and then click the desired list.

2.  If the list is hierarchical, in the center pane select an existing list item that is at the hierarchical level you want for the new item. **See** ![](../../assets/images/Important_Icon.gif) **Important** below.

3.  Do *one* of the following:

    - On the [Insert](../../User_Interface/Toolbars/Insert_toolbar.md) toolbar, click ![](../../assets/images/Using_Tools/Lists_tools/Insert_list_item_Lists.GIF).

    - On the **Insert** menu, click *\<**item name\>* (**Academic Domain**, **Anthropology Category** and so on).

4.  A new list item is added, with empty fields. It may appear as a **\*\*\*.\*\*\*** or as **\*\*\*** in the center column because it does not yet have a name or abbreviation.

    Refresh the screen (`F5`) if the center column does not show your list item name.

5.  Enter or [choose](choose_item_for_list_field.md) content for the fields as necessary.

## Reversal Index Categories

1.  In the **Navigation** **Pane**, click **Lists**, and then select **Reversal Index Categories**.

2.  Click the [Information bar](../../User_Interface/Toolbars/information_bar_overview.md) menu button ![](../../assets/images/Using_Tools/Lists_tools/Information_bar_Menu_button.PNG) in the **Categories (or Parts of Speech)** pane, and then select the reversal index into which you will insert the subcategory. **See:** [About Reversal Index Categories](about_reversal_index_categories.md).

3.  Do *one* of the following:

    - On the [Insert](../../User_Interface/Toolbars/Insert_toolbar.md) toolbar, click ![](../../assets/images/Using_Tools/Lists_tools/Insert_list_item_Lists.GIF).

    - On the **Insert** menu, click **Category**.

4.  Use the [Add from Catalog](../Lexicon_tools/Lexicon_Edit/Using_Add_from_Catalog_dialog_box.md) dialog box that appears to select the category.

> [!IMPORTANT]
>
> - If you insert a list item, it is inserted at the *same* level as the currently selected item or subitem.
>
> - If you [insert](Insert_a_list_subitem.md) a list subitem, it is inserted one hierarchical level *below* the currently selected item or subitem.
>
> - You *cannot* insert any new **Morpheme Types**. You can [change the leading or trailing token](Change_the_tokens_for_morpheme_types.md), or [change the secondary sort order](Change_the_secondary_sort_order.md).
>
> - For **Lexical Relations**, refer to [Create new Lexical Relations](Create_new_Lexical_Relations.md), [About Lexical Relations](About_Lexical_Relations.md) or [About Reference set types](About_reference_set_types.md) for help with this list.
