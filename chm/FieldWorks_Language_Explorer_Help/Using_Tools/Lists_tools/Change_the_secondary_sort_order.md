# Change the secondary sort order

*Using Tools › Lists tools*

You can control the dictionary order of similar entries, such as `in`, `in-`, `-in`, `in=`, `=in` and `-in-`.

The numeric values in the [Secondary Order](../../User_Interface/Field_Descriptions/Lists/Morpheme_Types_fields/Secondary_Order_field_Morpheme_Types.md) fields (**Morpheme Types** list) controls this order. **See also:** [About morpheme types](About_Morpheme_Types.md).

1.  In the **Navigation** **Pane**, click **Lists**, and then click **Morpheme Types**.

2.  Make a written note of the existing numeric values for each morpheme type, in case you need to return to the current settings.

3.  Determine a new order and make a written note of that order, that is, record the desired numeric value for each morpheme type.

4.  In the center pane, select a morpheme type that does not currently have the desired secondary order value.

5.  In the **Morpheme Type** pane, change the value in the **Secondary Order** field.

6.  Repeat the last two steps until each morpheme type has the numerical value that reflects the desired order.

> [!TIP]
>
> - The [Sorting](../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Writing_System_Properties_Sorting_tab.md) tab (**Writing System Properties** dialog box) allows you to enter [collation rules](../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Collation_in_FieldWorks.md) that affect the *primary* sort order.
