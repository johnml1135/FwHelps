# Insert a custom list

*Using Tools › Lists tools*

In **Lists**, you can insert a custom list, and then insert list items and subitems into it. Use custom lists with [custom](../../User_Interface/Menus/Tools/Custom_Fields/Custom_Fields_overview.md) *list reference* fields.

Insert the custom list *before* you [add the custom field](../../User_Interface/Menus/Tools/Custom_Fields/add_a_custom_field.md).

1.  In the **Navigation** **Pane**, click **Lists**.

2.  On the **Insert** menu, click **Custom List**.

    The **New List** dialog box appears.

3.  Do the applicable steps in [Configure List](../../User_Interface/Menus/Tools/Configure_List.md).

4.  Do any of these steps:

    - [Insert list items](Insert_a_list_item.md)

    - [Insert list subitems](Insert_a_list_subitem.md)

    - [Edit a list item or subitem](Edit_a_list_item_or_subitem.md).
