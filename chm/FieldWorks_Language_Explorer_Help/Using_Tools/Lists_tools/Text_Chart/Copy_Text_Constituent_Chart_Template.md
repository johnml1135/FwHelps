# Copy a Text Constituent Chart Template

*Using Tools › Lists tools › Text Chart lists*

1.  In the **Navigation** **Pane**, click ![](../../../assets/images/User_Interface/Changing_toolbars_and_menus/ListsICON.png) **Lists**, and then click the **Text Constituent Chart Template** list.

<!-- -->

2.  In the center column, click *top* level of the template you want to copy. For example, click **Default** if you want to copy that template.

3.  On the [toolbar](../../../User_Interface/Toolbars/Insert_toolbar.md), click ![](../../../assets/images/User_Interface/Toolbars/CopyTemplate.png) (**Text Constituent Chart Template**).

A copy of the template is added to the list in the center column.

The copy has the same name with **(Copy) (**\#**)** appended to it.

4.  Click the *top* level of the template copy and then edit the [name](../../../User_Interface/Field_Descriptions/Lists/Text_Chart_Temp_fields/name_field_tctemp.md) and [abbreviation](../../../User_Interface/Field_Descriptions/Lists/Text_Chart_Temp_fields/abbreviation_field_tctemp.md) of the template.

5.  If necessary, [specify](specify_columns_for_chart.md) which columns you want to appear in the **Text Chart** tab.

6.  For each column group and column, make sure all the [fields](../../../User_Interface/Field_Descriptions/Lists/Text_Chart_Temp_fields/Text_Chart_Temp_flds_overview.md) that you want to contain metadata are complete and accurate.

> [!NOTE]
>
> - The *top* level is the name of the template.
>
>   - The second level is the name of a group of columns, if you will have groups of columns.\
>     Otherwise, the second level would be for columns.
>
>     - The third level is for columns, if you had groups of columns.
>
> <!-- -->
>
> - To help you learn which column groups and columns you might need, review [Default Text Chart tab columns](default_chart_columns.md)
