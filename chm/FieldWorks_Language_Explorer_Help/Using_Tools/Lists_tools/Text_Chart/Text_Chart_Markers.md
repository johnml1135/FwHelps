# Text Chart Markers

*Using Tools › Lists tools › Text Chart lists*

The [Text Chart tab](../../Texts_&_Words_tools/Interlinear_Texts/Text_Chart_tab/Text_chart_overview.md) allows you to chart texts.

In the **Lists** area, the **Text Chart Marker** list stores items you use when you mark grammatical information in the text chart.

Things you can do to the list of markers include any of the following:

- Insert a [list item](../Insert_a_list_item.md) or [subitem](../Insert_a_list_subitem.md)

- Delete a [list item](../Delete_a_list_item.md) or [subitem](../Delete_a_list_subitem.md)

- [Edit](../Edit_a_list_item_or_subitem.md) a marker name, abbreviation or its metadata

- [Promote or demote](../Promote_or_Demote_a_list_item.md) items

- Reorder markers: In the center pane, right-click an item or subitem, and then select `Move Up` or **Move Down**.
