# Add a new Text Constituent Chart Template

*Using Tools › Lists tools › Text Chart lists*

1.  If you are in ![](../../../assets/images/User_Interface/Changing_toolbars_and_menus/TextsWordsICON.png) **Texts & Words**, with the **Text Chart** tab displayed, do these steps:

    - Click the down arrow (![](../../../assets/images/Using_Tools/Lists_tools/Text_Chart/TextChartChooser.png)) that is near the *top* of the **Text Chart** tab, and then click **Add a New Template**.

    - Read the ![](../../Texts_&_Words_tools/Interlinear_Texts/Text_Chart_tab/InfoBoxTextWords.png) **Information** box contents, and then click **OK**.

The window changes to ![](../../../assets/images/User_Interface/Changing_toolbars_and_menus/ListsICON.png) **Lists**.

A new template is added to the **Text Constituent Chart Template** list.

2.  Otherwise, in the **Navigation** **Pane**, click ![](../../../assets/images/User_Interface/Changing_toolbars_and_menus/ListsICON.png) **Lists**. Then, click **Text Constituent Chart Template** in the **Lists** pane.

Do these steps to add a new template:

- In the center pane, click the *top* level of any existing template.

- Click ![](../../../assets/images/User_Interface/Toolbars/Insert_list_item_Lists.GIF) **Text Constituent Chart Template** on the [toolbar](../../../User_Interface/Toolbars/Insert_toolbar.md) or on the [Insert](../../../User_Interface/Menus/Insert/Insert_overview.md) menu.

3.  Do these steps to complete the new template:

- [Specify](specify_columns_for_chart.md) column groups (if any) and columns.

- Edit the [names](../../../User_Interface/Field_Descriptions/Lists/Text_Chart_Temp_fields/name_field_tctemp.md), type [abbreviations](../../../User_Interface/Field_Descriptions/Lists/Text_Chart_Temp_fields/abbreviation_field_tctemp.md), and add other information to distinguish this template, each column group and each column.

- Add content to other [fields](../../../User_Interface/Field_Descriptions/Lists/Text_Chart_Temp_fields/Text_Chart_Temp_flds_overview.md), as appropriate.

> [!TIP]
>
> - Newly added templates have the *top* level, one column group and two columns.
>
> - The *top* level is the name of the template.
>
>   - The second level is the name of a group of columns, if you will have groups of columns.\
>     Otherwise, the second level would be for columns.
>
>     - The third level is for columns, if you had groups of columns.
>
> <!-- -->
>
> - To help you learn which column groups and columns you might need, review [Default Text Chart tab columns](default_chart_columns.md).
>
> - You can Return to the **Text Chart** tab and then choose (![](../../../assets/images/Using_Tools/Lists_tools/Text_Chart/TextChartChooser.png)) the newly added template.
>
> - You can [Copy a Text Constituent Chart template](Copy_Text_Constituent_Chart_Template.md) and [specify columns](specify_columns_for_chart.md) using that copy.
