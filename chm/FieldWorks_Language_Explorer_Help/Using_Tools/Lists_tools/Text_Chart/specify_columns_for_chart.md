# Specify columns for Text Chart tab

*Using Tools › Lists tools › Text Chart lists*

The **Text Chart** tab appears in the **Texts** **&** **Words** area, but the chart columns are stored in the **Lists** area. [Default Text Chart columns](default_chart_columns.md) describes the **Default** template.

*Before* you work with text charts, examine the **Default** template. You can make any necessary changes. Or you can [copy](Copy_Text_Constituent_Chart_Template.md) it and change the copy or [add](Add_a_new_Text_Constituent_Chart_Template.md) a new template that you can finish.

Do this as follows:

1.  In the **Navigation** **Pane**, click **Lists**, and then click **Text Constituent Chart Templates**.

2.  In the center pane, expand the **Default** template, and then click the node (![](../../../assets/images/Using_Tools/Lists_tools/NodePlus.png)) to expand each column group to see the columns.

3.  Examine the column groups and columns, and then do any of these steps to change the default, [copy](Copy_Text_Constituent_Chart_Template.md) or [new](Add_a_new_Text_Constituent_Chart_Template.md) template:

> [!NOTE]
>
> - [Clear](../../Texts_&_Words_tools/Interlinear_Texts/Text_Chart_tab/clear_chart_from.md) *all* existing data from all charts before you reorder, promote or delete columns. Otherwise, Language Explore may prevent the changes to preserve the integrity of your charts. You can work with metadata in the [Text Constituents Chart fields](../../../User_Interface/Field_Descriptions/Lists/Text_Chart_Temp_fields/Text_Chart_Temp_flds_overview.md) while you have data in charts.
>
> - If you click ![](../../../assets/images/Using_Tools/Lists_tools/Text_Chart/Insert_list_item_Lists.GIF) on the toolbar, the new list item (group or column) is inserted at the *same level* as the current selection in the center column. If you click ![](../../../assets/images/Using_Tools/Lists_tools/Text_Chart/Insert_List_Subitem_Lists.GIF) on the toolbar, a subitem is inserted, *subordinate* to the current selection.
>
> - Depending on the version of FieldWorks, you might see **Default** or **Default Template**.
>
> - The top level is the name of the template.
>
>   - The second level is the name of a group of columns, if you will have groups of columns.\
>     Otherwise, the second level would be for columns.
>
>     - The third level is for columns, if you had groups of columns.
