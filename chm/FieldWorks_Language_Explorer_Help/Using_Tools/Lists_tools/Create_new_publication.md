# Create new publication

*Using Tools › Lists tools*

**See:** [What is a publication](../../User_Interface/Field_Descriptions/Lists/Publications/What_is_a_Publication.md). Then, do the following to create a new publication in the **Publications** list:

1.  In the **Navigation** **Pane**, click **Lists**, and then click **Publications**.

2.  Do one of the following:

    - On the [Insert](../../User_Interface/Toolbars/Insert_toolbar.md) toolbar, click ![](../../assets/images/Using_Tools/Lists_tools/Insert_list_item_Lists.GIF).

    - On the **Insert** menu, click **Publication**.

    A new publication is added with empty fields.

3.  In the **Publication** pane, enter a name in the [Name](../../User_Interface/Field_Descriptions/Lists/Publications/Name_field_(Publications).md) field.

4.  Enter an abbreviation in the [Abbreviation](../../User_Interface/Field_Descriptions/Lists/Publications/Abbreviation_field_(Publications).md) field, and appropriate content in the other [fields](../../User_Interface/Field_Descriptions/Lists/Publications/Publications_fields_overview.md).

> [!IMPORTANT]
>
> - Publications stored in the **Publications** [list](List_item_usage_table.md) are automatically displayed in *all* the **Publish** \<item\> **In** [fields](../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Lexicon_Edit_fields_overview.md) and in the [Show As Headword In](../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Publication_Settings_flds/Show_As_Headword_In_field.md) field (**Lexicon Edit**).
>
> There is a [Publish Entry In](../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Publication_Settings_flds/Publish_In_(Publication_Settings).md) field for the entire *entry*, a [Publish Pronunciation In](../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Publish_In_(Pronunciations).md) field for each *publication*, a [Publish Sense In](../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Publish_In_(Sense).md) field for each *sense*, a [Publish Example In](../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Publish_In_(Example).md) field for each *example,* and a [Publish Picture In](../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Publish_In_(Pictures).md) field for each picture.
>
> This means that all lexical entries, pronunciations, senses, examples and pictures are assumed to be publishable by default.
