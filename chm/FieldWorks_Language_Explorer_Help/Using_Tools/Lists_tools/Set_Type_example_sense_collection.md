# Set Type example - Sense Collection

*Using Tools › Lists tools*

In this example, the lexical relation **Name** is "`Synonyms`" and its **Abbreviation** is "`syn`." The abbreviation can appear in the dictionary entry followed by the synonymous senses in the collection.

<table width="100%">
<tbody>
<tr>
<td><h3 id="sample-entries"><strong>Sample entries:</strong></h3></td>
</tr>
<tr>
<td><p><strong>enormous</strong> <em>Adj</em><em>.</em> very great in size, extent, number, or degree. <em>syn</em>: <strong>gigantic</strong>, <strong>huge</strong></p></td>
</tr>
<tr>
<td><p><strong>gigantic</strong> <em>Adj</em><em>.</em> very large or extensive. <em>syn</em>: <strong>enormous</strong>, <strong>huge</strong></p></td>
</tr>
<tr>
<td><p><strong>huge</strong> <em>Adj</em><em>.</em> of exceedingly great size, extent, or quantity. <em>syn</em><em>:</em> <strong>enormous</strong>, <strong>gigantic</strong></p></td>
</tr>
</tbody>
</table>

> [!NOTE]
>
> - **Sense Collections** do *not* use content from the **Reverse Name** and **Reverse Abbreviation** fields.
