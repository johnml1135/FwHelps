# Insert a list subitem

*Using Tools › Lists tools*

## Lists except Reversal Index Categories

This task is only for lists that [support hierarchy](../../User_Interface/Menus/Tools/Configure_List.md).

Here the term *item* includes category, type, domain and so on. Similarly, the term *subitem* includes subcategory, subtype, subdomain and so on. Accordingly, the menu commands might be worded differently, but the steps are the same.

1.  In the **Navigation** **Pane**, click **Lists**, and then click the desired list.

2.  In the center column, select the existing list item *or* subitem below which you want to add a subitem.

3.  Do *one* of the following:

    - On the [Insert](../../User_Interface/Toolbars/Insert_toolbar.md) toolbar, click ![](../../assets/images/Using_Tools/Lists_tools/Insert_List_Subitem_Lists.GIF).

    - On the **Insert** menu, click **Subitem**.

    - In the right pane, right-click the **Subitems** label, and then click the **Insert Subitem** command in the menu that appears.

    A new list subitem is added. In the center pane, it may appear as **\*\*\*.\*\*\*** or as **\*\*\*** when it does not yet have a name or abbreviation. In the right pane, the subitem appears with empty fields.

4.  In the right pane, enter or choose content for the fields as necessary.

## Reversal Index Categories

1.  In the **Navigation** **Pane**, click **Lists**, and then select **Reversal Index Categories**.

2.  Click the [Information bar](../../User_Interface/Toolbars/information_bar_overview.md) menu button ![](../../assets/images/Using_Tools/Lists_tools/Information_bar_Menu_button.PNG) in the **Categories (or part of Speech)** pane, and then select the desired reversal index. **See:** [About Reversal Index Categories](about_reversal_index_categories.md).

3.  In the **Categories (or Parts of Speech)** pane, click the category below which you want to add a subcategory.

4.  Do *one* of the following:

    - On the [Insert](../../User_Interface/Toolbars/Insert_toolbar.md) toolbar, click ![](../../assets/images/Using_Tools/Lists_tools/Insert_List_Subitem_Lists.GIF).

    - On the **Insert** menu, click **Subcategory**.

    - In the **Category** **(or Part of Speech)** pane, click the **Subcategories** label, and then click the **Insert Subcategory** link that appears to the right of the label.

5.  [Use](../Lexicon_tools/Lexicon_Edit/Using_Add_from_Catalog_dialog_box.md) the **Add from Catalog** dialog box that appears.
