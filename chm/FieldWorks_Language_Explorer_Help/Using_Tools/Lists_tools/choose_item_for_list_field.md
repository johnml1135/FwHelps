# Choose item for a list reference field (Lists)

*Using Tools › Lists tools*

In [Lists](Lists_overview.md), when you [insert](Insert_a_list_item.md) or [edit](Edit_a_list_item_or_subitem.md) a list item or subitem, you typically choose content for one or more [list reference fields](../../User_Interface/Field_Descriptions/Field_Types/List_reference_field.md). The list item or subitem you choose help describe or categorize the current item or subitem.

1.  In the **Navigation Pane**, click **Lists**, and then click the desired list.

2.  In the center pane, select the list item or subitem you want to change.

3.  In the right pane, click the desired list reference field, and then do *one* of the following:

    - If the field has a down arrow ![](../../assets/images/down_arrow_pic.png), select the item from the list.

    - If you can type ahead, type the name or abbreviation of the desired list item. Then, click it in the list that appears.

    - If the field has an ellipsis button ![](../../assets/images/Ellipsis_button.PNG), click it to open a dialog box. Then, do one of the following:

      Click or select (![](../../assets/images/CheckedBox.PNG)) a list item or subitem, and then click **OK**.

      If the desired list item or subitem is not listed in the dialog box, click the **Edit the** **\<name\>list** link (*if* available) so you can insert it in the source list. Otherwise, click **Cancel**, and then [insert the item](Insert_a_list_item.md) or [subitem](Insert_a_list_subitem.md).

> [!IMPORTANT]
>
> - In this Help topic, the terms *item* and *subitem* include category, domain, person, and so on. The [list items usage table](List_item_usage_table.md) indicates that there are various lists and uses for those lists. However, the steps are similar.
>
> - - In **Lists**, *list reference* fields typically include **Status**, **Discussion**, **Researchers**, **Confidence**, **Features**, and so on. These contrast with [text fields](../../User_Interface/Field_Descriptions/Field_Types/field_types_overview.md).
>
> - [Lexicon Edit overview](../Lexicon_tools/Lexicon_Edit/lexicon_edit_overview.md), [Category Edit overview](../Grammar_tools/Category_Edit/Category_Edit_overview.md), [Record Edit overview](../Notebook_tools/Record_Edit_overview/Record_Edit_overview.md) and other overview Help topics list tasks that help you choose content for list reference fields in those areas.
>
> - - The Help topic for each list reference field typically describes what content is displayed and referenced in the field. Use the menu button (![](../../assets/images/Menu_Button_pic.GIF)) in a field to open the Help topic.
>
> - If available, select (![](../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times each item has been used in the project.
