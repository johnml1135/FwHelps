# Edit a list item or subitem

*Using Tools › Lists tools*

In this topic, the terms *item* and *subitem* include category, domain and so on. The [list items usage table](List_item_usage_table.md) indicates that there are various lists and uses for those lists. However, the steps to edit them are similar.

1.  In the **Navigation Pane**, click **Lists**, and then click the list that has the item or subitem that you will edit.

2.  In the center pane, navigate to and then select the item or subitem you will edit.

3.  In the right pane, do any of the following:

    - [Choose](choose_item_for_list_field.md) a list item or subitem in a [list reference](../../User_Interface/Field_Descriptions/Field_Types/List_reference_field.md) field

    - [Change secondary sort order](Change_the_secondary_sort_order.md) (**Morpheme Types**)

    - [Change tokens](Change_the_tokens_for_morpheme_types.md) (**Morpheme Types**)

    - Enter or edit text in a *text* field

    - [Insert](Insert_a_list_subitem.md) or [delete](Delete_a_list_subitem.md) a subitem

    - [Insert](Insert_a_Question_Semantic_Domain.md) or [delete](delete_a_question_semantic_domain.md) a question (**Semantic Domains**)

    - [Use the Add from Catalog dialog box](../Lexicon_tools/Lexicon_Edit/Using_Add_from_Catalog_dialog_box.md) (**Reversal Index Categories**)

    - **See:** [Lists overview](Lists_overview.md) for more task topics related to lists.

> [!CAUTION]
>
> - Text or contents you change in a list item are typically reflected in other places, including produced materials ([Dictionary](../Lexicon_tools/Dictionary/Dictionary_overview.md), [Grammar Sketch](../Grammar_tools/Grammar_Sketch/Grammar_Sketch_overview.md), and so on), or in the user interface of this program.
>
>   Examples include the **Name** and **Abbreviation** field content, which can be [set to appear](../../User_Interface/Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) in **Dictionary**. They also appear in **Grammar Sketch** ([Grammar](../Grammar_tools/grammar_overview.md)). Another example is contents from the **Semantic Domains** list which appears in the **Collect Words** ([Lexicon](../Lexicon_tools/Lexicon_overview.md)).
