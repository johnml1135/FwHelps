# Use right-click to help configure Classified Dictionary layouts

*Using Tools › Lexicon tools › Classified Dictionary*

You use the **Configure Classified Dictionary** [dialog box](../../../User_Interface/Menus/Tools/Configure_Classified_Dictionary/Configure_Classified_Dictionary_View_dlgbox.md) to configure **Classified** **Dictionary** layouts.

It can be difficult to find the specific part of the entry you want to configure in the left pane of this dialog box.

Instead, *if* it is currently displayed, do the following steps to quickly open the dialog box to the specific part of the entry that you want to configure.

1.  In the **Navigation Pane**, click **Lexicon**, and then click **Classified Dictionary**.

2.  Right-click the part of the entry that you want to configure, and then click the right-click menu command.

    The **Configure Classified Dictionary** dialog box opens.

    The specific part of the entry that you right-clicked is selected in the **Configure** pane.

3.  [Configure](../../../User_Interface/Menus/Tools/Configure_Classified_Dictionary/Configuring_a_Classified_Dictionary_view.md) that part in the currently-selected [layout](../../../User_Interface/Menus/Tools/Configure_Classified_Dictionary/Manage_Classified_Dictionary_Views.md).
