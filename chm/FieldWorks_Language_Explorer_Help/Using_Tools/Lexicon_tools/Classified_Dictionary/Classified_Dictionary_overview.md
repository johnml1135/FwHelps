# Classified Dictionary overview

*Using Tools › Lexicon tools › Classified Dictionary*

**Classified Dictionary** displays semantic domains and lexical data from fields you [configure](../../../User_Interface/Menus/Tools/Configure_Classified_Dictionary/Configuring_a_Classified_Dictionary_view.md) for display.

### Tasks you can do

- [Configuring a Classified Dictionary layout](../../../User_Interface/Menus/Tools/Configure_Classified_Dictionary/Configuring_a_Classified_Dictionary_view.md)

- [Show or hide unused items](Show_Unused_Items.md) (semantic domains)

- [Export a Classified Dictionary](../../../User_Interface/Menus/File/Export/Export_a_Classified_Dictionary.md)

- [Print](../../../User_Interface/Menus/File/Print.md) the displayed layout

- [Modify the styles](../../../User_Interface/Menus/Format/Styles/Styles_overview.md) used for the semantic domains and displayed data.\
  Styles with “**Classified-**“ in their names are used exclusively in **Classified Dictionary**:

  - **Classified-Defn** sets the *character* style for glosses or definitions.

  - **Classified-Headword** sets the *character* style for headwords.

  - **Classified-Item** sets the *paragraph* style for the display of individual item paragraphs.

  - **Classified-MainEntry** sets the *paragraph* style for the display of the semantic domain.

  - **Classified-POS** sets the *character* style for grammatical information.

  - You can [add](../../../User_Interface/Menus/Format/Styles/Styles_overview.md) styles.

  - The style selections affect only the current language project. Similarly, they do not affect the display of the same data in other tools or views in the current project.

  - [Export](../../../User_Interface/Menus/File/Export/Export_a_Classified_Dictionary.md) the classified dictionary as configured.

> [!TIP]
>
> - In **Collect Words**, you [create](../Collect_Words/Create_a_Lexical_entry_in_Collect_Words.md) lexical entries that are categorized (classified) by semantic domains.
>
> - In **Lexicon Edit**, you manually [choose](../Lexicon_Edit/choose_semantic_domains.md) semantic domains to classify each sense and subsense of lexical entries.
>
> - **See Also:** [User Interface Language for Lists](../../../User_Interface/Menus/Tools/Options/User_interface_languages_for_lists.md).
