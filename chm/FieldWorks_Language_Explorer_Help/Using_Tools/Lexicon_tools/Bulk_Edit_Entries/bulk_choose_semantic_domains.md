# Bulk choose Semantic Domains

*Using Tools › Lexicon tools › Bulk Edit Entries*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Bulk Edit Entries**.

2.  Click the **List Choice** tab.

3.  [Use](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) the **Configure Columns** dialog box to hide/show/move columns (fields) and select writing systems, if permitted. Show the **Semantic Domains** field.

4.  [Filter](../../../Basic_Tasks/Filtering_data/filtering_data_overview.md) or [sort](../../../Basic_Tasks/Sorting_data/Sorting_data_overview.md) the data to display only applicable senses. For example, you might need to filter for particular words in the definitions to identify senses that belong to the same semantic domain.

5.  In the left column, [select the rows](select_rows.md) you want to change.

6.  In the **Target Field** box, select **Semantic Domains**.

7.  Do either of the following:

    - If you want FLEx to suggest semantic domains for the selected senses, click **Suggest** ![](../../../assets/images/Using_Tools/Lexicon_tools/Bulk_Edit_Entries/SuggestIcon.png) (below **Change To**). Suggestions are based on the glosses. You should do this iteratively, changing a limited number of senses with each pass.

    - If you want to manually select semantic domains, click **Choose** (below **Change To**).

      The **Choose** **Semantic Domains** dialog box appears. (It has additional features compared to the version of this dialog box that appears in [Lexicon Edit](../Lexicon_Edit/choose_semantic_domains.md).)

In the dialog box, do the following:

1.  1.  1.  Near the bottom of the dialog box, select the option that describes what you want to do: **Add**, **Remove**, or **Replace**.

        2.  Select (![](../../../assets/images/CheckedBox.PNG)) each semantic domain you want to add, remove, or replace in the **Semantic Domains** field for the selected senses.

            - If the semantic domain you need is *not* listed, [insert a new list item](../../Lists_tools/Insert_a_list_item.md).

        3.  Click **OK**.

        4.  Click **Preview**.

<!-- -->

8.  Review the pending changes, and then click **Apply**.

    The rows (senses) with a check mark in the left column change.
