# Change the properties of a processor

*Using Tools › Texts & Words tools › Bulk Edit Wordforms*

1.  In a **Bulk Edit** tool (**Entries**, **Reversal Entries** or **Wordforms**) click the **Process** tab, and then click **Setup**.

    The **Setup Processor** dialog box appears.

2.  In the **Available Processors** pane, click the processor that you want to change.

    Either the boxes in the **Properties** tab become available *or* a **Modify** button appears below the boxes and the boxes are unavailable.

3.  If the **Modify** button does *not* appear, do one or more of the following in the **Properties** tab:

    - In the **Converter Name** box, edit the name.

    - In the **Converter Type** box, select a converter type.

    - If a **Converter Mapping File** box appears, select a mapping file (*compiled* or *source*).

      If a **Mapping Name** box appears, select a mapping name.

      If a **Find-****\>****Replace** box appears, edit or enter the [regular expression](../../../Basic_Tasks/Filtering_data/About_Regular_Expressions.md).

    - In the **Conversion Type** box, select a conversion type.

4.  If the **Modify** button appears, click it, and then follow the steps in the dialog boxes that appear (described in the **About** tab).

5.  Click **Close**.

> [!NOTE]
>
> - For more information about the various boxes that appear in the **Properties** tab, see [Encoding Converters Properties](../../../Advanced_Tasks/Writing_Systems/Encoding_Converters/Encoding_Converters_Properties_tab.md) tab.
