# Bulk change Inflection Class

*Lexicography Tasks*

For entries that are *not affixes*, the **List Choice** tab features allow you to change or choose the inflection class of entries and senses. You could find sets of roots/stems, and then assign them their common inflection class.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Bulk Edit Entries**.

2.  Click the **List Choice** tab.

3.  [Use](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) the **Configure Columns** dialog box to hide/show/move columns (fields) and select writing systems, if permitted. Show the **Inflection Classes (Stem)** and **Grammatical Category** fields.

4.  [Filter](../../../Basic_Tasks/Filtering_data/filter_data.md) or [sort](../../../Basic_Tasks/Sorting_data/Sort_data.md) the data. For example, you might choose a particular category in the **Grammatical Category** column, and then filter **Citation Form** column to find a particular affix allomorph.

5.  In the left column, [select the rows](select_rows.md) you want to change.

6.  In the **Bulk Edit Operation** pane, do the following:

    - In the **Target Field** box, select **Inflection Classes (Stem)**.

    - In the **Change To** box, expand (![](../../../assets/images/Using_Tools/Lexicon_tools/Bulk_Edit_Entries/Plus_sign_box.GIF)) the appropriate category to see a list of inflection classes. Then, click the desired inflection class. If necessary, [insert an inflection class](../../Grammar_tools/Category_Edit/Insert_an_Inflection_Class.md).

7.  Click **Preview**, review the pending changes, and then click **Apply**.

    The rows with a check mark in the left column change.

> [!TIP]
>
> - Example: Suppose you have many citation forms with an affix which has different allomorphs depending on the inflection class of the stem. If you find the allomorph, you can assign the inflection class to numerous stems at the same time.
>
