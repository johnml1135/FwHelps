# Select rows for bulk edit

*Lexicography Tasks*

In **Bulk Edit** tools, a change is only applied to displayed rows that are selected. See **Note** below.

- Click the check box at the left end of each row to *select* (![](../../../assets/images/Using_Tools/Lexicon_tools/Bulk_Edit_Entries/CheckMark.PNG)) or *clear* (![](../../../assets/images/Using_Tools/Lexicon_tools/Bulk_Edit_Entries/NOCheckMark.PNG)) it.

  Alternatively, click the check box button ![](../../../assets/images/Using_Tools/Lexicon_tools/Bulk_Edit_Entries/Check_Box_Button.GIF) at the top of the left column, and then select one of these commands:

  - **Select All**

    This *selects* *all* displayed rows (![](../../../assets/images/Using_Tools/Lexicon_tools/Bulk_Edit_Entries/CheckMark.PNG)).

    Then, clear the check box for each row you do *not* want to change.

  - **Clear All**

    This *clears* *all* displayed rows (![](../../../assets/images/Using_Tools/Lexicon_tools/Bulk_Edit_Entries/NOCheckMark.PNG)).

    Then, select the check box for each row you want to change.

    Example: Initially, all rows are selected, but you want to change only a few rows. Fewer mouse clicks are needed if you clear all the rows, and then manually select the rows you want to change.

  - **Toggle**

    This *reverses* which displayed rows are selected and which are cleared.

    Example: Initially, all rows are selected. You begin clearing rows you do not want to change, but realize that you are clicking many rows. At this point, to save your work and reduce the number of necessary mouse clicks, click **Toggle**. Then manually select the rows you want to change.

> [!NOTE]
>
> - In **Lexicon**, each *row* in the window may contain an entry, one or more senses, one or more allomorphs, and so on. The [primary sort](../../../Basic_Tasks/Sorting_data/Sort_data.md) affects this: If you [sort](../../../Basic_Tasks/Sorting_data/Sort_lexical_entries.md) on [entry-level](../Lexicon_Edit/About_Lex_Edit_fld_levels.md) data, each row contains one lexical entry; if you sort sense-level data, each row contains one sense, and so on. So, the number of rows changes in the [Status bar](../../../User_Interface/Toolbars/status_bar.md).
>
> - [Bulk Edit overview](bulk_edit_overview.md) describes other check box behaviors.
>
> - [Target Field selection](Target_field_selection.md) describes how the **Target Field** box selection determines the [Information bar](../../../User_Interface/Toolbars/information_bar_overview.md) label.
>
> - The selections you make do not change when you click another tab (**List Choice**, **Bulk Copy** and so on).
