# Copy a processor

*Using Tools › Texts & Words tools › Bulk Edit Wordforms*

1.  In a **Bulk Edit** tool (**Entries**, **Reversal Entries** or **Wordforms**), click the **Process** tab, and then click **Setup**.

    The **Setup Processor** dialog box appears.

2.  In the **Available Processors** pane, click the processor you want to copy, and then click **Copy**.

    A selected processor is copied.

3.  [Change the properties](change_the_properties_of_a_processor.md) of the processors, as necessary.

4.  Click **Close**.

> [!NOTE]
>
> - You *cannot* copy a processor that was [added](add_a_processor.md) with the **More** button.
