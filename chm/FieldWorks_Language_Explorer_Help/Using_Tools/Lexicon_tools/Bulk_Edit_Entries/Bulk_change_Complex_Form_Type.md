# Bulk change Complex Form Type

*Using Tools › Lexicon tools › Bulk Edit Entries*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Bulk Edit Entries**.

2.  Click the **List Choice** tab.

3.  [Use](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) the **Configure Columns** dialog box to hide/show/move columns (fields) and select writing systems, if permitted. Show the **Complex Form Types** field.

4.  In the left column, [select the rows](select_rows.md) you want to change.

5.  In the **Target Field** box, select **Complex Form Types**.

6.  In the **Change To** area, click the **Choose** button.

The **Choose Complex Form Types** dialog box opens.

7.  In the dialog box, do the following:

    - If the desired type or subtype *is* listed, select it (![](../../../assets/images/CheckedBox.PNG)).

    - If the desired type or subtype is *not* listed, cancel this dialog box. Then, [insert a new type](../../Lists_tools/Insert_a_list_item.md) or [subtype](../../Lists_tools/Insert_a_list_subitem.md) in the **Complex Form Types** list.

    - Select the desired option (**Add**, **Remove** or **Replace**), and then click **OK**.

8.  Click **Preview**, review the pending changes, and then click **Apply**.

    The rows with a check mark in the left column change.

> [!IMPORTANT]
>
> - When you select **Complex Form Types** in the **Target Field** box, only entries that are set to have components, or are variants, appear.
>
> - - If you do not see all the entries you expect to see, look at the entries in **Lexicon Edit**. Use **Lexeme Form has Components** on the [Information bar menu button](../../../User_Interface/Toolbars/information_bar_overview.md), as necessary.
