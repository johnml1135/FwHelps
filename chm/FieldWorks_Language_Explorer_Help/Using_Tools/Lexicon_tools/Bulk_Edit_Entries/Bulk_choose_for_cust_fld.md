# Bulk choose for custom field

*Using Tools › Lexicon tools › Bulk Edit Entries*

If you [add a custom field](../../../User_Interface/Menus/Tools/Custom_Fields/add_a_custom_field.md), with the **Type** set to **List Reference (multiple items)** or **List Reference (single item)**, you can use **Bulk Edit Entries** to choose list items for the field.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Bulk Edit Entries**.

2.  Click the **List Choice** tab.

3.  [Use](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) the **Configure Columns** dialog box to hide/show/move columns (fields) and select writing systems, if permitted. Show the custom list reference field.

4.  [Filter](../../../Basic_Tasks/Filtering_data/filtering_data_overview.md) or [sort](../../../Basic_Tasks/Sorting_data/Sorting_data_overview.md) the data to display only applicable entries or senses.

5.  In the left column, [select the rows](select_rows.md) you want to change.

6.  In the **Target Field** box, select the custom list reference field.

7.  In the **Change To** box, click **Choose**.

    Depending on the setting for the custom field, and the settings of the list, the **Change To** box may open a drop-down list, or the **Choose** \<field name\> dialog box.

<!-- -->

8.  Choose an item from the drop-down list, *or* do the following in the dialog box:

    - Select or clear the `Display usage figures` check box (optional).

    - Select the check box (![](../../../assets/images/CheckedBox.PNG)) for each item you want to add, remove, or replace.

      - If an item you need is not listed, cancel the dialog box, and then [insert it](../../Lists_tools/Insert_a_list_item.md).

    - Select the option (**Add**, **Remove** or **Replace**) to account for any existing items in the field.

    - Click **OK**.

9.  Click **Preview**, review the pending changes, and then click **Apply**.

    The rows (senses) with a check mark in the left column change.
