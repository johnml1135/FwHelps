# Bulk change the grammatical category

*Using Tools › Lexicon tools › Bulk Edit Entries*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Bulk Edit Entries**.

2.  Click the **List Choice** tab.

3.  [Use](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) the **Configure Columns** dialog box to hide/show/move columns (fields) and select writing systems, if permitted. Show the **Grammatical Category** field.

4.  [Filter](../../../Basic_Tasks/Filtering_data/filtering_data_overview.md) or [sort](../../../Basic_Tasks/Sorting_data/Sorting_data_overview.md) the data to display only applicable senses.

5.  In the left column, [select the rows](select_rows.md) you want to change.

6.  In the **Bulk Edit Operation** pane, do the following:

    - In the **Target Field** box, select **Grammatical** **Category**.

    - In the **Change To** box, select the category you want to assign to the selected entries. If the desired category is not shown, click **More** to open the [Add from Catalog](../Lexicon_Edit/Using_Add_from_Catalog_dialog_box.md) dialog box.

7.  Click **Preview**, review the pending changes, and then click **Apply**.

    The row (senses) with a check mark change, as shown in the **Grammatical** **Category** field. You will also see the changes in the **Grammatical Info** **(Full)** or **Grammatical Info (Abbr)** fields, if displayed.

> [!NOTE]
>
> - The results you see *may* vary, depending on the writing systems selected for (used by) the various columns, and whether the names and abbreviation for the grammatical categories were entered using each of those writing systems.
>
> - Review the [fields](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_fields_overview.md) in the **Grammatical Info Details** area for changes to slots, inflection classes, inflection features and so on.
>
> <!-- -->
>
> - Senses of affixes show **n/a** in the **Grammatical Category** column and these cannot be bulk edited.
>
> - A variation of this topic, [Specify Grammatical Info](../../../Lexicography_Tasks/Specify_Grammatical_Info.md), is included in the **Lexicography Tasks** Help sub-book. For a discussion about it, point to **Resources** on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu and then click **Introduction to Lexicography**.
