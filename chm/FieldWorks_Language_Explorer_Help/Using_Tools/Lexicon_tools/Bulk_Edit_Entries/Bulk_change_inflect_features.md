# Bulk change Inflection Features

*Lexicography Tasks*

In [Bulk Edit Entries](Bulk_Edit_Entries_overview.md), the **List Choice** tab features allow you to specify or change the inflection features for multiple senses of entries that are *not* affixes.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Bulk Edit Entries**.

2.  Click the **List Choice** tab.

3.  [Use](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) the **Configure Columns** dialog box to hide/show/move columns (*fields*), and select writing systems, if permitted. Show the **Inflection Features** and **Grammatical Category** fields.

4.  In the **Target Field** box, select **Inflection** **Features**.

5.  Do the following:

    - [Use](../../../Basic_Tasks/Filtering_data/Using_Choose_Items_dialog_box.md) the **Choose Items** feature in the **Grammatical Category** field to show one particular grammatical category.

    - In the left column, [select](select_rows.md) (![](../../../assets/images/Using_Tools/Lexicon_tools/Bulk_Edit_Entries/CheckMark.PNG)) the rows you want to change.

6.  Click the **Change To** down arrow (![](../../../assets/images/Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/SortDownArrow.png)) and then do one these steps:

- Click the inflection feature value you want to use.

- Click **\<Not Sure\>** to remove all the currently used infection feature values from the selected rows.

- Click **Choose Inflection Features** to open the **Choose Inflection Features** dialog box. Then, expand (![](../../../assets/images/Using_Tools/Lexicon_tools/Bulk_Edit_Entries/Plus_sign_box.GIF)) the appropriate features to see all the available inflection feature values.

Then, do these steps:

- Select (![](../../../assets/images/SelectedRadioButton.png)) the inflection feature values you want to use.

- Select (![](../../../assets/images/SelectedRadioButton.png)) **Preserve existing values** if you do *not* want to change the inflection feature values that are already set. Otherwise, you would need to select the existing inflection feature value again to leave it unchanged.

- Select (![](../../../assets/images/SelectedRadioButton.png)) **None of the above** if you want to clear all the inflection feature values from the selected (![](../../../assets/images/Using_Tools/Lexicon_tools/Bulk_Edit_Entries/CheckMark.PNG)) rows. This would be the same as clicking **\<Not Sure\>** at the top level of the hierarchy.

- If the inflection feature or value you need is *not* listed in the dialog box, click the link to [insert a feature or complex feature](../../Grammar_tools/Inflection_Features/Insert_a_Feature_or_Complex_Feature.md) for the category, and then repeat the steps above.

7.  Click **Preview**, review the pending changes, and then click **Apply**.

    See **Note** below. The [Inflection Features field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Grammatical_Info_Details_fields/Inflection_Features_field.md) for selected (![](../../../assets/images/Using_Tools/Lexicon_tools/Bulk_Edit_Entries/CheckMark.PNG)) rows are changed.

8.  Repeat the above steps for each grammatical category as necessary.

> [!NOTE]
>
> - If you have populated [paradigm form fields](../../../Lexicography_Tasks/add_paradigm_forms.md), you can [filter](../../../Basic_Tasks/Filtering_data/filter_data.md) for the particular allomorph that indicates a particular inflection feature.
>
