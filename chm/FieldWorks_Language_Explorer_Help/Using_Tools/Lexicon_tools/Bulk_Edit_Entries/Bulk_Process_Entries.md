# Bulk process entries or senses

*Using Tools › Lexicon tools › Bulk Edit Entries*

In [Bulk Edit Entries](Bulk_Edit_Entries_overview.md), the **Process** tab features allow you to change writing systems for content you will copy. This process is for *unicode-to-unicode* (or *unicode-to-and-from-unicode*) transformations only.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Bulk Edit Entries**.

2.  Click the **Process** tab.

3.  [Use](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) the **Configure Columns** dialog box to hide/show/move columns and specify writing systems, if permitted.

4.  [Filter](../../../Basic_Tasks/Filtering_data/filter_data.md) or [sort](../../../Basic_Tasks/Sorting_data/Sort_data.md) the data to display only applicable entries and senses.

5.  In the left column, [select the rows](select_rows.md) you want to change.

6.  In the **Bulk Edit Operation** pane, do the following:

    - In the **Source Field** box, select the field that has the content you want to copy.

    - In the **Target Field** box, select the field into which you want to paste the content.

    - In the **In the Target field is not empty** area select the desired result, and, if necessary, enter a symbol or character as a separator.

    - In the **Process** box, select an existing processor, or click **Setup** to [use](Using_Setup_Processor_dialog_box.md) the **Setup Processor** dialog box so you can [add](add_a_processor.md) or [modify](change_the_properties_of_a_processor.md) a processor.

7.  Click **Preview**, review the pending changes, and then click **Apply**.

    The rows with a check mark in the left column change.
