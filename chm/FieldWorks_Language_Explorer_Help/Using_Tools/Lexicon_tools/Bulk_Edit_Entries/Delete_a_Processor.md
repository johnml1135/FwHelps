# Delete a processor

*Using Tools › Texts & Words tools › Bulk Edit Wordforms*

> [!IMPORTANT]
>
> - There is currently no way to undo or cancel the deletion of a processor. Make sure you really want to delete a processor, and make sure that you choose the one you want to delete.
>
> - When you remove the information about an encoding converter/processor from FieldWorks, it *does not delete* any external mapping files.
>
> 1.  In a **Bulk Edit** tool (**Entries**, **Reversal Entries** or **Wordforms**), click the **Process** tab, and then click **Setup**.
>
>     The **Setup Processor** dialog box appears.
>
> 2.  In the **Available Processors** pane, click the processor you want to remove, and then click **Delete**.
>
>     A selected processor is removed from the language project, both as a processor here *and* as an [encoding converter](../../../Advanced_Tasks/Writing_Systems/Encoding_Converters/Encoding_Converters_overview.md) for writing systems.
>
> 3.  Click **Close**.
