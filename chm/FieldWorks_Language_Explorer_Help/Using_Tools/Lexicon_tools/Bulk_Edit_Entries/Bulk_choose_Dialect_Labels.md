# Bulk choose Dialect Labels

*Using Tools › Lexicon tools › Bulk Edit Entries*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Bulk Edit Entries**.

2.  Click the **List Choice** tab.

3.  [Use](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) the **Configure Columns** dialog box to hide/show/move columns (fields) and select writing systems, if permitted. Show the **Dialect Labels (Entry)** or **Dialect Labels (Sense)** field.

4.  [Filter](../../../Basic_Tasks/Filtering_data/filtering_data_overview.md) or [sort](../../../Basic_Tasks/Sorting_data/Sorting_data_overview.md) the data to display only applicable senses.

5.  In the left column, [select the rows](select_rows.md) you want to change.

6.  In the **Target Field** box, select **Dialect Labels (Entry)** or **Dialect Labels (Sense)**.

7.  Click **Choose**.

    The **Choose Dialect Labels (Entry)** **or** **Choose** **Dialect Labels (Sense)** dialog box appears.

8.  In the dialog box, do the following:

    - Select the check box (![](../../../assets/images/CheckedBox.PNG)) for each dialect label you want to add, remove or replace.

      - If a dialect label you need is not listed, cancel the dialog box, and then [insert it](../../Lists_tools/Insert_a_list_item.md).

    - Select (![](../../../assets/images/SelectedRadioButton.png)) an option (**Add**, **Remove** or **Replace**).

    - Click **OK**.

9.  Click **Preview**, review the pending changes, and then click **Apply**.

    The rows (entries or senses) with a check mark in the left column change.
