# Bulk Replace

*Using Tools › Lexicon tools › Bulk Edit Entries*

1.  In the **Navigation** **Pane**, do *one* of the following:

    - Click **Lexicon**, and then click **Bulk Edit Entries** or **Bulk Edit Reversal Entries**.

    - Click **Texts** **&** **Words**, and then click **Bulk Edit Wordforms**.

2.  Click the **Bulk Replace** tab.

3.  [Use](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) the **Configure Columns** dialog box to hide/show/move columns and specify writing systems, if permitted.

4.  [Filter](../../../Basic_Tasks/Filtering_data/filtering_data_overview.md) or [sort](../../../Basic_Tasks/Sorting_data/Sorting_data_overview.md) the data to display only applicable entries, senses or words.

5.  In the left column, [select the rows](select_rows.md) you want to change.

6.  In the **Bulk Edit Operation** pane, do the following:

    - In the **Target Field** box, select the field in which you want to find and replace content.

    - Click **Setup**.

    The **Bulk Replace Setup** dialog box opens. It is similar to the [Find and Replace](../../../User_Interface/Menus/Edit/Find_and_Replace_Text.md) dialog box, but only has the **Replace** tab.

7.  Do the following in the **Bulk Replace Setup** dialog box:

    - Specify any [Search Options](../../../Basic_Tasks/Find_and_Replace/Search_Options.md). You can [use regular expressions assistance](../../../Basic_Tasks/Filtering_data/Using_regular_expressions_assistance.md).

    - In the **Find what** box, enter the *search text* (that is, the character string, word, or phrase that you want to search for).

      The **Preview** and **Apply** buttons are *not* available in the **Bulk Replace** tab if the **Find What** box is left empty.

    - In the **Replace with** box, enter the *replacement text*.

    - Click **OK**.

8.  Click **Preview**, review the pending changes, and then click **Apply**.

    The rows with a check mark in the left column change.
