# Bulk change Variant Type

*Using Tools › Lexicon tools › Bulk Edit Entries*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Bulk Edit Entries**.

2.  Click the **List Choice** tab.

3.  [Use](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) the **Configure Columns** dialog box to hide/show/move columns (fields) and select writing systems, if permitted. Show the **Variant Types** field.

4.  [Filter](../../../Basic_Tasks/Filtering_data/filtering_data_overview.md) or [sort](../../../Basic_Tasks/Sorting_data/Sorting_data_overview.md) the data to display only applicable senses. For example, you might need to filter for particular words in the definitions to identify senses that belong to the same academic domain.

5.  In the left column, [select the rows](select_rows.md) you want to change.

6.  In the **Target Field** box, select **Variant Types**.

7.  In the **Change To** area, click **Choose**.

    The **Choose Variant Types** dialog box opens.

8.  In the dialog box, do the following:

    - Near the bottom of the dialog box, select the option that describes what you want to do: **Add**, **Remove**, or **Replace**.

    - If the desired types or subtypes *are* listed, select (![](../../../assets/images/CheckedBox.PNG)) the types that you want to *add*, *remove*, or *replace*, per your previous selection.

      - If a desired type or subtype is *not* listed, cancel this dialog box, and then [insert it](../../Lists_tools/Insert_a_list_item.md).

    - Click **OK**.

9.  Click **Preview**, review the pending changes, and then click **Apply**.

    The rows with a check mark in the left column change.
