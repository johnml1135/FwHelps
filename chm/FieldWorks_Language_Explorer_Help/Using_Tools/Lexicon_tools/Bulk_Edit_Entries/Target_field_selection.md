# Target field selection

*Using Tools › Lexicon tools › Bulk Edit Entries*

In bulk edit tools, the **Target Field** box selection determines the label on the [Information bar](../../../User_Interface/Toolbars/information_bar_overview.md) and [more](bulk_edit_overview.md).

|  |  |  |
|----|----|----|
| If the **Target Field** box selection is a | The Information bar label is | 0r, a field name, such as |
| [entry-level field](../Lexicon_Edit/About_Lex_Edit_fld_levels.md) | **Entries** | **Pronunciations** |
| Sense-level field | **Senses** | **Translations** |
| Variant-level field | **Complex or Variant Entry References** |  |
| Allomorphs-level field | **Allomorphs** | n/a |
