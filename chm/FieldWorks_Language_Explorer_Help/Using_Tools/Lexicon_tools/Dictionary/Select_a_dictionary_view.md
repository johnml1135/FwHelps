# Select a dictionary layout

*Using Tools › Lexicon tools › Dictionary*

You should review [What is a publication?](../../../User_Interface/Field_Descriptions/Lists/Publications/What_is_a_Publication.md).

Then, do these steps:

1.  In the **Navigation Pane**, click **Lexicon**, and then click **Dictionary**.

2.  Click the *right* menu button (![](../../../assets/images/Information_bar_Menu_button.PNG)) on the [Information bar](../../../User_Interface/Toolbars/information_bar_overview.md), and then select (![](../../../assets/images/Using_Tools/Lexicon_tools/Dictionary/SelectedViewCheckBox.png)) a ****[layout](../../../User_Interface/Menus/Tools/Configure_Dictionary/Dictionary_views.md).

> [!TIP]
>
> - Click the *left* menu button (![](../../../assets/images/Information_bar_Menu_button.PNG)) on the Information bar to [select a publication](Select_a_publication.md).
>
> - Alternatively, [choose](../../../User_Interface/Menus/Tools/Configure_Dictionary/Choose_a_dictionary_view.md) a dictionary layout.
>
> - The view affects what you see in **Dictionary**, the [Dictionary preview pane](../Lexicon_Edit/About_Lex_Edit_fld_levels.md), and the [Dictionary Entry](../../../User_Interface/Menus/Tools/Dictionary_Entry_dialog_box.md) **dialog box**.
>
> - When you [Configure Headword numbers](../../../User_Interface/Menus/Tools/Configure_Headword_Numbers/Config_Hdwrd_Numbers_dialog_box.md), the configuration is for the *current* layout only.
