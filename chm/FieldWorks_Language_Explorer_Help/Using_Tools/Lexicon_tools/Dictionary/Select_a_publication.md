# Select a publication

*Using Tools › Lexicon tools › Dictionary*

1.  In the Navigation pane, **Lexicon** and then click **Dictionary** or **Reversal Indexes**.

2.  Click the menu button (![](../../../assets/images/Information_bar_Menu_button.PNG)) on the [Information bar](../../../User_Interface/Toolbars/information_bar_overview.md), and then select (![](../../../assets/images/Using_Tools/Lexicon_tools/Dictionary/SelectedViewCheckBox.png)) the desired publication or **All Entries**.

> [!IMPORTANT]
>
> - Use the [Manage Dictionary layouts](../../../User_Interface/Menus/Tools/Configure_Dictionary/Manage_Dictionary_Views.md) and [Manage Reversal Index layouts](../../../User_Interface/Menus/Tools/Configure_Reversal_Index/Manage_Views_Reversal_Index.md) dialog boxes to specify which layouts are available to each [publication](../../../User_Interface/Field_Descriptions/Lists/Publications/What_is_a_Publication.md).
>
> - - If you select a publication that has more than one available layouts,\
>     you can [select another dictionary layout](Select_a_dictionary_view.md) or [select another reversal index layout](../Reversal_Indexes/Select_a_Reversal_index_view.md).
>
>   - If you select a publication that has no available layouts, this notice appears instead of data: **No layouts match the current publication**.
>
> - **All Entries** functions as if *all* publications are displayed in *all* **Publish** \<item\> **In** [fields](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Lexicon_Edit_fields_overview.md). Data which are *not* excluded by [filters](../../../Basic_Tasks/Filtering_data/filter_data.md) or by selections in *other* fields are displayed (if configured for display).
>
> - The publication set in **Dictionary** also determines the display in **Classified Dictionary**.
