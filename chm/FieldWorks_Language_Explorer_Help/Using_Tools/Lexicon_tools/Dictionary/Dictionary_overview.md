# Dictionary overview

*Using Tools › Lexicon tools › Dictionary*

**Dictionary** on the [Navigation Pane](../../../User_Interface/Toolbars/Navigation/Navigation_Pane_graphic.md) displays lexical data from **Lexicon Edit** that is

- specified as [publishable](../Lexicon_Edit/Specify_publishable_lexical_data.md) in the currently [selected publication](Select_a_dictionary_view.md)

- [configured](../../../User_Interface/Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) for display

- *not* excluded by a [filter](../../../Basic_Tasks/Filtering_data/filter_lexical_entries.md)

- *not* excluded by choice in a field, such as [Show As Head Word In](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Publication_Settings_flds/Show_As_Headword_In_field.md),

- [sorted](../../../Basic_Tasks/Sorting_data/Sort_lexical_entries.md) according to the [sort](../../../Basic_Tasks/Sorting_data/Sort_data.md) order set in **Lexicon Edit**.

- [Use right-click to help configure Dictionary](Use_right-click_to_help_configure_Dictionary_view.md)

> [!TIP]
>
> - You can click a *referenced headword* to jump to that lexical entry.
>
> - You can [print](../../../User_Interface/Menus/File/Print_Dictionary_or_Reversal_Index.md) or [export](../../../User_Interface/Menus/File/Export/Export_overview.md) the displayed lexical data. **See Also:** [Print content](../../../User_Interface/Menus/File/Print_content.md) or [Styles for export](../../../User_Interface/Menus/File/Pathway_Configuration_Tool/Styles_for_export.md).
>
> - In the [Configure Dictionary](../../../User_Interface/Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) dialog box, you can choose to show various [layouts](../../../User_Interface/Menus/Tools/Configure_Dictionary/Dictionary_views.md) in the **Dictionary** view. The *last* layout you chose is displayed when you click **Dictionary**.
>
> - You can use [Find](../../../User_Interface/Menus/Edit/Find_a_lexical_entry.md), and you can [create](Create_a_lexical_entry_from_Dictionary_view.md) or [delete](../Lexicon_Edit/Delete_a_lexical_entry.md) an entry, but you cannot edit an entry while in the **Dictionary**.
>
> - The **Lexicon** area also includes a [Classified Dictionary](../Classified_Dictionary/Classified_Dictionary_overview.md), and a [Reversal Index](../Reversal_Indexes/reversal_indexes_overview.md), but the display properties you set in the **Dictionary** are *not* shared with these two views of the lexical data.
>
> - In Lexicon Edit, you can type USFM markers in a [custom field](../../../User_Interface/Menus/Tools/Custom_Fields/Custom_Fields_overview.md) to display data in one or more tables. Your tables appear in **Dictionary**.
