# Use right-click to help configure Dictionary layouts

*Using Tools › Lexicon tools › Dictionary*

You [use](../../../User_Interface/Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) the **Configure Dictionary** dialog box to configure a dictionary layout.

It can be difficult to find the specific part (data) of the entry you want to configure in the [left pane](../../../User_Interface/Menus/Tools/Configure_Dictionary/About_the_left_pane.md) of this dialog box.

Instead, *if* that data is currently displayed, do the steps below to quickly open the dialog box to the part of the entry that you want to configure.

1.  In the Navigation Pane, do either of the following:

    - Click **Lexicon**, and then click **Dictionary**.

    - Click **Lexicon**, and then click **Lexicon Edit**. Then in the **Entries** pane, click the desired entry. Examine that entry in the [preview pane](../Lexicon_Edit/About_Lex_Edit_fld_levels.md).

2.  In either the **Dictionary** or preview pane, right-click the part of the entry that you want to configure, and then **Configure Dictionary Layout**.

    The **Configure Dictionary** dialog box opens. Typically, the specific part of the entry that you right-clicked is selected in the [left pane](../../../User_Interface/Menus/Tools/Configure_Dictionary/About_the_left_pane.md).

If you see **This configuration is shared. Hover for details.** or **This item is configured somewhere else. Hover for details.** hold your mouse pointer over the statement. A pop-up box appears with a list of other nodes that are affected by the current node ([example](../../../User_Interface/Menus/Tools/Configure_Dictionary/Hover_for_details_example.md)).

3.  [Configure](../../../User_Interface/Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) that part in the currently dictionary layout.

> [!TIP]
>
> - For content that is a *single character*, such as the abbreviation for a grammatical category, put the insertion point immediately after that character. Then, right-click.
>
> - In the dictionary preview pane, right-click the part of the entry that you want to edit, and then **Jump to field**. This will move the cursor to the [field](../../../User_Interface/Field_Descriptions/field_descriptions_overview.md) that stores that part of the entry.
