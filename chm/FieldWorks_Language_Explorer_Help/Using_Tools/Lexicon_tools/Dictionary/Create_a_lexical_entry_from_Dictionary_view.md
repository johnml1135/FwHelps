# Create a lexical entry in Dictionary

*Using Tools › Lexicon tools › Dictionary*

You can create a lexical entry, but you *cannot* edit the content of any entry while in the **Dictionary**.

1.  Do one of the following steps:

    - On the [Insert](../../../User_Interface/Toolbars/Insert_toolbar.md) toolbar, click **![](../../../assets/images/User_Interface/Toolbars/Insert_Lexical_Entry.GIF)**.

    - On the **Insert** menu, click **Entry**.

    - Press the [shortcut keys](../../../User_Interface/Shortcuts/shortcut_keys_Lexicon_tools.md) `Ctrl+E`.

    The **New Entry** dialog box appears.

2.  Enter or select content for the boxes in the dialog box, and then click **Create**.

    See [Create a lexical entry](../Lexicon_Edit/Create_a_lexical_entry.md) for more details, if necessary.
