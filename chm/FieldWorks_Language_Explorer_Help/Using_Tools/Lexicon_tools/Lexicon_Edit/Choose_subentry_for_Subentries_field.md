# Choose a subentry for Subentries field

*Using Tools › Lexicon tools › Lexicon Edit*

(For *Root-based* and *Hybrid* dictionary [layouts](../../../User_Interface/Menus/Tools/Configure_Dictionary/Dictionary_views.md))

You can do this from the [Components](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Components_field.md) field, or you can do the following:

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** column, click the desired entry which is a component of a complex form.

3.  In the **Entry** pane, if you cannot see the appropriate **Subentries** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Click the **Subentries** field, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose Subentries to display in Root-based layouts** dialog box appears. Complex forms that reference this entry or sense as a component are listed.

5.  Do any of the following:

    - Clear (![](../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)) each complex form you do *not* want to be available for display as an indented subentry below this component.

    - Select (![](../../../assets/images/CheckedBox.PNG)) each complex form you want to be available for display as an indented subentry below this component.

    - Click the **Add a Complex Form** link to open the **Find Lexical Entry** dialog box.\
      Then you can search for an existing entry or create a new entry.

    - Click **OK**.

> [!IMPORTANT]
>
> - There is a [Subentries](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Publication_Settings_flds/Subentries_(Publication_Settings).md) field below the **Publication Settings** field, and a [Subentries](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Subentries_(Sense).md) field in *each* sense and subsense.
>
> - When you [choose a component](Choose_components_for_Components_field.md) for a complex form, that complex form automatically appears in a **Subentries** field in each component entry, or selected sense or subsense.
>
> - Complex forms displayed in **Subentries** fields are available for display in *Lexeme-based* dictionary [layouts](../../../User_Interface/Menus/Tools/Configure_Dictionary/Dictionary_views.md). You need to [configure](../../../User_Interface/Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) the dictionary layout to display the. **See Also:** [Subentries (Configure Dictionary)](../../../User_Interface/Menus/Tools/Configure_Dictionary/Subentries.md).
>
> - For *Lexeme-based* dictionary [layouts](../../../User_Interface/Menus/Tools/Configure_Dictionary/Dictionary_views.md), see [Choose "Referenced Complex Forms"](Choose_referenced_complex_forms.md).
