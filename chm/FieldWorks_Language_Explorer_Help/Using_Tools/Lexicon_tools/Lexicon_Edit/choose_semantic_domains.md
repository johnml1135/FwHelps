# Choose semantic domains

*Using Tools › Lexicon tools › Lexicon Edit*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** column, click the desired entry.

3.  In the **Entry** pane, if you cannot see a **Semantic Domains** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Click the **Semantic Domains** field in the desired sense, and then do one of the following:

    - Type the abbreviation or name of the semantic domain directly in the field. Click the desired semantic domain in the drop-down list. Repeat as needed. In this case, you are done.

    - Click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears, and then continue.

      The **Choose Semantic Domains** dialog box appears.

5.  Find the semantic domain in the dialog box in any of these ways:

    - In the *center* pane, manually expand (![](../../../assets/images/Plus_sign_box.GIF)) the list until you see it.

    - In the *top* pane, search for it: Type the [name](../../../User_Interface/Field_Descriptions/Lists/Semantic_Domains_fields/name_field_semantic_domains.md) or [abbreviation](../../../User_Interface/Field_Descriptions/Lists/Semantic_Domains_fields/abbreviation_field_semantic_domains.md) of the domain, or an [example word](../../../User_Interface/Field_Descriptions/Lists/Semantic_Domains_fields/Example_Words_field_Semantic_Domains.md).

Any semantic domains that match appear in a flat list (*not* hierarchical) in the *center* pane.

The closest matches are nearest to the top. The words in square brackets are the next domain up in the hierarchical order, that is the parent semantic domain. For example, **Sun \[Sky\]**. where **Sun** is 1.1.1, and **Sky** is 1.1.

The magnifying glass (![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/MagnifyingGlass.png)) changes to an 'x' (![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/BlackX.png)), which you can click to restore the hierarchical list.

1.  - Click ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Suggest.png) **Suggest**.

This feature tries to match words used in the [gloss](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Gloss_field_Sense.md), [definitions](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/definition_field.md) (up to two words), or [reversal entries](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/reversal_entries_field.md) with semantic domain [names](../../../User_Interface/Field_Descriptions/Lists/Semantic_Domains_fields/name_field_semantic_domains.md) or [example words](../../../User_Interface/Field_Descriptions/Lists/Semantic_Domains_fields/Example_Words_field_Semantic_Domains.md). Matches appear in the *bottom* pane.

The search begins with the top (default) [analysis writing systems](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md). If there is no content in that writing system, it looks in the next one (if any).

6.  Do these steps in the center *or* bottom pane:

    - Clear (![](../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)) the semantic domains you do *not* want to display.

    - Select (![](../../../assets/images/CheckedBox.PNG)) the semantic domains you want to display.

7.  Click **OK**.

> [!TIP]
>
> - Click the **Edit Semantic Domains** link to open the **Semantic Domains** list in [Lists](../../Lists_tools/Lists_overview.md). There, you can [edit](../../Lists_tools/Edit_a_list_item_or_subitem.md) or [insert](../../Lists_tools/Insert_a_list_item.md) a semantic domain or [subdomain](../../Lists_tools/Insert_a_list_subitem.md).
>
> - **Display usage figures** display a number in parenthesis that is the number of times each *used* semantic domain has been used in the project.
>
> - In many dialog boxes with check boxes, you can put the focus on an item with the arrow keys.\
>   Then press SPACEBAR to select (![](../../../assets/images/CheckedBox.PNG)) or clear (![](../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)) check boxes.
>
> - You can see semantic domains and lexical data in [Classified Dictionary](../Classified_Dictionary/Classified_Dictionary_overview.md).
