# Enter a summary definition

*Using Tools › Lexicon tools › Lexicon Edit*

You need to enter content in the [Summary Definition](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Summary_Definition_field.md) field *only* if both of the following are true:

- The entry is referenced as the primary entry of complex forms or the entry has variant forms.

- You want to [configure the dictionary](../../../User_Interface/Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md) to include the summary definitions.

To enter a summary definition in **Lexicon Edit**, do the following:

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, if you cannot see the **Summary Definition** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  In the **Summary Definition** field, click the line that shows the writing system you want to use (if more than one is shown), and then enter the summary definition.

    Repeat for other writing systems, if necessary.

> [!TIP]
>
> - You can use [Bulk Edit](../Bulk_Edit_Entries/bulk_edit_overview.md) features like [Bulk Click Copy](../Bulk_Edit_Entries/Bulk_Click_Copy.md), to rapidly copy particular content into the **Summary Definition** field from other fields, such as from the **Gloss** field or **Definition** field.
