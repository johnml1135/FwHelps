# Using Create New Grammatical Info. dialog box

*Using Tools › Lexicon tools › Lexicon Edit*

The **Create New Grammatical Info** dialog box ([sample](Create_New_Grammatical_Info_dialog_box_graphic.md)) may open when you [specify different (change)](change_the_grammatical_info.md) **Grammatical Info** field content in an affix entry.

**See:** [Change the Grammatical Info](change_the_grammatical_info.md).

1.  Do the following:

    - In the **Affix Type** box, select **Not Sure**, **Inflectional** or **Derivational**.

    - In the **Attaches to Category** box, select an existing category, **\<Any\>** or **More** so you can [add one from the catalog](Using_Add_from_Catalog_dialog_box.md).

    - For an *inflectional* affix, select a slot in the **Fills Slot** box.

      If the **Fills Slot** box is *not* available, you need to [insert an affix slot](../../Grammar_tools/Category_Edit/Insert_an_Affix_Slot.md) for the category shown in the **Attaches to Category** box.

    - For a *derivational* affix, in the **Changes to Category** box, select an existing category, **\<Any\>** or **More** so you can [add one from the catalog](Using_Add_from_Catalog_dialog_box.md).

2.  Click **Create**.
