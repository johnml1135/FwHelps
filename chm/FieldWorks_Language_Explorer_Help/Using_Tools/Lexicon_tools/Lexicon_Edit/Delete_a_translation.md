# Delete a translation

*Using Tools › Lexicon tools › Lexicon Edit*

One or more **Translation** fields can appear with each **Example** field in a sense or subsense, and with each **Example** field in an **Extended Note**.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry that has the example with the translation you will delete.

3.  In the **Entry** pane, click the **Translation** field label for the translation you will delete.

    A menu button (![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF)) appears.

4.  Click the menu button, and then click **Delete Translation**.

    The **Delete Translation** warning box appears.

5.  Click **Delete**.

    The **Translation** field is deleted.
