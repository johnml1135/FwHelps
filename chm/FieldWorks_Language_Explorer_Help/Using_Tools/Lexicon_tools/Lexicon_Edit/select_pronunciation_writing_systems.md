# Select pronunciation writing system

*Using Tools › Lexicon tools › Lexicon Edit*

To add or remove a pronunciation writing system in the **Pronunciation** field, do the following:

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click any entry.

3.  In the **Entry** pane, if you cannot see the **Pronunciation** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Do the steps in [Configure writing systems for fields](../../../Basic_Tasks/Showing_Writing_Systems/configure_field_WSs.md).

    - The **Pronunciation** field must be expanded, that is, it must contain data or the **Insert Pronunciation** command needs to be selected on the menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF) menu. Otherwise, the menu will not display the **Writing Systems** command.

> [!TIP]
>
> - You can select the variant (phonetic, phonemic and so on) or the orthographic writing systems in **Pronunciation** fields without affecting any other [single-line text](../../../User_Interface/Field_Descriptions/Field_Types/Single_line_text_field.md) fields.
