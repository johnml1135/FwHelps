# Insert Etymology

*Using Tools › Lexicon tools › Lexicon Edit*

One **Etymology** field is initially available in each entry at the [entry level](About_Lex_Edit_fld_levels.md). You can insert more than one.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, if you cannot see the **Etymology** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Do any of these steps:

    - Click the empty **Etymology** field and then start typing.

In this case, what you type appears in the **Source Form** field in the default analysis writing system.

1.  - On the **Insert** [menu](../../../User_Interface/Menus/Insert/Insert_overview.md), click **Etymology**.

    - Right-click the **Etymology** field label, and then click **Insert Etymology**.

    - Click the **Etymology** field label to display the menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF), and then click **Insert Etymology**.

    - To insert *another* etymology field set, click the **Insert Etymology** link that appears with an existing **Etymology** field.

    - Click the menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Information_bar_Menu_button.PNG) on the [Information bar](../../../User_Interface/Toolbars/information_bar_overview.md), and then click **Insert Etymology**.

A set of associated [fields](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Etymology_fields_overview.md) appears.

5.  [Enter](Enter_etymological_information.md) contents in the fields.

6.  [Reorder](Reorder_Etymologies.md) the etymologies if you inserted more than one and the order in **Dictionary** is not right.
