# Enter note content in a sense

*Using Tools › Lexicon tools › Lexicon Edit*

In each sense and subsense, there is a series of \<name\> **Note** fields (**Anthropology**, **Discourse**, **General**, **Grammar**, **Phonology**, **Semantics**, and **SocioLinguistics**). These are [single-line text fields](../../../User_Interface/Field_Descriptions/Field_Types/Single_line_text_field.md), which permit text in multiple [writing systems](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md) and [hyperlinks](../../../Basic_Tasks/Creating_Hyperlinks/Creating_Hyperlinks_overview.md).

1.  In the **Navigation** **Pane**, click **Lexicon**, and then select **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, if you cannot see the desired **Note** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  For the desired **Note** field, click the field or a particular line in the field (if more than one writing system is displayed), and then enter content.

5.  Click other writing system lines in the current **Note** field, and then enter content, if necessary.

6.  Repeat, as necessary, for other **Note** fields.
