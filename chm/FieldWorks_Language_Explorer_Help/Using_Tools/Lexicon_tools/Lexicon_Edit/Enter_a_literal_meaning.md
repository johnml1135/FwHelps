# Enter a literal meaning

*Using Tools › Lexicon tools › Lexicon Edit*

You can enter a literal meaning (of a compound, derivative, idiom, and so on) in the [Literal Meaning](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Literal_Meaning_field.md) field.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, if you cannot see the **Literal Meaning** field (at the [entry level](About_Lex_Edit_fld_levels.md)), [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  In the **Literal Meaning** field, click the line that shows the writing system you want to use (if more than one is shown), and then enter the literal meaning.

    Repeat for other writing systems, if necessary.
