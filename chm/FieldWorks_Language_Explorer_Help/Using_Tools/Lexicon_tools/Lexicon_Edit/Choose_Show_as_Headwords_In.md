# Choose Show as Headwords In Publications

*Using Tools › Lexicon tools › Lexicon Edit*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, if you cannot see the **Show As Headword In** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Click the **Show As Headword In** field, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose Show As Headword In** dialog box appears.

5.  Do any of the following:

    - Select (![](../../../assets/images/CheckedBox.PNG)) a publication if you want the current entry to appear as a main entry headword in **Dictionary** *and* **Classified Dictionary** for that publication.

    - Clear (![](../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)) a publication if you do *not* want the current entry to appear as a main entry headword for that publication. It remains available to appear as a *referenced* headword.

    - Click the **Edit the Publications list** link to edit or [create](../../Lists_tools/Create_new_publication.md) publications.

    - Click **OK**.

> [!IMPORTANT]
>
> - [Publications](../../../User_Interface/Field_Descriptions/Lists/Publications/What_is_a_Publication.md) stored in the **Publications** [list](../../Lists_tools/List_item_usage_table.md) are automatically displayed in the [Show As Headword In](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Publication_Settings_flds/Show_As_Headword_In_field.md) field, and also in *all* the **Publish** \<item\> **In** fields.
>
> - - This means that all lexical entries, senses, and examples are assumed to be [publishable](Specify_publishable_lexical_data.md) by default.
