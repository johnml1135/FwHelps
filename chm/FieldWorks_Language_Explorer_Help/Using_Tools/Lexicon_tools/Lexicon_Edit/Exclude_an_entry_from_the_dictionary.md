# Exclude an entry from the dictionary

*Using Tools › Lexicon tools › Lexicon Edit*

In a [dictionary view](../../../User_Interface/Menus/Tools/Configure_Dictionary/Dictionary_views.md) for a particular [publication](../../../User_Interface/Field_Descriptions/Lists/Publications/Publications_fields_overview.md), you can

- fully exclude an *entry*

- exclude an entry as a main entry [headword](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Publication_Settings_flds/Show_As_Headword_In_field.md) while keeping it available as a *referenced* headword

- exclude a particular *sense*

- exclude an *example*.

**See:** [Specify publishable lexical data](Specify_publishable_lexical_data.md) and [Configuring a dictionary view](../../../User_Interface/Menus/Tools/Configure_Dictionary/Using_the_Configure_Dictionary_dialog_box.md).
