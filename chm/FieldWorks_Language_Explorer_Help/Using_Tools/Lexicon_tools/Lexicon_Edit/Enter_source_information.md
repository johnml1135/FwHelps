# Enter source information

*Using Tools › Lexicon tools › Lexicon Edit*

Review the information in the **[Source](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Source_field.md) field** topic.

Then, do these steps:

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, if you cannot see the **Source** field (within each **Sense**), [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

This **Source** field is different from the [Source Form field (etymology)](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Source_Form_Etymology.md).

4.  In the applicable **Sense**, click the **Source** field, and then enter source information.
