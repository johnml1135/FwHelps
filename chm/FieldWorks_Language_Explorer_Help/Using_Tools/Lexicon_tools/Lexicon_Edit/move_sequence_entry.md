# Move an entry in a sequence

*Using Tools › Lexicon tools › Lexicon Edit*

For a lexical relation that uses a **Sequence/scale** [reference set type](../../Lists_tools/About_reference_set_types.md) (such as [Days of week](../../Lists_tools/About_reference_set_types.md)), you can move a reference (that is, a lexical entry) to change the sequence of the references in that lexical relation. If you change the sequence of the references in *one* of the entries that contains the lexical relation, the sequence changes in *all* the associated lexical entries.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click entry that has the lexical relation that you will reorder.

3.  In the **Entry** pane, click the field label (such as, **Days of week**) that has the sequence of references you will reorder.

4.  Right-click the reference in the field, and then click **Move Right** or **Move Left** on the menu that appears.

    The reference that you right-clicked moves one position to the right or left in the current entry and in all other associated entries.

5.  Repeat the last step until the sequence is as desired.

> [!TIP]
>
> - If you right-click the *last* alphabetical item, select **Show Entry in Lexicon**, and then sort the **Lexical Relation** field items in *that* entry, you will not need to set the order in the other entries that use item in this set of lexical relations.
