# Delete an extended note

*Using Tools › Lexicon tools › Lexicon Edit*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, do one of the following:

    - Right-click the label, and then click **Delete Extended Note**.

    - Click the **Extended Note** label to display the menu button (![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF)). Click the menu button and then click **Delete Extended Note**.

The **Delete Extended Note** warning box appears.

4.  Click **Delete**.
