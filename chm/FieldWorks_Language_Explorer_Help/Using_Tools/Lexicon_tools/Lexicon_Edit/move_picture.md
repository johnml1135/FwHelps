# Move a picture

*Using Tools › Lexicon tools › Lexicon Edit*

If you have more than one picture in a sense, you can move them up or down to reorder them within the sense.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click entry that has the picture you will move (reorder).

3.  In the **Entry** pane, click the **Picture** field label for the picture you will move.

    A menu button (![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF)) appears.

4.  Click the menu button, and then click one of the following commands:

    - **Move Picture Up**

    - **Move Picture Down**

The picture order changes. This change may be observed in the [dictionary preview pane](../../../User_Interface/Menus/View/View_overview.md) if pictures are [configured](../../../User_Interface/Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) for display.
