# Add reference to cross reference lexical relation

*Using Tools › Lexicon tools › Lexicon Edit*

At the *entry* level, for *existing* [cross reference](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/cross_references_field.md) lexical relations (previously [inserted](Insert_a_CR_lexical_relation.md)) you can add or replace a reference. That is, you can choose a *different* lexical entry, or for some relations *additional* entries.

To do this, follow the steps in the topic [Add reference to lexical relation](Add_Reference_to_Lexical_Relation.md).
