# Reorder Pronunciations

*Using Tools › Lexicon tools › Lexicon Edit*

You can [insert](Insert_a_pronunciation.md) multiple **Pronunciation** field sets in an entry. Their order in the entry determines their order in the **Dictionary** view.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, if you cannot see the **Pronunciation** fields, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Do one of the following:

    - Right-click the label for a **Pronunciation** field, and then select **Move** **Pronunciation** **Up** or **Move** **Pronunciation Down** on the menu.

    - Click the label for a **Pronunciation** field. Click the menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF) that appears, and then select **Move** **Pronunciation** **Up** or **Move** **Pronunciation Down** on the menu.

    The position of that **Pronunciation** field changes and dictionary order changes, as seen in the preview pane.

5.  Repeat this process until the desired order is displayed.
