# Choose Publish In field publications

*Using Tools › Lexicon tools › Lexicon Edit*

You use **Publish** \<item\> **In** fields to [specify publishable lexical data](Specify_publishable_lexical_data.md).

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, if you cannot see the field you need, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

|  |  |
|----|----|
| For | **Publish \<item\> In field** |
| the *entire* entry | [Publish Entry In](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Publication_Settings_flds/Publish_In_(Publication_Settings).md) |
| a pronunciation | [Publish Pronunciation In](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Publish_In_(Pronunciations).md) |
| a sense or subsense | [Publish Sense In](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Publish_In_(Sense).md) |
| an example | [Publish Example In](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Publish_In_(Example).md) |
| a picture | [Publish Picture In](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Publish_In_(Pictures).md) |

4.  Click the appropriate field, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

The **Choose Publish** \<item\> **In** dialog box appears.

5.  Do any of the following:

<!-- -->

1.  - Select (![](../../../assets/images/CheckedBox.PNG)) a publication to specify that the data is [publishable](Specify_publishable_lexical_data.md) in that publication.

    - Clear (![](../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)) a publication to specify that the data is *not* publishable in that publication.

Alternatively, in the **Publish** \<item\> **In** field, click the publication you want to remove. Then press your `Delete` or `Backspace` key.

1.  - Click the **Edit the Publications list** link to edit or [create](../../Lists_tools/Create_new_publication.md) publications.

    - Click **OK**.

> [!IMPORTANT]
>
> - Publications stored in the **Publications** [list](../../Lists_tools/List_item_usage_table.md) are automatically displayed in *all* the **Publish** \<item\> **In** fields (and also in the [Show As Headword In](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Publication_Settings_flds/Show_As_Headword_In_field.md) fields).
>
> This means that all entries, pronunciations, senses, examples and pictures are assumed to be [publishable](Specify_publishable_lexical_data.md) by default.
>
> - You can [bulk change publications](../Bulk_Edit_Entries/Bulk_change_publications.md).
