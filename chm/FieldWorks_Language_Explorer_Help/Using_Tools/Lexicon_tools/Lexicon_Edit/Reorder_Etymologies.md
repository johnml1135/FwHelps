# Reorder Etymologies

*Using Tools › Lexicon tools › Lexicon Edit*

You can [insert](Insert_Etymology.md) multiple **Etymology** field sets in an entry. Their order in the entry determines their order in the **Dictionary** view.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry in which you will reorder etymological information.

3.  In the **Entry** pane, if you cannot see the **Etymology** fields, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Do one of the following:

    - Right-click the label for an ![](../../../assets/images/minus_sign_box.GIF) **Etymology** field, and then select **Move** **Etymology Up** or **Move** **Etymology Down** on the menu.

    - Click the label for an ![](../../../assets/images/minus_sign_box.GIF) **Etymology** field. Click the menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF) that appears, and then select **Move** **Etymology** **Up** or **Move** **Etymology** **Down** on the menu.

    The position of that ![](../../../assets/images/minus_sign_box.GIF) **Etymology** field changes. The order changes in **Dictionary**, as observed in the preview pane.

5.  Repeat this process until the desired order is displayed.
