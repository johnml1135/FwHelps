# Choose Source Language

*Using Tools › Lexicon tools › Lexicon Edit*

When you [enter etymological information](Enter_etymological_information.md), you need to choose one or more source languages that correspond to the contents in the **Source Form** field.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** column, click the desired entry.

3.  In the **Entry** pane, if you cannot see the **Etymology** field or its associated fields, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Click the **Source Language** field, and then click the ellipsis button (![](../../../assets/images/Ellipsis_button.PNG)).

    The **Choose Source Language** dialog box appears.

5.  Do any of these steps:

    - If the **Languages** list [supports hierarchy](../../../User_Interface/Menus/Tools/Configure_List.md), expand the nodes (![](../../../assets/images/Plus_sign_box.GIF)) to see subitems.

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times each **Languages** list item is used in the project.

    - Click the **Edit the Languages List** link to open the **Languages** [list](../../Lists_tools/List_item_usage_table.md).\
      There you can [insert](../../Lists_tools/Insert_a_list_item.md) or [edit](../../Lists_tools/Edit_a_list_item_or_subitem.md) list items.

    - Select (![](../../../assets/images/CheckedBox.PNG)) each language that you want to display. Click **OK**.
