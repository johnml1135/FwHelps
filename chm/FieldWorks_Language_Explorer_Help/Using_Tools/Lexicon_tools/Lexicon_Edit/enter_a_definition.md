# Enter a definition

*Using Tools › Lexicon tools › Lexicon Edit*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, if you cannot see the **Definition** field in the applicable **Sense**, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  In the **Definition** field, click the line that shows the writing system you want to use (if more than one is shown), and then enter the definition.

    Repeat for other writing systems, if necessary.
