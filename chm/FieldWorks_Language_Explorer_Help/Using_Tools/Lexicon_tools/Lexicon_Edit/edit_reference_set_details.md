# Edit reference set details

*Using Tools › Lexicon tools › Lexicon Edit*

You can enter and maintain a name and comments (metadata) for individual [cross references](Add_Reference_to_CR_lexical_relation.md) lexical relations (*entry* level) and [lexical relations](Add_Reference_to_Lexical_Relation.md) (*sense* level). These are *not* visible except in the **Reference Set Details** dialog box. However, the content is common and shared with each reference (that is, lexical entry) in the set.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry that has the cross reference or lexical relation you will enter/edit.

3.  In the **Entry** pane, do one or both of the following:

    - Below the **Cross References** field label, click the label for the applicable cross reference.

    - Below the **Lexical Relations** field label, click the label for the applicable lexical relation.

    A menu button (![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF)) appears.

4.  Click the menu button, and then click **Edit Reference Set Details**.

    The **Reference Set Details** dialog box appears.

5.  Enter or edit content in the **Name** or **Comment** boxes, and then click **OK**.
