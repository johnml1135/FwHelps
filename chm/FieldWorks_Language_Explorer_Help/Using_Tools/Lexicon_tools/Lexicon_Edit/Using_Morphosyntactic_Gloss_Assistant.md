# Using Morphosyntactic Gloss Assistant

*Using Tools › Lexicon tools › Lexicon Edit*

For an inflectional affix, the **Morphosyntactic Gloss Assistant** (MGA) allows you to construct a gloss from a list of gloss components. The MGA also creates [inflection features](../../Grammar_tools/Inflection_Features/About_Infl_Features_and_Types.md) and [feature types](../../Lists_tools/Feature_Types/Feature_Types_overview.md).

The **Inflectional Affix Gloss Builder** link in the **New Entry** dialog box opens the MGA. The link is available when an affix is selected in the **Morpheme Type** box *and* **Inflectional** is selected in the **Affix Type** box.

Click the link to open the MGA, and then do the following:

1.  In the **List of possible gloss components** pane, expand the components that are applicable for the lexeme form (in the **New Entry** dialog box).

2.  Click a component you want, and then click **Insert** to copy it to the **Selected gloss components** pane.

    The component appears in the **Selected gloss components** pane *and* in a box near the top of the MGA (next to **Constructed gloss for**).

3.  Repeat the above steps until all the desired components are in the box near the top of the MGA.

    - Examine the gloss to make sure it is complete and that the components are in the desired order.

4.  If necessary, do one or more of the following:

    - To *reorder* the components, click one in the **Selected Gloss Components** pane, and then click **Move Up** or **Move Down**.

    - To *remove* a component, click it in the **Selected Gloss Components** pane, and then click **Remove**.

    - To *add* a component, click it in the **List of possible gloss components** pane, and then click **Insert**.

5.  Click **Accept Gloss**.

The gloss appears in the **Gloss** box of the **New Entry** dialog box. The features and feature types are added after you click **Create** in the **New Entry** dialog box. The features appear in the [Inflection Features](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Grammatical_Info_Details_fields/Inflection_Features_field.md) field.

> [!TIP]
>
> - To see information about the current (highlighted) gloss component, click **Show Info**.
>
> - The **Gloss List Item** box, **Modify** button, and **Show only the features and values I have used before** check box are *not* currently enabled.
