# Choose Type (Extended Note)

*Using Tools › Lexicon tools › Lexicon Edit*

You can choose a type for an existing [extended note](Insert_an_extended_note.md) at any time.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** column, click the desired entry.

3.  In the **Entry** pane, click the **Type** field for the extended note you will change, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

The **Choose Type** dialog box appears.

- If the **Extended Note Types** list [supports hierarchy](../../../User_Interface/Menus/Tools/Configure_List.md), expand the nodes (![](../../../assets/images/Plus_sign_box.GIF)) to see subitems.

- Select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times each type is used in the project.

- Click the extended note type you want to display.

If the type you want is *not* listed in the dialog box, click **Cancel**.

Then, [insert](../../Lists_tools/Insert_a_list_item.md) a list item in the **Extended Note Types** [list](../../Lists_tools/Lists_overview.md).

4.  Click **OK**.
