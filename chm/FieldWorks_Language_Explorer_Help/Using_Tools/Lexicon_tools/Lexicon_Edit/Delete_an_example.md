# Delete an example

*Using Tools › Lexicon tools › Lexicon Edit*

**Example** fields you can delete can be in a [sense or subsense](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Sense_level_fields_overview.md) or within an [Extended Note](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Extended_Note/Extended_Note_fields_overview.md).

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry that has the example you will delete.

3.  In the **Entry** pane, click the **Example** field label for example you will delete.

    A menu button (![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF)) appears.

4.  Click the menu button, and then click **Delete Example**.

    The **Delete Example** warning box appears.

5.  If you are sure you want to delete the current example and its translation, click **Delete**.
