# Choose Dialect Labels

*Using Tools › Lexicon tools › Lexicon Edit*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, if you cannot see the field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

A **Dialect Labels (Entry)** field appears at the [entry level](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Entry_level_fields_overview.md) and another one at the [variant level](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Variants_level_fields/Variant_level_fields_overview.md).

A **Dialect Labels (Sense)** field appears in each [sense and subsense](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Sense_level_fields_overview.md).

4.  Click the desired field, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

The **Choose Dialect Labels (Entry)** or **Choose Dialect Labels (Sense)** dialog box appears.

5.  Do any of these steps in the dialog box:

    - Select (![](../../../assets/images/User_Interface/Menus/Tools/Configure_Reversal_Index/CheckedBox.PNG)) **Display usage figures** to see how many times each **Dialect Labels** list item is used in the project.

    - Click the **Edit the Dialect Labels list** link to [insert](../../Lists_tools/Insert_a_list_item.md) or [edit](../../Lists_tools/Edit_a_list_item_or_subitem.md) list items.

    - Select (![](../../../assets/images/User_Interface/Menus/Tools/Configure_Reversal_Index/CheckedBox.PNG)) dialect labels you want to display. Click **OK**.

6.  Reorder the dialect labels if you chose more than one (*optional*):

    - Right-click one of the dialect labels in the field, and then click **Move Right** or **Move Left**.

    - Repeat this step until the order in the field and dictionary preview pane is correct.

> [!TIP]
>
> - You can choose a dialect label when you [insert a variant form](Insert_a_variant_form.md).
>
> - You can [bulk choose Dialect Labels](../Bulk_Edit_Entries/Bulk_choose_Dialect_Labels.md).
