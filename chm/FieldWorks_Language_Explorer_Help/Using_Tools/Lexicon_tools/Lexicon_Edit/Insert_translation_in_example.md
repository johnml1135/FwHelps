# Insert a translation in an example

*Using Tools › Lexicon tools › Lexicon Edit*

One or more **Translation** fields can appear with each **Example** field in a sense or subsense, and with each **Example** field in an **Extended Note**.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry that has the example into which you will add a translation.

3.  In the desired sense or subsense in the **Entry** pane, click the **Example** field label for the desired example.

    A menu button (![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF)) appears.

4.  Do one of the following:

    - Click the menu button, and then select **Insert Translation**.

    - Right-click the **Example** field label, and then select **Insert Translation**.

    A new **Translation** field is added. In a sense or subsense, an associated **Type** field also appears.

5.  Click the **Translation** field, and then enter (type or paste) a translation of the example.

    This field is a [single-line text field](../../../User_Interface/Field_Descriptions/Field_Types/Single_line_text_field.md). If more than one writing system line is displayed, enter the translation in the appropriate fields.

6.  For a sense or subsense, choose a translation type in the **Type** field.

> [!TIP]
>
> - In **Lists**, you can [insert additional Translation Types](../../Lists_tools/Insert_a_list_item.md).
>
> - You can insert or paste [links to external files](../../../Basic_Tasks/Creating_Hyperlinks/Creating_Hyperlinks_overview.md) in the **Example**, **Reference** and **Translation** fields.
