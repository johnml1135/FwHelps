# Choose a sense type

*Using Tools › Lexicon tools › Lexicon Edit*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** column, click the desired entry.

3.  In the dictionary preview pane, right-click **Entry** pane, if you cannot see the **Sense Type** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Click the **Sense Type** field for the applicable sense, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose Sense Type** dialog box appears.

5.  Do any of these steps:

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times each **Sense Type** list item is used in the project.

    - Click the **Edit the Sense Types** link to [insert](../../Lists_tools/Insert_a_list_item.md) or [edit](../../Lists_tools/Edit_a_list_item_or_subitem.md) **Sense Types** list items.

    - Click the sense type you want or **\<Empty\>** to clear the field. Click **OK**.
