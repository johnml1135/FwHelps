# Choose item for a custom list reference field (Lexicon)

*Using Tools › Lexicon tools › Lexicon Edit*

If you [add a custom field](../../../User_Interface/Menus/Tools/Custom_Fields/add_a_custom_field.md) that references items from an existing [list](../../Lists_tools/List_item_usage_table.md) or a custom list, choose items as follows:

1.  In the **Navigation Pane**, click **Lexicon Edit**.

2.  In the **Entries** pane, select the lexical entry.

3.  In the **Entry** pane, click the custom list reference field, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

A chooser dialog box appears.

4.  Do any of these steps:

    - If the desired list item or subitem is not listed in the dialog box, click the **Edit the** **\<name\>list** link (*if* available) so you can [insert](../../Lists_tools/Insert_a_list_item.md) it in the source list. Otherwise, click **Cancel**, and then [insert the item](../../Lists_tools/Insert_a_list_item.md) or [subitem](../../Lists_tools/Insert_a_list_subitem.md).

    - If available, select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times each item is used in the project.

    - For fields that allow *multiple* items, select (![](../../../assets/images/CheckedBox.PNG)) the items you want to display. Click **OK**.

    - For fields that allow only a single item, click the item you want to display. Click **OK**.
