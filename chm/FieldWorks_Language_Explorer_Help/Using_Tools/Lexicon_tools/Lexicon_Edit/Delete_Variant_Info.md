# Delete Variant Info

*Using Tools › Lexicon tools › Lexicon Edit*

In a variant entry, you can delete a set of fields referred to as a `Variant Info section`. This *also* deletes associated contents at the [Variants level](About_Lex_Edit_fld_levels.md) of each entry that was referenced in the [Variant of](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Variant_of_field.md) field that you delete.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired variant entry.

3.  In the **Entry** pane, if you cannot see an existing **Variant Type** field ([entry](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Entry_level_fields_overview.md) level) in the **Entry** pane, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Right-click the [Variant Type](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Variant_Type_field.md) field that is part of the **Variant Info** section you want to delete, and then click **Delete Variant Info** on the menu that appears.

The `Variant Info section` (**Variant Type**, **Variant of** and **Show Minor Entry** fields) is deleted. Also, in each entry that was referenced in the deleted **Variant of** field, the associated set of fields under **Variants** are deleted.
