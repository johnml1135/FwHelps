# Enter a comment

*Using Tools › Lexicon tools › Lexicon Edit*

You can enter prose comments with variants and complex forms.

## Overview

- For variants:

  - At the [entry level](About_Lex_Edit_fld_levels.md) of the entry that *is* the variant, there is a [Comment](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Comment_field.md) field with each [Variant Type](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Variants_level_fields/Variant_Type_field.md) field set.

  - At the [Variants level](About_Lex_Edit_fld_levels.md) of the entry that *has* a variant, there is a [Comment](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Variants_level_fields/Comment_field_Variants.md) field with each [Variant Form](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Variants_level_fields/Variant_Form_field.md) field set.

  These fields are two views of the same data. Therefore, when you enter or edit a comment about the variant in one of these **Comment** fields, the change appears in the *corresponding* **Comment** field.

<!-- -->

- For complex forms, the [Comment](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Comment_field.md) field appears with each [Complex Form Type](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Complex_Form_Type_field.md) field set.

## Steps

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry that has the variant field set or complex form field set.

3.  In the **Entry** pane, if you cannot see the **Comment** field in the field set, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  In the **Comment** field, click the line that shows the writing system you want to use (if more than one is shown), and then enter the comment.

    Repeat for other writing systems, if necessary.
