# Insert an allomorph

*Using Tools › Lexicon tools › Lexicon Edit*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  In the **Entry** pane, click the **Allomorphs** [field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Alternate_Forms_level_flds/Alternate_Forms_fld.md) label.

    Links and a menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF) appear.

5.  Do one of the following:

    - Click the menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF) next to the field label, and then click **Insert Allomorph**.

    - Click the **Insert Allomorph** link.

    - On the [Insert](../../../User_Interface/Menus/Insert/Insert_overview.md) menu, click **Allomorph**.

    - Click the menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Information_bar_Menu_button.PNG) on the [Information bar](../../../User_Interface/Toolbars/information_bar_overview.md), and then click **Insert Allomorph**.

    An empty set of fields appears. If the lexical entry is an affix, the field set is called **Affix Allomorph**; otherwise, it is called **Stem Allomorph**.

    If you have more than one *vernacular* writing system selected, there will be multiple lines in the **Stem Allomorph** or **Affix Allomorph** field, as they are [single-line text fields](../../../User_Interface/Field_Descriptions/Field_Types/Single_line_text_field.md).

6.  In the **Stem Allomorph** or **Affix Allomorph** field, enter the allomorph (for each displayed writing system, as necessary).

7.  [Change the morph type](change_the_morph_type.md), if necessary.

    Depending on the morph type you select, an *affix* allomorph may become a *stem* allomorph, or a *stem* allomorph may become an *affix* allomorph.

8.  [Choose environments](Choose_environments.md), if necessary.

9.  [Choose inflection classes](Choose_an_inflection_class.md), if necessary.

10. [Choose Stem Allomorph Labels](Choose_Stem_Allomorph_Label.md), if necessary.

11. [Choose inflection features](choose_inflection_features.md) in the **Required Features** field, if necessary.

> [!IMPORTANT]
>
> - Allomorphs and [Stem Allomorph Labels](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Alternate_Forms_level_flds/Stem_Allomorph_Label_fld_Allomorph.md) (for stem allomorphs) and [Required Features](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Alternate_Forms_level_flds/required_features.md) (for affix allomorphs) are used by the [parser](../../../User_Interface/Menus/Parser/Parsing_words_overview.md).
>
> - For more information, on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu point to **Resources**, and then click **Introduction to Parsing**. For example, see these sections:
>
> - - Section 2 to learn about inflection classes and inflection features.
>
>   - Section 3 to learn about allomorph environments and Stem Allomorph Labels.
>
>   - Section 4 to learn which morpheme types are significant to the parser, and the importance of the *order* of the allomorphs within a lexical entry.
