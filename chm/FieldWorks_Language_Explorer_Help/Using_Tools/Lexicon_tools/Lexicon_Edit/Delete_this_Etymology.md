# Delete this Etymology

*Using Tools › Lexicon tools › Lexicon Edit*

You can delete an **Etymology** field set that you previously [inserted](Insert_Etymology.md).

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry that has the **Etymology** you will delete.

3.  In the **Entry** pane, click the unwanted ![](../../../assets/images/minus_sign_box.GIF) **Etymology** field.

    The menu button (![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF)) appears.

4.  Click the menu button, or right-click the ![](../../../assets/images/minus_sign_box.GIF) **Etymology** field label, and then click **Delete this Etymology**.

    The **Delete Etymology** warning box appears.

5.  Click **Delete**.

    That **Etymology** field set is deleted.\
    An empty **Etymology** field remains.
