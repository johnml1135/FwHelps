# Insert a lexical relation

*Using Tools › Lexicon tools › Lexicon Edit*

At the [sense level](About_Lex_Edit_fld_levels.md), you can insert a lexical relation (such as *Antonym*) and then add a reference to it.\
For the *entry* level, see [Insert a cross reference lexical relation](Insert_a_CR_lexical_relation.md).

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, if you cannot see the **Lexical Relations** field in the desired sense or subsense, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Click the **Lexical Relations** field label to display the menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF) or right-click the label.

Then click one of the following:

1.  - **Insert** \<name\> **Relation** — this inserts that particular lexical relation.

      The **Add Reference** **(**\<name\>**)** dialog box appears. See [Add reference to lexical relation](Add_Reference_to_Lexical_Relation.md) for help with the dialog box.

    - **Create New Lexical Relation** — this opens the **Lexical Relations** tool (in **Lists**) *and* inserts a *new* lexical relation there.

      Select a reference set type for the new lexical relation, and then add information in the [fields](../../../User_Interface/Field_Descriptions/Lists/Lexical_Relations_fields/Lexical_Relations_fields_overview.md) to define the relation.\
      Click ![](../../../assets/images/User_Interface/Toolbars/GreenBackArrow.GIF) on the toolbar to return to **Lexicon Edit**.

      The new lexical relation is available for you to insert, as described above.
