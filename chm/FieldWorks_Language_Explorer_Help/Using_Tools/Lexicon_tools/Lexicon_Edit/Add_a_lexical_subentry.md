# Add a lexical subentry

*Using Tools › Lexicon tools › Lexicon Edit*

A *complex form* is a lexical entry that has *components*. **Components** fields are used to link a complex form to those forms that combine to make up the complex form. Complex forms can be of different [types](../../Lists_tools/About_Entry_Types.md).

How complex forms are displayed in **Dictionary** depends on a number of factors. A key factor is which [layout](../../../User_Interface/Menus/Tools/Configure_Dictionary/Dictionary_views.md) is used.

- In a *root*-based layout, complex forms are displayed as indented *subentries*. They are subordinated (indented) under one or more component entries.

- In a *lexeme*-based layout, complex forms are alphabetized with the other headwords, even those that are not complex. As such, there are no "subentries" in this layout.

There can be references to complex forms at which point you see them.

- In a [Hybrid layout](../../../User_Interface/Menus/Tools/Configure_Dictionary/About_the_Hybrid_Dictionary_view.md), complex forms appear as both full entries and possibly as subentries below one or more of their components.

Given that there are a number of factors, here is a high-level overview of the task of adding a lexical subentry.

1.  Create or [specify that a form is complex](Specify_that_Form_is_Complex.md).

2.  Choose the complex form in various fields, such as [Subentries](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Publication_Settings_flds/Subentries_(Publication_Settings).md) (**Publication Settings**) or [Subentries](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Subentries_(Sense).md) (**Senses**).

3.  [Configure](../../../User_Interface/Menus/Tools/Configure_Dictionary/Configure_Dictionary.md) the appropriate layout. You will use nodes like [Subentries](../../../User_Interface/Menus/Tools/Configure_Dictionary/Subentries.md) or [Minor Subentries](../../../User_Interface/Menus/Tools/Configure_Dictionary/Minor_Subentries_(Hybrid_view).md).

> [!TIP]
>
> - On the **Help** menu, point to **Resources**, and then click **Introduction to Lexicography**. There you can use find additional conceptual information about subentries.
