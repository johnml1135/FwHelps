# Insert Extended Note

*Using Tools › Lexicon tools › Lexicon Edit*

See [Extended Note fields overview](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Extended_Note/Extended_Note_fields_overview.md) for an overview of why you might want to insert one or more extended note field sets in your entry.

One **Extended Note** [field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Extended_Note/Extended_Note_field.md) is initially available in each sense or subsense.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, if you cannot see the **Extended Note** field in the desired sense or subsense, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Do any of these steps:

    - Click the empty **Extended Note** field and then start typing.

In this case, what you type appears in the **Discussion** field in the default analysis writing system.

1.  - Click anywhere in the sense and then click **Extended Note** on the **Insert** [menu](../../../User_Interface/Menus/Insert/Insert_overview.md).

    - Click an empty **Extended Note** field label to display the menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF). Click the menu button and then click **Insert Extended Note**.

    - Right-click the **Sense** field label and then click **Insert Extended Note**.

    - Right-click an empty **Extended Note** field label and then click **Insert Extended Note**.

    - The **Insert Extended Note** link appears with an existing **Extended Note** fields. Click it to insert another one.

A set of associated [fields](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Extended_Note/Extended_Note_fields_overview.md) appears.

5.  [Enter](Enter_Extended_Note.md) contents in the fields.

6.  [Reorder](Enter_Extended_Note.md) the extended notes if you inserted more than one and the order in **Dictionary** is not right.

7.  Do the steps above again if you want to insert another extended note. Alternatively, you might want to [insert](Insert_an_example_in_extended_note.md) another example.
