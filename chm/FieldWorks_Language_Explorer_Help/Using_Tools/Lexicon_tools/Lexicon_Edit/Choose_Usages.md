# Choose Usages

*Using Tools › Lexicon tools › Lexicon Edit*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, if you cannot see the **Usages** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  In applicable *sense*, click the **Usages** field, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose Usages** dialog box appears.

5.  Do any of these steps:

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times each **Usages** list item is used in the project.

    - Click the **Edit the list of Usages** link to [insert](../../Lists_tools/Insert_a_list_item.md) or [edit](../../Lists_tools/Edit_a_list_item_or_subitem.md) a **Usages** list item.

    - Select (![](../../../assets/images/CheckedBox.PNG)) one or more usages. Click **OK**.

> [!TIP]
>
> - The **Usages** list is *hierarchical*, so you may need to expand the list to open subitems in the dialog box.
>
> - You can use the [Usages](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Usages_field.md) field to help [specify publishable lexical data](Specify_publishable_lexical_data.md), and [bulk change publications](../Bulk_Edit_Entries/Bulk_change_publications.md).
>
> - For a more complete discussion about usages, such as when to use archaic or obsolete, on the **Help** menu point to **Resources** and then click **Introduction to Lexicography**.
