# Insert Pronunciation

*Using Tools › Lexicon tools › Lexicon Edit*

One **Pronunciation** field is initially available in each entry at the [entry level](About_Lex_Edit_fld_levels.md). You can insert more than one.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, if you cannot see the **Pronunciation** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Do any of these steps:

    - Click the empty **Pronunciation** field and then start typing.

In this case, what you type appears in the vernacular writing system that is at the top of the field.

1.  - On the **Insert** [menu](../../../User_Interface/Menus/Insert/Insert_overview.md), click **Pronunciation**.

    - Right-click an existing **Pronunciation** field label, and then select **Insert Pronunciation**.

    - Click an existing **Pronunciation** field label to display the menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF). Click the menu button, and then select **Insert Pronunciation**.

    - Click the menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Information_bar_Menu_button.PNG) on the [Information bar](../../../User_Interface/Toolbars/information_bar_overview.md), and then click **Insert Pronunciation**.

      A set of associated [fields](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Pronunciation_field.md) appears.

<!-- -->

5.  [Enter](Enter_a_Pronunciation.md) contents in the fields.

6.  [Reorder](reorder_pronunciations.md) the pronunciations if you inserted more than one and the order in **Dictionary** is not right.
