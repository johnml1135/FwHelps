# Delete an inflection feature

*Using Tools › Lexicon tools › Lexicon Edit*

You cannot select and delete an inflection feature from the **Inflection Features** field. Instead, do the following:

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry that has the feature you will delete.

3.  In the **Entry** pane, if you cannot see the **Inflection** **Features** field under the **Grammatical Info Details** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Click the **Inflection Features** field, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose Inflection Features** dialog box.

5.  Choose **None of the Above** or a different inflection feature.

6.  Click **OK**.

> [!IMPORTANT]
>
> - It is *strongly recommended* that you [contact](../../../Overview/Technical_support.md) a FLEx consultant before you overtly add or edit features or feature types. If these are not handled correctly, the parser may not analyze many of your word forms.
