# Move an example

*Using Tools › Lexicon tools › Lexicon Edit*

For senses with more than one example, you can move the examples up or down to change their order within the sense. In addition, using *two* open windows, you can use *drag and drop* to move an example and its associated fields to another existing sense or lexical entry.

## Move an example up or down

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the sense of the entry that has more than one example, click an **Example** field label.

    A menu button (![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF)) appears.

3.  Click the menu button, and then click one of the following commands:

    - **Move Example Up**

    - **Move Example Down**

    The examples and their associated fields are reordered.

## Move an example to another sense or lexical entry

1.  In the **Navigation** **Pane**, click **Lexicon**, and then select **Lexicon Edit**.

2.  [Resize](../../../User_Interface/Menus/Window/resizing_window_panes.md) the FLEx window so that it is *not* maximized (full screen). Otherwise the new window may be hidden behind the first window.

3.  On the **Window** menu, click **New Window**.

4.  With **Lexicon Edit** displayed in both windows, do the following:

    - In one window, select the *source* entry (has the **Example** field you will move).

    - In the other window, select the *destination* entry (the entry that has the sense into which you will move the example).

5.  Reposition and [resize](../../../User_Interface/Menus/Window/resizing_window_panes.md) the two windows, and then scroll the **Entry** panes, until you can see both

    - the **Example** field you want to move in the *source* entry window, *and*

    - an **Example** field which is not used in the *destination* entry window. Make sure that **Example** field is in the desired *sense*.

      **Tip:** [Collapse](../../../User_Interface/Menus/Window/resizing_window_panes.md) the width of the **Entries** panes. Then you can make both windows very narrow, but see the **Entry** panes fully.

6.  In the *source* **Entry** pane, click and hold the mouse button on the **Example** field label you want to move. Drag the mouse pointer over the **Example** field label in the *destination* entry, and then release the mouse button.

    The example and its associated fields move to the destination entry.

7.  Click the green arrow (![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/GreenRightArrow.PNG) or ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/green_left_arrow.GIF)) to return a collapsed pane to its previous width, if necessary.

> [!IMPORTANT]
>
> - When the mouse pointer is over an *invalid* drop location, it appears as a circle with a line through it.
>
> - When the mouse pointer is over a *valid* drop location, it changes back to your normal pointer, but with a small rectangle indicating there is content waiting to be dropped.
