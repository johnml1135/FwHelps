# Enter note content at the entry level

*Using Tools › Lexicon tools › Lexicon Edit*

It is recommended that you review the information in the [Note](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Note_field.md) field topic. It may help you decide what to put in the field.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, if you cannot see the **Note** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Click the [Note](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Note_field.md) field (or a particular line in it, if more than one writing system is displayed), and then enter content.

5.  Click other writing system lines in the current **Note** field, and then enter content, if necessary.
