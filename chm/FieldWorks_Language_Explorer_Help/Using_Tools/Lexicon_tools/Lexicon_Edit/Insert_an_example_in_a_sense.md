# Insert an example in a sense

*Using Tools › Lexicon tools › Lexicon Edit*

When you insert an example in a sense or subsense, you insert the [Example field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/example_field.md), [Translation field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Translation_field.md), [Reference field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Reference_field.md) and [Publish Example In field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Publish_In_(Example).md). The [Type field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Type_field.md) appears when the **Translation** field has contents. You can [insert other](Insert_translation_in_example.md) **Translation** and **Type** field pairs into an example.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, click the **Sense** field label for the sense or subsense into which you will insert an example.

    Links and a menu button (![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF)) appear.

4.  Do one of the following:

    - Click the menu button and then click **Insert Example**.

    - Right-click the **Sense** field and then click **Insert Example**.

    - Click the **Insert Example** link.

    The **Example** field, **Translation** field and **Reference** field appear.

5.  **Example** field:

Enter (type or paste) an example or use [find](Find_example_sentence.md) to copy an example and its translation from a [text](../../Texts_%26_Words_tools/Interlinear_Texts/texts_edit_overview.md).

This is a [single-line text](../../../User_Interface/Field_Descriptions/Field_Types/Single_line_text_field.md) field. If you have an [Audio](../../../Basic_Tasks/Audio_files/Audio_files_overview.md) writing system, you can record the example

6.  **Translation** field:

Enter a translation, or edit the copy of the translation found in a text.

7.  **Type** field:

Choose a translation type for the example, if there is not one already.

8.  **Reference** field:

Enter a reference, if there is not one already.

> [!TIP]
>
> - The **Translation Types** [list](../../Lists_tools/List_item_usage_table.md) stores the types. You can [insert list items](../../Lists_tools/Insert_a_list_item.md) to add more types.
>
> - You can insert or paste [links to external files](../../../Basic_Tasks/Creating_Hyperlinks/Creating_Hyperlinks_overview.md) in the **Example, Reference** and **Translation** fields.
