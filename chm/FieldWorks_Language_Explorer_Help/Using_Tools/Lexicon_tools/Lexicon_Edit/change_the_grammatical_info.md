# Change the Grammatical Info

*Using Tools › Lexicon tools › Lexicon Edit*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry you will change.

3.  In the **Entry** pane, find the **Grammatical Info** [field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Grammatical_Info_field.md) in the desired sense or subsense. Or, find the appropriate **Category Info** [field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Grammatical_Info_Details_fields/Category_Info_field.md) below **Grammatical Info Details**.

    - **See** ![](../../../assets/images/Important_Icon.gif) **Important** below.

> [!IMPORTANT]
>
> - Changes you make to in a **Grammatical Info** field for a particular sense or subsense are applied *only* to that sense or subsense. The **Grammatical Info Details** area updates *automatically*.
>
> - - However, if you edit grammatical information in a **Grammatical Info Details** area field, such as **Category Info**, then *all* senses or subsenses in the entry which use that grammatical information are updated.
>
> - Changes made in inflectional affix [template tables](../../Grammar_tools/Category_Edit/affix_template_table_example.md) affect the content in these fields, for example the [slots](../../Grammar_tools/Category_Edit/Edit_an_Affix_Template_Table.md) displayed.
>
> - [Parsers](../../../User_Interface/Menus/Parser/Parsing_words_overview.md) use grammatical information.

> [!NOTE]
>
> - The available selections vary depending on the morph type of the entry (root/stem, inflectional or derivational affix, and so on) and whether grammatical information was previously specified for the entry (for this or other senses/subsenses).
