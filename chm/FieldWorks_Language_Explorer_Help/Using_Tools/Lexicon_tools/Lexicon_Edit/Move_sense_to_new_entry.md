# Move a sense to new entry

*Using Tools › Lexicon tools › Lexicon Edit*

If you decide that a sense or subsense should be a separate lexical entry, you can move it to an automatically-created (*new*) entry. The new entry will have all of the entry-level content from the first entry.

Alternatively, you can [move it to another (existing) entry](Move_sense_to_another_entry.md).

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry with the sense or subsense you will move.

3.  In the **Entry** pane, click the **Sense** field label (sense *or* subsense) that you will move.

    A menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF) appears.

4.  Click the menu button, and then click **Move Sense to a New Entry**.

    A *new* lexical entry appears with the sense you moved. The entries will have homograph numbers.

> [!TIP]
>
> - This menu command is *not* available if the entry has only one sense.
>
> - If you want to duplicate an entry that has only one sense, [insert](Insert_a_sense_or_subsense_in_an_entry.md) a new sense and give it a different gloss. Then move that new sense to a new entry.
>
> - If the homograph numbers are not properly displayed, you can [refresh the screen](../../../User_Interface/Menus/View/View_overview.md) (`F5`) or run the language project utility to [reassign homographs](../../../User_Interface/Menus/Tools/Language_Project_Utilities_overview.md).
>
> - You can also [reorder or promote/demote](Reorder_demote_or_promote_a_sense.md) senses or subsenses.
