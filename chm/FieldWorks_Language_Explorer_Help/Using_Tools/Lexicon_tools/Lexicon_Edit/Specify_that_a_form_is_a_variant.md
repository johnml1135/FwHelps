# Specify that a form is a variant

*Using Tools › Lexicon tools › Lexicon Edit*

Typically, you [insert a variant form](Insert_a_variant_form.md) *of* an existing entry under the **Variants** field in that entry.

If an *existing* lexeme form is determined to *be* a variant form, do these steps:

1.  Do the applicable steps in the [Change the entry type](change_the_entry_type.md) topic.

2.  Clear (![](../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)) the **Show Minor Entry** [field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Publication_Settings_flds/Show_Minor_Entry_Pub_Set_level.md) check box if you do *not* want this variant form to be available for display as a [minor](../../../User_Interface/Menus/Tools/Configure_Dictionary/Main_Minor_entry.md) entry in **Dictionary**.

3.  You may want to [delete senses](delete_a_sense_or_subsense.md).

Consider that a "minor entry" is a short entry that refers the user to another entry where there is a full description of the headword.\
For example, if you [insert a variant form](Insert_a_variant_form.md) it is added without a [sense](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Sense_level_fields_overview.md).

> [!NOTE]
>
> - The **Show Minor Entry** [field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Publication_Settings_flds/Show_Minor_Entry_Pub_Set_level.md) check box is selected (![](../../../assets/images/CheckedBox.PNG)) by default.
>
> - [About "entry types"](../../Lists_tools/About_Entry_Types.md) describes variant [types](../../../User_Interface/Field_Descriptions/Lists/Variant_Types_flds/variant_types_flds_overview.md) that are installed with FieldWorks Language Explorer.
