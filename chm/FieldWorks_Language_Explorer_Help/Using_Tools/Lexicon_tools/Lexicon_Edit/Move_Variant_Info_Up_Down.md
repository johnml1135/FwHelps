# Move Variant Info Up Down

*Using Tools › Lexicon tools › Lexicon Edit*

For variant entries with more than one set of fields referred to as a `Variant Info section`, you can move a set of fields up or down to reorder them.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired variant entry.

3.  In the **Entry** pane, if you cannot see the **Variant Type** fields, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Right-click a [Variant Type](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Variant_Type_field.md) field, and then click **Move Variant Info Up** or **Move Variant Info Down** on the menu that appears.

5.  Repeat this until the order is as desired.

To set the order of the variant forms *by type*, see [Variant Forms](../../../User_Interface/Menus/Tools/Configure_Dictionary/Variant_Forms.md), [Variants of Sense](../../../User_Interface/Menus/Tools/Configure_Dictionary/Variants_of_Sense.md) or [Variant of](../../../User_Interface/Menus/Tools/Configure_Dictionary/Variant_of.md) (in **Configure Dictionary** dialog box).
