# Choose exception features

*Using Tools › Lexicon tools › Lexicon Edit*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** column, click the desired entry.

3.  In the **Entry** pane, if you cannot see any **Exception "Features"** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

    Different variations of the **Exception** **“Features”** fields may appear in the **Grammatical Info Details** area. For example, a derivational affix uses **From Exception** **“Features”** and **To Exception** **“Features”** fields, but a stem may use only one **Exception “Features”** field.

4.  Click the field for which you want to choose exception “features” and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose** (**From/To**) **Exception "Features"** dialog box appears.

5.  Do any of these steps:

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times each exception "feature" is used in the project.

    - Click the **Edit the Exception "Features"** link to [insert](../../Grammar_tools/Exception_Features/insert_an_exception_feature.md) or [edit](../../Lists_tools/Edit_a_list_item_or_subitem.md) **Exception "Features"** list items.

    - Select (![](../../../assets/images/CheckedBox.PNG)) exception "features" you want to display. Click **OK**.

6.  If the lexical entry has another field, such as a **To Exception “Features"** field paired with a **From Exception “Features”** field, repeat the above steps for that field.

> [!IMPORTANT]
>
> - **Exception "Features"** are used to restrict the productivity of certain affixes so that they only co-occur with stems that are tagged with the same set of exception “features.”
>
> You can also choose Exception "Features" that are used restrict the productivity of Compound Rules. **See:** [Exception "Features" field](../../../User_Interface/Field_Descriptions/Grammar/Compound_Rules_fields/Exception_Features_field_Comp_Rules.md).
>
> - For more information about exception "features," point to **Resources** on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
