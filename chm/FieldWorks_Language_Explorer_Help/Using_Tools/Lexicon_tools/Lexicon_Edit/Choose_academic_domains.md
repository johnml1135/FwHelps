# Choose academic domains

*Using Tools › Lexicon tools › Lexicon Edit*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** column, click the desired entry.

3.  In the **Entry** pane, if you cannot see the **Academic Domains** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  In the applicable sense, click the **Academic Domains** field, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose Academic Domains** dialog box appears.

5.  Do any of these steps:

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times each **Academic Domain** list item is used in the project.

    - Click the **Edit the Academic Domains** link to [insert](../../Lists_tools/Insert_a_list_item.md) or [edit](../../Lists_tools/Edit_a_list_item_or_subitem.md) an **Academic Domain** list item.

    - Select (![](../../../assets/images/CheckedBox.PNG)) one or more academic domains or subdomains. Click **OK**.

> [!TIP]
>
> - The **Academic Domains** list is hierarchical, so you may need to expand the list to find subdomains in the dialog box.
>
> - In "chooser" dialog boxes with check boxes, like this one, you can put the focus on an item with the arrow keys, and the press SPACEBAR to select ![](../../../assets/images/CheckedBox.PNG) or clear ![](../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG) the check box.
