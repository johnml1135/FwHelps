# Find example sentence

*Using Tools › Lexicon tools › Lexicon Edit*

The **Find example sentence** feature allows you to see the occurrences of the current sense (of the current lexical entry) in *interlinearized* texts. Selected occurrences are copied, along with any translation information, as examples. See ![](../../../assets/images/Important_Icon.gif) **Important** below.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry in which you want to copy one or more example sentences.

3.  In the **Entry** pane, if you cannot see the **Example** field (sense) or **Example** field (extended note), do one of the following:

    - [Show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

    - [Insert an example in the sense](Insert_an_example_in_a_sense.md).

    - [Insert an example in an extended note](Insert_an_example_in_extended_note.md).

4.  Click the **Example** field.

    A menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF) appears.

5.  Click the menu button, and then click **Find example sentence**.

    The **Find Example Sentence** dialog box appears.

    The **Concordance** pane displays each interlinearized occurrence of the current sense with a brief reference to the text and paragraph in which it is used. The **Sentence with Translations** pane shows the current sentence with any associated translations (*Free* and *Literal*).

6.  Do one or more of the following:

    - To *select* *all* displayed occurrences, click the check box ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Check_Box_Button2.GIF) button, and then click **Select All**.

    - To *clear* *all* check boxes, click ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Check_Box_Button2.GIF), and then click **Clear All**.

    - To *reverse* selected/cleared check boxes, click ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Check_Box_Button2.GIF), and then click **Toggle**.

    - Clear or select the check box at the left end of the row for one or more occurrences.

    - To change the displayed columns or open the [Configure Columns](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) dialog box, click the ([Configure Columns](../../../Basic_Tasks/Configure_Columns/configure_column_button_graphic.md)) button ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Check_Box_Button2.GIF).

7.  Click **Add**.

    The selected occurrence(s) are copied to the **Example** field.

    Any translations (*Free* and *Literal*) associated with each selected occurrence are also copied, along with their type. [Translation](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Translation_field.md) and [Type](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Type_field.md) fields are automatically added. The [Reference](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Reference_field.md) field shows the reference as a hyperlink you can click to see the text in **Interlinear Texts**.

> [!IMPORTANT]
>
> - The examples and translations are copied and are *not* live hyperlinks. So, if you edit a sentence or a translation in the **Baseline**, **Gloss** or **Analyze** [tabs](../../Texts_&_Words_tools/Interlinear_Texts/texts_edit_overview.md), those changes are *not* automatically reflected in the **Example** field.

> [!TIP]
>
> - The **Find example sentence** menu command appears if you right-click any **Example** field label. For examples in senses, but not in extended notes, it is also available in the menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF) that appears next to the **Sense** field label. You *cannot* access this feature on any [menu](../../../User_Interface/Menus/Menus_overview.md) or [toolbar](../../../User_Interface/Toolbars/Toolbars_overview.md).
