# Choose Slots

*Using Tools › Lexicon tools › Lexicon Edit*

In **Lexicon Edit**, the [Slots](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Grammatical_Info_Details_fields/Slots_field.md) field is only available for affix entries for which the **Affix Type** is set to **Inflectional**.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, if you cannot see the **Slots** field under the **Grammatical Info Details** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Click the **Slots** field, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose Slots** dialog box appears.

5.  Do any of these steps:

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times each slot is used in the project.

    - Click the **Edit slot for** **\<category\>** link to [insert](../../Grammar_tools/Category_Edit/Insert_an_Affix_Slot.md) or edit an affix slot.

    - Select (![](../../../assets/images/CheckedBox.PNG)) one or more affix slots you want to display. Click **OK**.

      The selected slot(s) appears in the **Slots** field. They also appear in the **Grammatical Info** field and its associated **Grammatical Info** column in the **Entries** pane, if displayed.

> [!TIP]
>
> - Other topics, such as [Grammatical Info field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Grammatical_Info_field.md) and [Category Info field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Grammatical_Info_Details_fields/Category_Info_field.md), have additional information about this field is populated.
