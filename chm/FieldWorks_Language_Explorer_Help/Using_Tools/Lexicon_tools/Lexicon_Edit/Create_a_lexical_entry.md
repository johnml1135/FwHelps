# Create a lexical entry (Create a lexical entry)

*Using Tools › Lexicon tools › Lexicon Edit*

*Ignore the first two steps below* if you accessed the **New Entry** dialog box from a different dialog box, such as [Find Lexical Entry](../../../User_Interface/Menus/Edit/Find_a_lexical_entry.md) or area, such as [Affix template table](../../Grammar_tools/Category_Edit/Edit_an_Affix_Template_Table.md) (**Grammar**), from a [word focus box](../../Texts_%26_Words_tools/Interlinear_Texts/Word_Focus_Box_examples.md) (**Texts**), or from a [fieldnote record](../../../User_Interface/Field_Descriptions/Notebook/Text_field_(Notebook).md) (**Notebook**). See ![](../../../assets/images/Important_Icon.gif) **Important** below.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**, **Browse** or **Dictionary**.

2.  Open the **New Entry** dialog box in one of these ways:

    - On the [Insert](../../../User_Interface/Toolbars/Insert_toolbar.md) toolbar, click ![](../../../assets/images/User_Interface/Toolbars/Insert_Lexical_Entry.GIF).

    - On the **Insert** menu, click **Entry**.

    - Press the [shortcut keys](../../../User_Interface/Shortcuts/shortcut_keys_Lexicon_tools.md) `Ctrl+E`.

3.  In the **Lexeme** **Form** box, enter the lexeme form. (You can [enter a citation form](Enter_a_citation_form.md) later.)

4.  If the **Similar Entries** pane lists an existing entry that you can use or modify (such as [insert a new sense](Insert_a_sense_or_subsense_in_an_entry.md)) click that entry, and then click the **Go to similar entry** link.

5.  If there is *not* a similar entry, then do the following:

    - In the **Morpheme Type** box, select the [morpheme type](../../Lists_tools/About_Morpheme_Types.md) for the new entry.

      The **Morpheme Type** box selection determines which boxes are available in the **Grammatical Info** pane. For affixes, the **Affix Type** box content further determines which boxes are available.

    - If the lexeme form is *complex* (has *components*, such as [multi-word expression](../../../User_Interface/Field_Descriptions/Lists/Complex_Form_Types_flds/Idiom_entry_type.md)), select a **Complex Form Type**.

    - If the **Grammatical Info** area shows the **Category** box, select the category for the new entry or **More** to open the [Add from Catalog](Using_Add_from_Catalog_dialog_box.md) dialog box.

    - If the **Grammatical Info** area shows the **Affix Type** box, select the affix type. Then, select content for the **Attaches to Category** box. Then, select content for *either* the **Changes to Category** or the **Fills Slot** box, depending on which is displayed.

      The **Fills Slot** box is *unavailable* if *no* slots have been [added](../../Grammar_tools/Category_Edit/Insert_an_Affix_Slot.md) in [Category Edit](../../Grammar_tools/Category_Edit/Category_Edit_overview.md) for the selected category.

    - In the **Gloss** box, enter a gloss for the new entry.

      - The [Morphosyntactic Gloss Assistant](Using_Morphosyntactic_Gloss_Assistant.md) (MGA) is available for inflectional affixes. Click the **Inflectional Affix Gloss Builder** link to open it. The MGA helps you construct the gloss. The gloss is added to the *default* (top) writing system in the **Gloss** box. The MGA also creates [inflection features](../../Grammar_tools/Inflection_Features/About_Infl_Features_and_Types.md) and feature types.

    - Click **Create**.

If you are not in the **Lexicon Edit** view, you can click **Create and Edit**. This opens a pop-up dialog box that is like the **Lexicon Edit** [view](lexicon_edit_overview.md).

6.  Select, choose, insert, or enter content in other lexical [fields](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Lexicon_Edit_fields_overview.md), as appropriate. You can do this in the view or in the pop-up dialog box.

> [!IMPORTANT]
>
> - If you jumped to the **New Entry** dialog box from another dialog box (such as clicking **Create** in the [Find Lexical Entry](../../../User_Interface/Menus/Edit/Find_a_lexical_entry.md) dialog box), then the **Lexeme Form** box usually contains content when **New Entry** dialog box opens. If the **Writing System** box in the **Find Lexical Entry** dialog box was set to an *analysis* writing system, the **Lexeme Form** box content is in an analysis writing system. Language Explorer permits you to create a lexical entry, *but that entry will not have a headword* because lexeme forms and citation forms use vernacular writing systems.
>
> - FLEx will remove any **Complex Form Info** section fields *if you leave the entry before* you [choose](Choose_components_for_Components_field.md) components. This prevents entries from being partially-defined complex forms. In this case, see [Change the "entry type"](change_the_entry_type.md).
>
> - Grammatical categories are organized *hierarchically*. The particular hierarchy in your language project affects how Language Explorer handles categories for derivational affixes, Stem Allomorph Labels and so on. See [Category Edit overview](../../Grammar_tools/Category_Edit/Category_Edit_overview.md) for more information.
>
> - If you selected \<**Not Sure\>** in the **Affix Type**, then **Grammatical Info Details** in the Lexicon may be empty, or may display that the entry is an affix found on the selected part of speech.
>
> <!-- -->
>
> - From a word focus box, if you select **Create New Entry**, the **Go to similar entry** link changes to Add allomorph to similar entry.
>
> - [Change homograph numbers](../Browse/Change_homograph_numbers.md) includes considerations for homograph orders.
>
> - If necessary, see Section 2.1.5 **Derivation versus Inflection** in the document *A Conceptual Introduction to Morphological Parsing* which you access from the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu.
