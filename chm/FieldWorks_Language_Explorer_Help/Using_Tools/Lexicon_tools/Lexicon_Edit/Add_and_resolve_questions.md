# Add and resolve questions/messages

*Using Tools › Lexicon tools › Lexicon Edit*

The **Send/Receive** [menu](../../../User_Interface/Menus/Send_Receive/Send_Receive_menu.md) has commands you can use to view messages (questions, notifications, and conflicts) that collaborators exchange.

You can *also* work with them in the **Messages** field in individual lexical entries.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the applicable entry.

3.  In the **Entry** pane, if you do not see a **Messages** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  In the [Messages](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Messages_field.md) field, click the appropriate button :

    - Click ![PIC](../../../assets/images/User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Question_ADD.png) to add a new question in the **Question about** dialog box.

    - Click ![PIC](../../../assets/images/User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Question_Has.png), ![PIC](../../../assets/images/User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/NotificationIcon.png), or ![PIC](../../../assets/images/User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/ConflictIcon.png) to open an existing message in a dialog box.

5.  Do any of the following in the dialog box:

    - Type a message.

    - Click ![PIC](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/ResolvedMessage.png) **Resolve Note** in the dialog box when the message had been sufficiently answered and any necessary action has been taken.

    - Clear ![PIC](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/ResolvedMessage.png) **Unresolve Note** to reopen the message for further discussion.

6.  Click **OK**.

The dialog box closes.

> [!IMPORTANT]
>
> - *Context-sensitive* right-click menu commands are available in the **Question about** dialog box.
>
> - - **Print Preview**, **Print**, **Export**, **Send to** and more are listed, depending whether you have used **Select All** or not.
>
> - Currently, you cannot edit existing questions or messages.
