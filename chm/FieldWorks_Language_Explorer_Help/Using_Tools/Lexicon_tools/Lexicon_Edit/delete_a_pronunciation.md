# Delete a pronunciation

*Using Tools › Lexicon tools › Lexicon Edit*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry that has the pronunciation you will delete.

3.  In the **Entry** pane, click the unwanted **Pronunciation** field.

    A menu button (![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF)) appears.

4.  Do one of the following:

    - Click the menu button, and then select **Delete this Pronunciation**.

    - Right-click the **Pronunciation** field label, and then select **Delete this Pronunciation**.

    The **Delete Pronunciation** warning box appears.

5.  Click **Delete**.

    The following fields are deleted: **Pronunciation** field and its associated fields, **Media File** field (and any [links to media files](Insert_link_to_sound_or_movie.md), but the actual files are not deleted), and the **Label** field.
