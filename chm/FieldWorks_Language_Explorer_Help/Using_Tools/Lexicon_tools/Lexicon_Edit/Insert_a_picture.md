# Insert a picture

*Using Tools › Lexicon tools › Lexicon Edit*

In any sense or subsense of a lexical entry, you can insert one or more pictures. If you will use [Webonary](../../../User_Interface/Menus/File/Export/Webonary.md), see [Upload to Webonary](../../../User_Interface/Menus/File/Upload_to_Webonary.md) to learn which picture file formats Webonary supports.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, click the **Sense** field label (**Sense 1**, **Sense 1.1**, **Sense 2** and so on) for the sense or subsense into which you will insert a picture.

    A menu button (![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF)) appears.

4.  Do one of the following:

    The **Picture Properties** dialog box appears.

    - Click the menu button, and then click **Insert Picture**.

    - Right-click the label, and then click **Insert Picture**.

    - On the **Insert** menu, click **Picture**.

5.  [Use](Use_the_Picture_Properties_dialog_box.md) the **Picture Properties** dialog box to choose and crop (if necessary) the desired picture.

6.  Copyright and license metadata:

You might see existing metadata that you need to use but cannot change.

Otherwise, click Set up metadata and then [use](Using_Credit_Copyright_License_dialog_box.md) the **Credit, Copyright and License** dialog box to specify this metadata. Or, if there is existing metadata that you set up and can use again, click **Use**.

7.  If the picture in the **File** path is already in the **Pictures** [folder](../../../User_Interface/Menus/File/Backup_and_Restore/Folder_Structure.md), the path to that file appears below the picture.

If the picture in the **File** path is *not* already in the **Pictures** folder or a custom subfolder, a **File Location Options** pane appears in the dialog box.

Select one of the following:

- **Copy to Linked Files folder** (*recommended*).

- **Move to Linked Files folder**

- **Leave in original folder**.

If necessary, click the **File** name box and edit the file name.

If necessary, click the button next to the **Destination** box, and select a different folder.

8.  Click **OK**.

The picture appears in the **Picture** [field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Picture_field.md) and **Thumbnail** [field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Thumbnail_field.md), depending on your [field visibility](../../../Basic_Tasks/Showing_and_hiding_fields/change_the_visibility_of_fields.md) settings.

The path and file name appear in the **File** [field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/File_field.md).

Review the publications in the **Publish Picture** **In** [field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Publish_In_(Pictures).md). Remove or add [publications](../../../User_Interface/Field_Descriptions/Lists/Publications/What_is_a_Publication.md) as desired.

9.  Click the **Caption** [field]() and then type or paste a caption in one or more writing systems.

10. To choose a different picture, delete the exiting picture and insert another one.

> [!TIP]
>
> - See also: [Linked Files tab](../../../User_Interface/Menus/File/Project_Properties/Project_Properties_Linked_Files_tab.md) and **Linked Files** [folder](../../../User_Interface/Menus/File/Backup_and_Restore/Folder_Structure.md).
>
> - If you selected **Leave in original folder**, you can right-click the picture or thumbnail to open the Picture Properties dialog box again, and then copy or move the picture at that time.
>
> - If you have more than one picture in a sense or subsense, use **Move Up** or **Move Down** on the menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF) to reorder the pictures.
