# Enter Extended Note information

*Using Tools › Lexicon tools › Lexicon Edit*

1.  [Insert Extended Note](Insert_an_extended_note.md).

The **Extended Note** field becomes a header field to a [set of fields](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Extended_Note/Extended_Note_fields_overview.md).

If necessary, [configure the writing systems](../../../Basic_Tasks/Showing_Writing_Systems/configure_field_WSs.md) in any of the fields.

2.  Do any of these steps:

    - **Discussion** field:

Enter (type or paste) information.

2.  - **Type** field:

[Choose](Choose_a_note_type.md) a type that is appropriate for the information in the **Discussion** field.

2.  - **Example** field:

[Insert](Insert_an_example_in_extended_note.md) an example.

The **Find example sentence** command appears only after you use the **Insert Example in Note** command.

2.  - **Translation** field:

Enter or edit the translation of the example.

3.  Do any of these steps (*optional*):

    - [Choose](Choose_a_note_type.md) a *different* type for an extended note.

    - [Insert](Insert_an_example_in_extended_note.md) *another* example in an extended note.

      - Reorder examples, if an extended note has more than one:\
        Right-click one of them, and then click **Move Example Up** or **Move Example Down**.

    - Insert *another* extended note in the same sense or subsense by clicking the **Insert Extended Note** link.

      - Reorder extended notes, if a sense or subsense has more than one:\
        Right-click one of them, and then click **Move Extended Note Up** or **Move Extended Note Down**.
