# Delete a picture

*Using Tools › Lexicon tools › Lexicon Edit*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry that has the picture you will delete.

3.  In the **Entry** pane, click any of the picture field labels (**Picture**, **Thumbnail**, **Caption** or **File**) for the picture you will delete.

    A menu button (![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF)) appears.

4.  Click the menu button, and then select **Delete Picture**.

    The **Delete Picture** warning box appears.

5.  Click **Delete**.

    The picture and its associated fields (**Picture**, **Thumbnail**, **Caption** and **File**) are removed from the lexical entry. However, any copy of the picture remains in your **Pictures** [folder](../../../User_Interface/Menus/File/Backup_and_Restore/Folder_Structure.md).

6.  Manually delete any pictures that you will never use or that others should never see.
