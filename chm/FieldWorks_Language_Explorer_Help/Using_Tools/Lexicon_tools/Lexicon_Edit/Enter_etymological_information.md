# Enter etymological information

*Using Tools › Lexicon tools › Lexicon Edit*

1.  [Insert Etymology](Insert_Etymology.md).

The **Etymology** field becomes a header field to a [set of fields](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Etymology_fields_overview.md).

If necessary, [configure the writing systems](../../../Basic_Tasks/Showing_Writing_Systems/configure_field_WSs.md) in any of the fields.

2.  Do any of these steps:

    - **Preceding Annotation** field:

Enter (type or paste) a word, phrase or symbol to introduce the etymology or borrowing, such as *from*, *borrowed from, possibly* or \<.

2.  - **Source Form** field:

Enter the etymon or proto form of the headword. You can enter them in one or more different writing systems.

2.  - **Source Language** field:

[Choose](Choose_a_source_language.md) one or more source languages that correspond to the contents in the **Source Form** field.

2.  - **Source Language Notes** field:

Enter information about the source language or languages.

2.  - **Gloss** field:

Enter the gloss of the form or forms in the **Source Form** field.

2.  - **Following Comment** field:

Enter a brief comment than you want to see at the end of the etymological information in the dictionary entry.

2.  - **Bibliographic Source** field:

Enter the source of the etymological information.

2.  - **Etymological Note** field:

Enter a note for the lexicographer (not for publication).

3.  [Insert](Insert_Etymology.md) another set of fields for other etymological information, if necessary.

4.  [Reorder](Reorder_Etymologies.md) the etymologies if you inserted more than one and the order in **Dictionary** is not right.

> [!IMPORTANT]
>
> - Contents from these [fields](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Etymology_fields_overview.md), except **Etymological Note**, can be displayed in **Dictionary** when you configure [Etymology](../../../User_Interface/Menus/Tools/Configure_Dictionary/Etymology.md).
