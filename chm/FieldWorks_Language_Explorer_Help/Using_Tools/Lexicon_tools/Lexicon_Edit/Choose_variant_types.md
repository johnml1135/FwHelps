# Choose variant types

*Using Tools › Lexicon tools › Lexicon Edit*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired variant entry.

3.  In the **Entry** pane, a variant entry can have multiple **Variant Type** fields. So, click the appropriate **Variant Type** field, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose Variant Type** dialog box appears.

4.  Do any of these steps:

    - Click the ![](../../../assets/images/User_Interface/Field_Descriptions/Field_Types/Plus_sign_box.GIF) (plus sign) to expand an item, if necessary.

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times each **Variant Types** list item is used in the project.

    - Click the **Edit the Variant Types** link to [insert a new type](../../Lists_tools/Insert_a_list_item.md) or [subtype](../../Lists_tools/Insert_a_list_subitem.md) in the **Variant Types** list.

    - Select (![](../../../assets/images/CheckedBox.PNG)) one or more variant types or **Unspecified Variant**. Click **OK**.

> [!IMPORTANT]
>
> - **Unspecified Variant** appears in **Variant Type** fields until you choose another type from the **Variant Types** [list](../../Lists_tools/List_item_usage_table.md).
>
