# Choose anthropology categories (Lexicon)

*Using Tools › Lexicon tools › Lexicon Edit*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, if you cannot see the **Anthropology Categories** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  In the applicable sense, click the **Anthropology Categories** field, and then do one of the following:

    - Type the name or abbreviation of a category directly in the field. Click the desired category in the drop-down list. Repeat, as needed. In this case, you are done.

    - Click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears. Then continue.

      The **Choose** **Anthropology Categories** dialog box appears.

5.  Do any of these steps:

    - Click the ![](../../../assets/images/Plus_sign_box.GIF) (plus sign) to expand an anthropology category item.

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times each **Anthropology Category** list item is used in the project.

    - Click the **Edit the Anthropology Categories** link to [insert](../../Lists_tools/Insert_a_list_item.md) or [edit](../../Lists_tools/Edit_a_list_item_or_subitem.md) an **Anthropology Category** list item.

    - Select (![](../../../assets/images/CheckedBox.PNG)) one or more anthropological categories. Click **OK**.
