# Enter a scientific name

*Using Tools › Lexicon tools › Lexicon Edit*

The [Scientific Name](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/scientific_name_field.md) field uses the default (top-most) *analysis* [writing system](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md). However, you can use any writing system you have added to the language project.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, if you cannot see the **Scientific Name** field in the desired sense, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Click the **Scientific Name** field, and type the scientific name.

    - If necessary, use the [Format](../../../User_Interface/Toolbars/Format_toolbar.md) toolbar to select a different writing system.
