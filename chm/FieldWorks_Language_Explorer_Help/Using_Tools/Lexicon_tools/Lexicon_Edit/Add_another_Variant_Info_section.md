# Add another Variant Info section

*Using Tools › Lexicon tools › Lexicon Edit*

An entry that [is a variant](change_the_entry_type.md) has this set of fields: [Variant Type](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Variant_Type_field.md), [Variant of](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Variant_of_field.md) and [Comment](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Comment_field.md). This set of fields is called a `Variant Info section`.

For a variant entry that is a variant of more than one entry, consider the following:

- If the variant type is the same for each one, choose multiple entries or senses in the **Variant of** field.

- If the variant type is different for some entries or senses, add a **Variant Info section** for each different variant type.

Add another **Variant Info section** as follows:

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry that is a variant.

3.  If necessary, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  In the **Entry** pane, do one of the following:

    - Right-click an existing [Variant Type](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Variant_Type_field.md) field, and then click **Add another Variant Info section** on the menu that appears.

    - On the [Information bar](../../../User_Interface/Toolbars/information_bar_overview.md), click the menu button ![PIC](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Information_bar_Menu_button.PNG), then click **Lexeme Form is a variant**.

A new set of fields is added.

5.  In the **Variant Type** field, [choose one or more variant types](Choose_variant_types.md).

6.  In the **Variant of** field, [choose a Variant of entry or sense](Choose_Variant_of_entry.md).

7.  In the **Comment** field, enter a comment (*optional*).
