# Move a Pronunciation

*Using Tools › Lexicon tools › Lexicon Edit*

Using *two* open windows, you can use *drag and drop* to move a pronunciation and its associated fields to another lexical entry.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  On the **Window** menu, click **New Window**.

3.  In one window, select the *source* entry (has the **Pronunciation** field you will move). In the other window, select the *destination* entry (where you want to move the pronunciation).

4.  Reposition and resize the two windows until you can see the **Pronunciation** field you want to move in the *source* entry window, and see an existing **Pronunciation** field in the *destination* entry window. **Tip:** Minimize the width of the **Entries** pane(s) to help you resize the windows such that you can easily see the fields.

5.  In the destination entry, right-click an unused **Pronunciation** field label, and then select **Insert Pronunciation** in the menu that appears.

    The fields that are associated with the **Pronunciation** field (**CV Pattern**, **Tone**, and **Location**) are added below the **Pronunciation** field.

6.  In the source **Entry** pane, click and hold the mouse button on the **Pronunciation** field label you want to move. Drag the mouse pointer over the newly inserted **Pronunciation** field label in the destination entry.

    When the mouse pointer is over an *invalid* drop location it appears as a circle with a line through it.

    When the mouse pointer is over a *valid* drop location, it changes back to your normal pointer, but with a small rectangle indicating there is content waiting to be dropped.

7.  Release the mouse button.

    The pronunciation fields are moved from the source to the destination entry.
