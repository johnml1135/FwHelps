# Using Edit Grammatical Info dialog box

*Using Tools › Lexicon tools*

- The **Edit Grammatical Info** (*or* [Create New Grammatical Info](Using_Create_New_Grammatical_Info_dialog_box.md)) dialog box opens from the **Grammatical Info** field in a [sense](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Sense_level_fields_overview.md) or subsense.

- The **Edit Category Info** dialog box opens from the **Category Info** field.

The features in these dialog boxes change depending on the *morph type* and *affix type* (for an affix) of the lexical entry.

**See:** [Change the Grammatical Info](change_the_grammatical_info.md).

1.  For a *stem* or *root*, in the **Category** box, select an existing category or **\<Not Sure\>**, or select **More** so you can [add one from the catalog](Using_Add_from_Catalog_dialog_box.md).

2.  For an *affix*, do the following:

    - In the **Affix Type** box, select **Not Sure**, **Inflectional** or **Derivational**.

    - In the **Attaches to Category** box, select an existing category, **\<Any\>** or **More** so you can [add one from the catalog](Using_Add_from_Catalog_dialog_box.md).

    - For an *inflectional* affix, select a slot in the **Fills Slot** box.

      If the **Fills Slot** box is *not* available, you need to [insert an affix slot](../../Grammar_tools/Category_Edit/Insert_an_Affix_Slot.md) for the category that is selected in the **Attaches to Category** box.

    - For a *derivational* affix, in the **Changes to Category** box, select an existing category, **\<Any\>** or **More** so you can [add one from the catalog](Using_Add_from_Catalog_dialog_box.md).

3.  Click **OK**.

> [!TIP]
>
> - Grammatical categories are organized hierarchically in Language Explorer. The particular hierarchy in your language project can affect how categories are handled. [Category Edit overview](../../Grammar_tools/Category_Edit/Category_Edit_overview.md) has more information.
