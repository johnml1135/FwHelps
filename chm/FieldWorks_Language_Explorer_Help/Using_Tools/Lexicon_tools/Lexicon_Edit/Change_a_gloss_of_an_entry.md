# Change or enter a gloss

*Using Tools › Lexicon tools › Lexicon Edit*

You normally enter a gloss in the [New Entry](Create_a_lexical_entry.md) dialog box, or possibly when you use [Collect Words](../Collect_Words/Collect_Words_overview.md).

To change or enter a gloss, see [Fill in the Gloss field](../../../Lexicography_Tasks/Fill_in_the_Gloss_Field.md) (using **Bulk Edit Entries**) *or* do the following steps:

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, if you cannot see the **Gloss** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  In the **Gloss** field, click the line that shows the writing system you want to use (if more than one is shown), and then edit or enter the gloss.

    Repeat for other writing systems, if necessary.

> [!IMPORTANT]
>
> - The [Gloss](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Gloss_field_Sense.md) field stores glosses in each **Sense**. They are [single-line text](../../../User_Interface/Field_Descriptions/Field_Types/Single_line_text_field.md) fields, so you can enter a gloss in each available [analysis writing system](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md).
>
> - As you [gloss a text](../../Texts_%26_Words_tools/Interlinear_Texts/specify_the_word_gloss.md) or [analyze a text](../../Texts_&_Words_tools/Interlinear_Texts/Analyze_Text_overview.md), existing glosses are available for selection or you can add more *while* you gloss or analyze text.
