# Using Add from Catalog dialog box

*Using Tools › Lexicon tools › Lexicon Edit*

The **Add from Catalog** dialog box allows you to select a predefined grammatical category. It provides descriptions to help you select the right one. You can create a custom category, if necessary.

- In the **Add from Catalog** dialog box, do *one* of the following:

  - In the **Grammatical Category Catalog** pane, select a category. Click **Add**.

    The selected category is added to the dialog box, field or list from which you opened the dialog box.

  - Click the **Create a custom category** link.

    The dialog box closes and the window changes to display a new (not completed) category in [Category Edit](../../Grammar_tools/Category_Edit/Category_Edit_overview.md) (**Grammar**) or [Reversal Index Categories](../../Lists_tools/about_reversal_index_categories.md) (**Lists**). Add the name, abbreviation and other data to complete the new category. Then, click the "back" button ![](../../../assets/images/User_Interface/Toolbars/GreenBackArrow.GIF) to return to the previous window.

>
> - Here, the term "category" means *category* or *subcategory*.
