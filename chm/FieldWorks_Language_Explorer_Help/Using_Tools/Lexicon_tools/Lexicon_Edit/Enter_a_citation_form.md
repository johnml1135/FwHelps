# Enter a citation form

*Using Tools › Lexicon tools › Lexicon Edit*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry in which you will enter a citation form.

3.  In the **Entry** pane, if you cannot see the [Citation Form](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Citation_Form_field.md) field (located below the [Lexeme Form](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Lexeme_Form_field.md) field), [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Click the **Citation Form** field, and then enter the citation form.

    The **Citation Form** field content *replaces* the **Lexeme Form** field content as the **headword** of the entry.

> [!NOTE]
>
> - If the **Lexeme Form** field contains a bound stem or bound root ([Morpheme Type](../../Lists_tools/About_Morpheme_Types.md)), but the **Citation Form** field content is *not* a bound form, the display of the “bound” token with the headword is *not* correct.
>
>   Currently, to remove the [token](../../Lists_tools/Change_the_tokens_for_morpheme_types.md) from the headword, you need to delete the token from the bound stem or bound root morpheme type in [Lists](../../Lists_tools/Lists_overview.md). This will, of course, remove it for *all* those bound forms.
>
>   You can see these changes in the [dictionary preview](../../../User_Interface/Menus/View/View_overview.md) pane and **Headword** column, if displayed.
