# Resolve conflicts and notifications

*Using Tools › Lexicon tools › Lexicon Edit*

In the [Messages](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Messages_field.md) field, do these steps:

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** column, click the desired entry.

3.  In the **Entry** pane, if you cannot see the **Messages** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Click the appropriate button in the **Messages** field:

    - Click ![](../../../assets/images/User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/ConflictIcon.png) or ![](../../../assets/images/User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/ResolovedConflictIcon.png) to open the **Merge Conflict** dialog box.

    - Click ![](../../../assets/images/User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/NotificationIcon.png) or ![](../../../assets/images/User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/resolvedNotification.png) to open the **Merge Report** dialog box.

5.  Do any of the following in the dialog box:

    - Type a message.

    - Click ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/ResolvedMessage.png) **Resolve Note** in the dialog box when the message had been sufficiently answered and any necessary action has been taken.

    - Clear ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/ResolvedMessage.png) **Unresolve Note** to reopen the message for further discussion.

6.  Click **OK**.

The dialog box closes.

> [!IMPORTANT]
>
> - *Context-sensitive* right-click menu commands are available in the dialog boxes.
>
> - - **Print Preview**, **Print**, **Export**, **Send to** and more are listed, depending whether you have used **Select All** or not.
>
> - Currently, you cannot edit existing messages in these dialog boxes.
>
> - *Alternatively*, open messages from the **Send/Receive** menu.
