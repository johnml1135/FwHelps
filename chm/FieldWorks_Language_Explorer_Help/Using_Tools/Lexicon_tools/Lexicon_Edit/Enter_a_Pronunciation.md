# Enter a pronunciation

*Using Tools › Lexicon tools › Lexicon Edit*

1.  [Insert Pronunciation](Insert_a_pronunciation.md).

A [set of fields](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Pronunciation_field.md) is added.

2.  If necessary, do any of these steps:

    - [Select](select_pronunciation_writing_systems.md) additional writing systems for the **Pronunciation** field.

    - [Insert](Insert_a_pronunciation.md) another **Pronunciation** field set if necessary.

      For example, the English word `either` may be pronounced ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/EitherIPA.GIF).

    - Start *Keyman*, if it is needed for a writing system but is not already turned on.

<!-- -->

3.  Do any of these steps for each pronunciation:

    - [Pronunciation](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Pronunciation_field.md) field: enter the pronunciation of the headword in one or more of the writing systems displayed in the field.

    - [CV Pattern](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/cv_pattern_field.md) field: enter the representation of the phonological pattern as entered in the **Pronunciation** field (IPA writing system).

    - [Tone](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Tone_field.md) field: enter the tone.

    - [Location](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Location_field.md) field: choose the location where this pronunciation is used. If the desired location is not listed, click the **Edit the Locations list** link so you [can insert the location](../../Lists_tools/Insert_a_list_item.md).

    - [Publish Pronunciation In](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Publish_In_(Pronunciations).md) field: [choose publications](Choose_Publish_In_publications.md).

    - [Insert sound or movie files](Insert_link_to_sound_or_movie.md), if any, so you can hear the actual pronunciation. Then, enter a description of the file or files in the associated [Label](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/label_field.md) field.

    - Use an [audio variant](../../../Advanced_Tasks/Writing_Systems/Modifying_a_Writing_System/Using_the_Writing_System_Properties_dialog_box.md) to record [audio files](../../../Basic_Tasks/Audio_files/Audio_files_overview.md) of the pronunciations.

    4.  [Reorder](reorder_pronunciations.md) the pronunciations if you inserted more than one and the order in **Dictionary** is not right.

> [!IMPORTANT]
>
> - You *cannot* apply a style (formatting) to text in the **Pronunciation** field. If you paste in a pronunciation, any styles are automatically removed.
>
>   You can change the **Normal** [style](../../../User_Interface/Menus/Format/Styles/Styles_overview.md), for example, for variant writing systems so each appears differently in the **Lexicon Edit** and **Browse** views.
>
>   In addition, you can specify styles for use in the **Dictionary**, using [Configure Dictionary View](../../../User_Interface/Menus/Tools/Configure_Dictionary/Configure_Dictionary.md).

> [!TIP]
>
> - You can use **Bulk Edit Entries** features to [fill in the Pronunciation field](../../../Lexicography_Tasks/Fill_in_the_Pronunciation_Field.md), and then to [fill in the CV Pattern field](../../../Lexicography_Tasks/Fill_in_the_CV_Field.md) ([add](../../../Lexicography_Tasks/Bulk_add_CV_Pattern.md) and [change](../../../Lexicography_Tasks/Bulk_change_CV_Pattern.md) **CV Pattern** field content). You can also [fill in the Tone field](../../../Lexicography_Tasks/Fill_in_the_Tone_Field.md).
