# Specify a Form is Abstract

*Using Tools › Lexicon tools › Lexicon Edit*

- When selected (![](../../../assets/images/CheckedBox.PNG)), **Is Abstract Form** instructs the selected [parser](../../../User_Interface/Menus/Parser/Parsing_words_overview.md) to ignore the [lexeme form](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Lexeme_Form_field.md) *or* an [allomorph](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Alternate_Forms_level_flds/Alternate_Forms_fld.md).

Do these steps:

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry that is or contains an abstract form.

3.  In the **Entry** pane, if you cannot see the **Is Abstract Form** field (lexeme form *or* an allomorph) you need, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Do one of these steps:

- If the lexeme form is abstract, select (![](../../../assets/images/CheckedBox.PNG)) the **Is Abstract Form** [field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Allomorph_Status_field.md) check box that is below the lexeme form.

- If an allomorph is abstract, select (![](../../../assets/images/CheckedBox.PNG)) the **Is Abstract Form** [field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Alternate_Forms_level_flds/Is_Abstract_Form_fld_Allomorph.md) check box that is below that allomorph.

> [!TIP]
>
> - If you determine a form is *not* abstract and you want it to be available to the parser, clear (![](../../../assets/images/User_Interface/Field_Descriptions/Grammar/Compound_Rules_fields/UncheckedBox.PNG)) the appropriate **Is Abstract Form** check box.
