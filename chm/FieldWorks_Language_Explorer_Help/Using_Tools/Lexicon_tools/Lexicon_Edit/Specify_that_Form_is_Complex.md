# Specify that a form is complex

*Using Tools › Lexicon tools › Lexicon Edit*

When you [create a new entry](Create_a_lexical_entry.md) for a form that you know is complex, you typically select a complex form [type](../../../User_Interface/Field_Descriptions/Lists/Complex_Form_Types_flds/complex_fm_types_flds_overview.md) in the **New Entry** dialog box, and then [choose components](Choose_components_for_Components_field.md).

If an *existing* lexeme is determined to *be* a complex form, do these steps:

1.  Do the applicable steps in the [Change the entry type](change_the_entry_type.md) topic.

2.  Do any of the following:

  - In the **Comment** field, enter a comment about the form.

  - [Choose components](Choose_components_for_Show_Subentry_Under.md) for the **Show Subentry under** [field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Publication_Settings_flds/Show_Subentry_under.md).

  - Clear (![](../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG)) the **Show Minor Entry** field check box if you do *not* want this complex form to be available for display as a [minor](../../../User_Interface/Menus/Tools/Configure_Dictionary/Main_Minor_entry.md) entry in **Dictionary**.

> [!NOTE]
>
> - The **Show Minor Entry** field check box is selected (![](../../../assets/images/CheckedBox.PNG)) by default.
>
> - [Add a lexical subentry](Add_a_lexical_subentry.md) gives a brief overview of what complex forms are, and how you create and display them.
>
> - [About "entry types"](../../Lists_tools/About_Entry_Types.md) describes complex form types that are installed with FieldWorks Language Explorer.
