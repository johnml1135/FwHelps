# Choose a complex form type

*Using Tools › Lexicon tools › Lexicon Edit*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** column, click the desired entry.

3.  In the **Entry** pane, if you cannot see the **Complex Form Type** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  Click the **Complex Form Type** field for the applicable sense, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose Complex Form Type** dialog box appears.

5.  Do any of these steps:

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times each **Complex Form Types** list item is used in the project.

    - Click the **Edit the Complex Form Types** link to [insert](../../Lists_tools/Insert_a_list_item.md) or [edit](../../Lists_tools/Edit_a_list_item_or_subitem.md) list items.

    - Select (![](../../../assets/images/CheckedBox.PNG)) types you want to display or **Unspecified Complex Form**. Click **OK**.

> [!TIP]
>
> - **Unspecified Complex Form** appears in the **Complex Form Type** field until you choose another type from the **Complex Form Types** [list](../../Lists_tools/List_item_usage_table.md).
>
