# Play a sound or movie file

*Using Tools › Lexicon tools › Lexicon Edit*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry that has the sound or movie file you will play.

3.  In the **Entry** pane, click the **Media File** field that contains the path to the sound or movie file you will play.

    A play button ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Play_button.PNG) appears.

4.  Click the play button.

    The appropriate media player automatically opens (if installed) and plays the file.

> [!TIP]
>
> - A [Media File](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/media_file_field.md) field and associated [Label](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/label_field.md) field is added when you [insert a sound or movie file](Insert_link_to_sound_or_movie.md).
>
> - If you cannot see the **Media File** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).
>
> - To play a sound (audio) or video file in **Dictionary**, see [Pronunciation](../../../User_Interface/Menus/Tools/Configure_Dictionary/Pronunciations.md).
>
> - See [Correct sound quality problems (Windows<sup>®</sup>10)](../../../Basic_Tasks/Audio_files/Correct_sound_quality_problem_on_Windows_10.md) if you have poor sound quality.
