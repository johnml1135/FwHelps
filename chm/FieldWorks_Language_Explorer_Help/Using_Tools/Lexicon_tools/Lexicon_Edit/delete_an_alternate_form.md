# Delete an allomorph

*Using Tools › Lexicon tools › Lexicon Edit*

If an allomorph is not currently used in an [interlinearized](../../Texts_%26_Words_tools/Texts_and_Words_overview.md) word, then you can simply delete it. However, if it is used in an interlinearized word, you should consider [merging](Merge_allomorphs.md) the allomorph instead of deleting it. This allows any interlinearizations to remain complete.

To learn if the allomorph is used, you can right-click the **Affix Allomorph** or **Stem Allomorph** field label, and then select **Show Allomorph in Concordance**.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry that has the allomorph (stem or affix) you will delete.

3.  In the **Entry** pane, in the **Allomorphs** area, click the **Stem Allomorph** or **Affix Allomorph** field label you will delete.

    A menu button (![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF)) appears to the *left* of the field label.

4.  Click that menu button, and then click **Delete Allomorph**.

    The **Delete Stem Form** or **Delete Affix Form** warning box appears, specifying the allomorph you have selected for deletion.

5.  If you are sure you want to delete the form specified in the warning box, click **Delete**.
