# Enter encyclopedic information

*Using Tools › Lexicon tools › Lexicon Edit*

**Encyclopedic** **Info** fields are available in each sense and subsense.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the desired entry.

3.  In the **Entry** pane, if you cannot see the desired **Encyclopedic** **Info** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  In the **Encyclopedic** **Info** field, click the line that shows the writing system you want to use (if more than one is shown), and then enter the information.

    Repeat for other writing systems, if necessary.
