# Enter a reversal entry

*Using Tools › Lexicon tools › Lexicon Edit*

See [About Reversal Entries](About_Reversal_Entries.md) for an overview.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry into which you will enter a reversal entry.

3.  In the **Entry** pane, if you cannot see the desired **Reversal Entries** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  In the **Reversal Entries** field, click the line that uses the desired analysis writing system, and then do any of the following:

    - To enter one reversal entry, type the form of that reversal entry.

    - To enter a reversal entry *and* a subentry, type the form, **:** (a colon) and then the form of the subentry.\
      For example, `servant: slave`.\
      (Otherwise, [insert reversal subentries](../Reversal_Indexes/Insert_a_reversal_subentry.md) in **Reversal Indexes**.)

    - To enter another form in the same sense, click the empty space adjacent to the gray vertical bar, and type the form.

5.  [Choose the category](../Reversal_Indexes/change_the_category_of_a_reversal_entry.md) of the reversal entry or subentry.

> [!NOTE]
>
> - You may need to [refresh the screen](../../../User_Interface/Menus/View/View_overview.md) manually (press `F5`), to see the writing system changes or other expected changes in the window.
