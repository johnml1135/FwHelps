# Lexicon Edit overview

*Using Tools › Lexicon tools › Lexicon Edit*

In **Lexicon Edit**, the **Entries** pane displays entries in rows and fields in columns (**See:** [Browse](../Browse/Lexicon_Browse_overview.md)). The **Entry** pane has all the lexical [fields](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Lexicon_Edit_fields_overview.md) necessary to develop each lexical entry. Here you can access a field and do tasks that are appropriate for that field. ![](../../../assets/images/Important_Icon.gif) **Important** below gives additional explanation.

> [!IMPORTANT]
>
> - There are different [types of fields](../../../User_Interface/Field_Descriptions/Field_Types/field_types_overview.md). Generally speaking, for some fields you enter (type or paste) the data directly into the field. Some fields display and reference data from another field in the lexicon. For other fields, you choose an item from a list. You maintain the lists in the [Lists](../../Lists_tools/Lists_overview.md) or [Grammar](../../Grammar_tools/grammar_overview.md) areas.
>
> - The tasks you do in **Lexicon Edit** typically affect one field in *one* entry or sense. Optionally, you can use [Bulk Edit](../Bulk_Edit_Entries/bulk_edit_overview.md) features to do many of the same tasks, but across *multiple* entries or senses at the same time. [Lexicography Tasks overview](../../../Lexicography_Tasks/Dictionary_and_Lexicon_overview.md) lists additional topics you can use.
