# Merge senses

*Using Tools › Lexicon tools › Lexicon Edit*

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry that has the senses you will merge.

3.  In the **Entry** pane, click the **Sense** field label for the sense you will merge into another sense.

    Links and a menu button (![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF)) appear.

4.  Click the menu button, and then click **Merge Sense into**.

    The **Merge Sense** dialog box appears.

5.  In the **Senses** pane, select the sense into which you will merge the current sense (indicated in the information area at the bottom of the dialog box).

6.  If the description of the merge describes the correct sense and the intended merge direction, click **Merge**.
