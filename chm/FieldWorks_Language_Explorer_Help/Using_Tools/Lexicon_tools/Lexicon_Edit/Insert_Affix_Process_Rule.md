# Insert an Affix Process

*Using Tools › Lexicon tools › Lexicon Edit*

You can insert a *new* Affix Process allomorph in an affix entry. You can also [convert](Convert_existing_form_or_allomorph.md) an *existing* affix allomorph to be Affix Process.

Instead of merely saying, for example, that "**-um-**" is an infix and it can occur in these positions: **/ \# \[C\] \_** or **/ \# \_ \[V\]**", that there is a process that matches this sequence of segments and converts them to another sequence (including inserting "**-um-**" at the appropriate place).

1.  Click the **Allomorphs** [field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Alternate_Forms_level_flds/Alternate_Forms_fld.md).

2.  Click the menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF) that appears, and then click **Insert Affix Process**.

3.  Enter the sequence of segments in the **Affix Allomorph (Process)** [field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Alternate_Forms_level_flds/Affix_allomorph_fld.md).

4.  Leave the **Is Abstract Form** [field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Alternate_Forms_level_flds/Is_Abstract_Form_fld_Allomorph.md) selected (![](../../../assets/images/CheckedBox.PNG)).

5.  Click the **Morph Type** [field](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Alternate_Forms_level_flds/Morph_type_fld_allomorph.md), and then use the **Choose Morpheme Type** dialog box to choose the morph type.

6.  [Build the Affix Process Rule](Build_Affix_Process_Rule.md).
