# Add reference to lexical relation

*Using Tools › Lexicon tools › Lexicon Edit*

> [!IMPORTANT]
>
> - For *existing* lexical relations (previously [inserted](Insert_a_CR_lexical_relation.md) at *entry* level or [inserted](Insert_a_lexical_relation.md) at *sense* level), you may be able to *add* additional references or only *replace* the existing one. The [reference set type](../../../User_Interface/Field_Descriptions/Lists/Lexical_Relations_fields/reference_set_type_field.md) determine this. The dialog box title could be **Add Reference (\<name\>)** or **Replace Reference**.
>
> - The [reference set type](../../Lists_tools/About_reference_set_types.md) also configures the [dialog box](Add_Reference_dialog_box_graphic.md).
>
> Do the following steps:
>
> 1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.
>
> 2.  In the **Entries** pane, click the desired entry (into which you will insert a lexical relation).
>
> 3.  In the **Entry** pane, if you cannot see the [Cross References](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/cross_references_field.md) field ([entry](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Entry_level_fields_overview.md) level) or [Lexical Relations](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/lexical_relations_field.md) field ([sense](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Sense_level_fields/Sense_level_fields_overview.md) level), [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).
>
> 4.  Below the **Cross References** or **Lexical Relations** label, click the desired lexical relation.
>
>     An ellipsis button ![PIC](../../../assets/images/Ellipsis_button.PNG) appears at the right end and a menu button (![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF)) appears at the left end of the field.
>
> 5.  Click the ellipsis button, *or* click the menu button, and then click **Add Reference**.
>
>     The **Add Reference** **(****\<name****\>)** or **Replace Reference** [dialog box](Add_Reference_dialog_box_graphic.md) appears.
>
> 6.  In the dialog box, do any of the following:
>
>     - If necessary, change the writing system in the **Writing System** box so it matches the writing system of the entry you want to find.
>
>     - In the **Find** box, enter the lexeme, citation or an allomorph of the entry.
>
>     - If the desired entry appears in the **Lexical Entries** area, click that entry. If not, click **Create** to open the **New Entry** dialog box to create a new lexical entry and add it in the relation field at the same time.
>
>     - If the dialog box has a **Step 2** and if it is *available*, then select either **Choose the selected lexical entry** or **Choose a sense of the entry**.
>
>     - If you selected **Choose a sense of the entry**, the **Sense** box is active. Then in the **Sense** box, select the applicable sense, if the entry has more than one sense.
>
> 7.  Click **Add** or **Replace**.
>
>     The selected entry is *added* as an additional reference or *replaces* the exiting one.
>
>     Other results may include the following:
>
>     - An equivalent field is *automatically generated and populated* in the corresponding entry. Examples include **Antonym,** or **Part**/**Whole** as every **Part** will automatically have a corresponding **Whole**.
>
>     - The other senses automatically show *all* the senses that are part of the set, such as for **synonyms**.

> [!TIP]
>
> - If the lexical relation uses a sequence, you can right-click an entry and [move](move_sequence_entry.md) it right or left to change the sequence (reorder the entries).
>
> - [About Reference set types](../../Lists_tools/About_reference_set_types.md) states that if the reference set type includes **Entry/Sense**, then **Step 2: Select Entry or Sense** is available.
>
> - - If you click a *variant* entry that has no sense in the dialog box, the buttons under **Step 2: Select Entry or Sense** and the **Add** button are *unavailable*. If you double-click that variant, the variant is *not* added as a lexical relation, but the dialog box will close.
