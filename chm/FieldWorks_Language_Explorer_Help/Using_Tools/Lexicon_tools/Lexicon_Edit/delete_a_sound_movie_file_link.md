# Delete this Media Link

*Using Tools › Lexicon tools › Lexicon Edit*

In the [Media File](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/media_file_field.md) field, you can have [links to external sound or movie files](Insert_link_to_sound_or_movie.md) (media). To remove the link to a media file, do the steps below.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Lexicon Edit**.

2.  In the **Entries** pane, click the entry.

3.  In the **Entry** pane, click the label for the unwanted **Media File** field.

    A menu button (![](../../../assets/images/Using_Tools/Lexicon_tools/Lexicon_Edit/Menu_Button_pic.GIF)) appears.

4.  Click or right-click the menu button, and then select **Delete this Media Link**.

    The link and the **Media File** and **Label** fields are deleted. However, any copy of the sound or movie file remains in your [folder](../../../User_Interface/Menus/File/Backup_and_Restore/Folder_Structure.md).

    - Manually delete files from your folders that you will never use or that others should never hear or see (*recommended*).

> [!TIP]
>
> - You can also right-click the **Label** field label to see the **Delete this Media Link** command.
