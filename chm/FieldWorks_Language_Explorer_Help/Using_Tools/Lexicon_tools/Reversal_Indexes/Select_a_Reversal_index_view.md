# Select a reversal index layout

*Using Tools › Lexicon tools › Reversal Indexes*

You should review [What is a publication?](../../../User_Interface/Field_Descriptions/Lists/Publications/What_is_a_Publication.md).

Then, do these steps:

1.  In the **Navigation Pane**, click **Lexicon**, and then click **Reversal Indexes**.

2.  Click the *left* menu button (![](../../../assets/images/Information_bar_Menu_button.PNG)) on the [Information bar](../../../User_Interface/Toolbars/information_bar_overview.md), and then select\
    (![](../../../assets/images/Using_Tools/Lexicon_tools/Dictionary/SelectedViewCheckBox.png)) a [layout](../../../User_Interface/Menus/Tools/Configure_Reversal_Index/Configuring_a_reversal_index_view.md).

> [!NOTE]
>
> - Click the *right* menu button (![](../../../assets/images/Information_bar_Menu_button.PNG)) on the Information bar to [select a publication](../Dictionary/Select_a_publication.md).
>
> - Alternatively, [choose](../../../User_Interface/Menus/Tools/Configure_Reversal_Index/Choose_a_Reversal_Index_view.md) a reversal index layout.
>
> - When you [Configure Headword numbers](../../../User_Interface/Menus/Tools/Configure_Headword_Numbers/Config_Hdwrd_Numbers_dialog_box.md), the configuration is for the *current* layout only.
