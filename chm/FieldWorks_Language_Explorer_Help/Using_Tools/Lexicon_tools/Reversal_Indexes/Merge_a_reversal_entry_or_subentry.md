# Merge a reversal entry or subentry

*Using Tools › Lexicon tools › Reversal Indexes*

You can merge a reversal entry or subentry into another reversal entry or subentry. ([Move](move_a_reversal_entry_or_subentry.md) is *different*.)

1.  In the **Navigation Pane**, click **Lexicon**, and then click **Reversal Indexes**.

2.  In the **Reversal Index** pane, do the following:

    - On the [Information bar](../../../User_Interface/Toolbars/information_bar_overview.md), click the menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Reversal_Indexes/Information_bar_Menu_button.PNG), and then select the writing system that has the reversal entries or subentries that you will merge.

    - Click the reversal entry or subentry that you will merge into another.

3.  In the **Reversal Entry** pane, do the following:

    - Click the **Reversal Form** field for reversal entry or subentry you will merge into another.

      A menu button (![](../../../assets/images/Using_Tools/Lexicon_tools/Reversal_Indexes/Menu_Button_pic.GIF)) appears.

    - Click the menu button, and then select **Merge Entry into**.

      The **Merge Reversal Entry** dialog box appears.

4.  In the dialog box, do the following:

    - In the **Entries** pane, select the entry into which you want to merge the current entry.

    - Click **Merge**.

      The reversal entries are merged.

5.  Edit the resulting entry, if necessary.
