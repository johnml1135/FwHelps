# Insert a reversal index

*Using Tools › Lexicon tools › Reversal Indexes*

When you create a language project, a reversal index is automatically generated for the default (top) analysis writing system. Later, if you add another analysis writing system, a reversal index is automatically added.

You use the **Configure Reversal Index** dialog box to [configure the layout](../../../User_Interface/Menus/Tools/Configure_Reversal_Index/Configuring_a_reversal_index_view.md) that corresponds to that analysis writing system.

> [!TIP]
>
> - You can use the **Manage Reversal Index Views** dialog box to [duplicate a layout](../../../User_Interface/Menus/Tools/Configure_Reversal_Index/Manage_Views_Reversal_Index.md).
>
> Then you can [configure each layout](../../../User_Interface/Menus/Tools/Configure_Reversal_Index/Configuring_a_reversal_index_view.md) of the same language differently.
