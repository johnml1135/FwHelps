# Use right-click to help configure Reversal Index layout

*Using Tools › Lexicon tools › Reversal Indexes*

You use the [Configure Reversal Index](../../../User_Interface/Menus/Tools/Configure_Reversal_Index/Configure_Reversal_Index_dialog_box.md) dialog box to configure a **Reversal Index** [layout](../../../User_Interface/Menus/Tools/Configure_Reversal_Index/Manage_Views_Reversal_Index.md).

It can be difficult to find the specific part of the reversal entry you want to configure in the left pane of this dialog box.

Instead, *if* that data is currently displayed, do the steps below to quickly open the dialog box to the part of the entry that you want to configure.

Do the following in **Reversal Indexes**:

1.  Right-click the part of the entry that you want to configure, and then click the right-click menu command.

    The **Configure Reversal Index** dialog box opens.

    The specific part of the reversal entry that you right-clicked is selected in the **Configure** pane.

2.  [Configure](../../../User_Interface/Menus/Tools/Configure_Reversal_Index/Configuring_a_reversal_index_view.md) that part in the currently-selected reversal index layout.

> [!TIP]
>
> - For content that is a *single character*, such as the abbreviation for a grammatical category, put the insertion point immediately after that character; then, right-click.
