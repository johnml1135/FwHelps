# Add a referenced sense to a reversal entry

*Using Tools › Lexicon tools › Reversal Indexes*

Do the following steps in **Reversal Indexes**:

1.  In the center pane, click the entry.

2.  Click the **Referenced Senses** [field](../../../User_Interface/Field_Descriptions/Lexicon/Reversal_Indexes_fields/senses_field.md), and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG).

    The **Identify sense** dialog box appears.

3.  In the **Find** box, enter the form of the lexical entry you want to find.

    Any entries that match appear in the **Lexical Entries** area.

4.  If there are no matches, do *any* of the following:

    - Change the selection in the **Writing System** box.

    - Change the text in the **Find** box.

    - Click **Create** to [open](../Lexicon_Edit/Create_a_lexical_entry.md) the **Create Entry** dialog box so you can create a new lexical entry.

    - Click **Cancel** to close the dialog box.

5.  If the desired entry appears in the **Lexical Entries** area, click it.

    - If the desired sense is not shown in the **Specific Sense** box, select it.

6.  Click **Set Reversal**.

    The sense appears in the **Referenced Senses** field; the reversal form appears in the sense.
