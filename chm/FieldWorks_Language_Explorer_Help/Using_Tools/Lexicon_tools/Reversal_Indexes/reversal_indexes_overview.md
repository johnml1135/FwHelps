# Reversal Indexes overview

*Using Tools › Lexicon tools › Reversal Indexes*

In the **Lexicon** area, **Reversal Indexes** and the associated **Reversal Entries** field in each lexical entry allows you to create *analysis-to-vernacular* reversal indexes. **See Also:** [About Reversal Entries](../Lexicon_Edit/About_Reversal_Entries.md).

- On the [Information bar](../../../User_Interface/Toolbars/information_bar_overview.md), there are two menu buttons (![](../../../assets/images/Using_Tools/Lexicon_tools/Reversal_Indexes/Information_bar_Menu_button.PNG)).

  - Use one to choose the reversal index based [layout (configuration)](../../../User_Interface/Menus/Tools/Configure_Reversal_Index/Manage_Views_Reversal_Index.md).

  - Use one to choose a layout based on [publications](../../../User_Interface/Field_Descriptions/Lists/Publications/What_is_a_Publication.md).
