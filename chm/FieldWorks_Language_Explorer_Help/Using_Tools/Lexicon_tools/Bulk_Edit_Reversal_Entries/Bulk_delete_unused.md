# Bulk delete unused reversal entries

*Using Tools › Lexicon tools › Bulk Edit Reversal Entries*

In [Bulk Edit Reversal Entries](bulk_edit_reversal_entries_overview.md), you use the **Delete** tab features to delete orphan reversal entries, that is, reversal entries that do not have *senses* of lexical entries specified for them. This is a way to clean up a reversal index.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Bulk Edit Reversal Entries**.

2.  Click the **Delete** tab.

3.  In the [Information bar](../../../User_Interface/Toolbars/information_bar_overview.md) at the top of the **Reversal Entries** pane, click the menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Bulk_Edit_Reversal_Entries/Information_bar_Menu_button.PNG), and then select the writing system that has the reversal entries you may delete.

4.  [Filter](../../../Basic_Tasks/Filtering_data/filtering_data_overview.md) or [sort](../../../Basic_Tasks/Sorting_data/Sorting_data_overview.md) the displayed reversal entries as necessary.

5.  In the left column, [select the rows](../Bulk_Edit_Entries/select_rows.md) you want to delete.

6.  Use the [Configure Columns](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) dialog box to hide/show/move columns (fields), and specify the writing systems displayed.

7.  In the **Bulk Edit Operation** pane, select **Entries** in the **Item to delete** box.

8.  Click **Delete**.

9.  A **Confirm multiple deletions** warning box appears, asking if you want to proceed with the deletion.

10. To delete all the selected reversal entries, click **OK**. Otherwise, click **Cancel**.
