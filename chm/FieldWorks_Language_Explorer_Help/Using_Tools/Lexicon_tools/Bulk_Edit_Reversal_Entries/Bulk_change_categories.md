# Bulk change the reversal category

*Using Tools › Lexicon tools › Bulk Edit Reversal Entries*

In [Bulk Edit Reversal Entries](bulk_edit_reversal_entries_overview.md), you can use the **List Choice** tab features to change the category for multiple reversal entries at the same time.

1.  In the **Navigation** **Pane**, click **Lexicon**, and then click **Bulk Edit Reversal Entries**.

2.  Click the **List Choice** tab.

3.  On the [Information bar](../../../User_Interface/Toolbars/information_bar_overview.md) at the top of the **Reversal Entries** pane, click the menu button ![](../../../assets/images/Using_Tools/Lexicon_tools/Bulk_Edit_Reversal_Entries/Information_bar_Menu_button.PNG), and then select the writing system that has the reversal entries you will change.

4.  [Filter](../../../Basic_Tasks/Filtering_data/filtering_data_overview.md) or [sort](../../../Basic_Tasks/Sorting_data/Sorting_data_overview.md) the displayed reversal entries as necessary.

5.  In the left column, [select the rows](../Bulk_Edit_Entries/select_rows.md) you want to change.

6.  Use the [Configure Columns](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) dialog box to hide/show/move columns (fields), and specify the writing systems displayed, if permitted.

7.  In the **Bulk Edit Operation** pane, do the following:

    - In the **Target Field** box, select **Category**.

    - In the **Change To** box, select the category you want to assign to the selected entries. If the desired category is not shown, click **More** to open the [Add from Catalog](../Lexicon_Edit/Using_Add_from_Catalog_dialog_box.md) dialog box.

8.  Click **Preview**, review the pending changes, and then click **Apply**.

    The reversal entries with a check mark in the left column change.
