# Search Semantic Domains

*Using Tools › Lists tools*

You can search for semantic domains in **Collect Words** ([Lexicon](../Lexicon_overview.md)) and **Semantic Domains** ([Lists](../../Lists_tools/List_item_usage_table.md)).

1.  Click the search box (![](../../../assets/images/Using_Tools/Lexicon_tools/Collect_Words/MagnifyingGlass.png)) at the top of the **Semantic Domains** (*center*) pane.

2.  Type or paste one of the following:

    - a word in the semantic domain [name](../../../User_Interface/Field_Descriptions/Lists/Semantic_Domains_fields/name_field_semantic_domains.md) or that is an [example word](../../../User_Interface/Field_Descriptions/Lists/Semantic_Domains_fields/Example_Words_field_Semantic_Domains.md)

    - an [abbreviation](../../../User_Interface/Field_Descriptions/Lists/Semantic_Domains_fields/abbreviation_field_semantic_domains.md) such as "4.3.4.2".

As you type, search results appear in the *center* pane in a flat list (not hierarchical). The closest matches are nearest to the top.

The words in square brackets are the next domain up in the hierarchical order, that is the parent semantic domain. For example, **Sun \[Sky\]**. where **Sun** is 1.1.1, and **Sky** is 1.1.

Usage figures (numbers) appear in parenthesis.

The magnifying glass (![](../../../assets/images/Using_Tools/Lexicon_tools/Collect_Words/MagnifyingGlass.png)) changes to an 'x' (![](../../../assets/images/Using_Tools/Lexicon_tools/Collect_Words/BlackX.png)), which you can click to restore the hierarchical list.

3.  Click a search result to display that semantic domain in the *right* pane.

> [!NOTE]
>
> - Search uses only the default (top) analysis writing system.
>
> - You cannot use Boolean operators, such as AND, OR, NOT, or NEAR.
>
> - When you [choose semantic domains](../Lexicon_Edit/choose_semantic_domains.md) in **Lexicon Edit**, the dialog box has similar search features.
