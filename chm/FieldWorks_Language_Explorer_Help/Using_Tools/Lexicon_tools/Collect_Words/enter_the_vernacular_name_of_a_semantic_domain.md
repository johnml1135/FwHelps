# Enter the vernacular name of a semantic domain

*Using Tools › Lexicon tools › Collect Words*

You can enter (or edit) the name of semantic domains using the default vernacular writing system in either the **Lists** *or* in **Lexicon** areas. The changes you make in either area appear in the other area. Specifically, the [Name](../../../User_Interface/Field_Descriptions/Lists/Semantic_Domains_fields/name_field_semantic_domains.md) field and [Vernacular](../../../User_Interface/Field_Descriptions/Lexicon/Collect_Words_fields/Vernacular_Field_Collect_Words.md) field show the same content for each semantic domain.

## Semantic Domains List (Lists)

1.  In the **Navigation Pane**, click **Lists**, and then click **Semantic Domains**.

2.  In the center column, select the semantic domain for which you will enter (or edit) the name using the default vernacular writing system.

3.  In the **Semantic Domain** pane, click the line in the [Name field](../../../User_Interface/Field_Descriptions/Lists/Semantic_Domains_fields/name_field_semantic_domains.md) that uses the vernacular writing system, and then type or edit the vernacular name that is equivalent to the names entered in analysis writing systems.

4.  Repeat steps 2 and 3 for each semantic domain, as necessary.

## **Collect Words (Lexicon)**

1.  In the **Navigation Pane**, click **Lexicon**, and then click **Collect Words**.

2.  In the center column, select the semantic domain for which you will enter (or edit) the name using the default vernacular writing system.

    The **Semantic Domain** pane displays one or more names for the selected semantic domain in *analysis* writing systems, a description and other information.

3.  In the **Semantic Domain** pane [Vernacular field](../../../User_Interface/Field_Descriptions/Lexicon/Collect_Words_fields/Vernacular_Field_Collect_Words.md), enter (or edit) the vernacular name that is equivalent to the **Analysis** field content.

    (The *default* *vernacular* writing system should be selected automatically when you click the field.)

4.  Repeat steps 2 and 3 for each semantic domain, as necessary.
