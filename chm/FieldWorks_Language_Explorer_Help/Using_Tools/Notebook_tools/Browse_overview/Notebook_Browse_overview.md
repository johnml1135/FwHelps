# Notebook Browse overview

*Using Tools › Notebook › Browse view*

In **Notebook**, the **Browse** view displays fieldnote records in rows and their [fields](../../../User_Interface/Field_Descriptions/Notebook/Notebook_fields_overview.md) in columns. This is like the **Records** pane in [Record Edit](../Record_Edit_overview/Record_Edit_overview.md). You can do any of the following in **Browse**:

- [Configure columns](../../../Basic_Tasks/Configure_Columns/Configure_Columns_overview.md).

- [Filter](../../../Basic_Tasks/Filtering_data/filtering_data_overview.md) and [sort](../../../Basic_Tasks/Sorting_data/Sorting_data_overview.md) data (also affects [Document](../Document_overview/Document_overview.md) view).

- [Insert a fieldnote record](../Record_Edit_overview/Insert_a_fieldnote_record.md).

- Click ![](../../../assets/images/Using_Tools/Notebook_tools/Browse_overview/Find_Record.PNG) on the [toolbar](../../../User_Interface/Toolbars/Insert_toolbar.md) to open **Find Record** dialog box.

- Use the [Find and Replace (Notebook)](../../../User_Interface/Menus/Edit/Find_and_Replace.md) dialog box.

- Right-click a record, and then select **Delete Record**.

- Edit the contents of cells that have an uncolored (white) background. These cells typically correspond to [text fields](../../../User_Interface/Field_Descriptions/Field_Types/field_types_overview.md).

> [!TIP]
>
> - You can also do any of the above in the **Records** pane.
>
> - For a given open window, any filtering or sorting you do in **Browse** also affects the **Record Edit** view. The reverse is also true. Click ![](../../../assets/images/Basic_Tasks/Filtering_data/Clear_Filters.GIF) on the toolbar to turn off all filters.
