# Record Edit overview

*Using Tools › Notebook › Record Edit*

In **Notebook**, the basic unit of information is called a *record* (to distinguish them from lexical *entries, texts,* list *items*, and so on). Each record has [fields](../../../User_Interface/Field_Descriptions/Notebook/Notebook_fields_overview.md) of various types ([date](../../../User_Interface/Field_Descriptions/Field_Types/date_field.md), [single-line text](../../../User_Interface/Field_Descriptions/Field_Types/Single_line_text_field.md), [multiparagraph text](../../../User_Interface/Field_Descriptions/Field_Types/Multiparagraph_text_field.md) or [list reference](../../../User_Interface/Field_Descriptions/Field_Types/List_reference_field.md)) that each store a particular kind of information.
