# Choose researchers

*Using Tools › Notebook › Record Edit*

1.  In the **Navigation Pane**, click **Notebook**, and then click **Record Edit**.

2.  In the **Records** pane, click the record you want to change.

3.  In the **Record** pane, click the **Researchers** field, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose Researchers** dialog box appears.

4.  Do any of these steps:

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times each **People** list item is used in the project.

    - Click the **Edit the list of People** link to [insert](../../Lists_tools/Insert_a_list_item.md) or [edit](../../Lists_tools/Edit_a_list_item_or_subitem.md) a person in the **People** list.

    - Select (![](../../../assets/images/CheckedBox.PNG)) one or more people. Click **OK**.

> [!NOTE]
>
> - If the record has content in the [Text](../../../User_Interface/Field_Descriptions/Notebook/Text_field_(Notebook).md) field, another instance of the same **Researchers** field appears as one of the **Info** tab [fields](../../../User_Interface/Field_Descriptions/Texts_%26_Words/Texts_%26_Words_fields_overview.md).
