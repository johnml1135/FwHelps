# Choose participants and roles

*Using Tools › Notebook › Record Edit*

## Choose Participants

1.  In the **Navigation Pane**, click **Notebook**, and then click **Record Edit**.

2.  In the **Records** pane, click the record you want to change.

3.  In the **Record** pane, click the **Participants** field, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose Participants** dialog box appears.

4.  Do any of these steps:

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times each **People** list item is used in the project.

    - Click the **Edit the list of People** link to [insert](../../Lists_tools/Insert_a_list_item.md) or [edit](../../Lists_tools/Edit_a_list_item_or_subitem.md) a person in the **People** list.

    - Select (![](../../../assets/images/CheckedBox.PNG)) one or more participants. Click **OK**.

## Add roles

1.  Click the **Participants** field to which you will add a role.

2.  Click the menu button (![](../../../assets/images/Menu_Button_pic.GIF)), and then click the role you want to add (**Add Accuser**, **Add Arbitrator**, and so on).

The **Choose** **Participants** dialog box appears.

3.  Select (![](../../../assets/images/CheckedBox.PNG)) the person or people that you want to appear in the role. Click **OK**.

A field is added. It has the [role name](../../../User_Interface/Field_Descriptions/Lists/Roles_fields/Name_field_(Roles).md) as the field label. It contains the person or people you selected.

> [!NOTE]
>
> - If the record has content in the **Text** field, another instance of the same **Participants** field appears as one of the **Info** tab [fields](../../../User_Interface/Field_Descriptions/Texts_%26_Words/Texts_%26_Words_fields_overview.md).
>
> - In "chooser" dialog boxes with check boxes, like this one, you can put the focus on an item with the arrow keys, and the press SPACEBAR to select ![](../../../assets/images/CheckedBox.PNG) or clear ![](../../../assets/images/User_Interface/Menus/Tools/UncheckedBox.PNG) the check box.
