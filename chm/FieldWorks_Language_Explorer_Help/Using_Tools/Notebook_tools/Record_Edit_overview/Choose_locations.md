# Choose locations

*Using Tools › Notebook › Record Edit*

1.  In the **Navigation Pane**, click **Notebook**, and then click **Record Edit**.

2.  In the **Records** pane, click the record you want to change.

3.  In the **Record** pane, click the [Locations](../../../User_Interface/Field_Descriptions/Notebook/Locations_field_Ntbk.md) field, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose Locations** dialog box appears.

4.  Do any of these steps:

    - Click the ![](../../../assets/images/User_Interface/Field_Descriptions/Field_Types/Plus_sign_box.GIF) (plus sign) to expand an item, if necessary.

    - Click the **Edit the list of Locations** link to [insert](../../Lists_tools/Insert_a_list_item.md) or [edit](../../Lists_tools/Edit_a_list_item_or_subitem.md) a **Locations** list item.

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times each **Locations** list item is used in the project.

5.  Click **OK**.

> [!NOTE]
>
> - If the record has content in the [Text](../../../User_Interface/Field_Descriptions/Notebook/Text_field_(Notebook).md) field, another instance of the **Locations** field appears as one of the [Info tab fields](../../../User_Interface/Field_Descriptions/Texts_%26_Words/Texts_%26_Words_fields_overview.md).
