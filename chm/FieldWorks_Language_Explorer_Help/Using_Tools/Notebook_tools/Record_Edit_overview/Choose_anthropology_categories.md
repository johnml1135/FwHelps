# Choose anthropology categories (Notebook)

*Using Tools › Notebook › Record Edit*

1.  In the **Navigation Pane**, click **Notebook**, and then click **Record Edit**.

2.  In the **Records** pane, click the desired record.

3.  In the **Record** pane, if you cannot see the **Anthropology Categories** field, [show hidden fields](../../../Basic_Tasks/Showing_and_hiding_fields/Show_Hidden_Fields.md).

4.  In the **Record** pane, click the **Anthropology Categories** field, and then do *one* of the following:

    - Type the name or abbreviation of a category directly in the field. Click the desired category in the drop-down list. Repeat as needed. In this case, you are done.

    - Click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears. The continue.

      The **Choose Anthropology Categories** dialog box appears.

5.  Do any of these steps:

    - Click the ![](../../../assets/images/Plus_sign_box.GIF) (plus sign) to expand an anthropology category item.

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times each category is used in the project.

    - Click the **Edit the Anthropology Categories** link to [insert](../../Lists_tools/Insert_a_list_item.md) or [edit](../../Lists_tools/Edit_a_list_item_or_subitem.md) an **Anthropology Category** list item.

    - Select (![](../../../assets/images/CheckedBox.PNG)) the anthropology categories you want, and then click **OK**.

> [!TIP]
>
> - <a href="https://hraf.yale.edu/resources/reference/outline-of-cultural-materials/" target="_blank" title="https://hraf.yale.edu/resources/reference/outline-of-cultural-materials/">https://hraf.yale.edu/resources/reference/outline-of-cultural-materials/</a>, <a href="https://hraf.yale.edu/help/" target="_blank" title="https://hraf.yale.edu/help/">https://hraf.yale.edu/help/</a> and associated internet pages can help you learn about these categories.
>
> - If the record has content in the [Text](../../../User_Interface/Field_Descriptions/Notebook/Text_field_(Notebook).md) field, another instance of the **Anthropology Categories** field appears as one of the [Info tab fields](../../../User_Interface/Field_Descriptions/Texts_%26_Words/Texts_%26_Words_fields_overview.md).
