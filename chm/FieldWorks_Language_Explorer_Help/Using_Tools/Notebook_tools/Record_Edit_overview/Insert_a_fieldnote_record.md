# Insert a fieldnote record

*Using Tools › Notebook › Record Edit*

In **Notebook**, you can insert a fieldnote record. **See Also:** [Insert a fieldnote subrecord](Insert_a_fieldnote_subrecord.md).

1.  In the **Navigation Pane**, click **Notebook**, and then click **Record Edit** or **Browse**.

2.  Do one of the following:

    - On the [Insert](../../../User_Interface/Menus/Insert/Insert_overview.md) menu, click **Record**.

    - In the [Insert](../../../User_Interface/Toolbars/Insert_toolbar.md) toolbar, click ![](../../../assets/images/User_Interface/Toolbars/Insert_Record.PNG).

    - Click **Create** in the **Find Record** dialog box, or in one of the **Add Reference** dialog boxes.

    The **New Record** dialog box appears. If you opened the **New Record** dialog box from the **Find Record** dialog box, or from an **Add Reference** dialog box, the writing system selected there determines the writing system of the **Title** box. All the other [fields](../../../User_Interface/Field_Descriptions/Notebook/Notebook_fields_overview.md) use the current *default* analysis writing system.**\
    See also:** [Title field](../../../User_Interface/Field_Descriptions/Notebook/Title_field_Ntbk.md).

3.  In the dialog box, do the following

    - Enter a title for the fieldnote record.

    - [Choose](Choose_record_type.md) the record type.

4.  Click **Create**.

    A new record appears, and is ready for you to [enter data](Record_Edit_overview.md). You can [change the record type](Choose_record_type.md) later, if necessary.

> [!NOTE]
>
> - Different records types have different [default fields](../../../User_Interface/Field_Descriptions/Notebook/Notebook_fields_overview.md) to support their different purposes. However, you can change the [visibility](../../../Basic_Tasks/Showing_and_hiding_fields/change_the_visibility_of_fields.md) for each field individually.
>
>   - "Event" records (**Observation**, **Performance**, **Interview**, and so on) consist of information that illustrates cultural behavior or other aspects of community life.
>
>   - **Analysis** record consists of a proposed explanation of an observed cultural behavior for further study. Analysis records allow you to describe your research agenda and link to event records that support or counter each hypothesis.
