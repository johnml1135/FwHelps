# Select Superceded By references

*Using Tools › Notebook › Record Edit*

There are times when a record becomes obsolete. For example, if you need to completely rewrite a record, you should not delete the original record. Instead, you should insert a new record. Then select that new record in the Superseded By field in the obsolete record. [Edit a record](Edit_a_record.md) discusses this.

1.  In the **Navigation Pane**, click **Notebook**, and then click **Record Edit**.

2.  In the **Records** pane, click the record you mark as "superseded" by another record.

3.  In the **Record** pane, click the [Superseded By](../../../User_Interface/Field_Descriptions/Notebook/See_Also_field_Ntbk.md) field.

4.  Click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears in the field.

    The **Add Reference** dialog box appears.

5.  In the dialog box, do the following:

    - In the **Find** box, type a word that is in the *title* of the record you want to find. Notice that existing records appear in the **Records** pane as you type.

      [Title](../../../User_Interface/Field_Descriptions/Notebook/Title_field_Ntbk.md) fields can use different writing systems. Select a different writing system in the **Writing System** box.

    - If the record you want appears, click it, and then click **Add**.

    - If the record you want does not appear, click **Create** to open the [Add Record](Insert_a_fieldnote_record.md) dialog box so you can insert a new fieldnote record.
