# Enter a vernacular text

*Using Tools › Notebook › Record Edit*

In **Notebook**, each record and subrecord has a [Text](../../../User_Interface/Field_Descriptions/Notebook/Text_field_(Notebook).md) field. This allows you to enter one or more texts in each record. Texts you enter in **Notebook** are included in the text corpus that you see and [analyze](../../Texts_%26_Words_tools/Interlinear_Texts/Analyze_Text_overview.md) in the [Texts & Words](../../Texts_%26_Words_tools/Texts_and_Words_overview.md) area. Consequently, the text must use the default vernacular writing system. It is possible to embed other writing systems in the text, but you will not be able to analyze them.

Contents in other fields in the record also appear in the **Info** tab as text metadata.

1.  In the **Navigation Pane**, click **Notebook**, and then click **Record Edit**.

2.  In the **Records** pane, click the record in which you will add a text.

3.  In the **Record** pane, click the appropriate [Text](../../../User_Interface/Field_Descriptions/Notebook/Text_field_(Notebook).md) field.

4.  Type or paste the text in that **Text** field.

5.  Enter a title and other metadata:

    - On the Navigation pane, click **Texts & Words** area, and then click **Interlinear Texts**.

    - In the **Texts** pane, click the text that does not show a title in the **Title** column.

    - If there are more than one text without a title, verify the text contents in the **Baseline** tab before you enter a title.

    - Click the **Info** tab to see the [Info tab fields](../../../User_Interface/Field_Descriptions/Texts_%26_Words/Texts_%26_Words_fields_overview.md).

    - Type a title in one or more writing systems.

    - Type or select other metadata as needed.

    - To return to the record, click the [Notebook Record](../../../User_Interface/Field_Descriptions/Texts_%26_Words/Notebook_Record_(Info).md) field, and then click the **Show Record in Notebook** link.

> [!NOTE]
>
> - For texts that do *not* need to be part of a notebook record, [insert the text](../../Texts_%26_Words_tools/Interlinear_Texts/Insert_new_Text.md) in a **Baseline** tab.
>
> - If you [delete the record](Delete_a_fieldnote_record.md), texts created in **Notebook** are *not* deleted from **Texts & Words**. Go to the **Interlinear Texts** view and [delete](../../../User_Interface/Menus/Edit/Delete.md) any texts you do not want to keep.
