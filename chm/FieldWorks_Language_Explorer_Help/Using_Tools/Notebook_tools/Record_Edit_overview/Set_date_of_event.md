# Set date of event

*Using Tools › Notebook › Record Edit*

1.  In the **Navigation Pane**, click **Notebook**, and then click **Record Edit**.

2.  In the **Records** pane, click the record you want to change.

3.  In the **Record** pane, click the [Date of Event](../../../User_Interface/Field_Descriptions/Notebook/Date_of_Event_field_Ntbk.md) field.

    The **Set Date of Event** dialog box appears.

4.  Do the following:

    - If needed, select the precision (**Before**, **On**, **About**, **After**, or **No Date**) in the list at the upper left.

    - Select the month.

    - Select the day.

    - Select the year.

    - Click **OK**.

> [!NOTE]
>
> - To remove a date from the field, select **No Date**.
>
> - When the month and year are correct, you can click the day on the calendar.
>
> - You can select **Unknown** for the month and day.
>
> - This **Date of Event** dialog box allows you to choose **AD** and **BC**. The need for dates marked as **BC** are unlikely.
>
> - To know the elapsed time between when you observe an event and when you write about it, compare the **Date of Event** to the [Date Created](../../../User_Interface/Field_Descriptions/Notebook/Date_Created_field_Ntbk.md) field.
