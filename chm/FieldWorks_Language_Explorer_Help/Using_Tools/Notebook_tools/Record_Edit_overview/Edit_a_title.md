# Edit a title

*Using Tools › Notebook › Record Edit*

The title of a fieldnote record or subrecord should be meaningful, and accurately reflect the description or conclusions stated in the record. The [Title](../../../User_Interface/Field_Descriptions/Notebook/Title_field_Ntbk.md) field topic describes the writing system the field uses.

To edit an existing title, do the following:

1.  In the **Navigation Pane**, click **Notebook**, and then click **Record Edit**.

2.  In the **Records** pane, click the record *or* subrecord that has a title which you want to change.

3.  In the **Record** pane, click the **Title** field of the record or subrecord.

4.  Do any of the following:

    - Edit the words in the title.

    - Select one or words, and then [select a different writing system](../../../User_Interface/Menus/Format/select_a_writing_system.md). If you selected all the words, then the writing system of the [Title](../../../User_Interface/Field_Descriptions/Notebook/Title_field_Ntbk.md) field changes. Otherwise, you *embed* words with a different writing system

    - [Apply a character style](../../../User_Interface/Menus/Format/apply_a_style_to_text.md) to one or more words in the title.

    - Insert or paste a [hyperlink](../../../Basic_Tasks/Creating_Hyperlinks/Creating_Hyperlinks_overview.md) to one or words in the title (not recommended).

> [!NOTE]
>
> - In the **Title** column (**Records** pane), the title of main records appears in a bold style. Subrecords appear in the normal style.
>
> - In the **Document** [view](../Document_overview/Document_overview.md), each title uses the paragraph style **Heading 1**.
>
> - - If necessary, you can choose a different paragraph style, or change the **Heading 1** style when you [configure the document layout](../../../User_Interface/Menus/Tools/Configure_Document/Configuring_a_Document_view.md).\
>     If you change the **Heading 1** style, the change would affect the entire language project in every place the style is used.
