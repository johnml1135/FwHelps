# Choose restrictions

*Using Tools › Notebook › Record Edit*

1.  In the **Navigation Pane**, click **Notebook**, and then click **Record Edit**.

2.  In the **Records** pane, click the record you want to change.

3.  In the **Record** pane, click the **Restrictions** field, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose Restrictions** dialog box appears.

<!-- -->

4.  Do any of these steps:

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times each **Restrictions** list item is used in the project.

    - Click the **Edit the list of Restrictions** link to [insert](../../Lists_tools/Insert_a_list_item.md) or [edit](../../Lists_tools/Edit_a_list_item_or_subitem.md) a **Restrictions** list item.

    - Select (![](../../../assets/images/CheckedBox.PNG)) one or more people. Click **OK**.
