# Create a lexical entry from a fieldnote record

*Using Tools › Notebook › Record Edit*

In **Notebook**, you can create a lexical entry for a vernacular word that appears in a fieldnote record. The word must use the *first* (top-most) [vernacular writing system](../../../Advanced_Tasks/Writing_Systems/Add_a_new_writing_system/About_Writing_Systems.md).

1.  In the **Navigation Pane**, click **Notebook**, and then click **Record Edit**.

2.  In the **Records** pane, click the record that has the vernacular word for which you want to create a lexical entry.

3.  In the **Record** pane, click the vernacular word.

    - Look at the writing system box on the [Format toolbar](../../../User_Interface/Toolbars/Format_toolbar.md) to make sure the vernacular writing system is shown. If not, [select the writing system](../../../User_Interface/Menus/Format/select_a_writing_system.md).

4.  Do one of the following:

    - Right-click the vernacular word, and then click **Add to Dictionary**.

    - On the [Insert](../../../User_Interface/Menus/Insert/Insert_overview.md) menu, click **Entry**.

    - In the [Insert](../../../User_Interface/Toolbars/Insert_toolbar.md) toolbar, click ![](../../../assets/images/User_Interface/Toolbars/Insert_Lexical_Entry.GIF).

    The **New Entry** dialog box appears.

5.  In the [New Entry](../../Lexicon_tools/Lexicon_Edit/Create_a_lexical_entry.md) dialog box, enter or select content as necessary, and then click **Create**.
