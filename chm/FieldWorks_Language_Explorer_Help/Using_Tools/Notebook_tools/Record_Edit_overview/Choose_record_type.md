# Choose record type

*Using Tools › Notebook › Record Edit*

You choose a record type when you [insert a fieldnote record](Insert_a_fieldnote_record.md) or [subrecord](Insert_a_fieldnote_subrecord.md).

Later, you can choose a different record type.

1.  In the **Navigation Pane**, click **Notebook**, and then click **Record Edit**.

2.  In the **Records** pane, click the record or subrecord you want to change.

3.  In the **Record** pane, click the **Record Type** field, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose Record Type** dialog box appears.

4.  Do any of these steps:

    - Click the ![](../../../assets/images/User_Interface/Field_Descriptions/Field_Types/Plus_sign_box.GIF) (plus sign) to expand an item, if necessary.

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times each **Record Type** list item is used in the project.

    - Click the **Edit the Record Types** link to [insert](../../Lists_tools/Insert_a_list_item.md) or [edit](../../Lists_tools/Edit_a_list_item_or_subitem.md) a **Record Type** list item.

    - Click the desired record type. Click **OK**.
