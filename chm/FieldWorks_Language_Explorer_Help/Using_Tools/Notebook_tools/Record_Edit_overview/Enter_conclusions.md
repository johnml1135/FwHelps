# Enter conclusions

*Using Tools › Notebook › Record Edit*

1.  In the **Navigation Pane**, click **Notebook**, and then click **Record Edit**.

2.  In the **Records** pane, click the record you want to change.

3.  In the **Record** pane, click the [Conclusions](../../../User_Interface/Field_Descriptions/Notebook/Conclusion_field_Ntbk.md) field.

4.  Type your conclusions regarding the associated hypothesis for the current record.

5.  You can also do any of the following:

    - [Apply a style](../../../User_Interface/Menus/Format/apply_a_style_to_text.md) (*character* style, in most text fields; *paragraph* style, in multiparagraph text fields).

    - Insert or paste a [hyperlink](../../../Basic_Tasks/Creating_Hyperlinks/Creating_Hyperlinks_overview.md).
