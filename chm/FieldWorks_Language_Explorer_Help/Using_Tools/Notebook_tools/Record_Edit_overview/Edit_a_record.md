# Edit a record

*Using Tools › Notebook › Record Edit*

You want to preserve the accuracy of your data, particularly the data in the [Description](../../../User_Interface/Field_Descriptions/Notebook/Description_field_Ntbk.md) field. So, editing of the data in such fields is *discouraged*, especially if it’s been more than a few days since a record was written. Edits to other fields like **Anthropology Categories** or **Further Questions** are expected.

If you really need to make changes to data in a text field, do one of the following.

### Make changes

Never actually delete words in text fields. Instead, do the following:

1.  Type the new additional words or replacement words immediately *after* the obsolete words.

2.  [Apply styles](../../../User_Interface/Menus/Format/apply_a_style_to_text.md) to mark *added/replacement* words and to the *obsolete* words:

    - Select the obsolete words, and apply the **Deleted Text** (or possibly **Disabled Text**) style to them.

    - Select the added/replacement words, and apply the **Added Text** style to them.

Example:\
![](../../../assets/images/Using_Tools/Notebook_tools/Record_Edit_overview/Styles_examples.PNG)

### Rewrite an entire record

1.  [Insert a new record](Insert_a_fieldnote_record.md), or [subrecord](Insert_a_fieldnote_subrecord.md).

2.  Copy the relevant data into the same text field into new record, and edit it there.

3.  Return to the obsolete record, and then in the [Superseded By](Select_Superceded_By_references.md) field, select the new record.
