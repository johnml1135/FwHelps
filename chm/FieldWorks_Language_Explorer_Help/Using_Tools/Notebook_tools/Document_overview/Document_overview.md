# Document overview

*Using Tools › Notebook › Document view*

In **Notebook**, the **Document** view displays fieldnote records and subrecords in an easy-to-read format.

You can do any of the following:

- Use the **Configure Document Layout** [dialog box](../../../User_Interface/Menus/Tools/Configure_Document/Configure_Document_View_dialog_box.md) to choose *which fields* to display, and how to display them. You can also choose to *globally display or hide* subrecords.

  - [Filter](../../../Basic_Tasks/Filtering_data/Filter_Notebook_records.md) and [sort](../../../Basic_Tasks/Sorting_data/Sort_Notebook_records.md) the data in **Browse** or **Record Edit** to specify *which records and subrecords* to display, and their sort order.

  - [Use right-click to help configure Document layout](Use_right-click_to_help_configure_Document_view.md) (optional).

- Scroll through the records.

- [Insert](../Record_Edit_overview/Insert_a_fieldnote_record.md) a fieldnote record.

- [Print](../../../User_Interface/Menus/File/Print.md) the configured data.

- Use the [Find Record](../../../User_Interface/Menus/Edit/Find_a_fieldnote_record.md) dialog box.

- Use the [Find and Replace (Notebook)](../../../User_Interface/Menus/Edit/Find_and_Replace.md) dialog box.
