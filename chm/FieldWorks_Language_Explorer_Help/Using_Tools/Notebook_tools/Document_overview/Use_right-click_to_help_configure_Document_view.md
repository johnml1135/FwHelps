# Use right-click to help configure Document layouts

*Using Tools › Notebook › Document view*

You use the **Configure Document Layout** [dialog box](../../../User_Interface/Menus/Tools/Configure_Document/Configure_Document_View_dialog_box.md) to configure **Document** layouts. In the **Configure** pane of the dialog box, it can be difficult to find the specific part of the record you want to configure.

Alternatively, you can use a *context-sensitive* right-click menu command to quickly open the dialog box to the specific part of the record that you want to configure:

1.  In the Navigation Pane, click **Notebook**, and then click **Document**.

2.  Right-click the part of the record that you want to configure, and then click the right-click menu command.

    The **Configure Document Layout** dialog box opens.

    The specific part of the record that you right-clicked is selected in the **Configure** pane.

3.  [Configure](../../../User_Interface/Menus/Tools/Configure_Document/Configuring_a_Document_view.md) that part in the currently-selected document layout.

    - If you select a different document layout, the selection in the **Configure** pane is forgotten. In this case, select the desired document layout, and then click **OK** to close the dialog box. Then, do step 2 again.

### ![](../../../assets/images/Important_Icon.gif) Examples

- In a record, right-click **Record Type**, and then click **Configure Record Type in Document Layout**. This opens the dialog box, with **Record Type** selected in the **Configure** pane.

- After "**Counter Evidence**" in a record, right-click the title of the record that has the counter evidence, and then click **Configure Title in Document Layout**. This opens the dialog box, with **Counter Evidence** / **Title** selected in the **Configure** pane.

> [!TIP]
>
> - For content that is a *single character*, put the insertion point immediately after that character; then, right-click. This can help ensure you see the correct right-click menu command.
