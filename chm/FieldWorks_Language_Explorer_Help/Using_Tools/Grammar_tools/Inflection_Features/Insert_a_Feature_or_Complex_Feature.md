# Insert a feature or complex feature

*Using Tools › Grammar tools › Inflection Features*

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Inflection Features**.

2.  Do one of the following:

    - On the [Insert](../../../User_Interface/Toolbars/Insert_toolbar.md) toolbar, click ![](../../../assets/images/Using_Tools/Grammar_tools/Inflection_Features/Add_Feature.GIF) (*feature*) or ![](../../../assets/images/Using_Tools/Grammar_tools/Inflection_Features/Add_Complex_Feature.GIF) (*complex feature*).

    - On the **Insert** menu, click **Feature** or **Complex Feature**.

    The **Add Inflection Feature from Catalog** dialog box appears, regardless of whether you clicked **Feature** or **Complex Feature**. However, if the feature you need is not in the catalog, the "create" link (discussed in step 3.) creates a *feature* or a *complex feature*, depending upon which you clicked in step 2.

3.  Do one of the following:

    - In the **Inflection Features Catalog** pane, select one or more feature value, and then click **Add**.

      The feature(s) you selected appears in the **Feature** pane. One or more new rows appears in the **Features** pane.

    - Click the "create" link, located near the bottom of the catalog.

      **Note:** The link text may be either "**The inflection feature I need is not shown in the Catalog. Create a custom inflection feature**" *or* "**The inflection feature I need is not shown in the Catalog. Create a custom complex feature**" depending on the toolbar or menu command you clicked in step 2.

      An empty set of fields appears in the **Feature** pane. One or more new rows appear in the **Features** pane.

4.  If necessary, edit existing content in [fields](../../../User_Interface/Field_Descriptions/Grammar/Inflection_Features_fields/Features_fields_overview.md) or do any of the following:

    - Select the check box for the **Display label** [field](../../../User_Interface/Field_Descriptions/Grammar/Inflection_Features_fields/Display_label_field_(Features).md) (optional).

    - For a feature (*not* a *complex* feature), [insert a feature value](Insert_a_feature_value.md).

    - Select the check box for the **Use Abbreviation as its label** [field](../../../User_Interface/Field_Descriptions/Grammar/Inflection_Features_fields/Show_Abbr_as_label_field_Features.md) (optional).

    - For a *complex* feature, click the [Type](../../../User_Interface/Field_Descriptions/Grammar/Inflection_Features_fields/Type_field_Features.md) field. Click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears to open the **Choose Type** dialog box. (The [Feature Types list](../../Lists_tools/Feature_Types/Feature_Types_overview.md) contains the available types.) Choose a [feature type](../../Lists_tools/Feature_Types/Feature_Types_overview.md), and then click **OK**.

> [!IMPORTANT]
>
> - It is *strongly recommended* that you [contact](../../../Overview/Technical_support.md) a FLEx consultant before you overtly add or edit features or feature types. If these are not handled correctly, [parsers](../../../User_Interface/Menus/Parser/Parsing_words_overview.md) may not analyze many of your wordforms.
>
> - *Bantu noun classes* are included in the **Add Inflection Feature from Catalog** dialog box.\
