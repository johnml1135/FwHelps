# Insert a feature value

*Using Tools › Grammar tools › Inflection Features*

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Inflection Features**.

2.  In the **Inflection Features** pane, select an existing feature to which you will insert a value, *or* [insert a new feature](Insert_a_Feature_or_Complex_Feature.md).

3.  In the **Feature** pane, click the [Values field](../../../User_Interface/Field_Descriptions/Grammar/Inflection_Features_fields/Values_field_Features.md) label.

    A link and a menu button (![](../../../assets/images/Using_Tools/Grammar_tools/Phonemes/Menu_Button_pic.GIF)) appear.

4.  Do one of the following:

    - Click the **Insert Feature Value** link.

    - Click the menu button, and then select **Insert Feature Value**.

    - Right-click the **Values** label, and then select **Insert Feature Value**.

    - In the **Insert** menu, click **Feature Value**.

    A new set of empty fields appear for a new value.

5.  Enter content in the **Name**, **Abbreviation**, and **Description** fields.

6.  For the **Use Abbreviation as its label** check box, do one of the following:

    - If you want the abbreviation to appear in the **Dictionary**, select the check box.

    - If you do *not* want the abbreviation to appear in the **Dictionary**, leave the check box cleared (without a check mark).

    (The abbreviation will always appear in appropriate **Grammatical Info Details** fields (**Lexicon Edit**.)

> [!IMPORTANT]
>
> - It is *strongly recommended* that you [contact](../../../Overview/Technical_support.md) a FLEx consultant before you overtly add or edit features or feature types. If these are not handled correctly, [parsers](../../../User_Interface/Menus/Parser/Parsing_words_overview.md) may not analyze many of your wordforms.
