# Inflection Features overview

*Using Tools › Grammar tools › Inflection Features*

Primarily, [categories](../Category_Edit/Category_Edit_overview.md) and [grammatical information](../../Lexicon_tools/Lexicon_Edit/change_the_grammatical_info.md) use inflection features. [Feature types](../../Lists_tools/Feature_Types/Feature_Types_overview.md) and [irregularly inflected form variant types](../../../User_Interface/Menus/Tools/Convert_variants_utility.md) also use them.

[Stem Allomorph Labels](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Stem_Allomorph_Label_field.md) use sets of inflection features ([Feature Sets](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Feature_Set_field_Category_Edit.md)) to control stem allomorphy that is dependent not on phonological issues, but on the presence of certain inflectional features. [Insert a Stem Allomorph Label](../Category_Edit/Insert_a_Stem_Allomorph_Label.md) has more information.

The **Inflection Features** `Help` topics are the following:

[About Inflection Features and Feature Types](About_Infl_Features_and_Types.md)

[Insert an inflection feature or complex feature](Insert_a_Feature_or_Complex_Feature.md)

[Insert an inflection feature value](Insert_a_feature_value.md)

[Delete an inflection feature or complex feature](delete_a_feature_or_complex_feature.md)

[Delete an inflection feature value](delete_a_feature_value.md)

> [!IMPORTANT]
>
> - It is *strongly recommended* that you [contact](../../../Overview/Technical_support.md) a FLEx consultant before you overtly add or edit features or feature types. If these are not handled correctly, [parsers](../../../User_Interface/Menus/Parser/Parsing_words_overview.md) may not analyze many of your wordforms.
>
> - For more information regarding when you should use *inflection classes* and when you should use *inflection features*, point to **Resources** on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
