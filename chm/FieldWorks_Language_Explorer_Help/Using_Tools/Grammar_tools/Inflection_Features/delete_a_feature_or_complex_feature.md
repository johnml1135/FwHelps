# Delete a feature or complex feature

*Using Tools › Grammar tools › Inflection Features*

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Inflectional Features**.

2.  In the **Inflection Features** pane, select the inflection feature or complex feature you will delete.

3.  Do one of the following:

    - On the [Standard](../../../User_Interface/Toolbars/Standard_toolbar.md) toolbar, click ![](../../../assets/images/Using_Tools/Grammar_tools/Inflection_Features/RedDeleteRecordX.GIF).

    - On the **Edit** menu, click **Delete Feature** or **Delete Complex Feature**.

    - Right-click the feature or complex feature in the **Inflection Features** pane, and then select **Delete Feature** or **Delete Complex Feature**.

    The **Delete Feature** or **Delete Complex Feature** warning box appears and asks if you want to continue with the deletion.

4.  If you are sure you want to delete the feature or complex feature specified in the warning box, click **Delete**.

    The specified feature or complex feature is deleted.

    - Otherwise, click **Cancel**.

> [!IMPORTANT]
>
> - It is *strongly recommended* that you [contact](../../../Overview/Technical_support.md) a FLEx consultant before you overtly add or edit features or feature types. If these are not handled correctly, [parsers](../../../User_Interface/Menus/Parser/Parsing_words_overview.md) may not analyze many of your wordforms.
