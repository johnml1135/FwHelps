# Delete a feature value

*Using Tools › Grammar tools › Inflection Features*

1.  In the **Navigation** **Pane**, click **Grammar**, and then select **Inflection Features**.

2.  In the **Inflection Features** pane, select the feature that has the value you will delete.

3.  In the **Feature** pane, do one of the following:

    - Click the **Value Name** field label of the feature value you will delete. Click the menu button ![](../../../assets/images/Menu_Button_pic.GIF) that appears, and then select **Delete Feature Value**.

    - Right-click the **Value Name** label of the feature you will delete, and then select **Delete Feature Value**.

    The **Delete Feature Value** warning box appears and asks if want to continue with the deletion.

4.  If you are sure you want to delete the feature value specified in the warning box, click **Delete**.

    The specified feature value is deleted.

> [!IMPORTANT]
>
> - It is *strongly recommended* that you [contact](../../../Overview/Technical_support.md) a FLEx consultant before you overtly add or edit features or feature types. If these are not handled correctly, [parsers](../../../User_Interface/Menus/Parser/Parsing_words_overview.md) may not analyze many of your wordforms.
