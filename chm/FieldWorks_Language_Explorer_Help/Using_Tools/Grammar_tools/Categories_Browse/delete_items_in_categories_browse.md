# Delete item in Categories Browse

*Using Tools › Grammar tools › Categories Browse*

You can delete a category from **Categories Browse**.

1.  In the **Navigation Pane**, click **Grammar**, and then click **Categories Browse**.

2.  In the **Categories** pane, click the item you will delete, and then do one of the following:

    - Right-click, and then select **Delete Selected Category (or Part of Speech)**.

    - On the [Standard](../../../User_Interface/Toolbars/Standard_toolbar.md) toolbar, click **![](../../../assets/images/Using_Tools/Grammar_tools/Categories_Browse/RedDeleteRecordX.GIF)**.

    - On the **Edit** menu, **Delete Category (or Part of Speech)**.

    The **Delete Category (or Part of Speech)** warning box appears, and specifies the category item you have selected for deletion and where it is used, if applicable.

3.  If you are sure you want to delete the item specified in the warning box, click **Delete**.

The selected category is deleted.

1.  - Otherwise, click **Cancel**.

> [!TIP]
>
> - If you have a [filter](../../../Basic_Tasks/Filtering_data/filter_grammar_data.md) turned on, you may not see the category you want to delete.
