# Generate a grammar sketch

*Using Tools › Grammar tools › Grammar Sketch*

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Grammar Sketch**.

2.  Click the **Generate** button, which is located below the toolbars.

    A progress indicator box appears and then the updated grammar sketch appears. The sketch is automatically saved in Language Explorer.

> [!NOTE]
>
> - The top line is the title of the sketch, such as **A Sketch of Sena 3 Morphology**.
>
> - Below the title are two placeholders: **\[Insert investigators' names here\]** and **\[Insert affiliation here\]**.
>
>   These are *not* editable in Language Explorer.
>
> - A date and time stamp records when the sketch was generated.
>
>   Generate the grammar sketch as often as needed to keep it current.
>
> - The **Contents** section has hyperlinks to each of the main sections.
>
> - For more information, on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu, point to **Resources** and then click **Editing Linguistics Papers Using XLingPaper**.
