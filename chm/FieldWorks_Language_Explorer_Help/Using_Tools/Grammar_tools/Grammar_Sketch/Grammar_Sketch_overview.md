# Grammar Sketch overview

*Using Tools › Grammar tools › Grammar Sketch*

The **Grammar Sketch** provides you or your consultant with a sketch of the current state of your grammatical description. It reflects the information you have entered in describing the language you are working on.

The **Grammar Sketch** `Help` topics are the following:

[Generate a grammar sketch](Generate_a_Grammar_Sketch.md)

[Using a grammar sketch](Using_a_Grammar_Sketch.md)

> [!TIP]
>
> - For more information about editing the saved grammar sketch, on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu, point to **Resources**, and then click **Editing Linguistics Papers Using XLingPaper**.
>
> - You can review the Help topics in [Field Descriptions](../../../User_Interface/Field_Descriptions/field_descriptions_overview.md) to learn which fields some of the content in the grammar sketch (not exhaustive). You can access the topics for each field using the menu button ![](../../../assets/images/Menu_Button_pic.GIF) in that field.
