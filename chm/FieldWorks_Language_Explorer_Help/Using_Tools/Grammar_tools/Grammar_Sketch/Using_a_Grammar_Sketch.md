# Using a grammar sketch

*Using Tools › Grammar tools › Grammar Sketch*

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Grammar Sketch**.

2.  After you [generate a grammar sketch](Generate_a_Grammar_Sketch.md), you can use its features and contents in any of these ways:

    - To navigate in the sketch, use the hyperlinks that appear in the **Contents** pane, in text and various tables' column headings.

    - You should review the **Residue** section often, for example, to learn about unclassified affixes. This could be particularly important if you are using a [parser](../../../User_Interface/Menus/Parser/Parsing_words_overview.md).

    - Use the **Back in Sketch** or **Forward in Sketch** buttons ![](../../../assets/images/Using_Tools/Grammar_tools/Grammar_Sketch/left_and_right_arrows.png) to move backwards or forward to previously-visited locations in the sketch.

    - Press the shortcut keys `Ctrl+F` to open a **Find** dialog box so search in a sketch.

> [!TIP]
>
> - The *Back* and *Forward* buttons on the [Standard](../../../User_Interface/Toolbars/Standard_toolbar.md) toolbar move you between previously visited [Navigation Pane](../../../User_Interface/Toolbars/Navigation/Navigation_Pane_overview.md) tool (view) or records (entries, list items, and so on).
