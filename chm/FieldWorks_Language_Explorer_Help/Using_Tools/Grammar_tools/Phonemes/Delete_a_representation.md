# Delete a grapheme

*Using Tools › Grammar tools › Phonemes*

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Phonemes**.

2.  In the **Phonemes** pane, click the phoneme that has the grapheme you will delete.

3.  In the **Phoneme** pane, do the following:

    - Click the **Grapheme** field, and then click the menu button ![](../../../assets/images/Using_Tools/Grammar_tools/Phonemes/Menu_Button_pic.GIF) that appears.

    - Click **Delete Grapheme**.

      The **Delete Phoneme Grapheme** warning box appears.

    - If you are sure you want to delete the grapheme specified in the warning box, click **Delete**.

      The **Grapheme** field and the grapheme in it are deleted.

      - Otherwise, click **Cancel**.

> [!IMPORTANT]
>
> - If there is only one grapheme, the **Delete Grapheme** command is not available, because the program requires that at least one be specified for a phoneme. In this case, you can [edit the phoneme](Edit_a_phoneme.md).
