# Phonemes overview

*Using Tools › Grammar tools › Phonemes*

In order to use [environments](../Environments/Environments_overview.md), which refer to either phonemes or [natural classes](../Natural_Classes/Natural_classes_overview.md), you need to create a list of all the phonemes in your language. The [Phonological Rule-based parser](../../../User_Interface/Menus/Parser/Parsing_words_(HermitCrab).md) requires fully specified phonemes.

For each phoneme, you need to enter one or more graphemes that represent them. For example, in Greek, the /s/ phoneme has two such graphemes:\
![](../../../assets/images/Using_Tools/Grammar_tools/Phonemes/sigma_character_Final.GIF) (which is used word finally) and ![](../../../assets/images/Using_Tools/Grammar_tools/Phonemes/sigma_character.GIF) (which is used everywhere else).

Enter the phonemic character in the **Refer to as** field and in the first **Grapheme** field. If other *graphemes* appear in the orthography, enter them in inserted **Grapheme** fields.

The **Phonemes** `Help` topics are the following:

- [Insert a phoneme](Insert_a_phoneme.md)

  - [Choose phonological features](Choose_phonological_features.md)

  - [Edit a phoneme](Edit_a_phoneme.md)

  - [Insert another grapheme](Insert_a_representation.md)

  - [Non-base characters as graphemes](Non_Base_Characters_as_Graphemes.md)

- [Delete a phoneme](Delete_a_Phoneme.md)

- [Delete a grapheme](Delete_a_representation.md)

- [Remove a phonological feature](Remove_a_phonological_feature.md)
