# Edit a phoneme

*Using Tools › Grammar tools › Phonemes*

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Phonemes**.

2.  In the **Phonemes** pane, click the desired phoneme.

3.  In the **Phoneme** pane, change the content in any of these fields:

    - [Refer to as](../../../User_Interface/Field_Descriptions/Grammar/Phonemes_fields/name_field_phonemes.md)

    - [IPA Symbol](../../../User_Interface/Field_Descriptions/Grammar/Phonemes_fields/Basic_IPA_Symbol_fld_(Phms).md)

    - [Description](../../../User_Interface/Field_Descriptions/Grammar/Phonemes_fields/description_field_phonemes.md)

    - [Phonological Features](../../../User_Interface/Field_Descriptions/Grammar/Phonemes_fields/Phonological_Features_field.md)

    - [Grapheme](../../../User_Interface/Field_Descriptions/Grammar/Phonemes_fields/representation_field_phonemes.md)

> [!TIP]
>
> - Review the information about these fields to learn about their optional interdependence. For example, entering content in the **IPA Symbol** field automatically adds a description and phonological features if those fields are empty.
>
> - [Bulk Edit Phoneme Features](../Bulk_Edit_Phoneme_Features/Bulk_Edit_Phoneme_Features.md) allows you to change multiple phonemes at the same time.
