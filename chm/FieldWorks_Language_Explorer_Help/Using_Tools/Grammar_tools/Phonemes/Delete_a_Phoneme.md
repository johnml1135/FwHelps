# Delete a phoneme

*Using Tools › Grammar tools › Phonemes*

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Phonemes**.

2.  In the **Phonemes** pane, click the phoneme you will delete

3.  Do one of the following:

    - On the [Standard](../../../User_Interface/Toolbars/Standard_toolbar.md) toolbar, click ![](../../../assets/images/Using_Tools/Grammar_tools/Phonemes/RedDeleteRecordX.GIF).

    - On the **Edit** menu, click **Delete Phoneme**.

    - Right-click, and then select **Delete Selected Phoneme**.

    The **Delete Phoneme** warning box appears and asks if want to continue with the deletion.

4.  If you are sure you want to delete the phoneme specified in the warning box, click **Delete**.

    The specified phoneme is deleted.

> [!IMPORTANT]
>
> - Phonemes are used by [natural classes](../Natural_Classes/Natural_classes_overview.md) and [environments](../Environments/Environments_overview.md).
