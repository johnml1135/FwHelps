# Bulk Edit Phoneme Features overview

*Using Tools › Grammar tools › Bulk Edit Phoneme Features*

Use this tool to choose a particular phonological feature and value for multiple phonemes at the same time. That is, you can [bulk edit](Bulk_Edit_Phoneme_Features.md) them. You can also choose to remove a feature from multiple phonemes.

> [!NOTE]
>
> - In the **Phonemes** pane, the **Phoneme** column matches the content in the [Refer to as](../../../User_Interface/Field_Descriptions/Grammar/Phonemes_fields/name_field_phonemes.md) field in [Phonemes](../Phonemes/Phonemes_overview.md).
>
> - You can [configure the columns](../../../Basic_Tasks/Configure_Columns/Configure_Columns_overview.md) to display the other [fields](../../../User_Interface/Field_Descriptions/Grammar/Phonemes_fields/Phonemes_fields_overview.md).
>
> - You cannot manually edit any data directly in the rows or cells.
