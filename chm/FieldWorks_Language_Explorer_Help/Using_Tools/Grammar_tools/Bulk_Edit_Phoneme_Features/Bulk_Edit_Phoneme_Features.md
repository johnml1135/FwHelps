# Bulk Edit Phoneme Features

*Using Tools › Grammar tools › Bulk Edit Phoneme Features*

1.  Make sure the project has the necessary [phonemes](../Phonemes/Insert_a_phoneme.md), [phonological features](../Phonological_Features/Insert_a_phonological_feature.md) and [values](../Phonological_Features/Insert_a_phonological_feature_value.md).

2.  In the **Navigation** **Pane**, click **Grammar**, and then click **Bulk Edit Phoneme Features**.

3.  [Configure the columns](../../../Basic_Tasks/Configure_Columns/Configure_Columns_overview.md) to show the feature you will choose.

4.  [Sort](../../../Basic_Tasks/Sorting_data/Sort_data.md) and [filter](../../../Basic_Tasks/Filtering_data/filter_data.md) columns (features), as necessary.

5.  [Select the rows](Select_rows_(Phonemes).md) (phonemes) that you want to change.

6.  Do the following:

    - Click the **Choose Feature** down arrow, and then click the feature.

    - Click the **Choose Value** down arrow, and then click the value or **Blank**.

**Blank** *removes* the feature/value from the selected phonemes.

1.  - Click **Preview**, and review the pending changes. Clear (![](../../../assets/images/UncheckedBox.PNG)) any row you decide not to change now.

    - Click **Apply**.

      Selected rows are changed.

> [!TIP]
>
> - The **Toggle** command discussed in [Select rows (Phonemes)](Select_rows_(Phonemes).md) may be particularly useful as values are often binary, (+ or -).
