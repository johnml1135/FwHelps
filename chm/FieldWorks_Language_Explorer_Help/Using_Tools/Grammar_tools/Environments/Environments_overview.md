# Environments overview

*Using Tools › Grammar tools › Environments*

Lexeme forms and allomorphs may be constrained by their phonological environment. [Parsers](../../../User_Interface/Menus/Parser/Parsing_words_overview.md) use environments.

You insert and edit environments in **Environments** ([Grammar](../grammar_overview.md)). This is where they are stored. However, you may type or construct environments directly in **Environments** fields ([Lexicon Edit](../../Lexicon_tools/Lexicon_Edit/lexicon_edit_overview.md)). **See:** [Environments field (Lexeme Form)](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Environments_field.md) or [Environments field (Allomorphs)](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Alternate_Forms_level_flds/Environments_fld_allomorph.md).

The **Environment** `Help` topics are the following:

[Insert an environment](Insert_an_environment.md)

[Delete an environment](Delete_an_Environment.md)

[Edit an environment](Edit_an_Environment.md)

[Environment String Representation examples](Environment_String_Rep_examples.md)

> [!NOTE]
>
> - Environments may use either [natural classes](../Natural_Classes/Natural_classes_overview.md) and/or [graphemes](../Phonemes/Phonemes_overview.md) ([phoneme](../../../User_Interface/Field_Descriptions/Grammar/Phonemes_fields/Phonemes_fields_overview.md)).
>
> - [Program-proposed analyses](../../Texts_&_Words_tools/Interlinear_Texts/interlinear_views_colors.md) based on previous *user* analyses do not use environments.
>
> - For a discussion about environments, point to **Resources** on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**. See to **3 Morphophonemics**.
