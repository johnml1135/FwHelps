# Delete an environment

*Using Tools › Grammar tools › Environments*

1.  In the **Navigation Pane**, click **Grammar**, and then click **Environments**.

2.  In the **Environments** pane, select the environment you will delete, and then do one of the following:

    - On the [Standard](../../../User_Interface/Toolbars/Standard_toolbar.md) toolbar, click ![](../../../assets/images/Using_Tools/Grammar_tools/Environments/RedDeleteRecordX.GIF).

    - On the **Edit** menu, click **Delete Environment**.

    - Right-click that environment, and then select **Delete Selected Environment**.

    The **Delete Environment** warning box appears and asks if you want to continue with the deletion.

3.  If you are sure you want to delete the environment specified in the warning box, click **Delete**.

    The specified environment is deleted.
