# Edit an environment

*Using Tools › Grammar tools › Environments*

1.  In the **Navigation Pane**, click **Grammar**, and the click **Environments**.

2.  In the **Environments** pane, click the environment that you will edit.

3.  Do any of the following:

    - If you typed or constructed the environment directly in an **Environments** field ([Lexicon Edit](../../Lexicon_tools/Lexicon_Edit/lexicon_edit_overview.md)), enter the name and description.

    - Edit the content in one or more fields.

    - If you edited the **String Representation** field, leave that field when you are done editing by clicking another field, such as the **Name** field.

      If a red wavy underline appears below the environment in the **String Representation** field, there is a problem with that environment. If you cannot determine and correct the problem, click [Problems](../Problems/Problems_overview.md) in the **Navigation Pane**.

      Environments with a problem are *not* available for use, such as in the **Choose Environments** dialog box.

> [!TIP]
>
> - Refer to [Environment String Representations](Environment_String_Rep_examples.md) for string representation syntax examples.
>
>   In addition, you can point to **Resources** on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing** for more information.
