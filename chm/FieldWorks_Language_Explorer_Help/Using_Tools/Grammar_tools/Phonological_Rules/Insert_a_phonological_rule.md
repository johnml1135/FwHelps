# Insert a phonological or metathesis rule

*Using Tools › Grammar tools › Phonological Rules*

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Phonological Rules**.

2.  Do one of the following:

    - On the [Insert menu](../../../User_Interface/Menus/Insert/Insert_overview.md), click **Phonological Rule** or **Metathesis Rule**.

    - On the **Insert** [toolbar](../../../User_Interface/Toolbars/Insert_toolbar.md), click ![](../../../assets/images/Using_Tools/Grammar_tools/Environments/Create_Environment_Grammar.GIF) or ![](../../../assets/images/Using_Tools/Grammar_tools/Phonological_Rules/MetathesisRuleIcon.GIF).

    An empty phonological rule or metathesis rule appears.

3.  Enter a [name](../../../User_Interface/Field_Descriptions/Grammar/Phonologocial_Rules_fields/Name_field_(Ph_Rules).md) and [description](../../../User_Interface/Field_Descriptions/Grammar/Phonologocial_Rules_fields/Description_field_(Ph_Rules).md).

4.  Select a [direction](../../../User_Interface/Field_Descriptions/Grammar/Phonologocial_Rules_fields/Direction_field_(Ph_Rules).md).

5.  In the **Order Number** [field](../../../User_Interface/Field_Descriptions/Grammar/Phonologocial_Rules_fields/Order_Number_field_(Ph_Rules).md), [specify an order](Specify_order_number.md).

6.  In the **Rule Formula** [field](../../../User_Interface/Field_Descriptions/Grammar/Phonologocial_Rules_fields/Rule_Formula_field_(Ph_Rules).md), do one of the following:

    - [Build the phonological rule](Build_a_phonological_rule.md).

    - [Build the metathesis rule](Build_a_metathesis_rule.md).
