# Choose required categories

*Using Tools › Grammar tools › Phonological Rules*

You can choose grammatical categories that constrain the phonological rule-based [parser](../../../User_Interface/Menus/Parser/Phonological_Rule_Based_parser_overview.md).

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Phonological Rules**.

2.  In the **Phonological Rules** pane, select the rule.

3.  Click the **Required Categories** [field](../../../User_Interface/Field_Descriptions/Grammar/Phonologocial_Rules_fields/Required_Categories.md), and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

The **Choose Required Categories** dialog box appears.

4.  Do any of these steps:

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times the categories are used in the project.

    - Click the **Add a category** link to [insert](../Category_Edit/Insert_a_Category.md) or edit a category.

    - Select (![](../../../assets/images/CheckedBox.PNG)) the categories you want to display. Click **OK**.
