# Specify the order of phonological rules

*Using Tools › Grammar tools › Phonological Rules*

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Phonological Rules**.

2.  In the **Phonological Rules** pane, click the desired phonological or metathesis rule.

3.  In the **Order Number** [field](../../../User_Interface/Field_Descriptions/Grammar/Phonologocial_Rules_fields/Order_Number_field_(Ph_Rules).md), select the current number, and then type a new number.

The number is replaced and any other rule that had that same number automatically changes to show a different number.

4.  Repeat this for each rule until all the rules in the **Phonological Rules** pane have the desired order number. You can [sort](../../../Basic_Tasks/Sorting_data/Sort_data.md) the rules by the values in the **Order** column.

> [!IMPORTANT]
>
> - The phonological rule-based [parser](../../../User_Interface/Menus/Parser/Parsing_words_(HermitCrab).md) uses these order numbers.
