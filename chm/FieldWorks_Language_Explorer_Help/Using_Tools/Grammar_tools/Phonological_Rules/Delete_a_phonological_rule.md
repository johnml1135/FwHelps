# Delete a phonological rule

*Using Tools › Grammar tools › Phonological Rules*

Optionally, before you delete a rule, you can first make it [inactive](../../../User_Interface/Field_Descriptions/Grammar/Phonologocial_Rules_fields/Active_field_(Ph_Rules).md) to see how the rule affects parsing.

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Phonological Rules**.

2.  In the **Phonological Rues** pane, select the rule you will delete.

3.  Do one of the following:

    - Click the **Edit** menu, click **Delete Phonological Rule** or **Delete Metathesis Rule**.

    - On the [Standard](../../../User_Interface/Toolbars/Standard_toolbar.md) toolbar, click ![](../../../assets/images/Using_Tools/Grammar_tools/Inflection_Features/RedDeleteRecordX.GIF).

    - Right-click the rule, and then select **Delete selected Phonological Rule** or **Delete selected Metathesis Rule**.

    The **Delete Phonological Rule** or **Delete Metathesis Rule** warning box appears and asks if you want to continue with the deletion.

4.  If you are sure you want to delete the rule, click **Delete**.

    The selected rule is deleted.

    - Otherwise, click **Cancel**.
