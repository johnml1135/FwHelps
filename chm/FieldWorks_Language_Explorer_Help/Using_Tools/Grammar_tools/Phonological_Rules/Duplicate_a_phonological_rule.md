# Duplicate a phonological or metathesis rule

*Using Tools › Grammar tools › Phonological Rules*

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Phonological Rules**.

2.  In the **Phonological Rues** pane, select the rule you will duplicate.

3.  Right-click the rule, and then select **Duplicate selected Phonological Rule** or **Duplicate selected Metathesis Rule**.

    The duplicated rule appears and the Order Number reflects that duplication.
