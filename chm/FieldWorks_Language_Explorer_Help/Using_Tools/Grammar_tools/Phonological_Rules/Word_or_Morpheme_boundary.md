# Word or Morpheme boundary

*Using Tools › Grammar tools › Phonological Rules*

A number sign (#) represents a word boundary. These are used with phonological rules and [environments](../Environments/Environment_String_Rep_examples.md). A plus sign (+) represents a morpheme boundary.

You can [insert](Insert_a_phonological_rule.md) a word boundary or a morpheme boundary in phonological rules.
