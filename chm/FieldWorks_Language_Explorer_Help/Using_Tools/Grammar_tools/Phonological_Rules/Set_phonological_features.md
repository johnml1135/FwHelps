# Set phonological features

*Using Tools › Grammar tools › Phonological Rules*

1.  In the Navigation Pane, click **Grammar**, and then click **Phonological Rules**.

2.  In the **Phonological Rules** pane, click the desired phonological rule.

3.  In the **Phonological Rule** pane, right-click the desired item the **Rule Formula** [field](../../../User_Interface/Field_Descriptions/Grammar/Phonologocial_Rules_fields/Rule_Formula_field_(Ph_Rules).md) and click **Set Phonological Features**.

The **Set Phonological Features** dialog box appears.

3.  In the dialog box, do the following:

    - Click the feature, and then, in the **Value** column select a value **+**, **-**, or a custom value you inserted. Or, select **agree** or **disagree**.

    - Repeat this step for each feature you want to insert. Click **OK**.

    - Click **OK**.

> [!TIP]
>
> - **\<n/a\>** removes a previous selection from the rule.
