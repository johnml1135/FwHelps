# Choose excluded properties

*Using Tools › Grammar tools › Phonological Rules*

You can choose exception "features" and/or inflection classes that constrain the phonological rule-based [parser](../../../User_Interface/Menus/Parser/Phonological_Rule_Based_parser_overview.md).

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Phonological Rules**.

2.  In the **Phonological Rules** pane, select the rule.

3.  Click the **Excluded Properties** [field](../../../User_Interface/Field_Descriptions/Grammar/Phonologocial_Rules_fields/Excluded_Properties.md), and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

The **Choose Excluded Properties** dialog box appears.

4.  Do any of these steps:

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times the exception "features" and inflection classes are used in the project.

    - Click the **Edit the Exception "Features"** link so you can [insert](../Exception_Features/insert_an_exception_feature.md) or edit and exception "feature".

    - Click the **Add an inflection class to a category** link so you can [insert](../Category_Edit/Insert_an_Inflection_Class.md) or edit an inflection class.

    - Select (![](../../../assets/images/CheckedBox.PNG)) one more exception "features" and/or inflection classes. Click **OK**.
