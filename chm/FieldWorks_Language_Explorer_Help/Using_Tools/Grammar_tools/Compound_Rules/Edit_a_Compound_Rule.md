# Edit a compound rule

*Using Tools › Grammar tools › Compound Rules*

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Compound Rules**.

2.  In the **Compound Rules** pane, click the compound rule you will edit.

3.  Do one or more of the following:

    - Edit the **Name**.

    - Edit the **Description**.

    - Select a different [category](../Category_Edit/Category_Edit_overview.md) for the **Left** or **Right Member**.

4.  For *headed* compound rules, do the following:

    - Select or clear the **Right Headed** check box.

    - If the **Override Head with: Category** needs to be changed, select a different category for it.

      For more information, point to **Resources** on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**. Refer to the section **Incorporation as a Headed Compound with Override**.

5.  For *non-headed* compound rules, select a different **Category** and, if necessary, an **Inflection Class** for the **Result**.

> [!NOTE]
>
> - You *cannot* change a *headed* compound rule into a *non-headed* compound rule, or vise versa. Instead, [delete](Delete_a_Compound_Rule.md) the incorrect rule and [insert](Insert_a_compound_rule.md) a correct rule.
>
> - **See Also:** [Active field](../../../User_Interface/Field_Descriptions/Grammar/Compound_Rules_fields/Active_field_Compound_Rules.md).
