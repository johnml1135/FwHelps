# Delete a compound rule

*Using Tools › Grammar tools › Compound Rules*

Optionally, before you delete a rule, you can first make it [inactive](../../../User_Interface/Field_Descriptions/Grammar/Compound_Rules_fields/Active_field_Compound_Rules.md) to see how the rule affects parsing.

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Compound Rules**.

2.  In the **Compound Rules** pane, click the rule you will delete, and then do one of the following:

    - On the [Standard](../../../User_Interface/Toolbars/Standard_toolbar.md) toolbar, click ![](../../../assets/images/Using_Tools/Grammar_tools/Compound_Rules/RedDeleteRecordX.GIF).

    - On the **Edit** menu, click **Delete** *\<rule\>* ****\
      (*\<rule\>* could be **Left- or Right-Headed Compound Rule**, or **Non-Headed Compound Rule**).

    - Right-click the unwanted compound rule, and then select **Delete selected Compound Rule**.

    The **Delete** *\<rule\>* warning box appears, and asks if you want to continue with the deletion.

3.  If you are sure you want to delete the rule specified in the warning box, click **Delete**.

    The specified rule is deleted.
