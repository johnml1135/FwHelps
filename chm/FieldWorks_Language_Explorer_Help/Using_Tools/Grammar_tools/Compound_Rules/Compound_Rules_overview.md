# Compound Rules overview

*Using Tools › Grammar tools › Compound Rules*

The **Compound Rules** feature allows you to define overt rules for word-internal compounds consisting of two stems.

There are two basic kinds of compounds:

- **Left- or Right-Headed**

  Either the left *or* the right member is the "head" of the compound. The resulting stem has the *same* category as the head.

- **Non-Headed**

  The resulting stem has a *different* category than either the left or the right member of the compound.

There are default compound rules that a parser can use if you have not defined overt ones. [HC Parser parameters](../../../User_Interface/Menus/Parser/About_parser_parameters.md) allow you control the use of the default compound rules by that parser.

The **Compound Rules** `Help` topics are the following:

[Insert a compound rule](Insert_a_compound_rule.md)

[Delete a compound rule](Delete_a_Compound_Rule.md)

[Edit a compound rule](Edit_a_Compound_Rule.md)

> [!IMPORTANT]
>
> - [Parsers](../../../User_Interface/Menus/Parser/Parsing_words_overview.md) use the compound rules you create while analyzing isolated word forms.
