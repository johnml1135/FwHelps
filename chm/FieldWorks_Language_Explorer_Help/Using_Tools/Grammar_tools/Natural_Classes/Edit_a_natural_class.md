# Edit a natural class

*Using Tools › Grammar tools › Natural Classes*

1.  In the **Navigation Pane**, click **Grammar**, and then click **Natural Classes**.

2.  In the **Natural Classes** pane, select the natural class you will edit.

    - See ![](../../../assets/images/Important_Icon.gif) **Important** below.

3.  Edit the content in any of these [fields](../../../User_Interface/Field_Descriptions/Grammar/Natural_Classes_fields/natural_classes_fields_overview.md):

    - [Name](../../../User_Interface/Field_Descriptions/Grammar/Natural_Classes_fields/name_field_natural_classes.md)

    - [Description](../../../User_Interface/Field_Descriptions/Grammar/Natural_Classes_fields/description_field_natural_classes.md)

    - [Abbreviation](../../../User_Interface/Field_Descriptions/Grammar/Natural_Classes_fields/Abbreviation_field_Natural_Classes.md)

    - [Phonemes](../../../User_Interface/Field_Descriptions/Grammar/Natural_Classes_fields/Phonemes_field_Natural_Classes.md)

    - [Phonological Features](../../../User_Interface/Field_Descriptions/Grammar/Natural_Classes_fields/Phonological_Features_fld(NC).md)

> [!IMPORTANT]
>
> - Language Explorer will automatically create a natural class when you insert one or more phonological features in a phonological rule (**Rule Formula** field) *or* in one of the **Affix Process Rule** fields, *if the resulting natural class is unique* (does not already exist).
>
> In this case:
>
> - The initial (default) [name](../../../User_Interface/Field_Descriptions/Grammar/Natural_Classes_fields/name_field_natural_classes.md) is "**Created automatically for rule "\<**name**\>"**. You can type a new name in the **Name** field.
>
> - Regarding edits in the **Phonological Features** field in **Natural Classes**, it is recommended that you edit the field where the you inserted the phonological feature. A change here in **Natural Classes** *may affect more rules than you intended*.
