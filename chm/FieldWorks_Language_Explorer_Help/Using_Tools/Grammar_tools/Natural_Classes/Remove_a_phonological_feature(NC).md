# Remove a phonological feature from Natural Classes

*Using Tools › Grammar tools › Natural Classes*

In **Natural Classes**, you cannot select and delete content in the [Phonological Features field](../../../User_Interface/Field_Descriptions/Grammar/Natural_Classes_fields/Phonological_Features_fld(NC).md). Instead, you use the **Choose Phonological Features** dialog box to remove or replace a phonological feature. This is true for natural classes that are defined by features.

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Phonemes**.

2.  In the **Phonemes** pane, click the phoneme that has the phonological feature you will remove.

3.  In the `Phoneme` pane, click the **Phonological Features** field, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose Phonological Features** dialog box appears.

4.  Click the feature you want to remove.

5.  Do one of the following in the **Value** column:

    - To remove a feature, select **\<n/a\>**. Then, you may [choose](../Phonemes/Choose_phonological_features.md) a different feature, if necessary.

    - To replace the current feature, select a different value.

6.  Click **OK**.

    The feature is removed from or changed in the **Phonological Features** field.
