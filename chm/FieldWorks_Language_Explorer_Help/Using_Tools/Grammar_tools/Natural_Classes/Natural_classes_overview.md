# Natural classes overview

*Using Tools › Grammar tools › Natural Classes*

The **Natural Classes** `Help` topics are the following:

- [Insert a natural class](Insert_a_Natural_Class.md)

  - [Choose phonemes](Choose_Phonemes_for_Natural_Class.md)

  - [Choose phonological features](Choose_phonological_features(NC).md)

  - [Edit a natural class](Edit_a_natural_class.md)

  - [Remove a phonological feature](Remove_a_phonological_feature(NC).md)

- [Delete a natural class](Delete_a_natural_class.md)

> [!NOTE]
>
> - Natural classes are used by [Environments](../Environments/Environments_overview.md) ([examples](../Environments/Environment_String_Rep_examples.md)), [Phonological Rules](../Phonological_Rules/Phonological_Rules_overview.md), [Affix Process Rules](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Affix_Process_Rule_field.md) (for the [lexeme form](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Lexeme_Form_field.md) and any [allomorphs](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Alternate_Forms_level_flds/Alt_Forms_lev_flds_ov.md)), and [pattern-matching entries](../../Lexicon_tools/Lexicon_Edit/Create_a_Template_Entry.md) for [GuessRoots](../../../User_Interface/Menus/Parser/About_parser_parameters.md) in the Hermit Crab [parser](../../../User_Interface/Menus/Parser/Parser_menu_overview.md).
>
> <!-- -->
>
> - If you use one of the computational [parsers](../../../User_Interface/Menus/Parser/Parsing_words_overview.md), then natural classes are part of how the parser determines where allomorphs can appear.
>
> - You can insert natural classes that are defined by [phonemes](../Phonemes/Phonemes_overview.md) *or* by [phonological features](../Phonological_Features/Phonological_Features_overview.md). Some common ones are *consonants*, *vowels*, *voiceless stops*, and *back vowels*.
>
> - - Language Explorer may automatically create a natural class. **See:** [Edit a natural class](Edit_a_natural_class.md).
