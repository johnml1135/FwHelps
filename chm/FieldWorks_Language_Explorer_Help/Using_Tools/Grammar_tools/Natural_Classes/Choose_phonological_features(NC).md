# Choose Phonological Features (Natural Classes)

*Using Tools › Grammar tools › Natural Classes*

For natural classes that are defined by features, you choose phonological features as follows:

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Natural Classes**.

2.  In the **Natural Classes** pane, click the desired natural class.

3.  In the **Natural Classes** `(Features)` pane, click the [Phonological Features](../../../User_Interface/Field_Descriptions/Grammar/Natural_Classes_fields/Phonological_Features_fld(NC).md) field, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose Phonological Features** dialog box appears.

4.  If necessary, [configure the columns](../../../Basic_Tasks/Configure_Columns/Using_Configure_Columns_dialog_box.md) (click ![](../../../assets/images/Using_Tools/Grammar_tools/Bulk_Edit_Phoneme_Features/Conf_Columns_Button.GIF)) in the dialog box.

5.  If a feature you need is *not* shown, click the link to open **Phonological Features**. There you can [insert a phonological feature](../Phonological_Features/Insert_a_phonological_feature.md).

<!-- -->

6.  If the feature you need is shown, click it. Then, in the **Value** column, select **+**, **-** or a value you [inserted](../Phonological_Features/Insert_a_phonological_feature_value.md). (**\<n/a\>** removes a selection.)

Repeat this step for each feature/value you want to appear in the **Phonological Features** field.

7.  Click **OK**.

The feature/value or features/values appear in the **Phonological Features** field in square brackets, such as **\[son:+\]** or **\[son:+ cons:+\]**.
