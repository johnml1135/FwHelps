# Delete a natural class

*Using Tools › Grammar tools › Natural Classes*

1.  In the **Navigation Pane**, click **Grammar**, and then click **Natural Classes**.

2.  In the **Natural Classes** pane, select the natural class you will delete, and then do one of the following:

    - On the [Standard](../../../User_Interface/Toolbars/Standard_toolbar.md) toolbar, click ![](../../../assets/images/Using_Tools/Grammar_tools/Natural_Classes/RedDeleteRecordX.GIF).

    - On the **Edit** menu, click **Delete Natural Class (Phonemes)**.

    - Right-click the natural class, and then click **Delete Natural Class (Phonemes)**.

    The **Delete** **Natural Class (Phonemes)** warning box appears.

3.  If you are sure you want to delete the natural class, click **Delete**.

    The specified natural class is deleted.

    - Otherwise, click **Cancel**.

> [!IMPORTANT]
>
> - Natural classes are *required* for some [environments](../Environments/Environments_overview.md) and are used by [parsers](../../../User_Interface/Menus/Parser/Parsing_words_overview.md).
>
> - It is *strongly recommended* that you [back up](../../../User_Interface/Menus/File/Backup_and_Restore/Back_up_this_Project.md) your project before deleting **Lists** or **Grammar** items.
