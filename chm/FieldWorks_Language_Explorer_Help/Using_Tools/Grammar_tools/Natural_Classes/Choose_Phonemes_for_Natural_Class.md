# Choose phonemes for natural class

*Using Tools › Grammar tools › Natural Classes*

1.  In the **Navigation Pane**, click **Grammar**, and then click **Natural Classes**.

2.  In the **Natural Classes** pane, click the natural class to which you will choose phonemes.

3.  In the **Natural Class (Phonemes)** pane, click **Phonemes** field or label.

4.  Click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose Phonemes** dialog box appears.

5.  Do any of these steps:

    - If a phoneme you need is not listed, [insert a phoneme](../Phonemes/Insert_a_phoneme.md).

6.  - Select (![](../../../assets/images/CheckedBox.PNG)) one or more phonemes that you want to add to the current natural class.

    - Use the check box button (![](../../../assets/images/Using_Tools/Grammar_tools/Natural_Classes/Check_Box_Button.GIF)) commands:

**Select All** *selects all* displayed phonemes.

**Clear All** *removes all* check marks.

**Toggle** *reverses* the selections.

6.  Click **OK**.

    The selected phonemes are added to the **Phonemes** field.
