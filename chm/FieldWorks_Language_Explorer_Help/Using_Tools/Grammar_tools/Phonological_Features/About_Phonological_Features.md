# About Phonological Features

*Using Tools › Grammar tools › Phonology Features*

FieldWorks Language Explorer (FLEx) allows you to define a phonological feature system for the language you are working on. The phonological feature system is in addition to the [Inflection Features and Feature Types](../Inflection_Features/About_Infl_Features_and_Types.md).

In **Phonological Features** ([Grammar](../grammar_overview.md)), you can [insert phonological features from a catalog](Insert_a_phonological_feature.md), or create custom phonological features. The phonological features in the catalog are all binary. That is, each has a positive value and a negative value, such as **voice**: **+** (voiced) and **-** (unvoiced).

> [!TIP]
>
> - **Phonological Features** [field](../../../User_Interface/Field_Descriptions/Grammar/Phonemes_fields/Phonological_Features_field.md) contains a description of features and phonemes.
>
> - For additional information, point to **Resources** on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
