# Using Add Phonological Features from Catalog dialog box

*Using Tools › Grammar tools › Phonology Features*

You use the **Add Phonological Features from Catalog** dialog box to select one or more predefined phonological features. The ones you select are added to **Phonological Features** ([Grammar](../grammar_overview.md)).

In the **Add Phonological Features from Catalog** dialog box, do *one* of the following:

- In the **Phonological Features Catalog** pane, select (![](../../../assets/images/Using_Tools/Grammar_tools/Phonological_Features/CheckedFeature.PNG)) one or more feature, and then click **Add**.

- Click the "**The phonological feature I need is not shown in the Catalog. Create a custom phonological feature**" link.

  The open dialog box closes. A new features are added to the **Phonological Features** pane. Fields appear in the **Phonological Feature and Values** pane so you can enter data in them.

> [!NOTE]
>
> - The catalog lists the features in a hierarchical structure.
>
> - - Click the ![](../../../assets/images/Using_Tools/Grammar_tools/Phonological_Features/Plus_sign_box.GIF) (plus sign) to expand a collapsed level.
>
>   - If you select the top level (**All phonological features**), *all* the features are selected.
>
>   - The second level identifies groups of features, such as **major class features** and **laryngeal features**. If you select a group of features, all of its subordinate features are selected.
>
> - If you select any check box in the left pane, a description appears in the **Phonological Features Description** pane.
>
> - You use this dialog box only to *add* phonological features. You cannot clear a check box to remove an existing feature. **See:** [Delete a phonological feature](Delete_a_phonological_feature.md) or [Delete a phonological feature value](Delete_a_phonological_feature_value.md).
