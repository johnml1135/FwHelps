# Insert a phonological feature

*Using Tools › Grammar tools › Phonology Features*

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Phonological Features**.

2.  Do one of the following:

    - On the [Insert](../../../User_Interface/Toolbars/Insert_toolbar.md) toolbar, click ![](../../../assets/images/Using_Tools/Grammar_tools/Inflection_Features/Add_Feature.GIF).

    - On the **Insert** menu, click **Phonological Feature**.

    The **Add Phonological Features from Catalog** dialog box appears.

3.  [Use](Using_Add_Ph_Features_Cat_dialog_box.md) the **Add Phonological Features from Catalog** dialog box to insert one or more features from the catalog or to create a custom feature.

4.  As necessary, edit existing content in fields

5.  As necessary, [insert a phonological feature value](Insert_a_phonological_feature_value.md).
