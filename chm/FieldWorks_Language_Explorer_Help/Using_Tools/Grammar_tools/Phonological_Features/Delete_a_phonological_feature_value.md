# Delete a phonological feature value

*Using Tools › Grammar tools › Phonology Features*

1.  In the **Navigation** **Pane**, click **Grammar**, and then select **Phonological Features**.

2.  In the **Phonological Features** pane, select the feature that has the value you will delete.

3.  In the **Phonological Feature and Values** pane, do one of the following:

    - Click the **Value Name** label of the feature value you will delete. Click the menu button ![](../../../assets/images/Using_Tools/Grammar_tools/Inflection_Features/Menu_Button_pic.GIF) that appears, and then select **Delete Feature Value**.

    - Right-click the **Value Name** label of the feature value you will delete, and then select **Delete Feature Value**.

    The **Delete Feature Value** warning box appears and asks if want to continue with the deletion.

4.  If you are sure you want to delete the feature value, click **Delete**.

    The specified feature value is deleted.

    - Otherwise, click **Cancel**.
