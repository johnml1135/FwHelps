# Insert a phonological feature value

*Using Tools › Grammar tools › Phonology Features*

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Phonological Features**.

2.  In the **Phonological Features** pane, select an existing feature to which you will insert a value, *or* [insert a new feature](../Inflection_Features/Insert_a_Feature_or_Complex_Feature.md).

3.  In the **Feature** pane, click the **Values** label.

    A link and a menu button (![](../../../assets/images/Using_Tools/Grammar_tools/Phonemes/Menu_Button_pic.GIF)) appear.

4.  Do one of the following:

    - Click the **Insert Feature Value** link.

    - Click the menu button, and then select **Insert Feature Value**.

    - Right-click the **Values** label, and then select **Insert Feature Value**.

    - In the **Insert** menu, click **Feature Value**.

    One new set of empty fields appear for a new value.

5.  Enter content in the **Value Name**, **Abbreviation**, and **Description** fields.
