# Delete a phonological feature

*Using Tools › Grammar tools › Phonology Features*

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Phonological Features**.

2.  In the **Phonological Features** pane, select the feature you will delete.

3.  Do one of the following:

    - On the [Standard](../../../User_Interface/Toolbars/Standard_toolbar.md) toolbar, click ![](../../../assets/images/Using_Tools/Grammar_tools/Inflection_Features/RedDeleteRecordX.GIF).

    - Click the **Edit** menu field click **Delete Feature**.

    - Right-click the phonological feature, and then select **Delete selected Feature**.

    The **Delete Feature** warning box appears and asks if you want to continue with the deletion.

4.  If you are sure you want to delete the phonological feature, click **Delete**.

    The phonological feature.

    - Otherwise, click **Cancel**.
