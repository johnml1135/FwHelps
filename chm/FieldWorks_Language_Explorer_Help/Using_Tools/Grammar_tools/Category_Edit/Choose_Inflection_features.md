# Choose inflection features for a Feature Set

*Using Tools › Grammar tools › Category Edit*

Stem Allomorph Labels use Feature Sets. The inflection features available for a Feature Set are only those currently in the **Inflectable Features** field for the current category *or* a parent category.

1.  In the **Navigation Pane**, click **Grammar**, and then click **Category Edit**.

2.  In the center column, select the category.

3.  In the **Category (or Part of Speech)** pane, do any of the following:

    - If necessary, [choose inflectable features](Choose_inflectable_features.md).

    - If necessary, [insert a Stem Allomorph Label](Insert_a_Stem_Allomorph_Label.md).

    - If necessary, [insert a Feature Set](Insert_a_Feature_Set.md).

4.  Click the appropriate **Feature Set** field. Then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose Inflection Feature** dialog box appears.

5.  Do any of these steps:

    - Select (![](../../../assets/images/SelectedRadioButton.png)) the inflection features you want to display or select (![](../../../assets/images/SelectedRadioButton.png)) **None of the above** to clear an existing selection for a particular inflection feature.

    - If an inflection feature you need is not shown, click the link to open the **Choose Inflectable Features** dialog box.

    - Click **OK**.

> [!TIP]
>
> - A category can have more than one Stem Allomorph Label, and each Stem Allomorph Label can have more than one Feature Set. So be careful that you choose features for the correct Feature Set.
>
> - Make sure that you have at least one [inflectional template](Edit_an_Affix_Template_Table.md) defined for the category (or categories) that use Stem Allomorph Labels. [Insert a Stem Allomorph Label](Insert_a_Stem_Allomorph_Label.md) has more information.
>
> - For a discussion of Stem Allomorph Labels and Feature Sets, point to **Resources** on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
