# Insert an affix slot

*Using Tools › Grammar tools › Category Edit*

You can insert a slot independent from a particular affix template table *or* as you [edit a template](Edit_an_Affix_Template_Table.md) table. See ![](../../../assets/images/Important_Icon.gif) **Important** below before you continue.

1.  In the **Navigation Pane**, click **Grammar**, and then click **Category Edit**.

2.  In the center column, select the category in which you will insert an affix slot.

3.  In the **Category (or Part of Speech)** pane, click the [Affix Slots](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Affix_Slots_field_Category_Edit.md) field label for the category *or* subcategory.

    A link and a menu button (![](../../../assets/images/Using_Tools/Grammar_tools/Category_Edit/Menu_Button_pic.GIF)) appear.

4.  Do one of the following:

    - Click the **Insert Affix Slot** link.

    - Click the menu button, and then click **Insert Affix Slot**.

    - In the **Insert** menu, click **Affix Slot**.

    The **Name** and **Description** fields and an **Optional** check box appears.

5.  Click the **Name** field, and then enter a name.

6.  Click the **Description** field, and then enter a description.

7.  If this slot is *optional*, that is not *obligatory*, select the **Optional** check box.

> [!IMPORTANT]
>
> - As indicated in [Category Edit overview](Category_Edit_overview.md), you can put affix slots at the top-most parent category in the hierarchical category list, or in a subcategory or sub-subcategory. You control where the slot is stored and its availability to the **Choose Slot** dialog box used in template tables.
>
>   For example, if in a sub-subcategory you insert an affix slot *from* *within* a [template table](Insert_an_affix_template.md), that slot is stored in the **Affix Slots** area of the top-most *parent* category. You would *not* see it in the **Affix Slots** areas of the subcategory or sub-subcategory. However, this slot *is available* in the dialog box if you [edit the template](Edit_an_Affix_Template_Table.md) of the parent, subcategory or sub-subcategory.
>
>   However, if following the steps in this topic you insert a slot in the **Affix Slots** area (*not* *from within* a template table), then the slot is stored at the hierarchical level where you inserted it. Therefore, if you insert a slot in the sub-subcategory, the slot will appear in the sub-subcategory's **Affix Slot** area, and is *only available* in the dialog box at that sub-subcategory level.
>
> - For more information and examples, point to **Resources** on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
