# Insert an inflection class subclass

*Using Tools › Grammar tools › Category Edit*

1.  In the **Navigation Pane**, click **Grammar**, and then click **Category Edit**.

2.  In the center column, select the category.

3.  In the **Category (or Part of Speech)** pane, click the [SubClasses](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/subclasses_field_category_edit.md) field label under which you will insert an inflection class subclass.

    The menu button (![](../../../assets/images/Using_Tools/Grammar_tools/Category_Edit/Menu_Button_pic.GIF)) appears to the left of the label.

4.  Do one of the following:

    - Click the menu button, and then click **Insert Inflection Class**.

    - Right click the field label, and then click **Insert Inflection Class**.

    A new subclass field set is inserted with **Subclass Name**, **Abbreviation**, and **Description** fields.

5.  Enter content in the fields.

> [!TIP]
>
> - For more information, point to **Resources** on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
