# Insert an affix template

*Using Tools › Grammar tools › Category Edit*

1.  In the **Navigation Pane**, click **Grammar**, and then click **Category Edit**.

2.  In the center column, click the category to which you will insert an affix template.

    - The categories are organized in a hierarchy. Where in the hierarchy you insert the template can make a difference. See [Category Edit overview](Category_Edit_overview.md) for more information.

3.  Click [Affix Templates field](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Affix_Templates_field_Category_Edit.md) label for the category *or* a subcategory.

    A link and a menu button (![](../../../assets/images/Using_Tools/Grammar_tools/Category_Edit/Menu_Button_pic.GIF)) appear.

4.  Do one of the following:

    - Click the **Insert Affix Template** link.

    - Click the menu button, and then select **Insert Affix Template**.

    - On the **Insert** menu, click **Affix Template**.

    These fields appear: **Template Name**, **Description**, **Table**, **Note** and **Requires more derivation**.

5.  Enter a template name and a description.

6.  Insert an affix slot into the template table as follows:

    - In the [Table field](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Table_field.md), right-click **STEM**, and then select **Insert Slot Before Stem** or **Insert Slot After Stem**.

      The **Choose Slot** dialog box appears.

    - Do one of the following:

      - Select an *existing* slot, and then click **OK**.

        The name of the slot appears in the [table](affix_template_table_example.md) (in parenthesis, if *optional*).

      - Click **Cancel** to close the **Choose Slot** dialog box, and then insert an affix slot at a *different level* *in the category hierarchy*. ([Insert an affix slot](Insert_an_Affix_Slot.md) and [Category Edit overview](Category_Edit_overview.md) both discuss hierarchical levels.) Then, subsequently [edit the template table](Edit_an_Affix_Template_Table.md) as necessary.

      - Click the **Add an optional slot** or the **Add an obligatory slot** link to add a new slot.

        The phrase **Type slot name here** appears in the table.

    - If **Type slot name here** appears, select it, and then enter a slot name.

7.  If necessary, select the [Requires more derivation](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/requires_more_derivation_field.md) check box.

8.  Add inflectional affixes and [edit the template](Edit_an_Affix_Template_Table.md) as needed.

> [!TIP]
>
> - To change the *optional* versus *obligatory* setting of a slot, do *one* of the following:
>
>   - In the table, right-click the slot name, and then select **Change Optionality of (**`name`**) slot**.
>
>   - In the **Affix Slots** field set for the particular slot, select or clear the **Optional** check box.
>
>   - For additional explanation such as regarding **Requires more derivation**, point to **Resources** on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
