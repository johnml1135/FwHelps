# Delete an affix slot

*Using Tools › Grammar tools › Category Edit*

The steps in this topic help you *delete* a slot from a category and from any [template table](Insert_an_affix_template.md) that uses the slot. Alternatively, if you only want to *remove* a slot from an affix template table, but not from the category, refer to [Edit an affix template table](Edit_an_Affix_Template_Table.md).

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Category Edit**.

2.  In the center column, click the category from which you will delete an affix slot.

3.  In the **Category (or Part of Speech)** pane, do one of the following for the affix slot you will delete:

    - Right-click the [Slot Name](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/name_field_slot_category_edit.md) field label, and then click **Delete Affix Slot**.

    - Click the **Slot Name** field label. Click the menu button ![](../../../assets/images/Using_Tools/Grammar_tools/Category_Edit/Menu_Button_pic.GIF) that appears, and then click **Delete Affix Slot**.

    The **Delete Affix Slot** warning box appears.

4.  Click **Delete**.

    The slot specified in the warning box is deleted from the category, and is removed from any affix templates in which it had been used.
