# Choose inflectable features

*Using Tools › Grammar tools › Category Edit*

1.  In the **Navigation Pane**, click **Grammar**, and then click **Category Edit**.

2.  In the center column, select the category for which you will choose **Inflectable Features**.

3.  In the **Category (or Part of Speech)** pane, click the [Inflectable Features](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Inflectable_Features_field_Category_Edit.md) field, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose Inflectable Features** dialog box appears.

(The **Choose Inflectable Features** dialog box may have been opened from the **Choose Inflection Features** dialog box when you [choose Inflection Features for a Feature Set](Choose_Inflection_features.md).)

4.  Do any of the following:

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times each feature is used in the project.

    - Click the **Edit the Features** link to edit an existing feature or [insert](../Inflection_Features/Insert_a_Feature_or_Complex_Feature.md) another one.

    - Select (![](../../../assets/images/CheckedBox.PNG)) one or more defined feature. Click **OK**.

      The selected feature(s) appears in the **Inflectable Features** field.

> [!TIP]
>
> - For a given category, only inflection features in the **Inflectable Features** field are available for use in the various **Inflection Features** fields (**Lexicon Edit**).
>
> - [Stem Allomorph Labels](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Stem_Allomorph_Label_field.md) use inflectable features in [Feature Sets](Insert_a_Feature_Set.md). See [Insert a Stem Allomorph Labels](Insert_a_Stem_Allomorph_Label.md).
>
> - For more information and examples, point to **Resources** on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
