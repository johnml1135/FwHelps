# Move an Affix Template

*Using Tools › Grammar tools › Category Edit*

You can move an Affix Template up or down to reorder multiple named templates. This includes the **Table** [field](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Table_field.md) and all the other associated fields.

1.  Select (![](../../../assets/images/CheckedBoxBLACK.png)) the **Show Hidden Fields** check box, if it is not already selected.

2.  Click the menu button (![](../../../assets/images/Basic_Tasks/Showing_and_hiding_fields/Menu_Button_pic.GIF)) for the **Template Name** [field](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/name_field_template_category_edit.md) and then click **Move Affix Template Up** or **Move Affix Template Down**.

- Do the step above until the field is where you want it to appear.
