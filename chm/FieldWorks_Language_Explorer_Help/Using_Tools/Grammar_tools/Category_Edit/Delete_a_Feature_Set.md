# Delete a Feature Set

*Using Tools › Grammar tools › Category Edit*

**Feature Sets** are under **Stem Allomorphy Labels** in **Category Edit**.

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Category Edit**.

2.  In the center column, click the category from which you will delete a Feature Set.

3.  In the **Category (or Part of Speech)** pane, click the [Feature Set](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Feature_Set_field_Category_Edit.md) field label you will delete.

    The menu button (![](../../../assets/images/Using_Tools/Grammar_tools/Category_Edit/Menu_Button_pic.GIF)) appears.

4.  Click the menu button, and then click **Delete Feature Set**.

    The **Delete Feature Structure** warning box appears.

5.  Click **Delete**.

    The Feature Set specified in the warning box is deleted.

> [!TIP]
>
> - You can also right-click the **Feature Set** field to access the **Delete Feature Set** menu command.
