# Choose Default Inflection Class

*Using Tools › Grammar tools › Category Edit*

[Parsers](../../../User_Interface/Menus/Parser/Parsing_words_overview.md) use the content in the **Default Inflection Class** field when a lexical entry for this category does *not* have an inflection class overtly marked for it.

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Category Edit**.

2.  In the center column, click the category.

3.  In the **Category (or Part of Speech)** pane, click the [Default Inflection Class](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Default_Inflection_Class_field.md) field (under **Inflectional Class Info**), and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears.

    The **Choose** **Default Inflection Class** dialog box appears.

4.  Do any of these steps:

    - Select (![](../../../assets/images/CheckedBox.PNG)) **Display usage figures** to see how many times each inflection class or subclass is used in the project.

    <!-- -->

    - Choose an inflection class, subclass or **\<empty\>**. Click **OK**.

      That class or subclass appears in the **Default Inflection Class** field, or the field is cleared (becomes empty).

> [!NOTE]
>
> - If the inflection class you need is not shown in the dialog box, click **Cancel**.
>
>   The dialog box closes so you can [insert an inflection class](Insert_an_Inflection_Class.md) or [subclass](Insert_an_Inflection_Class_Subclass.md). Then, do this topic again.
