# Insert a subcategory

*Using Tools › Grammar tools › Category Edit*

1.  In the **Navigation Pane**, click **Grammar** and then click **Category Edit**.

2.  In the center column, select the category under which you will insert a subcategory.

3.  In the **Category (or Part of Speech)** pane, do one of the following:

    - On the [Insert](../../../User_Interface/Toolbars/Insert_toolbar.md) toolbar, click ![](../../../assets/images/Using_Tools/Grammar_tools/Category_Edit/Insert_Subcategory.GIF).

    - On the **Insert** menu, click **Subcategory**.

    - Right-click the **Subcategories** label, and then select **Insert Subcategory**.

      The [Add from Catalog](../../Lexicon_tools/Lexicon_Edit/Using_Add_from_Catalog_dialog_box.md) dialog box appears.

4.  In the dialog box, do one of the following:

    - In the **Grammatical Category Catalog** area, select the desired subcategory, and then click **Add**.

      If a category or subcategory is already used in the project, it is *unavailable* for selection in the catalog.

    - Click the **Create a custom category** link.

    The selected subcategory or a new (not completed) subcategory appears in **Category (or Part of Speech)** area.

5.  For a custom subcategory, in the **Category (or Part of Speech)** pane, enter the name, abbreviation, and description to complete it.

> [!IMPORTANT]
>
> - Refer to [Category Edit overview](Category_Edit_overview.md) for information about how the hierarchical order of categories and subcategories can affect your language project and for additional topics related to the various fields in the new subcategory.
