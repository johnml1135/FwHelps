# Insert an inflection class

*Using Tools › Grammar tools › Category Edit*

1.  In the **Navigation Pane**, click **Grammar**, and then click **Category Edit**.

2.  In the center column, select the category or subcategory in which you will insert an **Inflection Class**.

3.  In the **Category (or Part of Speech)** pane, click the [Inflectional Class Info](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Inflection_Class_Info_field_Category_Edit.md) field label for the category *or* subcategory.

    A link and a menu button (![](../../../assets/images/Using_Tools/Grammar_tools/Category_Edit/Menu_Button_pic.GIF)) appear.

4.  Do one of the following:

    - Click the **Insert Inflection Class** link.

    - Click the menu button, and then select **Insert Inflection Class**.

    - On the **Insert** menu, click **Inflection Class**.

    The **Name**, **Abbreviation**, and **Description** fields appear.

    A **SubClasses** field label also appears under which you can [insert an inflection class subclass](Insert_an_Inflection_Class_Subclass.md).

5.  Enter content in the [Inflection Class Name](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/name_field_inflection_class_category_edit.md) field, [Abbreviation](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/abbreviation_field_inflection_class_category_edit.md) field and [Description](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/description_field_inflection_class_category_edit.md) field. Then, if necessary, select or change the [default inflection class](choose_a_default_inflection_class.md).

> [!TIP]
>
> - For more information such as use of inflection *classes* or inflection *features*, point to **Resources** on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
