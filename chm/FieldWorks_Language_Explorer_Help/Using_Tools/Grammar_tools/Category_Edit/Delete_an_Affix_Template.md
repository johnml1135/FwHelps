# Delete an affix template

*Using Tools › Grammar tools › Category Edit*

Optionally, before you delete an affix template, you can first make it [inactive](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Active_field_templates.md) to see how the template affects parsing.

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Category Edit**.

2.  In the center column, click the category from which you will delete an affix template.

3.  In the **Category (or Part of Speech)** pane, do one of the following for the affix template you will delete:

    - Right-click the [Template Name](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/name_field_template_category_edit.md) field label, and then click **Delete Affix Template**.

    - Click the **Template Name** field label. Click the menu button ![](../../../assets/images/Using_Tools/Grammar_tools/Category_Edit/Menu_Button_pic.GIF) that appears, and then click **Delet****e Affix Template**.

    The **Delete Inflectional Affix Template** warning box appears.

4.  Click **Delete**.

    The specified template is deleted.
