# Delete an inflection class or subclass

*Using Tools › Grammar tools › Category Edit*

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Category Edit**.

2.  In the center column, click the category from which you will delete an inflection class and any subclasses, or only a subclass.

3.  In the **Category (or Part of Speech)** pane, click the desired [Inflection Class Name](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/name_field_inflection_class_category_edit.md) field label under the **Inflectional Class Info**, *or* the [Subclass Name](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/name_field_inflection_class_category_edit.md) field label under **Subclasses**.

    The menu button (![](../../../assets/images/Using_Tools/Grammar_tools/Category_Edit/Menu_Button_pic.GIF)) appears.

4.  Click the menu button, and then click **Delete Inflection Class**.

    The **Delete Inflection Class** warning box appears. If you selected a top-level inflection class, any subclasses under it will be deleted as well.

5.  If you are sure you want to delete the inflection class or subclass identified in the warning box, click **Delete**.

    The inflection class or subclass specified in the warning box is deleted.

    - Otherwise, click **Cancel**.
