# Insert a Feature Set

*Using Tools › Grammar tools › Category Edit*

A category can have more than one Stem Allomorph Label. Under each Stem Allomorph Label, you will need one feature set for *each* mutually exclusive set of features. One **Feature Set** field is added when you insert a Stem Allomorph Label. Be careful to insert subsequent feature sets under the correct **Stem Allomorph Label** field.

1.  In the **Navigation Pane**, click **Grammar** and then click **Category Edit**.

2.  In the center column, select the category to which you want to add a Feature Set.

3.  If necessary, [insert a Stem Allomorph Label](Insert_a_Stem_Allomorph_Label.md).

4.  In the **Category (or Part of Speech)** pane, click the [Feature Sets](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Feature_Sets_field_Category_Edit.md) field label that is *under the appropriate* **Stem Allomorph Label**, and then do one of the following:

    - Click the **Insert Feature Set** link that appears.

    - Click the menu button ![](../../../assets/images/Using_Tools/Grammar_tools/Category_Edit/Menu_Button_pic.GIF) that appears, and then select **Insert Feature Set**.

    - Right-click the **Feature Sets** label, and then select **Insert Feature Set**.

      A [Feature Set](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Feature_Set_field_Category_Edit.md) field appears.

5.  [Choose](Choose_Inflection_features.md) a set of inflection features that are relevant to this Stem Allomorph Label.

> [!TIP]
>
> - The topic [Insert a Stem Allomorph Label](Insert_a_Stem_Allomorph_Label.md) has important information about Stem Allomorph Labels and Feature Sets.
>
> - The inflection features available for selection in the dialog box are only those present in the **Inflectable Features** field for the current category or a parent category.
>
> - For a discussion of Feature Sets (used with Stem Allomorph Labels), point to **Resources** on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
