# Duplicate an affix template

*Using Tools › Grammar tools › Category Edit*

Within a category (or part of speech), you can duplicate an existing affix template (fields and table contents). The duplicated template is inserted directly below the original. This is an alternative to inserting a new (empty) affix table.

The tables can have different slots. Affixes you add or remove from a slot that is in both tables will be added or removed from both tables.

To duplicate an affix template, do the following steps:

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Category Edit**.

2.  In the center column, click the category that has the affix template you will duplicate.

3.  In the **Category (or Part of Speech)** pane, right-click the **Template Name** field label of the affix template you will duplicate, and then click **Duplicate Affix Template**.

    The [Template Name](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/name_field_template_category_edit.md), [Description](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/description_field_template_category_edit.md), [Table](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Table_field.md) and [Requires more derivation](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/requires_more_derivation_field.md) fields and their contents are duplicated and inserted directly below the original table.

4.  [Edit the affix template table](Edit_an_Affix_Template_Table.md) and fields as necessary.

> [!NOTE]
>
> - The affix template is *not* copied to your clipboard, so **Paste** (**Ctrl+V**) is not needed or available.
>
> - For more information, point to **Resources** on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**. See section **2.1.2.3 Multiple Templates**.
