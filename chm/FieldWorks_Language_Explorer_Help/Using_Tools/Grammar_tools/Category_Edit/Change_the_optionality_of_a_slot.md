# Change the optionality of a slot

*Using Tools › Grammar tools › Category Edit*

1.  In the **Navigation Pane**, click **Grammar**, and then click **Category Edit**.

2.  In the center column, click the category you will change.

3.  To change the optionality from inside an [affix template table](affix_template_table_example.md), do the following:

    - In the **Affix Templates** area, right-click the slot name in the heading of the table, and then select **Change Optionality of** **\<name\>** **Slot**.

      The optionality of the slot toggles as indicated by the addition or removal of the parenthesis around the slot name.

4.  To change the optionality directly in the slot, do the following:

    - In the **Affix Slots** area, select (![](../../../assets/images/CheckedBoxBLACK.png)) or clear (![](../../../assets/images/UncheckedBox.PNG)) the [Optional](../../../User_Interface/Field_Descriptions/Grammar/Category_Edit_fields/Optional_field.md) field check box for the slot you want to change.

      If a template table is shown in the **Affix Templates** area, you will see the parenthesis appear or disappear for that slot. If no template tables are shown in the pane, the only visible effect you see is the **Optional** check box.

> [!IMPORTANT]
>
> - Slots have two optionality settings, O*ptional* or *Obligatory*.
>
>   In the **Category (or Part of Speech)** pane, you can change the setting in the **Affix Templates** area, that is, in a [template table](affix_template_table_example.md), *or* in a slot in the **Affix Slots** area. A setting made to a slot is applied to all template tables used in that category and any subordinate categories.
>
> - You can insert a slot from *within* a template table *or* in the **Affix Slots** area (*outside of* a template table), but the results are different. Refer to [Insert an affix slot](Insert_an_Affix_Slot.md) for a discussion about this.
