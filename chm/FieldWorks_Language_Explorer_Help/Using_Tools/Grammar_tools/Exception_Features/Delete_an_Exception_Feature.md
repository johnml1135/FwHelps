# Delete an exception feature

*Using Tools › Grammar tools › Exception "Features"*

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Exception "Features**.**"**

2.  In the **Exception "Features"** pane, select the exception "feature" you will delete.

3.  Do one of the following:

    - On the [Standard](../../../User_Interface/Toolbars/Standard_toolbar.md) toolbar, click ![](../../../assets/images/Using_Tools/Grammar_tools/Inflection_Features/RedDeleteRecordX.GIF).

    - On the **Edit** menu, click **Delete Inflection "Feature"**.

    - Right-click, and then select **Delete Selected Inflection "Feature"**.

    The **Delete List Item** warning box appears and asks if want to continue with the deletion.

4.  If you are sure you want to delete the exception "feature" specified in the warning box, click **Delete**.

    The specified exception "feature" is deleted.
