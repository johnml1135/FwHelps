# Insert an exception feature

*Using Tools › Grammar tools › Exception \"Features\"*

1.  In the **Navigation** **Pane**, click **Grammar**, and then click **Exception "Features**.**"**

2.  Do one of the following:

    - On the [Insert](../../../User_Interface/Toolbars/Insert_toolbar.md) toolbar, click ![](../../../assets/images/Using_Tools/Grammar_tools/Exception_Features/Insert_Exception_Feature.GIF).

    - In the **Insert** menu, click **Exception** "**Feature**."

    An empty set of fields appears in the **Exception** **"Feature"** pane.

3.  Enter a name, abbreviation and description for the new exception "feature."

> [!TIP]
>
> The content from the **Name** field appears in the dialog box and lexicon field when you [choose exception "features"](../../Lexicon_tools/Lexicon_Edit/choose_exception_features.md).
