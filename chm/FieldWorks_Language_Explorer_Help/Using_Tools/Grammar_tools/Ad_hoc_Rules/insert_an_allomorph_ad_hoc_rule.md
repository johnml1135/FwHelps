# Insert an allomorph ad hoc rule

*Using Tools › Grammar tools › Ad hoc Rules*

1.  In the **Navigation Pane**, click **Grammar**, and then click **Ad hoc Rules**.

2.  Do one of the following:

    - On the [Insert](../../../User_Interface/Menus/Insert/Insert_overview.md) toolbar, click ![](../../../assets/images/Using_Tools/Grammar_tools/Ad_hoc_Rules/Create_AllomorphCoProhibition_Grammar.GIF).

    - On the **Insert** menu, click **Rule to prevent allomorph co-occurrence**.

    A new allomorph ad hoc rule is inserted.

3.  In the **Rule to Prevent Allomorph Co-occurrence** pane, do the following:

    - Click the **Key Allomorph** field, and then click the ellipsis button ![](../../../assets/images/Ellipsis_button.PNG) that appears. In the **Choose Allomorph** dialog box, enter a form of a lexical entry in the **Find** box. In the **Lexical Entries** area, select the desired entry. In the **Allomorph** box, select an allomorph. Click **OK**.

    - Select an item for the **Cannot Occur** field.

    - Click the **Other Allomorph(s)** field, and then click the ellipsis button that appears. In the **Choose Allomorph** dialog box, enter a form of a lexical entry in the **Find** box. In the **Lexical Entries** area, select the desired entry. In the **Allomorph** box, select an allomorph. Click **OK**.

      **Note:** If there are two or more allomorphs listed, the order of these allomorphs is crucial. They *must* occur in the order they would in a word.

> [!TIP]
>
> - In the **Choose Allomorph** dialog box, you may need to select a different writing system in the **Writing System** box if you cannot find the desired lexical entry.
>
> - Once the [Key Allomorph](../../../User_Interface/Field_Descriptions/Grammar/Ad_hoc_Rules_fields/Key_Allomorph_field_Ad_hoc_Rules.md) field has content, you *cannot* select and delete that content. Instead, replace the content with other content.
>
> - For a more complete description of ad hoc rules, point to **Resources** on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**.
