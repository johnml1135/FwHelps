# Delete an ad hoc rule

*Using Tools › Grammar tools › Ad hoc Rules*

Optionally, before you delete a rule, you can first make it [inactive](../../../User_Interface/Field_Descriptions/Grammar/Ad_hoc_Rules_fields/Active_field_Ad_Hoc_Rules.md) to see how the rule affects parsing.

1.  In the **Navigation Pane**, click **Grammar**, and then click **Ad hoc Rules**.

2.  In the **Ad hoc Co-occurrence Prevention Rules** column, click the rule you will delete, and then do one of the following:

    - On the [Standard](../../../User_Interface/Toolbars/Standard_toolbar.md) toolbar, click ![](../../../assets/images/Using_Tools/Grammar_tools/Ad_hoc_Rules/RedDeleteRecordX.GIF).

    - On the **Edit** menu, click **Delete** *\<rule\>.*\
      (*\<rule\>* could be **Rule to Prevent Morpheme Co-occurrence**, **Rule to Prevent Allomorph Co-occurrence** *or* **Group of Ad hoc Rules**.)

    - In the center pane, right-click the unwanted ad hoc rule and then select the **Delete selected** *\<rule\>* command.

    The **Delete** *\<rule\>* warning box appears and asks if want to continue with the deletion.

3.  If you are sure you want to delete the rule or group of rules specified in the warning box, click **Delete**.

    The specified rule is deleted.

    - Otherwise, click **Cancel**.
