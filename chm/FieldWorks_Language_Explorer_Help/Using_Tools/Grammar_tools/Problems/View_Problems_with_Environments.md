# View problems with environments

*Using Tools › Grammar tools › Problems*

Language Explorer "flags" problematic environments with a red wavy underline (such as ![](../../../assets/images/User_Interface/Field_Descriptions/Grammar/Environments_fields/RedUnderlinedEnv.GIF)). You may see this when you [insert](../Environments/Insert_an_environment.md) or [edit](../Environments/Edit_an_Environment.md) one in a [String Representation](../../../User_Interface/Field_Descriptions/Grammar/Environments_fields/String_Representation_field_Environments.md) field, [Environments](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Environments_field.md) field or [Infix Positions](../../../User_Interface/Field_Descriptions/Lexicon/Lexicon_Edit_fields/Entry_level_fields/Infix_Positions_field.md) field.

In **Problems**, the **Records** pane lists all the problematic [environments](../Environments/Environments_overview.md) (unless you [deleted](Delete_a_problem_report.md) the problem report). The [Text](../../../User_Interface/Field_Descriptions/Grammar/Problems_fields/Text_field_Problems.md) field gives a description of the problem.

- Alternatively, right-click a flagged environment, and then select **Describe Error in Environment**. An information box appears with a description of the problem.

> [!TIP]
>
> - For example, the problem could be that the environment refers to a [natural class](../../../User_Interface/Field_Descriptions/Grammar/Natural_Classes_fields/Abbreviation_field_Natural_Classes.md) or a [phoneme](../../../User_Interface/Field_Descriptions/Grammar/Phonemes_fields/representation_field_phonemes.md) that is not defined yet.
>
> - For more information, point to **Resources** on the [Help](../../../User_Interface/Menus/Help/Help_overview.md) menu, and then click **Introduction to Parsing**. See **Allomorph Environments**.
